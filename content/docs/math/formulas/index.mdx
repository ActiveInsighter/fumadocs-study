# 数一公式手册1001

本目录根据《数一公式手册1001》整理，按三门科目和原手册章节顺序收录常用公式，适合复习时快速查找。

- [高等数学](./advanced-mathematics/)：基础预备知识、微积分、微分方程、级数、空间解析几何与曲线曲面积分。
- [线性代数](./linear-algebra/)：行列式、矩阵、向量组、线性方程组、特征值与特征向量、二次型。
- [概率论与数理统计](./probability-statistics/)：随机事件、随机变量、多维分布、数字特征、极限定理、统计推断。

公式用于速查，使用时仍应结合题目条件核对适用范围。
