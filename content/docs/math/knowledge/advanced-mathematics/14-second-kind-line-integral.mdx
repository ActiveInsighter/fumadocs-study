# 第二类曲线积分

## 概念与性质

- 物理意义：变力沿曲线做功
  - 表达式
    - \[
      \int_L \mathbf F\cdot d\mathbf s
      =
      \int_L P\,dx+Q\,dy+R\,dz
      \]
  - \[L\]：运动轨迹
  - \[\mathbf F=\{P,Q,R\}\]：作用力
  - \[
    d\mathbf s=ds\cdot\mathbf n=\{dx,dy,dz\}
    \]
    - \[\mathbf n\]：积分曲线的单位切向量
  - \[
    \int_L P\,dx
    \]
    - \[x\] 轴方向上的分力所做的功
- 基本性质
  - 线性性质
    - \[
      \int_L(k_1F_1+k_2F_2)\,ds
      =
      k_1\int_LF_1\,ds+k_2\int_LF_2\,ds
      \]
    - \[
      \int_L(k_1P_1+k_2P_2)\,dx
      =
      k_1\int_LP_1\,dx+k_2\int_LP_2\,dx
      \]
  - 可加性
    - \[
      \int_{L_1\cup L_2}F\,ds
      =
      \int_{L_1}F\,ds+\int_{L_2}F\,ds,
      \quad L_1\cap L_2=\varnothing
      \]
  - 有向性
    - \[
      \int_LF\,d\mathbf s
      =
      -\int_{L^-}F\,d\mathbf s
      \]

## 计算（二维）

### 化为定积分

- 代入
  - 目标：代入至被积函数自变量中只含积分变量
  - 方法：将曲线方程代入被积函数与积分变量
- 定限：由始至终

### 对称性

- \[L\] 关于 \[y\] 轴对称
  - \[
    \int_LP(x,y)\,dx=
    \begin{cases}
    0,&P(x,y)\text{ 关于 }x\text{ 为奇函数}\\
    2\int_{L_1}P(x,y)\,dx,&P(x,y)\text{ 关于 }x\text{ 为偶函数}
    \end{cases}
    \]
  - \[
    \int_LQ(x,y)\,dy=
    \begin{cases}
    0,&Q(x,y)\text{ 关于 }x\text{ 为偶函数}\\
    2\int_{L_1}Q(x,y)\,dy,&Q(x,y)\text{ 关于 }x\text{ 为奇函数}
    \end{cases}
    \]

### 格林公式

- 公式内容
  - 条件
    - \[L\] 为闭合曲线，\[D\] 为 \[L\] 所围区域
    - \[P,Q\] 在 \[D\] 上有连续的偏导数
    - \[L\] 关于 \[D\] 取正向
  - 结论
    - \[
      \oint_LP\,dx+Q\,dy
      =
      \iint_D
      \left(
      \frac{\partial Q}{\partial x}
      -
      \frac{\partial P}{\partial y}
      \right)\,dx\,dy
      \]
  - 意义：将第二类曲线积分化为二重积分
- 常考题型
  - 比大小或不等式证明
    - 1、化为二重积分
    - 2、结合二重积分的性质及常用不等式
  - 积分曲线不闭合
    - 1、补上一条简单曲线使曲线闭合
    - 2、在闭合曲线上使用格林公式
    - 3、将补的曲线上的积分减去
  - 被积函数有不连续点
    - 基本思路
      - 1、补一条围绕不连续点的闭合曲线（含在原曲线内）
      - 2、在两条曲线之间使用格林公式
      - 3、将补的闭合曲线上积分减去
    - 使用技巧
      - 使用格林公式的结果一般为零
      - 补的曲线方程：令被积函数的分母为充分小的常数

### 积分与路径无关

- 等价描述
  - \[
    \int_LP\,dx+Q\,dy
    \]
    - 在区域 \[G\] 内与路径无关
  - 对 \[G\] 内任意闭合曲线 \[\Gamma\]
    - \[
      \oint_{\Gamma}P\,dx+Q\,dy=0
      \]
- 充要条件
  - 使用前提
    - \[P,Q\] 在 \[G\] 内有连续的偏导数
    - \[G\] 为单连通区域
  - 具体表述
    - 对 \[G\] 内任何区域 \[D\]
      - \[
        \iint_D
        \left(
        \frac{\partial Q}{\partial x}
        -
        \frac{\partial P}{\partial y}
        \right)\,dx\,dy=0
        \]
    - \[
      \frac{\partial Q}{\partial x}
      =
      \frac{\partial P}{\partial y},
      \quad (x,y)\in G
      \]
    - \[P\,dx+Q\,dy\] 为某二元函数的全微分
    - \[(P,Q)\] 为二元函数梯度
    - \[P\,dx+Q\,dy=0\] 为全微分方程
- 常考题型
  - 对条件的考查
    - 证明积分与路径无关
    - 已知积分与路径无关求参数或建立微分方程
  - 计算原函数
    - 不定积分法
    - 曲线积分法（取特殊路径）
    - 解全微分方程
      - \[
        P\,dx+Q\,dy-du=0
        \Rightarrow
        u(x,y)=C
        \]
  - 计算曲线积分
    - 特殊路径法
      - 1、先验证积分与路径无关
      - 2、结合函数特点选取最有利于计算的路径
    - \[
      \int_{(x_1,y_1)}^{(x_2,y_2)}P\,dx+Q\,dy
      =
      \int_{(x_1,y_1)}^{(x_2,y_2)}du
      =
      u(x,y)\Big|_{(x_1,y_1)}^{(x_2,y_2)}
      \]

## 计算（三维）

### 化为定积分

- 代入
  - 目标：代入至被积函数自变量中只含积分变量
  - 方法：将曲线方程代入被积函数与积分变量
- 定限：由始至终

### 斯托克斯公式

- 条件
  - \[L\] 为闭合曲线，\[\Sigma\] 为以 \[L\] 为边界的有向曲面
  - \[P,Q,R\] 在 \[\Sigma\] 上有连续偏导
  - \[L\] 与 \[\Sigma\] 的方向满足右手定则
- 结论
  - \[
    \oint_LP\,dx+Q\,dy+R\,dz
    =
    \iint_{\Sigma}
    \left(
    \frac{\partial R}{\partial y}
    -
    \frac{\partial Q}{\partial z}
    \right)\,dy\,dz
    +
    \left(
    \frac{\partial P}{\partial z}
    -
    \frac{\partial R}{\partial x}
    \right)\,dz\,dx
    +
    \left(
    \frac{\partial Q}{\partial x}
    -
    \frac{\partial P}{\partial y}
    \right)\,dx\,dy
    \]
- 意义：将第二类曲线积分化为第二类曲面积分
- 使用要点
  - 适用范围：积分曲线为两曲面交线，不便于化为参数方程
  - 使用方法：直接使用
