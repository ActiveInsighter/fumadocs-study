```mindmap
# 第一类曲线积分

## 概念和性质

- 物理意义：曲线型物体质量的代数和
- 性质
  - 线性性质
    - \[
      \int_L [k_1f(x,y,z)+k_2g(x,y,z)]\,ds
      =
      k_1\int_L f(x,y,z)\,ds
      +
      k_2\int_L g(x,y,z)\,ds
      \]
  - 可加性
    - \[
      \int_{L_1\cup L_2}f(x,y,z)\,ds
      =
      \int_{L_1}f(x,y,z)\,ds
      +
      \int_{L_2}f(x,y,z)\,ds,
      \quad L_1\cap L_2=\varnothing
      \]
  - 比较定理
    - 估值定理
    - 第一类曲线积分中值定理

## 计算方法

- 化为定积分
  - 代入
    - 1、曲线方程代入积分式
    - 2、弧长微元
      - 三维
        - \[
          ds=\sqrt{(dx)^2+(dy)^2+(dz)^2}
          \]
      - 二维
        - \[
          ds=\sqrt{(dx)^2+(dy)^2}
          \]
  - 定限：从小到大
- 对称性
  - 奇偶性：偶倍奇零
  - 轮换对称性
    - 公式内容
      - 如果积分曲线关于 \(y=x\) 对称，则有
        - \[
          \int_L f(x,y,z)\,ds
          =
          \int_L f(y,x,z)\,ds
          \]
    - 使用技巧
      - 区域识别：如果在积分曲线方程中交换 \(x,y\)，方程不变，则积分区域关于 \(y=x\) 对称
      - 当 \(L\) 关于 \(x=y,\ y=z,\ z=x\) 均对称，则
        - 常用结论
          - \[
            \int_L f(x)\,ds
            =
            \int_L f(y)\,ds
            =
            \int_L f(z)\,ds
            =
            \int_L \frac{f(x)+f(y)+f(z)}{3}\,ds
            \]
```
