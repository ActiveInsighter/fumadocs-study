## 指数函数与对数函数

<MathPlot2D
  title="指数与对数互为反函数"
  description="y = aˣ 与 y = logₐx 的图像关于直线 y = x 对称。拖动底数 a，注意 0 < a < 1 时两条曲线的单调性一起翻转。"
  x={[-4, 5]}
  y={[-3, 5]}
  params={[{ name: 'a', label: 'a', min: 0.2, max: 4, step: 0.01, value: 2.718 }]}
  items={[
    { type: 'function', fn: 'a^x', label: 'y=a^x' },
    { type: 'function', fn: 'ln(x)/ln(a)', label: 'y=\\log_a x' },
    { type: 'function', fn: 'x', label: 'y=x', color: 'gray', dashed: true, width: 1.4 },
    { type: 'point', at: [0, 1], label: '(0,1)', dir: 150 },
    { type: 'point', at: [1, 0], label: '(1,0)', dir: -45 },
  ]}
/>

<Callout title="记忆要点">
$y=e^x$ 在 $x=0$ 处切线为 $y=x+1$，$y=\ln x$ 在 $x=1$ 处切线为 $y=x-1$，由此得到常用不等式 $e^x\ge x+1$ 与 $\ln x\le x-1$。
</Callout>
