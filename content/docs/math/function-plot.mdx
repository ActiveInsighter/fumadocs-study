这里的画板都可以直接改公式、拖动或输入参数、播放参数动画。二维图像用 `FunctionPlot`，三维图像用 `SurfacePlot`；两者已全局注册，复制到任意 MDX 文档即可使用。工具栏提供缩放、复位、全屏和 SVG/PNG 导出，宽屏或全屏时控制面板会移到画板右侧。

## 平面函数：导数与定积分

改变 $a$、$h$、$k$，观察 $y=a(x-h)^2+k$ 的开口与顶点。曲线上的探针给出坐标和斜率，打开“导数”会画出 $f'(x)$ 的图像；阴影是 $[-1, p]$ 上的定积分，拖动 $p$ 看面积如何变化。

<FunctionPlot
  title="函数、导数与面积"
  description="拖动探针读斜率；打开“导数”比较 f 与 f′；拖动 p 改变积分上限。"
  boundingBox={[-5, 7, 5, -4]}
  parameters={[
    { name: 'a', label: '形状系数 a', min: -2, max: 2, value: 1, step: 0.1 },
    { name: 'h', label: '水平平移 h', min: -3, max: 3, value: 0, step: 0.1 },
    { name: 'k', label: '竖直平移 k', min: -3, max: 3, value: -1, step: 0.1 },
    { name: 'p', label: '积分上限 p', min: -1, max: 3, value: 1.5, step: 0.1 },
  ]}
  plots={[
    { type: 'function', expression: 'a*(x-h)^2+k', label: '二次函数', probe: true, derivative: true, area: [-1, 'p'] },
    { type: 'function', expression: 'x+1', label: '比较直线', dashed: true },

## 平面曲线：隐式方程、参数方程与极坐标

圆锥曲线直接写成 $F(x,y)=0$ 或“左式=右式”。改变 $e$ 观察离心率如何把椭圆变成双曲线；焦点 $F$ 的坐标也写成参数表达式，会跟着移动。

<FunctionPlot
  title="圆锥曲线族"
  description="e < 1 是椭圆，e > 1 是双曲线；两焦点随 e 移动。"
  boundingBox={[-6, 5, 6, -5]}
  parameters={[{ name: 'ecc', label: '离心率 e', min: 0, max: 2, value: 0.6, step: 0.05 }]}
  plots={[
    { type: 'implicit', expression: 'x^2/4 + y^2/(4*(1-ecc^2)) = 1', label: '二次曲线' },
    { type: 'implicit', expression: 'x^2+y^2=4', label: '辅助圆', dashed: true },
  ]}
  points={[
    { x: '2*ecc', y: 0, name: 'F₁' },
    { x: '-2*ecc', y: 0, name: 'F₂' },
  ]}
/>

极坐标方程 $r=r(\theta)$ 中用 `t`（或 `θ`）表示角度。改变 $n$ 观察玫瑰线花瓣数，再试试心形线 `1+cos(t)` 或阿基米德螺线 `0.3*t`（把 θ 终点改成 `6*PI`）。

<FunctionPlot
  title="极坐标与参数曲线"
  description="玫瑰线与李萨如曲线；可编辑公式、添加新曲线。"
  boundingBox={[-3.5, 3.5, 3.5, -3.5]}
  parameters={[{ name: 'n', label: '花瓣参数 n', min: 1, max: 7, value: 3, step: 1 }]}
  plots={[
    { type: 'polar', expression: '2.5*cos(n*t)', label: '玫瑰线' },
    { type: 'parametric', x: '3*sin(2*t)', y: '3*sin(3*t)', range: [0, 6.283185307179586], label: '李萨如曲线', dashed: true },
  ]}
/>

## 二次曲面：用截面认识形状

二次曲面最有效的观察方法是**截痕法**：用平行于坐标面的平面 $z=k$（或 $x=k$、$y=k$）去切曲面，看交线是什么曲线。打开“截面”面板，拖动 $k$ 或点击扫描，小图显示截面上的真实形状，并给出截痕方程与类型。

<SurfacePlot
  title="单叶双曲面的截痕"
  description="z = k 截得椭圆；切到 x = k 或 y = k 截得双曲线。改变 c 观察腰部。"
  height={500}
  box={[[-4, 4], [-4, 4], [-3, 3]]}
  section={{ axis: 'z', value: 1 }}
  parameters={[
    { name: 'a', label: '半轴 a', min: 0.5, max: 2.5, value: 1.5, step: 0.1 },
    { name: 'b', label: '半轴 b', min: 0.5, max: 2.5, value: 1, step: 0.1 },
    { name: 'c', label: '半轴 c', min: 0.5, max: 2.5, value: 1.2, step: 0.1 },
  ]}
  plots={[{ type: 'quadric', kind: 'hyperboloid-one-sheet', a: 'a', b: 'b', c: 'c', extent: 1.6 }]}
/>

在曲面卡片中可以直接切换曲面类型、对称轴和半轴，比较椭球面、双叶双曲面、锥面、抛物面和柱面。马鞍面在 $z=k$ 上截得双曲线，$k=0$ 时退化为两条相交直线：

<SurfacePlot
  title="马鞍面与椭圆抛物面"
  description="两种抛物面放在一起：一个向上开口，一个呈马鞍形。"
  height={500}
  box={[[-3, 3], [-3, 3], [-3, 3]]}
  section={{ axis: 'z', value: 0 }}
  opacity={0.82}
  plots={[
    { type: 'quadric', kind: 'hyperbolic-paraboloid', a: 1.2, b: 1.2, c: 1, label: '马鞍面' },
    { type: 'quadric', kind: 'elliptic-paraboloid', a: 1, b: 1, c: 1, center: [0, 0, -2.5], extent: 1.6, label: '椭圆抛物面' },
  ]}
/>

## 隐式曲面与函数曲面

任意 $F(x,y,z)=0$ 都可以用 `implicit-surface` 绘制，图像由三组截面曲线构成。改变 $d$：$d>0$ 是单叶双曲面，$d=0$ 是锥面，$d<0$ 变成双叶双曲面。

<SurfacePlot
  title="一个参数串起三种曲面"
  description="x² + y² − z² = d：观察 d 穿过 0 时的拓扑变化。"
  height={480}
  box={[[-3, 3], [-3, 3], [-3, 3]]}
  section={{ axis: 'x', value: 0 }}
  parameters={[{ name: 'd', label: '常数 d', min: -2, max: 2, value: 1, step: 0.1 }]}
  plots={[{ type: 'implicit-surface', expression: 'x^2 + y^2 - z^2 = d', label: 'x²+y²−z²=d' }]}
/>

二元函数 $z=f(x,y)$ 是曲面；它在 $z=k$ 上的截痕就是二维中的等高线。

<SurfacePlot
  title="二元函数曲面与等高线"

## 写进自己的文档

```mdx
<FunctionPlot
  title="我的二维画板"
  parameters={[{ name: 'a', min: -3, max: 3, value: 1, step: 0.1 }]}
  plots={[
    { type: 'function', expression: 'a*x^2', probe: true, derivative: true, area: [0, 1] },
    { type: 'implicit', expression: 'x^2+y^2=4' },
    { type: 'polar', expression: '1+cos(t)' },
  ]}
/>

<SurfacePlot
  title="椭球面"
  box={[[-3, 3], [-3, 3], [-3, 3]]}
  section
  plots={[{ type: 'quadric', kind: 'ellipsoid', a: 2, b: 1.5, c: 1 }]}
/>
```

表达式使用普通数学语法：乘法写 `*`，乘方写 `^`，函数写 `sin(x)`、`sqrt(x)`、`exp(x)`、`log(x)`，圆周率写 `PI`；也可以直接粘贴 `π`、`θ`、`²`、`×` 等符号。角度一律用弧度。

| 组件 | 图像类型 | 主要字段 |
| --- | --- | --- |
| `FunctionPlot` | `function` | `expression`，可选 `domain`、`probe`、`derivative`、`area: [a, b]` |
| | `implicit` | `expression`：`F(x,y)` 或 `左式=右式` |
| | `parametric` | `x`、`y`（变量 `t`）、`range` |
| | `polar` | `expression`（变量 `t` 即 θ），可选 `range`，默认 `[0, 2π]` |
| `SurfacePlot` | `quadric` | `kind`、`a`、`b`、`c`，可选 `axis`、`center`、`extent` |
| | `implicit-surface` | `expression`：`F(x,y,z)` 或 `左式=右式` |
| | `surface` | `expression`（z 关于 x、y），可选 `domain` |
| | `parametric-surface` | `x`、`y`、`z`（变量 `u`、`v`）、`ranges` |
| | `parametric-curve` | `x`、`y`、`z`（变量 `t`）、`range` |

`quadric` 的 `kind` 可选 `sphere`（球面）、`ellipsoid`（椭球面）、`hyperboloid-one-sheet`（单叶双曲面）、`hyperboloid-two-sheets`（双叶双曲面）、`cone`（椭圆锥面）、`elliptic-paraboloid`（椭圆抛物面）、`hyperbolic-paraboloid`（马鞍面），以及 `elliptic-cylinder`、`hyperbolic-cylinder`、`parabolic-cylinder` 三种柱面。数值字段（区间端点、点坐标、二次曲面的 `a`、`b`、`c`、`center`）都可以写成参数表达式，例如 `'2*a'`。

两种画板共用 `parameters`、`editable`、`title`、`description`、`height`。二维另有 `boundingBox`、`points`、`axis`、`grid`；三维另有 `box`、`points`、`section`（`true` 或 `{ axis, value }`）、`opacity`、`mesh`、`probe`、`projection`。完整说明见仓库中的 `docs/jsxgraph.md`。
