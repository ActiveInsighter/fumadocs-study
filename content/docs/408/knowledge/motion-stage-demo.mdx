`MotionStage` 是一个由**步骤**驱动的动画舞台：它负责时间线、播放 / 暂停、上一步 / 下一步、倍速、键盘操作、讲解文字和代码高亮，舞台里的场景组件只需要描述“每一步长什么样”。

点击舞台后可以用键盘操作：<kbd>←</kbd> / <kbd>→</kbd> 切换步骤，<kbd>空格</kbd> 播放或暂停，<kbd>Home</kbd> 回到开头。也可以直接点击进度条上的任意一段跳到对应步骤。

## 编写方式

每个演示都由 `<MotionStage steps={[...]}>` 包裹。`steps` 中每一项是一步，可以带 `title`、`description`、`vars`（变量面板）、`lines`（高亮的代码行，从 1 开始）、`tone` 和 `duration`。舞台内的组件用以下两种方式响应步骤：

- **按步骤门控**：`at`、`activeAt`、`splitAt` 等属性接受 `2`、`[1, 3]`、`"2+"`、`"1-3"`、`"-2"` 这样的写法，步骤从 0 开始计数。
- **按帧描述**：`frames` 数组的第 n 项对应第 n 步，帧数少于步骤数时保持最后一帧。

```mdx
<MotionStage title="示例" steps={[{ title: "第一步" }, { title: "第二步" }]}>
  <StageNode label="A" activeAt={1} />
  <StageReveal at="1+">第二步才出现的内容</StageReveal>
</MotionStage>
```

需要更复杂的场景时，在 `components/motion-stage/scenes/` 中新建组件，用 `useStage()` 读取当前步骤即可，播放控制、讲解与布局都由舞台统一处理。
