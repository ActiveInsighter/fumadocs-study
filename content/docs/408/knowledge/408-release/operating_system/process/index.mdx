进程管理是操作系统的核心章节。建议从“**谁在运行—如何分配 CPU—并发时如何协作—资源竞争如何避免死锁**”四个问题理解整章。

| [处理机调度](/docs/408/knowledge/408-release/operating_system/process/scheduling/) | 调度指标、FCFS/SJF/HRRN/RR/优先级/多级反馈队列 |
| [同步和互斥](/docs/408/knowledge/408-release/operating_system/process/sync/) | 临界区、Peterson、原子指令、锁、信号量、条件变量 |
| [经典同步问题](/docs/408/knowledge/408-release/operating_system/process/problem/) | 生产者消费者、读者写者、哲学家就餐、前驱关系 |
| [死锁](/docs/408/knowledge/408-release/operating_system/process/deadlock/) | 四个必要条件、预防、避免、检测与解除、银行家算法 |
