---
title: "物理层"
description: "通信基础、编码调制、交换方式、传输介质与物理层设备。"
---

物理层解决的是**比特如何经过真实介质传播**。复习重点包括通信性能指标、奈奎斯特与香农公式、编码/调制方法，以及不同交换方式的时延计算。

| 内容 | 重点 |
| --- | --- |
| [通信概念](/docs/408/knowledge/408-release/computer_network/physical/concept/) | 码元、波特率、比特率、时延、奈奎斯特与香农定理 |
| [编码和调制](/docs/408/knowledge/408-release/computer_network/physical/encoding/) | 数字/模拟数据与信号的编码、调制方法 |
| [交换方式](/docs/408/knowledge/408-release/computer_network/physical/switching/) | 电路交换、报文交换、分组交换、数据报与虚电路 |
| [物理层设备](/docs/408/knowledge/408-release/computer_network/physical/dev/) | 中继器、集线器、网络适配器与传输介质 |

> **真题考察：** 奈奎斯特/香农公式、发送时延与传播时延、分组交换总时延是常见计算点。
