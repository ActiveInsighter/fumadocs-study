---
title: "网络层"
description: "IP 寻址与转发、辅助协议、路由算法、SDN 与路由器。"
---

网络层负责让 IP 数据报跨越多个异构网络到达目标主机。IP 本身提供的是**无连接、尽力而为**的数据报服务；路由器逐跳转发，可靠性若需要通常由端系统的上层协议实现。

| 内容 | 重点 |
| --- | --- |
| [IP](/docs/408/knowledge/408-release/computer_network/network/ip/) | IPv4 地址/CIDR、子网、聚合、分片、IPv6 |
| [ARP](/docs/408/knowledge/408-release/computer_network/network/arp/) | 同一链路上的 IP 到 MAC 地址解析 |
| [DHCP](/docs/408/knowledge/408-release/computer_network/network/dhcp/) | 动态地址配置与 DORA 过程 |
| [ICMP](/docs/408/knowledge/408-release/computer_network/network/icmp/) | 差错报告、查询报文、ping/traceroute |
| [路由算法](/docs/408/knowledge/408-release/computer_network/network/route/) | 距离向量、链路状态、RIP/OSPF/BGP |
| [SDN](/docs/408/knowledge/408-release/computer_network/network/sdn/) | 控制平面与数据平面分离、流表 |
| [网络层设备](/docs/408/knowledge/408-release/computer_network/network/dev/) | 路由器、路由表、最长前缀匹配、NAT |

> **真题考察：** IPv4 地址与子网、CIDR 聚合、IP 分片、最长前缀匹配以及路由算法是网络层的高频考点。
