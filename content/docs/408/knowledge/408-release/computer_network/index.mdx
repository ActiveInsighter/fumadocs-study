计算机网络研究的是：**数据如何从一个主机中的应用进程，经过协议栈和多级网络设备，到达另一台主机中的目标进程**。复习时应沿着“封装 → 转发 → 解封装”的数据流，把各层协议串联起来，而不是孤立记忆名词。

## 建议的知识主线

1. **数据从哪里来**：应用进程通过 socket/端口使用传输层服务。
2. **端到端如何传输**：UDP 提供无连接报文服务，TCP 提供面向连接的可靠字节流。
3. **跨网络如何到达目标主机**：IP 提供尽力而为的数据报转发，路由协议负责形成路由信息。
4. **一跳之内如何交付**：链路层使用帧和 MAC 地址完成相邻节点间传输。
5. **比特如何真正传播**：物理层把比特转换为电、光或无线信号。

> **真题考察：** 计算机网络既有大量协议概念题，也常出现计算题和跨层综合题。高频综合内容集中在 IP 子网与分片、路由转发、ARQ/信道利用率、TCP 序号与窗口、连接管理和拥塞控制。

> **复习提示：** 做“一个分组从主机 A 到主机 B”的题目时，逐跳区分 **IP 地址、MAC 地址、端口号** 哪些保持不变、哪些会变化，再结合 ARP、路由表与链路层封装分析。
