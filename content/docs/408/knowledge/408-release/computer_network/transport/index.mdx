---
title: "传输层"
description: "端口与复用、UDP、TCP 连接管理、可靠传输、流量控制与拥塞控制。"
---

传输层在**端系统**中运行，为应用进程提供进程到进程的逻辑通信。UDP 提供轻量的无连接报文服务；TCP 在 IP 的尽力而为服务之上，通过序号、确认、重传、窗口等机制构建可靠字节流。

| 内容 | 重点 |
| --- | --- |
| [UDP](/docs/408/knowledge/408-release/computer_network/transport/udp/) | 首部、校验和、无连接服务与应用场景 |
| [TCP](/docs/408/knowledge/408-release/computer_network/transport/tcp/) | 首部、三次握手、四次挥手、滑动窗口、可靠传输、拥塞控制 |

> **真题考察：** TCP 序号/确认号、发送与接收窗口、超时重传、三次握手/四次挥手以及拥塞窗口变化都适合综合计算。

> **易混淆点：** TCP **接收窗口 rwnd** 用于流量控制，反映接收端可用缓冲区；**拥塞窗口 cwnd** 属于拥塞控制，反映发送端根据网络拥塞状况允许注入网络的数据量。
