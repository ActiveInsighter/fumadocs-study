本章用于建立网络的整体框架。核心不是背七层名称，而是理解：**每一层向上一层提供服务，并通过同层协议规则与对端逻辑通信；真实数据则沿协议栈逐层封装和解封装。**

| 内容 | 重点 |
| --- | --- |
| [分层结构](/docs/408/knowledge/408-release/computer_network/overall/iso/) | OSI 与 TCP/IP 模型、各层功能、PDU |
| [各层协议总结](/docs/408/knowledge/408-release/computer_network/overall/protocol/) | 常见协议及所属层次 |
| [网络设备总结](/docs/408/knowledge/408-release/computer_network/overall/dev/) | 冲突域、广播域、设备工作层次 |

> **复习提示：** 判断设备或协议属于哪一层时，应看它主要依据哪一层的首部字段进行处理。例如交换机主要依据 MAC 地址转发，路由器主要依据 IP 地址转发。
