## 建议的知识主线

1. **先建立复杂度意识**：每个操作都要问“时间复杂度、额外空间复杂度是多少”。
2. **掌握线性结构**：顺序表、链表、栈、队列是后续算法的基础工具。
3. **理解树和图**：重点掌握存储结构、遍历框架以及典型算法的适用条件。
4. **统一比较排序算法**：从稳定性、时间复杂度、空间复杂度、是否适合链式/顺序存储等维度比较。
5. **算法设计题重视模板**：先写设计思想，再给伪代码/C 代码，最后明确复杂度。

> **真题考察：** 数据结构选择题常围绕复杂度、存储结构与算法性质；算法设计题则高频涉及数组/顺序表、链表、树和图。复习时应以“能写出操作过程并分析复杂度”为目标，而不是只记结论。
