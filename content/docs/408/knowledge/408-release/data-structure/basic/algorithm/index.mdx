> **复习优先级：中。**

复杂度分析几乎贯穿数据结构所有章节。看到一个算法时，应先确定输入规模，再选择能代表主要工作量的基本操作，最后分析它随输入规模增长的数量级。

### 算法概念

**算法**（Algorithm）是为解决某类问题而规定的一组有限、明确且可执行的步骤。408 中可重点掌握以下性质：

1. **有穷性**：算法在执行有限步后应结束。
2. **确定性**：每一步的含义明确，在给定状态下下一步确定。
3. **可行性**：每个基本操作都能在有限时间内完成。
4. **输入**：可以有零个或多个输入。
5. **输出**：至少产生一个与问题有关的输出结果。

> 教材对术语的归纳可能略有不同，但“有限、明确、可执行，并能从输入得到输出”是核心。

#### 时间复杂度

设输入规模为 $n$，选定的基本操作执行次数为 $T(n)$。复杂度分析关注的是 $n$ 增大时 $T(n)$ 的**增长趋势**，通常忽略常数因子和低阶项。

基本操作是为了建立分析模型而选定的操作，例如关键比较、赋值或循环体执行一次；它**不必等同于一条 CPU 机器指令**。

##### 常用渐近记号

- $O(f(n))$：给出渐近上界。
- $\Omega(f(n))$：给出渐近下界。
- $\Theta(f(n))$：表示与 $f(n)$ 同阶，即同时给出上下界。

408 题目通常直接使用大 $O$ 表示时间复杂度。例如：

$$
T(n)=3n^2+5n+7=O(n^2).
$$

##### 常见时间复杂度

按增长速度由慢到快，常见量级为：

$$
O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(n^3)<O(2^n)<O(n!).
$$

| 复杂度 | 典型场景 |
| --- | --- |
| $O(1)$ | 数组按下标访问 |
| $O(\log n)$ | 有序表二分查找、平衡搜索树单次查找 |
| $O(n)$ | 顺序扫描 |
| $O(n\log n)$ | 归并排序、平均情况下的快速排序 |
| $O(n^2)$ | 简单选择排序、最坏情况下的直接插入排序 |
| $O(2^n)$、$O(n!)$ | 未剪枝的组合枚举、排列枚举等 |

#### 空间复杂度

空间复杂度描述算法执行时所需空间随输入规模的增长量级。要区分：

- **总空间**：包括输入数据本身及程序执行所需空间；
- **辅助空间**：除输入数据外，算法额外使用的临时空间。408 更常直接考辅助空间。

常见来源包括临时变量、辅助数组、栈/队列以及递归调用栈。

| 辅助空间复杂度 | 典型情况 |
| --- | --- |
| $O(1)$ | 只使用常数个临时变量 |
| $O(\log n)$ | 平衡递归树的调用栈，如平均情况下的快速排序 |
| $O(n)$ | 归并排序辅助数组、线性深度递归 |
| $O(n^2)$ | 额外维护 $n\times n$ 矩阵 |

> **复习提示：** 循环主要影响时间复杂度；递归除了影响时间，还要额外分析**最大递归深度**带来的栈空间。
