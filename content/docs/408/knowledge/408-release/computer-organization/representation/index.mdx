数据表示是组成原理后续章节的基础。学习时要把“**位模式**”与“**位模式的解释方式**”分开：同一串二进制位，在无符号数、补码整数和浮点数规则下可能表示完全不同的值。

| 内容 | 重点 |
| --- | --- |
| [整数的表示](/docs/408/knowledge/408-release/computer-organization/representation/integer/) | 无符号数、原码、反码、补码、溢出判断 |
| [浮点数表示](/docs/408/knowledge/408-release/computer-organization/representation/floats/) | IEEE 754、规格化数、非规格化数、特殊值、舍入 |
| [运算电路](/docs/408/knowledge/408-release/computer-organization/representation/circuit/) | 加法器、补码减法、乘除法基本电路 |
| [类型转换](/docs/408/knowledge/408-release/computer-organization/representation/conversion/) | 有符号/无符号、宽度扩展、整数/浮点转换 |

> **复习提示：** 补码和 IEEE 754 几乎可以贯穿整个组成原理，后续学习指令、ALU、Cache 与异常时都会再次用到。
