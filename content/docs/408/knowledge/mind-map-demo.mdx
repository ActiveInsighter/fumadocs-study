## 408 专业课知识树

下面的示例覆盖了标题层级、无序列表、中文节点和较长的节点文本。可以点击节点旁的圆点折叠分支，也可以用滚轮缩放或拖动浏览。

```mindmap
# 408 计算机专业基础

## 数据结构
- 线性表
  - 顺序表
  - 链表
- 树与二叉树
  - 二叉树遍历
  - 哈夫曼树
- 图
  - 图的遍历
  - 最短路径

## 计算机组成原理
- 计算机系统概述
- 数据的表示和运算
- 存储系统
- 指令系统
- 中央处理器 CPU

## 操作系统
- 进程与线程
- 内存管理
- 文件管理
- 输入输出管理

## 计算机网络
- 物理层
- 数据链路层
- 网络层
- 传输层
- 应用层
```

## 写法

以后在任意文档中直接使用同样的代码块即可：

````md
```mindmap
# 主题
## 分支
- 知识点
```
````

普通的 `mermaid`、`js` 或其他语言代码块不会受到影响，仍然使用站点原有的渲染方式。
