排序部分既考算法过程，也考性质比较。建议统一从**时间复杂度、辅助空间、稳定性、数据初态敏感性、每趟特征**五个维度复习。

<InlineSvg src="/images/data-structure/data-structure-sort-001.svg" alt={"排序算法分类与比较"} />

| 内容 | 重点 |
| --- | --- |
| [内部排序](/docs/408/knowledge2/data-structure/sort/internal/) | 冒泡、插入、选择、归并、快速、堆、希尔、桶与基数排序 |
| [外部排序](/docs/408/knowledge2/data-structure/sort/external/) | 初始归并段、置换选择、多路归并、胜者树与败者树 |

> **真题考察：** 排序算法的稳定性、复杂度、趟特征和手工模拟是选择题常客；外部排序则重点理解减少归并趟数与磁盘 I/O 的方法。
