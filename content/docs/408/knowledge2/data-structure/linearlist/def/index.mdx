> **复习优先级：低。**
了解线性表的概念，通常作为基础概念理解，更常直接考察 **顺序表** 和 **链表** 这两种具体实现方案。

### 线性表定义

<InlineSvg src="/images/data-structure/data-structure-linearlist-def-001.svg" alt={"线性表 Linear List L = (a₁, a₂, a₃, ..., aᵢ, aᵢ₊₁, ..., aₙ) a₁ a₂ a₃ ... aᵢ aᵢ₊₁ ... aₙ 当前元素 前驱 后继 线性表特点： 个数有限： 表中元素个数是确定的有限值 类型相同： 所有元素数据类型一致，占用相同存储空间 逻辑有序： 元素间存在先后顺序，有前驱和后继关系"} />

**线性表**（Linear List）是 **L 数据结构** 中的一种基本结构。它是 **零个或多个数据元素的有限序列**。通常，**线性表** 中的 **数据元素** 之间是 **有序的**，它们之间存在着 **前驱和后继的关系**。

$L=(a_1,a_2,\dots,a_i,a_{i+1},\dots,a_n)$

特点：

- **个数有限**
- **表中元素数据类型都相同**，每个元素占有 **相同大小的存储空间**
- 仅讨论 **元素间的逻辑关系**，表中元素有 **先后顺序**

#### 顺序表和链表

线性表分为顺序存储结构（又称 **顺序表**）和链式存储结构（又称为 **链表**）。

顺序表要求一段**地址连续的存储区域**；链表结点之间则通过指针/游标建立逻辑关系，因此结点在物理地址上不必连续。是否位于运行时的栈区、堆区或静态存储区属于具体实现选择，并不是顺序表与链表的定义依据。顺序表中数据之间的 **逻辑关系** 和 **物理关系** 是一致的，链表中数据元素的逻辑关系和物理关系并不一定一致。

上图中左边为顺序表，右边为链表。顺序表可由首地址和元素下标在 $O(1)$ 时间定位任意元素；链表通常必须沿指针逐结点访问。链式结构通过额外的链接信息保存逻辑次序，因此插入/删除已定位结点附近的元素时通常无需整体移动数据。

### 操作

线性表中的操作包含以下类型，顺序表 和 链表 会各自使用不同的方案实现这些操作：

<InlineSvg src="/images/data-structure/data-structure-linearlist-def-003.svg" alt={"图示"} />

- **初始化** (`InitList`): 创建一个 **空的线性表**。
- **插入** (`Insert`): 在线性表的 **指定位置** 插入一个 **新的元素**。
- **删除** (`Delete`): 删除线性表中的 **指定位置的元素**。
- **查找** (`LocateElem`): 根据 **给定的条件** 查找线性表中的 **元素**。
- **获取元素** (`GetElem`): 获取线性表中 **指定位置的元素**。
- **设置元素** (`SetElem`): 修改线性表中 **指定位置的元素** 的 **值**。
- **长度** (`Length`): 返回线性表中的 **元素数量**。
- **判空** (`IsEmpty`): 判断线性表是否 **为空**。
- **清空** (`ClearList`): **清除**线性表中的 **所有元素**。
- **遍历** (`Traverse`): 对线性表中的 **每个元素** 执行 **某种操作**。
