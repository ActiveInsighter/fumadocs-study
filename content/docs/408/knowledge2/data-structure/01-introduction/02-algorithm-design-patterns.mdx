算法设计题真正考查的不是“会不会写语法”，而是：

> **能否识别数据结构的性质，并把题目给出的时间、空间、原地性等约束转换成合适的算法。**

<Callout type="info" title="总原则">
先得到一个**确定正确**的思路，再根据复杂度要求继续优化。考场上最危险的不是“写得不够漂亮”，而是为了追求最优而迟迟无法形成完整方案。
</Callout>

## 9. 算法设计题的标准答题结构

一份完整答案通常由三部分组成：

1. **基本设计思想**；
2. **C/C++ 或伪代码实现，并在关键处注释**；
3. **时间复杂度与空间复杂度分析**。

推荐答题顺序：

```text
① 用自然语言说明算法主线
② 写核心代码 / 伪代码
③ 单独说明时间复杂度与辅助空间复杂度
```

复杂度不要只给结论。例如：

```text
时间复杂度：O(n)。
数组被完整扫描两次，每次每个元素只进行常数次操作，因此总时间仍为 O(n)。

空间复杂度：O(1)。
只使用常数个指针、计数变量，没有申请随 n 增长的辅助空间。
```

> **真题标签**
>
> 408 数据结构大题长期反复考查顺序表、链表、树、图、查找和排序等对象。复习重点应放在“结构性质 + 算法模板 + 复杂度约束”，而不是根据上一年题型机械押题。

## 10. 先按“数据结构 + 题目约束”选型

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-001.svg" alt="输入的数据结构是什么？ 数组 / 顺序表 链表 二叉树 图 有序数组 / 两端关系 双指针 / 二分查找 值域明确 / 出现性判断 桶标记 / 原地哈希 每个位置依赖左右信息 前缀 / 后缀预处理 排序兜底 O(n log n) 找中间 / 倒数 k 快慢双指针 需要逆序访问 原地逆置 两个链表共享后缀 长度对齐 / 换头 BST / 递增序列 中序遍历 找差值、合法性、第 k 小 按层处理 / 顺序存储 层序遍历 BFS 队列驱动 路径 / 统计 / 高度 递归 DFS" />

先识别对象，再圈出约束：

| 题目线索 | 优先考虑 |
| --- | --- |
| 数组已有序 | 双指针、二分 |
| 值域与 $n$ 有明确关系 | 桶、标记数组、原地哈希 |
| 每个位置依赖左/右侧统计 | 前缀 / 后缀预处理 |
| 要求 Top-K、第 $k$ 大/小 | 堆、选择思想 |
| 链表中点 / 倒数第 $k$ 个 | 快慢双指针 |
| 链表需要逆向处理 | 原地逆置 |
| BST 的大小关系 | 中序遍历、沿搜索路径剪枝 |
| 树按层处理 | BFS / 队列 |
| 图的连通性 | DFS / BFS |
| 无权最短路 | BFS |
| 非负权单源最短路 | Dijkstra |
| 全源最短路 | Floyd |
| 最小生成树 | Prim / Kruskal |
| DAG 依赖关系 | 拓扑排序 |
| AOE 网工程时间 | 关键路径 |

尤其要检查：

- 数据是否已经有序；
- 是否允许修改原数据；
- 是否要求 $O(1)$ 辅助空间；
- 元素值域是否有限；
- 是否存在 BST、DAG 等特殊结构；
- 时间复杂度上限是否已经把某些常规做法排除。

<Callout type="warn" title="约束本身就是提示">
若题目要求 $O(n)$，通常意味着不能排序；若要求 $O(1)$ 辅助空间，往往意味着不能开哈希表或线性辅助数组；若给出“有序”条件，则通常应该主动利用它。
</Callout>

## 11. 数组与顺序表：有序性、排序与二分

### 11.1 排序兜底

面对无序数组，如果没有更强的结构性质，可以考虑：

> **先排序，再进行双指针、二分查找或相邻比较。**

比较排序通常把总时间带到：

$$
O(n\log n)
$$

排序后常见处理包括：

- 去重；
- 两数配对；
- 区间处理；
- 最小差值；
- 二分查找。

<Callout type="warn" title="什么时候不能直接排序">
如果题目要求保持原序、严格要求 $O(n)$、要求原地之外的特殊限制，或者修改输入会影响后续使用，就不能把“先排序”当作最终答案。
</Callout>

### 11.2 二分与双指针的前提

二分查找的关键前提是**搜索空间具有单调性**；双指针常利用的是**有序性、区间单调变化或两端关系**。

不要因为题目出现“数组”就直接二分，也不要因为出现“两数”就机械双指针。应先回答：

> **移动某个指针后，能否确定排除一整批不可能答案？**

能做到这一点，才说明有序性真正被利用。

## 12. 数组与顺序表：值域映射、预处理与投票

### 12.1 桶标记与原地哈希

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-002.svg" alt="图示" />

当元素值域与数组长度有明确关系，例如：

$$
0\le a[i]<n
$$

或：

$$
1\le a[i]\le n
$$

可以尝试建立“**值 ↔ 下标**”映射，用下标、正负号或交换位置完成标记。

> **真题标签**
>
> 2018 年第 41 题：求未出现的最小正整数，是“值域有限 + 原地标记”的典型题。

核心结论：对于长度为 $n$ 的数组，若答案不在 $[1,n]$，那么最小未出现正整数只能是 $n+1$。因此只需记录 $1\sim n$ 是否出现。

```c
int findMissMin(int a[], int n) {
    for (int i = 0; i < n; ++i) {
        if (a[i] <= 0 || a[i] > n)
            a[i] = n + 1;
    }

    for (int i = 0; i < n; ++i) {
        int v = abs(a[i]);
        if (1 <= v && v <= n)
            a[v - 1] = -abs(a[v - 1]);
    }

    for (int i = 0; i < n; ++i) {
        if (a[i] > 0)
            return i + 1;
    }

    return n + 1;
}
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

<Callout type="warn" title="原地标记的前提">
利用输入数组本身做标记会修改原数据。只有题目允许修改输入，或能在后续恢复时，才适合使用这种方法。
</Callout>

### 12.2 前缀 / 后缀预处理

如果“每个位置的答案都依赖左边或右边某种统计量”，直接从每个位置重新扫描常会达到 $O(n^2)$。

常见可递推状态：

- 前缀和、后缀和；
- 前缀最大值 / 最小值；
- 后缀最大值 / 最小值；
- 前缀出现次数、后缀出现次数；
- 其他能够由相邻状态 $O(1)$ 转移得到的信息。

> **真题标签**
>
> 2025 年第 41 题：对每个 $A[i]$，求 $A[i]\times A[j]$（$i\le j\le n-1$）的最大值。可从右向左维护后缀最大值与最小值。

```c
void calMulMax(int A[], int res[], int n) {
    int maxVal = INT_MIN;
    int minVal = INT_MAX;

    for (int i = n - 1; i >= 0; --i) {
        if (A[i] > maxVal) maxVal = A[i];
        if (A[i] < minVal) minVal = A[i];

        res[i] = (A[i] >= 0)
            ? A[i] * maxVal
            : A[i] * minVal;
    }
}
```

核心不是背代码，而是识别：

> **当前位置答案 = 当前元素 + 已经维护好的前缀/后缀状态。**

### 12.3 Boyer-Moore 投票

适用条件：寻找出现次数**超过一半**的元素，并要求 $O(n)$ 时间、$O(1)$ 辅助空间。

> **真题标签**
>
> 2013 年第 41 题：主元素。

核心思想是：**不同元素两两抵消**。若主元素确实超过半数，则最终候选者一定是它；若题目没有保证主元素存在，还必须二次验证。

```c
int majority(int a[], int n) {
    if (n <= 0) return -1;

    int cand = a[0];
    int cnt = 1;

    for (int i = 1; i < n; ++i) {
        if (a[i] == cand) {
            ++cnt;
        } else if (--cnt == 0) {
            cand = a[i];
            cnt = 1;
        }
    }

    int occur = 0;
    for (int i = 0; i < n; ++i)
        if (a[i] == cand)
            ++occur;

    return (occur > n / 2) ? cand : -1;
}
```

<Callout type="warn" title="候选者不等于答案">
第一遍只能得到“可能的主元素”。如果题目没有保证主元素一定存在，第二遍统计验证不可省略。
</Callout>

## 13. 多个有序序列：多指针夹逼

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-003.svg" alt="三指针夹逼 — 三元组最小距离 S1: -1 0 9 S2: -25 -10 10 11 S3: 2 9 17 30 41 步骤 i(S1) j(S2) k(S3) min值 D 移动 1 -1 -25 2 -25 52 j++ 2 -1 -10 2 -10 24 i++ 3 0 -10 2 -10 22 j++ 4 0 10 2 0 16 i++ … 9 10 9 9 2 ✓ 最小 规则：每步移动三者中的 最小值 对应的指针（移大值只会让D增大）" />

多个**有序序列**之间寻找最优组合时，常使用多个指针同步推进。

> **真题标签**
>
> 2020 年第 41 题：三个升序数组的三元组最小距离。

若当前三个数满足：

$$
a\le b\le c
$$

要缩小当前最大值与最小值的差距，应优先尝试**增大当前最小值**。因为移动中间值或最大值无法降低当前最小值，通常不能让区间向更小方向收缩。

```c
int i = 0, j = 0, k = 0;

while (i < n1 && j < n2 && k < n3) {
    int D = calc_D(S1[i], S2[j], S3[k]);
    ans = min(ans, D);

    int minVal = min(S1[i], min(S2[j], S3[k]));

    if (S1[i] == minVal) ++i;
    else if (S2[j] == minVal) ++j;
    else ++k;
}
```

这类算法的本质是：

> **每次移动都要能证明“被跳过的状态不可能优于当前保留的搜索方向”。**

## 14. 链表：快慢指针、逆置与公共结点

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-004.svg" alt="快慢双指针 — 找倒数第 k 个结点 head 1 2 3 4 5 6 ∅ q p ① p 先走 k=3 步 此时 q 在结点 1 ② p、q 同步移动 直到 p == NULL q 即为倒数第 k 个；原地逆置 — 三指针迭代" />

链表题的核心限制是：

> **不能像数组一样按下标随机访问。**

因此常用技巧是让“指针之间的相对位置”编码信息。

### 14.1 快慢双指针

常见用途：

- 找中间结点；
- 找倒数第 $k$ 个结点；
- 判断是否有环；
- 找环入口。

找中点：

```c
NODE *slow = head->next;
NODE *fast = head->next;

while (fast != NULL && fast->next != NULL) {
    slow = slow->next;
    fast = fast->next->next;
}
```

找倒数第 $k$ 个结点：先让快指针领先 $k$ 个结点，再同步移动。

```c
NODE *p = head->next;
NODE *q = head->next;

for (int i = 0; i < k; ++i) {
    if (p == NULL)
        return NULL;
    p = p->next;
}

while (p != NULL) {
    p = p->next;
    q = q->next;
}

return q;
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

### 14.2 原地逆置

单链表无法从当前结点向前访问。如果需要“从后往前”处理某一段链表，常先把该段**原地逆置**。

```c
NODE *reverse(NODE *start) {
    NODE *prev = NULL;
    NODE *cur = start;

    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }

    return prev;
}
```

三个指针的语义：

- `prev`：已经逆置完成的部分；
- `cur`：当前正在处理的结点；
- `next`：原链表中的下一个结点。

> **真题标签**
>
> 2019 年第 41 题是典型的组合模板：**快慢指针找中点 → 逆置后半部分 → 双指针重新组合**。

<Callout type="warn" title="链表逆置的第一原则">
必须先保存 `next = cur->next`，再修改 `cur->next`。否则一旦断开原链接，就会丢失尚未处理的后续链表。
</Callout>

### 14.3 Y 形链表公共结点

若两个单链表共享后缀，则从第一个公共结点开始，后续结点完全相同。

双指针换头法：

```c
NODE *p = headA;
NODE *q = headB;

while (p != q) {
    p = (p != NULL) ? p->next : headB;
    q = (q != NULL) ? q->next : headA;
}

return p;
```

两个指针各自最多走过：

$$
|A|+|B|
$$

因此会自动抵消两个链表前缀长度差。若不存在公共结点，二者最终也会同时到达 `NULL`。

## 15. 二叉树：先定义递归语义，再利用结构性质

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-005.svg" alt="图示" />

### 15.1 写递归前先回答三个问题

1. **函数语义是什么？**
2. **递归终止条件是什么？**
3. **已知左右子树结果后，如何得到当前结点结果？**

例如 `height(root)` 的语义应明确为：

> 返回“以 `root` 为根的树高”。

把函数语义说清楚后，递归关系通常会自然出现。

### 15.2 BST 的中序有序性

二叉搜索树的关键性质：

> **中序遍历得到按关键字递增（若允许重复关键字，则按题目定义可能为非递减）的序列。**

因此出现以下关键词时，应优先考虑中序遍历或利用 BST 搜索路径：

- 第 $k$ 小 / 第 $k$ 大；
- 前驱 / 后继；
- 最近关键字；
- 判断是否满足 BST 性质。

```c
void inorder(BTNode *root) {
    if (root == NULL)
        return;

    inorder(root->left);
    visit(root);
    inorder(root->right);
}
```

> **真题标签**
>
> 2026 年第 41 题要求在二叉搜索树中寻找与给定 $K$ 的绝对差最小的所有关键字，核心就是利用 BST 的有序性质缩小搜索范围或按中序序列分析。

### 15.3 层序遍历（BFS）

若题目强调：

- 按层处理；
- 层数、层宽；
- 最后一层；
- 从上到下恢复结构；

应优先想到队列和 BFS。

```c
Queue Q;
enqueue(Q, root);

while (!isEmpty(Q)) {
    BTNode *node = dequeue(Q);
    visit(node);

    if (node->left != NULL)
        enqueue(Q, node->left);
    if (node->right != NULL)
        enqueue(Q, node->right);
}
```

### 15.4 栈序列与卡特兰数也是“结构性质题”

2026 年另一道数据结构大题考查了固定入栈顺序下的合法出栈序列、禁形关系与计数。遇到这类题，不应只靠枚举，而应先寻找：

- 栈的 LIFO 约束；
- 合法出栈序列的局部禁形；
- 小规模计数与递推关系；
- 卡特兰数相关结构。

> **真题标签**
>
> 2026 年第 42 题考查顺序入栈 `1,2,...,n` 时的合法出栈序列与计数问题。

## 16. 图：先识别问题类型，再选算法

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-006.svg" alt="图示" />

| 问题类型 | 优先算法 | 关键条件 |
| --- | --- | --- |
| 遍历、连通性 | DFS / BFS | 看存储结构决定复杂度 |
| 无权最短路 | BFS | 按边数计最短距离 |
| 非负权单源最短路 | Dijkstra | 边权不能为负 |
| 全源最短路 | Floyd | 适合顶点规模较小、要求任意点对 |
| 最小生成树 | Prim / Kruskal | 无向连通带权图 |
| DAG 依赖顺序 | 拓扑排序 | 有向无环图 |
| AOE 网工程时间 | 关键路径 | 活动持续时间与事件时刻 |

### 16.1 DFS 与 BFS

以邻接矩阵为例，DFS：

```c
int visited[MAXV] = {0};

void DFS(MGraph G, int v) {
    visited[v] = 1;
    visit(v);

    for (int w = 0; w < G.numVertices; ++w) {
        if (G.Edge[v][w] && !visited[w])
            DFS(G, w);
    }
}
```

BFS：

```c
void BFS(MGraph G, int v) {
    int visited[MAXV] = {0};
    Queue Q;

    enqueue(Q, v);
    visited[v] = 1;

    while (!isEmpty(Q)) {
        int u = dequeue(Q);
        visit(u);

        for (int w = 0; w < G.numVertices; ++w) {
            if (G.Edge[u][w] && !visited[w]) {
                visited[w] = 1;
                enqueue(Q, w);
            }
        }
    }
}
```

对于无权图：

> BFS 从起点按层扩展，第一次访问某顶点时得到的是从起点到该顶点的**最少边数距离**。

### 16.2 拓扑排序

拓扑排序用于：

> **有向无环图（DAG）中的依赖关系排序。**

典型流程：

```text
1. 统计所有顶点入度
2. 将所有入度为 0 的顶点入队
3. 每次取出一个入度为 0 的顶点 u
4. “删除” u 发出的边，即相邻顶点入度减 1
5. 新出现的入度为 0 的顶点继续入队
6. 统计最终处理的顶点数
```

若最终处理顶点数为 $n$，则存在拓扑序；否则图中存在有向环。

```c
return count == n;
```

> **真题标签**
>
> 2024 年数据结构大题考查了拓扑排序相关内容；拓扑排序也长期以选择题形式考查算法过程、入度变化与有向环判断。

### 16.3 邻接矩阵中的度

对**无向图**的邻接矩阵，第 $v$ 行非零元素数就是顶点 $v$ 的度：

```c
int degree(MGraph G, int v) {
    int d = 0;

    for (int w = 0; w < G.numVertices; ++w)
        d += (G.Edge[v][w] != 0);

    return d;
}
```

对有向图，若邻接矩阵定义为“行表示出边、列表示入边”，则：

- 第 $v$ 行非零元素数为出度；
- 第 $v$ 列非零元素数为入度。

具体作答仍应以题目给定的矩阵定义为准。

> **真题标签**
>
> 2021 年数据结构算法题涉及图中度的统计与路径性质。

### 16.4 AOE 网与关键路径

AOE 网的常见任务包括：

- 求完成工程的最短时间；
- 判断关键活动；
- 计算活动余量；
- 分析某活动延迟或缩短后对总工期的影响。

解题主线是：

```text
事件最早发生时间 ve
        ↓
工程最短完成时间
        ↓
事件最晚发生时间 vl
        ↓
活动最早开始 e / 最晚开始 l
        ↓
时间余量 l - e
        ↓
余量为 0 的活动 = 关键活动
```

> **真题标签**
>
> 2025 年第 42 题系统考查了 AOE 网的最短工期、关键活动、并行活动、时间余量与工期压缩。
