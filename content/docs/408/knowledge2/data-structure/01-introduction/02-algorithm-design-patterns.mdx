算法设计题的难点通常不在语法，而在于：

> **能否迅速识别题目对象的结构性质，并把复杂度要求转换成正确的算法模板。**

<Callout type="info" title="总原则">
考场上先保证算法**正确**，再根据题目明确给出的时间、空间和原地性要求优化。不要一开始就执着于“最优写法”而迟迟无法落笔。
</Callout>

## 10. 算法设计题的标准答题结构

一道完整的算法设计题通常包含：

1. **基本设计思想**；
2. **C/C++ 或伪代码实现，并在关键处注释**；
3. **时间复杂度与空间复杂度分析**。

原文给出的常见分值理解为：设计思想约 4 分、代码约 7～9 分、复杂度约 2 分；实际分值以当年评分标准为准。

推荐答题顺序：

```text
① 先写自然语言设计思想
② 再写核心代码/伪代码
③ 最后单独分析时间与空间复杂度
```

复杂度不要只给结论。例如：

```text
时间复杂度：O(n)。
数组被完整扫描一次，每个元素只进行常数次操作。

空间复杂度：O(1)。
只使用常数个指针和计数变量，没有申请随 n 增长的辅助空间。
```

> 原文整理了 2009—2026 年算法题的数据结构分布，用于观察“数组/顺序表、链表、树、图、查找、排序”等题型反复出现的规律。复习时应记模板，不应根据“上一年考过”判断下一年不会再考。

## 11. 先按“数据结构 + 题目约束”选型

```text
数组 / 顺序表
├─ 已经有序 → 双指针 / 二分
├─ 值域明确 → 桶标记 / 原地哈希
├─ 每个位置依赖左/右侧统计 → 前缀 / 后缀预处理
├─ 需要第 k 大/小、Top-K → 堆 / 选择思想
└─ 无更强结构可用 → 排序兜底 O(n log n)

链表
├─ 中点 / 倒数第 k 个 → 快慢双指针
├─ 需要逆向访问 → 原地逆置
├─ 是否有环 / 找环入口 → Floyd 快慢指针
└─ 两链表共享后缀 → 长度对齐 / 双指针换头

二叉树
├─ BST / 有序序列 → 中序遍历
├─ 按层处理 → BFS / 层序遍历
└─ 高度 / 路径 / 统计 → DFS / 递归

图
├─ 遍历 / 连通性 → DFS / BFS
├─ 无权最短路 → BFS
├─ 非负权单源最短路 → Dijkstra
├─ 全源最短路 → Floyd
├─ 最小生成树 → Prim / Kruskal
└─ 依赖关系 → 拓扑排序 / AOE 关键路径
```

判断模板之前，先圈出题目限制：

- 是否已经有序；
- 是否允许修改原数据；
- 是否要求 $O(1)$ 辅助空间；
- 元素值域是否有限；
- 是否存在树、图、BST、DAG 等特殊性质。

## 12. 数组与顺序表：排序、映射与预处理

### 12.1 排序兜底

面对无序数组，如果没有更强的结构性质，可以考虑：

> **先排序，再进行双指针、二分查找或相邻比较。**

排序通常使总时间达到：

$$
O(n\log n)
$$

排序后常见操作：

- 去重；
- 两数配对；
- 区间处理；
- 最小差值；
- 二分查找。

<Callout type="warn" title="限制条件">
排序可能破坏原数组顺序。如果题目要求保持原序、要求严格 $O(n)$，或者修改输入会影响后续使用，就不能直接把“先排序”当作最终答案。
</Callout>

### 12.2 桶标记与原地哈希

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-002.svg" alt="图示" />

当元素值域与数组长度有明确关系，例如：

$$
0\le a[i]<n
$$

或：

$$
1\le a[i]\le n
$$

可以尝试建立“**值 ↔ 下标**”映射，用下标、正负号或交换位置完成标记。

> **真题标签**
>
> 2018 年第 41 题：求未出现的最小正整数。

核心思路：答案若不在 $[1,n]$，只能是 $n+1$；因此只需标记 $1\sim n$ 是否出现。

```c
int findMissMin(int a[], int n) {
    for (int i = 0; i < n; ++i) {
        if (a[i] <= 0 || a[i] > n)
            a[i] = n + 1;
    }

    for (int i = 0; i < n; ++i) {
        int v = abs(a[i]);
        if (1 <= v && v <= n)
            a[v - 1] = -abs(a[v - 1]);
    }

    for (int i = 0; i < n; ++i) {
        if (a[i] > 0)
            return i + 1;
    }

    return n + 1;
}
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

### 12.3 前缀 / 后缀预处理

如果“每个位置的答案都依赖左边或右边某种统计量”，直接重复扫描容易达到 $O(n^2)$。

常见可维护状态包括：

- 前缀和、前缀最大值、前缀最小值；
- 后缀和、后缀最大值、后缀最小值；
- 其他可以递推的状态。

> **真题标签**
>
> 2025 年第 41 题：对每个 $A[i]$，求 $A[i]\times A[j]$（$i\le j\le n-1$）的最大值。可从右向左维护后缀最大值与最小值。

```c
void calMulMax(int A[], int res[], int n) {
    int maxVal = INT_MIN;
    int minVal = INT_MAX;

    for (int i = n - 1; i >= 0; --i) {
        if (A[i] > maxVal) maxVal = A[i];
        if (A[i] < minVal) minVal = A[i];

        res[i] = (A[i] >= 0)
            ? A[i] * maxVal
            : A[i] * minVal;
    }
}
```

核心不是死记代码，而是识别：

> **当前位置的答案 = 当前元素 + 已经维护好的后缀/前缀信息。**

## 13. 数组与顺序表：投票算法与多指针

### 13.1 Boyer-Moore 投票

适用条件：寻找出现次数**超过一半**的元素，并要求 $O(n)$ 时间、$O(1)$ 辅助空间。

> **真题标签**
>
> 2013 年第 41 题：主元素。

核心思想：**不同元素两两抵消**。若主元素确实超过半数，最终候选者一定是它；但如果题目没有保证主元素存在，还必须二次验证。

```c
int majority(int a[], int n) {
    int cand = a[0];
    int cnt = 1;

    for (int i = 1; i < n; ++i) {
        if (a[i] == cand) {
            ++cnt;
        } else if (--cnt == 0) {
            cand = a[i];
            cnt = 1;
        }
    }

    int occur = 0;
    for (int i = 0; i < n; ++i)
        if (a[i] == cand)
            ++occur;

    return (occur > n / 2) ? cand : -1;
}
```

<Callout type="warn" title="易错点">
第一遍只能确定“候选者”，不能证明候选者一定超过半数。若题目没有保证主元素存在，第二遍验证不可省略。
</Callout>

### 13.2 多指针夹逼

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-003.svg" alt="三指针夹逼 — 三元组最小距离 S1: -1 0 9 S2: -25 -10 10 11 S3: 2 9 17 30 41 步骤 i(S1) j(S2) k(S3) min值 D 移动 1 -1 -25 2 -25 52 j++ 2 -1 -10 2 -10 24 i++ 3 0 -10 2 -10 22 j++ 4 0 10 2 0 16 i++ … 9 10 9 9 2 ✓ 最小 规则：每步移动三者中的 最小值 对应的指针（移大值只会让D增大）" />

多个**有序序列**之间寻找最优组合时，常使用多个指针同步移动。

> **真题标签**
>
> 2020 年第 41 题：三个升序数组的三元组最小距离。

```c
int i = 0, j = 0, k = 0;

while (i < n1 && j < n2 && k < n3) {
    int D = calc_D(S1[i], S2[j], S3[k]);
    ans = min(ans, D);

    int minVal = min(S1[i], min(S2[j], S3[k]));

    if (S1[i] == minVal) ++i;
    else if (S2[j] == minVal) ++j;
    else ++k;
}
```

若当前三个数满足：

$$
a\le b\le c
$$

想缩小最大值与最小值的差距，应优先尝试**增大当前最小值**；继续增大最大值通常不会使当前区间变短。

## 14. 链表：快慢指针、逆置与公共结点

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-004.svg" alt="快慢双指针 — 找倒数第 k 个结点 head 1 2 3 4 5 6 ∅ q p ① p 先走 k=3 步 此时 q 在结点 1 ② p、q 同步移动 直到 p == NULL q 即为倒数第 k 个；原地逆置 — 三指针迭代" />

链表题的核心约束是：

> **不能像数组一样按下标随机访问。**

因此常用技巧是“让指针之间的相对位置编码信息”。

### 14.1 快慢双指针

常见用途：

- 找中间结点；
- 找倒数第 $k$ 个结点；
- 判断是否有环；
- 找环入口。

找中点示例：

```c
NODE *slow = head->next;
NODE *fast = head->next;

while (fast != NULL && fast->next != NULL) {
    slow = slow->next;
    fast = fast->next->next;
}
```

找倒数第 $k$ 个结点：先让快指针领先 $k$ 个结点，再同步移动。

```c
NODE *p = head->next;
NODE *q = head->next;

for (int i = 0; i < k; ++i) {
    if (p == NULL)
        return NULL;
    p = p->next;
}

while (p != NULL) {
    p = p->next;
    q = q->next;
}

return q;
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

### 14.2 原地逆置

单链表无法从当前结点向前访问。如果需要“从后往前”处理一段链表，常先把该段**原地逆置**。

```c
NODE *reverse(NODE *start) {
    NODE *prev = NULL;
    NODE *cur = start;

    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }

    return prev;
}
```

三个指针含义：

- `prev`：已经逆置完成的部分；
- `cur`：当前正在处理的结点；
- `next`：原链表中的下一个结点。

> **真题标签**
>
> 2019 年第 41 题：典型组合为“**快慢指针找中点 → 逆置后半部分 → 双指针重新组合**”。

<Callout type="warn" title="指针操作易错">
必须先保存 `next = cur->next`，再修改 `cur->next`，否则会丢失尚未处理的后续链表。
</Callout>

### 14.3 Y 形链表公共结点

若两个单链表共享后缀，则从第一个公共结点开始，后续结点完全相同。

双指针换头法：

```c
NODE *p = headA;
NODE *q = headB;

while (p != q) {
    p = (p != NULL) ? p->next : headB;
    q = (q != NULL) ? q->next : headA;
}

return p;
```

原因是两个指针最终都会走过长度：

$$
|A|+|B|
$$

从而自动抵消两个链表前缀长度差。

## 15. 二叉树：递归、BST 中序与层序遍历

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-005.svg" alt="图示" />

### 15.1 写递归前先明确三个问题

1. **函数语义是什么？**
2. **递归终止条件是什么？**
3. **已知左右子树结果后，如何得到当前结点的结果？**

例如 `height(root)` 的语义应明确为：

> 返回“以 `root` 为根的树高”。

这比一上来写递归代码更重要。

### 15.2 利用 BST 的中序有序性

二叉搜索树的关键性质：

> **中序遍历得到按关键字递增（或非递减）的序列。**

所以出现以下关键词时应优先想到中序遍历：

- 第 $k$ 小 / 第 $k$ 大；
- 前驱 / 后继；
- 最近关键字；
- 判断是否满足 BST 性质。

```c
void inorder(BTNode *root) {
    if (root == NULL)
        return;

    inorder(root->left);
    visit(root);
    inorder(root->right);
}
```

> **真题标签**
>
> 原文将 2026 年第 41 题“二叉搜索树最近差值结点”归入“利用中序有序性”这一模板。

### 15.3 层序遍历（BFS）

若题目强调：

- 按层处理；
- 层数、层宽；
- 最后一层；
- 从上到下恢复结构；

应优先想到队列和 BFS。

```c
Queue Q;
enqueue(Q, root);

while (!isEmpty(Q)) {
    BTNode *node = dequeue(Q);
    visit(node);

    if (node->left != NULL)
        enqueue(Q, node->left);
    if (node->right != NULL)
        enqueue(Q, node->right);
}
```

> **真题标签**
>
> 2022 年第 41 题涉及顺序存储二叉搜索树，原文将其与层序处理思想联系起来。

## 16. 图：先识别“问题类型”再选算法

<InlineSvg src="/images/data-structure/data-structure-basic-alg-design-006.svg" alt="图示" />

| 问题类型 | 优先算法 |
| --- | --- |
| 遍历、连通性 | DFS / BFS |
| 无权图最短路 | BFS |
| 非负权单源最短路 | Dijkstra |
| 全源最短路 | Floyd |
| 最小生成树 | Prim / Kruskal |
| DAG 依赖顺序 | 拓扑排序 |
| AOE 网工程时间 | 关键路径 |

### 16.1 DFS

以邻接矩阵为例：

```c
int visited[MAXV] = {0};

void DFS(MGraph G, int v) {
    visited[v] = 1;
    visit(v);

    for (int w = 0; w < G.numVertices; ++w) {
        if (G.Edge[v][w] && !visited[w])
            DFS(G, w);
    }
}
```

DFS 常用于：

- 连通性；
- 路径搜索；
- 图遍历；
- 具有递归结构的图问题。

### 16.2 BFS

```c
void BFS(MGraph G, int v) {
    int visited[MAXV] = {0};
    Queue Q;

    enqueue(Q, v);
    visited[v] = 1;

    while (!isEmpty(Q)) {
        int u = dequeue(Q);
        visit(u);

        for (int w = 0; w < G.numVertices; ++w) {
            if (G.Edge[u][w] && !visited[w]) {
                visited[w] = 1;
                enqueue(Q, w);
            }
        }
    }
}
```

对于无权图：

> BFS 第一次到达某个顶点时，得到的通常就是从起点到该顶点的**最少边数路径**。

## 17. 拓扑排序与图中度的统计

### 17.1 拓扑排序

> **真题标签**
>
> 原文列举的选择题年份：2010、2012、2014、2016、2018、2021；解答题：2024 年第 41 题。

拓扑排序用于：

> **有向无环图（DAG）中的依赖关系排序。**

典型流程：

```text
1. 统计所有顶点入度
2. 把所有入度为 0 的顶点入队
3. 每次取出一个入度为 0 的顶点 u
4. “删除” u 发出的边，即相邻顶点入度减 1
5. 新出现的入度为 0 的顶点继续入队
6. 统计最终处理了多少个顶点
```

若最终处理顶点数为 $n$，说明存在拓扑序；否则图中存在有向环。

```c
return count == n;
```

### 17.2 邻接矩阵中的度

对**无向图**的邻接矩阵，第 $v$ 行非零元素数就是顶点 $v$ 的度：

```c
int degree(MGraph G, int v) {
    int d = 0;

    for (int w = 0; w < G.numVertices; ++w)
        d += (G.Edge[v][w] != 0);

    return d;
}
```

> **真题标签**
>
> 2021 年第 41 题涉及图中度的统计与路径性质。

对于有向图，应区分：

- 行方向常用于统计出度；
- 列方向常用于统计入度；

具体仍以邻接矩阵定义为准。
