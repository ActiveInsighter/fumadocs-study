本页解决最后一个问题：

> **已经有一个正确算法后，如何系统地继续优化，并把答案写成阅卷友好的形式？**

## 18. 从暴力法到优化算法

算法优化的本质通常是：

> **找出重复计算、重复查找或不必要的存储，再利用结构性质消除它们。**

| 场景 | 直接方法 | 常见优化 |
| --- | --- | --- |
| $n$ 个数中找较小的 Top-K | 全排序 $O(n\log n)$ | 大根堆维护 $k$ 个候选，$O(n\log k)$ |
| 两个升序数组找中位数 | 合并后再取中位数 | 利用有序性做二分夹逼 |
| 链表倒数第 $k$ 个结点 | 先求长度再定位 | 双指针一次扫描 |
| 主元素 | 哈希计数，$O(n)$ 空间 | Boyer-Moore，$O(1)$ 空间 |
| 每个位置依赖左右信息 | 每次重复扫描，$O(n^2)$ | 前缀 / 后缀预处理，$O(n)$ |
| 多个有序数组寻找最优组合 | 多重枚举 | 多指针夹逼 |
| 两链表第一个公共结点 | 哈希集合 | 双指针换头，$O(1)$ 空间 |

### 18.1 五个常用优化检查项

**① 是否重复扫描同一段数据？**

可考虑：前缀、后缀、动态维护状态。

**② 是否重复查找？**

可考虑：散列表、二分、BST、堆。

**③ 是否存在有序性？**

可考虑：双指针、二分、滑动指针。

**④ 是否真的需要保存全部数据？**

有时只需要维护：最大值、最小值、当前候选、Top-K 或少量状态。

**⑤ 能否利用输入本身存储标记？**

可考虑：改符号、下标映射、交换到对应位置。

这类技巧经常把辅助空间从：

$$
O(n)
$$

降为：

$$
O(1)
$$

## 19. 设计思想的写法

不要只写：

> “遍历数组即可。”

应写清：

1. 从哪里开始、向哪个方向扫描；
2. 维护哪些变量或数据结构；
3. 每一步按什么规则更新；
4. 最终答案如何得到；
5. 为什么满足题目的复杂度要求。

例如：

> 算法从数组右端向左扫描，并维护当前位置到数组末尾范围内的最大值和最小值。处理 $A[i]$ 时，若 $A[i]\ge 0$，与后缀最大值相乘取得当前最大乘积；若 $A[i]<0$，与后缀最小值相乘。每个元素仅处理一次，因此时间复杂度为 $O(n)$，除常数个变量外不使用额外空间，因此辅助空间复杂度为 $O(1)$。

这种写法比“把代码翻译成中文”更容易体现算法思想。

## 20. 标准答题模板

### 20.1 设计思想模板

```text
算法分为以下步骤：
1. 首先……，得到……；
2. 然后利用……性质，维护……；
3. 扫描过程中根据……更新……；
4. 最终……即为答案。
```

如果使用已有模板，可以明确指出：

- 双指针；
- 哈希标记；
- BFS / DFS；
- 中序遍历；
- 前缀 / 后缀；
- 堆；
- 拓扑排序。

### 20.2 代码模板要求

代码不必追求工程项目级写法，但应保证：

- 核心流程正确；
- 边界条件完整；
- 变量含义清晰；
- 关键步骤有注释；
- 不违反题目空间或原地性限制。

### 20.3 复杂度模板

不要只写结论：

```text
时间复杂度：O(n)。
数组被完整扫描两次，每次均为 O(n)，因此总时间仍为 O(n)。

空间复杂度：O(1)。
除若干指针和计数变量外，没有使用随输入规模增长的辅助空间。
```

若使用递归，还应说明**最大递归深度**。

## 21. 代码注释与常见失分点

### 21.1 注释写什么

关键变量应说明“它表示什么状态”：

```c
int cnt = 1;
// cnt 表示当前候选主元素尚未被抵消的票数
```

可以说明循环不变量：

```c
// 扫描到 i 时，a[0..i-1] 中的出现信息已经完成标记
```

非显然的下标映射必须解释：

```c
a[v - 1] = -abs(a[v - 1]);
// 用下标 v-1 位置的正负号表示整数 v 是否出现
```

### 21.2 六类常见失分

1. **只写代码，不写设计思想**；
2. **复杂度只写结果，没有说明来源**；
3. **忽略边界条件**：空链表、$k$ 越界、空树、数组长度为 1、图不连通等；
4. **使用了题目不允许的辅助空间**；
5. **算法正确，但不满足题目要求的时间复杂度**；
6. **原地算法修改输入，却没有注意题目是否允许修改原数据**。

<Callout type="warn" title="复杂度要求是约束，不是装饰">
如果题目明确要求 $O(n)$，那么“先排序再扫描”的 $O(n\log n)$ 解法即使结果正确，也不满足要求。若题目要求 $O(1)$ 辅助空间，也不能申请长度为 $n$ 的数组。
</Callout>

## 22. 考场思考顺序与章末速记

### 22.1 六步思考法

**第一步：识别数据结构。**

数组、顺序表、链表、树、图、散列表，还是多个有序序列？

**第二步：圈出限制条件。**

- 时间复杂度；
- 空间复杂度；
- 是否有序；
- 是否允许修改原数据；
- 元素值域；
- 特殊结构性质。

**第三步：先想一个确定正确的算法。**

优先保证正确性。

**第四步：定位性能瓶颈。**

是重复扫描、重复查找、多余存储，还是没有利用有序性？

**第五步：匹配高频模板。**

```text
有序数组       → 双指针 / 二分
值域有限       → 桶 / 原地哈希
左右依赖       → 前缀 / 后缀
链表倒数位置   → 快慢指针
链表逆向处理   → 原地逆置
BST            → 中序遍历
树的层次问题   → BFS
图连通性       → DFS / BFS
依赖关系       → 拓扑排序
```

**第六步：最后检查复杂度与边界条件。**

分别检查：时间、辅助空间、递归深度、空输入和极端输入。

### 22.2 本章核心框架

```text
逻辑结构
  ↓
存储结构
  ↓
基本操作
  ↓
算法
  ↓
时间复杂度
  ↓
空间复杂度
```

算法五个特性：

```text
有穷性
确定性
可行性
输入
输出
```

常见复杂度：

$$
O(1)
<
O(\log n)
<
O(n)
<
O(n\log n)
<
O(n^2)
<
O(n^3)
<
O(2^n)
<
O(n!)
$$

数组高频模板：

```text
有序        → 双指针 / 二分
值域明确    → 桶 / 原地哈希
左右依赖    → 前缀 / 后缀
超半数元素  → Boyer-Moore
多有序序列  → 多指针
无更强性质  → 排序兜底
```

链表高频模板：

```text
中点 / 倒数第 k 个 → 快慢指针
逆向访问           → 原地逆置
公共后缀           → 双指针换头
```

树高频模板：

```text
BST 有序性质 → 中序遍历
按层处理     → BFS
路径 / 高度  → DFS / 递归
```

图高频模板：

```text
遍历 / 连通性   → DFS / BFS
无权最短路      → BFS
非负权最短路    → Dijkstra
全源最短路      → Floyd
最小生成树      → Prim / Kruskal
依赖关系        → 拓扑排序
AOE 网          → 关键路径
```

<Callout type="info" title="本章最终目标">
看到一个算法时，应能主动回答：**输入规模是什么？主要基本操作是什么？时间复杂度是多少？辅助空间复杂度是多少？** 面对算法设计题，还要继续问：**题目给出的数据结构具有什么可利用的性质？**
</Callout>
