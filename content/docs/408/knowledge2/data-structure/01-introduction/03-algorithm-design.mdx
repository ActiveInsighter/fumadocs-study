算法设计题的本质是：**先识别数据结构与限制条件，再利用结构性质消除重复工作。**

答题时优先保证正确性，然后再根据时间、空间和“能否修改原数据”等限制优化。

---

## 1.3.1 标准答题结构

一般按三部分作答：

1. **基本设计思想**：用自然语言说明算法步骤和关键维护信息；
2. **算法实现**：使用 C/C++ 或伪代码，关键位置写注释；
3. **复杂度分析**：分别说明时间复杂度与辅助空间复杂度。

推荐顺序：

```text
设计思想
  ↓
核心代码 / 伪代码
  ↓
时间复杂度
  ↓
空间复杂度
```

> **真题标签｜算法设计题**
>
> 历年数据结构综合题经常要求“设计思想 + 代码 + 复杂度”。无论最终算法是否最优，这三部分都应分开写，避免只交代码。

## 1.3.3 拿到题后的快速选型

```text
数组 / 顺序表
├─ 已有序 → 双指针 / 二分
├─ 值域有限 → 桶标记 / 下标映射 / 原地哈希
├─ 每个位置依赖左右区间 → 前缀 / 后缀预处理
├─ 超过半数候选 → Boyer-Moore
└─ 没有更强性质 → 排序后处理

链表
├─ 中点 / 倒数第 k 个 → 快慢指针
├─ 逆向访问 → 原地逆置
├─ 公共后缀 → 长度对齐 / 双指针换头
└─ 环相关 → 快慢指针

二叉树
├─ BST 有序信息 → 中序遍历
├─ 按层处理 → BFS
└─ 路径 / 高度 / 子树统计 → 递归 DFS

图
├─ 遍历 / 连通性 → DFS / BFS
├─ 无权最短路 → BFS
├─ 非负权单源最短路 → Dijkstra
├─ 全源最短路 → Floyd
├─ 最小生成树 → Prim / Kruskal
└─ 依赖关系 → 拓扑排序 / AOE 关键路径
```

## 1.3.4 数组套路一：排序作为兜底方案

面对无序数组，如果暂时找不到线性算法，可以先考虑排序：

$$
O(n\log n)
$$

排序后往往可以使用：

- 双指针；
- 二分查找；
- 相邻元素比较；
- 去重；
- 区间合并。

```c
qsort(a, n, sizeof(int), cmp);

int left = 0, right = n - 1;
while (left < right) {
    if (condition)
        ++left;
    else
        --right;
}
```

> **限制条件**：排序会改变元素原有次序。题目要求保持原序时，不能直接使用这种方案。

## 1.3.5 数组套路二：值域映射与原地标记

当题目同时出现以下信号时，应优先检查“值能否映射到下标”：

- 元素值域与 $n$ 同阶；
- 目标是判断“某值是否出现”；
- 要求 $O(n)$ 时间；
- 要求 $O(1)$ 辅助空间。

> **真题标签｜2018 年 41 题：未出现的最小正整数**
>
> 典型思想是只关心 $[1,n]$，再用下标 $v-1$ 的符号记录整数 $v$ 是否出现。

```c
int findMissMin(int a[], int n) {
    for (int i = 0; i < n; ++i) {
        if (a[i] <= 0 || a[i] > n)
            a[i] = n + 1;
    }

    for (int i = 0; i < n; ++i) {
        int v = abs(a[i]);
        if (1 <= v && v <= n)
            a[v - 1] = -abs(a[v - 1]);
    }

    for (int i = 0; i < n; ++i) {
        if (a[i] > 0)
            return i + 1;
    }

    return n + 1;
}
```

时间复杂度：

$$
O(n)
$$

辅助空间复杂度：

$$
O(1)
$$

> **易错点**：原地标记会修改输入数组。若题目要求保留原数据，必须换方案或事先说明恢复方式。

## 1.3.6 数组套路三：前缀 / 后缀预处理

若“每个位置的答案”都依赖左侧或右侧整个区间，暴力地为每个位置重新扫描往往会产生：

$$
O(n^2)
$$

如果统计量可递推，可以把它维护成前缀或后缀状态，从而把总时间压到：

$$
O(n)
$$

常见状态：

- 前缀和；
- 前缀最大 / 最小值；
- 后缀最大 / 最小值；
- 前缀 / 后缀计数；
- 前缀 / 后缀积。

> **真题标签｜2025 年 41 题：后缀最值**
>
> 对每个 $A[i]$，若要在区间 $A[i..n-1]$ 中选一个数使乘积最大，只需从右向左维护后缀最大值与最小值。

```c
void calMulMax(int A[], int res[], int n) {
    int maxValue = INT_MIN;
    int minValue = INT_MAX;

    for (int i = n - 1; i >= 0; --i) {
        if (A[i] > maxValue) maxValue = A[i];
        if (A[i] < minValue) minValue = A[i];

        res[i] = (A[i] >= 0)
            ? A[i] * maxValue
            : A[i] * minValue;
    }
}
```

## 1.3.7 数组套路四：Boyer-Moore 投票

适合寻找“出现次数超过一半”的候选元素。

核心思想：不同元素可以两两抵消。如果某元素出现次数严格超过 $n/2$，抵消结束后它一定能留下来成为候选。

> **真题标签｜2013 年 41 题：主元素**

```c
int majority(int a[], int n) {
    int candidate = a[0];
    int cnt = 1;

    for (int i = 1; i < n; ++i) {
        if (a[i] == candidate) {
            ++cnt;
        } else if (--cnt == 0) {
            candidate = a[i];
            cnt = 1;
        }
    }

    int freq = 0;
    for (int i = 0; i < n; ++i)
        if (a[i] == candidate)
            ++freq;

    return (freq > n / 2) ? candidate : -1;
}
```

第一遍只得到“候选者”。如果题目没有保证主元素一定存在，必须第二遍验证。

时间复杂度：$O(n)$；辅助空间复杂度：$O(1)$。

## 1.3.8 数组套路五：多指针夹逼

多个**有序序列**之间寻找最优组合时，应考虑让多个指针单向移动，而不是枚举所有组合。

> **真题标签｜2020 年 41 题：三个升序数组的最小距离**

设当前三个值满足：

$$
a\le b\le c
$$

若希望缩小最大值与最小值之间的差距，移动当前最大值通常无益，因为最大值只会更大；应优先移动当前最小值。

```c
while (i < n1 && j < n2 && k < n3) {
    ans = min(ans, calc_D(S1[i], S2[j], S3[k]));

    int m = min(S1[i], min(S2[j], S3[k]));
    if (S1[i] == m) ++i;
    else if (S2[j] == m) ++j;
    else ++k;
}
```

关键不是背“移动最小值”，而是能解释：**只有抬高当前最小值，才有机会缩小当前跨度。**

## 1.3.9 链表套路一：快慢指针

链表不能随机访问，下标技巧通常要换成指针技巧。

### 找中点

```c
NODE *slow = head->next;
NODE *fast = head->next;

while (fast != NULL && fast->next != NULL) {
    slow = slow->next;
    fast = fast->next->next;
}
```

### 找倒数第 $k$ 个结点

先让快指针领先 $k$ 个结点，再让两者同步移动。

```c
NODE *p = head->next;
NODE *q = head->next;

for (int i = 0; i < k; ++i) {
    if (p == NULL)
        return NULL;
    p = p->next;
}

while (p != NULL) {
    p = p->next;
    q = q->next;
}

return q;
```

这种方法只需一趟线性扫描，时间复杂度为 $O(n)$，辅助空间为 $O(1)$。

## 1.3.10 链表套路二：原地逆置

单链表无法从后向前访问。如果题目需要“从尾部方向处理”，常用做法是先把目标部分原地逆置。

```c
NODE *reverse(NODE *start) {
    NODE *prev = NULL;
    NODE *cur = start;

    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }

    return prev;
}
```

> **易错点**：必须先保存 `next`，再修改 `cur->next`，否则会丢失未处理的后续链表。

> **真题标签｜2019 年 41 题：链表重排**
>
> 高频组合：**快慢指针找中点 → 后半段原地逆置 → 两段链表交替合并**。

## 1.3.11 链表套路三：Y 形链表公共结点

若两个单链表共享后缀，则从第一个公共结点起，后续结点完全相同。

可以让两个指针分别走：

```text
A → B
B → A
```

这样两者走过的总路程相同。

```c
NODE *p = headA;
NODE *q = headB;

while (p != q) {
    p = (p != NULL) ? p->next : headB;
    q = (q != NULL) ? q->next : headA;
}

return p;
```

返回 `NULL` 表示无公共结点，否则返回第一个公共结点。

## 1.3.12 二叉树套路：先定义递归函数语义

写树形递归前，先回答三个问题：

1. **函数语义是什么？** 例如 `height(root)` 表示什么；
2. **终止条件是什么？** 常见为 `root == NULL`；
3. **如何由左右子树的答案得到当前结点答案？**

这是比“背模板”更稳定的方法。

### BST：优先利用中序有序性

二叉搜索树满足：**中序遍历结果按关键字递增**。

因此题目出现以下关键词时，应首先想到中序遍历：

- 第 $k$ 小 / 第 $k$ 大；
- 前驱 / 后继；
- 判断是否为 BST；
- 相邻关键字差值；
- 生成有序序列。

```c
void inorder(BTNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    visit(root);
    inorder(root->right);
}
```

### 按层处理：使用 BFS

出现“层数、层宽、逐层访问、最近层次”等信息时，优先考虑队列与层序遍历。

```c
enqueue(Q, root);
while (!isEmpty(Q)) {
    BTNode *u = dequeue(Q);
    visit(u);

    if (u->left) enqueue(Q, u->left);
    if (u->right) enqueue(Q, u->right);
}
```

## 1.3.13 图题套路：先识别问题类型

| 问题 | 优先算法 |
| --- | --- |
| 遍历、连通性 | DFS / BFS |
| 无权图最短路 | BFS |
| 非负权单源最短路 | Dijkstra |
| 全源最短路 | Floyd |
| 最小生成树 | Prim / Kruskal |
| DAG 依赖顺序 | 拓扑排序 |
| AOE 网工程时间 | 关键路径 |

### DFS 模板

```c
void DFS(MGraph G, int v) {
    visited[v] = 1;
    visit(v);

    for (int w = 0; w < G.numVertices; ++w) {
        if (G.Edge[v][w] && !visited[w])
            DFS(G, w);
    }
}
```

### BFS 模板

```c
enqueue(Q, s);
visited[s] = 1;

while (!isEmpty(Q)) {
    int u = dequeue(Q);
    visit(u);

    for (int w = 0; w < G.numVertices; ++w) {
        if (G.Edge[u][w] && !visited[w]) {
            visited[w] = 1;
            enqueue(Q, w);
        }
    }
}
```

对于无权图，BFS 第一次到达某顶点时得到的是从起点到该顶点的最少边数路径。

## 1.3.14 拓扑排序：入度 + 队列

拓扑排序适用于 DAG 的依赖关系。

基本过程：

1. 统计每个顶点的入度；
2. 所有入度为 0 的顶点入队；
3. 每次取出一个顶点并“删除”它发出的边；
4. 相邻顶点入度减 1；
5. 新出现的入度为 0 的顶点继续入队。

```text
count = 0
把所有 indegree == 0 的顶点入队

while 队列非空:
    u = 出队
    count++

    for u 的每个邻接点 w:
        indegree[w]--
        if indegree[w] == 0:
            w 入队

若 count == 顶点数，则图无有向环；否则存在有向环。
```

> **真题标签｜2024 年 41 题：拓扑排序相关算法**
>
> 拓扑排序类题最关键的状态是“当前剩余图中的入度”。

## 1.3.15 邻接矩阵中的度统计

对于无向图：

> 第 $v$ 行非零元素个数就是顶点 $v$ 的度。

对于有向图：

- 第 $v$ 行非零元素个数是出度；
- 第 $v$ 列非零元素个数是入度。

```c
int outDegree(MGraph G, int v) {
    int d = 0;
    for (int w = 0; w < G.numVertices; ++w)
        d += (G.Edge[v][w] != 0);
    return d;
}
```

图题看到邻接矩阵时，首先检查“行”和“列”分别代表什么信息，很多统计题都能直接利用这一点。
