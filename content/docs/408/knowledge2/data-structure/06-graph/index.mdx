图是一种描述**多对多关系**的数据结构。本章既要掌握图的基本术语与存储结构，又要能够根据具体问题选择并手工执行经典图算法。

<InlineSvg src="/images/data-structure/data-structure-graph-001.svg" alt={"图结构与经典算法概览"} />

| 模块     | 408 复习重点                 |
| ------ | ------------------------ |
| 图的基本概念 | 有向/无向、度、路径、回路、连通、强连通、完全图 |
| 图的存储   | 邻接矩阵、邻接表、邻接多重表、十字链表      |
| 图的遍历   | DFS、BFS、遍历序列、连通分量、复杂度    |
| 最小生成树  | Prim、Kruskal、贪心思想、算法过程   |
| 最短路径   | Dijkstra、Floyd-Warshall  |
| DAG 应用 | 拓扑排序、AOV 网、AOE 网、关键路径    |
| 图与树    | 使用 DAG 消除重复子表达式          |

> **复习提示**
>
> 图算法最容易混淆的不是步骤，而是**适用条件**：
>
> * 最小生成树：连通、无向、带权图；
> * Dijkstra：单源最短路径，边权必须非负；
> * Floyd：全源最短路径，可包含负权边，但不能存在相关负权环；
> * 拓扑排序：有向无环图 DAG；
> * 关键路径：AOE 网，本质上是带权 DAG。
