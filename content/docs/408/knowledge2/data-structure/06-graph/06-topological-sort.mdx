拓扑排序用于处理“任务之间存在先后依赖”的问题。它不是按编号排序，而是寻找一个满足全部有向边约束的线性序列。

> **真题标签｜2010 第 8 题、2012 第 6 题、2014 第 7 题、2016 第 7 题、2018 第 7 题、2020 第 6 题、2021 第 7 题；2024 第 41 题：拓扑排序与 DAG**
>
> 2020 年真题尤其体现了“DFS 完成顺序与拓扑序”的关系；2016 年真题常用于考邻接表下 $O(V+E)$ 的复杂度。

## 6.6.1 DAG 与拓扑序

DAG 是 Directed Acyclic Graph，即**有向无环图**。

若能把全部顶点排列为：

$$
v_1,v_2,\ldots,v_n
$$

并使每条有向边：

$$
u\rightarrow v
$$

都满足 $u$ 出现在 $v$ 之前，则该序列称为一个**拓扑序列**。

一个有限有向图存在拓扑序，当且仅当它是 DAG。

## 6.6.2 AOV 网

AOV：Activity On Vertex Network，即**顶点表示活动**。

在 AOV 网中：

- 顶点：活动/任务；
- 有向边：活动之间的先后约束。

若：

$$
u\rightarrow v
$$

表示活动 $u$ 必须先于活动 $v$。

若出现有向环，就意味着循环依赖，因此合法的 AOV 网必须是 DAG。

## 6.6.3 Kahn 算法：不断删除入度为 0 的顶点

Kahn 算法是 408 最常见的拓扑排序过程。

基本思想：

> 当前入度为 0 的顶点已经没有未完成的前驱，可以立刻输出。

步骤：

1. 统计所有顶点入度；
2. 把所有入度为 0 的顶点加入栈或队列；
3. 取出一个顶点 $u$ 并输出；
4. “删除” $u$ 的所有出边，即把各后继入度减 1；
5. 新产生的入度 0 顶点加入容器；
6. 重复直到容器为空。

伪代码：

```text
TopologicalSort(G):
    统计 indegree[*]
    将所有 indegree[v] = 0 的顶点加入容器
    count = 0

    while 容器非空:
        u = 取出一个入度为 0 的顶点
        output(u)
        count++

        for each edge u -> v:
            indegree[v]--
            if indegree[v] == 0:
                加入容器

    return count == |V|
```

## 6.6.4 用拓扑排序判断是否有环

若算法最终只输出了：

$$
count<|V|
$$

说明剩余顶点都无法把入度降到 0，它们中必存在有向环。

因此 Kahn 算法同时可以完成：

- 求拓扑序；
- 判断有向图是否为 DAG。

## 6.6.5 拓扑序是否唯一

拓扑序不一定唯一。

在 Kahn 算法中：

- 若某一步同时存在多个入度为 0 的顶点，就存在不同的选择分支，因此拓扑序不唯一；
- 若从头到尾每一步都**恰好只有一个**入度为 0 的可选顶点，则拓扑序唯一。

这不是“通常”，而是对有限 DAG 的一个直接判定方法。

> **注意容器策略**
>
> 使用栈、队列或优先队列，只会影响“多个合法候选点之间选择谁”，不会改变拓扑排序的合法性判定。

## 6.6.6 DFS + 栈求拓扑序

对 DAG 执行 DFS：

1. 访问顶点；
2. 递归访问它的所有后继；
3. 当该顶点的 DFS 即将结束时，将它压栈；
4. DFS 全部完成后不断出栈。

因为存在边：

$$
u\rightarrow v
$$

时，若从 $u$ 深入到 $v$，通常会先完成 $v$，再完成 $u$。因此：

- **完成顺序**是逆拓扑方向；
- **完成时压栈、最后出栈**得到拓扑序。

> **真题标签｜2020 第 6 题**
>
> 如果把 DFS 中的“输出顶点”语句移到退出递归之前直接执行，那么打印顺序对应的是**逆拓扑有序序列**；若把这些完成顶点压栈后再弹出，则得到拓扑序。

## 6.6.7 DFS 判断有向环：三色标记

只用 `visited[]` 不能区分“已处理完成”和“当前仍在递归路径上”。判断有向环常使用三种状态：

- `0`：未访问；
- `1`：正在访问（灰色）；
- `2`：已完成（黑色）。

DFS 遇到一条指向灰色顶点的边，说明出现**回边**，因此存在有向环。

## 6.6.8 拓扑排序复杂度

若使用邻接表：

- 每个顶点进出容器至多一次；
- 每条边用于减少一次入度。

总时间复杂度：

$$
O(V+E)
$$

额外空间主要是入度数组和容器：

$$
O(V)
$$

若使用邻接矩阵，为寻找和删除出边往往需要反复扫描行，复杂度通常上升到 $O(V^2)$。

## 6.6.9 本节速查

| 问题 | 结论 |
| --- | --- |
| 哪类图有拓扑序 | DAG |
| Kahn 每次选什么 | 入度为 0 的顶点 |
| 输出顶点后做什么 | 删除其出边，后继入度减 1 |
| 未输出全部顶点 | 图中存在有向环 |
| DFS 完成顺序 | 逆拓扑方向 |
