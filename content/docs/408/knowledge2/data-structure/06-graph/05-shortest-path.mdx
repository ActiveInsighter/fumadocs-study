- **Floyd-Warshall**：任意两点之间的最短路径。

> **真题标签｜2012 第 7 题、2016 第 8 题、2021 第 8 题；2009 第 41 题、2014 第 42 题：最短路径与 Dijkstra/Floyd**
>
> 真题尤其喜欢考“看似贪心但不是 Dijkstra”的错误策略，以及手工更新 `dist[]` 的过程。

## 6.5.1 松弛：最短路径算法的基本动作

若当前已知源点 $s$ 到 $u$ 的距离为 $dist[u]$，且存在边：

$$
u\rightarrow v
$$

边权为 $w(u,v)$，则可以尝试经 $u$ 改进到 $v$ 的距离：

$$
dist[v]=\min\left(dist[v],\ dist[u]+w(u,v)\right)
$$

这个操作称为**松弛**。

如果要恢复具体路径，还应在更新时记录：

```c
prev[v] = u;
```

最后从终点沿 `prev[]` 反向回溯到源点。

## 6.5.2 Dijkstra 算法的适用条件

Dijkstra 求一个源点到其他各顶点的最短路径。

适用于：

- 有向图或无向图；
- 带权图；
- **所有边权必须非负**。

不能把“只要没有负环”误当成 Dijkstra 的条件。即使没有负环，只要存在负权边，标准 Dijkstra 的贪心正确性就可能失效。

## 6.5.3 Dijkstra 的两个核心数组

设源点为 $s$。

### `dist[]`

初始化：

$$
dist[s]=0
$$

其他顶点：

$$
dist[v]=\infty
$$

`dist[v]` 表示当前已知的 $s\rightarrow v$ 最短暂定距离。

### `final[]` / `visited[]`

表示顶点的最短距离是否已经**最终确定**。

初始全部为 `false`。

## 6.5.4 Dijkstra 的执行过程

每轮执行：

1. 从所有尚未最终确定的顶点中，找 `dist[]` 最小的顶点 $u$；
2. 把 $u$ 标记为最终确定；
3. 用 $u$ 对所有未确定邻接点执行松弛；
4. 重复，直到所有可达顶点被确定。

伪代码：

```text
Dijkstra(G, s):
    dist[*] = INF
    final[*] = false
    dist[s] = 0

    repeat |V| times:
        u = 未确定顶点中 dist 最小者
        if u 不存在或 dist[u] = INF:
            break

        final[u] = true

        for each edge (u, v):
            if !final[v] and dist[v] > dist[u] + w(u, v):
                dist[v] = dist[u] + w(u, v)
                prev[v] = u
```

### 手工模拟的标准表格

建议每轮记录：

| 轮次 | 新确定顶点 | 已确定集合 $S$ | 各未确定顶点 `dist` |
| --- | --- | --- | --- |
| 0 | 源点 | $\{s\}$ | 初始化 |
| 1 | 当前最小者 | 扩大 $S$ | 松弛后更新 |
| … | … | … | … |

不要“凭图看起来近”直接选下一顶点，一定比较**源点到它的累计暂定距离**。

## 6.5.5 为什么不能有负权边

当 Dijkstra 把 $u$ 加入最终集合时，它假定：

$$
dist[u]
$$

今后不会再减小。

这一结论依赖“后续边权非负”。若存在负权边，后来绕一圈再到 $u$ 的路径可能比当前值更小，于是已经“最终确定”的值被推翻。

> **真题思维｜2009 第 41 题**
>
> “每次从当前顶点选一条最短邻边继续走”并不是 Dijkstra。Dijkstra 选择的是**所有未确定顶点中源点累计距离最小者**，而不是“离当前顶点最近的邻居”。

## 6.5.6 Dijkstra 的复杂度

顺序数组 / 邻接矩阵实现：

$$
O(V^2)
$$

邻接表 + 二叉堆：

$$
O((V+E)\log V)
$$

稀疏图中常简写为：

$$
O(E\log V)
$$

408 手工与基础实现通常以 $O(V^2)$ 版本为主。

## 6.5.7 Floyd-Warshall 算法

Floyd 求所有顶点对之间的最短路径，是典型的动态规划。

它允许：

- 有向图；
- 无向图；
- 负权边。

但若存在可达的**负权环**，则某些顶点对不存在有限意义上的最短路径。

## 6.5.8 Floyd 的动态规划状态

设：

$$
D^{(k)}[i][j]
$$

表示只允许顶点 $v_1,\ldots,v_k$ 作为中间点时，$v_i$ 到 $v_j$ 的最短距离。

状态转移：

$$
D^{(k)}[i][j]
=
\min\left(
D^{(k-1)}[i][j],
D^{(k-1)}[i][k]+D^{(k-1)}[k][j]
\right)
$$

实际实现可以原地更新：

```c
for (int k = 0; k < n; ++k) {
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            if (dist[i][k] != INF && dist[k][j] != INF) {
                dist[i][j] = min(dist[i][j],
                                 dist[i][k] + dist[k][j]);
            }
        }
    }
}
```

> **高频易错｜`k` 必须在最外层**
>
> Floyd 的含义是“逐步开放新的中间顶点”，所以 `k` 必须先固定，再更新所有 $(i,j)$。随意交换三重循环顺序会破坏动态规划阶段含义。

## 6.5.9 Floyd 的初始化与负环判断

通常初始化：

$$
dist[i][i]=0
$$

若存在边 $(i,j)$：

$$
dist[i][j]=w(i,j)
$$

否则：

$$
dist[i][j]=\infty
$$

若算法结束后某个：

$$
dist[i][i]<0
$$

则说明存在可达的负权环。

## 6.5.10 Floyd 的复杂度

时间复杂度：

$$
O(V^3)
$$

空间复杂度：

$$
O(V^2)
$$

## 6.5.11 Dijkstra 与 Floyd 对比

| 项目 | Dijkstra | Floyd-Warshall |
| --- | --- | --- |
| 问题 | 单源最短路径 | 全源最短路径 |
| 思想 | 贪心 | 动态规划 |
| 负权边 | 不允许 | 允许 |
| 负权环 | 不适用 | 会导致无有限最短路 |
| 常见复杂度 | $O(V^2)$ | $O(V^3)$ |
| 408 常见操作 | 更新一维 `dist[]` | 更新距离矩阵 |

> **算法选择速记**
>
> - 无权图单源最短路径 → BFS；
> - 非负权图单源最短路径 → Dijkstra；
> - 所有顶点对最短路径 → Floyd。
