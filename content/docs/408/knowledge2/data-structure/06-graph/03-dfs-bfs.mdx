图与树的遍历有一个本质区别：**图可能存在环，也可能存在多条路径到达同一顶点**。因此必须维护访问标记，否则会重复访问甚至陷入死循环。

> **真题标签｜2012 第 5 题、2013 第 8 题、2015 第 5 题、2016 第 6 题、2020 第 6 题：DFS、BFS、遍历序列与遍历性质**
>
> 高频题型包括判断可能的 DFS/BFS 序列、由遍历树推导最短边数路径、分析邻接矩阵/邻接表下的复杂度。

## 6.3.1 遍历的统一框架

通常维护：

```c
bool visited[MAXV];
```

对非连通图，不能只从一个起点搜索，而要套一层外循环：

```c
for (int v = 0; v < G.vexnum; ++v) {
    if (!visited[v]) {
        Search(G, v);
    }
}
```

对无向图而言，每次从一个未访问顶点启动新的 DFS/BFS，就进入了一个新的连通分量。

## 6.3.2 深度优先搜索 DFS

DFS 的核心思想：

> 沿一条分支尽可能深入；走不下去时回溯，再尝试其他分支。

它天然对应：

- 递归调用栈；
- 或显式栈。

基本伪代码：

```text
DFS(G, v):
    visited[v] = true
    visit(v)

    for each neighbor u of v:
        if !visited[u]:
            DFS(G, u)
```

### 邻接矩阵下的复杂度

每访问一个顶点，都要扫描矩阵的一整行，因此总时间复杂度为：

$$
O(V^2)
$$

### 邻接表下的复杂度

所有顶点和边只被检查常数次，因此：

$$
O(V+E)
$$

递归 DFS 的额外栈空间最坏可达：

$$
O(V)
$$

## 6.3.3 广度优先搜索 BFS

BFS 的核心思想：

> 从起点开始逐层向外扩展，先访问距离起点 1 条边的顶点，再访问距离 2 条边的顶点……

它使用**队列**。

```text
BFS(G, s):
    visited[s] = true
    enqueue(Q, s)

    while Q not empty:
        v = dequeue(Q)
        visit(v)

        for each neighbor u of v:
            if !visited[u]:
                visited[u] = true
                enqueue(Q, u)
```

> **高频易错｜BFS 应在入队时标记**
>
> 如果等到出队时才把顶点标为已访问，同一个顶点可能被多个前驱重复入队。正确做法通常是：第一次发现它时立刻 `visited[u] = true`，然后入队。

复杂度：

| 存储方式 | BFS 时间复杂度 |
| --- | ---: |
| 邻接矩阵 | $O(V^2)$ |
| 邻接表 | $O(V+E)$ |

队列额外空间最坏为：

$$
O(V)
$$

## 6.3.4 DFS 与 BFS 的访问序列

同一张图的 DFS/BFS 序列**可能不唯一**，原因是某个顶点可能同时有多个尚未访问的邻接点。

因此做题时要先确定邻接点选取规则，例如：

- 邻接矩阵按列下标从小到大；
- 邻接表按链表出现顺序；
- 题目明确要求按顶点编号从小到大。

### 判断 DFS 序列

关键看是否满足“深度优先”：

- 当前顶点只要还有未访问邻接点，就应该继续深入；
- 只有当前分支无路可走才回溯。

### 判断 BFS 序列

关键看“层次”：

- 距离起点更近的层必须先于更远的层被发现；
- 同一层内部顺序则取决于邻接点扫描顺序。

## 6.3.5 BFS 与无权最短路径

在**无权图**中，从源点 $s$ 执行 BFS，顶点第一次被发现时，其 BFS 层次就是从 $s$ 到该顶点的最少边数。

设：

$$
d[s]=0
$$

当从 $u$ 第一次发现 $v$ 时：

$$
d[v]=d[u]+1
$$

因此 BFS 可以在线性时间内求无权图的单源最短路径：

$$
O(V+E)
$$

若同时维护：

```c
parent[v] = u;
```

还可以恢复具体路径。

> **易错点｜BFS 只保证无权/等权图的最少边数路径**
>
> 一旦边权不同，就不能用普通 BFS 直接替代 Dijkstra。

## 6.3.6 遍历生成树与生成森林

在连通无向图中，从某个起点进行 DFS/BFS 时，第一次发现新顶点所使用的边称为**树边**。

这些树边构成：

- DFS → 深度优先生成树；
- BFS → 广度优先生成树。

若原图不连通，则对各连通分量分别得到一棵生成树，整体称为**生成森林**。

对于含 $n$ 个顶点、$c$ 个连通分量的无向图，生成森林中的树边总数为：

$$
n-c
$$

## 6.3.7 DFS/BFS 与连通性

对无向图：

- 从某顶点出发能访问到全部顶点 → 图连通；
- 外层循环启动搜索的次数 → 连通分量数。

对有向图：

- 从某一点能到达所有点，只说明该点对所有点可达；
- 不能据此直接推出强连通；
- 强连通要求任意两点互相可达。

## 6.3.8 DFS 与完成时间

DFS 中一个顶点“退出递归”的时刻称为完成时刻。

若 DAG 中存在边：

$$
u\rightarrow v
$$

则在适当的 DFS 过程中，按**完成时间逆序**排列顶点可以得到拓扑序。

因此：

- DFS 退出递归时直接打印 → 得到的是逆拓扑方向；
- DFS 退出递归时压栈，最后依次出栈 → 得到拓扑序。

这个性质会在拓扑排序小节再次使用。

## 6.3.9 DFS 与 BFS 对比

| 项目 | DFS | BFS |
| --- | --- | --- |
| 核心结构 | 栈 / 递归 | 队列 |
| 搜索方式 | 优先深入 | 按层扩展 |
| 邻接表复杂度 | $O(V+E)$ | $O(V+E)$ |
| 邻接矩阵复杂度 | $O(V^2)$ | $O(V^2)$ |
| 无权单源最短路径 | 不保证 | 可以 |
| 常见扩展 | 连通性、拓扑、环判断 | 无权最短路、层次关系 |
