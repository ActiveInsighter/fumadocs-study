查找的核心目标是：**给定一个关键字，在查找表中确定是否存在与之匹配的记录，并尽可能减少比较或探测次数。**

408 对本章的考查主要集中在以下三条主线：

1. **线性表上的查找**：顺序查找、折半查找、分块查找。
2. **树形查找**：BST、AVL、红黑树，以及重点考查的 B 树和 B+ 树。
3. **散列表查找**：散列函数、冲突处理、装填因子，以及成功/失败的平均查找长度 ASL。

其中，**B 树的阶数与结点性质、B 树与 B+ 树的区别、开放定址法的探测过程、散列表 ASL 的计算**是选择题和综合题中的重点。
