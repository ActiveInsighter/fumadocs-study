树结构把线性结构中的“一对一”关系扩展为“一对多”的层次关系。本章是 408 数据结构的核心章节之一，复习时应抓住以下主线：

**基本概念与性质 → 存储结构 → 树/森林与二叉树转换 → 二叉树遍历与重建 → 搜索树与平衡树 → 哈夫曼树 → 并查集。**

<InlineSvg src="/images/data-structure/data-structure-tree-001.svg" alt={"树与二叉树知识结构"} />

> **复习重点**
>
> 二叉树性质、遍历序列、树与森林转换、BST、AVL、红黑树、哈夫曼树的 WPL 都属于高频考点。算法题中还应能够写出遍历、BST 操作以及基本树结构的递归代码。
