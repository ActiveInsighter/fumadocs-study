普通 BST 可能退化成链表。平衡搜索树的目标是控制树高，使查找、插入和删除维持对数级复杂度。

> **真题标签｜2009 第 4 题、2010 第 4 题、2012 第 4 题、2013 第 3 题、2015 第 4 题、2019 第 4 题、2021 第 6 题、2026 第 8 题：AVL 平衡与旋转**

## 5.6.1 AVL 的定义

AVL 首先是一棵 BST，并额外要求任意结点左右子树高度差的绝对值不超过 1。

定义平衡因子：

$$
BF=h_{left}-h_{right}
$$

AVL 要求：

$$
|BF|\le 1
$$

因此每个结点的平衡因子只能是：

```text
-1, 0, +1
```

AVL 树高保持在：

$$
O(\log n)
$$

所以查找、插入、删除均可保持：

$$
O(\log n)
$$

## 5.6.2 最小不平衡子树

插入新结点后，从插入位置沿祖先方向向上检查。

> **第一个满足 $|BF|>1$ 的祖先结点，就是最小不平衡子树的根。**

调整时只需围绕这个局部结构旋转，不需要重建整棵树。

## 5.6.3 四种失衡类型

设最小不平衡根为 `A`。

| 类型 | 新结点位置 | 调整 |
| --- | --- | --- |
| LL | `A` 左孩子的左子树 | `A` 右旋 |
| RR | `A` 右孩子的右子树 | `A` 左旋 |
| LR | `A` 左孩子的右子树 | 先左旋左孩子，再右旋 `A` |
| RL | `A` 右孩子的左子树 | 先右旋右孩子，再左旋 `A` |

记忆：

- LL、RR 是“同向直线”，单旋；
- LR、RL 是“折线”，先把折线拉直，再做单旋。

## 5.6.4 为什么旋转后仍然是 BST

旋转并不是随意交换结点，而是在保持中序序列不变的前提下重新组织局部父子关系。

例如 LL 型中，若有：

```text
      A
     /
    B
   /
  C
```

右旋后：

```text
    B
   / \
  C   A
```

关键字仍满足：

```text
C < B < A
```

因此 BST 的中序有序性质不变。

## 5.6.5 左旋与右旋模板

### 左旋

```c
TreeNode *leftRotate(TreeNode *x) {
    TreeNode *y = x->right;
    TreeNode *t2 = y->left;

    y->left = x;
    x->right = t2;

    updateHeight(x);
    updateHeight(y);
    return y;
}
```

### 右旋

```c
TreeNode *rightRotate(TreeNode *y) {
    TreeNode *x = y->left;
    TreeNode *t2 = x->right;

    x->right = y;
    y->left = t2;

    updateHeight(y);
    updateHeight(x);
    return x;
}
```

## 5.6.6 AVL 插入的标准判断顺序

插入过程：

1. 按普通 BST 规则插入；
2. 回溯更新每个祖先的高度；
3. 计算平衡因子；
4. 遇到第一个失衡祖先时，判断 LL/RR/LR/RL；
5. 旋转后返回新的局部根。

常见判断逻辑：

```c
if (bf > 1 && key < root->left->data) {
    return rightRotate(root);          // LL
}

if (bf < -1 && key > root->right->data) {
    return leftRotate(root);           // RR
}

if (bf > 1 && key > root->left->data) {
    root->left = leftRotate(root->left);
    return rightRotate(root);          // LR
}

if (bf < -1 && key < root->right->data) {
    root->right = rightRotate(root->right);
    return leftRotate(root);           // RL
}
```

408 中更重要的是能手算旋转，而不是背完整实现。

## 5.6.7 AVL 高度与最少结点数

若高度按“叶结点高度为 1”计，设高度为 $h$ 的 AVL 最少结点数为 $N_h$，则为了让树尽量稀疏而仍保持高度 $h$，左右子树高度应分别为 $h-1$ 与 $h-2$：

$$
N_h=N_{h-1}+N_{h-2}+1
$$

初值：

$$
N_1=1,\quad N_2=2
$$

因此：

```text
N1 = 1
N2 = 2
N3 = 4
N4 = 7
N5 = 12
...
```

这类递推常用于“给定高度求最少结点”或“给定结点数求最大可能高度”。

## 5.6.8 红黑树的五条核心约束

红黑树也是一种自平衡 BST，但平衡条件比 AVL 宽松。典型定义：

1. 每个结点非红即黑；
2. 根结点是黑色；
3. 所有 NIL 空叶结点视为黑色；
4. 红结点不能有红孩子，即不存在连续两个红结点；
5. 从任一结点到其所有后代 NIL 的路径包含相同数量的黑结点。

第 5 条中的黑色结点数量称为**黑高**。

## 5.6.9 红黑树的高度

红黑性质保证最长根到叶路径不会超过最短路径的 2 倍，因此树高仍为：

$$
O(\log n)
$$

更具体地，对含 $n$ 个内部结点的红黑树，可得：

$$
h\le 2\log_2(n+1)
$$

所以搜索、插入、删除都保持对数级复杂度。

## 5.6.10 AVL 与红黑树比较

| 对比 | AVL | 红黑树 |
| --- | --- | --- |
| 首先是否为 BST | 是 | 是 |
| 平衡程度 | 更严格 | 较宽松 |
| 约束方式 | 高度差 $|BF|\le1$ | 颜色 + 黑高 |
| 树高 | $O(\log n)$，通常更矮 | $O(\log n)$ |
| 查找 | 通常路径更短 | 同样为对数级 |
| 插入/删除维护 | 可能需要较严格旋转调整 | 常用旋转 + 重新着色 |
| 中序遍历 | 递增 | 递增 |

> **易错点**
>
> AVL 与红黑树的“平衡规则”不同，但它们首先都是 BST，因此都保留 BST 的有序性质。
