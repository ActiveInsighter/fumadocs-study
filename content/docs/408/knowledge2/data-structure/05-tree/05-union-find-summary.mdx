## 二十三、并查集

**并查集（Disjoint Set Union / Union-Find）**用于维护若干个互不相交的集合。

它主要支持：

* `Find`：查询某元素属于哪个集合；
* `Union`：把两个集合合并。

并查集通常用一片森林表示。

每个集合对应一棵树，而集合的代表元素就是这棵树的根。

## 二十四、Find 操作与路径压缩

基本 Find：

> 不断沿 `parent` 向上查找，直到遇到满足 `parent[x] == x` 的根结点。

若每次都按原路径查找，树过高时效率会下降。

因此通常采用**路径压缩（Path Compression）**：

在一次 Find 过程中，让路径上的所有结点直接指向根。

例如原来：

```text
x → a → b → root
```

执行一次路径压缩后可变为：

```text
x ─────→ root
a ─────→ root
b ─────→ root
```

后续查询就会明显加快。

## 二十五、Union 操作与按秩合并

合并两个集合时，首先分别执行：

```text
Find(x)
Find(y)
```

得到两个集合的根。

若两个根不同，再将其中一棵树挂到另一棵树下面。

为了避免树快速变高，可使用：

* 按秩合并（union by rank）；
* 按大小合并（union by size）。

按秩合并的基本原则是：

> 尽量把较矮的树挂到较高的树下面。

若两棵树的秩相同，则任选一棵作为新根，并将其秩加 1。

需要注意：

> 使用路径压缩后，`rank` 通常只是用于指导合并的启发式指标，不一定再等于当前树的真实高度。

## 二十六、并查集代码

```c
#define MAXN 1000

int parent[MAXN];
int rank[MAXN];

void initialize(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;
        rank[i] = 0;
    }
}

int find(int x) {
    if (parent[x] != x) {
        parent[x] =
            find(parent[x]);
    }

    return parent[x];
}

void unionSet(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);

    if (rootX != rootY) {
        if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else if (
            rank[rootX] < rank[rootY]
        ) {
            parent[rootX] = rootY;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }
}
```

同时采用：

* 路径压缩；
* 按秩或按大小合并；

以后，并查集单次操作的均摊复杂度可以达到：

$$
O(\alpha(n))
$$

其中 $\alpha(n)$ 是反阿克曼函数，增长极其缓慢，在实际规模下几乎可以看作常数。

## 二十七、本章易错点总结

| 易错点             | 正确理解               |
| --------------- | ------------------ |
| 结点的度            | 在普通树中通常指孩子数        |
| 路径长度            | 计算边数，不是结点数         |
| 深度              | 408 常规定根深度为 1      |
| WPL 中的路径长度      | 使用根到叶结点的边数         |
| 满二叉树            | 每一层都达到最大结点数        |
| “每个内部结点有两个孩子”   | 不一定是 408 定义下的满二叉树  |
| 完全二叉树           | 最后一层必须从左向右连续       |
| 树是否有普通中序遍历      | 没有                 |
| 树的后根遍历          | 对应孩子兄弟二叉树的中序遍历     |
| 森林的先序遍历         | 对应二叉树先序遍历          |
| 森林的中序遍历         | 对应二叉树中序遍历          |
| 二叉链表空指针数        | $n+1$            |
| BST 中序遍历        | 得到递增有序序列           |
| BST 查找复杂度       | 与树高有关，最坏 $O(n)$  |
| AVL 最小不平衡子树     | 从插入点向上遇到的第一个失衡祖先为根 |
| LL              | 右旋                 |
| RR              | 左旋                 |
| LR              | 先左后右               |
| RL              | 先右后左               |
| 红黑树             | 是近似平衡 BST，不等同于 AVL |
| 前缀编码            | 没有码字是其他码字的前缀       |
| 哈夫曼树            | WPL 最小，但具体树形可能不唯一  |
| 哈夫曼树叶子为 $n$ 个 | 总结点数为 $2n-1$     |
| 哈夫曼构造           | 每次合并当前权值最小的两棵树     |
| 哈夫曼编码左右 0/1     | 可以互换，不影响码长和 WPL    |
| 并查集 rank        | 路径压缩后不一定是真实树高      |

## 二十八、408 高频公式与结论

设二叉树根位于第 1 层。

第 $i$ 层最大结点数：

$$
2^{i-1}
$$

高度为 $h$ 时最大结点数：

$$
2^h-1
$$

完全二叉树结点数与高度：

$$
2^{h-1}
\le n
\le
2^h-1
$$

$$
h=
\left\lfloor
\log_2 n
\right\rfloor
+1
$$

二叉树叶结点数与度为 2 的结点数：

$$
n_0=n_2+1
$$

二叉链表中的空孩子指针数：

$$
n+1
$$

定长编码最短位数：

$$
l=
\left\lceil
\log_2 n
\right\rceil
$$

树的带权路径长度：

$$
WPL=
\sum_i w_i l_i
$$

编码总长度：

$$
WPL=
\sum_{i=1}^{n}
f_i l_i
$$

平均编码长度：

$$
L=
\sum_{i=1}^{n}
p_i l_i
$$

AVL 平衡条件：

$$
|BF|\le1
$$

红黑树高度：

$$
h=O(\log n)
$$

BST、AVL、红黑树搜索的统一理解：

$$
T=O(h)
$$

其中 BST 最坏可能：

$$
h=O(n)
$$

而 AVL 与红黑树均保证：

$$
h=O(\log n)
$$

含 $n$ 个叶结点的二叉哈夫曼树：

$$
\text{内部结点数}=n-1
$$

$$
\text{总结点数}=2n-1
$$

并查集采用路径压缩与按秩合并后的均摊复杂度：

$$
O(\alpha(n))
$$
