并查集（Disjoint Set Union，DSU / Union-Find）用于动态维护若干互不相交的集合。

每个集合可看作一棵树，集合代表元就是该树的根。

核心操作只有两个：

- `Find(x)`：找到 `x` 所属集合的代表元；
- `Union(x, y)`：合并 `x`、`y` 所在集合。

## 5.8.1 基本表示

最常见的是父指针数组：

```c
int parent[MAXN];
```

初始化时每个元素独自构成集合：

```c
for (int i = 0; i < n; ++i) {
    parent[i] = i;
}
```

根结点满足：

```text
parent[x] == x
```

## 5.8.2 Find 操作

最基础的 `Find` 沿父指针不断向上：

```c
int findRoot(int x) {
    while (parent[x] != x) {
        x = parent[x];
    }
    return x;
}
```

若树很高，反复查询会变慢。

## 5.8.3 路径压缩

路径压缩在一次查找完成后，让路径上的结点尽量直接指向根。

原来：

```text
x → a → b → root
```

压缩后：

```text
x ─────→ root
a ─────→ root
b ─────→ root
```

递归实现：

```c
int findRoot(int x) {
    if (parent[x] != x) {
        parent[x] = findRoot(parent[x]);
    }
    return parent[x];
}
```

关键语句：

```c
parent[x] = findRoot(parent[x]);
```

既完成查找，也完成路径压缩。

## 5.8.4 Union 操作

合并时先找两个根：

```c
int rx = findRoot(x);
int ry = findRoot(y);
```

若：

```text
rx == ry
```

说明原本已经属于同一集合，不需要合并。

否则把一个根挂到另一个根下面。

## 5.8.5 按秩合并与按大小合并

为了避免不断形成长链，可让较小/较矮的树挂到较大/较高的树下。

### 按秩合并

```c
int rankv[MAXN];

void unionSet(int x, int y) {
    int rx = findRoot(x);
    int ry = findRoot(y);

    if (rx == ry) return;

    if (rankv[rx] < rankv[ry]) {
        parent[rx] = ry;
    } else if (rankv[rx] > rankv[ry]) {
        parent[ry] = rx;
    } else {
        parent[ry] = rx;
        rankv[rx]++;
    }
}
```

若两棵树秩相同，合并后新根的秩加 1。

> **易错点｜`rank` 不一定等于当前真实高度**
>
> 一旦使用路径压缩，树会被压扁，而 `rank` 通常不随之回退，所以它更像指导合并的上界/启发式指标。

### 按大小合并

也可以维护每个根所代表集合的元素个数，把较小集合挂到较大集合根下。效果与按秩合并类似。

## 5.8.6 并查集复杂度

同时使用：

- 路径压缩；
- 按秩合并或按大小合并；

单次操作的均摊复杂度可达到：

$$
O(\alpha(n))
$$

其中 $\alpha(n)$ 是反阿克曼函数，增长极慢，在实际规模中几乎可视为常数。

## 5.8.7 并查集常见应用

- 判断两个元素是否属于同一连通分量；
- 动态合并集合；
- Kruskal 最小生成树中判断加边是否成环；
- 等价类划分；
- 离线连通性问题。

## 5.8.8 本章易错点总表

| 易错点 | 正确理解 |
| --- | --- |
| 树中结点的度 | 通常只指孩子数 |
| 含 $n$ 个结点的树边数 | $n-1$ |
| 路径长度 | 边数 |
| 根深度 | 408 常用定义为 1 |
| 叶高度 | 408 常用定义为 1 |
| WPL 中路径长度 | 根到叶经过的边数 |
| 普通树是否有天然中序 | 没有 |
| 树的后根遍历 | 对应孩子兄弟二叉树中序 |
| 森林先序 | 对应二叉树先序 |
| 森林中序 | 对应二叉树中序 |
| 满二叉树 | 每层都达到最大结点数 |
| “所有内部结点度为 2” | 不必然是满二叉树 |
| 完全二叉树最后一层 | 必须从左向右连续 |
| 二叉链表空孩子指针数 | $n+1$ |
| BST 中序遍历 | 递增有序 |
| BST 查找复杂度 | $O(h)$，最坏 $O(n)$ |
| AVL 最小不平衡根 | 插入点向上第一个失衡祖先 |
| LL / RR | 右旋 / 左旋 |
| LR / RL | 先左后右 / 先右后左 |
| 红黑树 | 近似平衡 BST，不等同 AVL |
| 前缀编码 | 任一码字不是其他码字前缀 |
| 哈夫曼树 | WPL 最小，树形可不唯一 |
| 哈夫曼内部结点 | 都有两个孩子 |
| 哈夫曼左右 0/1 | 可互换，不影响码长与 WPL |
| 并查集 `rank` | 路径压缩后未必是真实高度 |

## 5.8.9 高频公式速查

根位于第 1 层。

### 一般树

含 $n$ 个结点：

$$
E=n-1
$$

若 $n_i$ 为度为 $i$ 的结点数：

$$
\sum_i i n_i=n-1
$$

$m$ 叉树第 $i$ 层最大结点数：

$$
m^{i-1}
$$

高度为 $h$ 的 $m$ 叉树最大结点数：

$$
\frac{m^h-1}{m-1}
$$

### 二叉树

第 $i$ 层最大结点数：

$$
2^{i-1}
$$

高度为 $h$ 时最大结点数：

$$
2^h-1
$$

叶结点数与度为 2 结点数：

$$
n_0=n_2+1
$$

完全二叉树：

$$
2^{h-1}\le n\le 2^h-1
$$

$$
h=\lfloor\log_2 n\rfloor+1
$$

二叉链表空孩子指针数：

$$
n+1
$$

### 搜索树

BST、AVL、红黑树查找统一理解：

$$
T=O(h)
$$

普通 BST 最坏：

$$
h=O(n)
$$

AVL、红黑树：

$$
h=O(\log n)
$$

AVL 平衡条件：

$$
|BF|\le1
$$

### 编码与哈夫曼树

定长编码最短位数：

$$
l=\lceil\log_2 n\rceil
$$

带权路径长度：

$$
WPL=\sum_i w_i l_i
$$

平均编码长度：

$$
L=\sum_i p_i l_i
$$

含 $n$ 个叶结点的二叉哈夫曼树：

$$
\text{内部结点数}=n-1
$$

$$
\text{总结点数}=2n-1
$$

### 并查集

路径压缩 + 按秩/大小合并的均摊复杂度：

$$
O(\alpha(n))
$$
