## 十三、二叉排序树 BST

> **真题考察**
>
> * 选择题：2011 年第 7 题、2013 年第 6 题、2017 年第 8 题、2018 年第 6 题、2020 年第 5 题、2024 年第 7 题
> * 解答题：2022 年第 41 题、2026 年第 41 题

**二叉排序树（Binary Search Tree，BST）**又称二叉查找树。

对于任意结点：

1. 左子树中所有关键字均小于该结点；
2. 右子树中所有关键字均大于该结点；
3. 左右子树本身也分别是 BST。

<InlineSvg src="/images/data-structure/data-structure-tree-btree-012.svg" alt={"8 3 10 1 6 4 7 14 13"} />

因此 BST 的一个核心性质是：

> **对 BST 进行中序遍历，可以得到递增有序序列。**

### 1. 结点结构

```c
typedef struct TreeNode {
    int data;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;

TreeNode* newNode(int data) {
    TreeNode* node =
        (TreeNode*)malloc(sizeof(TreeNode));

    node->data = data;
    node->left = NULL;
    node->right = NULL;

    return node;
}
```

### 2. 查找

```c
TreeNode* search(TreeNode* root, int data) {
    if (root == NULL || root->data == data) {
        return root;
    }

    if (data < root->data) {
        return search(root->left, data);
    }

    return search(root->right, data);
}
```

每次查找只进入左、右子树中的一个，因此时间复杂度取决于树高：

$$
T=O(h)
$$

若树较平衡：

$$
h=O(\log n)
$$

若 BST 极度退化成链表：

$$
h=O(n)
$$

所以最坏查找复杂度为：

$$
O(n)
$$

### 3. 插入

BST 插入首先执行一次查找，找到应该出现的位置，再把新结点作为叶结点插入。

```c
TreeNode* insert(TreeNode* root, int data) {
    if (root == NULL) {
        return newNode(data);
    }

    if (data < root->data) {
        root->left = insert(root->left, data);
    } else if (data > root->data) {
        root->right = insert(root->right, data);
    }

    return root;
}
```

插入顺序会显著影响最终 BST 的形态。

例如：

```text
1, 2, 3, 4, 5
```

按此顺序插入会得到近似单链表的结构，从而失去 BST 理想情况下的高效查找性能。

### 4. 删除

<InlineSvg src="/images/data-structure/data-structure-tree-btree-013.svg" alt={"BST 删除节点的三种情况 情况 1：叶子节点 直接删除，无需后续处理 删除前 8 3 12 1 5 删 1 删除后 8 3 12 5 情况 2：只有一个子节点 用唯一子树替代被删节点 删除前 8 3 12 5 删 3 删除后 8 5 12 把唯一子节点 5 提到原位置 情况 3：两个子节点 用 中序后继（右子树最小） 或 中序前驱（左子树最大） 顶替，再递归删除该后继/前驱 删除前（删 8） 8 3 12 1 6 10 14 中序后继 = 10 ① 值替换 ② 删原 10 "} />

BST 删除分三种情况。

#### 情况一：叶结点

直接删除即可。

#### 情况二：只有一个孩子

让唯一的孩子直接接替被删除结点的位置。

#### 情况三：存在两个孩子

可以用：

* **中序前驱**：左子树中的最大结点；
* **中序后继**：右子树中的最小结点；

替换待删除结点，再删除原来的前驱或后继。

```c
TreeNode* deleteNode(TreeNode* root, int data) {
    if (root == NULL) {
        return root;
    }

    if (data < root->data) {
        root->left =
            deleteNode(root->left, data);
    } else if (data > root->data) {
        root->right =
            deleteNode(root->right, data);
    } else {
        if (root->left == NULL) {
            TreeNode* temp = root->right;
            free(root);
            return temp;
        } else if (root->right == NULL) {
            TreeNode* temp = root->left;
            free(root);
            return temp;
        }

        TreeNode* temp =
            findMin(root->right);

        root->data = temp->data;

        root->right =
            deleteNode(
                root->right,
                temp->data
            );
    }

    return root;
}
```

> **做题技巧**
>
> 删除具有两个孩子的结点时，不要试图直接“大范围重连”。先找前驱或后继进行值替换，问题就会转换成删除一个至多只有一个孩子的结点。

## 十四、AVL 平衡二叉树

> **真题考察**
>
> * 选择题：2009 年第 4 题、2010 年第 4 题、2012 年第 4 题、2013 年第 3 题、2015 年第 4 题、2019 年第 4 题、2021 年第 6 题、2026 年第 8 题

**AVL 树**是一棵特殊的 BST。

对于任意结点，定义平衡因子：

$$
BF=
h_{\text{left}}
-
h_{\text{right}}
$$

AVL 要求：

$$
|BF|\le1
$$

因此一个结点的平衡因子只能为：

```text
-1、0、+1
```

AVL 通过限制左右子树高度差，使树高始终保持：

$$
O(\log n)
$$

因此查找、插入、删除的复杂度都可以维持在：

$$
O(\log n)
$$

<InlineSvg src="/images/data-structure/data-structure-tree-btree-014.svg" alt={"图示"} />

### 1. 最小不平衡子树

插入新结点后，从新结点沿祖先方向向上检查。

遇到的**第一个平衡因子绝对值大于 1 的结点**，就是最小不平衡子树的根。

旋转只需要围绕这棵最小不平衡子树进行。

---

### 2. 四种旋转类型

判断方法：

> 看新结点相对于最小不平衡子树根结点所在的方向。

#### LL 型

新结点位于：

```text
A 的左孩子的左子树
```

执行：

```text
A 右旋
```

#### RR 型

新结点位于：

```text
A 的右孩子的右子树
```

执行：

```text
A 左旋
```

#### LR 型

新结点位于：

```text
A 的左孩子的右子树
```

执行：

```text
先对 A 的左孩子左旋
再对 A 右旋
```

#### RL 型

新结点位于：

```text
A 的右孩子的左子树
```

执行：

```text
先对 A 的右孩子右旋
再对 A 左旋
```

汇总如下：

| 失衡类型 | 调整      |
| ---- | ------- |
| LL   | 右旋      |
| RR   | 左旋      |
| LR   | 先左旋，再右旋 |
| RL   | 先右旋，再左旋 |

<InlineSvg src="/images/data-structure/data-structure-tree-btree-015.svg" alt={"A B (+1) (0) B L B R A R h A B (+2) (+1) B L B R A R h h+1 X X Insert X into B L LL Rotation B A B R A R B L h+1 X h h h (0) (0) A B (-1) (0) B L B R A L h h Insert X into B R A B (-2) (-1) B L B R A L h X h h+1 RR Rotation B A A L B L h (0"} />

> **记忆**
>
> LL、RR 是“同向”，只旋一次。
>
> LR、RL 是“折线”，先把折线拉直，再做一次单旋。

### 3. AVL 结点定义

```c
struct TreeNode {
    int data;
    struct TreeNode* left;
    struct TreeNode* right;
    int height;
};
```

### 4. 左旋

```c
struct TreeNode* leftRotate(
    struct TreeNode* x
) {
    struct TreeNode* y = x->right;
    struct TreeNode* T2 = y->left;

    y->left = x;
    x->right = T2;

    updateHeight(x);
    updateHeight(y);

    return y;
}
```

### 5. 右旋

```c
struct TreeNode* rightRotate(
    struct TreeNode* y
) {
    struct TreeNode* x = y->left;
    struct TreeNode* T2 = x->right;

    x->right = y;
    y->left = T2;

    updateHeight(y);
    updateHeight(x);

    return x;
}
```

### 6. 高度与平衡因子

```c
int getHeight(struct TreeNode* node) {
    if (node == NULL) {
        return 0;
    }

    return node->height;
}

int getBalanceFactor(
    struct TreeNode* node
) {
    if (node == NULL) {
        return 0;
    }

    return
        getHeight(node->left)
        - getHeight(node->right);
}
```

更新高度：

```c
void updateHeight(
    struct TreeNode* node
) {
    int leftHeight =
        getHeight(node->left);

    int rightHeight =
        getHeight(node->right);

    node->height =
        (
            leftHeight > rightHeight
                ? leftHeight
                : rightHeight
        ) + 1;
}
```

### 7. AVL 插入完整框架

```c
struct TreeNode* insert(
    struct TreeNode* node,
    int data
) {
    // 1. 普通 BST 插入
    if (node == NULL) {
        return createNode(data);
    }

    if (data < node->data) {
        node->left =
            insert(node->left, data);
    } else if (data > node->data) {
        node->right =
            insert(node->right, data);
    } else {
        return node;
    }

    // 2. 更新高度
    updateHeight(node);

    // 3. 计算平衡因子
    int balanceFactor =
        getBalanceFactor(node);

    // 4. LL
    if (
        balanceFactor > 1
        && data < node->left->data
    ) {
        return rightRotate(node);
    }

    // 5. RR
    if (
        balanceFactor < -1
        && data > node->right->data
    ) {
        return leftRotate(node);
    }

    // 6. LR
    if (
        balanceFactor > 1
        && data > node->left->data
    ) {
        node->left =
            leftRotate(node->left);

        return rightRotate(node);
    }

    // 7. RL
    if (
        balanceFactor < -1
        && data < node->right->data
    ) {
        node->right =
            rightRotate(node->right);

        return leftRotate(node);
    }

    return node;
}
```

> **408 复习重点**
>
> 不需要死记完整 AVL 代码。应重点掌握：
>
> * 如何计算 BF；
> * 如何找到最小不平衡子树；
> * 如何判断 LL、RR、LR、RL；
> * 旋转后如何保持 BST 的中序有序性质。

## 十五、红黑树

**红黑树（Red-Black Tree）**也是一种自平衡二叉搜索树。

它不像 AVL 那样严格要求：

$$
|BF|\le1
$$

而是使用结点颜色和黑高约束维持**近似平衡**。

<InlineSvg src="/images/data-structure/data-structure-tree-btree-016.svg" alt={"红黑树及黑色 NIL 哨兵"} />

典型红黑树满足：

1. 每个结点要么为红色，要么为黑色；
2. 根结点为黑色；
3. 所有空孩子使用黑色 NIL 哨兵表示；
4. 红色结点的孩子不能是红色，即不存在两个连续红结点；
5. 从任一结点到其所有后代 NIL 的简单路径都包含相同数量的黑结点。

第 5 条中的黑色结点数量称为**黑高**。

利用这些性质可以证明红黑树高度保持在：

$$
O(\log n)
$$

更具体地，具有 $n$ 个内部结点的红黑树高度满足数量级上界：

$$
h\le2\log_2(n+1)
$$

因此搜索、插入和删除均可保持对数级复杂度。

### AVL 与红黑树比较

| 特性   | AVL                | 红黑树               |       |             |
| ---- | ------------------ | ----------------- | ----- | ----------- |
| 本质   | BST                | BST               |       |             |
| 平衡要求 | 严格                 | 相对宽松              |       |             |
| 平衡条件 | 任意结点 (             | BF                | \le1) | 颜色、红结点限制、黑高 |
| 树高   | $O(\log n)$，通常较矮 | $O(\log n)$     |       |             |
| 查找   | 通常路径较短             | 同样为 $O(\log n)$ |       |             |
| 更新   | 平衡约束严格             | 常通过旋转与重新着色维护      |       |             |
| 典型特点 | 查找性能优秀             | 插入、删除时维护成本通常更灵活   |       |             |

> **易混淆点**
>
> AVL 和红黑树都首先是 **BST**。
>
> 因此它们都满足：
>
> **中序遍历得到有序序列。**
