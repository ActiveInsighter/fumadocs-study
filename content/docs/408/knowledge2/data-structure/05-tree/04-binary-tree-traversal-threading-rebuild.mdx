## 5.4.1 三种深度优先遍历

三种 DFS 的区别只是**访问根结点的时机**。

| 遍历 | 顺序 | 记忆 |
| --- | --- | --- |
| 先序 | 根—左—右 | NLR |
| 中序 | 左—根—右 | LNR |
| 后序 | 左—右—根 | LRN |

### 先序遍历

```c
void preorder(TreeNode *root) {
    if (root == NULL) return;

    visit(root);
    preorder(root->left);
    preorder(root->right);
}
```

### 中序遍历

```c
void inorder(TreeNode *root) {
    if (root == NULL) return;

    inorder(root->left);
    visit(root);
    inorder(root->right);
}
```

### 后序遍历

```c
void postorder(TreeNode *root) {
    if (root == NULL) return;

    postorder(root->left);
    postorder(root->right);
    visit(root);
}
```

## 5.4.2 用“递归三次经过”理解 DFS

对一个结点而言，递归过程会经历三个关键时刻：

1. 第一次到达该结点；
2. 左子树处理完返回；
3. 右子树处理完返回。

因此：

- 第一次到达就访问：先序；
- 左子树返回后访问：中序；
- 右子树返回后访问：后序。

这也是设计树上递归算法最重要的思维方式。

## 5.4.3 层序遍历 BFS

层序遍历按“从上到下、同层从左到右”访问，使用队列。

```c
void levelOrder(TreeNode *root) {
    if (root == NULL) return;

    Queue q;
    initQueue(&q);
    enqueue(&q, root);

    while (!isEmpty(&q)) {
        TreeNode *p = dequeue(&q);
        visit(p);

        if (p->left != NULL) enqueue(&q, p->left);
        if (p->right != NULL) enqueue(&q, p->right);
    }
}
```

所有遍历都需要访问每个结点一次，因此时间复杂度均为：

$$
O(n)
$$

递归 DFS 的额外空间与树高有关，最坏为：

$$
O(h)
$$

## 5.4.4 遍历序列常见用途

### 先序：适合自顶向下

因为访问根早于子树，常用于：

- 复制树；
- 输出目录结构；
- 根先于后代的处理。

### 中序：BST 中得到有序序列

对二叉排序树做中序遍历，关键字按递增顺序输出。

### 后序：适合自底向上

因为子树先于根完成，常用于：

- 计算树高；
- 统计子树信息；
- 删除整棵树；
- 表达式树求值。

## 5.4.5 线索二叉树的动机

含 $n$ 个结点的二叉链表有：

$$
n+1
$$

个空孩子指针。

线索二叉树利用这些空指针保存某种遍历序列下的**前驱**或**后继**，从而在部分情况下不借助递归栈就能遍历。

典型结点：

```c
typedef struct ThreadNode {
    ElementType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode;
```

通常约定：

| 标志 | 含义 |
| --- | --- |
| `ltag = 0` | `lchild` 指向真实左孩子 |
| `ltag = 1` | `lchild` 指向遍历前驱 |
| `rtag = 0` | `rchild` 指向真实右孩子 |
| `rtag = 1` | `rchild` 指向遍历后继 |

> **关键原则**
>
> 只有原本为空的孩子指针才能改作线索，真实孩子指针不能被覆盖。

## 5.4.6 中序线索树的后继

中序顺序是：

```text
左子树 → 根 → 右子树
```

对结点 `p`：

- 若 `p->rtag == 1`，`p->rchild` 直接指向中序后继；
- 若 `p->rtag == 0`，存在真实右子树，后继是右子树中最左下结点。

```c
ThreadNode *firstNode(ThreadNode *p) {
    while (p != NULL && p->ltag == 0) {
        p = p->lchild;
    }
    return p;
}

ThreadNode *nextNode(ThreadNode *p) {
    if (p->rtag == 1) {
        return p->rchild;
    }
    return firstNode(p->rchild);
}
```

利用线索中序遍历：

```c
void inorderThread(ThreadNode *root) {
    for (ThreadNode *p = firstNode(root);
         p != NULL;
         p = nextNode(p)) {
        visit(p);
    }
}
```

## 5.4.7 前序、后序线索的理解

线索可以按先序、中序、后序分别建立。

考试中最常见的是中序线索树，因为其中序前驱/后继关系最容易利用左右子树定位。

后序线索树若想从某结点直接找后继，往往还需要知道双亲，因此不如中序情形直接。

## 5.4.8 单个普通遍历序列通常不能唯一确定树

只给：

- 一个普通前序；
- 一个普通中序；
- 一个普通后序；

通常都不能唯一还原二叉树。

但若在前序序列中显式记录空子树，例如 `#`，就可以唯一重建：

```text
A B # # C # #
```

原因是空指针位置也被编码进序列，结构信息完整。

## 5.4.9 两种遍历序列重建

当结点关键字互异时：

| 已知序列 | 是否通常能唯一确定 |
| --- | --- |
| 前序 + 中序 | 是 |
| 后序 + 中序 | 是 |
| 前序 + 后序 | 否 |

### 前序 + 中序

- 前序第一个结点确定根；
- 在中序中找到根；
- 根左边全部属于左子树；
- 根右边全部属于右子树；
- 对左右两部分递归。

### 后序 + 中序

- 后序最后一个结点确定根；
- 中序负责划分左右子树；
- 对左右两部分递归。

### 为什么前序 + 后序通常不够

如果一个结点只有一个孩子，则无法仅由前序和后序判断该孩子是左孩子还是右孩子。

> **补充条件**
>
> 若额外规定每个非叶结点都有两个孩子，或序列中包含空指针标记，就可能消除歧义。

## 5.4.10 重建题稳定步骤

1. 先在“能定位根”的序列中找根：前序看首元素，后序看尾元素；
2. 去中序中找根的位置；
3. 按中序划分左右子树规模；
4. 回到另一序列中截取对应数量的元素；
5. 递归处理。

不要凭图形感觉直接猜左右子树。
