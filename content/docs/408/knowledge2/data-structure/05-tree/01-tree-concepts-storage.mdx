树把线性结构中的“一对一”关系扩展为“一对多”的层次关系。复习这一章时，先建立统一的计数口径，再进入二叉树、搜索树和哈夫曼树，否则非常容易在“层数、深度、路径长度”之间混淆。

> **真题标签｜2010 第 5 题、2011 第 6 题、2013 第 4 题、2021 第 9 题、2022 第 4 题；2016 第 42 题：树的基本概念与数量关系**
>
> 高频考法包括结点度数关系、树高下界、路径长度以及由结点数反推层数。

## 5.1.1 树的定义

一棵非空树满足：

1. 有且仅有一个根结点；
2. 除根以外，其余结点可划分为若干互不相交的集合；
3. 每个集合本身又是一棵树，称为根的子树。

把树看成有根图时，它具有两个本质特征：

- **连通**：任意两个结点之间存在路径；
- **无环**：不存在回路。

因此，含 $n$ 个结点的树一定有：

$$
 n-1
$$

条边。

若把边统一看作“双亲指向孩子”，则：

- 根的入度为 0；
- 其余每个结点入度均为 1；
- 从根到任意结点的路径唯一。

## 5.1.2 结点之间的关系

| 概念 | 含义 |
| --- | --- |
| 根结点 | 唯一没有双亲的结点 |
| 双亲 | 某结点的直接上层结点 |
| 孩子 | 某结点直接连接的下一层结点 |
| 兄弟 | 具有同一双亲的结点 |
| 祖先 | 从根到该结点路径上除自身外的所有结点 |
| 子孙 | 以该结点为根的子树中除自身外的结点 |

## 5.1.3 结点的度、树的度与叶结点

**结点的度**：该结点拥有的孩子数。

**树的度**：整棵树中结点度的最大值。

因此：

- 度为 0 的结点称为叶结点；
- 度大于 0 的结点称为分支结点。

若 $n_i$ 表示度为 $i$ 的结点数，则：

$$
 n=\sum_i n_i
$$

所有结点向下发出的边数之和等于树的边数：

$$
 \sum_i i n_i=n-1
$$

由这两式可以处理大量“给定各度结点个数求未知量”的选择题。

> **易错点｜树中结点的度 ≠ 无向图中的顶点度**
>
> 在树的术语中，“度”只计算孩子数；若把树看作无向图，非根结点还要额外计算连接双亲的一条边。

## 5.1.4 深度、高度与层次

本资料统一采用 408 常用计数方式：

- 根结点位于第 1 层，深度为 1；
- 叶结点高度为 1；
- 结点深度：从根到该结点经过的结点数；
- 结点高度：从该结点到其最远叶结点经过的结点数；
- 树的高度等于根的高度，也等于整棵树的最大深度。

对整棵树有：

$$
\text{树高}=\text{最大结点深度}
$$

但对某个具体结点而言，“高度”和“深度”通常不同。

> **计数约定**
>
> 有些教材把根深度定义为 0、叶高度定义为 0。两种定义相差 1。做题时优先服从题干；若题干未说明，408 通常按“根深度为 1、叶高度为 1”理解。

## 5.1.5 路径与路径长度

树中任意两个结点之间有且仅有一条简单路径。

- **路径**：从一个结点到另一个结点依次经过的结点序列；
- **路径长度**：路径中经过的边数。

因此：

$$
\text{路径长度}=\text{路径上的结点数}-1
$$

例如路径：

```text
A → B → D
```

经过 3 个结点，但长度为 2。

## 5.1.6 权与带权路径长度 WPL

在带权树中，若叶结点 $i$ 的权值为 $w_i$，根到该叶结点的路径长度为 $l_i$，则叶结点的带权路径长度为：

$$
 w_i l_i
$$

整棵树的带权路径长度为：

$$
 WPL=\sum_i w_i l_i
$$

这里的 $l_i$ 是**边数**。若根深度从 1 开始，则：

$$
 l_i=\text{depth}_i-1
$$

WPL 是理解哈夫曼树的基础：哈夫曼树的目标就是让所有叶结点的加权路径长度之和最小。

## 5.1.7 $m$ 叉树的最大结点数

若一棵树每个结点至多有 $m$ 个孩子，根位于第 1 层，则第 $i$ 层至多有：

$$
 m^{i-1}
$$

个结点。

高度为 $h$ 时，总结点数至多为：

$$
1+m+m^2+\cdots+m^{h-1}
=\frac{m^h-1}{m-1}
$$

因此，给定总结点数 $n$，求“高度至少是多少”时，应寻找最小的 $h$ 使：

$$
 n\le \frac{m^h-1}{m-1}
$$

## 5.1.8 树的三种典型存储结构

普通树中孩子个数不固定，因此常用以下三种表示法。

### 双亲表示法

数组保存结点，每个结点额外记录双亲下标：

```c
#define MAXSIZE 100

typedef struct {
    int data;
    int parent;
} PTNode;

typedef struct {
    PTNode nodes[MAXSIZE];
    int n;
} PTree;
```

特点：

- 找双亲非常快；
- 找某结点的全部孩子需要扫描数组。

### 孩子表示法

数组保存每个结点，每个结点再维护一条孩子链表：

```c
typedef struct ChildNode {
    int child;
    struct ChildNode *next;
} ChildNode;

typedef struct {
    int data;
    ChildNode *firstchild;
} CTBox;
```

特点：

- 找孩子方便；
- 若不额外记录双亲，向上寻找双亲较慢。

### 孩子兄弟表示法

每个结点只保留两个指针：

- `firstchild`：第一个孩子；
- `rightsib`：右边下一个兄弟。

```c
typedef struct CSNode {
    int data;
    struct CSNode *firstchild;
    struct CSNode *rightsib;
} CSNode, *CSTree;
```

这实际上用**二叉链表**表示任意树，是后续“树/森林与二叉树转换”的结构基础。

## 5.1.9 本节速查

| 问题 | 结论 |
| --- | --- |
| 含 $n$ 个结点的树有多少条边 | $n-1$ |
| 所有结点度数之和 | $n-1$ |
| 路径长度 | 边数，不是结点数 |
| 根深度 | 通常记为 1 |
| 叶高度 | 通常记为 1 |
| WPL 中的 $l_i$ | 根到叶的边数 |
| 找双亲最方便 | 双亲表示法 |
| 找孩子最方便 | 孩子表示法 |
| 可自然转为二叉树 | 孩子兄弟表示法 |
