## 六、二叉树

**二叉树（Binary Tree）**是每个结点最多具有两个子树，并且这两个子树明确区分为**左子树**与**右子树**的树形结构。

二叉树与度不超过 2 的普通树并不完全相同，因为二叉树的左右次序不能交换。

---

## 七、二叉树的基本性质

这些性质是选择题和计算题的基础。

### 1. 第 $i$ 层的最大结点数

规定根结点位于第 1 层，则二叉树第 $i$ 层至多有：

$$
2^{i-1}
$$

个结点。

### 2. 高度为 $h$ 的二叉树最多有多少结点

各层全部达到最大结点数时：

$$
n_{\max}
=
1+2+2^2+\cdots+2^{h-1}
=
2^h-1
$$

### 3. 叶结点与度为 2 的结点数量关系

设：

* $n_0$：度为 0 的结点数；
* $n_1$：度为 1 的结点数；
* $n_2$：度为 2 的结点数。

则二叉树中恒有：

$$
n_0=n_2+1
$$

推导：

总结点数：

$$
n=n_0+n_1+n_2
$$

一棵具有 $n$ 个结点的树有 $n-1$ 条边，而每个度为 1 的结点贡献 1 条向下的边，每个度为 2 的结点贡献 2 条，因此：

$$
n-1=n_1+2n_2
$$

两式相减得到：

$$
n_0=n_2+1
$$

> **高频结论**
>
> 二叉树中，**叶结点总比度为 2 的结点多 1 个**。

## 八、二叉树的存储结构

> **真题考察**
>
> * 选择题：2020 年第 3 题、2023 年第 1 题、2025 年第 3 题、2026 年第 1 题
> * 解答题：2010 年第 42 题、2013 年第 41 题、2018 年第 41 题、2020 年第 41 题、2025 年第 41 题

二叉树主要有**链式存储**和**顺序存储**两种方式。

### 1. 二叉链表

每个结点保存：

* 数据域；
* 左孩子指针；
* 右孩子指针。

```c
typedef struct TreeNode {
    ElementType data;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;
```

适用于：

* 任意形态的二叉树；
* 动态插入与删除；
* 递归遍历。

若含 $n$ 个结点，则二叉链表中共有 $2n$ 个孩子指针域。

树中实际存在：

$$
n-1
$$

条父子边，因此非空孩子指针有 $n-1$ 个。

所以空孩子指针数量为：

$$
2n-(n-1)=n+1
$$

这一结论也是线索二叉树的基础。

### 2. 顺序存储

<InlineSvg src="/images/data-structure/data-structure-tree-btree-001.svg" alt="14 4 34 18 8 22 7 53 实际二叉树结构 顺序存储结构 下标 元素 0 1 2 3 4 5 6 7 14 4 8 34 18 22 7 -1 8 9 10 11 -1 -1 -1 53" />

顺序存储使用数组保存二叉树结点，并利用下标关系隐式表示父子关系。

#### 1 基下标

若当前结点编号为 $i$：

$$
\text{left}(i)=2i
$$

$$
\text{right}(i)=2i+1
$$

$$
\text{parent}(i)=\left\lfloor\frac{i}{2}\right\rfloor
$$

#### 0 基下标

若当前结点编号为 $i$：

$$
\text{left}(i)=2i+1
$$

$$
\text{right}(i)=2i+2
$$

当 $i>0$ 时：

$$
\text{parent}(i)=
\left\lfloor\frac{i-1}{2}\right\rfloor
$$

简单示例：

```c
#define MAX_SIZE 100

int tree[MAX_SIZE];

int lchild(int i) {
    return tree[2 * i + 1];
}

int rchild(int i) {
    return tree[2 * i + 2];
}
```

顺序存储特别适合**完全二叉树**。

典型应用是二叉堆，因为：

* 几乎不存在数组空间浪费；
* 不需要保存左右孩子指针；
* 可以通过下标直接找到父结点和孩子结点；
* 交换父子结点十分方便。

## 九、特殊二叉树

<InlineSvg src="/images/data-structure/data-structure-tree-btree-002.svg" alt="满二叉树与完全二叉树" />

### 1. 满二叉树

> **真题考察**
>
> * 选择题：2018 年第 4 题

在 408 的常用定义中，**满二叉树**指每一层的结点数均达到最大值。

若根位于第 1 层，树高为 $h$，则第 $i$ 层有：

$$
2^{i-1}
$$

个结点。

总结点数：

$$
n=2^h-1
$$

因此：

$$
h=\log_2(n+1)
$$

> **易错点**
>
> “所有非叶结点都有两个孩子”只能说明它是一棵严格二叉树或正则二叉树，并不能保证每一层都达到最大结点数，因此不一定是 408 语境中的满二叉树。

### 2. 完全二叉树

> **真题考察**
>
> * 选择题：2009 年第 5 题、2011 年第 4 题

完全二叉树满足：

* 除最后一层之外，其余各层全部满；
* 最后一层结点从左到右连续排列。

若高度为 $h$，则：

$$
2^{h-1}\le n\le 2^h-1
$$

所以：

$$
h=
\left\lfloor\log_2 n\right\rfloor+1
$$

也可写为：

$$
h=
\left\lceil\log_2(n+1)\right\rceil
$$

完全二叉树还有一组非常实用的 1 基编号结论。

若总结点数为 $n$，结点编号为 $i$：

* 当 $i>1$ 时，其双亲编号为 $\lfloor i/2\rfloor$；
* 若 $2i\le n$，则左孩子编号为 $2i$；
* 若 $2i+1\le n$，则右孩子编号为 $2i+1$；
* 若 $i>\lfloor n/2\rfloor$，则该结点一定为叶结点。

因此最后一个非叶结点的编号为：

$$
\left\lfloor\frac n2\right\rfloor
$$

## 十、二叉树的遍历

> **真题考察**
>
> * 选择题：2009 年第 3 题、2011 年第 5 题、2012 年第 3 题、2017 年第 4 题、2017 年第 5 题、2020 年第 4 题、2022 年第 3 题、2023 年第 5 题、2024 年第 3 题、2026 年第 3 题
> * 解答题：2014 年第 41 题、2017 年第 41 题

### 1. 深度优先遍历 DFS

<InlineSvg src="/images/data-structure/data-structure-tree-btree-003.svg" alt="1 2 3 左子树 右子树 先序遍历 1 2 3 左子树 右子树 中序遍历 1 2 3 左子树 右子树 后序遍历" />

三种 DFS 的本质区别只是“什么时候访问根”。

| 遍历 | 次序    | 记忆  |
| -- | ----- | --- |
| 先序 | 根—左—右 | NLR |
| 中序 | 左—根—右 | LNR |
| 后序 | 左—右—根 | LRN |

#### 先序遍历

<InlineSvg src="/images/data-structure/data-structure-tree-btree-004.svg" alt="图示" />

```text
根 → 左子树 → 右子树
```

```c
void preorderTraversal(struct TreeNode* root) {
    if (root == NULL) {
        return;
    }

    // operation here

    preorderTraversal(root->left);
    preorderTraversal(root->right);
}
```

#### 中序遍历

<InlineSvg src="/images/data-structure/data-structure-tree-btree-005.svg" alt="图示" />

```text
左子树 → 根 → 右子树
```

```c
void inorderTraversal(struct TreeNode* root) {
    if (root == NULL) {
        return;
    }

    inorderTraversal(root->left);

    // operation here

    inorderTraversal(root->right);
}
```

#### 后序遍历

<InlineSvg src="/images/data-structure/data-structure-tree-btree-006.svg" alt="图示" />

```text
左子树 → 右子树 → 根
```

```c
void postorderTraversal(struct TreeNode* root) {
    if (root == NULL) {
        return;
    }

    postorderTraversal(root->left);
    postorderTraversal(root->right);

    // operation here
}
```

> **理解递归遍历**
>
> 对每个结点而言，三种遍历都会经过“第一次到达结点—左子树返回—右子树返回”三个时刻。
>
> * 第一次到达时访问：先序；
> * 左子树返回后访问：中序；
> * 右子树返回后访问：后序。

### 2. 层序遍历 BFS

<InlineSvg src="/images/data-structure/data-structure-tree-btree-007.svg" alt="图示" />

层序遍历从根开始，一层一层地从左到右访问结点。

实现时使用**队列**。

```c
void levelOrderTraversal(struct TreeNode* root) {
    if (root == NULL) {
        return;
    }

    struct Queue* queue = createQueue();
    enqueue(queue, root);

    while (queue->front != NULL) {
        struct TreeNode* current = dequeue(queue);

        // operation here

        if (current->left != NULL) {
            enqueue(queue, current->left);
        }

        if (current->right != NULL) {
            enqueue(queue, current->right);
        }
    }
}
```

遍历复杂度均为：

$$
O(n)
$$

因为每个结点都会被访问一次。

递归 DFS 的额外空间主要来自递归栈，最坏为：

$$
O(h)
$$

其中 $h$ 为树高。

## 十一、线索二叉树

> **真题考察**
>
> * 选择题：2010 年第 3 题、2013 年第 5 题、2014 年第 4 题

<InlineSvg src="/images/data-structure/data-structure-tree-btree-008.svg" alt="后继线索 A B C D E F G H I 前驱线索 中序线索二叉树" />

普通二叉链表中含 $n$ 个结点时存在：

$$
n+1
$$

个空孩子指针。

**线索二叉树（Threaded Binary Tree）**的思想就是：

> 利用原本为空的孩子指针，保存某种遍历顺序下的前驱或后继。

这样可以在部分遍历过程中避免使用递归和辅助栈。

### 1. 结点结构

```c
// ltag = 1：lchild 指向遍历前驱
// rtag = 1：rchild 指向遍历后继

typedef struct ThreadNode {
    ElementType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode;
```

通常约定：

| 标志         | 含义               |
| ---------- | ---------------- |
| `ltag = 0` | `lchild` 指向真实左孩子 |
| `ltag = 1` | `lchild` 是前驱线索   |
| `rtag = 0` | `rchild` 指向真实右孩子 |
| `rtag = 1` | `rchild` 是后继线索   |

<InlineSvg src="/images/data-structure/data-structure-tree-btree-009.svg" alt="线索二叉树节点：ltag / rtag 标识子指针还是线索 节点字段结构 ltag lchild data rchild rtag 0 = 左孩子 1 = 前驱线索 0 = 右孩子 1 = 后继线索 指针含义： child 指针（实线）：指向真实左/右孩子 thread 指针（虚线）：指向中序前驱/后继 利用空指针存线索 → 省去栈式遍历 中序线索化示例 中序序列：D B E A F C G A l:0 r:0 B l:0 r:0 C l:0 r:0 D l:1 r:1 E " />

### 2. 线索的类型

| 类型    | 线索指向         |
| ----- | ------------ |
| 前序线索树 | 前序遍历的前驱 / 后继 |
| 中序线索树 | 中序遍历的前驱 / 后继 |
| 后序线索树 | 后序遍历的前驱 / 后继 |

中序线索二叉树最典型。

寻找中序序列第一个结点：

```c
ThreadNode *FirstNode(ThreadNode *p) {
    while (p != NULL && p->ltag == 0) {
        p = p->lchild;
    }
    return p;
}
```

寻找中序后继：

```c
ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 1) {
        return p->rchild;
    }

    return FirstNode(p->rchild);
}
```

利用线索完成中序遍历：

```c
void InOrder(ThreadNode *root) {
    for (
        ThreadNode *p = FirstNode(root);
        p != NULL;
        p = NextNode(p)
    ) {
        visit(p);
    }
}
```

中序后继判断可归纳为：

* 若 `rtag = 1`，右指针直接就是后继；
* 若 `rtag = 0`，说明存在真实右子树，其后继为**右子树中最左下的结点**。

## 十二、由遍历序列构造二叉树

> **真题考察**
>
> * 选择题：2020 年第 4 题、2021 年第 4 题、2026 年第 3 题

### 1. 带空结点标记的单序列

普通的单个前序、中序或后序序列通常不能唯一确定一棵二叉树。

但如果显式记录空指针，例如使用 `#`，则带空结点标记的前序序列可以唯一表示一棵二叉树。

<InlineSvg src="/images/data-structure/data-structure-tree-btree-010.svg" alt="BinaryTreePreorder" />

构造规则：

* 遇到普通元素：创建结点；
* 遇到 `#`：对应子树为空；
* 按照前序“根—左—右”的顺序递归构建。

```c
TreeNode* createTree(char a[], int *i) {
    if (a[*i] == '#') {
        (*i)++;
        return NULL;
    }

    TreeNode *cur =
        (TreeNode*)malloc(sizeof(TreeNode));

    cur->val = a[*i];
    (*i)++;

    cur->left = createTree(a, i);
    cur->right = createTree(a, i);

    return cur;
}
```

### 2. 两种遍历序列重建

结点值互异时：

| 已知序列    | 是否通常能唯一确定 |
| ------- | --------- |
| 前序 + 中序 | 是         |
| 后序 + 中序 | 是         |
| 前序 + 后序 | 否         |

原因是：

* 前序的第一个结点能够确定根；
* 后序的最后一个结点能够确定根；
* **中序序列能够确定左右子树的分界线**。

因此中序遍历是重建结构的关键。

<InlineSvg src="/images/data-structure/data-structure-tree-btree-011.svg" alt="A B D C E 前序遍历： B D A C E 中序遍历： 根左右 左根右 可以确定是根节点 B、D 在 A 的左边 C、E 在 A 的右边 A B、D C、E" />

例如：

```text
前序：A B D C E
中序：B D A C E
```

首先由前序可知：

```text
A
```

是根。

中序中：

```text
B D | A | C E
```

因此：

```text
BD
```

属于左子树，

```text
CE
```

属于右子树。

继续分别递归分析，可得到：

```text
    A
   / \
  B   C
   \   \
    D   E
```

> **易错点**
>
> 单纯给出前序 + 后序一般不能唯一确定二叉树。
>
> 例如某结点只有一个孩子时，仅由前序和后序无法判断这个孩子究竟是左孩子还是右孩子。
>
> 若额外规定二叉树为严格二叉树，或者给出空结点标记，则可能消除这种歧义。
