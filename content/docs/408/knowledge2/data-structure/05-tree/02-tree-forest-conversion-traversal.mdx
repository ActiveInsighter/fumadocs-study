这一节的核心不是死记图形，而是抓住一句话：

> **左孩子 = 第一个孩子，右孩子 = 下一个兄弟。**

只要始终按这条规则，树、森林与二叉树之间的转换以及遍历对应关系都能自然推出。

> **真题标签｜2016 第 5 题、2019 第 2 题、2009 第 6 题、2014 第 5 题、2021 第 4 题、2025 第 4 题、2026 第 4 题：森林与二叉树转换**
>
> 常考转换后的根、左右孩子关系，以及遍历序列的对应关系。

## 5.2.1 森林

**森林**是若干棵互不相交树的集合。

- 一棵树只有一个根；
- 一个森林可以有多个根；
- 一棵树可看作只含一棵树的特殊森林。

若要讨论森林高度，可把它理解为森林中各棵树高度的最大值。

## 5.2.2 树转换为二叉树

转换规则：

1. 原树中某结点的**第一个孩子**变成二叉树中的左孩子；
2. 原树中其余孩子依次通过右指针连接为兄弟链；
3. 对所有结点重复同样操作。

因此：

```text
原树关系          对应二叉树关系
第一个孩子   ->   左孩子
下一个兄弟   ->   右孩子
```

这就是“左孩子、右兄弟”原则。

### 结构判断技巧

若原树结点 `A` 有孩子：

```text
B, C, D
```

则转换后二叉树中：

```text
A.left = B
B.right = C
C.right = D
```

而 `A` 不会直接拥有 `C`、`D` 作为二叉树孩子。

## 5.2.3 森林转换为二叉树

设森林依次包含：

```text
T1, T2, T3, ...
```

转换步骤：

1. 先分别把每棵树按“左孩子右兄弟”转换成二叉树；
2. `T1` 的根作为整棵二叉树的根；
3. `T2` 的根作为 `T1` 根的右孩子；
4. `T3` 的根作为 `T2` 根的右孩子；
5. 依次连接。

所以：

> **森林中各棵树的根，在对应二叉树中沿右孩子链连接。**

## 5.2.4 二叉树还原为树或森林

逆转换同样按指针语义进行：

- 左孩子解释为“第一个孩子”；
- 一串右孩子解释为“同一层兄弟”；
- 若根自身还存在右孩子链，则这些根结点分别对应森林中的其他树。

做图题时建议先把所有右链理解成“兄弟”，再恢复多叉结构。

## 5.2.5 树的先根遍历

规则：

1. 先访问根；
2. 从左到右依次先根遍历各子树。

即：

```text
根 → 第 1 棵子树 → 第 2 棵子树 → ...
```

典型递归框架：

```c
void preRoot(TreeNode *root) {
    if (root == NULL) return;

    visit(root);

    for (int i = 0; i < root->numChildren; ++i) {
        preRoot(root->children[i]);
    }
}
```

## 5.2.6 树的后根遍历

规则：

1. 从左到右依次后根遍历各子树；
2. 最后访问根。

即：

```text
第 1 棵子树 → 第 2 棵子树 → ... → 根
```

```c
void postRoot(TreeNode *root) {
    if (root == NULL) return;

    for (int i = 0; i < root->numChildren; ++i) {
        postRoot(root->children[i]);
    }

    visit(root);
}
```

> **易错点｜普通树没有天然的“中序遍历”**
>
> 二叉树可以明确划分为“左子树—根—右子树”，而普通树的孩子数不固定，因此不存在唯一自然的“中间位置”。

## 5.2.7 树与对应二叉树的遍历关系

树采用孩子兄弟表示法转为二叉树后：

| 原树遍历 | 对应二叉树遍历 |
| --- | --- |
| 先根遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 |

### 为什么后根对应中序

在孩子兄弟二叉树中：

- 左子树代表“这个结点的孩子们”；
- 根代表“这个结点本身”；
- 右子树代表“这个结点的兄弟及其后续兄弟”。

二叉树中序的“左—根—右”，正好对应：

```text
先访问全部孩子 → 再访问自己 → 再处理兄弟
```

这与树的后根遍历递归顺序一致。

## 5.2.8 森林的先序与中序遍历

教材对森林通常定义：

### 森林先序遍历

依次对森林中每棵树做先根遍历。

它与转换后二叉树的**先序遍历**完全一致。

### 森林中序遍历

递归理解为：

1. 中序遍历第一棵树根的子树森林；
2. 访问第一棵树的根；
3. 中序遍历其余树组成的森林。

它与转换后二叉树的**中序遍历**完全一致。

| 森林遍历 | 对应二叉树遍历 |
| --- | --- |
| 森林先序遍历 | 二叉树先序遍历 |
| 森林中序遍历 | 二叉树中序遍历 |

> **概念区分**
>
> “森林的中序遍历”是教材针对森林递归结构定义的专门概念，并不意味着普通多叉树本身存在类似二叉树的天然中序。

## 5.2.9 转换题快速检查表

做完转换后，可用以下规则自检：

- 原树的第一个孩子是否变成左孩子；
- 同一双亲的孩子是否通过右链连接；
- 森林中不同树的根是否通过右链连接；
- 原树先根序列是否等于二叉树先序序列；
- 原树后根序列是否等于二叉树中序序列。
