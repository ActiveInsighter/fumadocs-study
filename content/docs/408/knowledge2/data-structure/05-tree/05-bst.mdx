**二叉排序树（Binary Search Tree，BST）**&#x2060;又称二叉查找树。

对任意结点：

1. 左子树所有关键字小于该结点；
2. 右子树所有关键字大于该结点；
3. 左、右子树本身也分别是 BST。

本节默认关键字互异；若允许重复关键字，必须额外规定相等元素统一放在哪一侧。

> **真题标签｜2011 第 7 题、2013 第 6 题、2017 第 8 题、2018 第 6 题、2020 第 5 题、2024 第 7 题；2022 第 41 题、2026 第 41 题：BST 查找、构造与算法**

## 5.5.1 核心性质：中序遍历递增

BST 的最重要性质：

> **中序遍历得到按关键字递增的有序序列。**

因此，判断一棵树是否为 BST、求第 $k$ 小元素、输出有序序列等问题，都可以围绕中序遍历展开。

## 5.5.2 查找

从根开始比较目标 `key`：

- `key == root->data`：查找成功；
- `key < root->data`：只需进入左子树；
- `key > root->data`：只需进入右子树。

```c
TreeNode *searchBST(TreeNode *root, int key) {
    if (root == NULL || root->data == key) {
        return root;
    }

    if (key < root->data) {
        return searchBST(root->left, key);
    }

    return searchBST(root->right, key);
}
```

每次只进入一棵子树，因此复杂度取决于树高：

$$
T=O(h)
$$

若较平衡：

$$
h=O(\log n)
$$

若退化为链表：

$$
h=O(n)
$$

所以普通 BST 的最坏查找复杂度为：

$$
O(n)
$$

## 5.5.3 插入

BST 插入本质是“查找失败位置 + 作为叶结点插入”。

```c
TreeNode *insertBST(TreeNode *root, int key) {
    if (root == NULL) {
        TreeNode *p = malloc(sizeof(TreeNode));
        p->data = key;
        p->left = p->right = NULL;
        return p;
    }

    if (key < root->data) {
        root->left = insertBST(root->left, key);
    } else if (key > root->data) {
        root->right = insertBST(root->right, key);
    }

    return root;
}
```

插入顺序会决定 BST 的形态。例如依次插入：

```text
1, 2, 3, 4, 5
```

会形成向右倾斜的链状结构，查找优势几乎消失。

> **高频判断**
>
> 同一组关键字按不同顺序插入，可能得到完全不同的 BST；但它们的中序序列相同。

## 5.5.4 删除：三种情况

### 叶结点

直接删除，不影响其他子树。

### 只有一个孩子

让唯一孩子接替被删除结点的位置。

### 有两个孩子

用以下任一结点替换其关键字：

- 中序前驱：左子树中的最大结点；
- 中序后继：右子树中的最小结点。

随后再去原位置删除该前驱/后继。

因为前驱或后继不可能同时拥有两个孩子，所以问题会转化成前两种简单情况。

## 5.5.5 删除框架

```c
TreeNode *findMin(TreeNode *root) {
    while (root != NULL && root->left != NULL) {
        root = root->left;
    }
    return root;
}

TreeNode *deleteBST(TreeNode *root, int key) {
    if (root == NULL) return NULL;

    if (key < root->data) {
        root->left = deleteBST(root->left, key);
    } else if (key > root->data) {
        root->right = deleteBST(root->right, key);
    } else {
        if (root->left == NULL) {
            TreeNode *r = root->right;
            free(root);
            return r;
        }

        if (root->right == NULL) {
            TreeNode *l = root->left;
            free(root);
            return l;
        }

        TreeNode *s = findMin(root->right);
        root->data = s->data;
        root->right = deleteBST(root->right, s->data);
    }

    return root;
}
```

## 5.5.6 查找成功与失败的比较次数

BST 的平均查找长度与树形高度分布有关。

- 查找成功：比较次数等于从根到目标结点路径上的结点数；
- 查找失败：搜索最终落到某个空指针位置，比较次数由所经过的内部结点决定。

本质仍然是：

$$
\text{查找代价}\propto\text{结点深度}
$$

因此让树尽量矮，是 AVL、红黑树等平衡搜索树出现的直接原因。

## 5.5.7 BST 高频判断

| 说法 | 判断 |
| --- | --- |
| BST 中序遍历有序 | 对 |
| BST 先序遍历一定有序 | 错 |
| 普通 BST 查找一定是 $O(\log n)$ | 错 |
| BST 插入的新结点最初一定是叶结点 | 对 |
| 删除两个孩子的结点必须物理移动整棵子树 | 错 |
| BST 性能取决于树高 | 对 |
