希尔排序和归并排序都常出现在“给中间序列判断算法”的题目中，但它们的中间状态完全不同：

- 希尔排序强调 **按增量分组后局部有序**；
- 归并排序强调 **连续有序段的长度逐步扩大**。

## 8.2.1 希尔排序

> **真题标签｜2014 年第 10 题、2015 年第 11 题、2018 年第 10 题：希尔排序过程与性质**
>
> 重点不是背某个固定复杂度，而是理解增量分组、每趟后的序列特征和不稳定性。

希尔排序是对直接插入排序的改进。

直接插入排序在以下情况很快：

- 序列规模较小；
- 序列已经基本有序。

希尔排序的思路就是先用较大的增量，让元素能一次跨越较远距离，把序列快速调整到“基本有序”，最后再进行一次 `gap = 1` 的插入排序。

### 增量分组

设当前增量为 `gap`，则下标满足：

```text
0, gap, 2gap, ...
1, 1+gap, 1+2gap, ...
2, 2+gap, 2+2gap, ...
```

的元素分别组成若干子序列，对每个子序列执行插入排序。

例如 `gap = 4` 时：

```text
下标 0,4,8,... 为一组
下标 1,5,9,... 为一组
...
```

一趟结束后应得到：

> 所有相隔 `gap` 的子序列分别有序。

但原数组中连续的一段未必有序，更不能说已有元素全部到达最终位置。

### 代码模板

```cpp
void shellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int temp = a[i];
            int j = i;
            while (j >= gap && a[j - gap] > temp) {
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = temp;
        }
    }
}
```

常见增量可以写成：

$$
\left\lfloor\frac n2\right\rfloor,
\left\lfloor\frac n4\right\rfloor,
\ldots,
1
$$

但希尔排序的增量序列并不唯一。

### 复杂度与稳定性

希尔排序的时间复杂度与增量序列密切相关，408 复习时不要把它机械记成一个对所有增量都成立的紧确复杂度。

可以稳定记住：

- 辅助空间：$O(1)$；
- 不稳定；
- 最后一趟 `gap = 1` 就是直接插入排序；
- 其效率来自前面几趟已经显著降低了序列的无序程度。

### 为什么不稳定

相同关键字记录可能分属不同增量子序列，并在较远距离移动时跨越彼此，因此相对次序可能改变。

## 8.2.2 二路归并

归并的前提是：**两个输入子序列本身已经有序**。

例如：

```text
A = 1, 4, 7
B = 2, 3, 8
```

分别用两个指针指向当前首个未处理元素，每次把较小者写入辅助数组：

```text
1, 2, 3, 4, 7, 8
```

若一个子序列先耗尽，则把另一个子序列剩余部分直接复制。

```cpp
void merge(int a[], int temp[], int left, int mid, int right) {
    int i = left;
    int j = mid + 1;
    int k = left;

    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) temp[k++] = a[i++];
        else temp[k++] = a[j++];
    }

    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];

    for (int p = left; p <= right; ++p) a[p] = temp[p];
}
```

这里使用：

```cpp
if (a[i] <= a[j])
```

当关键字相等时先取左侧记录，因此可保持稳定性。

## 8.2.3 归并排序

> **真题标签｜2017 年第 10 题、2022 年第 10 题、2024 年第 10 题、2026 年第 11 题；2011 年第 42 题、2012 年第 41 题：二路归并及其应用**
>
> 高频考法包括归并趟数、中间序列、稳定性、辅助空间和算法设计。

归并排序是典型分治算法：

```text
不断二分
→ 子问题排序
→ 把相邻有序子序列归并
```

递归版本：

```cpp
void mergeSort(int a[], int temp[], int left, int right) {
    if (left >= right) return;

    int mid = left + (right - left) / 2;
    mergeSort(a, temp, left, mid);
    mergeSort(a, temp, mid + 1, right);
    merge(a, temp, left, mid, right);
}
```

### 自底向上的趟特征

若从长度为 1 的有序段开始做二路归并，归并段长度大致按以下规律增长：

```text
1 → 2 → 4 → 8 → ...
```

若 $n$ 不是 2 的幂，最后一个归并段可能较短，但核心判断仍是：

> 每一趟后，连续有序段的规模明显扩大。

### 时间复杂度

每一层归并都要处理全部 $n$ 个元素，递归树高度约为：

$$
\lceil\log_2 n\rceil
$$

故：

$$
T(n)=\Theta(n\log n)
$$

这一结论与原序列是否有序基本无关，因此：

- 最好：$\Theta(n\log n)$；
- 平均：$\Theta(n\log n)$；
- 最坏：$\Theta(n\log n)$。

### 空间复杂度

常规数组归并排序需要长度约为 $n$ 的辅助数组：

$$
O(n)
$$

递归调用还会产生 $O(\log n)$ 栈空间，但被 $O(n)$ 辅助数组主导，因此总辅助空间仍记为：

$$
O(n)
$$

### 稳定性

归并时若相等关键字优先取左半部分，就不会改变相等记录原来的相对次序，因此归并排序是稳定排序。

## 8.2.4 希尔与归并的中间序列辨析

看到以下特征时，可快速判断：

**希尔排序：**

```text
相隔固定 gap 的位置分别有序
```

**归并排序：**

```text
连续的若干小段各自有序，且段长按趟扩大
```

> **易错点｜归并排序一趟不保证“某个元素已经最终归位”**
>
> 某个短归并段内部虽然已经有序，但后续与其他段合并时，其元素仍可能整体移动到新的位置。
