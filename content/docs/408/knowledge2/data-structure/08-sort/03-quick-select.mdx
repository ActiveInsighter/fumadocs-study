快速排序是 408 中最需要理解“划分后发生了什么”的排序算法之一。

> **真题标签｜2014 年第 11 题、2024 年第 8 题；2016 年第 43 题：快速排序、划分与快速选择思想**
>
> 高频考法：一次划分后的性质、最坏情况、递归深度、中间序列和只递归一侧的选择问题。

## 8.3.1 快速排序的核心思想

快速排序同样属于分治算法，但与归并排序的处理顺序不同：

**归并排序：**

```text
先分解 → 递归排序 → 再合并
```

**快速排序：**

```text
先划分 → 枢轴归位 → 再递归两侧
```

对区间 `a[low...high]`：

1. 选择枢轴 `pivot`；
2. 调整区间，使左侧元素不大于枢轴；
3. 使右侧元素不小于枢轴；
4. 把枢轴放到其最终位置；
5. 递归处理左右子区间。

## 8.3.2 一次划分后必须掌握的三个结论

设一次划分后枢轴位置为 `p`，则：

```text
[ low ... p-1 ]  pivot  [ p+1 ... high ]
      <= pivot             >= pivot
```

最重要的是：

1. `pivot` 已经处于最终位置；
2. 左右两边满足相对枢轴的大小关系；
3. 左右区间内部通常仍然无序。

因此不能把“一次划分”误认为“左右两部分已经排好序”。

## 8.3.3 双向扫描划分模板

以下使用区间首元素作为枢轴，并采用“挖坑填数”写法：

```cpp
int partition(int a[], int low, int high) {
    int pivot = a[low];
    int i = low, j = high;

    while (i < j) {
        while (i < j && a[j] >= pivot) --j;
        a[i] = a[j];

        while (i < j && a[i] <= pivot) ++i;
        a[j] = a[i];
    }

    a[i] = pivot;
    return i;
}

void quickSort(int a[], int low, int high) {
    if (low >= high) return;
    int p = partition(a, low, high);
    quickSort(a, low, p - 1);
    quickSort(a, p + 1, high);
}
```

> **做题提醒｜划分算法不唯一**
>
> Hoare、Lomuto、挖坑法等实现得到的“中间序列”和枢轴位置可能不同。题目若给出具体划分代码，应严格按该代码模拟，不能套另一种实现的结果。

## 8.3.4 时间复杂度来自划分是否均衡

一次 `partition` 需要线性扫描当前区间，因此代价为 $\Theta(n)$。

### 理想情况

若每次枢轴都把问题近似平分：

$$
T(n)=2T(n/2)+\Theta(n)
$$

得到：

$$
T(n)=\Theta(n\log n)
$$

### 最坏情况

若每次枢轴都是当前区间最小值或最大值：

$$
T(n)=T(n-1)+\Theta(n)
$$

于是：

$$
T(n)=\Theta(n^2)
$$

当固定选择区间首元素作为枢轴时，已经有序或近似有序的输入可能导致严重退化。

### 实践中的改进方向

常见思路包括：

- 随机选择枢轴；
- 三数取中；
- 小区间改用插入排序；
- 优先递归较短的一侧、把另一侧改写成循环，以控制栈深度。

408 做题重点仍是理解“划分平衡程度决定递归树高度”。

## 8.3.5 空间复杂度

快速排序的主要额外空间来自递归栈：

- 平均递归深度：$O(\log n)$；
- 最坏递归深度：$O(n)$。

因此常记为：

$$
S_{avg}(n)=O(\log n),\qquad S_{worst}(n)=O(n)
$$

快速排序通常不稳定，因为划分时的跨区间交换可能改变相等关键字记录的相对次序。

## 8.3.6 快速选择 Quick Select

快速排序每次划分都会确定一个枢轴的最终位置。若目标只是寻找第 $k$ 小元素，就没有必要对左右两边全部排序。

设划分位置为 `p`：

- 若 `p == k`：已经找到目标；
- 若 `p > k`：目标只可能在左边；
- 若 `p < k`：目标只可能在右边。

```cpp
int quickSelect(int a[], int low, int high, int k) {
    while (low <= high) {
        int p = partition(a, low, high);
        if (p == k) return a[p];
        if (p > k) high = p - 1;
        else low = p + 1;
    }
    return -1;
}
```

这里 `k` 表示升序后的 **0 基下标**。

若题目要求“第 $k$ 大”且 $k$ 从 1 开始，则对应升序下标为：

$$
n-k
$$

例如长度为 10 的数组，第 1 大元素对应：

$$
10-1=9
$$

### Quick Select 的复杂度

若划分较均衡，平均只递归一侧：

$$
T(n)\approx T(n/2)+\Theta(n)=\Theta(n)
$$

因此平均时间复杂度可达到：

$$
O(n)
$$

但若连续极端划分，最坏仍可能是：

$$
O(n^2)
$$

> **核心对比**
>
> - 快速排序：划分后 **左右两边都递归**；
> - 快速选择：划分后 **只处理目标所在一边**。

## 8.3.7 中间序列判断

若某一步后存在元素 `x`，满足：

```text
左边所有元素 <= x
右边所有元素 >= x
```

则 `x` 很可能是快速排序本趟刚归位的枢轴。

但仅看到“某个元素已经在最终位置”还不够，因为选择排序、堆排序也会产生已归位元素。要结合：

- 左小右大的划分关系；
- 是否出现连续末端归位；
- 未排序区是否保持堆结构；
- 是否发生相邻交换。
