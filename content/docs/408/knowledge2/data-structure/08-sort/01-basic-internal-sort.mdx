排序题不能只背代码。408 更常考的是：**给出一段中间序列、一次操作次数、稳定性或复杂度条件，让你反推算法性质**。

复习本章时建议始终从以下 7 个维度比较排序算法：

| 维度 | 要问的问题 |
| --- | --- |
| 基本思想 | 每一趟到底做了什么？ |
| 时间复杂度 | 最好、平均、最坏分别是多少？ |
| 辅助空间 | 是否原地排序？递归栈是否计入？ |
| 稳定性 | 相同关键字记录的相对次序会不会改变？ |
| 初始状态敏感性 | “基本有序”“逆序”等状态是否影响效率？ |
| 一趟特征 | 哪些元素已经归位？哪些只是局部有序？ |
| 适用场景 | 数据规模、分布、内外存条件有什么要求？ |

<Callout type="info" title="408 复习主线">

内部排序重点掌握 **直接插入、冒泡、简单选择、希尔、快速、堆、归并、基数排序**。外部排序重点掌握 **初始归并段、置换选择、多路归并、胜者树与败者树**。

</Callout>

## 1. 排序的基本概念

### 1.1 内部排序与外部排序

若待排序记录可以一次全部装入内存，排序过程主要在内存中完成，称为**内部排序**。

若数据规模过大，排序过程中必须借助磁盘等外存反复读写，称为**外部排序**。

两者的主要优化目标不同：

* 内部排序更关注**比较次数、移动次数、CPU 时间和辅助空间**；
* 外部排序更关注**磁盘 I/O 次数**，其次才是内存中的比较次数。

### 1.2 稳定性

设待排序序列中有两个记录 $R_i$、$R_j$，满足：

$$
key_i=key_j
$$

且排序前 $R_i$ 位于 $R_j$ 之前。若排序完成后 $R_i$ 仍位于 $R_j$ 之前，则这两个相等关键字记录的相对次序被保持。

若算法对任意输入都能保持所有相等关键字记录的相对次序，则称该排序算法是**稳定排序**。

例如：

```text
5₁, 3, 5₂, 1
```

若排序后为：

```text
1, 3, 5₁, 5₂
```

则两个 `5` 的相对次序没有改变。

常见排序的典型稳定性如下：

| 排序算法 | 稳定性 | 关键原因 |
| --- | --- | --- |
| 冒泡排序 | 稳定 | 相等元素不交换 |
| 直接插入排序 | 稳定 | 新元素通常插到相等元素之后 |
| 折半插入排序 | 可保持稳定 | 折半定位时选择相等元素之后的位置 |
| 归并排序 | 稳定 | 相等时优先取左半段元素 |
| 基数排序 | 稳定 | LSD 每一位的分配/收集必须稳定 |
| 简单选择排序 | 不稳定 | 远距离交换可能跨过相等记录 |
| 快速排序 | 不稳定 | 划分过程中的交换可能改变相等记录次序 |
| 希尔排序 | 不稳定 | 不同增量组中的远距离移动可能越过相等记录 |
| 堆排序 | 不稳定 | 堆顶与末尾等远距离交换会改变相对次序 |
| 桶排序 | 取决于实现 | 取决于桶内排序和收集是否稳定 |

<Callout type="warn" title="稳定性描述的是算法性质，不是结果是否有序">

“稳定”不等于“更快”或“更好”。它只描述**相同关键字记录的相对次序是否被保持**。若记录除了关键字外还带有其他字段，稳定性才会体现出实际意义。

</Callout>

### 1.3 内部排序复杂度总表

| 排序算法 | 最好时间 | 平均时间 | 最坏时间 | 辅助空间 | 稳定性 |
| --- | --- | --- | --- | --- | --- |
| 冒泡排序（带提前结束） | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 直接插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 简单选择排序 | $\Theta(n^2)$ | $\Theta(n^2)$ | $\Theta(n^2)$ | $O(1)$ | 不稳定 |
| 归并排序 | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(n)$ | 稳定 |
| 快速排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | 平均 $O(\log n)$，最坏 $O(n)$ | 不稳定 |
| 堆排序 | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(1)$ | 不稳定 |
| 希尔排序 | 与增量序列有关 | 与增量序列有关 | 与增量序列有关 | $O(1)$ | 不稳定 |
| 桶排序 | 分布良好时接近 $O(n+k)$ | 依实现与分布 | 可能明显退化 | $O(n+k)$ | 依实现 |
| 基数排序 | $O(d(n+k))$ | $O(d(n+k))$ | $O(d(n+k))$ | $O(n+k)$ | 稳定 |

其中：

* $n$：记录数；
* $k$：桶数或某一位可能出现的取值个数；
* $d$：关键字位数。

### 1.4 比较排序的下界

若排序算法只能通过“比较两个关键字”获取相对大小信息，则可以用**比较决策树**描述其执行过程。

$n$ 个互异元素共有：

$$
n!
$$

种可能排列。决策树至少要有 $n!$ 个叶结点，因此其高度 $h$ 必须满足：

$$
2^h\ge n!
$$

于是：

$$
h\ge \log_2(n!)=\Omega(n\log n)
$$

所以任何基于关键字比较的排序，在最坏情况下都需要至少：

$$
\Omega(n\log n)
$$

次比较。

<Callout type="info" title="为什么基数排序可以突破比较排序下界">

桶排序、计数思想、基数排序利用的是关键字的**取值结构或数位信息**，并不只靠元素两两比较，因此不受上述比较决策树下界直接限制。

</Callout>

### 1.5 比较次数、交换次数和移动次数必须分清

排序题经常分别问：

* 关键字比较次数；
* 交换次数；
* 元素移动次数；
* 赋值次数。

这些口径不能混用。

例如：

```cpp
swap(a, b);
```

若按“交换”计数，通常算 1 次；若展开为临时变量赋值，则可能包含 3 次赋值。

因此遇到精确计数题，应先明确题目采用的操作模型；若题目只问数量级，再使用渐近复杂度。

从典型行为看：

| 算法 | 比较/移动的典型特点 |
| --- | --- |
| 冒泡排序 | 逆序程度越高，交换越多；本趟无交换可提前结束 |
| 直接插入排序 | 越接近有序，比较和移动通常越少 |
| 简单选择排序 | 比较次数固定为 $n(n-1)/2$，交换最多 $n-1$ 次 |
| 归并排序 | 每层都要线性扫描并写入记录，总体 $\Theta(n\log n)$ |
| 快速排序 | 与枢轴位置和划分均衡程度密切相关 |
| 堆排序 | 建堆 $O(n)$，随后反复 $O(\log n)$ 调整 |

### 1.6 各算法的“一趟特征”

<InlineSvg src="/images/data-structure/data-structure-sort-internal-004.svg" alt="图示" />

中间序列判断题的核心不是“看起来像不像”，而是寻找**一趟结束后的不变量**。

| 算法 | 一趟主要操作 | 一趟结束后的典型性质 |
| --- | --- | --- |
| 冒泡排序 | 相邻比较、交换 | 当前未排序区最大元素进入末端最终位置 |
| 简单选择排序 | 在未排序区选最小值 | 当前最小元素进入前端最终位置 |
| 直接插入排序 | 将一个元素插入前方有序区 | 前缀内部有序，但其中元素未必已经最终归位 |
| 希尔排序 | 按当前增量进行分组插入 | 所有相隔 `gap` 的子序列分别有序 |
| 归并排序 | 合并相邻有序段 | 有序归并段长度逐轮扩大 |
| 快速排序 | 围绕枢轴划分 | 枢轴进入最终位置，左侧不大于它、右侧不小于它 |
| 堆排序 | 堆顶与未排序区末尾交换后调整 | 当前最大元素进入最终位置，剩余部分重新成堆 |
| 桶排序 | 按值域分配到桶 | 元素已进入相应值域，桶内不一定有序 |
| 基数排序 | 按当前数位稳定分配、收集 | 已按处理过的数位建立有序关系 |

<Callout type="warn" title="“有序区”不等于“最终位置区”">

直接插入排序产生的是**内部有序前缀**；简单选择排序产生的是**已经归位的前缀**。这是中间序列判断题中最常见的混淆点之一。

</Callout>

## 2. 冒泡排序

<InlineSvg src="/images/data-structure/data-structure-sort-internal-005.svg" alt="5 1 4 2 8 1 5 4 2 8 1 4 5 2 8 1 4 2 5 8 1 5 4 2 8 1 4 5 2 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 2 4 5 8 1 2 4 5 8 1 2 4 5 8 第一次冒泡 ：将最大的数放到最后一个位置 第二次冒泡 ：将第二大的数放到倒数第二个位置" />

冒泡排序（Bubble Sort）的核心是**相邻逆序对交换**。

对升序排序，一趟从左向右扫描：

1. 比较相邻元素 `a[j]` 和 `a[j+1]`；
2. 若 `a[j] > a[j+1]`，则交换；
3. 较大的元素会逐步向右移动；
4. 一趟结束后，当前未排序区的最大元素到达最右端并最终归位。

例如：

```text
5, 1, 4, 2, 8
```

第一趟的关键变化为：

```text
5 1 4 2 8
↓
1 5 4 2 8
↓
1 4 5 2 8
↓
1 4 2 5 8
```

此时未排序区中的最大值 `8` 已在末端；若继续完整扫描，序列逐步有序。

### 2.1 代码模板

```cpp
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        bool exchanged = false;

        for (int j = 0; j < n - i - 1; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                exchanged = true;
            }
        }

        if (!exchanged) {
            break;
        }
    }
}
```

若某一趟没有发生任何交换，则整个序列已经有序，可以提前结束。

因此：

| 性质 | 结论 |
| --- | --- |
| 最好时间 | $O(n)$ |
| 平均时间 | $O(n^2)$ |
| 最坏时间 | $O(n^2)$ |
| 辅助空间 | $O(1)$ |
| 稳定性 | 稳定 |

### 2.2 冒泡排序与逆序对

若只在相邻元素逆序时交换，则**每次交换恰好消去一个逆序对**。

因此冒泡排序的交换次数等于初始序列的逆序对数。

特别地，完全逆序序列的逆序对数为：

$$
\frac{n(n-1)}{2}
$$

所以最坏情况下需要同数量级的交换。

> **真题考察**
>
> 冒泡排序常与“交换次数”“逆序对”“中间序列判断”结合考查。

## 3. 插入排序

<InlineSvg src="/images/data-structure/data-structure-sort-internal-006.svg" alt="4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6" />

> **真题考察**
>
> * 选择题：2017 年第 10 题、2020 年第 11 题、2026 年第 9 题
> * 解答题：2022 年第 42 题

插入排序（Insertion Sort）把序列分成：

* 前部的**已排序区**；
* 后部的**未排序区**。

每一趟从未排序区取出第一个元素，将它插入前面的有序区。

例如：

```text
4, 3, 2, 10, 12, 1, 5, 6
```

插入过程的核心不变量是：

> 第 $i$ 趟结束后，前 $i+1$ 个元素已经按关键字有序，但它们未必已经处于整个序列中的最终位置。

### 3.1 直接插入排序

```cpp
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int temp = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > temp) {
            a[j + 1] = a[j];
            --j;
        }

        a[j + 1] = temp;
    }
}
```

这里使用严格条件：

```cpp
a[j] > temp
```

因此遇到与 `temp` 相等的元素时不会把它越过去，可以保持稳定性。

直接插入排序对初始有序程度非常敏感。

若序列已经有序，每个新元素只需做常数次判断，整体为：

$$
O(n)
$$

若序列完全逆序，第 $i$ 个待插入元素需要向前移动约 $i$ 个位置，总工作量为：

$$
1+2+\cdots+(n-1)=\frac{n(n-1)}{2}
$$

因此最坏为：

$$
O(n^2)
$$

综合性质：

| 性质 | 结论 |
| --- | --- |
| 最好时间 | $O(n)$ |
| 平均时间 | $O(n^2)$ |
| 最坏时间 | $O(n^2)$ |
| 辅助空间 | $O(1)$ |
| 稳定性 | 稳定 |
| 适用场景 | 小规模或基本有序序列 |

### 3.2 折半插入排序

<InlineSvg src="/images/data-structure/data-structure-sort-internal-007.svg" alt="直接插入排序与折半插入排序对比图" />

已排序区本身有序，因此可以用折半查找确定插入位置。

与直接插入排序相比：

| 方法 | 寻找插入位置 | 元素移动 |
| --- | --- | --- |
| 直接插入 | 从后向前顺序比较 | 仍需移动 |
| 折半插入 | 在有序区折半定位 | 仍需移动 |

对第 $i$ 个元素而言，折半定位可以把寻找位置的比较次数降到：

$$
O(\log i)
$$

所有趟定位比较的总量约为：

$$
O(n\log n)
$$

但找到位置后仍可能整体后移：

$$
O(n)
$$

个元素，因此最坏和平均总时间仍为：

$$
O(n^2)
$$

<Callout type="warn" title="折半插入只减少比较次数，不消除移动">

折半插入排序不会因为使用折半查找就整体变成 $O(n\log n)$。在顺序表上，**移动元素仍然是二次量级瓶颈**。

</Callout>

### 3.3 折半插入如何保持稳定

若待插入元素与有序区中若干元素关键字相等，应把它插到这些相等元素的**后面**。

也就是说，折半定位的边界规则要找到“第一个大于待插入元素的位置”，而不是随便找到一个相等位置就插入。

这样才能保持稳定性。

## 4. 简单选择排序

<InlineSvg src="/images/data-structure/data-structure-sort-internal-008.svg" alt="11 25 12 22 64 11 25 12 22 64 11 12 25 22 64 11 12 22 25 64 11 12 22 25 64 11 12 22 25 64" />

简单选择排序（Selection Sort）也把序列划分为已排序区和未排序区，但它与插入排序的“有序区”性质不同。

每一趟：

1. 扫描整个未排序区；
2. 找出最小元素；
3. 将它与未排序区第一个元素交换；
4. 已排序区扩大一个元素。

例如：

```text
11, 25, 12, 22, 64
```

| 已排序区 | 未排序区 | 本趟最小值 |
| --- | --- | ---: |
| `()` | `(11, 25, 12, 22, 64)` | 11 |
| `(11)` | `(25, 12, 22, 64)` | 12 |
| `(11, 12)` | `(25, 22, 64)` | 22 |
| `(11, 12, 22)` | `(25, 64)` | 25 |
| `(11, 12, 22, 25)` | `(64)` | 64 |

### 4.1 代码模板

```cpp
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int minIndex = i;

        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[minIndex]) {
                minIndex = j;
            }
        }

        if (minIndex != i) {
            swap(a[i], a[minIndex]);
        }
    }
}
```

### 4.2 比较次数固定

无论原序列已经有序、逆序还是随机，简单选择排序每一趟都必须扫描整个未排序区。

关键字比较次数恒为：

$$
(n-1)+(n-2)+\cdots+1
=\frac{n(n-1)}{2}
$$

因此：

$$
T(n)=\Theta(n^2)
$$

但每一趟最多交换 1 次，所以交换次数最多为：

$$
n-1
$$

这说明选择排序的特点是：**比较很多，但交换较少**。

### 4.3 为什么简单选择排序不稳定

考虑带标记的序列：

```text
5₁, 5₂, 2
```

第一趟会选出最小值 `2`，并与第一个元素 `5₁` 交换：

```text
2, 5₂, 5₁
```

原来 `5₁` 在 `5₂` 前面，交换后顺序颠倒，因此简单选择排序不稳定。

<Callout type="info" title="选择排序与插入排序的本质区别">

* 简单选择排序：每趟确定一个**最终位置**，比较次数基本不受初始状态影响。
* 直接插入排序：每趟只保证前缀**内部有序**，但对“基本有序”序列非常高效。

</Callout>
