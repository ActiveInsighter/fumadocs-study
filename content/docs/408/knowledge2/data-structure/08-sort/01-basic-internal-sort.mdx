排序是考研 408 数据结构中的高频章节。复习时不要只记代码，而应统一从以下几个维度比较：

* **排序过程**：每一趟究竟做什么。
* **时间复杂度**：最好、平均、最坏情况。
* **辅助空间**：是否原地排序。
* **稳定性**：相同关键字记录的相对次序是否改变。
* **初始状态敏感性**：原序列是否接近有序会不会影响效率。
* **趟特征**：给出中间序列时，能否判断是哪种排序。
* **适用场景**：数据规模、数据分布、内外存条件等。

> **408 复习重点**
>
> 内部排序重点掌握 **直接插入排序、冒泡排序、简单选择排序、希尔排序、快速排序、堆排序、归并排序和基数排序**；外部排序重点掌握 **初始归并段、置换选择、多路归并、胜者树和败者树**。

## 1. 排序的基本概念

### 1.1 稳定性

若待排序序列中存在两个关键字相等的记录，排序完成后它们的**相对先后次序保持不变**，则称该排序算法是**稳定的**。

例如：

```text
5₁, 3, 5₂, 1
```

若排序后仍为：

```text
1, 3, 5₁, 5₂
```

则两个关键字相等的 `5` 的相对次序没有改变，因此该次排序保持稳定。

常见算法的稳定性如下：

| 排序算法   | 稳定性          |
| ------ | ------------ |
| 冒泡排序   | 稳定           |
| 直接插入排序 | 稳定           |
| 折半插入排序 | 可保持稳定        |
| 归并排序   | 稳定           |
| 基数排序   | 稳定           |
| 简单选择排序 | 不稳定          |
| 快速排序   | 不稳定          |
| 希尔排序   | 不稳定          |
| 堆排序    | 不稳定          |
| 桶排序    | 取决于桶内排序及收集方式 |

> **易错点**
>
> 稳定与否并不表示算法“好不好”。稳定性只描述**相同关键字记录的相对次序是否保持**。

### 1.2 复杂度总表

| 排序算法        | 最好时间                | 平均时间                | 最坏时间                | 辅助空间                         | 稳定性 |
| ----------- | ------------------- | ------------------- | ------------------- | ---------------------------- | --- |
| 冒泡排序（带提前结束） | $O(n)$            | $O(n^2)$          | $O(n^2)$          | $O(1)$                     | 稳定  |
| 直接插入排序      | $O(n)$            | $O(n^2)$          | $O(n^2)$          | $O(1)$                     | 稳定  |
| 简单选择排序      | $\Theta(n^2)$     | $\Theta(n^2)$     | $\Theta(n^2)$     | $O(1)$                     | 不稳定 |
| 归并排序        | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(n)$                     | 稳定  |
| 快速排序        | $O(n\log n)$      | $O(n\log n)$      | $O(n^2)$          | 平均 $O(\log n)$，最坏 $O(n)$ | 不稳定 |
| 堆排序         | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(1)$                     | 不稳定 |
| 希尔排序        | 与增量序列有关             | 与增量序列有关             | 与增量序列有关             | $O(1)$                     | 不稳定 |
| 桶排序         | 良好分布时接近 $O(n+k)$  | 依实现与分布              | 可能退化                | $O(n+k)$                   | 依实现 |
| 基数排序        | $O(d(n+k))$       | $O(d(n+k))$       | $O(d(n+k))$       | $O(n+k)$                   | 稳定  |

其中：

* $n$：待排序记录数；
* $k$：桶或某一位可能出现的取值个数；
* $d$：关键字包含的位数。

对于只依靠关键字比较的排序算法，在比较决策树模型下，其最坏情况时间复杂度存在下界：

$$
\Omega(n\log n)
$$

桶排序、计数思想和基数排序利用了关键字的实际取值，因此并不直接受到这一比较排序下界限制。

### 1.3 元素移动次数

若题目问“移动次数”，首先要确认题目的计数规则。

一次交换：

```cpp
swap(a, b);
```

有的题目记作 **1 次交换**，有的题目会拆成 3 次赋值，因此不能机械套公式。

从数量级看：

| 算法     | 元素移动或写入特点                             |
| ------ | ------------------------------------- |
| 冒泡排序   | 最坏 $O(n^2)$，本趟无交换时可提前结束             |
| 选择排序   | 比较始终为 $\Theta(n^2)$，交换最多 $O(n)$ 次 |
| 插入排序   | 最好 $O(n)$，最坏 $O(n^2)$             |
| 归并排序   | 每层归并都需写入全部元素，总体 $\Theta(n\log n)$   |
| 快速排序   | 与划分结果有关                               |
| 堆排序    | 整体 $O(n\log n)$                     |
| 希尔排序   | 与增量序列有关                               |
| 桶、基数排序 | 一般按每趟线性扫描和分配、收集分析                     |

### 1.4 各算法的“一趟特征”

一趟通常指外层循环的一次完整处理。中间序列判断题经常利用不同排序算法的“一趟特征”。

<InlineSvg src="/images/data-structure/data-structure-sort-internal-004.svg" alt="图示" />

| 算法     | 一趟的主要操作        | 一趟结束后的典型特征          |
| ------ | -------------- | ------------------- |
| 冒泡排序   | 相邻元素依次比较、交换    | 当前最大元素进入末端最终位置      |
| 简单选择排序 | 在未排序区选择最小元素    | 当前最小元素进入前端最终位置      |
| 插入排序   | 将一个新元素插入已有序区   | 前若干个元素内部有序，但未必已归位   |
| 希尔排序   | 按当前增量进行分组插入排序  | 所有相隔 `gap` 的子序列分别有序 |
| 归并排序   | 合并相邻有序子序列      | 有序归并段的长度逐步扩大        |
| 快速排序   | 围绕枢轴进行划分       | 枢轴进入最终位置，左小右大       |
| 堆排序    | 堆顶与未排序区末尾交换并调整 | 当前最大元素进入最终位置        |
| 桶排序    | 按值域把记录分配到桶     | 记录已进入对应值域，桶内未必有序    |
| 基数排序   | 按当前位进行稳定分配、收集  | 已按当前处理过的数位有序        |

> **高频区分**
>
> **选择排序**与**插入排序**虽然都会形成一个“有序部分”，但性质完全不同：
>
> * 选择排序的有序区中的元素已经处于**最终位置**。
> * 插入排序的有序区只是**内部有序**，其中元素以后仍可能移动。

## 2. 冒泡排序

冒泡排序（Bubble Sort）通过不断比较相邻元素，将较大的元素逐步移动到序列末端。

升序排序的一趟过程为：

1. 比较 `a[0]` 与 `a[1]`；
2. 若前者更大，则交换；
3. 接着比较 `a[1]` 与 `a[2]`；
4. 持续向右；
5. 一趟结束后，当前未排序区中的最大元素一定到达末端。

例如数组：

```text
5, 1, 4, 2, 8
```

其前几次冒泡过程如下。

<InlineSvg src="/images/data-structure/data-structure-sort-internal-005.svg" alt="5 1 4 2 8 1 5 4 2 8 1 4 5 2 8 1 4 2 5 8 1 5 4 2 8 1 4 5 2 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 4 2 5 8 1 2 4 5 8 1 2 4 5 8 1 2 4 5 8 第一次冒泡 ：将最大的数放到最后一个位置 第二次冒泡 ：将第二大的数放到倒数第二个位置" />

### 2.1 代码模板

```cpp
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        bool exchanged = false;

        for (int j = 0; j < n - i - 1; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                exchanged = true;
            }
        }

        if (!exchanged) {
            break;
        }
    }
}
```

若某一趟没有任何交换，说明整个序列已经有序，可以提前结束。

因此：

* 最好情况：$O(n)$；
* 平均情况：$O(n^2)$；
* 最坏情况：$O(n^2)$；
* 辅助空间：$O(1)$；
* 稳定。

## 3. 插入排序

> **真题考察**
>
> * 选择题：2017 年第 10 题、2020 年第 11 题、2026 年第 9 题
> * 解答题：2022 年第 42 题

插入排序（Insertion Sort）把序列划分为：

* 前部的**已排序区**；
* 后部的**未排序区**。

每一趟从未排序区取出第一个元素，将其插入前面的有序区。

对于：

```text
4, 3, 2, 10, 12, 1, 5, 6
```

排序过程如下。

<InlineSvg src="/images/data-structure/data-structure-sort-internal-006.svg" alt="4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6 4 3 2 10 12 1 5 6" />

### 3.1 直接插入排序

```cpp
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int temp = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > temp) {
            a[j + 1] = a[j];
            --j;
        }

        a[j + 1] = temp;
    }
}
```

直接插入排序对序列的**初始有序程度非常敏感**。

例如：

```text
1, 2, 3, 5, 4, 6, 7, 8
```

只需把 `4` 向前移动少量位置。

而对于逆序序列：

```text
8, 7, 6, 5, 4, 3, 2, 1
```

每插入一个新元素，都需要移动大量已有元素。

因此：

* 最好情况：$O(n)$；
* 最坏情况：$O(n^2)$；
* 平均情况：$O(n^2)$；
* 辅助空间：$O(1)$；
* 稳定。

### 3.2 折半插入排序

插入排序寻找插入位置时，可以使用折半查找。

<InlineSvg src="/images/data-structure/data-structure-sort-internal-007.svg" alt="直接插入排序与折半插入排序对比图" />

两者区别主要在于：

| 方法     | 查找插入位置       |
| ------ | ------------ |
| 直接插入排序 | 从后向前顺序比较     |
| 折半插入排序 | 在已有序区中进行折半查找 |

折半查找能够减少**比较次数**，但找到位置以后仍可能需要整体移动一段元素。

因此折半插入排序的总体时间复杂度仍为：

$$
O(n^2)
$$

> **易错点**
>
> 折半插入排序只是降低了“寻找插入位置”的比较次数，并没有消除元素移动，因此总体复杂度并不会变成 $O(n\log n)$。

## 4. 简单选择排序

简单选择排序（Selection Sort）也将序列划分为已排序区和未排序区。

每一趟：

1. 扫描整个未排序区；
2. 找出其中最小元素；
3. 与未排序区第一个元素交换。

例如：

```text
11, 25, 12, 22, 64
```

| 已排序区                   | 未排序区                   | 当前最小值 |
| ---------------------- | ---------------------- | ----- |
| `()`                   | `(11, 25, 12, 22, 64)` | 11    |
| `(11)`                 | `(25, 12, 22, 64)`     | 12    |
| `(11, 12)`             | `(25, 22, 64)`         | 22    |
| `(11, 12, 22)`         | `(25, 64)`             | 25    |
| `(11, 12, 22, 25)`     | `(64)`                 | 64    |
| `(11, 12, 22, 25, 64)` | `()`                   | —     |

<InlineSvg src="/images/data-structure/data-structure-sort-internal-008.svg" alt="11 25 12 22 64 11 25 12 22 64 11 12 25 22 64 11 12 22 25 64 11 12 22 25 64 11 12 22 25 64" />

### 4.1 代码模板

```cpp
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int minIndex = i;

        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[minIndex]) {
                minIndex = j;
            }
        }

        if (minIndex != i) {
            swap(a[i], a[minIndex]);
        }
    }
}
```

无论初始序列是否有序，它都需要扫描剩余元素，因此比较次数始终为：

$$
(n-1)+(n-2)+\cdots+1
=
\frac{n(n-1)}{2}
$$

所以：

$$
T(n)=\Theta(n^2)
$$

但其交换次数最多只有 $O(n)$。

> **稳定性**
>
> 简单选择排序**不稳定**。因为一次将最小元素直接与前面的元素交换，可能跨越与它关键字相同的其他记录。
