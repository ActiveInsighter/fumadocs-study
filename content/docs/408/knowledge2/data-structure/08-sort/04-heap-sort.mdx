堆既是树形结构的应用，也是排序章节中的高频考点。

> **真题标签｜2009 年第 9 题、2011 年第 11 题、2015 年第 10 题、2018 年第 11 题、2020 年第 9 题、2021 年第 11 题、2024 年第 9 题；2022 年第 42 题：堆与堆排序**
>
> 重点掌握数组下标关系、建堆起点、向下调整、插入删除、建堆复杂度和排序中间状态。

## 8.4.1 堆的定义

堆必须同时满足：

1. **结构性质**：是一棵完全二叉树；
2. **堆序性质**：父结点与孩子结点满足固定大小关系。

### 大根堆

每个父结点都不小于其孩子：

```text
parent >= children
```

根结点是全堆最大值。

### 小根堆

每个父结点都不大于其孩子：

```text
parent <= children
```

根结点是全堆最小值。

因此：

- 大根堆可在 $O(1)$ 时间访问最大值；
- 小根堆可在 $O(1)$ 时间访问最小值。

## 8.4.2 堆的顺序存储

完全二叉树特别适合顺序存储。

### 数组从 1 开始编号

对结点 $i$：

$$
left=2i
$$

$$
right=2i+1
$$

$$
parent=\left\lfloor\frac i2\right\rfloor
$$

### 数组从 0 开始编号

对结点 $i$：

$$
left=2i+1
$$

$$
right=2i+2
$$

$$
parent=\left\lfloor\frac{i-1}{2}\right\rfloor
$$

> **易错点｜先确认下标起点**
>
> 0 基与 1 基公式不能混用。考试手工建堆前应先在草稿上写清编号体系。

## 8.4.3 向下调整 Heapify

以大根堆为例。若当前结点可能破坏堆序：

1. 在当前结点、左孩子、右孩子中找到最大者；
2. 若最大者不是当前结点，则交换；
3. 对交换到下层的结点继续向下调整。

```cpp
void heapify(int a[], int size, int i) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < size && a[left] > a[largest]) largest = left;
        if (right < size && a[right] > a[largest]) largest = right;

        if (largest == i) break;
        std::swap(a[i], a[largest]);
        i = largest;
    }
}
```

一次向下调整最多沿树高移动，因此：

$$
O(\log n)
$$

## 8.4.4 自底向上建堆

对于 0 基数组，最后一个非叶结点为：

$$
\left\lfloor\frac n2\right\rfloor-1
$$

从它开始向前逐个执行 `heapify`：

```cpp
void buildHeap(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; --i) {
        heapify(a, n, i);
    }
}
```

### 为什么建堆是 $O(n)$ 而不是 $O(n\log n)$

不能简单地用：

```text
n 个结点 × 每个 O(log n)
```

因为大多数结点离叶子很近，实际能下沉的高度很小。

按高度分层估计：高度为 $h$ 的结点数量约为 $n/2^{h+1}$，故总工作量：

$$
\sum_{h\ge 0}\frac{n}{2^{h+1}}\cdot O(h)
=O(n)
$$

> **高频结论**
>
> 自底向上建立初始堆：$O(n)$；完整堆排序：$O(n\log n)$。

## 8.4.5 堆的插入与删除

### 插入

把新元素放到完全二叉树末尾，然后不断与父结点比较，必要时向上交换。

```cpp
void heapInsert(int heap[], int& size, int value) {
    int i = size++;
    heap[i] = value;

    while (i > 0) {
        int p = (i - 1) / 2;
        if (heap[p] >= heap[i]) break;
        std::swap(heap[p], heap[i]);
        i = p;
    }
}
```

时间复杂度：

$$
O(\log n)
$$

### 删除堆顶

1. 用最后一个元素覆盖堆顶；
2. 堆大小减 1；
3. 从根向下调整。

时间复杂度同样为：

$$
O(\log n)
$$

## 8.4.6 堆排序

升序排序通常使用**大根堆**：

1. 把整个数组建成大根堆；
2. 当前最大元素在根；
3. 交换堆顶与未排序区最后一个元素；
4. 缩小堆的有效范围；
5. 对根执行向下调整；
6. 重复直到排序完成。

```cpp
void heapSort(int a[], int n) {
    buildHeap(a, n);

    for (int end = n - 1; end > 0; --end) {
        std::swap(a[0], a[end]);
        heapify(a, end, 0);
    }
}
```

每一趟“堆顶与末尾交换”后：

> 当前未排序区最大元素进入最终位置。

### 复杂度

建堆：

$$
O(n)
$$

随后约执行 $n-1$ 次堆顶交换与调整，每次调整最坏：

$$
O(\log n)
$$

故总时间：

$$
\Theta(n\log n)
$$

辅助空间：

$$
O(1)
$$

堆排序不稳定。

## 8.4.7 堆排序中间序列识别

升序大根堆排序进行若干趟后，序列通常呈现：

```text
[ 未排序区：仍满足大根堆 ] [ 已排序区：若干最大元素递增排列 ]
```

因此看到“末尾已有若干最大元素归位”时，既可能是冒泡，也可能是堆排序。

区分关键：

- 冒泡未排序区没有堆结构要求；
- 堆排序每次调整后，未排序区必须重新成为合法大根堆。

## 8.4.8 堆排序的优缺点

优势：

- 最坏仍为 $\Theta(n\log n)$；
- 原地，辅助空间 $O(1)$；
- 可自然支持优先队列和 Top-K 问题。

不足：

- 不稳定；
- 相比高质量快速排序，常数和缓存局部性通常不占优势；
- 手工模拟时容易在“交换末尾后调整的有效堆范围”上出错。
