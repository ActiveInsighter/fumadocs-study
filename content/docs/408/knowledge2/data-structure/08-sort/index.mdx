排序是考研 408 数据结构中的高频章节。复习时不要只记代码，而应统一从以下几个维度比较：

* **排序过程**：每一趟究竟做什么。
* **时间复杂度**：最好、平均、最坏情况。
* **辅助空间**：是否原地排序。
* **稳定性**：相同关键字记录的相对次序是否改变。
* **初始状态敏感性**：原序列是否接近有序会不会影响效率。
* **趟特征**：给出中间序列时，能否判断是哪种排序。
* **适用场景**：数据规模、数据分布、内外存条件等。

> **408 复习重点**
>
> 内部排序重点掌握 **直接插入排序、冒泡排序、简单选择排序、希尔排序、快速排序、堆排序、归并排序和基数排序**；外部排序重点掌握 **初始归并段、置换选择、多路归并、胜者树和败者树**。
