本节用于考前快速复盘。排序题最容易丢分的原因通常不是不会代码，而是**混淆“局部有序、最终归位、稳定性、比较次数和移动次数”这些不同维度**。

## 8.8.1 高频易错点

### 1. “有序”不等于“已经归位”

直接插入排序一趟后：

```text
前部内部有序
```

但其中元素以后仍可能继续移动。

简单选择、快速、堆排序则会不断产生已经进入最终位置的元素。

### 2. 快速排序与归并排序都是分治，但顺序相反

归并：

```text
分 → 递归 → 合
```

快速：

```text
划分 → 枢轴归位 → 两边递归
```

### 3. 自底向上建堆是 $O(n)$

不要写成：

$$
O(n\log n)
$$

完整堆排序才是：

$$
\Theta(n\log n)
$$

### 4. 折半插入仍可能有 $O(n^2)$ 元素移动

折半查找只减少寻找插入位置的比较，不能消除把一段元素整体后移的成本。

### 5. LSD 基数排序每一趟必须稳定

更高位排序必须保留低位已经建立的相对次序，否则前一趟的信息会被破坏。

### 6. 外部排序的主要目标是减少 I/O

优化链条：

```text
初始归并段更长
→ 段数更少
→ 归并趟数更少
→ 磁盘 I/O 更少
```

### 7. 归并路数不是无限增大

更多路可以减少归并趟数，但会占用更多输入缓冲区，并提高候选选择问题的规模。

### 8. 一次交换如何计“移动次数”要看题目口径

`swap(a,b)` 可以被视为一次交换，也可能被拆成多次赋值。题目若明确给计数规则，应以题意为准。

## 8.8.2 全章总表

| 算法 | 核心思想 | 一趟典型特征 | 时间复杂度重点 | 空间 | 稳定 |
| --- | --- | --- | --- | ---: | --- |
| 冒泡 | 相邻比较交换 | 最大值进入末端最终位置 | 最好 $O(n)$，最坏 $O(n^2)$ | $O(1)$ | 是 |
| 直接插入 | 插入已有序区 | 前部内部有序 | 基本有序时优秀 | $O(1)$ | 是 |
| 选择 | 每趟选最小值 | 最小值进入前端最终位置 | 始终 $\Theta(n^2)$ 比较 | $O(1)$ | 否 |
| 希尔 | 增量分组插入 | `gap` 子序列分别有序 | 与增量序列有关 | $O(1)$ | 否 |
| 快速 | 枢轴划分 | 枢轴归位，左小右大 | 平均 $O(n\log n)$，最坏 $O(n^2)$ | 平均 $O(\log n)$ | 否 |
| 堆 | 堆顶选择 | 最大值进入末端最终位置 | 始终 $\Theta(n\log n)$ | $O(1)$ | 否 |
| 归并 | 二路合并 | 连续有序段逐步扩大 | 始终 $\Theta(n\log n)$ | $O(n)$ | 是 |
| 桶 | 按值域分桶 | 元素进入对应值域 | 分布良好时接近线性 | $O(n+k)$ | 依实现 |
| 基数 | 逐位稳定处理 | 已处理数位次序正确 | $O(d(n+k))$ | $O(n+k)$ | 是 |

## 8.8.3 “看到什么想到什么”

**最大元素连续在末尾归位：**

```text
冒泡 / 堆
```

**最小元素连续在前端归位：**

```text
简单选择
```

**前缀有序但仍可能变化：**

```text
直接插入
```

**某个元素左小右大且已经归位：**

```text
快速排序
```

**连续有序段越来越长：**

```text
归并排序
```

**固定间隔子序列分别有序：**

```text
希尔排序
```

**按个位、十位、百位逐趟处理：**

```text
LSD 基数排序
```

## 8.8.4 复杂度选择题常用结论

稳定且比较排序达到 $\Theta(n\log n)$：

```text
归并排序
```

原地且最坏仍是 $\Theta(n\log n)$：

```text
堆排序
```

平均很快但最坏可能退化为 $O(n^2)$：

```text
快速排序
```

输入基本有序时表现特别好：

```text
直接插入
冒泡（带提前结束）
```

比较次数基本不受初始状态影响：

```text
简单选择
```

## 8.8.5 外部排序计算题框架

遇到外部排序计算题，按以下顺序写草稿：

1. 求或数出初始归并段数量 $r$；
2. 确认是否使用置换选择；
3. 确认归并路数 $k$；
4. 计算归并趟数；
5. 若问 I/O，再计算每趟全部数据的读写；
6. 若问多路选择比较次数，判断是线性扫描、堆还是胜者/败者树。

常用式：

$$
r=\left\lceil\frac NM\right\rceil
$$

$$
p=\left\lceil\log_k r\right\rceil
$$

一趟完整归并：

$$
\text{读写量}\approx 2N
$$

树形候选更新：

$$
O(\log k)
$$

## 8.8.7 最终记忆框架

```text
简单排序
├─ 冒泡：相邻交换，尾部归位，稳定
├─ 插入：前部有序，基本有序时快，稳定
└─ 选择：每趟选最小，比较固定，不稳定

高效比较排序
├─ 希尔：增量分组，不稳定
├─ 快速：枢轴归位，平均快，最坏 n²
├─ 堆：原地，最坏 nlogn，不稳定
└─ 归并：稳定 nlogn，但需 O(n) 辅助空间

非比较/分布思想
├─ 桶：按值域
└─ 基数：按数位稳定处理

外部排序
├─ 置换选择：拉长初始归并段
├─ 多路归并：减少归并趟数
└─ 胜者/败者树：O(log k) 更新候选最小值
```
