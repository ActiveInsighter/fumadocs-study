排序题不要只背代码。408 更常从 **排序过程、复杂度、稳定性、初始序列敏感性、元素是否归位、中间序列特征** 等角度综合考查。

本章统一采用升序排序讨论，若题目要求降序，只需把比较方向相应反转。

## 8.1.1 排序的基本概念

设待排序记录为：

```text
R1, R2, ..., Rn
```

每条记录都有关键字 `key`。排序的目标是重新排列这些记录，使关键字满足非递减或非递增关系。

按数据是否能全部装入内存，可分为：

- **内部排序**：待排序记录可全部装入内存，主要关注 CPU 比较、移动和辅助空间；
- **外部排序**：数据规模超过内存容量，需要借助外存，主要瓶颈通常是磁盘 I/O。

按是否主要依赖关键字之间的比较，可分为：

- **比较排序**：插入、冒泡、选择、希尔、快速、堆、归并等；
- **分布式/非比较排序**：桶排序、计数思想、基数排序等，利用关键字值域或数位信息。

### 稳定性

若两个记录关键字相同，排序后它们的相对先后次序仍保持不变，则称排序算法 **稳定**。

例如：

```text
5₁, 3, 5₂, 1
```

排序后若仍为：

```text
1, 3, 5₁, 5₂
```

则这两个 `5` 的相对次序未改变。

> **易错点｜稳定性不是“算法好坏”**
>
> 稳定性只描述相同关键字记录的相对顺序是否保持，与时间复杂度优劣不是同一概念。

### 比较排序的下界

对仅通过关键字两两比较来区分 $n!$ 种排列的排序算法，比较决策树至少需要 $n!$ 个叶结点，因此最坏情况下比较次数至少为：

$$
\left\lceil \log_2(n!) \right\rceil
$$

由此得到比较排序的渐进下界：

$$
\Omega(n\log n)
$$

基数排序、桶排序等利用关键字值域信息，因此不直接受这一比较模型下界约束。

## 8.1.2 判断“每一趟”的典型特征

| 排序算法 | 一趟主要操作 | 一趟结束后的典型性质 |
| --- | --- | --- |
| 冒泡排序 | 相邻元素比较、交换 | 当前未排序区最大元素到达末端最终位置 |
| 简单选择排序 | 从未排序区选最小元素 | 当前最小元素进入前端最终位置 |
| 直接插入排序 | 将一个新元素插入前面的有序区 | 前若干元素内部有序，但通常未全部归位 |
| 希尔排序 | 按当前增量做分组插入 | 所有相隔 `gap` 的子序列分别有序 |
| 快速排序 | 围绕枢轴划分 | 枢轴进入最终位置，左侧不大于它、右侧不小于它 |
| 堆排序 | 堆顶与未排序区末尾交换后调整 | 当前最大元素进入末端最终位置 |
| 归并排序 | 合并相邻有序段 | 有序归并段长度逐步扩大 |
| 基数排序 | 按当前数位稳定分配、收集 | 已处理数位形成正确的相对次序 |

> **真题标签｜2012 年第 10 题：哪些排序每一趟至少确定一个元素最终位置**
>
> 重点区分：简单选择、快速、堆排序会不断产生已归位元素；希尔和二路归并的一趟通常只能保证“局部有序”。

## 8.1.3 冒泡排序

冒泡排序通过不断比较相邻元素，将较大元素逐步“冒”到右端。

一趟升序冒泡：

1. 比较 `a[0]` 与 `a[1]`；
2. 若前者更大则交换；
3. 继续比较 `a[1]` 与 `a[2]`；
4. 一直处理到当前未排序区末端；
5. 本趟结束后，未排序区最大值到达最终位置。

例如：

```text
5 1 4 2 8
```

第一趟：

```text
1 4 2 5 8
```

其中当前最大值 `8` 已在末尾。

```cpp
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        bool exchanged = false;
        for (int j = 0; j < n - i - 1; ++j) {
            if (a[j] > a[j + 1]) {
                std::swap(a[j], a[j + 1]);
                exchanged = true;
            }
        }
        if (!exchanged) break;
    }
}
```

若某一趟没有发生交换，说明整个序列已经有序，可以提前结束。

因此：

- 最好时间：$O(n)$；
- 平均时间：$O(n^2)$；
- 最坏时间：$O(n^2)$；
- 辅助空间：$O(1)$；
- 稳定。

### 冒泡排序与逆序对

一次相邻逆序元素交换会使逆序对数量恰好减少 1。因此，若使用标准相邻交换冒泡排序，则交换次数与初始序列的逆序对数量直接相关。

这也是理解“序列越接近有序，冒泡越快”的重要角度。

## 8.1.4 直接插入排序

直接插入排序把序列划分成：

```text
已排序区 | 未排序区
```

每一趟取未排序区第一个元素，把它插入前面的正确位置。

> **真题标签｜2017 年第 10 题、2020 年第 11 题、2026 年第 9 题；2022 年第 42 题：插入排序及其应用**
>
> 高频考法包括中间序列、比较/移动次数、基本有序序列、算法设计中的“维护有序区”。

```cpp
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int temp = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > temp) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = temp;
    }
}
```

### 复杂度为何取决于初始有序程度

若原序列已经有序，内层条件很快失败，每个元素只需少量比较：

$$
T_{best}(n)=O(n)
$$

若原序列完全逆序，第 $i$ 个元素插入时需要向前移动约 $i$ 个位置：

$$
1+2+\cdots+(n-1)=\frac{n(n-1)}2
$$

因此：

$$
T_{worst}(n)=O(n^2)
$$

直接插入排序：

- 对**基本有序**序列很有优势；
- 辅助空间 $O(1)$；
- 稳定。

> **关键区分｜插入排序的“有序区”没有全部归位**
>
> 前部元素只是相互之间有序，以后遇到更小的新元素时仍可能整体右移。

## 8.1.5 折半插入排序

直接插入排序寻找插入位置时从后向前逐个比较。由于前部已经有序，因此可以使用折半查找定位插入位置。

折半插入排序的改进点是：

- **减少关键字比较次数**；
- 但找到插入位置后，仍要移动一段元素。

因此总体时间复杂度仍为：

$$
O(n^2)
$$

> **易错点｜折半插入不是 $O(n\log n)$ 排序**
>
> 折半只优化“找位置”，没有消除最坏情况下的大量元素移动。

为了保持稳定性，若待插入关键字与已有元素相等，应把新记录插在已有相等记录之后。

## 8.1.6 简单选择排序

简单选择排序每一趟都从未排序区中找出最小元素，与未排序区第一个位置交换。

```cpp
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int minPos = i;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[minPos]) minPos = j;
        }
        if (minPos != i) std::swap(a[i], a[minPos]);
    }
}
```

无论输入是否已有序，比较次数都是：

$$
(n-1)+(n-2)+\cdots+1
=\frac{n(n-1)}2
$$

因此最好、平均、最坏时间均为：

$$
\Theta(n^2)
$$

但交换次数最多只有 $O(n)$。

简单选择排序不稳定。例如：

```text
5₁, 5₂, 2
```

第一趟选择 `2` 与 `5₁` 交换后：

```text
2, 5₂, 5₁
```

两个相等关键字的相对次序发生改变。

## 8.1.7 三种简单排序对比

| 指标 | 冒泡排序 | 直接插入排序 | 简单选择排序 |
| --- | --- | --- | --- |
| 核心操作 | 相邻交换 | 插入已有序区 | 选择最小值 |
| 最好时间 | $O(n)$ | $O(n)$ | $\Theta(n^2)$ |
| 最坏时间 | $O(n^2)$ | $O(n^2)$ | $\Theta(n^2)$ |
| 辅助空间 | $O(1)$ | $O(1)$ | $O(1)$ |
| 稳定性 | 稳定 | 稳定 | 不稳定 |
| 对初始有序程度敏感 | 是 | 是 | 否（比较次数固定） |
| 一趟后有最终归位元素 | 是 | 通常没有 | 是 |

### 元素“移动次数”题的计数口径

题目若问移动次数，先看是否明确把：

```cpp
swap(a, b)
```

记为 1 次交换，还是拆成若干次赋值。不同题目口径可能不同，不能只背一个数字公式。

从数量级上看：

- 冒泡：最坏交换/移动为 $O(n^2)$；
- 插入：最坏移动为 $O(n^2)$；
- 选择：比较始终为 $\Theta(n^2)$，但交换最多 $O(n)$。
