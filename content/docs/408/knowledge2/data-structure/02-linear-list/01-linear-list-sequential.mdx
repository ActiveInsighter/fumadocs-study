线性表是数据结构中最基础的线性结构之一。它描述元素之间的**一对一前驱—后继关系**。

顺序表和链表具有相同的逻辑结构，但采用不同的物理存储方式，因此它们在**随机访问、插入删除、空间开销和缓存局部性**等方面存在明显差异。

<InlineSvg src="/images/data-structure/data-structure-linearlist-001.svg" alt={"线性表及其顺序存储与链式存储"} />

| 存储方式 | 核心特点       | 按位访问   | 插入、删除            | 额外空间  |
| ---- | ---------- | ------ | ---------------- | ----- |
| 顺序表  | 元素连续存储     | `O(1)` | 通常 `O(n)`        | 较少    |
| 链表   | 通过指针建立逻辑关系 | `O(n)` | 已知操作位置后通常 `O(1)` | 需要指针域 |

> **408 复习重点**
>
> 线性表本身的定义通常不是难点。真正需要重点掌握的是：
>
> * 顺序表的插入、删除和复杂度；
> * 单链表中指针的修改顺序；
> * 头结点、头指针、首元结点的区别；
> * 双向链表和循环链表；
> * 链表算法设计，如逆置、倒数第 \(k\) 个结点、公共结点等。
>
> 特别注意：所谓“链表插入、删除是 `O(1)`”通常有一个重要前提——**已经找到了相关结点或前驱结点**。如果还需要从头查找位置，总复杂度仍可能是 `O(n)`。

## 1. 线性表的定义与基本操作

### 1.1 线性表的定义

<InlineSvg src="/images/data-structure/data-structure-linearlist-def-001.svg" alt={"线性表 Linear List L = (a₁, a₂, a₃, ..., aᵢ, aᵢ₊₁, ..., aₙ) a₁ a₂ a₃ ... aᵢ aᵢ₊₁ ... aₙ 当前元素 前驱 后继 线性表特点： 个数有限： 表中元素个数是确定的有限值 类型相同： 所有元素数据类型一致，占用相同存储空间 逻辑有序： 元素间存在先后顺序，有前驱和后继关系"} />

**线性表（Linear List）**是由**零个或多个具有相同数据类型的数据元素组成的有限序列**。

记为：

$$
L=(a_1,a_2,\ldots,a_i,a_{i+1},\ldots,a_n)
$$

其中：

* \(n\) 为线性表的长度；
* 当 \(n=0\) 时，称为空表；
* \(a_1\) 是第一个数据元素；
* \(a_n\) 是最后一个数据元素。

在线性表中：

* \(a_1\) 没有前驱；
* \(a_n\) 没有后继；
* 对于中间元素 \(a_i\)，其直接前驱为 \(a_{i-1}\)，直接后继为 \(a_{i+1}\)。

线性表具有三个基本特征：

1. **元素个数有限**；
2. **元素数据类型相同**；
3. **元素之间存在确定的逻辑次序**。

这里讨论的是元素之间的**逻辑关系**，并不要求它们在物理内存中一定连续。

---

### 1.2 顺序表与链表

线性表可以采用两类典型存储方式：

* **顺序存储**：形成顺序表；
* **链式存储**：形成链表。

<InlineSvg src="/images/data-structure/data-structure-linearlist-def-002.svg" alt={"1 2 3 4 5 1 3 2 物 理 地 址 逐 渐 增 大 顺序表 链表 5 4 物 理 地 址 逐 渐 增 大"} />

#### 顺序表

顺序表要求元素存储在一段**地址连续的存储区域**中。

因此：

* 逻辑上相邻的元素在物理上也相邻；
* 可以根据首地址和元素下标直接计算地址；
* 支持随机访问。

#### 链表

链表的结点通过指针或游标保存后继关系。

因此：

* 逻辑上相邻的结点在物理地址上不要求连续；
* 通常不能通过下标直接定位某个结点；
* 插入、删除时无需像顺序表一样整体移动大量元素。

> **易错点：存储结构与“栈区 / 堆区”没有必然联系**
>
> 顺序表的定义依据是**元素地址连续**，链表的定义依据是**通过链接信息维护逻辑关系**。
>
> 顺序表既可以位于栈区，也可以位于堆区或静态存储区；链表结点也不一定必须通过 `malloc` 动态申请。

### 1.3 线性表的抽象操作

<InlineSvg src="/images/data-structure/data-structure-linearlist-def-003.svg" alt={"图示"} />

常见基本操作如下。

| 操作           | 含义           |
| ------------ | ------------ |
| `InitList`   | 初始化一个空线性表    |
| `Insert`     | 在指定位置插入新元素   |
| `Delete`     | 删除指定位置的元素    |
| `LocateElem` | 根据元素值或条件查找元素 |
| `GetElem`    | 获取指定逻辑位置上的元素 |
| `SetElem`    | 修改指定位置元素的值   |
| `Length`     | 返回线性表长度      |
| `IsEmpty`    | 判断线性表是否为空    |
| `ClearList`  | 清空线性表        |
| `Traverse`   | 按顺序访问所有元素    |

这些都是**逻辑层面的操作**。顺序表和链表会采用完全不同的底层实现。

## 2. 顺序表

### 2.1 顺序表的存储结构

**顺序表（Sequential List）**使用一段连续的存储空间依次保存线性表中的数据元素。

假设：

* 顺序表首地址为 `LOC(A)`；
* 每个元素占用的空间为 `sizeof(Elem)`；
* \(a_i\) 是第 \(i\) 个数据元素。

则 \(a_i\) 的地址为：

$$
LOC(a_i)=LOC(A)+(i-1)\times sizeof(Elem)
$$

<InlineSvg src="/images/data-structure/data-structure-linearlist-sequential-001.svg" alt={"a 1 a i a 2 a n Sequential List A Index 0 1 i-1 n-1 Memory Address LOC(A) LOC(A) + sizeof(Elem) LOC(A) + (i-1) x sizeof(Elem) Maxsize - 1 LOC(A) + (n-1) x sizeof(Elem) LOC(A) + (Maxsize-1) x sizeof(Elem)"} />

这就是顺序表可以进行**随机访问**的根本原因。

只要知道：

* 首地址；
* 元素大小；
* 下标；

就可以直接计算目标元素的地址，而不需要逐个访问前面的元素。

---

### 2.2 顺序表的特点

#### 优点

* **随机访问效率高**：按位置访问为 `O(1)`；
* **存储密度高**：不需要额外保存指针；
* **空间局部性好**：相邻元素物理地址连续，有利于 CPU Cache；
* **结构简单**：操作时无需维护指针关系。

#### 缺点

* **插入和删除可能需要移动大量元素**；
* 静态数组需要提前确定最大容量；
* 动态扩容时可能需要重新分配空间并复制数据；
* 若预留空间过大，会造成空间浪费。

---

### 2.3 顺序表的定义与初始化

下面使用固定长度数组实现顺序表：

```c
#define MAXSIZE 100

typedef struct {
    ElementType data[MAXSIZE];
    int length;
} SeqList;
```

其中：

* `data` 保存数据元素；
* `length` 保存当前有效元素个数；
* `MAXSIZE` 表示顺序表最大容量。

初始化：

```c
void InitList(SeqList *L) {
    L->length = 0;
}
```

<InlineSvg src="/images/data-structure/data-structure-linearlist-sequential-002.svg" alt={"图示"} />

> **逻辑位置与数组下标**
>
> 408 题目通常将线性表的第一个元素称为“第 1 个元素”，即逻辑位置从 1 开始。
>
> C 数组下标从 0 开始，因此：
>
> * 第 1 个元素对应 `data[0]`；
> * 第 `pos` 个元素对应 `data[pos - 1]`。
>
> 这是顺序表代码中最容易出现的下标错误之一。

---

### 2.4 顺序表的插入

若要在第 `pos` 个位置插入新元素 `e`，原来从该位置开始的元素都需要向后移动一位。

<InlineSvg src="/images/data-structure/data-structure-linearlist-sequential-003.svg" alt={"顺序表插入过程图解：在位置 3 插入元素 99 步骤1：初始状态 10 20 30 40 50 1 2 3 4 5 6 7 length = 5 插入位置 pos=3 步骤2：从尾部开始，向后移动元素 10 20 30 40 50 50 移动 10 20 30 40 40 50 移动 10 20 30 30 40 50 移动 步骤3：插入新元素并更新长度 10 20 99 30 40 50 新元素 99 length = 6 关键要点： 1. 检查插入位置合法性：1 ≤ po"} />

```c
bool Insert(SeqList *L, int pos, ElementType e) {
    if (L->length == MAXSIZE ||
        pos < 1 ||
        pos > L->length + 1) {
        return false;
    }

    for (int i = L->length; i >= pos; --i) {
        L->data[i] = L->data[i - 1];
    }

    L->data[pos - 1] = e;
    ++L->length;

    return true;
}
```

#### 插入位置是否合法

长度为 \(n\) 的顺序表共有 \(n+1\) 个合法插入位置：

$$
1\leq pos\leq n+1
$$

例如一个长度为 5 的顺序表，可以：

* 在第 1 个位置插入；
* 在第 6 个位置插入，即尾插。

#### 元素移动次数

若在第 \(i\) 个位置插入，需要移动：

$$
n-i+1
$$

个元素。

因此：

| 情况   |      移动次数 | 时间复杂度  |
| ---- | --------: | ------ |
| 尾部插入 |         0 | `O(1)` |
| 头部插入 |     \(n\) | `O(n)` |
| 平均情况 | 约 \(n/2\) | `O(n)` |

> **易错点**
>
> 元素一定要**从后向前移动**。
>
> 如果从前向后移动，尚未保存的元素可能会被后面的赋值覆盖。

---

### 2.5 顺序表的删除

删除第 `pos` 个元素后，需要将后面的元素全部向前移动一位。

<InlineSvg src="/images/data-structure/data-structure-linearlist-sequential-004.svg" alt={"图示"} />

```c
bool Delete(SeqList *L, int pos, ElementType *e) {
    if (pos < 1 || pos > L->length) {
        return false;
    }

    *e = L->data[pos - 1];

    for (int i = pos; i < L->length; ++i) {
        L->data[i - 1] = L->data[i];
    }

    --L->length;

    return true;
}
```

合法删除位置满足：

$$
1\leq pos\leq n
$$

若删除第 \(i\) 个元素，需要移动：

$$
n-i
$$

个元素。

| 情况       |          移动次数 | 时间复杂度  |
| -------- | ------------: | ------ |
| 删除最后一个元素 |             0 | `O(1)` |
| 删除第一个元素  |       \(n-1\) | `O(n)` |
| 平均情况     | 约 \((n-1)/2\) | `O(n)` |

---

### 2.6 顺序表的查找

#### 按值查找

在线性表中顺序扫描，寻找第一个值等于 `e` 的元素：

```c
int LocateElem(SeqList L, ElementType e) {
    for (int i = 0; i < L.length; ++i) {
        if (L.data[i] == e) {
            return i + 1;
        }
    }

    return 0;
}
```

时间复杂度为 `O(n)`。

#### 按位查找

顺序表支持随机访问，因此获取第 `pos` 个元素不需要遍历：

```c
bool GetElem(SeqList L, int pos, ElementType *e) {
    if (pos < 1 || pos > L.length) {
        return false;
    }

    *e = L.data[pos - 1];
    return true;
}
```

时间复杂度为 `O(1)`。

> **408 高频区分**
>
> * **按位查找**：已知“第几个元素”，顺序表为 `O(1)`；
> * **按值查找**：已知元素值，需要扫描，普通顺序表为 `O(n)`。
>
> “顺序表支持随机访问”并不意味着“所有查找都是 `O(1)`”。

---

### 2.7 其他基本操作

#### 判空

```c
bool IsEmpty(SeqList L) {
    return L.length == 0;
}
```

#### 清空

```c
void ClearList(SeqList *L) {
    L->length = 0;
}
```

对于固定数组实现，只需要将有效长度置为 0。

数组中的旧内容可能仍存在于物理存储中，但从线性表的逻辑意义上已经不存在。

#### 获取长度

```c
int Length(SeqList L) {
    return L.length;
}
```

### 2.8 顺序表复杂度总结

| 操作     | 时间复杂度  |
| ------ | ------ |
| 按位访问   | `O(1)` |
| 按值查找   | `O(n)` |
| 头部插入   | `O(n)` |
| 尾部插入   | `O(1)` |
| 一般位置插入 | `O(n)` |
| 删除尾元素  | `O(1)` |
| 删除一般位置 | `O(n)` |
| 求长度    | `O(1)` |
