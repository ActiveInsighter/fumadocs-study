## 3. 链表

### 3.1 链式存储的基本思想

线性表的**链式表示**通过一组结点保存数据。

每个结点不仅保存数据，还保存用于表示逻辑关系的链接信息。

对于单链表，每个结点包括：

* 数据域 `data`；
* 后继指针域 `next`。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-001.svg" alt={"a 1 a 2 a n Linked List L header node NULL"} />

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-002.svg" alt={"data next"} />

单链表最重要的特征是：

> **结点之间通过指针建立逻辑关系，物理地址不要求连续。**

链表结点在实际程序中经常通过 `malloc` 或 `new` 动态申请，但这不是链表的定义条件。结点也可以来自静态数组、对象池或其他存储管理机制。

---

### 3.2 链表的优缺点

#### 优点

* 不要求整体连续的存储空间；
* 表长可以灵活变化；
* 已知相关结点后，插入和删除通常只需要修改指针；
* 不需要像顺序表一样移动大量元素。

#### 缺点

* 不支持真正的随机访问；
* 查找第 \(i\) 个结点通常需要从前向后遍历；
* 每个结点需要额外保存指针；
* 结点物理位置通常较分散，缓存局部性往往不如连续数组。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-003.svg" alt={"图示"} />

连续数组中相邻元素地址相邻，因此顺序访问通常具有较好的空间局部性。

链表结点则可能分散在不同位置，访问下一个结点需要根据指针取得其地址。

> **易错点**
>
> “数组一定在栈上、链表一定在堆上”是错误的。
>
> 数组可以动态申请到堆中，链表也可以使用静态数组模拟。
>
> 判断顺序存储和链式存储的依据是**元素之间如何建立物理和逻辑关系**，而不是变量位于哪个内存区域。

## 4. 单链表

### 4.1 单链表结点定义

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-004.svg" alt={"图示"} />

其中：

* `data` 保存数据；
* `next` 保存下一个结点的地址。

`data` 的类型可以根据需要换成其他类型。

例如：

```c
typedef struct Node {
    ElementType data;
    struct Node *next;
} Node;
```

---

### 4.2 头指针、头结点和首元结点

这是 408 中非常容易混淆的一组概念。

假设链表采用带头结点的形式：

```text
head
 ↓
[头结点] → [a1] → [a2] → ... → NULL
```

#### 头指针

`head` 是指向链表起始位置的指针。

#### 头结点

人为增加在第一个数据结点之前的辅助结点。

通常不保存有效数据。

#### 首元结点

真正保存线性表第一个数据元素 \(a_1\) 的结点。

采用头结点后：

```c
head->next
```

才指向首元结点。

引入头结点的主要作用是：

* 统一空表和非空表的操作；
* 统一首元结点和其他结点的插入、删除处理；
* 减少特殊情况判断。

---

### 4.3 初始化

创建一个带头结点的空单链表：

```c
Node *InitList(void) {
    Node *head = (Node *)malloc(sizeof(Node));

    if (head == NULL) {
        exit(1);
    }

    head->next = NULL;

    return head;
}
```

空表结构为：

```text
head
 ↓
[头结点] → NULL
```

---

### 4.4 判空

```c
bool IsEmpty(Node *head) {
    return head->next == NULL;
}
```

注意：

```c
head == NULL
```

和

```c
head->next == NULL
```

含义不同。

对于已经正常初始化的带头结点链表：

* `head == NULL` 通常表示头指针本身无效；
* `head->next == NULL` 才表示线性表为空。

## 5. 单链表的插入

### 5.1 在结点后插入

假设：

* `p` 指向某个已有结点；
* `s` 指向待插入的新结点。

希望将 `s` 插入 `p` 之后。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-005.svg" alt={"p q p q n p q n"} />

原结构：

```text
p → q
```

插入后：

```text
p → s → q
```

核心代码：

```c
void InsertNodeAfter(Node *p, Node *s) {
    s->next = p->next;
    p->next = s;
}
```

> **必须掌握指针修改顺序**
>
> 应先执行：
>
> ```c
> s->next = p->next;
> ```
>
> 再执行：
>
> ```c
> p->next = s;
> ```
>
> 如果先把 `p->next` 修改为 `s`，原来的后继结点地址可能丢失。

如果直接插入一个值：

```c
bool InsertValueAfter(Node *p, int value) {
    Node *s = (Node *)malloc(sizeof(Node));

    if (s == NULL) {
        return false;
    }

    s->data = value;
    s->next = p->next;
    p->next = s;

    return true;
}
```

已知 `p` 后插的核心操作只修改常数个指针，因此为 `O(1)`。

---

### 5.2 头插

带头结点时，在首元结点之前插入，本质上就是在头结点后插入：

```c
bool InsertAtHead(Node *head, int value) {
    return InsertValueAfter(head, value);
}
```

单次头插为 `O(1)`。

如果不断读取新元素并使用头插法建立链表，则最终元素顺序通常与输入顺序**相反**。

---

### 5.3 尾插

如果没有维护尾指针，需要先遍历到尾结点：

```c
bool InsertAtTail(Node *head, int value) {
    Node *tail = head;

    while (tail->next != NULL) {
        tail = tail->next;
    }

    return InsertValueAfter(tail, value);
}
```

寻找尾结点需要 `O(n)`。

因此不维护尾指针时，单次尾插整体为 `O(n)`。

如果额外维护：

```c
Node *tail;
```

则尾插可以做到 `O(1)`。

---

### 5.4 按位置插入

在第 `pos` 个数据位置插入：

```c
bool InsertAtPos(Node *head, int pos, int value) {
    if (pos < 1) {
        return false;
    }

    Node *p = head;
    int i = 0;

    while (p != NULL && i < pos - 1) {
        p = p->next;
        ++i;
    }

    if (p == NULL) {
        return false;
    }

    Node *s = (Node *)malloc(sizeof(Node));

    if (s == NULL) {
        return false;
    }

    s->data = value;
    s->next = p->next;
    p->next = s;

    return true;
}
```

虽然实际插入只需要修改两个指针，但查找第 `pos-1` 个结点需要遍历。

因此按位置插入总体通常是 `O(n)`。

> **核心结论**
>
> * 已知前驱结点：插入 `O(1)`；
> * 只知道逻辑位置：通常需要先查找，总体 `O(n)`。

## 6. 单链表的删除

### 6.1 删除某结点的后继结点

假设 `p` 指向已有结点，希望删除 `p` 的直接后继 `q`。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-006.svg" alt={"p q p q p p→next ≠ NULL 时 p→next = q→next free(q);"} />

```c
bool DeleteAfter(Node *p) {
    Node *q = p->next;

    if (q == NULL) {
        return false;
    }

    p->next = q->next;
    free(q);

    return true;
}
```

已知前驱结点 `p` 后，删除为 `O(1)`。

---

### 6.2 删除第 pos 个结点

删除第 `pos` 个数据结点，需要先找到其前驱结点。

```c
bool DeleteAtPos(Node *head, int pos, int *value) {
    if (pos < 1) {
        return false;
    }

    Node *p = head;
    int i = 0;

    while (p->next != NULL && i < pos - 1) {
        p = p->next;
        ++i;
    }

    if (p->next == NULL) {
        return false;
    }

    Node *q = p->next;

    if (value != NULL) {
        *value = q->data;
    }

    p->next = q->next;
    free(q);

    return true;
}
```

复杂度：

* 找前驱：`O(n)`；
* 修改指针和释放结点：`O(1)`；
* 总体：`O(n)`。

## 7. 单链表的查找、遍历与清空

### 7.1 按值查找

```c
int LocateElem(Node *head, int value) {
    Node *p = head->next;
    int pos = 1;

    while (p != NULL) {
        if (p->data == value) {
            return pos;
        }

        p = p->next;
        ++pos;
    }

    return 0;
}
```

时间复杂度为 `O(n)`。

---

### 7.2 按位查找

链表无法根据下标直接计算目标结点地址。

查找第 `pos` 个数据结点必须从前向后遍历：

```c
Node *GetElem(Node *head, int pos) {
    if (pos < 1) {
        return NULL;
    }

    Node *p = head->next;
    int i = 1;

    while (p != NULL && i < pos) {
        p = p->next;
        ++i;
    }

    return p;
}
```

时间复杂度为 `O(n)`。

因此：

> **链表不支持随机访问。**

---

### 7.3 清空单链表

需要逐个释放数据结点。

```c
void ClearList(Node *head) {
    Node *p = head->next;
    Node *q;

    head->next = NULL;

    while (p != NULL) {
        q = p->next;
        free(p);
        p = q;
    }
}
```

这里必须先保存：

```c
q = p->next;
```

然后才能：

```c
free(p);
```

否则释放 `p` 后再访问 `p->next` 属于非法访问。

## 8. 双向链表

单链表只能方便地访问后继结点。

如果经常需要访问前驱，可以在每个结点中增加一个前驱指针。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-007.svg" alt={"^ a1 a2 a3 prev data next head DNode"} />

双向链表结点：

```c
typedef struct DNode {
    ElementType data;
    struct DNode *prev;
    struct DNode *next;
} DNode;
```

每个结点包含：

* 数据域 `data`；
* 前驱指针 `prev`；
* 后继指针 `next`。

---

### 8.1 双向链表的特点

优点：

* 可以向前遍历；
* 可以向后遍历；
* 已知某结点后，可以直接获得其前驱；
* 删除当前结点时，不需要再从头寻找其前驱。

缺点：

* 每个结点需要额外保存一个指针；
* 插入和删除时需要维护更多链接关系。

---

### 8.2 在结点 p 前插入 s

原来：

```text
... ⇄ pre ⇄ p ⇄ ...
```

插入后：

```text
... ⇄ pre ⇄ s ⇄ p ⇄ ...
```

代码：

```c
s->prev = p->prev;
s->next = p;
p->prev->next = s;
p->prev = s;
```

四个链接关系都必须维护正确。

可以理解为：

1. `s` 找到自己的前驱；
2. `s` 找到自己的后继；
3. 原前驱指向 `s`；
4. `p` 的前驱改为 `s`。

---

### 8.3 删除结点 p

原来：

```text
... ⇄ prev ⇄ p ⇄ next ⇄ ...
```

删除后：

```text
... ⇄ prev ⇄ next ⇄ ...
```

核心代码：

```c
p->prev->next = p->next;
p->next->prev = p->prev;
free(p);
```

若链表没有使用特殊的头尾哨兵结点，还应注意首结点、尾结点等边界条件。

> **易错点**
>
> 双向链表修改某一方向的指针后，通常还需要同步修改反方向的指针。
>
> 只修改 `next` 而忘记修改 `prev` 会破坏双向链表结构。

## 9. 循环链表

**循环链表（Circular Linked List）**是一类首尾相接的链表。

其核心特点是：

> 链表尾部不再以普通的 `NULL` 作为唯一结束形式，而是通过指针重新连接到链表前部。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-009.svg" alt={"a 1 a 2 a n head a 2 a 1 a 3 ^ head 循环单链表 循环双链表"} />

循环链表可以分为：

| 类型     | 特点               |
| ------ | ---------------- |
| 单向循环链表 | 尾结点的 `next` 指向头部 |
| 双向循环链表 | 首尾双向连接，可以双向循环    |

---

### 9.1 循环单链表

若采用带头结点的循环单链表，常见结构为：

```text
head → a1 → a2 → ... → an
 ↑                    ↓
 └────────────────────┘
```

此时尾结点满足：

```c
tail->next == head
```

而不是：

```c
tail->next == NULL
```

因此遍历时不能继续使用普通单链表的：

```c
while (p != NULL)
```

而应该根据具体结构判断是否重新回到头结点。

例如：

```c
Node *p = head->next;

while (p != head) {
    /* 处理 p */
    p = p->next;
}
```

---

### 9.2 循环双链表

循环双链表通常满足：

```c
head->next->prev == head;
head->prev->next == head;
```

若为空表并采用头结点，则常见初始化形式为：

```c
head->next = head;
head->prev = head;
```

因此判空可以写为：

```c
head->next == head
```

循环双链表可以从任意结点向前或向后不断移动。

## 10. 静态链表

**静态链表**使用数组来模拟链式结构。

<InlineSvg src="/images/data-structure/data-structure-linearlist-linked-008.svg" alt={"2 b 5 a 1 d -1 c 3 0 1 2 3 4 5 6 静态链表示例 a b c d ^ 对应的单链表"} />

结点定义：

```c
#define MAXSIZE 100

typedef struct {
    ElementType data;
    int next;
} SNode;

SNode list[MAXSIZE];
```

其中：

* `data` 保存数据；
* `next` 不再保存真实内存地址；
* `next` 保存**下一个结点在数组中的下标**。

因此 `next` 又称为**游标**。

例如：

```text
下标 2 的结点：
next = 5
```

表示其逻辑后继位于：

```c
list[5]
```

资料中使用：

```text
next == -1
```

表示链表结束。

---

### 10.1 静态链表的本质

静态链表：

* 物理上使用数组；
* 逻辑上按照链表方式连接。

因此修改逻辑关系时只需要修改游标，而不需要像普通顺序表一样移动大量元素。

其主要意义在于：

> 在不适合或不允许使用真实指针的环境中，用数组下标模拟链式结构。
