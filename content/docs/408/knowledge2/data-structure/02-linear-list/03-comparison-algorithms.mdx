学完顺序表和各种链表后，真正需要建立的是一套**选择结构与分析复杂度的统一框架**。

## 17. 顺序表与链表综合比较

### 17.1 核心对比

| 比较项 | 顺序表 | 单链表 |
| --- | --- | --- |
| 物理存储 | 连续 | 不要求连续 |
| 逻辑关系表示 | 物理次序直接体现 | `next` 链接体现 |
| 按位访问 | $O(1)$ | $O(n)$ |
| 按值查找 | $O(n)$ | $O(n)$ |
| 已知相关结点后的插入 | 仍可能需要移动元素 | 通常 $O(1)$ |
| 已知前驱后的删除 | 仍可能需要移动元素 | $O(1)$ |
| 按逻辑位置插入 | $O(n)$ | $O(n)$ |
| 按逻辑位置删除 | $O(n)$ | $O(n)$ |
| 空间局部性 | 通常较好 | 通常较差 |
| 每元素链接开销 | 无 | 有指针域 |
| 容量扩展 | 可能重新分配、搬移 | 较灵活 |
| 空间浪费来源 | 预留容量 | 指针域、分配开销 |

### 17.2 如何选择

通常可按访问模式判断：

- **大量随机访问**：优先考虑顺序表；
- **频繁在已知结点附近插入、删除**：链表更合适；
- **数据规模固定、结构简单**：顺序表方便；
- **规模变化明显且难以预估**：链表更灵活；
- **实际运行性能**还要考虑缓存局部性、内存分配和数据规模，不能只看渐进复杂度。

<Callout type="info" title="复杂度判断的关键前提">
看到“链表插入/删除是 $O(1)$”时，必须检查题目是否已经给出目标结点或前驱结点。若还需要从表头寻找位置，总复杂度通常仍为 $O(n)$。
</Callout>

## 18. 408 高频易错点

### 18.1 “链表插入、删除一定是 $O(1)$”——错误

例如：

> 在单链表的第 $i$ 个位置插入元素。

必须先找到第 $i-1$ 个结点，因此：

$$
O(n)+O(1)=O(n)
$$

### 18.2 “顺序表随机访问 $O(1)$，所以查值也是 $O(1)$”——错误

- 已知位置求元素：$O(1)$；
- 已知值找位置：普通顺序表通常 $O(n)$。

### 18.3 头结点不等于首元结点

```text
head -> [头结点] -> [a1] -> [a2] -> ...
```

因此：

```c
head->next
```

才是首元结点。

### 18.4 插入时不能覆盖仍需使用的旧后继

正确：

```c
s->next = p->next;
p->next = s;
```

核心原则：

> **覆盖一个指针之前，先保存它指向的旧结点。**

### 18.5 释放结点后不能再通过它访问后继

正确：

```c
q = p->next;
free(p);
p = q;
```

错误：

```c
free(p);
p = p->next;
```

后者访问了已释放对象。

### 18.6 循环链表不能机械使用 `NULL` 作为遍历终点

普通单链表常见：

```c
while (p != NULL)
```

循环单链表则常根据具体定义判断：

```c
p != head
```

或是否重新回到起始结点。

### 18.7 顺序表/链表与栈区/堆区不是定义关系

不能写成：

```text
顺序表一定在栈上。
链表一定在堆上。
```

真正的区分是：

```text
顺序表：数据元素连续存储。
链表：通过链接信息表达逻辑次序。
```

### 18.8 双向链表的“已知结点删除”与单链表不同

双向链表中的当前结点 `p` 自带 `prev`，因此在边界条件已处理的前提下可直接：

```c
p->prev->next = p->next;
p->next->prev = p->prev;
```

而单链表只给出 `p` 时通常无法直接取得其前驱。

## 19. 链表算法设计高频模型

链表是 408 算法设计题的重要载体。常见限制包括：

- 要求 $O(n)$ 时间；
- 要求 $O(1)$ 辅助空间；
- 不允许把所有结点地址额外存入数组；
- 需要在原链表上重新链接。

遇到链表算法题，优先考虑：

```text
快慢指针
长度对齐
原地逆置
头插/尾插
拆分 + 逆置 + 交叉合并
```

### 19.1 单链表原地逆置

原链表：

```text
head -> a1 -> a2 -> a3 -> NULL
```

逆置后：

```text
head -> a3 -> a2 -> a1 -> NULL
```

迭代实现：

```c
void Reverse(Node *head) {
    Node *prev = NULL;
    Node *p = head->next;

    while (p != NULL) {
        Node *next = p->next; // 先保存后继
        p->next = prev;       // 当前结点反向
        prev = p;             // prev 前进
        p = next;             // p 前进
    }

    head->next = prev;
}
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

记忆主线：

```text
保存后继 -> 反转当前指针 -> 两个工作指针前进
```

### 19.2 查找倒数第 $k$ 个结点

使用快慢指针，使两个指针始终保持固定距离。

一种常用写法：

1. `fast` 与 `slow` 都从首元结点出发；
2. `fast` 先前进 $k$ 步；
3. 若不足 $k$ 步即遇到 `NULL`，说明 $k$ 越界；
4. 两指针同步前进；
5. `fast == NULL` 时，`slow` 指向倒数第 $k$ 个结点。

```c
Node *FindKthFromEnd(Node *head, int k) {
    if (head == NULL || k <= 0) return NULL;

    Node *fast = head->next;
    Node *slow = head->next;

    for (int i = 0; i < k; ++i) {
        if (fast == NULL) return NULL;
        fast = fast->next;
    }

    while (fast != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    return slow;
}
```

复杂度：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

> **真题标签**
>
> 2009 年第 42 题是经典的“倒数第 $k$ 个结点”问题，核心就是一次扫描中的双指针间距控制。

### 19.3 两个无环单链表的第一个公共结点

若两个无环单链表相交，从第一个公共结点开始，后续结点必然完全共享：

```text
A: a1 -> a2 ------\
                   -> c1 -> c2 -> NULL
B: b1 -> b2 -> b3 /
```

不可能“相交后再分叉”，因为一个单链表结点只有一个 `next`。

**方法一：长度对齐。**

1. 求两个链表长度 $m,n$；
2. 长链先走 $|m-n|$ 步；
3. 两指针同步前进；
4. 第一次满足 `pa == pb` 的结点就是第一个公共结点。

关键：比较的是**结点地址**，不是数据域的值。

复杂度：

$$
T(m,n)=O(m+n),\qquad S(m,n)=O(1)
$$

> **真题标签**
>
> 2012 年第 42 题考查两个单链表共享后缀/寻找公共结点。

### 19.4 绝对值去重：用值域换时间

若链表中数据的绝对值范围较小，可以使用辅助标记数组记录某个绝对值是否已经出现。

思路：

```text
扫描链表
  ↓
取 abs(data)
  ↓
未出现：标记并保留
已出现：删除当前结点
```

若值域上界为 $M$，则通常：

$$
T(n)=O(n),\qquad S(M)=O(M)
$$

> **真题标签**
>
> 2015 年第 41 题考查链表按绝对值去重，典型思路是使用辅助标记结构换取线性时间。

### 19.5 链表重排：拆分 + 逆置 + 交叉合并

目标形态：

$$
L=(a_1,a_2,\ldots,a_n)
$$

重排为：

$$
L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots)
$$

高效做法：

```text
① 快慢指针找到中点
② 将后半段断开
③ 原地逆置后半段
④ 前半段与逆置后的后半段交叉合并
```

每个阶段都只需线性时间，且只使用常数个指针：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

> **真题标签**
>
> 2019 年第 41 题是这一模型的代表题。若每次都从头寻找“最后一个结点”，会退化为 $O(n^2)$；先逆置后半段可将整体优化为 $O(n)$。

### 20.2 结构总览

```text
线性表
|
|-- 顺序存储：顺序表
|   |-- 连续地址

|   |-- 插入通常需要后移

|
`-- 链式存储：链表
    |-- 单链表
    |   |-- 头结点
    |   |-- 插入 / 删除
    |   `-- 查找 / 遍历
    |
    |-- 双向链表
    |   |-- prev
    |   `-- next
    |
    |-- 循环链表
    |   `-- 首尾形成环
    |
    `-- 静态链表
        `-- 数组 + 游标
```

<Callout type="info" title="本章最终目标">
不要把线性表复习成一堆孤立代码。真正掌握的标志是：看到一个操作后，能立刻判断**需要先找什么、会改哪些位置、是否会丢链接、总复杂度是多少**。
</Callout>
