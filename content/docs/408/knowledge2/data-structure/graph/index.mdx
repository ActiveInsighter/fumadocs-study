图用于描述多对多关系。408 中需要同时掌握**邻接矩阵/邻接表等表示方式**和建立在这些表示之上的经典算法。

<InlineSvg src="/images/data-structure/data-structure-graph-001.svg" alt={"图结构与经典算法概览"} />

| 内容 | 重点 |
| --- | --- |
| [图的定义和存储](/docs/408/knowledge2/data-structure/graph/defs/) | 顶点/边、连通性、度、邻接矩阵、邻接表、十字链表等 |
| [图的基本算法](/docs/408/knowledge2/data-structure/graph/operation/) | DFS/BFS、MST、最短路、拓扑排序、关键路径 |

> **复习提示：** 每个图算法都要先明确适用条件，例如 Dijkstra 要求边权非负，MST 针对连通无向带权图，拓扑排序针对 DAG。
