固定入栈顺序下的出栈序列，是栈最经典的综合题型之一。它把“LIFO”从定义题升级成了**过程模拟与计数问题**。

本节先解决“某个序列是否合法”，再解决“合法序列一共有多少个”，最后汇总本章最容易错的公式与判断。

---

## 3.5.1 固定入栈顺序意味着什么

设元素按固定顺序：

```text
1, 2, 3, ..., n
```

依次具备入栈资格。

每个元素只能：

- 按这个顺序入栈；
- 在到达栈顶后出栈。

入栈与出栈可以交替进行。

例如入栈顺序：

```text
1, 2, 3
```

以下过程合法：

```text
push 1
push 2
pop  2
push 3
pop  3
pop  1
```

得到出栈序列：

```text
2, 3, 1
```

> **真题标签｜2009、2010、2011、2013、2015、2017、2018、2020、2022：出栈序列判断与栈容量**
>
> 高频题型包括：判断某个序列是否可能出现、确定某个目标序列所需最小栈容量、加入“不能连续出栈若干次”等额外约束。

---

## 3.5.2 合法出栈序列的核心限制

任何时刻：

> **只能弹出当前栈顶元素。**

若元素 `A` 比 `B` 先入栈，且 `B` 入栈时 `A` 还没有出栈，则栈局部为：

```text
B   ← 栈顶更近
A
```

因此在 `A` 出栈之前，`B` 必须先出栈。

这就是所有合法性判断的基础。

---

## 3.5.3 通用模拟法：判断目标出栈序列

给定：

```text
input  = 固定入栈序列
output = 目标出栈序列
```

最稳妥的算法是模拟真实栈：

```text
初始化空栈 S
j = 0  // 指向 output 当前待匹配元素

for x in input:
    push(x)

    while S 非空 且 top(S) == output[j]:
        pop()
        j++

若最终 j == output 长度：合法
否则：不合法
```

C 风格伪代码：

```c
for (int i = 0; i < n; ++i) {
    Push(&S, input[i]);

    while (!StackEmpty(&S) &&
           j < n &&
           GetTop(&S) == output[j]) {
        Pop(&S);
        ++j;
    }
}

return j == n;
```

时间复杂度：每个元素至多入栈一次、出栈一次，因此：

$$
O(n)
$$

## 3.5.4 最小栈容量：记录模拟过程中的最大深度

若题目问“为了产生某个出栈序列，栈容量至少多大”，仍然按目标序列模拟。

每次：

```text
Push → 当前深度 +1
Pop  → 当前深度 -1
```

在整个合法过程中出现的**最大深度**，就是所需最小容量。

例如入栈：

```text
a b c d e f g
```

目标出栈：

```text
b d c f e a g
```

一种过程：

```text
push a     深度 1
push b     深度 2
pop  b     深度 1
push c     深度 2
push d     深度 3  ← 最大
pop  d     深度 2
pop  c     深度 1
push e     深度 2
push f     深度 3
pop  f     深度 2
pop  e     深度 1
pop  a     深度 0
push g     深度 1
pop  g     深度 0
```

因此最小容量为：

$$
3
$$

> **真题标签｜2009 第 2 题：目标出栈序列与最小栈容量**
>
> 先根据目标序列确定必要的 Push / Pop，再记录过程中的最大栈深度即可。

## 3.5.5 带额外限制的出栈序列题

题目还可能加入限制，例如：

```text
不允许连续 3 次出栈
栈容量不超过 k
某一步必须先入栈 / 先出栈
```

处理原则不变：

```text
基础约束：固定入栈顺序 + 只能弹栈顶
附加约束：在模拟过程中额外检查
```

不要试图只凭“看起来像不像合法序列”判断，复杂限制下显式模拟更可靠。

## 3.5.6 固定入栈顺序的合法出栈序列数量：卡特兰数

若有 $n$ 个互不相同元素，按固定顺序依次入栈，并规定：

- 每个元素恰好入栈一次；
- 每个元素恰好出栈一次；

那么合法出栈序列数量为第 $n$ 个**卡特兰数（Catalan Number）**：

$$
C_n=\frac{1}{n+1}\binom{2n}{n}
$$

等价写法：

$$
C_n=\frac{(2n)!}{n!(n+1)!}
$$

前几个值：

| $n$ | $C_n$ |
| ---: | ---: |
| 0 | 1 |
| 1 | 1 |
| 2 | 2 |
| 3 | 5 |
| 4 | 14 |
| 5 | 42 |
| 6 | 132 |

> **真题标签｜2015 选择题；2026 第 42 题：卡特兰数与合法栈操作序列**
>
> 一看到“固定入栈次序 + 每个元素恰好入栈一次、出栈一次 + 求合法方案数”，就应联想到卡特兰数。

---

## 3.5.7 为什么卡特兰数会出现

把：

```text
入栈 → +1
出栈 → -1
```

整个过程一共有：

$$
n
$$

次入栈和：

$$
n
$$

次出栈。

关键限制是不能从空栈继续出栈，所以任意前缀都必须满足：

$$
\text{入栈次数}\ge\text{出栈次数}
$$

同时最终二者相等。

这正对应经典卡特兰路径 / 合法括号结构。

---

## 3.5.8 卡特兰数递推与等价模型

递推：

$$
C_0=1
$$

$$
C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i},\qquad n\ge1
$$

常见等价问题：

- 固定入栈顺序的合法出栈序列数量；
- $n$ 对括号的合法匹配数量；
- 含 $n$ 个结点的不同二叉树**形状**数量。

注意：

> 若二叉树结点还带互不相同的标签，并允许任意标签排列，则不能只用 $C_n$；还需要考虑标签分配。

## 3.5.11 本章最容易失分的 8 个细节

1. **栈顶指针定义不同，所有边界条件都会变。**
2. **循环队列一定先读 `rear` 的语义。**
3. **牺牲一个存储单元时，数组长度不是最大元素数。**
4. **链式队列删掉唯一有效结点后要重置 `rear`。**
5. **后缀求值中先弹出的是右操作数。**
6. **中缀转后缀时，左结合运算符同优先级要先弹栈顶。**
7. **矩阵压缩题先统一 0 / 1 基下标和行 / 列主序，再推公式。**
8. **卡特兰数只适用于满足相应“前缀合法”约束的计数模型，不要看到二叉树或括号就机械套用。**
