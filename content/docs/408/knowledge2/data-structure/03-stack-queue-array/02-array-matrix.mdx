## 八、多维数组

> **真题考察：** 2021 年第 3 题。

数组的特点是：

> **逻辑上可以是多维的，但在物理内存中最终仍然是一维连续地址空间。**

因此二维数组地址计算的核心，就是把二维下标映射为一维偏移量。

<InlineSvg src="/images/data-structure/data-structure-array-matrix-001.svg" alt={"图示"} />

---

### 1. 行主序

设二维数组：

```text
A[R][C]
```

其中：

* 首元素地址为 $A_0$；
* 每个元素占 $B$ 字节；
* 行下标、列下标均从 0 开始；
* 一共有 $R$ 行、$C$ 列。

若使用**行主序（Row-major Order）**，元素 `a[i][j]` 前面共有：

$$
iC+j
$$

个元素。

因此地址为：

$$
\operatorname{Addr}(a[i][j])
=
A_0+(iC+j)B
$$

C、C++ 等语言采用行主序。

例如：

```c
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

内存中的顺序实际是：

```text
a[0][0]
a[0][1]
a[0][2]
a[1][0]
a[1][1]
a[1][2]
```

例如若：

```text
a[0][0] = 0x100
sizeof(int) = 4
```

则地址依次为：

```text
a[0][0]  0x100
a[0][1]  0x104
a[0][2]  0x108
a[1][0]  0x10C
a[1][1]  0x110
a[1][2]  0x114
```

---

### 2. 列主序

Fortran、MATLAB 等环境常采用**列主序（Column-major Order）**。

存储顺序变为：

```text
a[0][0]
a[1][0]
a[0][1]
a[1][1]
a[0][2]
a[1][2]
```

元素 `a[i][j]` 前面共有：

$$
jR+i
$$

个元素，因此：

$$
\operatorname{Addr}(a[i][j])
=
A_0+(jR+i)B
$$

> **解题关键：**
>
> * 行主序：先完整跨过前面的**行**；
> * 列主序：先完整跨过前面的**列**。
>
> 不建议只死记地址公式，应理解“目标元素前面一共有多少个元素”。

## 九、特殊矩阵的压缩存储

> **真题考察：**
> 2016 年第 4 题、2017 年第 3 题、2018 年第 3 题、2020 年第 1 题、2023 年第 3 题。

特殊矩阵中的许多元素具有重复或固定规律，因此没必要保存所有 $n^2$ 个元素。

压缩存储的核心问题是：

> **建立矩阵下标 $(i,j)$ 与一维数组下标 $k$ 的映射。**

常见类型包括：

* 对称矩阵；
* 三角矩阵；
* 三对角矩阵；
* 稀疏矩阵。

---

## 十、对称矩阵

若一个 $n\times n$ 矩阵满足：

$$
a_{ij}=a_{ji}
$$

则称其为**对称矩阵**。

只需要存储：

* 上三角部分；

或：

* 下三角部分。

因为另一半可由对称关系得到。

独立元素总数为：

$$
1+2+\cdots+n
=
\frac{n(n+1)}{2}
$$

<InlineSvg src="/images/data-structure/data-structure-array-matrix-002.svg" alt={"对称矩阵压缩存储"} />

![对称矩阵按下三角区域压缩到一维数组的存储示意](/images/data-structure/data-structure-array-matrix-003.png)

---

### 1. 下三角按行优先存储

假设：

* 原矩阵使用 **1 基下标**；
* 一维压缩数组 `B` 使用 **0 基下标**；
* 保存下三角部分。

当：

$$
i\ge j
$$

时，第 $i$ 行之前已经存储：

$$
1+2+\cdots+(i-1)
=
\frac{i(i-1)}{2}
$$

个元素。

当前元素在本行内是第 $j$ 个，因此：

$$
k
=
\frac{i(i-1)}{2}+j-1
$$

当：

$$
i<j
$$

时，利用：

$$
a_{ij}=a_{ji}
$$

转换为下三角位置，因此：

$$
k
=
\frac{j(j-1)}{2}+i-1
$$

综合得到：

$$
k(i,j)=
\begin{cases}
\dfrac{i(i-1)}{2}+j-1, & i\ge j,\\[6pt]
\dfrac{j(j-1)}{2}+i-1, & i<j.
\end{cases}
$$

> **记忆方法：**
> 先把元素“翻转”到实际存储的三角区域，再计算其前面共有多少元素。

---

## 十一、三角矩阵

三角矩阵中，主对角线某一侧的元素全部相同，通常全部为 0。

例如上三角矩阵：

```text
a11 a12 a13 a14
  0 a22 a23 a24
  0   0 a33 a34
  0   0   0 a44
```

只需保存上三角中的独立元素。

<InlineSvg src="/images/data-structure/data-structure-array-matrix-004.svg" alt={"三角矩阵压缩存储"} />

独立元素个数为：

$$
\frac{n(n+1)}{2}
$$

如果下三角中的统一常量也需要保存，可以再增加一个位置，因此总空间为：

$$
\frac{n(n+1)}{2}+1
$$

---

### 上三角矩阵按行优先存储

假设：

* 原矩阵使用 1 基下标；
* 压缩数组使用 0 基下标；
* $i\le j$。

第 1 行有 $n$ 个元素，第 2 行有 $n-1$ 个元素，……

第 $i$ 行之前共有：

$$
n+(n-1)+\cdots+(n-i+2)
$$

个元素。

化简可得压缩数组下标：

$$
k(i,j)
=
\frac{(i-1)(2n-i+2)}{2}
+
(j-i)
$$

对于不在独立区域内的元素，直接返回矩阵规定的统一常量即可。

---

## 十二、三对角矩阵

**三对角矩阵**中，只有：

* 主对角线；
* 主对角线上方一条对角线；
* 主对角线下方一条对角线；

可能为非零。

即只有满足：

$$
|i-j|\le 1
$$

的位置需要保存。

其非零区域元素数量为：

$$
n+(n-1)+(n-1)
=
3n-2
$$

若原矩阵采用 1 基下标，并把有效元素按行优先存入 0 基数组，则：

$$
k=2i+j-3
$$

其中：

$$
|i-j|\le1
$$

例如第一行：

```text
a11 a12
```

对应：

```text
B[0], B[1]
```

第二行：

```text
a21 a22 a23
```

对应：

```text
B[2], B[3], B[4]
```

最后一个元素的压缩下标为：

$$
3n-3
$$

因此压缩数组总长度为：

$$
3n-2
$$

> **高频易错点：**
> 特殊矩阵压缩题第一步不是套公式，而是先写清：
>
> * 原矩阵下标从 0 还是 1 开始；
> * 压缩数组下标从 0 还是 1 开始；
> * 按行优先还是按列优先。
>
> 只要其中一个约定不同，最终公式中的常数项就会改变。

## 十三、稀疏矩阵

若矩阵中绝大多数元素均为 0，只有少量非零元素，则称为**稀疏矩阵（Sparse Matrix）**。

与普通二维数组相比，直接存储全部元素会浪费大量空间。

因此常用：

1. **三元组表**；
2. **十字链表**。

来只保存非零元素。

---

## 十四、三元组表

> **真题考察：** 2023 年第 3 题。

设一个 $m\times n$ 的稀疏矩阵中共有 $t$ 个非零元素。

三元组表只记录每个非零元素的：

```text
(行号, 列号, 值)
```

因此只需要存储 $t$ 个三元组。

<InlineSvg src="/images/data-structure/data-structure-array-matrix-012.svg" alt={"0 0 1 0 0 0 0 0 2 0 0 0 0 0 3 0 0 0 0 0 0 0 0 0 5 0 0 0 0 0 0 0 6 0 0 0 0 0 0 0 7 4 i j a ij 0 2 1 1 1 2 2 0 3 3 3 5 4 4 6 5 5 7 5 6 4 稀疏矩阵 三元组表"} />

通常按照：

1. 行号递增；
2. 行号相同时列号递增；

的顺序保存。

---

### 1. 三个数组分别保存

```c
#define MAXSIZE 100

typedef struct {
    int m;
    int n;
    int t;

    int row[MAXSIZE];
    int col[MAXSIZE];
    int val[MAXSIZE];
} TSMatrix;
```

---

### 2. 结构体数组保存

```c
#define MAXSIZE 100

typedef struct {
    int row;
    int col;
    int val;
} Triple;

typedef struct {
    int m;
    int n;
    int t;

    Triple data[MAXSIZE];
} TSMatrix;
```

---

### 3. 特点

优点：

* 结构简单；
* 只保存非零元素；
* 空间利用率高；
* 适合矩阵转置、输出、相加等操作。

缺点：

> **随机访问效率较低。**

如果要访问：

```text
A[i][j]
```

通常需要在三元组序列中寻找对应的 `(i,j)`。

## 十五、十字链表

如果既需要经常按行访问，又需要经常按列访问，可以采用**十字链表（Cross List）**。

<InlineSvg src="/images/data-structure/data-structure-array-matrix-013.svg" alt={"3 1 1 3 2 2 -1 ^ ^ 3 1 2 ^ ^ ^ 1 4 5 ^ ^ rhead chead 0 0 5 0 -1 0 0 2 0 0 0"} />

每个非零元素对应一个结点，结点包含：

* 行号 `row`；
* 列号 `col`；
* 数据 `value`；
* 指向同行下一个非零元素的 `right`；
* 指向同列下一个非零元素的 `down`。

因此一个结点同时属于：

* 一条行链表；
* 一条列链表。

这就是“十字”结构的来源。

---

### 1. 结点定义

```c
typedef struct CrossListNode {
    int row;
    int col;
    int value;

    struct CrossListNode *right;
    struct CrossListNode *down;
} CrossListNode;
```

---

### 2. 十字链表结构

```c
typedef struct {
    CrossListNode **rhead;
    CrossListNode **chead;

    int rows;
    int cols;
    int nums;
} CrossList;
```

其中：

* `rhead[i]`：第 `i` 行第一个非零元素；
* `chead[j]`：第 `j` 列第一个非零元素。

因此可以在常数时间得到任意一行或一列的链表入口，再沿链表进行遍历。

---

### 3. 十字链表特点

* 只保存非零元素；
* 可以方便地按行遍历；
* 可以方便地按列遍历；
* 插入、删除非零元素时无需移动大量元素；
* 适合动态稀疏矩阵；
* 常用于矩阵加法、乘法、转置等操作。
