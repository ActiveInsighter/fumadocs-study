栈和队列都是**操作受限的线性表**：栈只允许在一端进行插入和删除，队列则分别在队尾插入、队头删除。数组依靠连续存储和下标映射实现随机访问，也是特殊矩阵压缩存储的基础。

本章在 408 中的主要考点包括：

* 栈的后进先出特性、顺序栈与链栈；
* 队列的先进先出特性、循环队列的判空与判满；
* 多维数组的地址计算；
* 对称矩阵、三角矩阵、三对角矩阵的压缩存储；
* 稀疏矩阵的三元组表与十字链表；
* 中缀表达式求值、中缀转后缀、后缀表达式求值；
* 固定入栈序列对应的合法出栈序列；
* 卡特兰数。
