数组在逻辑上可以是多维的，但最终仍映射到一维连续地址空间。特殊矩阵压缩的本质也一样：

> **把二维下标 $(i,j)$ 映射为一维存储下标 $k$。**

这一章的公式很多，但最稳妥的做法不是死记常数项，而是先确定下标体系，再数“目标元素前面已经存了多少个元素”。

---

## 3.3.1 二维数组地址计算的统一思路

设二维数组有 $R$ 行、$C$ 列，每个元素占 $B$ 字节，首元素地址为 $A_0$。

如果目标元素前面有 $N$ 个元素，那么：

$$
Addr=A_0+NB
$$

所以所有地址计算都可以化成一个问题：

```text
目标元素前面一共有多少个元素？
```

> **真题标签｜2021：多维数组地址计算**
>
> 先判断行主序还是列主序，再算线性偏移；不要直接把行号、列号代入背下来的公式。

---

## 3.3.2 行主序（Row-major Order）

设下标均从 0 开始，目标为 `A[i][j]`。

行主序先存完整的第 0 行，再存第 1 行……

目标元素前面有：

- 完整的 $i$ 行，共 $iC$ 个元素；
- 当前行前面的 $j$ 个元素。

所以线性偏移为：

$$
iC+j
$$

地址：

$$
Addr(A[i][j])=A_0+(iC+j)B
$$

C / C++ 的普通二维数组采用行主序。

例如：

```c
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

物理顺序为：

```text
a[0][0], a[0][1], a[0][2],
a[1][0], a[1][1], a[1][2]
```

---

## 3.3.3 列主序（Column-major Order）

列主序先存完整的第 0 列，再存第 1 列……

目标 `A[i][j]` 前面有：

- 完整的 $j$ 列，共 $jR$ 个元素；
- 当前列前面的 $i$ 个元素。

因此：

$$
Addr(A[i][j])=A_0+(jR+i)B
$$

记忆方法：

```text
行主序：先数前面完整的行
列主序：先数前面完整的列
```

---

## 3.3.4 下界不为 0 时怎样处理

若二维数组逻辑下标为：

$$
A[L_1..U_1][L_2..U_2]
$$

列数为：

$$
C=U_2-L_2+1
$$

行主序下，`A[i][j]` 相对首元素 `A[L_1][L_2]` 的元素偏移为：

$$
(i-L_1)C+(j-L_2)
$$

地址为：

$$
Addr(A[i][j])
=
A_0+\left[(i-L_1)C+(j-L_2)\right]B
$$

因此所谓“0 基公式”只是下界为 0 的特例。

## 3.3.5 特殊矩阵压缩的基本原则

特殊矩阵中大量元素相同、可由其他元素推出，或固定为 0，因此没必要保存全部 $n^2$ 个元素。

常见对象：

- 对称矩阵；
- 上 / 下三角矩阵；
- 三对角矩阵；
- 稀疏矩阵。

做题前先写四个条件：

```text
1. 原矩阵下标从 0 还是 1 开始？
2. 压缩数组下标从 0 还是 1 开始？
3. 按行还是按列存？
4. 实际保存哪一部分？
```

只要其中一项改变，公式常数项就可能改变。

> **真题标签｜2016、2017、2018、2020、2023：特殊矩阵压缩下标**
>
> 高频失分不是数学不会，而是下标体系和存储方向读错。

## 3.3.6 对称矩阵

若 $n\times n$ 矩阵满足：

$$
a_{ij}=a_{ji}
$$

则称为**对称矩阵**。

只需保存主对角线与一个三角区域，独立元素数为：

$$
1+2+\cdots+n=\frac{n(n+1)}{2}
$$

### 下三角按行优先：矩阵 1 基、数组 0 基

假设只存：

$$
i\ge j
$$

第 $i$ 行前面已经保存：

$$
1+2+\cdots+(i-1)=\frac{i(i-1)}{2}
$$

当前元素是本行第 $j$ 个，因此：

$$
k=\frac{i(i-1)}{2}+j-1
$$

若 $i<j$，利用对称性把 $(i,j)$ 映射到 $(j,i)$。

综合：

$$
k(i,j)=
\begin{cases}
\dfrac{i(i-1)}{2}+j-1, & i\ge j,\\
\dfrac{j(j-1)}{2}+i-1, & i<j.
\end{cases}
$$

最稳定的思路是：

```text
先把目标翻到实际存储区域 → 再计算前面有多少元素
```

## 3.3.7 三角矩阵

以上三角矩阵为例，主对角线下方元素均为同一常量（常见为 0）：

```text
a11 a12 a13 a14
  c a22 a23 a24
  c   c a33 a34
  c   c   c a44
```

上三角独立元素数：

$$
\frac{n(n+1)}{2}
$$

如果还需要单独保存统一常量 $c$，总空间为：

$$
\frac{n(n+1)}{2}+1
$$

### 上三角按行优先：矩阵 1 基、数组 0 基

只考虑 $i\le j$。

前 $i-1$ 行保存的元素数为：

$$
n+(n-1)+\cdots+(n-i+2)
$$

化简：

$$
\frac{(i-1)(2n-i+2)}{2}
$$

目标在第 $i$ 行中的偏移为：

$$
j-i
$$

所以：

$$
k(i,j)
=
\frac{(i-1)(2n-i+2)}{2}+j-i
$$

若目标在统一常量区域，则无需存成独立元素，访问时直接返回该常量。

## 3.3.8 三对角矩阵

三对角矩阵只有：

- 主对角线；
- 主对角线上方一条对角线；
- 主对角线下方一条对角线；

可能为非零。

有效元素满足：

$$
|i-j|\le1
$$

有效元素总数：

$$
n+(n-1)+(n-1)=3n-2
$$

若原矩阵为 1 基下标，按行优先压缩到 0 基数组，则有效元素的压缩下标可写为：

$$
k=2i+j-3
$$

其中：

$$
|i-j|\le1
$$

> **真题标签｜2016：三对角矩阵压缩**
>
> 对 $m_{30,30}$，代入 $k=2i+j-3$ 得 $87$。更稳妥的验证方式是数出它前面有多少个有效元素。

最后一个有效元素的下标为：

$$
3n-3
$$

因此长度为：

$$
3n-2
$$

### 反向由 $k$ 求行号的思路

若题目反过来给压缩下标 $k$，不要强行背反函数。可以利用：

```text
第一行 2 个元素
中间各行通常 3 个元素
最后一行 2 个元素
```

先定位落在哪一行，再结合本行第几个位置恢复列号。

## 3.3.9 稀疏矩阵

若矩阵绝大多数元素为 0，只有很少非零元素，则称为**稀疏矩阵（Sparse Matrix）**。

直接保存 $m\times n$ 个位置会浪费大量空间，常见压缩方式有：

1. 三元组表；
2. 十字链表。

这两种结构与前面的“规则矩阵压缩”不同：

- 对称 / 三角矩阵利用的是**固定规律**；
- 稀疏矩阵通常记录每个非零元素的**实际坐标和值**。

---

## 3.3.10 三元组表

设稀疏矩阵共有 $t$ 个非零元素，每个非零元素只保存：

```text
(row, col, value)
```

通常按：

```text
行号递增；同行时列号递增
```

排列。

一种结构体数组表示：

```c
typedef struct {
    int row;
    int col;
    ElementType value;
} Triple;

typedef struct {
    int rows;
    int cols;
    int nums;
    Triple data[MAXSIZE];
} TSMatrix;
```

也可以把 `row[]`、`col[]`、`value[]` 分开保存。

> **真题标签｜2023：稀疏矩阵与压缩存储**
>
> 三元组只保存非零元素及其坐标，随机访问某个指定位置通常不能像二维数组那样 $O(1)$ 直接定位。

### 三元组表特点

优点：

- 结构简单；
- 空间主要与非零元素个数 $t$ 成正比；
- 适合顺序输出、转置、矩阵加法等操作。

缺点：

- 按任意坐标随机访问效率较低；
- 动态插入、删除可能涉及顺序表移动。

---

## 3.3.11 十字链表

若既要频繁按行访问，又要频繁按列访问，可以使用**十字链表（Cross List）**。

每个非零元素结点至少记录：

- 行号 `row`；
- 列号 `col`；
- 数据 `value`；
- 同行下一个非零元素 `right`；
- 同列下一个非零元素 `down`。

```c
typedef struct CrossListNode {
    int row;
    int col;
    ElementType value;
    struct CrossListNode *right;
    struct CrossListNode *down;
} CrossListNode;
```

整个矩阵维护行头与列头：

```c
typedef struct {
    CrossListNode **rhead;
    CrossListNode **chead;
    int rows;
    int cols;
    int nums;
} CrossList;
```

其中：

```text
rhead[i] → 第 i 行第一个非零元素
chead[j] → 第 j 列第一个非零元素
```

一个非零结点同时位于：

```text
某一条行链表 + 某一条列链表
```

这就是“十字”的含义。

### 十字链表特点

- 只保存非零元素；
- 按行和按列遍历都方便；
- 动态插入、删除不需要整体移动大量元素；
- 适合动态稀疏矩阵；
- 可用于矩阵转置、加法、乘法等操作。

---

## 3.3.12 压缩下标题的统一解题模板

遇到压缩存储题，按以下顺序处理：

```text
Step 1  写清原矩阵下标基准
Step 2  写清压缩数组下标基准
Step 3  写清按行还是按列
Step 4  写清真正被保存的区域
Step 5  数“目标元素前面已保存多少个元素”
Step 6  再决定是否需要 +1 / -1 调整
```

最危险的做法是：

```text
看到“对称矩阵”或“三对角矩阵”就直接套固定公式
```

因为考试最容易改的恰好是**下标从 0 / 1 开始、按行 / 按列、存上三角 / 下三角**这些条件。
