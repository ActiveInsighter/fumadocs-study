## 24. 本章高频易错点

### 24.1 `top` 到底指向栈顶元素，还是下一个可插入位置

两种定义都合法，但对应公式不同。

若本章规定：

```text
top 指向当前栈顶元素
```

则：

```text
空栈：top == -1
入栈：data[++top] = x
出栈：x = data[top--]
```

若题目另有定义，必须重新推导。

> **做栈题先写一句：`top` 的语义是什么。**

### 24.2 循环队列必须先确认 `front`、`rear` 的语义

本章约定：

```text
front 指向队头元素
rear  指向下一个待插入位置
```

并牺牲一个数组单元时：

$$
front=rear
$$

表示队空；

$$
(rear+1)\bmod MaxSize=front
$$

表示队满；

队列长度：

$$
(rear-front+MaxSize)\bmod MaxSize
$$

真正队尾元素位置：

$$
(rear-1+MaxSize)\bmod MaxSize
$$

<Callout type="warn" title="公式成立有前提">
一旦题目令 `rear` 指向当前队尾元素，或使用 `size/tag` 区分空满，上述公式就不能机械套用。
</Callout>

### 24.3 链式队列删除最后一个元素后必须重置 `rear`

原来只有一个数据结点：

```text
front -> head -> p <- rear
```

删除 `p` 后，除了：

```c
front->next = NULL;
```

还必须：

```c
rear = front;
```

否则 `rear` 会指向已经释放的结点。

### 24.4 后缀求值中减法、除法不能颠倒操作数

读到二元运算符 `op`：

```text
B = pop()
A = pop()
```

计算：

```text
A op B
```

而不是 `B op A`。

### 24.5 中缀转后缀时不能只看优先级，还要看结合性

对左结合运算符 `+ - * /`：

- 栈顶优先级更高：弹栈；
- 栈顶与当前优先级相同：也弹栈。

因此：

```text
a-b-c
```

对应：

```text
(a-b)-c
```

后缀：

```text
ab-c-
```

但对于右结合运算符，例如常见的 `^`，相同优先级时通常不能按左结合规则直接弹栈。

### 24.6 中缀表达式中的括号不会出现在后缀表达式中

转换时：

- `(` 只用于建立运算边界；
- 遇到 `)` 时，把 `(` 之前的运算符弹出；
- 最后把 `(` 自身删除，但**不输出**。

所以规范的后缀表达式不需要括号来表示原有优先级。

### 24.7 多维数组先确定“哪一维变化最快”

行主序中最后一维变化最快；列主序中第一维变化最快。多维地址题不要只记二维公式，应把每一维下标乘上“后续（或前序）维长之积”后求和。

### 24.8 矩阵压缩题第一步不是背公式

先写清：

```text
原矩阵：0 基还是 1 基？
压缩数组：0 基还是 1 基？
按行还是按列？
保存上三角还是下三角？
```

然后只问：

> **目标元素之前已经存了多少个元素？**

这比死记常数项更可靠。

### 24.9 对称矩阵：不在存储区就先“翻转”

若只保存下三角，而要求 $a_{ij}$ 且 $i<j$，先利用：

$$
a_{ij}=a_{ji}
$$

把它转成下三角位置，再计算压缩下标。

### 24.10 三对角矩阵只有满足 `|i-j| <= 1` 的位置需要保存

有效元素总数：

$$
3n-2
$$

不能误写为 $3n$，因为第一行和最后一行各少一个邻对角元素。

### 24.11 三元组表支持压缩存储，但不等于随机访问

普通二维数组已知 `(i,j)` 时可直接按地址公式定位。

三元组表只保存非零元素；要找任意 `A[i][j]`，通常仍需在三元组中搜索，因此不能把“节省空间”误解成“访问也一定更快”。

### 24.12 入栈顺序确定，不代表出栈顺序唯一

固定：

```text
1, 2, 3
```

既可以得到：

```text
1, 2, 3
```

也可以得到：

```text
3, 2, 1
```

还可以得到其他合法序列。

判断具体目标序列时，最稳妥的方法是**按固定入栈顺序模拟**。

### 24.13 卡特兰数的使用必须满足模型前提

固定顺序入栈、每个元素恰好入栈/出栈一次时，合法出栈序列数才是：

$$
C_n=\frac{1}{n+1}\binom{2n}{n}
$$

如果题目附加了“第一个出栈元素固定”“某些元素相对位置固定”等额外条件，通常还需要继续分类或建立递推，不能只写一个 $C_n$。

## 25. 408 考前速查

### 25.1 栈与队列

| 知识点 | 结论 |
| --- | --- |
| 栈 | 后进先出 LIFO |
| 队列 | 先进先出 FIFO |
| 顺序栈空（本章约定） | `top == -1` |
| 顺序栈满 | `top == MAX_SIZE - 1` |
| 顺序栈入栈/出栈 | $O(1)$ |
| 链栈入栈/出栈 | $O(1)$ |
| 循环队列空 | `front == rear` |
| 循环队列满（牺牲一格） | `(rear + 1) % MaxSize == front` |
| 循环队列长度 | `(rear - front + MaxSize) % MaxSize` |
| 循环队列最大元素数 | `MaxSize - 1` |
| 链式队列入队/出队 | $O(1)$ |

### 25.2 数组与矩阵

| 知识点 | 结论 |
| --- | --- |
| 行主序二维数组偏移 | $iC+j$（0 基） |
| 列主序二维数组偏移 | $jR+i$（0 基） |
| $d$ 维行主序偏移 | $i_1(n_2\cdots n_d)+i_2(n_3\cdots n_d)+\cdots+i_d$ |
| 对称矩阵独立元素数 | $\frac{n(n+1)}{2}$ |
| 三角矩阵独立区域元素数 | $\frac{n(n+1)}{2}$ |
| 三对角矩阵有效元素数 | $3n-2$ |
| 稀疏矩阵顺序压缩 | 三元组表 |
| 稀疏矩阵行列双向组织 | 十字链表 |

### 25.3 表达式与栈序列

| 知识点 | 结论 |
| --- | --- |
| 前序遍历表达式树 | 前缀表达式 |
| 中序遍历表达式树 | 中缀表达式 |
| 后序遍历表达式树 | 后缀表达式 |
| 后缀表达式求值 | 一个操作数栈 |
| 中缀表达式求值 | 操作数栈 + 运算符栈 |
| 中缀转后缀 | 运算符栈 + 输出序列 |
| 二元运算弹栈顺序 | `B=pop(); A=pop(); A op B` |
| 固定入栈序列合法性 | 栈模拟，$O(n)$ |
| $n$ 个元素合法出栈序列总数 | $C_n$ |
| 卡特兰数 | $\frac{1}{n+1}\binom{2n}{n}$ |
| 首个出栈为 1 或 2（固定入栈 `1..n`） | 均为 $C_{n-1}$ |

<Callout type="info" title="本章最终解题框架">
栈和队列题：**先确认指针/下标语义，再模拟状态变化。**

数组和矩阵题：**先确认下标体系，再数目标元素之前已有多少元素。**

表达式题：**先明确运算符优先级与结合性，再严格执行栈规则。**
</Callout>
