## 二十四、本章高频易错点

### 1. 栈顶指针到底指哪里

不同题目可能定义：

```text
top 指向当前栈顶元素
```

也可能定义：

```text
top 指向下一个可插入位置
```

两种定义对应的：

* 空栈条件；
* 满栈条件；
* `Push`；
* `Pop`；

都会不同。

**做题先读定义，不要机械套代码。**

---

### 2. 循环队列一定先确认 `rear` 的含义

若采用本章的约定：

```text
rear 指向下一个待插入位置
```

并牺牲一个空间，则：

$$
front=rear
$$

表示队空，

$$
(rear+1)\bmod MaxSize=front
$$

表示队满，

队列长度为：

$$
(rear-front+MaxSize)\bmod MaxSize
$$

---

### 3. 减法和除法不要颠倒操作数

后缀求值时：

```text
B = pop()
A = pop()
```

计算：

```text
A op B
```

例如栈中：

```text
10, 8
```

遇到：

```text
-
```

结果是：

```text
10 - 8
```

而不是：

```text
8 - 10
```

---

### 4. 中缀转后缀时，相同优先级也要考虑结合性

对于普通左结合运算符：

```text
+ - * /
```

若当前运算符与栈顶运算符优先级相同：

> **应先弹出栈顶运算符，再让当前运算符入栈。**

例如：

```text
a-b-c
```

正确含义是：

```text
(a-b)-c
```

对应后缀表达式：

```text
ab-c-
```

---

### 5. 矩阵压缩最容易错的是下标体系

不要一上来背公式。

先写：

```text
矩阵：0 基还是 1 基？
压缩数组：0 基还是 1 基？
按行还是按列？
到底存上三角还是下三角？
```

然后再用：

> **目标元素前面已经存了多少个元素**

推导压缩下标。

## 二十五、408 速查表

| 知识点              | 必记结论                                 |
| ---------------- | ------------------------------------ |
| 栈                | 后进先出                                 |
| 队列               | 先进先出                                 |
| 顺序栈空             | `top == -1`（本章约定）                    |
| 顺序栈满             | `top == MAX_SIZE - 1`                |
| 循环队列空            | `front == rear`                      |
| 循环队列满            | `(rear + 1) % MaxSize == front`      |
| 循环队列长度           | `(rear - front + MaxSize) % MaxSize` |
| 顺序栈入栈/出栈         | $O(1)$                             |
| 链栈入栈/出栈          | $O(1)$                             |
| 队列入队/出队          | $O(1)$                             |
| 行主序二维数组          | 先完整跨过前面的行                            |
| 对称矩阵独立元素数        | $\frac{n(n+1)}{2}$                 |
| 三角矩阵独立元素数        | $\frac{n(n+1)}{2}$                 |
| 三对角矩阵有效元素数       | $3n-2$                             |
| 后缀表达式求值          | 一个操作数栈                               |
| 中缀表达式求值          | 操作数栈 + 运算符栈                          |
| 中缀转后缀            | 运算符栈                                 |
| $n$ 个元素合法出栈序列数 | $C_n$                              |
| 卡特兰数             | $\frac{1}{n+1}\binom{2n}{n}$       |

本章复习时，应把几个看似独立的内容连起来理解：

```text
栈
│
├─ 顺序栈 / 链栈
│
├─ 表达式树
│   ├─ 前缀
│   ├─ 中缀
│   └─ 后缀
│
├─ 中缀表达式求值
├─ 后缀表达式求值
├─ 中缀转后缀
└─ 出栈序列 → 卡特兰数

队列
│
├─ 顺序队列 → 假溢出
├─ 循环队列
└─ 链式队列

数组
│
├─ 行主序 / 列主序
└─ 特殊矩阵
    ├─ 对称矩阵
    ├─ 三角矩阵
    ├─ 三对角矩阵
    └─ 稀疏矩阵
        ├─ 三元组表
        └─ 十字链表
```

408 对本章的考查重点不只是记住定义，而是能够根据具体约定**模拟指针变化、推导下标、执行表达式转换以及判断栈序列是否合法**。
