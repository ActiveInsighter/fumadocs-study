## 1. 栈的基本概念

**栈（Stack）**是一种只允许在表的一端进行插入和删除操作的线性表。

允许操作的一端称为**栈顶（Top）**，另一端称为**栈底（Bottom）**。

栈遵循：

**后进先出（LIFO，Last In First Out）**

即最后进入栈中的元素最先离开。

<InlineSvg src="/images/data-structure/data-structure-array-stack-001.svg" alt={"PUSH POP"} />

例如依次执行：

```text
push(A)
push(B)
push(C)
```

栈中元素为：

```text
栈顶
 C
 B
 A
栈底
```

此时执行一次 `pop()`，得到的一定是 `C`。

---

## 2. 栈的基本操作

常见操作如下：

| 操作                | 含义          |
| ----------------- | ----------- |
| `InitStack`       | 初始化栈        |
| `Push`            | 将元素压入栈顶     |
| `Pop`             | 删除并返回栈顶元素   |
| `GetTop` / `Peek` | 读取栈顶元素，但不删除 |
| `StackEmpty`      | 判断栈是否为空     |
| `StackFull`       | 顺序栈中判断栈是否已满 |

栈的核心限制是：

> **只能访问当前栈顶元素。**

## 二、顺序栈

## 1. 基本结构

**顺序栈**是在顺序表基础上实现的栈，通常使用数组保存元素，并设置一个变量 `top` 表示栈顶位置。

<InlineSvg src="/images/data-structure/data-structure-array-stack-002.svg" alt={"0 1 2 3 4 5 6 7 top A B C D E F G H 0 1 2 3 4 5 6 7 top A B C D 0 1 2 3 4 5 6 7 top 栈空 栈满 A B C D E 0 1 2 3 4 5 6 7 top A B C D E 0 1 2 3 4 5 6 7 top E 入栈 A B C D 0 1 2 3 4 5 6 7 top 栈顶元素出栈"} />

一种最常见的约定是：

* `top = -1`：栈为空；
* `top = 0`：数组第一个元素为栈顶；
* `top = MAX_SIZE - 1`：栈满。

因此：

$$
\text{栈中元素个数}=top+1
$$

## 2. 顺序栈定义

```c
#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];
    int top;
} SeqStack;
```

初始化：

```c
void InitStack(SeqStack *S) {
    S->top = -1;
}
```

判断栈空：

```c
bool StackEmpty(SeqStack *S) {
    return S->top == -1;
}
```

判断栈满：

```c
bool StackFull(SeqStack *S) {
    return S->top == MAX_SIZE - 1;
}
```

---

## 3. 入栈

入栈过程：

1. 判断栈是否已满；
2. 栈顶指针后移；
3. 写入新元素。

```c
bool Push(SeqStack *S, int x) {
    if (StackFull(S)) {
        return false;
    }

    S->data[++S->top] = x;
    return true;
}
```

关键语句：

```c
S->data[++S->top] = x;
```

即：

> **先移动 `top`，再存数据。**

时间复杂度为：

$$
O(1)
$$

---

## 4. 出栈

出栈过程：

1. 判断栈是否为空；
2. 读取栈顶元素；
3. 栈顶指针前移。

```c
bool Pop(SeqStack *S, int *x) {
    if (StackEmpty(S)) {
        return false;
    }

    *x = S->data[S->top--];
    return true;
}
```

即：

> **先读取栈顶元素，再令 `top--`。**

时间复杂度为：

$$
O(1)
$$

---

## 5. 获取栈顶元素

```c
bool GetTop(SeqStack *S, int *x) {
    if (StackEmpty(S)) {
        return false;
    }

    *x = S->data[S->top];
    return true;
}
```

注意：

`GetTop` **不会改变 `top`**。

## 三、链栈

## 1. 基本结构

栈也可以使用单链表实现，称为**链栈**。

<InlineSvg src="/images/data-structure/data-structure-array-stack-004.svg" alt={"a 1 a 2 a n NULL head 栈增长方向 栈顶 栈底"} />

为了使入栈和出栈都保持常数时间，通常把链表的**头部作为栈顶**。

本节采用带头结点的链栈：

* `head` 为哨兵结点，不保存有效数据；
* `head->next` 指向栈顶元素；
* `head->next == NULL` 表示栈空。

这样：

* 入栈使用头插法；
* 出栈删除第一个有效结点。

二者时间复杂度均为：

$$
O(1)
$$

---

## 2. 数据结构

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

typedef struct {
    Node *head;
} LinkedStack;
```

初始化：

```c
LinkedStack *InitStack(void) {
    LinkedStack *S =
        (LinkedStack *)malloc(sizeof(LinkedStack));

    S->head = (Node *)malloc(sizeof(Node));
    S->head->next = NULL;

    return S;
}
```

---

## 3. 入栈

```c
void Push(LinkedStack *S, int x) {
    Node *p = (Node *)malloc(sizeof(Node));

    p->data = x;
    p->next = S->head->next;
    S->head->next = p;
}
```

本质就是：

> **在头结点之后进行头插。**

---

## 4. 出栈

```c
bool Pop(LinkedStack *S, int *x) {
    if (S->head->next == NULL) {
        return false;
    }

    Node *p = S->head->next;

    *x = p->data;
    S->head->next = p->next;

    free(p);
    return true;
}
```

---

## 5. 获取栈顶元素和判空

```c
bool GetTop(LinkedStack *S, int *x) {
    if (S->head->next == NULL) {
        return false;
    }

    *x = S->head->next->data;
    return true;
}

bool StackEmpty(LinkedStack *S) {
    return S->head->next == NULL;
}
```

---

## 6. 顺序栈与链栈对比

| 对比项  | 顺序栈      | 链栈               |
| ---- | -------- | ---------------- |
| 存储   | 连续空间     | 链式空间             |
| 入栈   | $O(1)$ | $O(1)$         |
| 出栈   | $O(1)$ | $O(1)$         |
| 最大容量 | 通常预先确定   | 可动态增长            |
| 额外空间 | 无结点指针    | 每个结点需要指针         |
| 局部性  | 好        | 较差               |
| 栈满   | 可能发生     | 内存耗尽前通常不存在固定容量问题 |

> **易错点：**
> 链栈若把链表尾部作为栈顶，在单链表中删除尾结点需要寻找其前驱，会导致出栈退化为 $O(n)$。因此一般使用链表头部作为栈顶。
