## 6.1.1 总线是什么

**总线（Bus）**&#x2060;是一组供多个部件共享、用于传送信息的信号线路或逻辑互连。传统 408 模型中，CPU、主存和 I/O 接口可以通过系统总线交换：

- 数据；
- 地址；
- 控制与状态信息。

传统共享总线最重要的两个特征是：

- **共享性**：多个部件可以挂接到同一组通信资源上；
- **分时性**：共享资源同一时刻通常只允许一个主设备主导一次事务。

现代 PCIe 等互连大量采用点到点链路，但考试仍可沿用“总线/系统互连”的抽象来理解：核心仍是**传输通路、协议、主从关系和资源竞争**。

## 6.1.2 数据总线、地址总线、控制总线

系统总线按所传信息的功能，可分为三类。

| 类型 | 主要作用 | 典型内容 |
| --- | --- | --- |
| 数据总线 | 传“数据本身” | 指令、操作数、结果、I/O 数据 |
| 地址总线 | 指定“访问谁” | 主存地址、I/O 端口地址 |
| 控制总线 | 说明“怎么传、何时传” | 读/写、请求/允许、中断、时钟、复位、就绪 |

### 数据总线宽度

若数据总线宽度为 $W$ bit，则一次并行数据传送最多承载：

$$
\frac{W}{8}\ \text{Byte}
$$

例如 64 位数据总线一次可承载 8 Byte。

> **高频易错点**
>
> 数据总线宽度、机器字长、存储字长彼此可能有关，但**不要求一定相等**。不能仅凭“32 位 CPU”推出“数据总线一定为 32 位”。

### 地址总线宽度

若有 $n$ 根独立地址线，可形成：

$$
2^n
$$

个不同地址。

若系统按字节编址，则理论地址空间大小为：

$$
2^n\ \text{Byte}
$$

因此：

> **地址线宽度决定能区分多少地址；数据线宽度决定一次能传多少数据。**

### 控制总线

控制总线可传送：

- 存储器读/写；
- I/O 读/写；
- 总线请求、总线允许；
- 中断请求、中断响应；
- 时钟、复位；
- 设备就绪、错误等状态。

有些总线采用**地址/数据复用**：同一组物理引脚在不同时间先传地址、后传数据。这样能减少引脚和布线，但并不意味着数据阶段和地址阶段可以同时占用同一组线路。

> **结论**
>
> 地址/数据复用的首要作用是**节省线路和引脚**，不能直接等同于提高数据传输率。

## 6.1.3 总线的多维分类

总线可以从不同维度分类，这些分类**不是互斥的**。

| 分类依据 | 常见类型 |
| --- | --- |
| 所传信息 | 数据总线、地址总线、控制总线 |
| 连接范围/用途 | 核内总线、系统总线、通信总线 |
| 数据传送方式 | 串行总线、并行总线 |
| 定时方式 | 同步总线、异步总线 |

例如某条互连可以同时具有“系统级 + 串行 + 某种同步链路协议”的特征。

### 核内总线、系统总线、通信总线

- **核内总线**：连接 CPU 核内部的寄存器、ALU、控制部件等；
- **系统总线**：连接 CPU、主存、I/O 接口等主要功能部件；
- **通信总线**：面向计算机与其他系统/设备之间的通信，传统教材也常称外部总线。

## 6.1.4 串行与并行：不要只看“几根线”判断快慢

### 并行传输

多根数据线在同一时刻并行传送多个 bit。

优点：

- 单次可传多个 bit；
- 适合短距离板级连接。

局限：

- 线路多、布线复杂；
- 高频下存在串扰；
- 多根线到达时间不同，容易产生**时钟偏斜（Skew）**；
- 距离越长，高频同步越困难。

典型传统并行互连：PCI、ISA、IDE/PATA；DDR 内存通道也包含大量并行数据线。

### 串行传输

数据位按时间顺序传送，一条 lane 内不要求多位同时到达。

特点：

- 数据线较少；
- 线路间同步问题较小；
- 更适合高频和较长距离；
- 现代高速互连广泛采用多 lane 高速串行技术。

典型串行互连：USB、PCIe、SATA、Thunderbolt、DisplayPort、HDMI。

> **高频辨析**
>
> - PCI：传统**并行**扩展总线；
> - PCIe：高速**串行**点到点互连；
> - PATA/IDE：并行 ATA；
> - SATA：串行 ATA。

## 6.1.5 同步与异步：区别在“时序依据”

### 同步方式

通信双方服从统一时钟或固定节拍。

- 控制简单；
- 时序明确；
- 适合速度比较接近的部件；
- 慢设备可能需要插入等待周期。

### 异步方式

双方不依赖统一固定节拍，而通过请求/应答等握手信号协调传送。

- 能适应速度差异较大的设备；
- 控制更灵活；
- 握手逻辑和控制开销更大。

这里是**分类层面**的理解；具体的同步定时、异步定时将在 6.2 展开。

## 6.1.6 单总线、多总线与分层结构

### 单总线结构

CPU、主存和多个 I/O 接口共享同一套主要系统总线。

优点：

- 结构简单；
- 成本低；
- 易扩展。

缺点：

- 设备竞争同一共享资源；
- 容易形成带宽瓶颈；
- 同一时刻很难让多个独立事务真正并行占用这套总线。

> **易错点**
>
> “单总线”不是“只有一根导线”。一套系统总线仍可包含多根地址线、数据线和控制线。

### 多总线结构

使用多套不同用途的互连，例如：

- CPU—主存互连；
- I/O 总线；
- 高速扩展互连；
- DMA 所使用的数据通路。

这样可以减少不同类型传输对同一共享总线的竞争。

### 分层互连结构

现代系统通常按速度和用途分层：

```text
CPU / SoC
├─ 内存控制器 ── DDR 主存
├─ 高速 PCIe ── GPU / NVMe / 高速网卡
└─ 芯片组或片上外设互连 ── USB / SATA / 音频 / 低速设备
```

核心原则：

> **高速设备尽量接高速低延迟链路，低速设备集中到较低层次，由桥接器/控制器连接各层。**

## 6.1.7 总线、接口、协议、插槽要分开

考试和现实硬件中这些词容易混用，但侧重点不同：

- **物理接口/连接器/插槽**：设备怎样在物理上接入；
- **互连/总线**：信息通过什么通路传输；
- **协议**：通信双方如何组织、解释和确认信息。

典型辨析：

| 设备/规格 | 重点理解 |
| --- | --- |
| M.2 | 主要描述外形和连接器规格，并不等于 NVMe |
| NVMe | 面向非易失性存储的命令/协议体系，常运行在 PCIe 上 |
| SATA | 串行存储互连/接口体系 |
| PCIe | 高速串行互连体系 |
| USB | 外设连接与通信体系 |

例如：

- M.2 SATA SSD：M.2 外形 + SATA 链路/协议栈；
- M.2 NVMe SSD：M.2 外形 + PCIe 链路 + NVMe 命令协议。

## 6.1.8 常见标准速记

| 名称 | 典型性质 | 典型用途 |
| --- | --- | --- |
| ISA / EISA | 早期并行扩展总线 | 旧式扩展卡 |
| PCI | 并行扩展总线 | 旧式网卡、声卡等 |
| PCIe | 高速串行互连 | GPU、NVMe、网卡 |
| IDE / PATA | 并行存储接口 | 早期硬盘、光驱 |
| SATA | 串行存储接口 | HDD、SATA SSD |
| USB | 串行外设接口 | 键鼠、U 盘、打印机等 |

> **缩写陷阱**
>
> ISA、EISA、PCI、PCIe 属于互连/总线类名词；而 CRT、CPI、RAM、MIPS 分别属于显示、性能指标、存储器等其他概念，不能看到英文缩写就当作总线。
