## 5.1.1 CPU 的基本功能

冯·诺依曼计算机由运算器、控制器、存储器、输入设备、输出设备五大部分构成。CPU 主要集成：

- **运算器**：完成算术、逻辑、移位、比较等数据处理；
- **控制器**：取指、译码并按时序发出控制信号，协调各部件工作。

从现代处理器实现角度，更适合把 CPU 抽象为：

```text
CPU
├─ Datapath 数据通路：保存、传送、加工数据
└─ Control Unit 控制器：决定什么时候让数据怎样流动
```

一句话区分：

> **数据通路回答“数据怎么走”，控制器回答“为什么现在这样走”。**

CPU 的主要功能可概括为：

1. **指令控制**：保证指令按正确顺序执行；
2. **操作控制**：产生完成指令所需的控制信号；
3. **时间控制**：让微操作在正确时刻发生；
4. **数据加工**：通过 ALU 等部件完成运算；
5. **异常与中断处理**：特殊事件出现时安全改变正常控制流。

## 5.1.2 数据通路是什么

**数据通路（Datapath）**&#x2060;是 CPU 执行指令时，数据在内部经过的路径以及路径上的功能部件的总称。

典型部件包括：

- ALU；
- 通用寄存器组；
- PC、IR、MAR、MDR 等专用寄存器；
- 暂存寄存器；
- 多路选择器 MUX；
- 译码器；
- 三态门；
- CPU 内部总线；
- 流水段寄存器。

### 组合逻辑元件

组合逻辑电路的输出只取决于**当前输入**，本身不保存历史状态。

常见部件：

- ALU；
- 译码器；
- 多路选择器；
- 三态门。

若译码器有 $n$ 位输入，理论上最多区分：

$$
2^n
$$

种输入组合。

MUX 根据选择信号从多个输入中选择一路输出，例如：

```text
Select = 0 → 输出 A
Select = 1 → 输出 B
```

三态门除 `0`、`1` 外还有**高阻态 Z**。多个设备共享总线时，未被选中的设备可进入高阻态，避免同时驱动总线。

### 时序逻辑元件

时序逻辑电路具有保存状态的能力，通常受时钟控制。常见部件：

- 通用寄存器；
- PC、IR、MAR、MDR；
- 状态寄存器；
- 暂存寄存器；
- 流水段寄存器；
- 存储器。

> **高频易错点**
>
> ALU 通常是组合逻辑部件，**不能长期保存结果**。运算结果必须写入寄存器或存储器等有状态部件。

## 5.1.3 CPU 寄存器的核心分类

### 程序计数器 PC

PC 保存**下一条待取指令的地址**或形成该地址所需的体系结构状态。

顺序执行时通常有：

$$
PC \leftarrow PC + \text{当前指令长度}
$$

遇到跳转、调用、返回、异常或中断时，PC 改为新的控制流地址。

### 指令寄存器 IR

IR 保存**当前正在解释/执行的机器指令**。控制器会从 IR 中取得：

- 操作码；
- 寻址字段；
- 寄存器编号；
- 立即数字段等。

### MAR 与 MDR

- `MAR`：Memory Address Register，保存本次存储器访问的地址；
- `MDR`：Memory Data Register，保存与主存交换的数据。

典型读操作：

```text
MAR ← 地址
MDR ← M[MAR]
```

典型写操作：

```text
MAR ← 地址
MDR ← 待写数据
M[MAR] ← MDR
```

### 通用寄存器 GPR

保存：

- 运算数；
- 地址；
- 中间结果；
- 函数参数与返回值等。

### 状态/标志寄存器 PSW / FLAGS

保存运算状态和处理器控制状态，如：

- `CF`：Carry Flag；
- `ZF`：Zero Flag；
- `SF`：Sign Flag；
- `OF`：Overflow Flag；
- 中断允许状态等。

### 暂存寄存器

暂存寄存器用于保存内部中间值，尤其常见于**单总线数据通路**。

若 ALU 需要两个输入，而同一时刻内部总线只能承载一路数据，可先把第一个操作数送入暂存器 `T`，再通过总线送第二个操作数。

## 5.1.4 程序员可见与不可见寄存器

考试判断“某寄存器是否程序员可见”时，要问：

> **普通机器指令或汇编程序能否显式引用这个寄存器？**

通常：

| 类别 | 典型寄存器 | 可见性 |
| --- | --- | --- |
| 通用寄存器 | `R0`、`R1`、`AX` 等 | 通常可见 |
| 地址/变址/栈寄存器 | `SP`、`BP`、`SI`、`DI` | 通常可见 |
| PC | 体系结构相关 | 常为特殊可见/不可直接普通读写 |
| FLAGS / PSW | 部分位可见 | 体系结构相关 |
| IR | 当前指令寄存器 | 通常不可见 |
| MAR | 内部访存地址寄存器 | 通常不可见 |
| MDR | 内部访存数据寄存器 | 通常不可见 |
| 内部暂存寄存器 | `T`、`Y`、`Z` 等 | 不可见 |

> **判断原则**
>
> ISA 规定的软件可见状态属于体系结构接口；为实现 ISA 而添加的内部寄存器属于微架构实现细节。

## 5.1.5 FLAGS：CF 与 OF 必须分清

> **真题标签｜状态标志**
>
> 原资料索引：选择题 2011 第 17 题、2018 第 19 题、2023 第 16 题；解答题 2013 第 44 题、2017 第 44 题、2019 第 45 题。

常见条件标志：

| 标志 | 含义 | 主要解释对象 |
| --- | --- | --- |
| `CF` | 最高位进位/无符号借位信息 | 无符号数 |
| `ZF` | 结果是否为 0 | 通用 |
| `SF` | 结果最高位 | 有符号解释常用 |
| `OF` | 有符号运算是否溢出 | 有符号数 |
| `PF` | 低 8 位中 `1` 的个数为偶数时置 1（x86） | 校验 |
| `AF` | 低 4 位向高 4 位的辅助进位/借位（x86） | BCD 等 |

x86 中原资料还列出三个典型控制标志：

- `IF`（Interrupt Flag）：允许/禁止响应普通可屏蔽外部中断；它不能屏蔽 NMI；
- `TF`（Trap Flag）：用于单步调试，典型情况下每执行一条指令后触发调试陷阱；
- `DF`（Direction Flag）：控制字符串指令中 `SI/DI` 的自动增减方向。

对 $n$ 位加法器，无符号加法的进位标志可理解为：

$$
CF=c_n
$$

其中 $c_n$ 是最高位向更高位产生的进位。

对两个 $n$ 位补码数 $A$、$B$ 做加法并得到 $C$，有符号溢出满足：

> **两个操作数同号，结果与它们异号。**

可写成：

$$
OF=A_{n-1}B_{n-1}\overline{C_{n-1}}
+\overline{A_{n-1}}\overline{B_{n-1}}C_{n-1}
$$

也可由符号位附近的进位判断：

$$
OF=C_{\text{in,sign}}\oplus C_{\text{out,sign}}
$$

例：8 位运算

```text
  01111111
+ 00000001
----------
  10000000
```

此时：

- 作为无符号数：$127+1=128$，合法，`CF=0`；
- 作为有符号补码：$127+1$ 超出范围，`OF=1`。

> **核心认识**
>
> 加法器只做二进制位运算，并不知道数据被软件解释成有符号还是无符号；硬件同时产生多种状态标志，后续指令按语义选择使用。

## 5.1.6 8086 寄存器：只作为辅助理解

8086 不是 408 所有结论的唯一实现，但原资料使用它帮助理解寄存器分工。

### 常见寄存器

| 类别 | 寄存器 | 典型用途 |
| --- | --- | --- |
| 通用 | `AX` | 累加/算术逻辑 |
| 通用 | `BX` | 基址 |
| 通用 | `CX` | 计数、循环、移位次数 |
| 通用 | `DX` | 数据、I/O、大整数辅助 |
| 段寄存器 | `CS` | 代码段 |
| 段寄存器 | `DS` | 数据段 |
| 段寄存器 | `SS` | 栈段 |
| 段寄存器 | `ES` | 附加段 |
| 指针/变址 | `SP` | 栈顶指针 |
| 指针/变址 | `BP` | 栈帧基址 |
| 指针/变址 | `SI` | 源变址 |
| 指针/变址 | `DI` | 目的变址 |
| 指令位置 | `IP` | 当前代码段内的下一条指令偏移 |

8086 分段寻址中：

$$
\text{Physical Address}=CS\times16+IP
$$

因此在“下一条指令地址”这一抽象功能上，可把 `CS:IP` 看作 PC 功能的一种具体实现。

### SP、BP 与函数栈

在典型向低地址增长的栈中：

- `SP` 指向当前栈顶；
- `BP` 常作为当前函数栈帧的基准。

以 `BP + offset` 常可访问参数、局部变量、保存的寄存器和返回地址。

### SI、DI 与字符串操作

`SI`、`DI` 可用于数组、字符串和变址寻址。x86 的 `DF` 控制字符串指令地址变化方向：

- `DF=0`：地址递增；
- `DF=1`：地址递减。

## 5.1.7 CPU 外部接口：低优先级辅助知识

原资料还以 8086 引脚说明 CPU 与外部总线的关系。8086 的典型背景是 **16 位数据通路、20 位地址、1 MB 地址空间**，部分地址线与数据/状态线复用：

- `AD0–AD15`：低位地址/数据复用；
- `A16/S3–A19/S6`：高位地址/状态复用；
- `RD#`、`WR#`：读/写控制；
- `ALE`：地址锁存使能；
- `READY`：慢速设备就绪控制，可引入等待状态；
- `HOLD/HLDA`：外部设备申请/获得总线，常与 DMA 联系；
- `INTR`：可屏蔽中断请求；
- `NMI`：不可屏蔽中断请求；
- `INTA#`：中断响应；
- `RESET`：处理器复位（8086 中为高电平有效）。

这部分不应压过 CPU 主线。408 更核心的是理解：

> **CPU 通过地址、数据和控制信息与存储器/I/O 协作；具体引脚名属于特定处理器实现。**
