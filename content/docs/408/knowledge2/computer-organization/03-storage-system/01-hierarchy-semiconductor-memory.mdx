存储系统的本质，是在**速度、容量、成本与持久性**之间折中。越靠近 CPU 的层次通常越快、越贵、容量越小；越远离 CPU，容量越大、单位成本越低，但访问延迟也更高。

## 3.1.1 存储层次的统一视角

典型层次可以写成：

```text
CPU
↓
寄存器
↓
L1 / L2 / L3 Cache
↓
主存 DRAM
↓
SSD / HDD 等辅助存储
```

可以用一句话概括层次结构：

> **上一层保存下一层中“当前更可能被访问”的一小部分内容。**

| 层次 | 常见实现 | 典型特点 | 主要管理者 |
| --- | --- | --- | --- |
| 寄存器 | 触发器 / 寄存器堆 | 容量最小、速度最快 | CPU、编译器 |
| Cache | SRAM | 小容量高速缓存 | 硬件 |
| 主存 | DRAM | 容量较大、速度低于 Cache | 硬件 + 操作系统 |
| 辅存 | NAND Flash、磁盘 | 非易失、容量大、速度较慢 | 操作系统、文件系统 |

需要区分两组主要矛盾：

- **Cache—主存层次**：主要解决 CPU 与主存之间的速度差距；
- **主存—辅存层次**：主要解决主存容量有限的问题，典型机制是虚拟存储器。

不要背现代硬件的固定纳秒数。408 更关注**相对快慢、工作原理和题目给出的参数**。

## 3.1.2 局部性：整个存储层次的共同基础

程序的访问通常不是完全随机的，而具有局部性。

### 时间局部性

最近访问过的指令或数据，短时间内再次访问的概率较高。

例如循环变量、循环体指令、反复使用的数组元素等。

### 空间局部性

访问某个地址后，附近地址很可能很快被访问。

顺序执行指令、顺序遍历数组都是典型例子。

这也是 Cache 以“块”为单位调入数据、虚拟存储器以“页”为单位调入数据的根本原因之一。

> **易错点**
>
> “局部性好”不等于“必然命中”。局部性只是让命中概率提高；实际是否命中还取决于容量、映射、替换策略和具体访问序列。

## 3.1.3 RAM：随机存取，不等于“只读写内存”

RAM 的 R 是 **Random**，表示给出地址后可以直接访问对应位置。

主流 RAM 的共同特点：

- 支持随机访问；
- 可读可写；
- SRAM、DRAM 都是**易失性**存储器；
- 断电后通常不能保持数据。

“随机存取”与“是否掉电保存”是两个不同维度。

## 3.1.4 SRAM

SRAM（Static RAM）使用双稳态存储结构保存 1 bit 数据。经典 SRAM 单元常用 6 个晶体管实现。

核心特性：

- 只要供电持续，状态即可稳定保持；
- **不需要周期性刷新**；
- 速度快；
- 集成度相对较低；
- 单位容量成本较高；
- 常用于 Cache、片上小容量高速存储。

> **“Static” 的含义**
>
> 静态是指“不需要刷新”，不是“非易失”。SRAM 断电后仍会丢失数据。

## 3.1.5 DRAM

DRAM（Dynamic RAM）典型单元使用“1 个晶体管 + 1 个电容”，即 1T1C 结构。

核心特性：

- 单元结构简单；
- 集成度高；
- 单位容量成本低；
- 适合构成大容量主存；
- 电容会漏电，因此必须刷新；
- 速度通常慢于 SRAM。

SRAM 与 DRAM 的高频对比：

| 项目 | SRAM | DRAM |
| --- | --- | --- |
| 典型基本单元 | 双稳态结构，经典 6T | 1T1C |
| 是否刷新 | 否 | 是 |
| 速度 | 快 | 较慢 |
| 集成度 | 较低 | 高 |
| 单位容量成本 | 高 | 低 |
| 典型用途 | Cache | 主存 |
| 易失性 | 是 | 是 |

## 3.1.6 ROM 与非易失性存储器

ROM 家族强调的是**断电保持与以读为主**。现代教材中，“ROM”不应机械理解成“绝对不能改写”。

| 类型 | 擦写方式 | 典型特点 |
| --- | --- | --- |
| MROM | 制造时固定 | 出厂后不可修改 |
| PROM | 用户一次性编程 | OTP，一般不可恢复 |
| EPROM | 紫外线擦除 | 通常整片擦除，再编程 |
| EEPROM | 电擦除 | 可在线更新，擦写粒度较细 |
| Flash | 电擦除，通常按块 | 高密度、低成本、应用广泛 |

### Flash 的定位

Flash 是可反复改写的非易失性半导体存储器。常见用途包括：

- SSD；
- U 盘；
- SD 卡；
- 手机存储；
- BIOS / UEFI 固件。

Flash 写入不像 RAM 那样可以任意覆盖：通常需要先擦除，再写入，并且擦写寿命有限。

> **考试口径**
>
> 很多教材把 Flash 放在 ROM 家族中讲解，因此按教材分类作答即可；但不能把它理解为“一次写死”的真正只读存储器。

## 3.1.7 RAM、ROM 与辅助存储不要混淆

ROM 和 RAM 通常都可以按地址随机访问；它们的关键差异主要在**可写性、写入机制和掉电保持能力**。

CD-ROM 虽然名字里也有 ROM，但它是**光学辅助存储介质**，不是半导体 ROM。

> **速记**
>
> - SRAM：快、不刷新、贵、Cache；
> - DRAM：要刷新、密度高、主存；
> - Flash：非易失、可擦写、按块管理、SSD；
> - “静态/动态”看刷新，“易失/非易失”看断电保持。
