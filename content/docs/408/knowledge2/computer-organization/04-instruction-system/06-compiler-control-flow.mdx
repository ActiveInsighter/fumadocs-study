408 越来越强调“高级语言代码与机器级代码之间的对应”。本节重点不是编译原理细节，而是知道**每个阶段做什么**，以及如何从汇编恢复高级语言控制结构。

> **真题标签｜高级语言与机器码**
>
> 原资料索引：2022 第 20 题；综合题包括 2010 第 44 题、2014 第 44 题、2019 第 45 题、2024 第 44 题等。

## 4.6.1 四阶段基本流程

传统 C 程序可抽象为：

```text
源代码
  ↓ 预处理
预处理后的源代码
  ↓ 编译
汇编代码
  ↓ 汇编
目标文件
  ↓ 链接
可执行文件
```

## 4.6.2 预处理做什么

典型工作：

- 展开 `#include`；
- 宏替换 `#define`；
- 处理条件编译；
- 完成若干文本级变换。

输出仍然可以看作高级语言文本。

## 4.6.3 编译做什么

在“预处理—编译—汇编—链接”四阶段模型中：

> **编译：高级语言 → 汇编语言。**

内部可以经历词法、语法、语义分析，中间表示、优化、目标代码生成等过程，但 408 通常只要求掌握阶段边界。

> **语境陷阱**
>
> 日常所说“编译一个程序”有时泛指从源码到可执行文件的全过程；考试若明确分四阶段，就按狭义阶段定义作答。

## 4.6.4 汇编做什么

汇编器 Assembler 将汇编助记符转换为机器码，并生成目标文件。

目标文件中除了机器指令，还可能包含：

- 符号信息；
- 重定位信息；
- 各种代码/数据节。

## 4.6.5 链接做什么

链接器的核心任务：

1. **符号解析**：把对函数、全局对象的引用与定义对应起来；
2. **重定位**：确定最终地址并修正地址相关字段；
3. **合并目标文件与库的相关节**。

### 静态链接

需要的库代码被并入最终可执行文件，文件通常更大。

### 动态链接

可执行文件保留对共享库的引用，在装入或运行过程中完成关联。共享库常见形式如 `.so`、`.dll`。

## 4.6.6 从 if-else 恢复控制流

C：

```c
if (a > b) {
    max = a;
} else {
    max = b;
}
```

典型机器级结构：

```asm
cmp eax, ebx
jle else_label

mov max, eax
jmp end_if

else_label:
mov max, ebx

end_if:
```

读法：

```text
比较
├─ 不满足 if 条件 → else
└─ 满足 → then
             ↓
          跳过 else
             ↓
            合流
```

## 4.6.7 while：先判断后执行

```c
while (count < 10) {
    count++;
}
```

典型：

```asm
loop_test:
cmp ecx, 10
jge loop_end

inc ecx
jmp loop_test

loop_end:
```

结构：

```text
条件测试 ←─────┐
  │            │
  ├─ false → 退出
  ↓ true       │
循环体 ────────┘
```

## 4.6.8 do-while：先执行后判断

```c
do {
    count++;
} while (count < 10);
```

典型：

```asm
loop_body:
inc ecx
cmp ecx, 10
jl loop_body
```

关键区别：

> **循环体至少执行一次。**

## 4.6.9 for：拆成四块

```c
for (int i = 0; i < 10; i++) {
    sum += i;
}
```

可以机械拆成：

```text
初始化
  ↓
条件测试 ←────────┐
  ↓ true          │
循环体             │
  ↓                │
更新表达式 ────────┘
```

所以在汇编里通常能找到：

- 一次初始化；
- 循环头比较；
- 循环体；
- 计数变量更新；
- 回跳。

## 4.6.10 编译优化会改变“表面形状”

同一个 C 程序在不同：

- ISA；
- ABI；
- 编译器；
- 优化等级；

下可能生成不同汇编。

例如编译器可能：

- 把局部变量长期放在寄存器；
- 消除帧指针；
- 合并或重排基本块；
- 用条件移动替代分支；
- 展开循环。

因此考试恢复高级语言时应看**语义和控制流**，不要背某一份固定汇编模板。

## 4.6.11 机器级控制流恢复法

一段陌生汇编建议这样处理：

1. 把所有 `cmp/test` 圈出来；
2. 给条件跳转写出“成立条件”；
3. 画控制流箭头；
4. 找回边形成的循环；
5. 找前向分支形成的 `if/else`；
6. 找 `call/ret` 划分过程边界；
7. 最后再识别变量、数组、指针和函数参数。

这比逐行翻译成 C 更稳。
