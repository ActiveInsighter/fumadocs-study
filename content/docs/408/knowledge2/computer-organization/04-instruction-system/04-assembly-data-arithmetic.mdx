408 的汇编题通常不要求写大型程序，而要求你**读懂机器级语义**。最稳的方法是：

> **先认操作数 → 再判断读写方向 → 再写出寄存器传送语义 → 最后检查标志位。**

> **真题标签｜汇编与操作码**
>

## 4.4.1 x86 常见寄存器层级

| 用途 | 16 位 | 32 位 | 64 位 |
| --- | --- | --- | --- |
| 累加器 | AX | EAX | RAX |
| 基址 | BX | EBX | RBX |
| 计数 | CX | ECX | RCX |
| 数据 | DX | EDX | RDX |
| 源变址 | SI | ESI | RSI |
| 目的变址 | DI | EDI | RDI |
| 帧指针 | BP | EBP | RBP |
| 栈指针 | SP | ESP | RSP |
| 指令指针 | IP | EIP | RIP |

重点记：

- `EIP/RIP`：控制流位置；
- `ESP/RSP`：栈顶；
- `EBP/RBP`：经典栈帧基准；
- `EAX/RAX`：常用于算术与返回值。

## 4.4.2 Intel 与 AT&T 语法

### Intel

```asm
mov eax, ebx
mov eax, [ebx+ecx*4+8]
```

顺序：

> **目的，源**

### AT&T

```asm
movl %ebx, %eax
movl 8(%ebx,%ecx,4), %eax
```

顺序：

> **源，目的**

快速辨认：

- `%eax`：寄存器；
- `$10`：立即数；
- `8(%ebx,%ecx,4)`：内存；
- `b/w/l/q` 常表示 8/16/32/64 bit 数据宽度。

两种写法的复杂地址都可还原为：

$$
EA=Base+Index\times Scale+Displacement
$$

## 4.4.3 MOV：复制而不是“移动后清空”

```asm
mov eax, ebx
mov eax, [var]
mov [var], eax
mov ecx, 100
```

`MOV` 是复制语义，源操作数通常不会因为“move”而自动消失。

经典 x86 普通 `MOV` 通常不允许两个普通操作数同时为内存：

```text
memory → memory
```

通常需要借助寄存器中转。

## 4.4.4 PUSH 与 POP

经典 32 位 x86 栈向低地址增长。

`push eax` 可以抽象成：

```text
ESP ← ESP - 4
M[ESP] ← EAX
```

`pop ebx` 可以抽象成：

```text
EBX ← M[ESP]
ESP ← ESP + 4
```

若数据宽度不同，SP 变化量也应按题设数据宽度确定。

## 4.4.5 ADD、SUB 与条件标志

```asm
add eax, ebx
sub eax, 10
```

分别可写为：

$$
EAX\leftarrow EAX+EBX
$$

$$
EAX\leftarrow EAX-10
$$

常见标志：

- `ZF`：结果是否为 0；
- `SF`：结果符号位；
- `CF`：无符号进位/借位；
- `OF`：有符号溢出。

这四个标志在后面的 `CMP + Jxx` 中会反复使用。

## 4.4.6 MUL / IMUL

以经典 x86 单操作数 32 位形式为例：

```asm
mul ebx
```

无符号完整乘积放入：

$$
EDX:EAX\leftarrow EAX\times EBX
$$

即高 32 bit 在 EDX，低 32 bit 在 EAX。

`IMUL` 对应有符号乘法，并存在多种显式目的操作数形式。

> **注意**
>
> 不能仅凭助记符“乘法”就假定结果仍只有一个寄存器宽度。题目若涉及溢出，必须关注完整乘积和目标位数。

## 4.4.7 DIV / IDIV

32 位 `div ecx` 的经典模型：

- 被除数：`EDX:EAX`；
- 除数：`ECX`；
- 商：`EAX`；
- 余数：`EDX`。

有符号除法常见：

```asm
cdq
idiv ecx
```

`CDQ` 将 EAX 的符号扩展到 EDX，为有符号被除数准备高位。

可能产生除法异常的典型情况：

1. 除数为 0；
2. 商无法用规定的目标宽度表示。

## 4.4.8 AND / OR / XOR / NOT

- `AND`：常用于清零某些位；
- `OR`：常用于置 1；
- `XOR`：常用于翻转，`xor eax,eax` 可把 EAX 清零；
- `NOT`：逐位取反。

> **NOT ≠ 取负。**
>
> 二进制补码取负通常是“按位取反再加 1”。

## 4.4.9 INC / DEC 与“等价指令”陷阱

数值上：

$$
x\leftarrow x+1
$$

或：

$$
x\leftarrow x-1
$$

但 ISA 对标志位的定义可能不同。经典 x86 中 `INC/DEC` 不修改 `CF`，因此不能认为 `INC x` 与 `ADD x,1` 在所有架构状态上完全等价。

## 4.4.10 CMP：做减法但不保存结果

```asm
cmp eax, ebx
```

内部相当于计算：

$$
EAX-EBX
$$

但不把差写回 EAX，只更新条件标志。

所以看到：

```asm
cmp eax, ebx
jg  L1
```

应理解为：

1. 比较 EAX 与 EBX；
2. 标志位记录比较关系；
3. `JG` 根据有符号比较条件决定是否转移。

## 4.4.11 逻辑移位、算术移位、循环移位

| 指令 | 语义 |
| --- | --- |
| `SHL/SAL` | 左移，低位补 0 |
| `SHR` | 逻辑右移，高位补 0 |
| `SAR` | 算术右移，高位补原符号位 |
| `ROL/ROR` | 循环移位 |

对于补码有符号数，`SAR` 的关键是维持符号扩展。

例如 8 bit：

```text
11110000  (-16)
SAR 1
11111000  (-8)
```

## 4.4.12 移位与乘除 $2^k$ 的关系

在不发生溢出且语义允许时，左移 $k$ 位常对应乘以：

$$
2^k
$$

无符号数逻辑右移 $k$ 位常对应整除：

$$
2^k
$$

有符号数右移应关注舍入规则与 ISA 语义，不能机械套用“除以 $2^k$”而忽略负数处理。

## 4.4.13 做汇编题时优先写 RTL

例如：

```asm
add eax, [ebx+4]
```

先翻译：

$$
EA=(EBX)+4
$$

再写：

$$
EAX\leftarrow EAX+M[EA]
$$

这种写法能把寻址、访存和 ALU 运算拆开，特别适合后续 CPU 数据通路综合题。
