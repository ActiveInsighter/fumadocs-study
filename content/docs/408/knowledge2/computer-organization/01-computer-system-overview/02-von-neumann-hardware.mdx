冯·诺依曼结构的核心不是“有五大部件”这一句本身，而是 **存储程序思想**：程序能够像数据一样存入存储器，由机器自动逐条取出和执行。

## 1.2.1 存储程序思想

**存储程序（Stored Program）** 的基本思想是：

> 程序指令和程序处理的数据都以二进制形式存放在存储器中，计算机按照程序规定的控制流程自动取出并执行指令。

这使程序不必通过重新接线来改变计算任务，而可以通过修改存储器中的程序实现通用计算。

## 1.2.2 冯·诺依曼机的基本特征

经典教材通常概括为：

1. 硬件由 **运算器、控制器、存储器、输入设备、输出设备** 五大部件组成；
2. **指令和数据以同等地位存放在存储器中**；
3. 指令和数据都用二进制表示；
4. 指令通常由操作码、地址码等字段构成；
5. 经典冯·诺依曼结构通常表述为 **以运算器为中心**。

> **易错点｜“同等地位”不等于“CPU 无法区分”**
>
> 指令和数据在存储器中本质上都只是二进制位串，**形式上没有天然标签**。CPU 根据当前控制过程、地址来源和指令语义，把某些位串解释为指令，把另一些位串作为数据使用。

## 1.2.3 五大部件及作用

| 部件 | 主要作用 | 后续章节关联 |
| --- | --- | --- |
| 运算器 ALU | 完成算术、逻辑、移位、比较等运算 | 数据表示、CPU |
| 控制器 CU | 取指、译码并产生控制信号 | CPU、控制器 |
| 存储器 Memory | 存放程序、数据及中间结果 | 存储系统 |
| 输入设备 Input | 将外部信息送入计算机 | I/O 系统 |
| 输出设备 Output | 将处理结果送到外部 | I/O 系统 |

现代处理器内部的执行单元远比一个简单 ALU 复杂，但在 408 的基础模型中，仍从这五类功能理解整机。

## 1.2.4 运算器与控制器

### 运算器

运算器主要负责数据处理，例如：

- 整数加减；
- 逻辑与、或、非、异或；
- 移位；
- 大小比较；
- 浮点运算等。

### 控制器

控制器负责组织指令的执行过程，基本逻辑可抽象为：

```text
取指 → 译码 → 形成控制信号 → 执行 / 写回
```

运算器和控制器构成 CPU 的核心功能。现代 CPU 还包含寄存器、Cache、流水线控制等大量结构。

## 1.2.5 存储器与 I/O

存储器保存：

- 机器指令；
- 操作数；
- 中间结果；
- 最终结果。

后续会进一步形成：

```text
寄存器 → Cache → 主存 → 辅存
```

I/O 设备的速度和工作方式往往与 CPU、主存差异很大，因此需要：

- I/O 接口；
- 总线或互连；
- 中断；
- DMA；

来完成协调和数据交换。

## 1.2.6 经典模型与现代计算机

经典冯·诺依曼机常称“以运算器为中心”。现代计算机则大量采用以存储系统和总线/互连为核心的数据交换方式，不再要求所有数据都先经过 ALU。

复习时按题目语境判断：

- 问“冯·诺依曼机基本特点”时，按经典教材表述；
- 问“现代计算机实际组织”时，应认识到 CPU、存储器和 I/O 可通过总线/互连直接交换数据。

> **易错点｜五大部件是功能划分，不等于五块独立芯片**
>
> 现代 SoC 可以把 CPU、内存控制器、I/O 控制器等集成到一颗芯片中，但功能上仍能对应到运算、控制、存储和输入输出等基本职责。

## 1.2.7 指令执行的整机视角

一条机器指令的执行往往需要多个部件协作：

```text
PC 给出指令地址
    ↓
主存 / Cache 提供指令
    ↓
控制器译码
    ↓
寄存器 / 存储器提供操作数
    ↓
ALU 或其他执行部件运算
    ↓
结果写回寄存器或存储器
```

这个过程把本章与后续 **指令系统、存储系统、CPU 数据通路** 连成一条主线。
