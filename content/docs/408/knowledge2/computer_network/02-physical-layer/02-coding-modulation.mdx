## 十一、编码

> **真题考察**
>
> * 2015 年第 34 题
> * 2021 年第 34 题

编码的目标是：

> 将数字数据转换成适合在数字信道上传输的数字信号。

<InlineSvg src="/images/computer-network/computer-network-physical-encoding-001.svg" alt={"编码和调制 图 1"} />

常见编码包括：

* 归零编码 RZ；
* 不归零编码 NRZ；
* 反向不归零编码 NRZI；
* 曼彻斯特编码；
* 差分曼彻斯特编码。

### 1. RZ

RZ 即 Return to Zero，归零编码。

一种常见的单极性表示方式为：

* 1：前半周期为高电平，后半周期回到零；
* 0：保持零电平。

特点是每个码元周期内都可能返回零电平，因此同步信息较丰富，但需要更高的信号变化频率。

### 2. NRZ

NRZ 即 Non-Return-to-Zero，不归零编码。

典型表示：

* 1：高电平；
* 0：低电平。

一个比特周期内电平通常保持不变。

优点是编码简单、所需带宽较低；缺点是连续大量相同比特时缺少跳变，不利于时钟同步。

### 3. NRZI

NRZI 即 Non-Return-to-Zero Inverted。

它不直接使用高、低电平表示数据，而是利用：

> **码元开始处是否发生跳变**

来表示 0 和 1。

按照本章采用的约定：

* 0：发生跳变；
* 1：不发生跳变。

NRZI 属于差分编码，因此解码时关注的是“变没变”，而不是当前究竟是高电平还是低电平。

### 4. 曼彻斯特编码

曼彻斯特编码要求：

> 每一个比特周期的中间都必须发生一次跳变。

按照本章采用的约定：

* 1：中间由高变低；
* 0：中间由低变高。

因为每个比特中间都有跳变，所以接收端可以利用这一跳变提取时钟信息。

#### 曼彻斯特编码的特点

* 自同步能力强；
* 每个比特至少存在一次跳变；
* 信号变化频繁；
* 所需频带通常比 NRZ 更宽。

### 5. 差分曼彻斯特编码

差分曼彻斯特编码中：

* 每个比特周期中间一定发生跳变，用于同步；
* 数据由比特开始处是否发生跳变来表示。

按照本章采用的约定：

* 0：比特开始处发生跳变；
* 1：比特开始处不发生跳变。

> **注意**
>
> 不同教材可能采用相反的 0/1 映射约定。
>
> 考试时真正应该识别的是编码规则本身，而不是死记某幅图中高低电平的绝对方向。

### 6. NRZI 与差分曼彻斯特的初始电平

二者都属于差分思想，因此数据取决于：

> **相对于前一个电平是否发生变化**

而不是绝对高低电平。

如果没有给出初始电平，仅根据数据序列无法唯一确定整幅波形。

初始电平不同只会使整个波形上下翻转，并不会改变数据所表达的内容。

### 7. 编码方式对比

| 编码     | 判断依据    | 主要特征      |
| ------ | ------- | --------- |
| RZ     | 电平并归零   | 一个码元内回到零  |
| NRZ    | 高低电平    | 一个比特期间不归零 |
| NRZI   | 是否跳变    | 差分编码      |
| 曼彻斯特   | 中间跳变方向  | 每比特中间必跳变  |
| 差分曼彻斯特 | 开始处是否跳变 | 中间始终跳变    |

> **记忆**
>
> * NRZ：看“电平”。
> * NRZI：看“变不变”。
> * 曼彻斯特：看“中间怎么变”。
> * 差分曼彻斯特：中间必变，数据看开始处。

## 十二、调制

> **真题考察**
>
> * 2009 年第 34 题
> * 2011 年第 34 题
> * 2024 年第 34 题

调制主要用于：

> 将数字数据映射到模拟载波的某些参数上，使其能够通过模拟信道或带通信道传播。

<InlineSvg src="/images/computer-network/computer-network-physical-encoding-002.svg" alt={"编码和调制 图 2"} />

最常见的四种数字调制方式为：

* ASK；
* FSK；
* PSK；
* QAM。

### 1. ASK

ASK：Amplitude Shift Keying，幅移键控。

通过改变载波的**振幅**表示不同的数据。

例如：

* 较小振幅表示 0；
* 较大振幅表示 1。

### 2. FSK

FSK：Frequency Shift Keying，频移键控。

通过改变载波的**频率**表示数据。

例如：

* 一种频率表示 0；
* 另一种频率表示 1。

### 3. PSK

PSK：Phase Shift Keying，相移键控。

通过改变载波的**相位**表示数据。

例如二进制相移键控中可以使用：

* 0°；
* 180°。

表示不同的二进制数据。

### 4. QAM

QAM：Quadrature Amplitude Modulation，正交振幅调制。

QAM 同时改变：

* 振幅；
* 相位。

因此一个码元可以拥有大量不同状态。

例如 16-QAM 有 16 种状态：

$$
\log_2 16=4
$$

所以一个码元可以携带：

$$
4\ \mathrm{bit}
$$

数据。

### 5. 四种调制方法对比

| 调制方式 | 改变的参数   |
| ---- | ------- |
| ASK  | 振幅      |
| FSK  | 频率      |
| PSK  | 相位      |
| QAM  | 振幅 + 相位 |

> **408 速记**
>
> ASK 看“高不高”，FSK 看“快不快”，PSK 看“相位”，QAM 同时看“振幅和相位”。
