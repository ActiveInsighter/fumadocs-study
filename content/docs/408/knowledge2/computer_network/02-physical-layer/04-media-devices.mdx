## 23. 物理层设备的判断方法

判断网络设备层次时，不要只背设备名称，优先问：

> **这个设备能“看懂”到哪一层的信息？**

典型层次链：

```text
中继器 / 集线器：比特和物理信号
二层交换机：帧、MAC 地址
路由器：IP 分组、IP 地址
```

网卡比较特殊，它通常同时实现物理层和数据链路层的一部分功能。

## 24. 中继器

![物理层设备 图 2](/images/computer-network/computer-network-physical-dev-002.jpg)

**中继器（Repeater）**&#x2060;工作在物理层，主要用于延长数字信号能够可靠传播的距离。

数字信号长距离传输后可能出现衰减、畸变。中继器对收到的数字信号进行：

- 接收；
- 判决与整形；
- 再生；
- 重新发送。

它不会：

- 解析帧首部；
- 根据 MAC 地址选择端口；
- 查看 IP 地址；
- 执行路由选择。

<Callout type="warning" title="中继器不是简单模拟放大器">

对数字信号，更准确的理解是“再生出新的标准数字波形再发送”，而不是把有用信号与噪声一起无条件放大。

</Callout>

## 25. 集线器

<InlineSvg src="/images/computer-network/computer-network-physical-dev-001.svg" alt={"物理层设备 图 1"} />

**集线器（Hub）**&#x2060;工作在物理层，可以理解为**多端口中继器**。

某端口收到物理信号后，集线器会进行必要的再生，并把信号转发到其他相关端口。

它：

- 不学习 MAC 地址；
- 不解析帧；
- 不根据目的 MAC 地址定向转发；
- 本质上只处理物理信号和比特。

因此传统共享式以太网中，连接在同一集线器上的主机共享通信资源，并处于同一冲突域。

### 25.1 与二层交换机的区别

| 对比项 | 集线器 Hub | 二层交换机 Switch |
| --- | --- | --- |
| 工作层 | 物理层 | 数据链路层 |
| 处理对象 | 比特/信号 | 帧 |
| 是否识别 MAC | 否 | 是 |
| 转发方式 | 广泛复制物理信号 | 根据 MAC 表定向转发 |
| 冲突域 | 多端口共享一个冲突域 | 每个交换端口通常独立冲突域 |

> **设备判断**：Hub 看到的是**比特**，Switch 看到的是**帧**，Router 看到的是**IP 分组**。

## 26. 网络适配器（网卡）

![物理层设备 图 3](/images/computer-network/computer-network-physical-dev-003.jpg)

网络适配器又称：

- Network Adapter；
- Network Interface Card；
- NIC；
- 网卡。

它是主机连接网络的重要接口硬件，通常横跨：

- **物理层功能**：比特与物理信号转换、发送接收、连接传输介质；
- **数据链路层功能**：帧的收发、MAC 地址处理、差错检测等具体网卡功能。

网卡通常具有 MAC 地址，用于局域网中的链路层寻址。

<Callout type="warning" title="网卡不是“纯物理层设备”">

考试若问 NIC 涉及哪些层，应注意它通常同时实现物理层和数据链路层的部分功能。

</Callout>

## 27. 传输介质的分类

传输介质可先分为两大类：

### 27.1 导向传输介质

电磁波被限制在实体介质中传播，典型包括：

- 双绞线；
- 同轴电缆；
- 光纤。

### 27.2 非导向传输介质

信号通过自由空间传播，例如无线电、微波、卫星链路等。

<Callout type="info" title="介质不是物理层协议">

传输介质位于物理通信环境中。教材有时把它与物理层一起讲，但不要把“铜缆、光纤、无线电波”理解成协议本身。

</Callout>

## 28. 双绞线、同轴电缆与光纤

![物理层设备 图 4](/images/computer-network/computer-network-physical-dev-004.jpg)
![物理层设备 图 5](/images/computer-network/computer-network-physical-dev-005.webp)

### 28.1 双绞线

双绞线由两根绝缘铜导线按一定节距相互绞合。

绞合的重要目的之一是：

> **降低外界电磁干扰，并减小线对之间的串扰。**

特点通常包括成本较低、布线方便，是局域网常见铜缆介质。

### 28.2 同轴电缆

![物理层设备 图 6](/images/computer-network/computer-network-physical-dev-006.png)

同轴电缆通常包括：

1. 中心导体；
2. 绝缘层；
3. 金属屏蔽层；
4. 外护套。

其屏蔽结构使其具有较好的抗电磁干扰能力，历史上广泛用于早期以太网、有线电视与宽带接入等场景。

### 28.3 光纤

光纤使用光信号传输信息。纤芯和包层具有不同折射率，在满足条件时光可通过全反射沿光纤传播。

常见优势：

- 可提供很高的通信容量；
- 适合较长距离；
- 衰减相对较小；
- 不受电磁干扰；
- 电气隔离性好。

### 28.4 单模与多模的基本辨析

- **单模光纤**：主要允许单一传播模式，模间色散小，适合更高带宽和更长距离；
- **多模光纤**：允许多个传播模式，设备成本可较低，但更容易受到模间色散影响。

<Callout type="warning" title="传播速度和数据率是两个概念">

光纤“带宽高”指可支持高数据率，不意味着其中单个信号一定比所有铜缆中的电磁波“传播得快很多”。发送能力和传播速度必须分开判断。

</Callout>

## 29. 非导向介质与无线传播

无线通信不依赖实体导线把信号限制在固定路径中，而是利用电磁波在自由空间传播。

做 408 概念题时可抓住以下特点：

- 便于移动通信与广播；
- 传播范围、方向性和绕射能力与频率相关；
- 容易受到同频干扰、遮挡、多径等无线环境因素影响；
- 微波等较高频段常具有较强方向性，工程上通常要求更明确的视距或定向传播条件。

这一部分一般以概念辨析为主，不需要在本章额外引入复杂无线传播模型。

## 30. 设备与介质横向比较

| 对象 | 层次/性质 | 主要处理对象 | 核心作用 |
| --- | --- | --- | --- |
| 中继器 | 物理层设备 | 比特/信号 | 再生信号、延长距离 |
| 集线器 | 物理层设备 | 比特/信号 | 多端口物理转发 |
| 网卡 | 物理层 + 数据链路层 | 信号、帧 | 主机接入网络 |
| 二层交换机 | 数据链路层设备 | 帧 | 按 MAC 地址转发 |
| 路由器 | 网络层设备 | IP 分组 | 按 IP 信息路由转发 |
| 双绞线 | 导向介质 | 电信号 | 常见铜缆接入 |
| 同轴电缆 | 导向介质 | 电信号 | 屏蔽较好 |
| 光纤 | 导向介质 | 光信号 | 高速、长距离、抗电磁干扰 |
| 无线介质 | 非导向介质 | 电磁波 | 支持无线与移动传播 |

## 31. 全章易错点与真题速查

### 31.1 十个高频易错点

1. **码元不等于比特**：$R_b=R_s\log_2V$。
2. **Hz 带宽与 bit/s 带宽不是同一物理量**，先看题目语境与单位。
3. **发送时延与传播时延不同**：前者是 $L/R$，后者是 $d/v$。
4. **单向链路的时延带宽积使用单向传播时延**：$R\cdot T_{\text{prop}}$。
5. **奈奎斯特与香农限制角度不同**，同时给条件时通常两者都要算。
6. **香农公式中的 $S/N$ 不能直接代 dB**：先转为 $10^{\mathrm{SNR}_{dB}/10}$。
7. **差分编码看“变不变”**，不能只看绝对高低电平。
8. **分组交换可以流水**，不能把单分组端到端时间简单乘分组数。
9. **虚电路仍属于分组交换**，逻辑连接不等于专用物理电路，也不天然可靠。
10. **集线器不识别 MAC 地址**，它工作在物理层。
