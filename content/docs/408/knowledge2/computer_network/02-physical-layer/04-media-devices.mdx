## 23. 物理层设备的判断方法

判断网络设备层次时，不要只背设备名称，优先问：

> **这个设备为了完成核心转发功能，需要理解到哪一层的信息？**

典型层次链：

```text
中继器 / 集线器：比特和物理信号
二层交换机：帧、MAC 地址
路由器：IP 分组、IP 地址
```

网卡比较特殊，它通常同时实现物理层和数据链路层的一部分功能。

## 24. 中继器

![物理层设备 图 2](/images/computer-network/computer-network-physical-dev-002.jpg)

**中继器（Repeater）**工作在物理层，主要用于延长数字信号能够可靠传播的距离。

数字信号长距离传输后可能出现衰减、波形畸变。中继器对收到的数字信号进行：

- 接收；
- 判决与整形；
- 再生；
- 重新发送。

它不会：

- 解析帧首部；
- 根据 MAC 地址选择端口；
- 查看 IP 地址；
- 执行路由选择。

中继器连接的网段在逻辑上仍属于同一共享介质范围，因此**不能隔离冲突域，也不能隔离广播域**。

<Callout type="warning" title="中继器不是简单模拟放大器">

对数字信号，更准确的理解是“判决后再生出新的标准数字波形再发送”，而不是把有用信号和噪声一起无条件放大。

</Callout>

## 25. 集线器

<InlineSvg src="/images/computer-network/computer-network-physical-dev-001.svg" alt={"物理层设备 图 1"} />

**集线器（Hub）**工作在物理层，可以理解为**多端口中继器**。

某端口收到物理信号后，集线器会进行必要的再生，并把信号复制到其他端口。它：

- 不学习 MAC 地址；
- 不解析帧；
- 不根据目的 MAC 地址定向转发；
- 本质上只处理物理信号和比特。

传统共享式以太网中，连接在同一集线器上的主机：

- 共享同一冲突域；
- 共享集线器所连接的介质带宽；
- 通常按半双工共享介质方式工作；
- 集线器不能隔离广播域。

### 25.1 与二层交换机的区别

| 对比项 | 集线器 Hub | 二层交换机 Switch |
| --- | --- | --- |
| 工作层 | 物理层 | 数据链路层 |
| 处理对象 | 比特/信号 | 帧 |
| 是否识别 MAC | 否 | 是 |
| 转发方式 | 向其他端口复制物理信号 | 根据 MAC 表选择端口转发 |
| 冲突域 | 多端口共享一个冲突域 | 每个交换端口通常独立冲突域 |
| 广播域 | 不能隔离 | 默认也不隔离，VLAN/路由另论 |
| 端口带宽 | 共享 | 交换端口通常可独立使用链路带宽 |

> **设备判断**：Hub 看的是**比特**，Switch 看的是**帧**，Router 看的是**IP 分组**。

## 26. 网络适配器（网卡）

![物理层设备 图 3](/images/computer-network/computer-network-physical-dev-003.jpg)

网络适配器又称 Network Adapter、Network Interface Card、NIC、网卡。

它是主机连接网络的重要接口硬件，通常横跨：

- **物理层功能**：比特与物理信号转换、发送接收、连接传输介质；
- **数据链路层功能**：帧的收发、MAC 地址处理、差错检测等。

网卡通常具有 MAC 地址，用于局域网中的链路层寻址；主机 CPU 与网卡之间还会通过设备接口、DMA/中断等机制交换数据，但这些属于计算机组成原理和操作系统中的 I/O 管理问题。

<Callout type="warning" title="网卡不是纯物理层设备">

考试若问 NIC 涉及哪些层，应注意它通常同时实现物理层和数据链路层的部分功能。

</Callout>

## 27. 传输介质的分类

传输介质可先分为两大类。

### 27.1 导向传输介质

电磁能量被限制在实体介质中传播，典型包括：

- 双绞线；
- 同轴电缆；
- 光纤。

### 27.2 非导向传输介质

信号通过自由空间传播，例如无线电、微波、卫星链路等。

<Callout type="info" title="介质不是协议">

传输介质属于物理通信环境。教材常把它与物理层一起讲，但“铜缆、光纤、无线电波”本身不是网络协议。

</Callout>

## 28. 双绞线、同轴电缆与光纤

![物理层设备 图 4](/images/computer-network/computer-network-physical-dev-004.jpg)
![物理层设备 图 5](/images/computer-network/computer-network-physical-dev-005.webp)

### 28.1 双绞线

双绞线由两根绝缘铜导线按一定节距相互绞合。

绞合的重要目的之一是：

> **减小外界电磁干扰，并降低线对之间的串扰。**

其成本较低、布线方便，是局域网中非常常见的铜缆介质。按是否额外设置屏蔽层，还可区分非屏蔽双绞线和屏蔽双绞线等类型。

### 28.2 同轴电缆

![物理层设备 图 6](/images/computer-network/computer-network-physical-dev-006.png)

同轴电缆通常包括：

1. 中心导体；
2. 绝缘层；
3. 金属屏蔽层；
4. 外护套。

由于导体与屏蔽层同轴布置，抗外界电磁干扰能力较好，历史上广泛用于早期以太网、有线电视与宽带接入等场景。

### 28.3 光纤

光纤使用光信号传输信息。纤芯和包层具有不同折射率，在满足条件时，光可利用全反射沿光纤传播。

常见优势：

- 可支持很高的数据传输能力；
- 适合较长距离；
- 衰减相对较小；
- 不受电磁干扰；
- 电气隔离性好，且较难从介质外直接感应窃听。

### 28.4 单模与多模的基本辨析

| 对比项 | 单模光纤 | 多模光纤 |
| --- | --- | --- |
| 传播模式 | 主要为单一模式 | 多种模式 |
| 纤芯 | 通常较细 | 通常较粗 |
| 模间色散 | 小 | 较明显 |
| 适用距离 | 更长 | 相对较短 |
| 典型能力 | 高带宽、长距离 | 短距离接入常见 |

<Callout type="warning" title="传播速度和数据率是两个概念">

光纤“带宽高”是指可支持高数据率，不代表其中某个比特的传播速度必然远高于铜缆中的电磁波。**数据传输速率**和**信号传播速度**必须分开判断。

</Callout>

## 29. 非导向介质与无线传播

无线通信不依赖实体导线把信号限制在固定路径中，而是利用电磁波在自由空间传播。

408 概念题可抓住：

- 便于移动通信、广播和灵活部署；
- 传播范围、方向性、绕射能力与频率相关；
- 容易受到同频干扰、遮挡、衰落和多径传播影响；
- 微波等较高频段方向性更强，工程上常需要视距或定向天线；
- 卫星通信本质上仍利用无线电/微波传播，但传播距离大，因此传播时延不可忽视。

本章通常只做定性辨析，不需要引入复杂无线传播模型。

## 30. 设备与介质横向比较

| 对象 | 层次/性质 | 主要处理对象 | 核心作用 |
| --- | --- | --- | --- |
| 中继器 | 物理层设备 | 比特/信号 | 再生信号、延长距离 |
| 集线器 | 物理层设备 | 比特/信号 | 多端口信号复制与共享介质连接 |
| 网卡 | 物理层 + 数据链路层 | 信号、帧 | 主机接入网络 |
| 二层交换机 | 数据链路层设备 | 帧 | 按 MAC 地址转发 |
| 路由器 | 网络层设备 | IP 分组 | 按 IP 信息路由转发 |
| 双绞线 | 导向介质 | 电信号 | 常见铜缆接入 |
| 同轴电缆 | 导向介质 | 电信号 | 屏蔽较好 |
| 光纤 | 导向介质 | 光信号 | 高速、长距离、抗电磁干扰 |
| 无线介质 | 非导向介质 | 电磁波 | 支持无线与移动传播 |

## 31. 全章易错点与真题速查

### 31.1 高频易错点

1. **码元不等于比特**：$R_b=R_s\log_2V$。
2. **Hz 带宽与 bit/s 带宽不是同一物理量**：先看语境和单位。
3. **发送时延与传播时延不同**：前者是 $L/R$，后者是 $d/v$。
4. **单向链路的时延带宽积使用单向传播时延**：$R\cdot T_{\text{prop}}$。
5. **奈奎斯特与香农限制角度不同**：条件同时给出时，两者都要检查。
6. **香农公式中的 $S/N$ 不能直接代 dB**：先转成 $10^{\mathrm{SNR}_{\mathrm{dB}}/10}$。
7. **差分编码看“变不变”**：不能只看绝对高低电平，初始电平也可能影响整幅波形上下翻转。
8. **曼彻斯特每比特中点必跳变**，但“实际跳变率/码元率”要按题目对信号元素的定义判断。
9. **分组交换可以流水**：不能把单分组端到端时间简单乘分组数。
10. **分组首部也要发送**：计算链路发送时延时要使用真实在线长度。
11. **虚电路仍属于分组交换**：逻辑连接不等于专用物理电路，也不要求天然预留带宽。
12. **虚电路面向连接不代表天然可靠**：可靠性取决于协议机制。
13. **集线器不识别 MAC 地址**：它工作在物理层，不能隔离冲突域或广播域。
14. **网卡通常跨物理层和数据链路层**：不要机械归成纯物理层设备。
15. **光纤数据率高不等于传播速度一定更快**：发送能力与传播速度是不同物理量。
