OSI 参考模型的价值不在于“互联网真的严格按七层实现”，而在于它提供了一套非常清晰的**功能分层坐标系**。

> **真题标签**
>
> OSI 模型：2009 年第 33 题、2010 年第 33 题、2013 年第 33 题、2014 年第 33 题、2016 年第 33 题、2017 年第 33 题、2019 年第 33 题、2021 年第 33 题、2022 年第 33 题、2026 年第 33 题。

## 1.3.1 七层顺序

从低到高：

```text
7 应用层
6 表示层
5 会话层
4 传输层
3 网络层
2 数据链路层
1 物理层
```

中文速记：

> **物、链、网、输、会、示、用。**

更重要的是建立“服务范围”概念：

```text
物理/链路：围绕一段具体链路
网络层：主机到主机、跨网络
传输层：进程到进程、端到端
应用层：具体网络应用语义
```

## 1.3.2 物理层：传比特

物理层关注：

> **如何把 0 和 1 变成真实可传输的物理信号。**

典型问题：

- 机械、电气、功能和规程特性；
- 传输介质；
- 信号编码、调制；
- 数据率；
- 接口针脚和电平。

PDU 视角通常记为：**Bit，比特**。

典型设备：

- 中继器；
- 集线器。

## 1.3.3 数据链路层：相邻结点传帧

数据链路层在一段链路上，把网络层交下来的数据组织成**帧**。

主要功能：

- 组帧；
- 物理寻址（如 MAC 地址）；
- 差错检测与必要的可靠传输机制；
- 流量控制；
- 介质访问控制。

服务范围重点记忆：

> **相邻结点之间的一跳传输。**

例如：

```text
主机 A → 路由器 R1 → 路由器 R2 → 主机 B
```

链路层分别处理：

```text
A ↔ R1
R1 ↔ R2
R2 ↔ B
```

而不是把 A 到 B 整条路径当作“一条链路”。

## 1.3.4 网络层：跨网络传分组

网络层要解决：

> **分组从源主机如何跨越多个网络到达目的主机。**

主要功能：

- 逻辑寻址（IP 地址）；
- 路由选择；
- 分组转发；
- 异构网络互联；
- 某些体系中的拥塞相关功能。

典型协议：IP。

典型设备：路由器。

服务对象可理解为：**主机到主机**。

## 1.3.5 传输层：进程到进程

传输层是 OSI 中自下而上第一个典型的**端到端层**。

它关注：

> **源主机中的应用进程与目的主机中的应用进程之间如何通信。**

典型功能：

- 复用与分用；
- 端口寻址；
- 可靠传输；
- 流量控制；
- 差错恢复；
- 连接管理。

典型协议：TCP、UDP。

<Callout type="warn" title="点到点、主机到主机、端到端">
408 中最容易混淆的是：链路层强调相邻结点的一跳传输；网络层负责跨网络的主机到主机；传输层进一步定位到主机中的具体进程。
</Callout>

## 1.3.6 会话层：管理会话

会话层主要负责：

- 建立会话；
- 管理会话；
- 终止会话；
- 对话控制；
- 同步点 / 检查点。

可以把它理解为：

> **决定双方怎样开始谈、怎样继续谈、故障后从哪里接着谈。**

## 1.3.7 表示层：统一表示

表示层解决不同系统之间的数据表示差异：

- 字符编码转换；
- 数据格式转换；
- 压缩 / 解压；
- 加密 / 解密。

一句话：

> **表示层关心“数据以什么形式表达”。**

## 1.3.8 应用层：直接服务网络应用

应用层面向具体网络应用，为用户进程提供网络服务。

常见协议：

- HTTP；
- FTP；
- SMTP；
- DNS；
- DHCP。

“应用层协议”并不意味着协议运行逻辑全部位于某个 GUI 应用程序中，而是强调它描述**应用进程之间的网络通信规则**。

## 1.3.9 七层总表

| 层 | 名称 | 典型功能 | 关键标识/对象 | 常见 PDU |
| ---: | --- | --- | --- | --- |
| 7 | 应用层 | 面向应用提供网络服务 | 域名、URL 等应用标识 | Data |
| 6 | 表示层 | 编码、压缩、加密 | 数据表示 | Data |
| 5 | 会话层 | 会话管理、同步 | 会话 | Data |
| 4 | 传输层 | 进程到进程 | 端口号 | Segment / Datagram |
| 3 | 网络层 | 路由与转发 | IP 地址 | Packet / IP Datagram |
| 2 | 数据链路层 | 相邻结点传帧 | MAC 地址 | Frame |
| 1 | 物理层 | 传比特 | 物理信号 | Bit |

## 1.3.10 高频反向判断

看到题干关键词时可以快速定位：

```text
电压 / 信号 / 介质       → 物理层
帧 / MAC / 相邻结点      → 数据链路层
IP / 路由 / 分组         → 网络层
端口 / 进程 / 可靠端到端 → 传输层
会话 / 检查点            → 会话层
编码 / 压缩 / 加密       → 表示层
HTTP / DNS / FTP         → 应用层
```
