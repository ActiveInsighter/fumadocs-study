网络设备题本质上考两件事：

1. **设备能理解到协议栈的哪一层？**
2. **它依据什么信息决定转发或过滤？**

> **真题标签**
>
> 设备层次、冲突域与广播域：2010 年第 38 题、2016 年第 33 题、2016 年第 35 题、2020 年第 35 题。

## 1.6.1 中继器 Repeater

工作层次：**物理层**。

主要作用：

- 再生信号；
- 整形；
- 延长传输距离。

它不理解：

- 帧；
- MAC 地址；
- IP 地址。

因此通常：

- 不隔离冲突域；
- 不隔离广播域。

## 1.6.2 集线器 Hub

集线器可以看作：

> **多端口中继器。**

它收到某端口的物理信号后，会在其他端口重复传播。

特点：

```text
物理层设备
不学习 MAC 地址
共享传输介质
半双工共享以太网中可能发生冲突
```

因此：

> **同一 Hub 上的设备处于同一个冲突域，也处于同一个广播域。**

## 1.6.3 网桥 Bridge

工作层次：**数据链路层**。

网桥会根据 MAC 地址进行帧过滤和转发。

与 Hub 的本质区别是：

> Hub 只复制信号；Bridge 能理解帧并作转发决策。

因此网桥可以分割冲突域，但普通网桥不会天然隔离二层广播域。

## 1.6.4 二层交换机 Switch

交换机可理解为高性能、多端口网桥。

它的关键机制是：

- 学习源 MAC 地址；
- 建立 MAC 地址表；
- 根据目的 MAC 地址选择端口转发；
- 未知单播与广播可能进行泛洪。

现代交换式全双工以太网中，一个交换机端口连接一台主机时，该链路通常不再发生经典共享介质冲突。

考试按传统“冲突域划分”口径记：

> **交换机的不同端口属于不同冲突域。**

普通二层交换机默认仍处于同一广播域，除非使用 VLAN 等机制进一步划分。

## 1.6.5 路由器 Router

工作层次：**网络层**。

主要依据：

- 目的 IP 地址；
- 路由表 / 转发表；

选择下一跳和出接口。

路由器会终止当前二层帧，在新的链路上重新封装，因此不同路由接口天然形成不同的二层广播范围。

通常记忆：

> **路由器既隔离冲突域，也隔离二层广播域。**

## 1.6.6 冲突域

冲突域强调：

> **共享介质上的设备是否可能因同时发送而发生碰撞。**

经典半双工共享以太网使用 CSMA/CD 时：

```text
多台主机共享同一介质
        ↓
若同时发送
        ↓
可能发生碰撞
```

典型结论：

- Hub：不分割冲突域；
- Bridge / Switch：分割冲突域；
- Router：不同接口进一步隔开链路。

<Callout type="info" title="现代全双工交换以太网">
现代交换机端口通常工作在全双工点到点链路上，经典“碰撞”已经很少真正出现；但 408 的设备判断仍会使用“交换机每端口划分冲突域”的传统模型表述。
</Callout>

## 1.6.7 广播域

广播域强调：

> **一个二层广播帧能够传播到的范围。**

普通二层交换机会把广播帧向同一 VLAN 中其他相关端口转发。

因此：

- Hub：不隔离广播域；
- Bridge / 二层 Switch：默认不隔离广播域；
- Router：隔离二层广播域。

### VLAN 的补充

VLAN 可以在一台或多台交换机上逻辑划分多个二层广播域。

所以“交换机不能隔离广播域”更严谨的表述是：

> **普通二层交换转发本身不会跨 VLAN 自动隔离同一 VLAN 内的广播；不同 VLAN 则属于不同广播域。**

不同 VLAN 之间若要通信，需要三层转发。

## 1.6.8 设备总表

| 设备 | 最高典型层次 | 主要处理依据 | 分割冲突域 | 分割广播域 |
| --- | --- | --- | :---: | :---: |
| 中继器 | 物理层 | 信号 | ❌ | ❌ |
| 集线器 | 物理层 | 信号 | ❌ | ❌ |
| 网桥 | 数据链路层 | MAC 地址 | ✅ | ❌ |
| 二层交换机 | 数据链路层 | MAC 地址表 | ✅ | 默认 ❌ |
| 路由器 | 网络层 | IP 地址、路由表 | ✅ | ✅ |

## 1.6.9 “层次—地址—设备”对应

| 层次 | 典型地址 / 标识 | 典型设备 |
| --- | --- | --- |
| 应用层 | 域名、URL | 应用服务器 |
| 传输层 | 端口号 | — |
| 网络层 | IP 地址 | 路由器 |
| 数据链路层 | MAC 地址 | 网桥、交换机 |
| 物理层 | 无逻辑网络地址 | 中继器、集线器 |

判断设备层次的最好方法是：

> **看它为了做出转发决策，必须读取到哪一层的控制信息。**

## 1.6.10 本章高频易错点

### 协议与服务

```text
同层实体：遵守协议
上下相邻层：提供 / 使用服务
```

### OSI 与 TCP/IP

```text
OSI：7 层
TCP/IP：4 层
教学常用：5 层
```

### 点到点与端到端

```text
链路层：相邻结点
网络层：主机到主机
传输层：进程到进程
```

### 交换机与路由器

```text
二层交换机：看 MAC
路由器：看 IP
```

### PDU

```text
传输层：Segment / Datagram
网络层：Packet / IP Datagram
链路层：Frame
物理层：Bit
```

## 1.6.11 一张图串完第 1 章

```text
应用进程
  │ 端口号
  ▼
传输层  TCP / UDP
  │ Segment / Datagram
  ▼
网络层  IP
  │ IP 地址 / Packet
  ▼
链路层  Ethernet 等
  │ MAC 地址 / Frame
  ▼
物理层
  │ Bit / Signal
  ▼
传输介质
```

沿途设备：

```text
中继器 / Hub       → 看物理信号
Bridge / Switch   → 看 MAC
Router            → 看 IP
```

最终要形成的不是“七层背诵表”，而是：

> **数据如何从应用进程逐层封装，经过各类设备，再在目的主机逐层解封装并交给目标进程。**
