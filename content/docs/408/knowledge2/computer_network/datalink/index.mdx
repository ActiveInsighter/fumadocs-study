title: "数据链路层"

数据链路层关注**相邻节点之间如何可靠而高效地传输帧**。学习时可以按“如何分帧 → 如何发现错误 → 如何重传 → 多个节点如何共享介质 → 交换机如何转发”的顺序理解。

| 内容 | 重点 |
| --- | --- |
| [组帧](/docs/408/knowledge2/computer_network/datalink/framing/) | 字符计数、定界符、零比特填充、违规编码 |
| [差错控制](/docs/408/knowledge2/computer_network/datalink/error/) | 奇偶校验、CRC、海明码与海明距离 |
| [流量控制](/docs/408/knowledge2/computer_network/datalink/flow_control/) | Stop-and-Wait、GBN、SR、窗口大小与信道利用率 |
| [介质访问控制](/docs/408/knowledge2/computer_network/datalink/mac/) | 信道划分、ALOHA、CSMA/CD、CSMA/CA |
| [局域网和广域网](/docs/408/knowledge2/computer_network/datalink/lan/) | 以太网、WLAN、VLAN、PPP |
| [数据链路层设备](/docs/408/knowledge2/computer_network/datalink/dev/) | MAC 地址、交换机、自学习与转发 |

> **复习提示：** ARQ 题先明确序号空间、发送/接收窗口和 ACK 含义；CSMA/CD 题先明确传播时延与最小帧长之间的关系。
