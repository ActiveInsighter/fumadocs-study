这一节把数据链路层协议落到实际 LAN/WAN：

```text
共享/交换式 LAN → Ethernet
无线 LAN         → IEEE 802.11
逻辑广播域       → VLAN
点到点 WAN 链路  → PPP
```

## 3.7.1 局域网的基本特征

局域网通常覆盖家庭、办公室、校园和企业园区。其技术特征常由三类因素决定：

1. 网络拓扑；
2. 传输介质；
3. 介质访问控制方法。

经典 LAN 可采用总线、星形、环形等拓扑；现代有线 LAN 主流是**交换式以太网**。

IEEE 802 体系中，数据链路层传统上可进一步分为：

- **LLC（Logical Link Control）子层**：向网络层提供逻辑链路相关服务；
- **MAC 子层**：处理介质访问、MAC 地址和帧传输等。

408 的以太网、WLAN、交换机题主要集中在 MAC 子层语义。

## 3.7.2 Ethernet：共享式与交换式

经典共享式半双工以太网：

- 多站共享介质；
- 存在碰撞；
- 使用 CSMA/CD。

现代交换式全双工以太网：

- 端口通常是点到点链路；
- 每个端口独立冲突域；
- 全双工时不发生共享介质碰撞；
- 不再需要执行 CSMA/CD 碰撞处理。

## 3.7.3 Ethernet 命名

经典命名如：

```text
10BASE5
10BASE2
10BASE-T
10BASE-FL
```

可理解为：

```text
速率 + BASE + 介质/形式
```

其中 `BASE` 表示基带传输，`T` 常表示双绞线。

## 3.7.4 Ethernet 帧格式

线上发送时常见顺序：

```text
Preamble(7B)
SFD(1B)
Destination MAC(6B)
Source MAC(6B)
Type/Length(2B)
Data + Padding(46~1500B)
FCS(4B)
```

### Preamble 与 SFD

- Preamble：7 B，用于时钟同步；
- SFD：1 B，标志 MAC 帧即将开始。

它们通常视为物理层辅助字段，**不计入 64～1518 B 的 Ethernet MAC 帧长度**。

### MAC 首部

- 目的 MAC：6 B；
- 源 MAC：6 B；
- Type/Length：2 B。

Ethernet II 中常作 EtherType；IEEE 802.3 语境下也可表示长度。

### 数据与填充

普通 Ethernet Payload：

```text
46~1500 B
```

若上层交下来的有效数据不足 46 B，需要 Padding 到至少 46 B。

### FCS

FCS 长度 4 B，使用 CRC 检错。

## 3.7.5 为什么最小 64 B、最大 1518 B

不含 Preamble 与 SFD：

$$
L_{\min}=6+6+2+46+4=64\ \mathrm{B}
$$

普通最大帧：

$$
L_{\max}=6+6+2+1500+4=1518\ \mathrm{B}
$$

经典 Ethernet MTU：

```text
1500 B
```

MTU 指**可承载的上层数据最大长度**，不是整个以太网帧。

<Callout type="warn" title="64 B 不含前导码和 SFD">
常规 64 B 最小帧指从 Destination MAC 到 FCS 的 MAC 帧。Preamble(7B) 和 SFD(1B) 不计入这 64 B。
</Callout>

## 3.7.6 MAC 地址

常规 MAC 地址长度：

$$
48\ \mathrm{bit}=6\ \mathrm{B}
$$

例如：

```text
00:1A:2B:3C:4D:5E
```

广播 MAC：

```text
FF:FF:FF:FF:FF:FF
```

在同一广播域内，广播帧会被相关二层设备泛洪。

MAC 与 IP 的角色：

| 地址 | 层次 | 主要作用 |
| --- | --- | --- |
| MAC | 数据链路层 | 当前链路/二层域内交付 |
| IP | 网络层 | 跨网络逻辑寻址与路由 |

经过路由器时会重新封装二层帧，所以 MAC 地址通常逐跳改变。

## 3.7.7 VLAN：逻辑划分广播域

VLAN（Virtual LAN）允许在同一物理交换网络上划分多个逻辑广播域。

例如：

```text
VLAN 10 → 财务
VLAN 20 → 技术
VLAN 30 → 人事
```

默认情况下，不同 VLAN 之间不能直接二层通信；跨 VLAN 需要路由器或三层交换功能。

### IEEE 802.1Q

802.1Q Tag 长度：

```text
4 B
```

插在：

```text
Source MAC
→ 802.1Q Tag
→ Type/Length
```

之间。

VLAN ID 字段为 12 bit：

$$
2^{12}=4096
$$

其中 0 和 4095 保留，常规可配置 VLAN ID 通常为 1～4094。

插入 4 B VLAN Tag 后，常见最大带标签 Ethernet 帧可达到：

```text
1522 B
```

> **真题标签**
>
> 2024-35 涉及 VLAN/ARP 广播域边界；2026-36 直接考 VLAN 交换机中的帧接收范围。

## 3.7.8 VLAN 内的广播与未知单播

交换机的广播/泛洪范围被 VLAN 限制：

- 广播帧只在源端口所属 VLAN 内传播；
- 未知单播也只在对应 VLAN 内泛洪；
- 不同 VLAN 不会仅靠二层交换直接互通。

因此 VLAN 的核心效果是：

> **逻辑上分隔广播域。**

## 3.7.9 广域网与 PPP

广域网跨越更大的地理范围，常依赖运营商或点到点链路连接远端网络。408 主线中的典型点到点链路层协议是 **PPP（Point-to-Point Protocol）**。

PPP 主要包含：

- **LCP**：建立、配置、测试和终止数据链路；
- **NCP**：为不同网络层协议配置参数；
- 可选身份认证机制。

PPP 可以通过 FCS 检测帧错误，但：

> **PPP 本身不提供像 GBN/SR 那样的可靠重传、序号和滑动窗口流量控制。**

因此：

```text
FCS 检错 ≠ ARQ 重传
```

## 3.7.10 HDLC：作为组帧知识的联系

HDLC 是经典面向比特链路层协议，常用：

```text
01111110
```

作标志字段，并使用**零比特填充**实现透明传输。

现行 408 大纲的广域网主线更强调 PPP，因此 HDLC 更适合作为“零比特填充/面向比特协议”的联系点，而不是本章复习中心。

## 3.7.11 LAN/WAN 一页速查

| 项目 | 核心结论 |
| --- | --- |
| Ethernet 最小帧 | 64 B |
| 普通 Ethernet 最大帧 | 1518 B |
| Ethernet MTU | 1500 B |
| 最小 Payload | 46 B |
| MAC 地址 | 48 bit |
| 广播 MAC | `FF:FF:FF:FF:FF:FF` |
| VLAN Tag | 4 B |
| VLAN ID | 12 bit，常规 1～4094 |
| VLAN 作用 | 分隔广播域 |
| PPP | 点到点、FCS 检错，不负责可靠重传 |
