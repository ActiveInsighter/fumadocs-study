TCP（Transmission Control Protocol）向应用提供**可靠、有序、无重复、全双工的字节流**。408 中，所有握手、滑动窗口和重传题都建立在两个字段上：**Sequence Number 与 Acknowledgment Number**。

> **真题标签**
>
> TCP 首部：2021 年第 39 题、2012 年第 47 题。

## 5.3.1 TCP 的基本特性

TCP 具有：

- 面向连接；
- 点到点；
- 全双工；
- 面向字节流；
- 可靠交付；
- 流量控制；
- 拥塞控制。

<Callout type="warn" title="面向字节流意味着什么">
TCP 不保留应用层的天然消息边界。应用写入多次，接收方不一定按相同次数读取；需要消息边界时由应用层协议自己定义。
</Callout>

## 5.3.2 TCP 首部长度

TCP 普通首部最小为：

$$
20\text{ B}
$$

带选项时最大可达：

$$
60\text{ B}
$$

首部长度字段以 32 bit 字为单位，因此若字段值为 5：

$$
5\times4=20\text{ B}
$$

## 5.3.3 关键字段

| 字段 | 作用 |
| --- | --- |
| Source Port / Destination Port | 复用与分用 |
| Sequence Number | 本段数据第一个字节的序号 |
| Acknowledgment Number | 下一个期望收到的字节序号 |
| Header Length | TCP 首部长度 |
| Flags | 连接与控制状态 |
| Window | 通告接收窗口 `rwnd` |
| Checksum | 伪首部 + TCP 首部 + 数据检错 |
| Urgent Pointer | `URG=1` 时有意义 |
| Options | MSS、窗口扩大、SACK、时间戳等 |

## 5.3.4 序列号：给“字节”编号

Sequence Number 为 32 bit。若某段：

```text
seq = S
数据长度 = L B
```

则该段数据字节序号范围是：

$$
S\sim S+L-1
$$

下一段连续数据的起始序号为：

$$
S+L
$$

例如：

```text
seq = 1000
数据长度 = 500 B
```

则本段覆盖：

$$
1000\sim1499
$$

下一段从 `1500` 开始。

## 5.3.5 确认号：永远指向“下一字节”

ACK 有效时：

$$
ACK=N
$$

表示：

> 序号小于 `N` 的连续字节已经正确收到，下一步期望字节 `N`。

因此若连续收到：

$$
S\sim S+L-1
$$

确认号应为：

$$
ACK=S+L
$$

这就是**累计确认**。

<Callout type="tip" title="408 最稳的计算口径">
不要问“这个 ACK 确认了哪个段”，先问“接收方下一字节想要什么序号”。答案就是 ACK。
</Callout>

## 5.3.6 32 位序列号与回绕

TCP 序列号空间大小为：

$$
2^{32}
$$

序列号到达最大值后会模 $2^{32}$ 回绕。教材题通常不会要求实现完整的序列号展开算法，只需按题目给定序号和长度计算，并在必要时考虑模运算。

若某方向 ISN 为 `x`，SYN 消耗一个序号，则第一个普通数据字节通常从：

$$
(x+1)\bmod2^{32}
$$

开始。

## 5.3.7 六个常考控制位

| 标志 | 含义 |
| --- | --- |
| `URG` | 紧急指针有效 |
| `ACK` | 确认号字段有效 |
| `PSH` | 希望尽快交付应用 |
| `RST` | 复位连接 |
| `SYN` | 建立连接、同步序列号 |
| `FIN` | 关闭一个方向的发送 |

高频主线：

```text
SYN：建连
ACK：确认
FIN：释放
RST：异常复位
```

## 5.3.8 Window 字段是 `rwnd`，不是 `cwnd`

TCP 首部 Window 字段由报文发送方通告，表示其**接收窗口 `rwnd`**。

`cwnd` 是发送端本地维护的拥塞控制状态，**TCP 首部里没有一个直接存 `cwnd` 的字段**。

## 5.3.9 MSS 与 MTU

MSS（Maximum Segment Size）指一个 TCP 报文段中最大**数据部分**长度，不含 TCP/IP 首部。

若：

```text
MTU = 1500 B
IPv4 首部 = 20 B
TCP 首部 = 20 B
```

则常见：

$$
MSS=1500-20-20=1460\text{ B}
$$

MSS 与链路层 MTU 不属于同一层次，计算时不要混淆。

## 5.3.10 TCP 校验和

TCP 校验范围为：

```text
IP 伪首部 + TCP 首部 + TCP 数据
```

同样采用 16 bit 反码校验思想。与 IPv4 首部校验和的关键区别是：IPv4 首部校验和只保护 IPv4 首部，而 TCP 校验和还保护传输层数据。

## 5.3.11 本节速记

```text
seq = 本段第一个数据字节序号
ACK = 下一个期望字节序号
数据 L 字节 → 序号消耗 L
SYN 消耗 1 个序号
FIN 消耗 1 个序号
纯 ACK 通常不额外消耗序号
Window 字段 = rwnd，不是 cwnd
```
