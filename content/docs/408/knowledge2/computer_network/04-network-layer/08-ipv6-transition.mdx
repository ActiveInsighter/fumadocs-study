IPv6 不是“把 IPv4 地址简单加长”，而是同时调整了地址空间和首部设计。

> **真题标签**
>
> IPv6：2023 年第 40 题；IPv6 地址相关内容在 2023 年真题中出现。

## 4.8.1 IPv6 的核心特征

IPv6 地址长度：

```text
128 bit
```

地址空间规模：

$$
2^{128}\approx 3.4\times10^{38}
$$

高频特征：

- 基本首部固定 **40 Byte**；
- 取消 IPv4 首部校验和；
- 可通过扩展首部添加可选功能；
- 支持单播、多播、任播；
- **没有 IPv4 式广播地址**；
- 路由器不执行 IPv4 式的中途分片；
- 需要分片时由源节点借助分片扩展首部完成。

## 4.8.2 IPv6 基本首部

IPv6 基本首部只有 8 个主要字段：

| 字段 | 作用 |
| --- | --- |
| Version | 值为 6 |
| Traffic Class | 服务质量/优先级相关 |
| Flow Label | 标识数据流 |
| Payload Length | 基本首部之后的负载长度 |
| Next Header | 指向扩展首部或 TCP/UDP 等上层协议 |
| Hop Limit | 类似 IPv4 TTL |
| Source Address | 128 bit 源地址 |
| Destination Address | 128 bit 目的地址 |

对比 IPv4，IPv6 基本首部中没有：

- Header Checksum；
- Identification / Flags / Fragment Offset 这组三个 IPv4 基本首部分片字段；
- 可变长 Options 区直接堆在基本首部中的设计。

## 4.8.3 IPv6 地址表示

IPv6 写成 8 组、每组 16 bit 的十六进制：

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

### 规则 1：省略每组前导 0

```text
2001:db8:85a3:0:0:8a2e:370:7334
```

### 规则 2：连续全 0 组可用 `::`

例如：

```text
2001:db8:85a3::8a2e:370:7334
```

一个 IPv6 地址中 `::` **最多出现一次**，否则无法唯一判断省略了多少个 0 组。

## 4.8.4 单播、多播与任播

### 单播 Unicast

一个地址对应一个接口，典型一对一通信。

### 多播 Multicast

一个地址表示一组接收者；发送一份数据，网络按组播转发结构复制。

### 任播 Anycast

同一任播地址可配置给多个节点，路由通常把数据送到拓扑意义上“最近”的一个实例。

<Callout type="warn" title="IPv6 没有广播">
IPv6 不使用传统 IPv4 广播地址。很多原先靠广播完成的功能改由多播等机制完成。
</Callout>

## 4.8.5 Hop Limit 与 Next Header

- `Hop Limit`：每经一台路由器递减，功能类似 IPv4 TTL；
- `Next Header`：既可以指向 IPv6 扩展首部，也可以直接指向 TCP、UDP 等上层协议。

因此扩展功能被“串”在基本首部之后，而不是让基本首部本身变得复杂可变。

## 4.8.6 IPv6 与 IPv4 分片的核心区别

IPv4：

```text
中间路由器在 DF=0 时可以分片
```

IPv6：

```text
中间路由器不做这种传统分片
需要时由源节点处理
```

这降低了路由器数据平面的处理复杂度。

## 4.8.7 双协议栈

过渡期设备同时运行：

```text
IPv4 协议栈 + IPv6 协议栈
```

通信时根据目标地址、DNS 结果和网络能力选择 IPv4 或 IPv6。

优点是语义直接；代价是网络在过渡期需要同时维护两套能力。

## 4.8.8 隧道

如果两个 IPv6 网络之间隔着只支持 IPv4 的网络，可以：

```text
IPv6 数据报
   ↓ 整体封装
IPv4 数据报穿过 IPv4 网络
   ↓ 解封装
IPv6 数据报继续转发
```

这相当于在 IPv4 网络上为 IPv6 建立“逻辑隧道”。

## 4.8.9 IPv4 / IPv6 高频对比

| 项目 | IPv4 | IPv6 |
| --- | --- | --- |
| 地址长度 | 32 bit | 128 bit |
| 基本首部 | 20 Byte 起，可变 | 固定 40 Byte |
| 首部校验和 | 有 | 无 |
| TTL | TTL | Hop Limit |
| 选项/扩展 | Options | 扩展首部 |
| 中间路由器分片 | 可发生 | 不执行传统中途分片 |
| 广播 | 有 | 无传统广播 |
| 组播 | 支持 | 支持且更重要 |

复习时不要只背“128 bit”，真正高频的是首部简化、分片方式和地址类型差异。
