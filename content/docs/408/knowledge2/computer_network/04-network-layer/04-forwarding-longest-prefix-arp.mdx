综合题中最重要的一条判断链是：

```text
目标是否在本子网？
├─ 是 → 下一跳就是目标主机 → ARP 目标主机
└─ 否 → 下一跳是默认网关 → ARP 默认网关
```

> **真题标签**
>
> 路由表/转发：2022 年第 36 题、2026 年第 37 题；2015、2024 年综合题。
>
> 最长前缀匹配：2015 年第 38 题；2014 年第 43 题。
>
> ARP：2012 年第 38 题、2024 年第 35 题；2011、2015 年综合题。

## 4.4.1 路由表与转发表

典型表项包含：

- 目的网络前缀；
- 下一跳；
- 输出接口；
- 路由度量/属性。

例如：

| 目的前缀 | 下一跳 | 输出接口 |
| --- | --- | --- |
| `192.168.1.0/24` | 直连 | `eth0` |
| `10.0.0.0/8` | `192.168.1.254` | `eth0` |
| `0.0.0.0/0` | `192.168.1.1` | `eth0` |

严格区分时：

- **路由表**偏控制平面；
- **转发表**偏数据平面的高速查询结果。

408 题干常统称“路由表”，按题意作答即可。

## 4.4.2 直连路由与下一跳路由

### 直连网络

若目的网络直接连接在路由器某接口上，则无需再经过另一台路由器：

```text
下一跳 = 目的主机本身
```

路由器在该接口所在链路上解析目的主机的 MAC。

### 非直连网络

若目的网络在更远处：

```text
下一跳 = 某相邻路由器
```

当前路由器只需解析**下一跳路由器接口的 MAC**，不需要知道最终远端主机的 MAC。

## 4.4.3 最长前缀匹配

若目的 IP 同时命中多个前缀，选择**前缀最长**的表项。

例如：

| 前缀 | 接口 |
| --- | --- |
| `192.168.1.0/24` | A |
| `192.168.0.0/16` | B |
| `0.0.0.0/0` | C |

目的地址：

```text
192.168.1.100
```

三个前缀都可以匹配，但 `/24` 最具体，因此从 A 转发。

### 最稳的判断方法

对每一项执行：

```text
目的 IP AND 该项掩码
```

若结果等于该项网络地址，则该项命中。所有命中项中选 `/n` 最大者。

## 4.4.4 默认路由

```text
0.0.0.0/0
```

前缀长度为 0，可匹配所有 IPv4 地址，因此只在“没有更具体表项”时兜底。

<Callout type="warn" title="默认路由不是优先路由">
它恰恰是最不具体的路由。只要存在任何更长的匹配前缀，就不会选 `/0`。
</Callout>

## 4.4.5 主机发送前也要先做一次路由判断

主机并不是看到目标 IP 就立刻 ARP。它先把目标地址与自己的掩码结合判断：

```text
(本机 IP AND Mask) ?= (目标 IP AND Mask)
```

- 相等：认为目标在本地子网；
- 不等：交给默认网关。

这一步决定接下来 ARP 的对象是谁。

## 4.4.6 ARP 解决什么问题

ARP（Address Resolution Protocol）用于：

```text
已知当前链路上下一跳的 IPv4 地址
             ↓
获得这个下一跳接口的 MAC 地址
```

ARP 不是“把任何远端 IP 解析成远端 MAC”的协议。

## 4.4.7 ARP 基本流程

假设 A 与 B 在同一以太网，A 已知 B 的 IP：

1. A 查询 ARP 缓存；
2. 若无记录，A 广播 ARP Request；
3. 以太网目的 MAC 为 `FF:FF:FF:FF:FF:FF`；
4. 当前广播域内设备收到请求；
5. 拥有目标 IP 的 B 返回 ARP Reply；
6. Reply 通常单播给 A；
7. A 缓存 `B IP ↔ B MAC`；
8. A 用 B 的 MAC 封装后续帧。

ARP 缓存中的动态条目通常会老化。

## 4.4.8 同网段与跨网段

### 同网段

```text
IP 数据报：源 IP=A，目的 IP=B
以太网帧：源 MAC=A，目的 MAC=B
```

A ARP 查询 B。

### 跨网段

A 要访问远端 B：

```text
IP 数据报：源 IP=A，目的 IP=B
以太网帧：源 MAC=A，目的 MAC=默认网关
```

A ARP 查询的是**默认网关接口**。

到下一跳后，原链路层帧被拆掉，路由器再为下一条链路生成新的帧。

<Callout type="info" title="地址变化总表">
普通跨网转发中：源/目的 IP 端到端通常不变；源/目的 MAC 逐跳变化；TTL 逐跳减小。若经过 NAT，则 IP 和端口也可能改变。
</Callout>

## 4.4.9 路由器接口与默认网关

一个路由器连接多个 IP 子网时，每个三层接口通常都拥有属于对应子网的 IP 地址。

例如：

```text
LAN：192.168.1.0/24
路由器接口：192.168.1.1/24
```

主机可以把 `192.168.1.1` 配为默认网关。

传统点对点 IPv4 链路在教材题中常见 `/30`，其地址块有 4 个地址，按传统规则有两个普通可用地址，适合链路两端接口。

## 4.4.10 转发题的固定落笔顺序

```text
① 目的 IP 是否与本机同子网？
② 确定下一跳 IP
③ 若是路由器：最长前缀匹配确定下一跳/接口
④ ARP 获取“当前下一跳”的 MAC
⑤ 重新封装当前链路层帧
⑥ 进入下一跳后重复
```

只要始终把“最终目的 IP”和“当前下一跳 MAC”分开，跨网段综合题就不会乱。
