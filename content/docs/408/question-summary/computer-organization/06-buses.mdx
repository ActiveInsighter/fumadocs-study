<Callout type="warn" title="先确定题目要求：峰值带宽还是完整事务的平均带宽">

**物理数据链路峰值**只看一次有效传输量和单位时间传输次数；**有效负载带宽**还要剔除校验/编码/协议开销；**完整事务平均带宽**则必须计入地址、等待、仲裁和数据阶段。全双工只有在统计两个方向的**合计**吞吐量时才相加。

</Callout>

<Tabs items={['基础速率','完整事务','Burst 与非 Burst','传输方向']} defaultIndex={0}>
<Tab value="基础速率">

若数据宽度为 $W$ bit，时钟频率 $f$，每时钟周期有 $r$ 次数据传输，则不考虑编码和协议开销时：

$$
B_{\max}=\frac{W}{8}\,f\,r.
$$

若 $f$ 使用 Hz、$W$ 使用 bit，则结果单位为 B/s。采用 $10^9$ 为 GB、$2^{30}$ 为 GiB，换算不得混用。

</Tab>
<Tab value="完整事务">

不能重叠的事务传输 $L$ 字节，地址/等待/数据阶段分别用 $n_a,n_w,n_d$ 个周期，则：

$$
T_{\mathrm{txn}}=\frac{n_a+n_w+n_d}{f},\qquad
B_{\mathrm{eff}}=\frac{L}{T_{\mathrm{txn}}}.
$$

若支持事务流水重叠，需按实际总时序而不是单事务耗时求长期吞吐率。

</Tab>
<Tab value="Burst 与非 Burst">

若每次送出 $D$ 字节，连续读取 $L$ 字节，单次数据传输次数为 $N=\lceil L/D\rceil$。非突发通常逐次付地址/访问开销；突发常一次给首地址后连续传输，但**后续是否零等待**由题设决定。

</Tab>
<Tab value="传输方向">

区分“一条全双工链路每个方向的吞吐率”和“两方向合计”。串行链路的通道数量、lane 数量与并行数据总线位宽是不同概念，不可仅凭 PCIe ×16 就按 16 位并行总线计算。

</Tab>
</Tabs>

### 1.3 一个最重要的统一思想

整章可以归结为三个问题：

第一：谁在传？

CPU、主存、DMA 控制器和 I/O 接口之间，谁是当前总线主设备，谁拥有控制权？

第二：怎样传？

采用同步还是异步？一次发一个地址还是连续传多个数据？各阶段需要多长时间？

第三：传得有多快？

每次传多少有效数据，每秒能够传输多少次，实际有多少时间在传有效数据？

贯穿全章的两个核心公式是：

$$
\boxed{ B_{\max} = \text{每次传输的数据字节数} \times \text{每秒有效传输次数} }
$$

$$
\boxed{ B_{\mathrm{eff}} = \frac{\text{完成的有效数据量}} {\text{实际耗费的总时间}} }
$$

第一个回答理论上最快能传多少；第二个回答实际完成任务时平均传了多少。

## 二、总线的基本概念

### 2.1 为什么需要总线？

假设计算机包含 CPU、主存、显卡、磁盘控制器和网卡。

如果所有部件之间都使用独立线路连接，设备数量增加后，连接关系会变得非常复杂。

传统总线系统通过共享通信线路来减少连接数量：

```text
                  CPU
                   │
           ┌───────┴───────┐
           │    系统总线    │
           └───────┬───────┘
                   │
          ┌────────┼────────┐
          │        │        │
         主存    I/O接口   其他控制器
                   │
                  外设
```

总线是一组用于多个部件之间传输信息的公共通信线路。

传统共享总线具有两个核心特点。

**共享性：**&#x2060;多个设备可以连接到同一套总线资源。

**分时性：**&#x2060;同一条共享总线通常不能让多个主设备同时驱动相互冲突的数据传输，必须协调使用时间。

例如 CPU 正在访问主存，而 DMA 控制器也希望访问主存，就可能发生总线竞争。

因此，总线虽然简化了硬件连接，却引入了仲裁和定时问题。

需要注意，现代 PCIe 等互连通常采用点对点链路与交换结构，并不一定是所有设备物理共享一组导线。408 教材中的传统共享总线模型是理解这些互连技术的基础。

### 2.2 主设备与从设备

这是理解总线事务的重要前提。

| 类型         | 作用               | 典型例子        |
| ---------- | ---------------- | ----------- |
| 主设备 Master | 发起总线事务，给出地址及控制信息 | CPU、DMA 控制器 |
| 从设备 Target | 接收请求并执行读写等操作     | 主存、I/O 接口   |

例如 CPU 读取主存：

```text
CPU（主设备）                主存（从设备）
     │                           │
     │────── 地址和读命令 ──────>│
     │                           │
     │         准备数据          │
     │                           │
     │<──────── 数据 ───────────│
     │                           │
```

此时 CPU 是主设备，主存是从设备。

但在 DMA 传输过程中，DMA 控制器可能成为当前总线主设备。

所以一定要区分：

- CPU 是处理器，这是设备的功能身份。
- 总线主设备是当前能够发起事务的设备，这是总线控制身份。

CPU 并不永远拥有总线控制权。

### 2.3 总线周期与总线事务

三个概念必须分清。

| 概念   | 含义                |
| ---- | ----------------- |
| 时钟周期 | 时钟信号完成一次周期变化的时间   |
| 总线周期 | 完成一次规定总线操作所需要的时间  |
| 总线事务 | 一次完整的读、写或其他总线交互过程 |

例如总线时钟频率为：

$$
f=100\ \mathrm{MHz}
$$

对应时钟周期：

$$
T=\frac{1}{100\times10^6} =10\ \mathrm{ns}
$$

如果一个总线周期占用 4 个时钟周期：

$$
T_{\mathrm{bus}}=4T=40\ \mathrm{ns}
$$

每秒最多完成：

$$
\frac{1}{40\times10^{-9}} =25\times10^6
$$

个这样的总线周期。

一个总线周期不一定等于一个时钟周期，一次完整总线事务也不一定只有一次数据传输。

特别是突发传输，一次事务可以连续传送多个数据单位。

## 三、总线分类：数据总线、地址总线和控制总线

这是本章最基础、最容易出选择题的一部分。

### 3.1 三种系统总线

系统总线通常可以按传输信息的功能划分为三类。

| 比较项目  | 数据总线         | 地址总线       | 控制总线        |
| ----- | ------------ | ---------- | ----------- |
| 主要作用  | 传送数据内容       | 指定访问位置     | 协调操作与时序     |
| 传输的信息 | 指令、操作数、结果等   | 主存或 I/O 地址 | 读写、应答、中断等信号 |
| 典型方向  | 双向           | 当前主设备到目标设备 | 不同信号线方向不同   |
| 宽度的意义 | 一次并行传输的数据量   | 可表示的地址数量   | 取决于控制功能     |
| 典型考点  | 哪些信息可在数据线上传输 | 寻址空间计算     | 信号方向与类型     |

可以记成：

> 地址总线回答“访问哪里”，数据总线回答“传输什么”，控制总线回答“如何传输”。

### 3.2 数据总线

数据总线负责传输实际的信息内容。

例如 CPU 从主存读取一条指令：

```text
CPU                       主存
 │                         │
 │──────── 取指请求 ───────>│
 │                         │
 │<────── 机器指令 ────────│
 │                         │
```

机器指令本质上是一串二进制信息，因此也通过数据通路传输。

注意：数据总线不只传读者通常说的操作数。

还可能传送指令、状态字、命令字、中断类型号等。

这里有一个特别容易混淆的问题：

命令字和控制信号是不是同一回事？

不完全相同。

- 命令字是一组编码好的二进制数据，可以通过数据总线写入接口寄存器。
- 读使能、写使能、握手应答等具体时序控制信号通常属于控制总线。

例如 CPU 向 I/O 接口发送一个 8 位命令字，可以通过数据总线完成；但用于指示“现在写入这个命令字”的写选通信号，通常走控制线。

### 真题：2011 年

**题目：**&#x2060;在系统总线的数据线上，不可能传输的是：

A. 指令\
B. 操作数\
C. 握手（应答）信号\
D. 中断类型号

答案：C。

解析：

指令、操作数和中断类型号都是二进制信息内容。

握手应答信号主要用于控制传输过程，属于控制信号。

这道题的关键是区分“编码成数据传送的信息”与“直接控制总线时序的信号”。

### 3.3 地址总线

地址总线负责传输地址。

假设系统具有 $n$ 根独立地址线，则理论上能够表示：

$$
\boxed{N=2^n}
$$

个不同的地址。

如果采用按字节编址，那么理论最大寻址空间为：

$$
\boxed{S=2^n\ \mathrm{B}}
$$

例如 16 根地址线：

$$
S=2^{16}\ \mathrm{B}=64\ \mathrm{KiB}
$$

如果有 32 根地址线且按字节编址：

$$
S=2^{32}\ \mathrm{B}=4\ \mathrm{GiB}
$$

注意这里应严格区分：

$$
1\ \mathrm{GB}=10^9\ \mathrm{B}
$$

$$
1\ \mathrm{GiB}=2^{30}\ \mathrm{B}
$$

考试中经常把二进制容量习惯写成 GB，需要结合题目的单位约定判断。

#### 易错题

某计算机拥有 32 位地址总线、64 位数据总线，按字节编址。

问：最大理论寻址空间是多少？一次并行数据传输可以传送多少字节？

解答：

地址总线是 32 位：

$$
S=2^{32}\ \mathrm{B}=4\ \mathrm{GiB}
$$

数据总线是 64 位：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

所以答案为：

$$
\boxed{4\ \mathrm{GiB},\quad 8\ \mathrm{B}}
$$

这说明：

地址总线宽度决定地址数量，数据总线宽度决定一次能传多少位，两者没有必须相等的关系。

如果采用按字编址，且一个字为 4 B，则 32 位地址可表示的最大字节容量会变成：

$$
2^{32}\times4=16\ \mathrm{GiB}
$$

所以做寻址空间题时必须先确认编址单位。

### 3.4 控制总线

控制总线负责传输控制和状态信号。

例如：

| 信号          | 作用            |
| ----------- | ------------- |
| Read        | 发出读操作请求       |
| Write       | 发出写操作请求       |
| Ready       | 表示从设备准备就绪     |
| ACK         | 表示收到请求或完成相应阶段 |
| IRQ         | 发出中断请求        |
| Bus Request | 请求总线控制权       |
| Bus Grant   | 允许设备使用总线      |
| Reset       | 复位            |
| Clock       | 提供同步时序基准      |

控制总线整体并不能简单归类为只有一个传输方向。

因为具体信号方向可能不同。

例如：

```text
CPU ───── Read ─────> 主存

CPU <──── Ready ───── 主存
```

Read 通常由主设备发出，Ready 则由从设备返回。

因此经典教材中“控制信号是单向的”，通常指每一种具体控制信号沿规定方向传输，不是说控制总线中所有线路都只能朝同一个方向工作。

### 3.5 四种不同分类依据

除了按信息功能分类，总线还可以从其他维度分类。

| 分类依据     | 典型类别           |
| -------- | -------------- |
| 传输信息的功能  | 数据总线、地址总线、控制总线 |
| 连接的对象    | 片内总线、系统总线、通信总线 |
| 数据位的传输组织 | 串行总线、并行总线      |
| 时序控制方式   | 同步总线、异步总线      |

这些分类并不是互相排斥的。

例如某条内存总线可以同时是：

- 系统互连的一部分；
- 并行数据传输；
- 采用同步定时。

不要把“同步”“并行”“系统总线”当成同一个分类层次的互斥选项。

## 四、串行传输、并行传输与全双工

### 4.1 串行与并行到底有什么区别？

区别在于数据位如何组织传送。

**并行传输：**&#x2060;多根数据线同时传送多个 bit。

例如 8 位并行总线：

```text
D7 ───── 1 ───>
D6 ───── 0 ───>
D5 ───── 1 ───>
D4 ───── 0 ───>
D3 ───── 1 ───>
D2 ───── 1 ───>
D1 ───── 0 ───>
D0 ───── 0 ───>
```

一个传输时刻，可以同时传送 8 bit。

**串行传输：**&#x2060;数据位沿较少的通信线路按时间顺序传送。

```text
发送端

1 → 0 → 1 → 0 → 1 → 1 → 0 → 0

                  ↓
              串行链路
                  ↓

接收端依次恢复这些数据位
```

### 4.2 为什么现代高速互连经常采用串行方式？

直觉上，并行一次传多个 bit，似乎一定比串行快。

但这只考虑了“每次传送的数据位数”，没有考虑传输频率。

并行传输在频率升高后面临：

- 多根线路之间的传播时延差异，即时钟偏斜；
- 相邻信号线的串扰；
- 布线长度匹配困难；
- 引脚数量和物理空间开销。

现代高速串行互连可以采用差分传输、高速收发器、时钟恢复和多通道聚合等技术。

因此：

$$
\boxed{\text{并行传输不一定比串行传输快}}
$$

### 真题：2016 年

问：下列关于总线设计的说法，哪一项错误？

A. 并行总线的传输速度一定比串行总线快。\
B. 信号线复用可以减少信号线数量。\
C. 突发传输可以提高实际数据传输率。\
D. 分离事务可以提高总线利用率。

答案：A。

其余三项在经典总线模型下都是合理的性能或成本优化手段。

### 4.3 PCI 与 PCIe

两者名称相似，但传输组织有显著区别。

| 比较   | PCI                | PCI Express |
| ---- | ------------------ | ----------- |
| 传输方式 | 传统并行               | 高速串行        |
| 典型连接 | 共享总线               | 点对点链路、交换结构  |
| 扩展方式 | 共享有限带宽             | 多条 Lane 组合  |
| 全双工  | 传统 PCI 不是独立收发全双工链路 | 支持全双工       |

尤其注意：

PCIe ×16 不等于 16 位并行总线。

它代表使用 16 条串行 Lane 组成链路。

每条 Lane 都具有对应的高速串行传输通道。

### 真题：2017 年

题目询问多总线结构中的错误描述，其中一项为：

> PCI-Express ×16 采用并行传输方式。

这项错误。

因为 PCIe 是高速串行互连。即使有 16 条 Lane，也不是传统并行总线那种共享时钟、同时传送一个 16 位字的组织方式。

### 4.4 USB 总线

USB 是 Universal Serial Bus，即通用串行总线。

408 中主要掌握：

| 特征     | 解释                 |
| ------ | ------------------ |
| 串行传输   | 数据采用串行通信技术         |
| 即插即用   | 支持设备自动识别与配置        |
| 热插拔    | 系统运行期间可连接或断开设备     |
| 集线器扩展  | 可通过 USB Hub 连接多台设备 |
| 外部设备通信 | 常见于键鼠、打印机、移动存储设备   |

注意：USB 有多种物理连接器和协议版本，不能仅根据接口外形判断具体速率。

### 真题：2012 年

问：下列关于 USB 总线特性的描述，哪项错误？

其中一项认为 USB 可以同时并行传输 2 位数据，因此速度高。

该项错误。

USB 采用串行通信，其高速性能不来自传统的多位并行数据总线。

### 4.5 单工、半双工和全双工

这是计算带宽时的高频陷阱。

| 类型  | 特点         | 能否同时双向发送 |
| --- | ---------- | -------- |
| 单工  | 只能单向传输     | 不可以      |
| 半双工 | 可以双向，但需要分时 | 不可以      |
| 全双工 | 两个方向可同时传输  | 可以       |

假设一条全双工链路：

$$
B_{\rightarrow}=5\ \mathrm{GB/s}
$$

$$
B_{\leftarrow}=5\ \mathrm{GB/s}
$$

如果题目问单向最大速率：

$$
\boxed{5\ \mathrm{GB/s}}
$$

如果问两个方向同时传输的总吞吐量：

$$
B_{\mathrm{total}}=5+5 =\boxed{10\ \mathrm{GB/s}}
$$

不能只要看到“全双工”就机械乘以 2，必须判断题目问的是单方向还是双方向合计。

## 五、总线结构：单总线、双总线与多总线

### 5.1 单总线结构

CPU、主存、I/O 接口等共享同一套主要总线资源。

```text
                系统总线
══════════════════════════════════
       │          │         │
      CPU        主存      I/O接口
                              │
                             外设
```

优点是连接结构简单、成本低、扩展方便。

缺点是所有设备都可能竞争共享资源。

假设 CPU 正在访问主存，同时 DMA 控制器也希望进行主存访问。

如果两者共享同一条数据通路且没有独立并发能力，则需要协调或分时访问。

因此，单总线结构容易形成性能瓶颈。

特别注意：

单总线不是只有一根物理导线。

它表示多个部件共享同一套主要总线资源，这套资源通常仍然具有地址、数据和控制信号。

### 5.2 双总线结构

为了降低竞争，可以将 CPU—主存通信与 I/O 通信分离。

一种经典示意结构为：

```text
           存储总线
CPU ══════════════════ 主存
 │
 │
 ╚══════ I/O总线 ═════ I/O设备
```

这种设计可以减少一些不必要的争用。

但具体 CPU、主存和 I/O 之间的数据交换路径，需要依据教材给出的双总线结构判断，不能假设所有双总线系统都具有完全相同的连接方式。

### 5.3 三总线结构

经典三总线结构可以增加专用的 I/O 或 DMA 数据交换通路。

目的之一是让高速外设能够直接与主存交换数据，避免所有数据都由 CPU 中转。

```text
          CPU
           │
      ┌────┴────┐
      │         │
     主存      I/O总线
      │         │
      └── DMA ──┘
```

该图只表达 DMA 可通过相关通路访问主存的思想，实际三总线结构以具体教材图为准。

### 5.4 总线分层与桥接器

不同设备的速度和协议不一样。

例如：

- CPU 与主存需要极高吞吐率；
- 显卡与高速 SSD 需要高速扩展互连；
- 键盘、鼠标等设备的传输需求相对较低。

因此系统往往采用分层互连结构。

不同层次之间可以通过桥接器、控制器或交换结构进行连接。

传统 PC 中会涉及南桥、北桥：

| 部件 | 传统主要职责           |
| -- | ---------------- |
| 北桥 | 连接 CPU、主存及高速图形通路 |
| 南桥 | 连接较低速的各种 I/O 设备  |

现代处理器普遍已经将内存控制器等功能集成到 CPU 或 SoC 中，因此南北桥结构更多用于理解传统计算机的演进。

### 真题：2017 年

考查多总线结构时，应该认识到：

靠近 CPU 的互连通常性能较高；存储器总线可以采用突发传输；不同层次或协议的总线需要相应的互连转换或桥接机制。

本题真正的错误项仍然是“PCIe ×16 属于并行总线”。

## 六、总线仲裁：谁能使用总线？

### 6.1 为什么需要仲裁？

假设 CPU、DMA 控制器和另一台 I/O 控制器同时希望使用共享总线。

```text
CPU ────────── 请求
                 │
DMA ────────── 请求
                 ├──> 总线仲裁器
I/O控制器 ───── 请求
                 │
                 ↓
          决定谁先获得控制权
```

如果大家同时驱动同一组共享信号线，就可能发生冲突。

因此必须先决定由谁获得总线控制权。

这就是总线仲裁。

### 6.2 三种典型集中式仲裁方式

| 仲裁方式    | 工作原理            | 优点          | 缺点               |
| ------- | --------------- | ----------- | ---------------- |
| 链式查询    | 允许信号按设备顺序传递     | 控制线路较少，结构简单 | 优先级通常固定，低优先级可能饥饿 |
| 计数器定时查询 | 仲裁器依次输出设备编号     | 可调整轮询顺序     | 查询可能增加延迟         |
| 独立请求    | 每台主设备有独立请求/允许信号 | 响应较快，优先级灵活  | 线路与逻辑较多          |

### 6.3 链式查询

例如：

```text
仲裁器 ──> 设备A ──> 设备B ──> 设备C
             高                   低
```

在固定优先级的菊花链设计中，A 的优先级最高，C 最低。

假设 A 和 C 同时请求总线：

1. 仲裁器发出允许信号。
2. 信号首先到达 A。
3. A 发现自己正在请求总线。
4. A 截获允许信号。
5. C 无法得到本次总线使用权。

所以 A 获得控制权。

如果 A 长期持续请求，低优先级的 C 可能长时间无法使用总线。

这种现象称为饥饿。

### 6.4 计数器定时查询

仲裁器维护一个计数器，依次查询设备。

```text
设备0 → 设备1 → 设备2 → 设备3
   ↑                      │
   └──────────────────────┘
```

假设只有设备 2 请求：

计数器依次输出 0、1、2，查询到设备 2 后将总线分配给它。

这种方案相比链式查询，可以更灵活地调整优先顺序。

但需要经历一定查询过程。

### 6.5 独立请求方式

每个潜在主设备具有独立的请求线。

```text
设备A ── REQ_A ──┐
设备B ── REQ_B ──┼── 仲裁器
设备C ── REQ_C ──┘
```

仲裁器可以直接掌握多个设备的请求状态，再通过各自的允许信号分配控制权。

优点是仲裁速度和优先级设计较灵活，代价是信号线数量和硬件复杂度增加。

本节不需要死背复杂电路，但必须理解：

> 总线仲裁解决控制权竞争；总线定时解决获得控制权后如何按时序完成通信。

## 七、总线定时：同步、异步、半同步与分离式

这是容易混淆概念的一大部分。

### 7.1 什么是总线定时？

总线定时规定一次通信过程中各类信号什么时候有效。

例如：

- 什么时候发送地址；
- 什么时候发出读写命令；
- 什么时候准备数据；
- 什么时候采样数据；
- 什么时候结束当前操作。

总线定时不是单纯决定“传输频率”，而是规定通信各阶段的协调规则。

### 7.2 同步定时

同步定时以共同的时钟作为时序基准。

例如：

| 时钟阶段      | 典型操作    |
| --------- | ------- |
| $T_1$ | 输出地址    |
| $T_2$ | 发出读命令   |
| $T_3$ | 从设备提供数据 |
| $T_4$ | 采样数据并结束 |

这是一个简化示例，实际协议可能允许地址与命令同时传送，也可能存在流水重叠。

同步定时的优点是控制较简单、时序关系明确。

缺点是所有参与者必须满足相应的时钟时序约束。

如果设备响应速度差异很大，可能需要等待周期。

### 7.3 异步定时

异步定时没有要求所有通信动作都在统一的固定时钟节拍完成。

它通过请求与应答信号进行协调。

典型全互锁握手过程：

```text
时间向右 →

主设备请求 REQ：
       ┌──────────────┐
───────┘              └──────────

从设备应答 ACK：
             ┌──────────────┐
─────────────┘              └────
```

其动作顺序为：

$$
\boxed{ REQ\uparrow \rightarrow ACK\uparrow \rightarrow REQ\downarrow \rightarrow ACK\downarrow }
$$

可以这样理解：

主设备先说“我要传了”，从设备回答“可以”；主设备撤销请求，从设备确认本次握手结束并撤销应答。

这种方式对不同设备的响应速度更有适应性。

例如 CPU 接口与机械打印设备之间，响应时间不固定，异步握手可能更合适。

<Callout type="info" title="三种互锁方式的比较限于具体握手协议">

非互锁、半互锁、全互锁的区别在于**请求和应答何时撤销**。对于教材典型全互锁模型，请求方看到应答才撤销请求，应答方看到请求撤销再撤销应答；不能由此推出所有现代高速链路都采用相同波形。

</Callout>

### 7.4 三种异步互锁方式

| 方式  | 请求信号如何撤销       | 应答信号如何撤销      | 特点          |
| --- | -------------- | ------------- | ----------- |
| 不互锁 | 可不等待对方确认而按约定撤销 | 可自行撤销         | 控制简单，依赖时序约定 |
| 半互锁 | 请求方等待应答后撤销     | 应答方可自行撤销      | 折中          |
| 全互锁 | 请求方等待应答后撤销     | 应答方等待请求撤销后再撤销 | 完整四阶段握手     |

对于考试中的经典模型：

全互锁通常最可靠，但握手过程开销较大。

非互锁较简单，但对传播延迟、信号持续时间等时序假设依赖更强。

不要把“全互锁最慢”理解为所有现代通信系统、所有实际实现中的绝对规律；它是教材典型模型中的比较。

### 7.5 半同步定时

半同步定时试图结合同步与异步方式的优点。

基本思想是：

仍然使用统一时钟，但允许从设备通过等待信号延长操作时间。

假设 CPU 请求读取主存，但主存没有按原定周期准备好数据。

```text
时钟： T1    T2    T3    T4    T5

地址： 有效
命令：       读
WAIT：             有效  有效
数据：                         有效
```

这里通过插入等待周期，让较慢设备仍然可以与同步总线配合。

核心特征：

$$
\boxed{ \text{统一时钟} + \text{等待/应答机制} }
$$

### 7.6 分离式定时与分离事务

普通非分离读事务可能需要一直等待从设备返回数据。

例如：

```text
请求 ── 等待主存 ── 返回数据 ── 结束
```

如果主存等待时间很长，共享总线可能出现大量空闲占用。

分离事务则把一次逻辑访问拆成两个独立的通信阶段：

```text
时间向右 →

CPU：  发送读取请求 ───────────── 接收结果

主存：          准备数据 ─────── 发送结果

总线： 请求 ── 其他设备事务 ─── 响应
```

第一次请求发出后，释放总线。

从设备准备数据期间，总线可以处理其他设备的请求。

之后再进行响应传输。

主要收益：

$$
\boxed{\text{提高共享互连的利用率与并发能力}}
$$

但需要注意，分离事务不一定减少单次访问本身的延迟，有时还可能增加协议与仲裁开销。

它主要解决的是等待期间总线资源被低效占用的问题。

### 7.7 真题：2015 年总线定时

题目问下列有关总线定时的描述中，哪一项错误。

A. 异步通信方式中，全互锁协议通常最慢。\
B. 异步通信方式中，非互锁协议的可靠性最差。\
C. 同步通信方式中，同步时钟信号可由各设备各自独立提供。\
D. 半同步通信中，握手信号的采样由同步时钟控制。

答案：C。

同步总线需要协调一致的时序基准。

不能让设备各自按照彼此不协调的独立时钟完成同一次同步总线事务。

A、B、D 符合题目使用的经典教材模型。

### 7.8 真题：2021 年异步握手

题目中有一个错误说法：

> 异步总线一次握手过程只能完成一位数据交换。

错误。

一次握手协调的是一次数据传输操作，其传输数据量取决于协议与数据通路宽度。

如果是 32 位并行异步总线，一次完整握手就可能完成 32 bit 的数据交换。

因此：

$$
\boxed{ \text{一次握手} \ne \text{只能传 1 bit} }
$$

另外还要分清两组容易混淆的概念：

**同步/异步总线定时：**&#x2060;讨论总线参与者如何协调一次事务的时序。

**同步/异步串行通信：**&#x2060;讨论串行数据传输中的时钟组织、字符或帧同步方式。

这两组术语有关联，但不是同一个概念。

## 八、总线性能指标与带宽计算——本章最重要的考点

这一节必须真正理解，因为历年真题会不断组合不同条件。

### 8.1 总线宽度

总线宽度通常指数据总线一次并行传输的数据位数。

例如：

| 数据总线宽度  | 每次传输的数据量 |
| ------- | -------- |
| 8 bit   | 1 B      |
| 16 bit  | 2 B      |
| 32 bit  | 4 B      |
| 64 bit  | 8 B      |
| 128 bit | 16 B     |

一般公式：

$$
\boxed{ D=\frac{W}{8} }
$$

其中：

$W$ 为数据总线宽度，单位 bit；

$D$ 为每次传输的字节数，单位 B。

### 8.2 总线时钟频率

频率与周期互为倒数：

$$
\boxed{ T=\frac{1}{f} }
$$

考试中要熟悉以下换算。

| 时钟频率    | 时钟周期   |
| ------- | ------ |
| 10 MHz  | 100 ns |
| 50 MHz  | 20 ns  |
| 100 MHz | 10 ns  |
| 200 MHz | 5 ns   |
| 500 MHz | 2 ns   |
| 1 GHz   | 1 ns   |

例如：

$$
f=250\ \mathrm{MHz}
$$

则：

$$
T=\frac{1}{250\times10^6} =4\ \mathrm{ns}
$$

### 8.3 时钟频率与数据传输频率

两者可能不同。

假设时钟频率为：

$$
f=100\ \mathrm{MHz}
$$

如果每个时钟周期传送一次数据：

$$
R=100\ \mathrm{MT/s}
$$

如果每个时钟周期传送两次：

$$
R=200\ \mathrm{MT/s}
$$

如果每个时钟周期传送四次：

$$
R=400\ \mathrm{MT/s}
$$

这里：

- MHz 表示每秒百万个时钟周期；
- MT/s 表示每秒百万次数据传输。

在每周期传输 $r$ 次的情况下：

$$
\boxed{ R=f\times r }
$$

例如 DDR 的基础概念，就是一个时钟周期可利用两个数据传输时机。

但是还有另一类题：

一个数据传输必须占用 $c$ 个时钟周期。

此时：

$$
\boxed{ R=\frac{f}{c} }
$$

两种模型不能不加判断地混用。

一定要根据题干识别：究竟是每个周期传多次，还是每次传输占多个周期。

<Callout type="idea" title="速率计算先检查单位和有效负载">

$\mathrm{MHz}$ 表示时钟频率，$\mathrm{MT/s}$ 表示每秒传输次数；DDR 数据接口常每时钟周期有两次数据传输，但题目若直接给出有效传输率，不能再次乘 2。十进制 $\mathrm{MB/s}$、$\mathrm{GB/s}$ 与二进制 $\mathrm{MiB/s}$、$\mathrm{GiB/s}$ 单位也不同。

</Callout>

### 8.4 理论总线带宽

基本公式：

$$
\boxed{ B_{\max} = \frac{W}{8}\times R }
$$

若每周期传输 $r$ 次：

$$
\boxed{ B_{\max} = \frac{W}{8}\times f\times r }
$$

如果具有 $C$ 条能够真正独立工作的同规格通道：

$$
\boxed{ B_{\max,\mathrm{total}} = C\times\frac{W}{8}\times f\times r }
$$

注意：只有题目明确表示多个通道可以独立并行、且统计的是总带宽时，才可以乘以 $C$。

### 8.5 理论带宽与有效带宽

这是近年来综合性计算题的重要区别。

理论峰值带宽关注总线在连续有效数据传输时的最大能力。

有效带宽关注实际完成一批数据传输时的平均有效数据率。

假设一个总线事务需要：

| 阶段   | 时钟周期数 |
| ---- | ----- |
| 地址阶段 | 1     |
| 等待阶段 | 2     |
| 数据阶段 | 4     |
| 总计   | 7     |

假设数据总线每个有效传输周期能够传输 $8\ \mathrm{B}$，时钟频率为 $100\ \mathrm{MHz}$，每周期最多完成一次数据传输。

理论峰值：

$$
B_{\max} =8\times100\times10^6 =\boxed{800\ \mathrm{MB/s}}
$$

完整事务传送的数据量为：

$$
D=4\times8=32\ \mathrm{B}
$$

事务时间：

$$
T=\frac{7}{100\times10^6} =70\ \mathrm{ns}
$$

如果事务依次进行且没有重叠：

$$
B_{\mathrm{eff}} =\frac{32}{70\times10^{-9}} \approx\boxed{457.14\ \mathrm{MB/s}}
$$

利用率：

$$
\eta =\frac{B_{\mathrm{eff}}}{B_{\max}} =\frac47 \approx57.14\%
$$

这说明即使硬件具有 $800\ \mathrm{MB/s}$ 的理论带宽，事务中的地址与等待开销也可能使实际有效吞吐量明显下降。

### 8.6 最通用的计算框架

遇到总线带宽题，建议固定按照以下顺序：

第一步：计算每次传多少数据。

$$
D=\frac{W}{8}
$$

第二步：计算单位时间传输次数。

$$
R=f\times r
$$

或者：

$$
R=\frac{f}{c}
$$

第三步：确定通道数和传输方向。

例如多通道、双向合计全双工。

第四步：判断是否需要扣除事务开销。

如果问峰值带宽，一般使用硬件数据通路的最大传输能力。

如果问完成整个数据块的时间或平均有效数据率，则应考虑地址、等待、控制等实际开销。

## 九、总线事务与突发传输——最重要的综合计算模型

### 9.1 什么是一次总线事务？

一次总线读写操作通常可以抽象为：

```text
获得总线控制权
       ↓
发送地址
       ↓
发送读写命令
       ↓
目标设备准备数据
       ↓
完成数据传输
       ↓
释放资源
```

具体阶段能否重叠，取决于硬件与协议。

考试最常见的问题，是判断一次事务中哪些阶段只进行一次，哪些阶段需要重复进行。

### 9.2 非突发传输

非突发传输通常需要对多个数据单位分别发起事务。

例如读取四个连续数据：

```text
地址A   → 等待 → 数据A

地址A+1 → 等待 → 数据A+1

地址A+2 → 等待 → 数据A+2

地址A+3 → 等待 → 数据A+3
```

如果每次需要：

- 地址阶段 $a$ 个时钟周期；
- 等待阶段 $m$ 个时钟周期；
- 数据阶段 $d$ 个时钟周期；

且 $N$ 次事务依次完成，没有重叠，则：

$$
\boxed{ T_{\mathrm{non}} = N(a+m+d)T_c }
$$

<Callout type="warn" title="Burst 并不自动消除主存等待">

突发允许使用首地址连续读取多个数据单位，常减少重复地址开销。若题目没有给出连续读出能力、存储器行缓冲行为或后续等待周期，就**不能仅凭“支持突发”推断后续数据每拍都已准备好**。

</Callout>

### 9.3 突发传输 Burst

突发传输的核心：

一次给出起始地址，连续传送多个数据单位。

例如：

```text
地址A
  │
  ├──── 数据A
  ├──── 数据A+1
  ├──── 数据A+2
  └──── 数据A+3
```

它可以减少重复寻址与控制开销。

典型使用场景包括 Cache 块装入、连续内存访问以及批量数据传送。

在一个简化模型下，假设：

- 起始地址阶段需要 $a$ 个周期；
- 首次准备数据需要 $m$ 个周期；
- 后续连续传送 $N$ 个数据，每个数据占用 $d$ 个周期；
- 题目允许数据连续输出，没有额外等待。

则：

$$
\boxed{ T_{\mathrm{burst}} = (a+m+Nd)T_c }
$$

但一定注意，这是有条件的模型。

如果题目将首个数据的产生时间包括在首延迟 $L$ 中，且后续每间隔 $d$ 个周期产生一个数据，那么应该写成：

$$
\boxed{ T_{\mathrm{burst}} = [L+(N-1)d]T_c }
$$

二者并不矛盾，只是首延迟的定义不同。

### 9.4 为什么突发传输能提高效率？

假设总线时钟为 $100\ \mathrm{MHz}$，每次传送 4 B。

读取 8 个数据，共 32 B。

每次地址阶段占 1 个周期，每次数据阶段占 1 个周期，忽略其他延迟。

非突发传输：

$$
N_{\mathrm{non}}=8\times(1+1)=16
$$

总时间：

$$
T_{\mathrm{non}}=160\ \mathrm{ns}
$$

有效带宽：

$$
B_{\mathrm{non}} =\frac{32}{160\times10^{-9}} =\boxed{200\ \mathrm{MB/s}}
$$

突发传输：

$$
N_{\mathrm{burst}}=1+8=9
$$

总时间：

$$
T_{\mathrm{burst}}=90\ \mathrm{ns}
$$

有效带宽：

$$
B_{\mathrm{burst}} =\frac{32}{90\times10^{-9}} \approx\boxed{355.56\ \mathrm{MB/s}}
$$

在这个理想模型下，突发传输节约：

$$
\Delta T=160-90=70\ \mathrm{ns}
$$

相对于非突发方式，时间减少：

$$
\frac{70}{160}\times100\% =\boxed{43.75\%}
$$

但数据总线的理论峰值带宽仍然是：

$$
4\times100\times10^6 =\boxed{400\ \mathrm{MB/s}}
$$

重要结论：突发传输通常提高的是实际有效数据率，并不必然改变物理数据通路的峰值传输能力。

### 9.5 地址/数据线复用

复用是指同一组物理线路在不同时间承担不同功能。

例如：

```text
第1周期：发送地址
第2周期：发送数据1
第3周期：发送数据2
第4周期：发送数据3
```

如果地址与数据采用两组独立线路，则在硬件条件允许时，两者可能有更多并发或流水安排空间。

采用复用后，主要优点是：

减少信号线与引脚数量，降低硬件成本。

缺点是必须分时使用这组线路，可能增加事务开销。

所以地址/数据线复用并不是直接提高最大带宽的方法。

### 9.6 真题：2018 年总线优化方式

问：能够提高同步总线数据传输率的措施有：

I. 增加总线宽度\
II. 提高总线工作频率\
III. 支持突发传输\
IV. 采用地址/数据线复用

答案：I、II、III。

理解：

增加宽度，提高每次数据传输量。

提高频率，增加单位时间传输次数。

突发传输，减少重复事务开销，从而提高有效传输效率。

地址/数据线复用，主要节省线路成本，并不是为了提高数据传输率。

### 真题 1：2009 年——总线周期与时钟周期

【2009 年真题】

某系统总线在一个总线周期中并行传输 4 B 信息，一个总线周期占用 2 个时钟周期，总线时钟频率为 10 MHz。

求总线带宽。

选项：

A. 10 MB/s\
B. 20 MB/s\
C. 40 MB/s\
D. 80 MB/s

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-01">

解题过程

第一步：计算一个时钟周期。

$$
T_c=\frac{1}{10\times10^6} =100\ \mathrm{ns}
$$

第二步：一个总线周期占 2 个时钟周期。

$$
T_{\mathrm{bus}}=2\times100 =200\ \mathrm{ns}
$$

第三步：求每秒完成多少次数据传输。

$$
R=\frac{1}{200\times10^{-9}} =5\times10^6\ \mathrm{次/s}
$$

第四步：计算带宽。

$$
B=4\times5\times10^6 =\boxed{20\ \mathrm{MB/s}}
$$

答案：B。

这道题的核心就是：

$$
\boxed{ B = \frac{\text{每次传输数据量}\times f_{\mathrm{clk}}} {\text{每次传输占用的时钟周期数}} }
$$

前提是每个所述总线周期完成一次规定的数据传输。

**易错点：**&#x2060;直接使用 $4\times10=40\ \mathrm{MB/s}$，忘记一个总线周期占用两个时钟周期。

</Accordion>
</Accordions>

### 真题 2：2012 年——突发传输与地址数据复用

【2012 年真题】

某同步总线：

- 时钟频率为 100 MHz；
- 数据总线宽度为 32 位；
- 地址线与数据线复用；
- 发送一个地址或一个数据均占一个时钟周期；
- 支持突发传输。

如果一次主存写事务需要传送 128 bit 数据，至少需要多少时间？

选项：

A. 20 ns\
B. 40 ns\
C. 50 ns\
D. 80 ns

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-02">

解题过程

第一步：计算时钟周期。

$$
T_c=\frac{1}{100\times10^6} =10\ \mathrm{ns}
$$

第二步：计算数据传输次数。

$$
N_d=\frac{128}{32}=4
$$

第三步：由于采用突发传输，只需要发送一次首地址。

所以：

$$
N_a=1
$$

第四步：总周期数：

$$
N=N_a+N_d =1+4=5
$$

第五步：总时间：

$$
T=5\times10 =\boxed{50\ \mathrm{ns}}
$$

答案：C。

最容易错选 B，即 40 ns。

因为只计算了四个数据周期，遗漏地址阶段。

这道题还可以作一个对比。

如果不使用突发传输，且每次都需要单独发送一次地址：

$$
N_{\mathrm{non}}=4\times(1+1)=8
$$

则：

$$
T_{\mathrm{non}}=80\ \mathrm{ns}
$$

由此可见：

$$
\boxed{ T_{\mathrm{burst}}=50\ \mathrm{ns} < T_{\mathrm{non}}=80\ \mathrm{ns} }
$$

</Accordion>
</Accordions>

### 真题 3：2014 年——双沿传输与带宽

某同步总线采用地址线和数据线复用，复用线路共有 32 根。

总线时钟频率为 66 MHz，每个时钟周期在上升沿和下降沿分别传送一次数据。

求最大数据传输率。

选项：

A. 132 MB/s\
B. 264 MB/s\
C. 528 MB/s\
D. 1056 MB/s

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-03">

解题过程

第一步：计算每次传输的数据字节数。

$$
D=\frac{32}{8}=4\ \mathrm{B}
$$

第二步：每时钟周期传输两次。

$$
r=2
$$

第三步：最大带宽：

$$
B_{\max}=4\times66\times10^6\times2
$$

得到：

$$
\boxed{B_{\max}=528\ \mathrm{MB/s}}
$$

答案：C。

这里地址/数据复用并不要求在计算数据传输阶段的理论峰值带宽时，机械扣除某个固定比例。

只有题目进一步询问一笔具体事务的完成时间或平均有效速率时，才需要考虑地址阶段的时间开销。

### 真题 4：2019 年——DDR 多通道存储器带宽

【2019 年真题】

某计算机采用 3 通道存储器总线，内存型号为 DDR3-1333。

题目规定总线工作频率为 1333 MHz，每通道数据宽度为 64 位。

求三通道总带宽。

选项：

A. 10.66 GB/s\
B. 32 GB/s\
C. 64 GB/s\
D. 96 GB/s

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-04">

解题过程

第一步：每通道每次传送：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

第二步：每通道传输率：

$$
B_1=1333\times10^6\times8
$$

$$
B_1=10.664\ \mathrm{GB/s}
$$

第三步：三个独立通道：

$$
B_{\mathrm{total}}=3B_1
$$

$$
B_{\mathrm{total}} =3\times10.664 =31.992\ \mathrm{GB/s}
$$

因此：

$$
\boxed{B_{\mathrm{total}}\approx32\ \mathrm{GB/s}}
$$

答案：B。

这里有一个极重要的概念辨析：

DDR3-1333 中的 1333 通常描述的是有效数据传输率等级，约 1333 MT/s，而不是一定代表物理基础时钟为 1333 MHz。

这道题已经将 1333 作为总线的有效工作频率给出，因此不能再次因为 DDR 而乘以 2。

如果机械计算：

$$
1333\times2\times8\times3
$$

就会多乘一次，得到错误结果。

这类题一定要判断题目给出的究竟是物理时钟频率还是有效数据传输频率。

</Accordion>
</Accordions>

### 真题 5：2020 年——QPI、校验位、双沿传输与全双工

【2020 年真题】

某 QPI 总线具有以下条件：

- 点对点全双工同步串行总线；
- 时钟频率为 2.4 GHz；
- 每个时钟周期传送两次；
- 每个方向每次传送 20 位信息；
- 20 位中有 16 位有效数据、4 位校验信息。

求两个方向合计的有效总线带宽。

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-05">

解题过程

第一步：每方向每次传送的有效数据量：

$$
D=\frac{16}{8}=2\ \mathrm{B}
$$

注意不是：

$$
\frac{20}{8}=2.5\ \mathrm{B}

第二步：每秒有效数据传输次数：

B_{\mathrm{one}} =2\times2.4\times10^9\times2
$$

$$
B_{\mathrm{one}} =9.6\ \mathrm{GB/s}
$$

第四步：题目明确是全双工总带宽，统计两个方向合计：

\boxed{ B_{\mathrm{total}}=19.2\ \mathrm{GB/s} }

| 每时钟周期传两次         | 乘以 2             |
| 全双工              | 如果统计双向总吞吐量，再乘以 2 |
| 2.4 GHz          | 换算成每秒时钟周期数       |

这类题特别容易因为重复乘 2，或把校验位计入有效数据，而得到错误答案。

### 真题 6：2023 年——非突发方式读取主存块

【2023 年真题】

某存储器总线：

- 数据宽度为 64 位；
- 时钟频率为 1 GHz；
- 发送一个地址占一个时钟周期；
- 传送一个数据占一个时钟周期；
- 不支持突发传输；
- 主存每次准备一个 64 位数据需要 6 ns；
- 主存块大小为 32 B。

求读取一个主存块需要多少时间。

选项：

A. 8 ns\
B. 11 ns\
C. 26 ns\
D. 32 ns

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-06">

解题过程

第一步：总线时钟周期：

$$
T_c=\frac{1}{1\times10^9} =1\ \mathrm{ns}
$$

第二步：总线每次传送：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

第三步：主存块大小为 32 B，因此需要：

$$
N=\frac{32}{8}=4
$$

次数据读取。

第四步：因为不支持突发传输，需要分别完成四次事务。

每次事务：

$$
T_{\mathrm{single}} = T_{\mathrm{addr}} + T_{\mathrm{mem}} + T_{\mathrm{data}}
$$

代入：

$$
T_{\mathrm{single}}=1+6+1=8\ \mathrm{ns}
$$

第五步：总时间：

$$
T_{\mathrm{total}}=4\times8
$$

$$
\boxed{T_{\mathrm{total}}=32\ \mathrm{ns}}
$$

答案：D。

这道题的重点不是简单的带宽公式，而是完整事务时序。

#### 为什么不是 8 ns？

因为 8 ns 只够完成一次 64 位数据的读取。

整个主存块有 32 B，需要读取四次。

#### 为什么不是 11 ns？

11 ns 对应的是一种额外假设下的理想模型：

只发送一次地址，首次主存准备需要 6 ns，之后四个数据能够以每周期一个的速度连续输出。

但原题明确不支持突发传输，因此不能擅自采用这一模型。

即使题目改成支持突发传输，也必须确认后续数据能否连续准备，不能只凭 Burst 一个词就断言总时间一定是 11 ns。

这道题对后面的 Cache 块装入、主存访问和 DMA 总线竞争都有帮助。

</Accordions>

### 真题 7：2024 年——峰值带宽与事务平均带宽

【2024 年真题】

某存储器总线：

- 时钟频率为 420 MHz；
- 数据总线宽度为 64 位；
- 每时钟周期传输两次数据；
- 支持突发传输；
- 一次突发最多传送 8 次数据；
- 第 1 时钟周期传送地址和读写命令；
- 第 4～7 时钟周期连续完成 8 次数据传输。

求总线带宽（最大数据传输率）。

选项：

A. 3.84 GB/s\
B. 6.72 GB/s\
C. 30.72 GB/s\
D. 53.76 GB/s

这道题非常值得精讲，因为它同时给出了峰值速率参数和一整笔事务的时序。

<Accordions>
<Accordion title="展开：参考答案与详细解析" id="bus-exam-07">

### 第一种计算：理论最大带宽

每次传输：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

每周期传两次：

$$
r=2
$$

因此：

$$
B_{\max} =420\times10^6\times2\times8
$$

$$
\boxed{ B_{\max}=6.72\ \mathrm{GB/s} }
$$

所以答案是 B。

### 第二种计算：完整事务的平均有效数据率

一次突发传送：

$$
8\times8=64\ \mathrm{B}
$$

整个事务占用：

$$
7T_c
$$

因此：

$$
T_{\mathrm{transaction}} =\frac{7}{420\times10^6}
$$

平均有效数据率：

$$
B_{\mathrm{eff}} = \frac{64}{7/(420\times10^6)}
$$

$$
\boxed{ B_{\mathrm{eff}}=3.84\ \mathrm{GB/s} }
$$

这恰好对应选项 A。

为什么 A 不对？

因为原题问的是总线的最大数据传输率，而不是完整突发事务的平均传输率。

两个结果回答的是不同的问题。

### 第三种计算：利用率

数据阶段为第 4～7 周期，共 4 个时钟周期。

完整事务共 7 个时钟周期。

如果按该事务独立、顺序执行的模型：

$$
\eta=\frac47
$$

所以：

$$
B_{\mathrm{eff}} =\eta B_{\max}
$$

$$
B_{\mathrm{eff}} =\frac47\times6.72 =3.84\ \mathrm{GB/s}
$$

这里也说明：如果系统允许不同事务流水化并重叠执行，长期吞吐率还需要根据实际重叠时序计算，不能不加条件地把 $3.84\ \mathrm{GB/s}$ 当作所有工作负载下的唯一有效带宽。

本章最重要的考试经验：看到“最大带宽”，优先看数据通路能力；看到“事务耗时、平均有效数据率”，必须分析完整时序。

## 十一、模拟题精讲：考查方式比单纯套公式更灵活

原稿引用的模拟题资料中，这一章包含了王道模拟卷和竟成模拟卷相关题目。

其中最值得学习的是综合条件叠加的计算题，以及容易出现绝对化表述的概念题。

### 模拟题 1：全双工、校验位与总线周期

【竟成·模拟五-22】

设备 A 和设备 B 之间采用全双工同步串行总线进行数据交互。

已知：

- 每个总线周期内，双方同时各传送 24 位信息；
- 每个方向的信息中有 16 位有效数据和 8 位校验位；
- 总线时钟频率为 1 GHz；
- 一个总线周期包含两个时钟周期。

问总线双向合计有效带宽。

选项：

A. 1 GB/s\
B. 1.5 GB/s\
C. 2 GB/s\
D. 3 GB/s

解题过程

第一步：每个总线周期包含两个时钟周期，所以每秒有：

$$
N=\frac{1\times10^9}{2} =5\times10^8
$$

个总线周期。

第二步：一个方向每个总线周期有 16 位有效数据。

$$
D_{\mathrm{one}}=\frac{16}{8}=2\ \mathrm{B}
$$

第三步：全双工两个方向合计：

$$
D_{\mathrm{total}}=2\times2=4\ \mathrm{B}
$$

第四步：有效带宽：

$$
B=4\times5\times10^8
$$

$$
\boxed{B=2\ \mathrm{GB/s}}
$$

答案：C。

这题至少有三个陷阱：

一是 24 位并不全部是有效数据；

二是一个总线周期有两个时钟周期，需要将每秒时钟周期数除以 2；

三是全双工双向合计带宽要把两个方向相加。

如果题目只问单方向带宽，则为：

$$
\boxed{1\ \mathrm{GB/s}}
$$

### 模拟题 2：异步总线的适用场景

【王道·卷二-Q21】

以下哪种情况最适合异步传输？

A. I/O 接口与打印机交换信息\
B. CPU 与主存交换信息\
C. CPU 与 PCI 总线交换信息\
D. 已经由统一时钟控制的设备

答案：A。

异步传输适合双方响应速度相差较大、完成时间不确定的通信场景。

机械打印设备的响应时间可能受到机械运动、缓存状态等因素影响。

通过握手信号协调，可以避免单纯依赖固定等待时间。

但不要误以为异步方式只能用于低速设备。异步握手的本质是通过事件和信号协调通信，而不是对速度作绝对限制。

### 模拟题 3：双倍数据率的陷阱

【竟成·模拟四-21】

某题的错误选项为：

> 每条存储器总线在一个总线时钟周期内最多只能传输一次数据。

答案：错误。

如果总线支持双沿传输：

$$
1\text{ 个时钟周期} \rightarrow 2\text{ 次数据传输}
$$

因此：

$$
R_{\mathrm{transfer}}=2f_{\mathrm{clock}}
$$

这也是为什么某些现代存储器接口标称的传输率可以高于基础时钟频率。

### 模拟题 4：控制信息是否单向传输？

原稿引用的模拟练习中还出现了一个很有代表性的分类题，涉及：

I. 地址信息\
II. 数据信息\
III. 控制信息\
IV. 状态信息

该题将地址、控制、状态信息归为具有规定的单向传输方向，而数据可双向传输。

这一说法应结合其分类语境理解。

例如：

```text
主设备 ───── 地址 ─────> 从设备
主设备 ───── 命令 ─────> 从设备
主设备 <──── 状态 ────── 从设备
主设备 <──── 数据 ─────> 从设备
```

但是不能由此推出“控制总线作为整体只有一个方向”。

实际上，控制总线可能同时包含不同方向的请求与应答信号。

考试中必须区分具体信号的方向与控制总线整体的信号构成。

## 十二、历年大题：总线与 I/O 系统的综合考查

这里先说明资料情况。

原稿引用的 [历年大题文档](https://exam.any1.tech/docs/408/past-exams-large-questions/02-ec68095a/06-2a956ea9/) 将第 6 章设置为《总线和输入输出系统》，目前收录了 3 道相关历年大题及 6 道拓展题。

三道大题分别是 2009 年第 43 题、2016 年第 44 题和 2018 年第 43 题。

它们主要涉及 I/O 方式、异步串行通信、中断开销及 DMA，与本章总线性能计算联系密切。

下面重点讲解其中的综合计算思想。

### 大题 1：2009 年第 43 题——中断与 DMA 的 CPU 占用率

已知：

CPU 主频：

$$
f=500\ \mathrm{MHz}
$$

平均：

$$
CPI=5
$$

某设备数据率为：

$$
R=0.5\ \mathrm{MB/s}
$$

采用中断方式，每次传输单位为 32 bit。

每次中断需要执行 18 条服务程序指令，其他开销相当于执行 2 条指令。

第（1）问：CPU 用于设备 I/O 的时间占比是多少？

每次中断传送：

$$
D=\frac{32}{8}=4\ \mathrm{B}
$$

每秒中断次数：

$$
N=\frac{0.5\times10^6}{4} =125000
$$

每次中断执行等效指令：

$$
18+2=20
$$

每次中断消耗：

$$
C=20\times5=100
$$

个 CPU 时钟周期。

每秒中断总开销：

$$
C_{\mathrm{total}}=125000\times100 =12.5\times10^6
$$

CPU 每秒时钟周期数：

$$
500\times10^6
$$

所以占用率：

$$
\eta=\frac{12.5\times10^6}{500\times10^6}
$$

$$
\boxed{\eta=2.5\%}
$$

第（2）问：改用 DMA

设备数据率提高到：

$$
R=5\ \mathrm{MB/s}
$$

DMA 每次传送：

$$
D=5000\ \mathrm{B}
$$

每个 DMA 块的预处理和后处理开销为 500 个 CPU 周期。

每秒块数：

$$
N=\frac{5\times10^6}{5000} =1000
$$

每秒 CPU 管理开销：

$$
C_{\mathrm{DMA}}=1000\times500 =5\times10^5
$$

所以 CPU 占用率：

$$
\eta_{\mathrm{DMA}} =\frac{5\times10^5}{500\times10^6}
$$

$$
\boxed{\eta_{\mathrm{DMA}}=0.1\%}
$$

本题给定 DMA 与 CPU 无访存冲突，因此这里不另外计算 CPU 因总线争用而等待的时间。

最终比较：

| 方式  | 设备数据率    | CPU 占用率 |
| --- | -------- | ------- |
| 中断  | 0.5 MB/s | 2.5%    |
| DMA | 5 MB/s   | 0.1%    |

设备数据率增加了 10 倍，但 CPU 的管理占用比例反而降低。

为什么？

因为中断方式需要频繁执行 CPU 指令来完成数据搬运。

DMA 则让硬件控制器承担大批量数据传输，CPU 主要负责初始化和结束处理。

这也说明：

DMA 可以显著减少 CPU 的软件管理开销，但不意味着 DMA 完全不使用 CPU，也不意味着 DMA 不消耗主存和总线资源。

### 大题 2：2016 年第 44 题——异步串行通信

这道题将串行帧格式、设备工作时间与中断处理时序组合到一起。

设备 D 传送 7 位 ASCII 字符。

每个字符还需要：

- 1 位起始位；
- 1 位奇校验位；
- 1 位停止位。

所以每个字符在通信线上实际传送：

$$
L=1+7+1+1
$$

$$
\boxed{L=10\ \mathrm{bit}}
$$

注意：

7 位 ASCII 是真正的字符数据。

起始位、校验位和停止位属于额外传输开销。

如果设备每隔：

$$
0.5\ \mathrm{ms}
$$

最多产生一个字符，则每秒最多产生：

$$
N=\frac{1}{0.5\times10^{-3}}
$$

$$
\boxed{N=2000\ \mathrm{字符/s}}
$$

但这并不等于通信线的波特率。

这里 2000 字符/s 是设备的字符产生速率。若还给出线路波特率，则需要进一步判断线路是否能跟上设备。

#### 补充：有波特率时怎样算？

例如采用 9600 bit/s 的二进制串行线路，每帧为：

```text
1位起始 + 8位数据 + 1位校验 + 1位停止
```

共：

$$
L=1+8+1+1=11\ \mathrm{bit}
$$

每秒最多完整发送：

$$
N_{\mathrm{char}}=\frac{9600}{11} \approx872.73
$$

个字符。

如果每个字符有效数据为 8 bit，则有效数据率：

$$
R_{\mathrm{eff}} =9600\times\frac8{11}
$$

$$
\boxed{R_{\mathrm{eff}}\approx6981.82\ \mathrm{bit/s}}
$$

物理线路速率和有效数据率不是一回事。

#### 原题进一步考查：设备工作与 CPU 中断能否重叠？

题设 CPU 主频 50 MHz，CPI 为 4。

设备每个字符工作耗时：

$$
0.5\ \mathrm{ms}\times50\ \mathrm{MHz} =25000
$$

个 CPU 时钟周期。

每次中断响应耗时 10 周期。

中断服务程序共有 20 条指令，其中第 15 条指令启动设备下一次工作。

因此下一次设备启动前，CPU 需要经历：

$$
10+15\times4=70
$$

个周期。

设备相邻工作任务的关键时间间隔为：

$$
25000+70=25070
$$

周期。

处理 1000 个字符，按最后一次中断服务完成作为任务结束，且按照题目时序：

$$
\begin{aligned} T_{\mathrm{total}} &=1000\times25000\\ &\quad+999\times70\\ &\quad+(10+20\times4) \end{aligned}
$$

$$
\boxed{ T_{\mathrm{total}} =25\,070\,020\ \mathrm{cycles} }
$$

但 CPU 真正用于中断响应和服务程序的周期数为：

$$
T_{\mathrm{CPU}} =1000\times(10+20\times4)
$$

$$
\boxed{ T_{\mathrm{CPU}}=90\,000\ \mathrm{cycles} }
$$

两个结果差距非常大。

这是因为设备处理字符期间，CPU 可以进行其他工作。

因此：

> 完成一项 I/O 任务的总历时，不等于 CPU 实际被该任务占用的时间。

这点在操作系统和计算机组成原理的综合大题里也非常重要。

### 大题 3：2018 年第 43 题——查询、中断与 DMA 综合

已知：

$$
f=500\ \mathrm{MHz},\qquad CPI=4
$$

设备 A 的数据率：

$$
R_A=2\ \mathrm{MB/s}
$$

设备 B 的数据率：

$$
R_B=40\ \mathrm{MB/s}
$$

两设备接口各有一个 32 位数据缓冲寄存器。

### 第（1）问：A 使用定时查询

每次缓冲数据量：

$$
D=4\ \mathrm{B}
$$

缓冲填满间隔：

$$
T_A=\frac{4}{2\times10^6}
$$

$$
\boxed{T_A=2\ \mu\mathrm{s}}
$$

为了不丢失数据，理想单缓冲模型下查询间隔不能超过这个时间。

每秒至少需要：

$$
N_A=\frac{2\times10^6}{4} =5\times10^5
$$

次有效查询。

每次查询至少执行 10 条指令，每条平均 4 个周期：

$$
C_A=10\times4=40
$$

CPU 占用率：

$$
\eta_A =\frac{5\times10^5\times40}{500\times10^6}
$$

$$
\boxed{\eta_A=4\%}
$$

### 第（2）问：B 能否采用逐数据缓冲中断方式？

每 4 B 需要：

$$
T_B=\frac{4}{40\times10^6}
$$

$$
\boxed{T_B=0.1\ \mu\mathrm{s}}
$$

才能接收到下一组数据。

但每次中断响应和处理至少需要 400 个时钟周期。

$$
T_{\mathrm{ISR}} =\frac{400}{500\times10^6}
$$

$$
\boxed{T_{\mathrm{ISR}}=0.8\ \mu\mathrm{s}}
$$

发现：

$$
T_{\mathrm{ISR}}>T_B
$$

一次中断还没有处理完，新的数据已经不断到达。

在题设单缓冲、逐缓冲中断的方式下，CPU 无法跟上设备速度。

也可以从 CPU 周期预算角度判断。

每秒需要：

$$
N=\frac{40\times10^6}{4} =10^7
$$

次中断。

需要的 CPU 周期：

$$
10^7\times400=4\times10^9
$$

CPU 每秒只有：

$$
500\times10^6
$$

个时钟周期。

所需周期是 CPU 总周期预算的 8 倍，因此无法持续完成全部中断处理。

### 第（3）问：B 使用 DMA

DMA 每块为 1000 B。

每秒传送块数：

$$
N_{\mathrm{DMA}} =\frac{40\times10^6}{1000} =40000
$$

每块 CPU 管理开销为 500 周期。

$$
C_{\mathrm{DMA}} =40000\times500 =20\times10^6
$$

CPU 占用率：

$$
\eta_{\mathrm{DMA}} =\frac{20\times10^6}{500\times10^6}
$$

$$
\boxed{\eta_{\mathrm{DMA}}=4\%}
$$

完整结论：

| 问题             | 结果                     |
| -------------- | ---------------------- |
| A 最长查询间隔       | $2\ \mu\mathrm{s}$ |
| A 查询方式 CPU 占用率 | 4%                     |
| B 逐缓冲中断方式      | 不可行                    |
| B DMA 管理开销占比   | 4%                     |

这道大题对理解总线和 CPU 性能之间的关系很重要。

CPU 忙不忙，不仅取决于设备数据率，还取决于每次数据传输需要 CPU 参与多少工作。

## 十三、总线与 Cache、主存和 DMA 的综合联系

这一节属于跨章节综合理解。

### 13.1 总线与 Cache 缺失

CPU 访问 Cache 时，如果未命中，需要从下一层存储器读取相应数据块。

假设：

- Cache 块大小为 64 B；
- 存储器数据总线宽度为 64 bit；
- 每个有效传输周期传送一次数据。

每次传输：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

需要的数据传输次数：

$$
N=\frac{64}{8}=8
$$

如果一次地址阶段需要 1 周期，主存首次准备数据需要 6 周期，之后允许按每周期一个数据连续突发传输：

$$
T_{\mathrm{burst}} =(1+6+8)T_c
$$

$$
\boxed{T_{\mathrm{burst}}=15T_c}
$$

如果不允许突发传输，且每次完整事务均需要：

$$
1+6+1=8
$$

个周期：

$$
T_{\mathrm{non}}=8\times8T_c
$$

$$
\boxed{T_{\mathrm{non}}=64T_c}
$$

注意这两个结果都是在明确给定的简化时序条件下计算的。

其本质说明：

Cache 块越大，需要传输的数据量可能越多；总线带宽、主存首字延迟和突发能力都会影响一次 Cache 缺失的处理时间。

这和第 3 章的 Cache 缺失代价直接相关。

### 13.2 DMA 为什么会影响 CPU？

DMA 的数据通路通常为：

```text
外部设备
   │
I/O控制器
   │
DMA控制器
   │
系统互连
   │
  主存
```

CPU 可以不亲自搬运每个数据字。

但 DMA 和 CPU 仍可能争用主存或共享互连资源。

例如 CPU 想访问主存：

```text
CPU ───────> 主存
```

DMA 同时希望：

```text
DMA ───────> 主存
```

如果两者需要使用同一条共享总线或同一个不可并发服务的存储资源，就需要仲裁。

### 13.3 DMA 的三种典型总线使用方式

| 方式             | 原理                | 对 CPU 的影响         |
| -------------- | ----------------- | ----------------- |
| 停止 CPU 访存      | DMA 在某段时间连续使用相关资源 | CPU 对该资源的访问受阻     |
| 周期挪用           | DMA 每次获取一个或若干总线周期 | CPU 的部分访存请求被延迟    |
| DMA 与 CPU 交替访问 | 按一定规则分配访存时机       | 可以降低相互争用，但受具体结构限制 |

注意“DMA 与 CPU 交替访问”不是所有系统都天然支持的模式，需要具体硬件协调。

### 13.4 一个跨章节计算题

假设：

- CPU 每秒发出 $100\times10^6$ 次主存访问请求；
- DMA 每秒发出 $20\times10^6$ 次主存访问请求；
- 每次请求都需要占用同一共享总线 1 个周期；
- 总线每秒最多提供 $150\times10^6$ 个这样的周期；
- 忽略其他开销。

问总线是否能够满足总需求。

每秒需求：

$$
N_{\mathrm{req}} =(100+20)\times10^6
$$

$$
N_{\mathrm{req}}=120\times10^6
$$

资源利用率：

$$
\eta =\frac{120\times10^6}{150\times10^6}
$$

$$
\boxed{\eta=80\%}
$$

从平均总线周期需求看，总容量足够。

但这还不能保证任意时刻所有请求都零等待。

如果 CPU 和 DMA 的请求集中在同一时段，仍可能发生排队与竞争。

平均带宽足够，不代表没有瞬时争用，也不代表访问延迟一定满足要求。

## 十四、综合预测题：把多个高频考点放到一道题里

下面是一道根据历年真题常见组合方式编写的原创练习题，不是历年真题原题。

### 题目

某存储器总线具有以下参数：

- 数据总线宽度 64 bit；
- 基础时钟频率 250 MHz；
- 每个时钟周期传送两次数据；
- 支持突发传输；
- 每次突发最多传输 8 个数据单位；
- 每笔事务需要 1 个地址周期；
- 地址之后需要等待 3 个周期；
- 后续数据连续传输，每个周期可以传两次；
- 假定不同事务之间不发生流水重叠。

回答：

1. 该总线的理论峰值带宽是多少？
2. 一次完整突发最多传多少字节？
3. 完成一次 8 数据单位突发需要多少时钟周期？
4. 该突发事务需要多少时间？
5. 连续重复这种事务时，平均有效带宽是多少？
6. 如果将数据总线宽度增加到 128 bit，其他时序不变，理论峰值带宽是多少？

<Accordions>
<Accordion title="展开：综合预测题六问完整推导" id="bus-combined-worked">

### 第（1）问：理论峰值带宽

每次传：

$$
D=\frac{64}{8}=8\ \mathrm{B}
$$

每周期两次：

$$
r=2
$$

所以：

$$
B_{\max} =8\times250\times10^6\times2
$$

$$
\boxed{B_{\max}=4\ \mathrm{GB/s}}
$$

### 第（2）问：一次突发数据量

$$
D_{\mathrm{burst}}=8\times8
$$

$$
\boxed{D_{\mathrm{burst}}=64\ \mathrm{B}}
$$

### 第（3）问：总周期数

地址阶段：

$$
N_a=1
$$

等待阶段：

$$
N_w=3
$$

8 次数据传输，每周期传两次：

$$
N_d=\frac82=4
$$

所以：

$$
N=N_a+N_w+N_d
$$

$$
\boxed{N=8}
$$

### 第（4）问：总时间

时钟周期：

$$
T_c=\frac{1}{250\times10^6} =4\ \mathrm{ns}
$$

总时间：

$$
T=8\times4
$$

$$
\boxed{T=32\ \mathrm{ns}}
$$

### 第（5）问：平均有效带宽

$$
B_{\mathrm{eff}} =\frac{64}{32\times10^{-9}}
$$

$$
\boxed{B_{\mathrm{eff}}=2\ \mathrm{GB/s}}
$$

总线有效利用率：

$$
\eta=\frac{2}{4}=50\%
$$

因此：

$$
\boxed{\eta=50\%}
$$

### 第（6）问：将数据总线增宽至 128 bit

每次传输：

$$
D=\frac{128}{8}=16\ \mathrm{B}
$$

理论峰值：

$$
B'_{\max} =16\times250\times10^6\times2
$$

$$
\boxed{B'_{\max}=8\ \mathrm{GB/s}}
$$

峰值带宽翻倍。

如果同样进行一次 8 数据单位的突发，那么突发总数据量也从 64 B 增加到 128 B。

但如果任务是读取固定大小的 64 B 数据块，就要重新计算需要的数据传输次数，不能机械认为事务时间完全不变。

这道题的核心是区分：

传输单位数量固定与总数据量固定是两个不同条件。

## 十六、本章最容易失分的 15 个知识点

| 常见错误认识             | 正确理解                |
| ------------------ | ------------------- |
| 1. 数据总线只能传送操作数     | 指令、状态字等也可能通过数据线传送   |
| 2. 地址总线宽度决定每次传输量   | 地址总线宽度决定可表示的地址数量    |
| 3. 控制总线全部信号方向相同    | 具体控制线可以具有不同方向       |
| 4. 单总线就是一根导线       | 单总线表示共享一套主要互连资源     |
| 5. CPU 永远是总线主设备    | DMA 控制器等也可能成为主设备    |
| 6. 时钟周期等于总线周期      | 一个总线周期可包含多个时钟周期     |
| 7. MHz 总是等于 MT/s   | 每周期可以进行多次数据传输       |
| 8. DDR 有效频率还要再乘 2  | 需要判断给定的是时钟频率还是有效传输率 |
| 9. 总线位宽可直接当成字节数    | bit 换算成 B 要除以 8     |
| 10. 全双工带宽必须乘 2     | 仅在统计双方向合计吞吐量时相加     |
| 11. 突发传输重复发送所有地址   | 通常只发送一次起始地址         |
| 12. 复用地址线和数据线能直接提速 | 主要目的是节省线路           |
| 13. 并行总线必然比串行快     | 还受到频率、编码和物理实现限制     |
| 14. 分离事务必然降低单次访问延迟 | 它主要提高总线利用率与并发性      |
| 15. 理论峰值等于实际有效带宽   | 实际事务还可能包含等待、地址和协议开销 |

其中尤其应该注意第 8、10、11、15 项。

这些知识点经常被组合到一道题中。

## 十七、本章公式总表

考试前可以集中复习以下公式。

| 计算对象        | 公式                                                                          | 使用条件               |
| ----------- | --------------------------------------------------------------------------- | ------------------ |
| 时钟周期        | $T_c=\dfrac1f$                                                          | 已知时钟频率             |
| 每次数据量       | $D=\dfrac W8$                                                           | 宽度 $W$ 单位为 bit |
| 每周期传多次      | $R=fr$                                                                  | 每周期完成 $r$ 次传输  |
| 每次占多个周期     | $R=\dfrac fc$                                                           | 每次传输占 $c$ 个周期  |
| 理论带宽        | $B_{\max}=DR$                                                          | 求最大数据传输能力          |
| 多通道带宽       | $B_{\mathrm{total}}=CB_{\mathrm{channel}}$                            | $C$ 个独立并行通道    |
| 双向全双工合计     | $B_{\mathrm{total}}=B_{\rightarrow}+B_{\leftarrow}$                  | 统计双方向总吞吐量          |
| 有效带宽        | $B_{\mathrm{eff}}=\dfrac{D_{\mathrm{payload}}}{T_{\mathrm{total}}}$  | 完整事务或任务            |
| 带宽利用率       | $\eta=\dfrac{B_{\mathrm{eff}}}{B_{\max}}$                             | 分子分母采用一致统计口径       |
| 非突发时间       | $T=N(a+m+d)T_c$                                                         | 各次事务独立且不重叠         |
| 突发时间        | $T=(a+m+Nd)T_c$                                                         | 首次准备后可以连续传输        |
| 首延迟模型       | $T=[L+(N-1)d]T_c$                                                       | 首数据已经包含在 $L$ 中 |
| 串行帧总位数      | $L=s+d+p+t$                                                             | 起始、数据、校验和停止位       |
| 串行有效数据率     | $R_{\mathrm{eff}}=R_b\dfrac dL$                                        | 线路速率为 $R_b$    |
| CPU I/O 占用率 | $\eta_{\mathrm{CPU}}=\dfrac{\text{每秒I/O消耗的CPU周期数}}{f_{\mathrm{CPU}}}$ | 统计 CPU 执行开销        |

这里最需要牢牢记住的不是所有公式的字母，而是：

$$
\boxed{ \text{理论带宽} = \text{每次数据量} \times \text{每秒传输次数} }
$$

$$
\boxed{ \text{实际数据率} = \frac{\text{有效数据量}} {\text{实际总时间}} }
$$

以及：

$$
\boxed{ \text{完整事务时间} = \text{必要的地址、等待、数据等阶段时间} }
$$

这三种思路基本贯穿了本章的主要计算题。

## 十八、最后总结：第 6 章应该掌握到什么程度？

结合原稿引用的 Fumadocs 知识资料、分类真题和模拟题，建议按照下面的优先顺序复习。

| 复习顺序 | 重点内容            | 掌握标准                 |
| ---- | --------------- | -------------------- |
| 第一   | 总线带宽、频率、宽度      | 看到条件能立即列出正确公式        |
| 第二   | 理论峰值与有效吞吐量      | 能判断是否计入事务开销          |
| 第三   | Burst 与非 Burst  | 能准确画出事务时间线           |
| 第四   | DDR、多通道、全双工     | 不重复乘 2，不漏通道          |
| 第五   | 2023、2024 年真题模型 | 会算 Cache 块读取和完整突发事务  |
| 第六   | 同步、异步、半同步       | 能解释握手与等待机制           |

| 第九   | 总线与 DMA、I/O 综合  | 能区分 CPU 占用、总线占用和任务历时 |

#### 本章最值得反复练习的真题

从目前读取的站内资料看，推荐按这个顺序练习：

2024 年 → 2023 年 → 2020 年 → 2012 年 → 2019 年 → 2015 年 → 2016 年 → 2018 年。

前五个年份优先练计算，后几个年份优先掌握概念辨析和性能优化的理解。

其中 2023 年和 2024 年两道题尤其重要：

2023 年真正考查的是：

$$
\boxed{ \text{非突发传输} + \text{主存等待时间} + \text{连续数据块读取} }
$$

2024 年真正考查的是：

$$
\boxed{ \text{理论峰值带宽} \ne \text{一次完整事务的平均有效带宽} }
$$

最后，把整章串成一个完整的认识：

总线负责连接部件，仲裁决定谁先使用，定时决定什么时候传，事务决定传输过程，宽度和频率决定物理传输能力，Burst 与分离事务等机制则影响实际传输效率。

真正掌握了这条逻辑链，就不再需要针对每一道题记住独立的计算套路。即使题目将 Cache、主存、DMA、双倍数据率以及总线事务混合起来，也能够从数据量、传输次数和时间开销三个方面逐步拆解。
