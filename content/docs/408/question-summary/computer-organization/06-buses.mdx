## 二、总线的基本概念
### 2.1 什么是总线？
总线（Bus）是连接计算机多个功能部件、用于传送地址、数据以及控制信息的一组公共通信线路或互连资源。

传统计算机可以抽象为：

```text
             CPU
              │
              │
   ┌──────────┼───────────┐
   │          │           │
  主存      I/O接口A    I/O接口B
   │          │           │
   └──────────┼───────────┘
              │
           系统总线
```

总线有两个典型特征。

**共享性：**&#x2060;多个部件共享同一组通信资源。

**分时性：**&#x2060;在经典共享总线中，同一时刻通常只有一个主设备获得总线控制权。

例如：

```text
时间 ──────────────────────────→

| CPU访存 | DMA访存 | CPU访存 |
```

CPU 与 DMA 都需要访问主存，但不能在同一个共享总线周期内无冲突地独占同一组资源。

注意两个细节：

- 单总线不代表只有一根导线，而是一套共享互连。
- PCIe 等现代高速互连采用点到点连接和交换结构，并不一定具有传统物理共享总线的全部特征。

#### 真题考点
常见问法包括：

- 总线是否只能连接两个部件？
- 一条总线是否必须包含统一时钟？
- 一条总线上是否可以同时有两个主设备？
- 总线主设备是否一定是CPU？

关键是区分经典共享总线模型与现代交换式互连。选择题如果采用传统单总线模型，同一时刻通常只有一个主设备控制共享数据通路。

### 2.2 三类系统总线
这是本章最基本的概念，也是非常容易出现细节陷阱的地方。

| 类型   | 功能         | 典型方向       | 决定什么     |
| ---- | ---------- | ---------- | -------- |
| 数据总线 | 传输数据与编码信息  | 双向         | 一次传输的数据量 |
| 地址总线 | 指定访问目标     | 当前主设备到目标设备 | 可表示的地址数量 |
| 控制总线 | 协调读写、请求与应答 | 各控制信号方向不同  | 总线事务如何执行 |

#### 2.2.1 数据总线
数据总线传输的内容不只是普通操作数，还包括：

- 指令；
- 操作数；
- 运算结果；
- I/O命令字；
- I/O状态字；
- 中断类型号等编码信息。

例如：

```text
CPU读取主存：

主存 ──────数据──────→ CPU

CPU写入主存：

CPU ──────数据──────→ 主存
```

所以数据总线通常是双向的。

如果数据总线宽度为 $W$ bit，那么一次满宽度传输的数据量为：

$$
\boxed{D=\frac{W}{8}\ \mathrm B}
$$

例如64位数据总线：

$$
D=\frac{64}{8}=8\ \mathrm B
$$

注意：数据总线宽度、机器字长、存储字长是不同概念，三者不一定相等。

#### 真题：2011年数据总线
题目：在系统总线的数据线上，不可能传输的是：

A. 指令\
B. 操作数\
C. 握手应答信号\
D. 中断类型号

答案：C。

原因是：

指令、操作数、中断类型号都可以作为二进制编码信息传送。

但握手应答用于控制通信过程，是控制信号。

这里要特别区分：

命令字可以作为数据传输，而控制信号通常通过控制线传输。

例如：

- 向设备写入一个编码命令字，可以经过数据总线。
- 向设备发出的读使能、写使能、ACK等信号，属于控制信号。

这类题不能简单地认为“带有命令意义的信息都必须走控制总线”。

### 2.2.2 地址总线
地址总线用于指出目标存储单元或者I/O端口。

如果有 $n$ 根地址线，最多可以表示：

$$
\boxed{N=2^n}
$$

个不同地址。

当采用按字节编址时，最大可寻址空间为：

$$
\boxed{S=2^n\ \mathrm B}
$$

例如32位地址总线：

$$
S=2^{32}\ \mathrm B=4\ \mathrm{GiB}
$$

如果是按字编址，并且一个字为4 B，那么：

$$
S=2^n\times4\ \mathrm B
$$

这说明：

地址总线宽度决定地址数量，存储容量还取决于编址单位。

#### 典型计算题
某计算机：

- 地址总线32位；
- 数据总线64位；
- 按字节编址。

求最大可寻址空间和一次满宽度传输的数据量。

第一步，计算地址空间：

$$
2^{32}\ \mathrm B=4\ \mathrm{GiB}
$$

第二步，计算一次传输量：

$$
\frac{64}{8}=8\ \mathrm B
$$

答案是：

4 GiB，8 B。

容易出错的地方是把64位数据总线误认为能决定64位地址空间。

#### 地址总线一定从CPU指向主存吗？
不一定。

普通CPU访存：

```text
CPU ──地址──→ 主存
```

DMA访存：

```text
DMA控制器 ──地址──→ 主存
```

地址由当前总线主设备发出，并不一定由CPU发出。

在传统CPU—主存模型下，教材常称地址总线单向；进入多主设备系统后，应理解为当前事务的地址传送方向由主设备指向目标设备。

### 2.2.3 控制总线
控制总线主要传输：

- 读/写控制；
- 总线申请；
- 总线允许；
- 中断请求；
- 中断响应；
- 就绪信号；
- 握手应答；
- 时钟和复位等。

例如：

```text
CPU ─────Read────→ 主存

CPU ←────Ready──── 主存
```

读命令由CPU发出，而Ready信号由主存返回。

因此：

控制总线内部既有主设备向从设备传输的信号，也有反方向信号。

不能简单说整个控制总线一定单向。

#### 模拟题：总线信息方向
典型模拟题问：

在传统主从总线模型中，地址、数据、控制命令、状态响应，哪些信息类型具有典型的单向传输方向？

答案：地址、控制命令、状态响应。

原因：

- 地址：主到从；
- 控制命令：主到从；
- 状态响应：从到主；
- 数据：读写方向不同。

注意，题目问的是“控制命令”而非“整个控制总线”。

### 2.3 总线的分类
总线可以根据不同标准分类。

| 分类依据   | 类型             |
| ------ | -------------- |
| 传输信息   | 数据总线、地址总线、控制总线 |
| 连接对象   | 核内总线、系统总线、通信总线 |
| 传输组织方式 | 串行总线、并行总线      |
| 定时方式   | 同步、异步、半同步      |
| 连接结构   | 单总线、双总线、多总线    |

这些分类是不同维度。

一条系统总线可以同时是并行总线和同步总线。

#### 2.3.1 串行总线与并行总线
**串行总线：**&#x2060;数据的各个比特按时间先后沿较少的线路传输。

**并行总线：**&#x2060;多位数据在同一个传输时刻通过多条线路并行传输。

| 比较      | 串行            | 并行                |
| ------- | ------------- | ----------------- |
| 信号线数量   | 通常较少          | 通常较多              |
| 同时传送比特数 | 单通道较少         | 多位                |
| 高频信号完整性 | 较易控制          | 易受偏斜与串扰影响         |
| 典型标准    | USB、SATA、PCIe | PCI、PATA、传统内存数据通道 |

最重要的结论：

并行传输不一定比串行传输快。

总带宽既取决于一次传输的数据量，也取决于传输频率、通道数量和协议开销。

例如：

32位并行总线，33 MHz，每周期传一次：

$$
B=\frac{32}{8}\times33\times10^6 =132\ \mathrm{MB/s}
$$

如果一条串行链路的有效数据速率达到2 Gbit/s：

$$
B=\frac{2\times10^9}{8} =250\ \mathrm{MB/s}
$$

即使采用串行方式，也可能具有更高带宽。

#### 2.3.2 PCI与PCIe
这是很典型的选择题考点。

PCI：传统并行扩展总线。

PCIe：采用高速串行链路的点到点互连。

PCIe ×16 中的16指的是：

16条Lane，而不是16位并行数据总线。

每条Lane采用高速串行传输，多条Lane可以并行工作以提高整体带宽。

其他容易混淆的标准：

| 名称       | 特征         |
| -------- | ---------- |
| ISA/EISA | 传统并行扩展总线   |
| PCI      | 并行扩展总线     |
| PCIe     | 串行点到点互连    |
| PATA     | 并行ATA      |
| SATA     | 串行ATA      |
| USB      | 外部串行总线     |
| NVMe     | 非易失性存储设备协议 |

另外，M.2主要描述设备外形与连接器规范，不等于NVMe。

#### 真题：2017年
题目涉及PCIe ×16的传输方式。

错误说法是：

“PCIe ×16采用并行传输方式。”

原因是PCIe采用多条高速串行Lane，不能把它当成传统16位并行总线。

### 2.4 单总线、双总线与多总线结构
#### 单总线结构

```text
 CPU
  │
  ├────────┐
  │        │
 主存    I/O接口
  │        │
  └──总线──┘
```

优点：

- 结构简单；
- 成本较低；
- 扩展方便。

缺点：

- 竞争严重；
- 总线容易成为系统瓶颈；
- 不同事务难以在同一共享通路上并行。

#### 多总线结构
通过不同总线连接不同速度和用途的设备，例如：

```text
           CPU
            │
     ┌──────┴──────┐
     │             │
  高速存储通路   高速I/O互连
     │             │
    主存       PCIe设备
                   │
                桥接/控制
                   │
                低速设备
```

优点是减少不同设备之间的竞争，并让各个层次适配不同的性能需求。

考试中常见结论：

- 靠近CPU的存储通路通常要求较高速度；
- 高速设备与低速设备可以连接到不同互连层次；
- 不同协议或层次之间可能需要桥接器、控制器或交换结构。

特别注意：CPU内部数据通路的“单总线”与整个计算机系统的“单总线结构”不是同一个讨论对象。

## 三、总线仲裁、事务与定时
### 3.1 主设备与从设备
一次总线事务中：

**主设备（Master）**&#x2060;负责主动发起访问。

**从设备（Slave/Target）**&#x2060;负责识别访问目标并作出响应。

例如CPU读取主存：

```text
CPU                     主存
 │                       │
 │────地址与读命令───────→│
 │                       │
 │      准备数据         │
 │                       │
 │←──────数据────────────│
 │                       │
```

CPU是主设备，主存是从设备。

如果DMA控制器申请总线并向主存写数据，那么DMA控制器就是这次事务的主设备。

因此主设备身份取决于谁发起当前事务。

### 3.2 总线仲裁
当多个主设备同时希望使用共享总线时，必须决定谁获得控制权，这就是总线仲裁。

#### 三种集中式仲裁方式
| 仲裁方式    | 基本原理        | 优点        | 缺点         |
| ------- | ----------- | --------- | ---------- |
| 链式查询    | 总线允许信号逐级传递  | 线路少、简单    | 固定优先级，可能饥饿 |
| 计数器定时查询 | 计数器逐个查询设备   | 可调整优先级    | 逐个查询存在延迟   |
| 独立请求    | 每设备独立请求和允许线 | 速度快、优先级灵活 | 线路多、逻辑复杂   |

<Tabs items={['链式查询', '计数器查询', '独立请求']} defaultIndex={0}>
  <Tab value="链式查询">

```text
仲裁器 → 设备A → 设备B → 设备C
```

离仲裁器较近的设备通常优先级较高。

如果设备A长期申请总线，后面的低优先级设备可能长期得不到使用权。

因此链式查询容易出现饥饿。

  </Tab>
  <Tab value="计数器查询">

```text
设备0 → 设备1 → 设备2 → 设备3
```

通过计数器给出设备编号，判断相应设备是否申请。

可以通过改变计数起点改善公平性，但扫描需要时间。

  </Tab>
  <Tab value="独立请求">

```text
设备A ──请求A──→
设备B ──请求B──→ 仲裁器
设备C ──请求C──→
```

仲裁器根据请求与策略选择设备。

它通常响应较快，但需要更多控制线路。

  </Tab>
</Tabs>

#### 选择题常考
如果问：

- 哪种方式控制线路最少？通常考虑链式查询。
- 哪种方式优先级容易固定？链式查询。
- 哪种方式能够灵活设置优先级？独立请求。
- 哪种方式可通过调整查询起点改变顺序？计数器定时查询。

不要把“设备获得总线控制权”理解为“CPU执行中断服务程序”。

总线仲裁决定谁使用硬件传输资源；中断决定CPU是否转去执行处理程序。

### 3.3 时钟周期、总线周期与总线事务
这是总线计算题必须严格区分的三个概念。

#### 时钟周期
一个时钟信号的周期：

$$
\boxed{T_c=\frac{1}{f}}
$$

例如100 MHz：

$$
T_c=\frac{1}{100\times10^6} =10\ \mathrm{ns}
$$

#### 总线周期
完成一次规定的总线操作所需的时间。

若一个总线周期需要 $N$ 个时钟周期：

$$
\boxed{T_{\mathrm{bus}}=NT_c}
$$

例如一次总线周期需要4个时钟周期：

$$
T_{\mathrm{bus}}=4\times10=40\ \mathrm{ns}
$$

#### 总线事务
主设备与目标设备之间完成的一次完整逻辑访问，例如一次读事务。

它可能包括：

```text
申请总线
   ↓
获得控制权
   ↓
传送地址和命令
   ↓
等待从设备准备
   ↓
传送数据
   ↓
结束事务
```

一次总线事务可能包含多个总线周期，也可能传送多个数据单位。

总线周期不一定等于时钟周期；总线事务也不一定只包含一次数据传输。

### 3.4 同步通信
同步通信通过统一或协调的时钟组织数据传送。

例如：

```text
时钟周期：

T1       T2       T3       T4
│        │        │        │
地址     读命令   数据     结束
```

优点：

- 控制逻辑简单；
- 时序明确；
- 便于组织高速连续数据传输。

缺点：

- 对设备速度差异的适应性不够灵活；
- 慢速设备可能需要等待周期。

例如：

```text
T1：地址
T2：等待
T3：等待
T4：数据有效
```

同步总线可以插入等待周期。

#### 真题：2015年
题目询问同步总线时钟能否由设备各自独立提供。

错误观点是：

“同步总线中各设备可以各自独立提供互不协调的同步时钟。”

同步通信必须有共同或经过协调的时序关系，不能任由设备以互不协调的时钟采样数据。

### 3.5 异步通信
异步通信不依赖统一固定时钟来决定全部传输动作，而是利用请求、应答等握手信号协调。

```text
主设备发出REQ
      ↓
从设备收到请求
      ↓
从设备准备数据
      ↓
从设备发出ACK
      ↓
主设备确认完成
```

典型应用是两端速度差异较大或者响应时间不固定的场景。

例如打印机接口与打印机构之间的通信。

但不能认为所有低速设备都必须采用异步通信。

#### 三种异步互锁方式
| 方式  | 请求信号如何撤销    | 应答信号如何撤销    |
| --- | ----------- | ----------- |
| 不互锁 | 可以按约定时序自行撤销 | 可以按约定时序自行撤销 |
| 半互锁 | 通常等待应答后撤销   | 可以自行撤销      |
| 全互锁 | 等待应答后撤销     | 等待请求撤销后再撤销  |

最重要的是全互锁的四相握手：

```text
REQ ↑
  ↓
ACK ↑
  ↓
REQ ↓
  ↓
ACK ↓
```

记忆：

请求升、回答升、请求降、回答降。

全互锁的信号依赖关系最完整，因而可靠性较高，但通常也需要更多握手步骤。

#### 半同步通信
半同步结合了统一时钟和等待、就绪控制信号。

例如慢设备可通过等待信号要求增加周期。

与纯异步方式的区别是：

半同步仍以时钟作为时序基础。

### 3.6 突发传输与分离事务
#### 普通非突发传输
假设读取连续4个数据单位：

```text
地址1 → 数据1
地址2 → 数据2
地址3 → 数据3
地址4 → 数据4
```

每次都需要指定地址并完成相应访问。

#### 突发传输（Burst）

```text
首地址 → 数据1 → 数据2 → 数据3 → 数据4
```

只提供一次首地址，后续地址通常自动递增。

主要优点：

- 减少重复寻址开销；
- 减少重复控制开销；
- 提高大块连续数据传输的平均效率。

典型应用包括Cache块填充和连续主存访问。

突发传输不等于增加总线宽度，也不意味着一次传完整个数据块。

一次突发依然可能包含多个连续的数据传输周期。

#### 分离事务
假设CPU读主存，而主存需要很长时间准备数据。

普通非分离事务中，总线可能在等待期间被占用。

分离事务将访问拆成：

```text
请求事务
   ↓
主设备释放互连
   ↓
从设备准备数据
   ↓
响应事务
```

这样等待期间互连可以为其他请求服务。

突发传输主要减少重复寻址开销；分离事务主要减少等待期间的总线占用。

#### 真题：2016年
题目问关于总线设计的错误说法。

错误选项是：

“并行总线传输一定比串行总线传输速度快。”

其他几个设计手段需要理解：

| 设计手段     | 主要效果          |
| -------- | ------------- |
| 增加数据总线宽度 | 一次传更多数据       |
| 提高工作频率   | 单位时间增加传输机会    |
| 突发传输     | 减少重复寻址与事务启动开销 |
| 地址/数据线复用 | 减少线路和引脚       |
| 分离事务     | 减少等待期间的资源占用   |

其中地址/数据线复用的主要目标不是提高带宽。

## 四、总线性能指标与计算题
这是本章第一类必须熟练掌握的计算题。

### 4.1 总线带宽的基本公式
总线带宽表示单位时间内能够传输的数据量。

最基本的公式是：

$$
\boxed{ B=\text{每次传输的数据量}\times\text{每秒传输次数} }
$$

假设：

- 数据总线宽度为 $W$ bit；
- 总线时钟频率为 $f$ Hz；
- 每个时钟周期能传输 $M$ 次数据。

那么理论峰值带宽为：

$$
\boxed{ B_{\max}=\frac{W}{8}\times f\times M }
$$

如果存在 $C$ 个真正能够并行工作的独立通道：

$$
\boxed{ B_{\max}=C\times\frac{W}{8}\times f\times M }
$$

注意：这里的 $f$ 是时钟频率，而不是已经计算过倍频的有效数据传输率。

例如：

- 总线宽64 bit；
- 时钟频率200 MHz；
- 每个时钟周期传输2次。

那么：

$$
B=\frac{64}{8}\times200\times10^6\times2
$$

$$
\boxed{B=3.2\ \mathrm{GB/s}}
$$

本章带宽题最容易出现四类错误：

1. bit没有转换成Byte；
2. 把总线时钟频率直接当成有效传输频率；
3. DDR已经给出有效传输率，却再次乘2；
4. 题目要求有效带宽，却只计算了理论峰值。

### 4.2 真题：2009年总线带宽

题目：

某系统总线一个总线周期并行传输4 B，一个总线周期需要2个时钟周期，总线时钟频率为10 MHz。

求总线带宽。

<Steps>
  <Step>

    ### 第一步：计算每秒时钟周期数

$$
f=10\times10^6\ \mathrm{Hz}
$$

  </Step>
  <Step>

    ### 第二步：计算每秒总线周期数

因为一个总线周期需要2个时钟周期：

$$
N=\frac{10\times10^6}{2} =5\times10^6
$$

  </Step>
  <Step>

    ### 第三步：计算带宽

每个总线周期传4 B：

$$
B=4\times5\times10^6
$$

$$
\boxed{B=20\ \mathrm{MB/s}}
$$

正确答案为B。

核心考点：总线周期与时钟周期不一定相同。

不能直接计算：

$$
4\times10\ \mathrm{MHz}=40\ \mathrm{MB/s}
$$

因为这忽略了一个总线周期包含2个时钟周期的条件。

  </Step>
</Steps>

### 4.3 真题：2012年突发传输
题目：

某同步总线：

- 时钟频率100 MHz；
- 总线宽32 bit；
- 地址和数据线复用；
- 每传输一个地址或数据需要1个时钟周期；
- 支持突发传输。

一次主存写事务需要传输128 bit数据。

求最少时间。

#### 第一步：计算时钟周期

$$
T=\frac{1}{100\times10^6} =10\ \mathrm{ns}
$$

#### 第二步：计算数据传输次数

$$
K=\frac{128}{32}=4
$$

需要4个数据周期。

#### 第三步：计算寻址开销
因为地址与数据线复用，且题目采用先传地址、再传数据的时序：

- 首地址：1个周期；
- 4次数据传输：4个周期。

所以：

$$
N=1+4=5
$$

#### 第四步：计算总时间

$$
T_{\text{total}}=5\times10
$$

$$
\boxed{T_{\text{total}}=50\ \mathrm{ns}}
$$

正确答案为C。

#### 为什么不是80 ns？
不能因为数据有128 bit，就把128 bit当成8次或更多次传输。

每次传输宽度是32 bit，所以只需要4次。

#### 为什么不是40 ns？
40 ns只计算了4个数据周期，遗漏了首次传送地址的1个周期。

突发传输可以避免重复寻址，但不能省去第一次寻址。

### 4.4 真题：2014年双沿数据传输
题目：

某总线：

- 地址/数据线32根；
- 时钟频率66 MHz；
- 每个时钟周期传送两次数据；
- 上升沿和下降沿各一次。

求最大总线带宽。

一次传送的数据量：

$$
D=\frac{32}{8}=4\ \mathrm B
$$

每秒传送次数：

$$
N=66\times10^6\times2
$$

因此：

$$
B=4\times66\times10^6\times2
$$

$$
\boxed{B=528\ \mathrm{MB/s}}
$$

正确答案为C。

这里要特别理解：

每时钟周期传送两次，不代表总线宽度增加了一倍。

数据宽度仍然是32 bit，只是数据传输机会增加了一倍。

### 4.5 DDR与多通道带宽
DDR表示Double Data Rate，即双倍数据率。

其基础思想是：

在一个时钟周期的两个有效边沿进行数据传输。

需要区分两个频率：

| 频率      | 含义          |
| ------- | ----------- |
| 时钟频率    | 每秒时钟周期数     |
| 有效数据传输率 | 每秒完成的数据传输次数 |

若给定真实时钟频率 $f$，且每周期传两次：

$$
R_{\text{transfer}}=2f
$$

但是如果题目直接给出1333 MT/s，那么这已经是有效传输率，不应该再次乘2。

#### 真题：2019年三通道DDR3
题目：

计算机采用3通道存储器，总线宽度64 bit，DDR3-1333，求总带宽。

按题目的有效数据传输率口径：

$$
R=1333\times10^6\ \mathrm{次/s}
$$

每次传输：

$$
D=\frac{64}{8}=8\ \mathrm B
$$

单通道：

$$
B_1=1333\times10^6\times8
$$

$$
B_1=10.664\ \mathrm{GB/s}
$$

三个独立通道：

$$
B=3\times10.664
$$

$$
\boxed{B\approx32\ \mathrm{GB/s}}
$$

正确答案为B。

特别注意：资料中的题目把1333 MHz作为工作频率表述。严格的内存术语下，DDR3-1333通常指约1333 MT/s的有效数据传输率，而不是1333 MHz的基础时钟频率。

做题时一定要区分题目给出的到底是时钟频率还是有效传输率。

### 4.6 全双工、半双工与总带宽
#### 单工
只能单向传输。

```text
A ─────→ B
```

#### 半双工
两个方向都能传输，但不能同时进行。

```text
A ─────→ B

或

A ←───── B
```

#### 全双工
两个方向可以同时传输。

```text
A ─────→ B
A ←───── B
```

如果单方向有效带宽为 $B$，两个方向完全对称并且都能同时满速工作，那么双方向合计：

$$
\boxed{B_{\text{total}}=2B}
$$

但如果题目问的是单向带宽，就不能乘2。

#### 真题：2020年QPI总线
题目条件：

- 点对点全双工同步串行总线；
- 每个方向一次传送20 bit信息；
- 其中16 bit是数据，4 bit是校验；
- 时钟频率2.4 GHz；
- 每时钟周期传送2次。

求双向合计有效带宽。

第一步，排除校验位：

$$
D=\frac{16}{8}=2\ \mathrm B
$$

第二步，计算单方向带宽：

$$
B_1=2.4\times10^9\times2\times2
$$

$$
B_1=9.6\ \mathrm{GB/s}
$$

第三步，全双工双方向：

$$
B=9.6\times2
$$

$$
\boxed{B=19.2\ \mathrm{GB/s}}
$$

正确答案为C。

这道题同时考查三个问题：

- 20 bit信息中，真正的数据只有16 bit；
- 每周期有两次传输；
- 全双工双向合计需要乘2。

必须严格区分物理传输信息量与有效负载信息量。

<Callout type="idea" title="理论带宽不等于实际吞吐">

带宽的分母应是实际占用的时间。非突发读写须计入地址与等待周期；突发传输可摊薄启动开销。

</Callout>

### 4.7 理论峰值带宽与有效带宽
这是2023、2024年相关真题以及王道模拟综合题的关键。

理论峰值带宽：

$$
\boxed{ B_{\max}=\frac{W}{8}\times f\times M }
$$

而完整事务的有效数据传输率：

$$
\boxed{ B_{\text{eff}}=\frac{\text{有效数据总字节数}}{\text{完整事务总时间}} }
$$

完整事务可能包含：

```text
地址阶段
   ↓
命令阶段
   ↓
等待阶段
   ↓
数据传送阶段
   ↓
结束事务
```

理论峰值一般只看数据通路能够达到的最高传输能力。

有效传输率则必须计算地址、等待、控制等开销。

#### 示例
假设：

- 总线宽64 bit；
- 频率100 MHz；
- 每周期传一次；
- 每个事务有1个地址周期；
- 2个等待周期；
- 4个连续数据周期。

理论峰值：

$$
B_{\max}=8\times100\times10^6
$$

$$
\boxed{B_{\max}=800\ \mathrm{MB/s}}
$$

一次事务数据量：

$$
D=4\times8=32\ \mathrm B
$$

完整事务周期数：

$$
N=1+2+4=7
$$

时钟周期：

$$
T=10\ \mathrm{ns}
$$

事务耗时：

$$
T_{\text{total}}=70\ \mathrm{ns}
$$

有效带宽：

$$
B_{\text{eff}} =\frac{32}{70\times10^{-9}}
$$

$$
\boxed{B_{\text{eff}}\approx457.14\ \mathrm{MB/s}}
$$

利用率：

$$
\eta=\frac{457.14}{800}
$$

$$
\boxed{\eta\approx57.14\%}
$$

#### 真题：2024年存储器总线带宽
题目：

- 总线频率420 MHz；
- 宽度64 bit；
- 每周期传送2次数据；
- 支持突发传输；
- 第一周期传地址和命令；
- 第4～7周期传送8次数据。

求总线带宽（最大数据传输率）。

答案：

$$
B_{\max}=8\times420\times10^6\times2
$$

$$
\boxed{B_{\max}=6.72\ \mathrm{GB/s}}
$$

正确答案为B。

注意，题目还有另一种可计算的指标。

一次突发传输8次数据：

$$
D=8\times8=64\ \mathrm B
$$

完整事务共7个时钟周期：

$$
T=\frac7{420\times10^6}
$$

因此在题目规定的事务串行、无重叠条件下，长期连续执行同类事务的有效带宽为：

$$
B_{\text{eff}} =\frac{64\times420\times10^6}{7}
$$

$$
\boxed{B_{\text{eff}}=3.84\ \mathrm{GB/s}}
$$

所以：

- 最大数据通路带宽：6.72 GB/s；
- 包含事务开销的持续有效带宽：3.84 GB/s。

两种答案不是互相矛盾，而是对应不同的性能指标。

考试必须看清楚“最大带宽”和“完整事务有效传输率”的区别。

### 4.8 真题：2023年非突发主存块读取
题目：

- 总线宽64 bit；
- 时钟频率1 GHz；
- 每传送一个地址或数据需要1个时钟周期；
- 不支持突发传输；
- 主存准备一个64位数据需要6 ns；
- 主存块大小32 B。

求读取一个主存块的时间。

#### 第一步：计算每次数据传输量

$$
D=\frac{64}{8}=8\ \mathrm B
$$

#### 第二步：计算需要多少次传输

$$
K=\frac{32}{8}=4
$$

#### 第三步：计算每次完整访问时间
时钟周期：

$$
T=\frac1{1\ \mathrm{GHz}}=1\ \mathrm{ns}
$$

一次访问包括：

- 地址：1 ns；
- 主存准备：6 ns；
- 数据传送：1 ns。

因此：

$$
T_1=1+6+1=8\ \mathrm{ns}
$$

#### 第四步：计算整块时间
由于不支持突发，按题设的非重叠访问模型，4次访问都需要完整的地址、等待和数据阶段：

$$
T_{\text{total}}=4\times8
$$

$$
\boxed{T_{\text{total}}=32\ \mathrm{ns}}
$$

正确答案为D。

#### 迁移：如果改成突发传输呢？
假设题目额外规定：

- 只发送一次首地址；
- 主存首次准备数据需要6 ns；
- 后续每1 ns可以连续传送一个数据；
- 数据阶段不再有额外等待。

那么：

$$
T_{\text{burst}}=1+6+4\times1
$$

$$
\boxed{T_{\text{burst}}=11\ \mathrm{ns}}
$$

这是根据新增时序条件推导的变式题，不是原真题答案。

为什么原题是32 ns，而变式可以是11 ns？

因为后者通过突发传输以及连续数据提供能力，减少了重复寻址和等待开销。

仅仅出现“支持突发传输”四个字，并不能无条件推导11 ns。后续数据是否需要等待必须由题干说明。

### 4.9 总线计算通用模型
建议记住以下三种时间模型。

#### 模型一：每次完整事务都重新访问
若传输 $K$ 个数据单位，每次需要：

- 地址阶段 $a$ 周期；
- 等待阶段 $m$ 周期；
- 数据阶段 $d$ 周期。

那么：

$$
\boxed{ T_{\text{nonburst}}=\frac{K(a+m+d)}{f} }
$$

#### 模型二：一次突发共享启动开销
若只需要一次地址和等待阶段，随后每个数据占用 $d$ 周期：

$$
\boxed{ T_{\text{burst}}=\frac{a+m+Kd}{f} }
$$

#### 模型三：题干给出首数据延迟
若首数据需要 $L$ 个周期，之后每隔 $d$ 个周期出现一个数据：

$$
\boxed{ T_{\text{burst}}=\frac{L+(K-1)d}{f} }
$$

第三种模型中，首数据已经包含在 $L$ 内，所以不能再多加一次数据周期。

这三个公式的区别，实质上就是首数据的时间是否已经计算。

## 五、I/O系统与接口
### 5.1 为什么需要I/O接口？
CPU和外设之间存在明显差异：

- 工作速度不同；
- 数据格式不同；
- 控制时序不同；
- 电气信号不同。

例如CPU速度很快，而打印机需要完成复杂的机械动作。

因此需要I/O接口负责协调。

经典结构：

```text
      CPU / 主存
          │
        系统总线
          │
       I/O接口
          │
       外设连接
          │
         外设
```

I/O接口主要承担：

| 功能       | 作用                    |
| -------- | --------------------- |
| 数据缓冲     | 缓解CPU与设备速度差异          |
| 格式转换     | 串并转换、数据宽度转换等          |
| 控制与定时    | 组织命令与数据交换             |
| 状态检测     | 保存Ready、Busy、Error等信息 |
| 地址译码     | 识别CPU访问哪个端口           |
| 中断/DMA支持 | 向主机报告事件或申请传输          |

#### 真题：2021年
题目询问不属于I/O接口的部件。

答案是：磁盘驱动器。

磁盘驱动器属于外部设备，而网络控制器、打印机适配器等具有I/O接口控制功能。

### 5.2 I/O接口与I/O端口
两个概念必须严格区分。

**I/O接口：**&#x2060;主机与外设之间的控制电路。

**I/O端口：**&#x2060;I/O接口中CPU可以访问的寄存器。

例如：

```text
             CPU
              │
          地址译码器
              │
    ┌─────────┼──────────┐
    │         │          │
 数据寄存器 状态寄存器 控制寄存器
    │         │          │
    └─────────┼──────────┘
              │
             外设
```

#### 三种端口
| 端口   | 作用     | CPU主要操作 |
| ---- | ------ | ------- |
| 数据端口 | 暂存数据   | 读/写     |
| 状态端口 | 表示设备状态 | 读       |
| 控制端口 | 接收操作命令 | 写       |

例如读取键盘数据：

1. CPU检测键盘接口状态；
2. 判断数据是否就绪；
3. CPU读取接口中的数据端口；
4. 获得键盘数据。

这里的I/O端口不是机箱上的USB插孔，而是硬件寄存器。

### 5.3 I/O端口编址
408主要考两种方式：

<Tabs items={['统一编址 MMIO', '独立编址 PMIO']} defaultIndex={0}>
  <Tab value="统一编址 MMIO">

Memory-Mapped I/O。

设备寄存器与主存共用统一的地址空间。

例如：

```text
统一地址空间

0x00000000  ┌─────────────┐
            │    RAM      │
            │             │
0xF0000000  ├─────────────┤
            │  I/O寄存器  │
            │             │
0xFFFFFFFF  └─────────────┘
```

CPU可以使用普通访存指令访问设备寄存器。

例如：

```text
MOV EAX, [0xF0001000]
```

如果该地址映射到设备状态寄存器，那么这条指令实际上是在读取设备状态。

优点：

- 不需要专用I/O指令；
- 可以使用普通访存寻址方式；
- 编程模型统一。

缺点：

\- 设备寄存器占据统一地址空间中的地址范围。

注意：MMIO地址属于统一的地址空间，但不代表它是普通RAM。设备寄存器通常还具有特殊的缓存与访问顺序要求。

  </Tab>
  <Tab value="独立编址 PMIO">

Port-Mapped I/O。

主存与I/O端口使用两套独立地址空间。

通常需要专门的I/O指令。

例如传统x86：

```text
IN  AL, 0x60
OUT 0x3F8, AL
```

  </Tab>
</Tabs>

#### 两种方式对比
| 项目         | 统一编址MMIO | 独立编址PMIO     |
| ---------- | -------- | ------------ |
| 地址空间       | 主存与I/O统一 | 主存与I/O分开     |
| 指令         | 普通访存指令   | 专用I/O指令      |
| 是否占用统一地址空间 | 是        | 否            |
| 区分目标       | 地址映射与译码  | I/O操作类型和端口地址 |

#### 真题：2014年
错误说法：

“采用统一编址方式时，CPU不能用访存指令访问I/O端口。”

答案：错误。

统一编址最重要的特征恰恰是可以使用普通访存指令访问I/O寄存器。

另一个常见陷阱：

独立编址下，主存地址和I/O端口地址的数值可以相同。

因为它们属于不同地址空间。

#### 模拟题
“MMIO通过不同的指令类型区分主存和I/O端口。”

这个说法也是错误的。

MMIO主要根据地址映射确定访问目标，而不是根据是否使用专用I/O指令区分。

## 六、四种I/O控制方式
这是本章最重要的知识体系之一。

必须从三个角度理解：

CPU是否等待？数据是谁搬的？CPU在什么时候介入？

### 6.1 四种方式总对比
| 方式   | CPU是否忙等 | 数据由谁搬运    | CPU介入粒度 |
| ---- | ------- | --------- | ------- |
| 程序查询 | 通常是     | CPU       | 每次查询和传输 |
| 程序中断 | 否       | CPU       | 每次中断    |
| DMA  | 否       | DMA控制逻辑   | 数据块首尾   |
| 通道   | 否       | 通道组织的数据通路 | I/O任务首尾 |

记忆方法：

- 查询：CPU等，CPU搬。
- 中断：CPU不等，CPU搬。
- DMA：CPU不等，DMA搬。
- 通道：CPU启动任务，通道按程序组织I/O。

注意：这里的“CPU不等”表示CPU可以执行其他工作，并非CPU绝对不会因I/O发生任何停顿。

### 6.2 程序查询方式
程序查询由CPU主动检查设备状态。

例如：

```text
CPU启动设备
    ↓
读取状态寄存器
    ↓
设备是否就绪？
    │
    ├── 否 → 继续查询
    │
    └── 是 → 读取数据
                 ↓
              写入主存
```

数据路径：

```text
外设
  ↓
I/O接口
  ↓
CPU寄存器
  ↓
主存
```

主要缺点是忙等待。

设备未准备好时，CPU依然不断执行查询代码。

#### CPU占用率
假设：

- 每秒查询 $N$ 次；
- 每次查询消耗 $C$ 个CPU时钟周期；
- CPU主频为 $f$。

那么CPU用于查询的时间比例：

$$
\boxed{ \eta=\frac{NC}{f} }
$$

如果每次查询执行 $I$ 条指令，平均CPI为 $c$：

$$
C=Ic
$$

所以：

$$
\boxed{ \eta=\frac{NIc}{f} }
$$

#### 真题：2011年定时查询
CPU：

- 主频50 MHz；
- 每次查询至少500个时钟周期；
- 每秒至少查询200次。

求最低CPU时间占比。

$$
\eta=\frac{200\times500}{50\times10^6}
$$

$$
\eta=0.002
$$

$$
\boxed{\eta=0.2\%}
$$

正确答案为C。

注意：题目已经给出500个时钟周期，不能再乘CPI。

### 6.3 查询间隔计算
假设：

- 设备传输速度为 $R$ B/s；
- I/O缓冲区能够保存 $D$ B；
- 数据持续到达；
- 若不及时读取，后续数据会覆盖前一份数据。

那么相邻数据到达的时间间隔为：

$$
\boxed{ T_{\max}=\frac{D}{R} }
$$

这是理想条件下允许的最长查询间隔上界。

例如：

设备每秒传输2 MB，数据缓冲寄存器32 bit。

缓冲容量：

$$
D=\frac{32}{8}=4\ \mathrm B
$$

传输速度：

$$
R=2\times10^6\ \mathrm{B/s}
$$

所以：

$$
T_{\max}=\frac4{2\times10^6}
$$

$$
\boxed{T_{\max}=2\ \mu\mathrm s}
$$

即每隔最多2微秒就要及时处理一次数据。

这里要区分两种时间：

- $\frac{D}{R}$：最晚多长时间必须处理数据；
- $\frac{Ic}{f}$：CPU执行一次查询程序需要的时间。

前者由设备数据率和缓冲容量决定，后者由CPU性能决定。

## 七、中断I/O方式
### 7.1 中断方式的基本思想
中断方式不要求CPU不断查询设备。

设备准备好数据后，会主动通知CPU。

```text
CPU启动设备
     ↓
CPU执行其他程序
     ↓
设备数据就绪
     ↓
设备发出中断请求
     ↓
CPU响应中断
     ↓
执行中断服务程序
     ↓
CPU读取数据并写入主存
     ↓
中断返回
```

相比查询方式，中断的主要改进是：

设备没有准备好时，CPU可以处理其他工作。

但是中断方式中的数据搬运通常仍由CPU指令完成。

所以：

中断解决了等待问题，但没有消除CPU逐次搬运数据的开销。

### 7.2 中断响应与中断服务程序
典型外部中断响应过程：

1. CPU检测到有效的中断请求；
2. 判断当前是否允许响应；
3. 在合适的指令边界进入中断响应；
4. 硬件保存必要的断点和处理器状态；
5. 确定中断服务程序入口；
6. 转入中断服务程序；
7. 软件完成设备服务；
8. 恢复现场并中断返回。

必须区分硬件响应动作和软件ISR动作。

| 操作        | 典型完成方式      |
| --------- | ----------- |
| 检测中断请求    | 硬件          |
| 中断应答      | 硬件          |
| 保存必要断点    | 硬件机制        |
| 获取中断向量与入口 | 硬件机制参与      |
| 保存大量通用寄存器 | 通常由软件       |
| 执行设备服务    | 软件ISR       |
| 恢复状态并返回   | 软件指令与硬件语义结合 |

不同体系结构对保存寄存器的具体方式可能不同，但上述分工是408中的典型模型。

#### 外部中断与异常
两者不能混淆。

| 事件      | 类型      |
| ------- | ------- |
| DMA传送结束 | 外部中断    |
| 键盘输入完成  | 外部中断    |
| 定时器中断   | 外部中断    |
| 整数除零    | 异常      |
| 缺页      | 异常      |
| 存储保护错误  | 异常      |
| 系统调用    | 同步异常/陷阱 |

重要区别：

- 外部中断一般在当前指令结束后的适当边界响应；
- 异常可能在当前指令执行过程中被检测；
- 缺页处理完成后通常需要重新执行引发缺页的指令；
- DMA完成中断通常返回到下一条待执行指令。

### 7.3 中断响应优先级与处理优先级
这是中断相关选择题最容易出错的部分。

#### 中断响应优先级
表示：

多个中断请求同时等待CPU响应时，CPU先响应哪一个。

主要受中断控制器、硬件优先级等机制影响。

#### 中断处理优先级
表示：

CPU正在处理某个中断时，哪些其他中断可以打断当前处理程序。

可利用中断屏蔽字等机制调整。

注意：

$$
\boxed{\text{中断响应优先级}\neq\text{中断处理优先级}}
$$

二者可以相同，也可以不同。

### 7.4 真题：2011年中断屏蔽字
题目：

系统有5级中断：

$$
L_4,L_3,L_2,L_1,L_0
$$

中断响应优先级为：

$$
L_0>L_1>L_2>L_3>L_4
$$

要求中断处理优先级为：

$$
L_4>L_0>L_2>L_1>L_3
$$

屏蔽字按照：

$$
M_4M_3M_2M_1M_0
$$

排列，1表示屏蔽，0表示允许。

问：正在处理 $L_1$ 时应设置什么屏蔽字？

#### 第一步：确定当前中断的位置
处理优先级：

$$
L_4>L_0>L_2>L_1>L_3
$$

当前正在处理 $L_1$。

比它高的：

$$
L_4,L_0,L_2
$$

比它低的：

$$
L_3
$$

#### 第二步：确定允许和屏蔽
高于 $L_1$ 的中断允许进入：

$$
M_4=0,\quad M_0=0,\quad M_2=0
$$

当前中断和低优先级中断屏蔽：

$$
M_1=1,\quad M_3=1
$$

#### 第三步：按照规定顺序填写
| 位 | $M_4$ | $M_3$ | $M_2$ | $M_1$ | $M_0$ |
| - | --------- | --------- | --------- | --------- | --------- |
| 值 | 0         | 1         | 0         | 1         | 0         |

因此：

$$
\boxed{01010}
$$

正确答案为D。

最重要的是：

设置屏蔽字依据处理优先级，而不是直接依据响应优先级。

<Callout type="warn" title="中断开销与设备用时不可混算">

中断方式下，CPU 用于中断服务的时间与外设连续工作的时间不是同一口径；先找每秒事件次数与每次服务周期数，再除以 CPU 每秒总周期数。

</Callout>

### 7.5 中断CPU占用率
假设：

- 设备速率为 $R$ B/s；
- 每次中断传输 $D$ B；
- 一次中断消耗 $C$ 个CPU周期；
- CPU频率为 $f$。

每秒中断次数：

$$
\boxed{ N_{\text{int}}=\frac{R}{D} }
$$

每秒消耗CPU周期数：

$$
N_{\text{int}}C
$$

因此：

$$
\boxed{ \eta_{\text{int}}= \frac{R}{D}\frac{C}{f} }
$$

如果一次中断包含：

- $I$ 条指令；
- CPI为 $c$；
- 额外响应开销为 $C_0$ 个周期。

那么：

$$
C=Ic+C_0
$$

注意：如果额外开销以“等效指令条数”表示，应与其他指令一起乘CPI；如果直接给出时钟周期，就不能再乘CPI。

#### 中断方式能不能持续工作？
除了计算CPU占用率，还必须判断处理速度是否足够。

设备每产生一份数据的时间：

$$
T_{\text{arrival}}=\frac{D}{R}
$$

一次中断服务时间：

$$
T_{\text{ISR}}=\frac{C}{f}
$$

对于单缓冲、逐缓冲中断且不能丢失数据的典型模型，至少需要：

$$
\boxed{ T_{\text{ISR}}\le T_{\text{arrival}} }
$$

否则下一份数据可能在上一份尚未处理完成时到达。

这也是2018年真题的核心。

## 八、DMA直接存储器访问
### 8.1 DMA的基本思想
DMA全称Direct Memory Access。

DMA的核心是：

不需要CPU亲自执行逐字节或逐字的数据搬运指令，由DMA控制逻辑直接组织I/O接口与主存之间的数据传送。

#### 中断方式的数据路径

```text
外设
 ↓
I/O接口
 ↓
CPU寄存器
 ↓
主存
```

#### DMA方式的数据路径

```text
外设
 ↓
I/O接口
 ↓
DMA控制的系统数据通路
 ↓
主存
```

CPU只需要完成初始化和传送完成后的处理。

所以：

DMA减少的不只是等待开销，还减少了CPU逐个数据单位搬运数据的开销。

### 8.2 DMA控制器结构
典型DMA控制器包含以下部件：

| 部件        | 主要作用         |
| --------- | ------------ |
| 地址寄存器MAR  | 保存当前主存地址     |
| 计数器DC     | 记录剩余传输量      |
| 数据缓冲寄存器DR | 暂存传送数据       |
| 命令状态寄存器CR | 保存传输模式、方向和状态 |
| I/O控制逻辑   | 与设备交换控制信号    |
| 总线控制逻辑    | 申请和获得访问权     |

DMA工作过程中，通常：

```text
传输一个数据单位
       ↓
更新主存地址
       ↓
更新计数器
       ↓
判断是否完成
       ↓
继续传输或结束
```

需要注意：

- 地址每次增加多少取决于数据单位大小与编址方式；
- 计数器不一定按字节减1；
- 具体地址、计数更新方向由题设决定。

### 8.3 DMA的完整工作过程
可以分成三个阶段。

#### 第一阶段：CPU预处理
CPU设置DMA控制器：

- 主存起始地址；
- 数据传输长度；
- 数据传输方向；
- 使用的设备；
- DMA工作模式。

#### 第二阶段：DMA传输
DMA控制逻辑：

1. 接收设备的传输请求；
2. 申请总线或主存访问权；
3. 获得控制权；
4. 在主存与I/O接口之间传输数据；
5. 更新地址和计数器；
6. 重复至数据块完成。

#### 第三阶段：传输完成
DMA控制器：

- 设置完成状态；
- 释放相关资源；
- 通常通过中断通知CPU。

CPU进行后处理。

#### 真题：2019年DMA工作过程
题目列出：

I. DMA前由设备驱动程序设置传输参数。\
II. DMA控制器请求总线使用权。\
III. DMA控制器控制数据传送。\
IV. DMA结束后由中断服务程序处理。

答案：全部正确。

这四句话就是DMA工作流程的完整考点。

### 8.4 DMA请求与中断请求
这是非常重要的辨析题。

| 项目        | DMA请求       | 中断请求         |
| --------- | ----------- | ------------ |
| 直接目的      | 申请总线或主存访问资源 | 请求CPU处理事件    |
| 是否立即执行ISR | 不要求         | CPU接受后进入ISR  |
| 数据由谁搬     | DMA控制逻辑     | 普通中断I/O由CPU搬 |
| 常见时机      | DMA需要传数据时   | 数据块完成或出错后    |

记忆：

DMA请求的是传输资源，中断请求的是CPU处理。

#### 真题：2013年
题目比较中断I/O与DMA。

其中：

- 中断请求CPU处理时间；
- DMA请求总线使用权；
- 中断传送主要通过CPU软件执行；
- DMA数据传送由硬件控制。

这些结论都是正确的。

错误的是：

“DMA只能用于快速外部设备。”

DMA更适合高速、批量传输，但从原理上讲并不局限于高速设备。

### 8.5 DMA与CPU争用主存
CPU和DMA都可能需要访问主存。

经典教材主要讨论三种协调方式。

#### 第一种：DMA成组传送
DMA获得控制权后，连续占用总线传送多个数据单位或一个数据块。

```text
CPU  CPU  | DMA DMA DMA DMA | CPU
```

优点：

- 数据传送连续；
- 仲裁与控制开销较少；
- DMA吞吐率较高。

缺点：

- DMA占用期间，CPU可能无法经该共享通路访问主存；
- CPU可能出现较长停顿。

#### 第二种：周期挪用
DMA一次只占用一个或少数几个主存周期。

```text
CPU CPU DMA CPU CPU DMA CPU ...
```

优点：

- 设备能够及时传输数据；
- CPU只在部分访存周期受到影响。

这种方式是408中最典型的DMA考点。

#### 第三种：透明传送
DMA利用CPU不访问主存或总线的空闲时隙传输数据。

```text
CPU使用 │ 空闲DMA │ CPU使用 │ 空闲DMA
```

优点：

\- 对CPU影响通常较小。

缺点：

- DMA完成速度依赖空闲周期；
- 不一定适合实时性要求高的传输。

### 8.6 真题：2020年周期挪用DMA
题目：

- DMA每块传送512 B；
- I/O接口包含32位数据缓冲寄存器；
- 采用周期挪用方式。

错误说法是：

“整个DMA数据块传输过程中，CPU都不能访问主存。”

答案：C。

因为周期挪用只是DMA在需要时取走一个或少数几个主存周期。

两次DMA传输之间，CPU仍然可以获得总线控制权。

注意：DMA一次管理一个512 B的数据块，不代表512 B只使用一次总线周期。

若接口每次提供4 B数据，则在简单的单数据单位传送模型下，整个块至少涉及：

$$
\frac{512}{4}=128
$$

次数据单位传输。

这些访问可能分散在不同主存周期中。

### 8.7 DMA的CPU管理开销
设：

- 设备速率 $R$ B/s；
- 每个DMA块大小 $B$ B；
- 每块CPU管理开销 $C$ 周期；
- CPU主频 $f$。

每秒DMA块数：

$$
\boxed{ N_{\text{DMA}}=\frac{R}{B} }
$$

CPU管理占用率：

$$
\boxed{ \eta_{\text{DMA}} =\frac{R}{B}\frac{C}{f} }
$$

这里的 $C$ 是每个DMA块的CPU预处理与后处理总周期数，而不是整个DMA硬件传输期间所有时钟周期。

#### CPU管理占用率与总线占用率不同
例如：

- 总线100 MHz；
- 每周期传8 B；
- DMA设备持续传输50 MB/s。

理论数据带宽：

$$
B_{\max}=100\times10^6\times8 =800\ \mathrm{MB/s}
$$

DMA最少占用的数据传输能力比例：

$$
\eta_{\text{bus}}=\frac{50}{800}
$$

$$
\boxed{\eta_{\text{bus}}=6.25\%}
$$

但这不能直接说明CPU性能下降6.25%。

因为CPU可能：

- 正在进行不需要访存的运算；
- 正在访问Cache；
- 此时不需要共享总线；
- 或者与DMA发生实际资源冲突。

只有明确CPU访存模式和总线仲裁方式，才能准确计算CPU停顿率。

## 九、通道方式
通道方式可以理解为具有一定专用指令执行能力的I/O处理方式。

DMA控制器主要按照预先设置的地址、长度和方向搬运数据。

通道则可以执行存放在主存中的通道程序，组织更复杂的I/O操作。

典型工作流程：

```text
CPU准备通道程序
        ↓
CPU启动通道
        ↓
通道执行通道程序
        ↓
通道组织设备I/O
        ↓
设备与主存交换数据
        ↓
任务完成
        ↓
通道中断通知CPU
```

重要考点：

- 通道程序由CPU准备；
- 通道程序通常由通道执行，而非CPU逐条执行；
- 通道可控制复杂I/O操作；
- CPU可以与通道并行工作。

#### 四种方式最后对比
| 比较项            | 查询     | 中断       | DMA     | 通道      |
| -------------- | ------ | -------- | ------- | ------- |
| CPU是否忙等        | 是      | 否        | 否       | 否       |
| 数据是否逐次经过CPU寄存器 | 是      | 是        | 否       | 否       |
| CPU主要负责        | 查询和搬运  | 中断服务和搬运  | 配置与完成处理 | 启动通道程序  |
| 典型传输粒度         | 小数据单位  | 中断对应的数据量 | 数据块     | 完整I/O任务 |
| 适合场景           | 简单低速设备 | 低中速事件    | 高速批量数据  | 复杂I/O组织 |

特别注意：

DMA完成后也可以发中断，所以不能通过“是否存在中断”区分DMA和普通中断I/O。

真正的区别是传输过程中谁负责搬运数据。

## 十、历年408综合大题详解
下面结合三道历年综合题完整推导。

这三题分别代表：

- 2009年：中断与DMA的CPU占用率；
- 2016年：异步串行通信、中断与设备时间重叠；
- 2018年：查询、中断、DMA三种方式综合比较。

### 10.1 2009年第43题：中断与DMA占用率
题目条件：

CPU：

- 500 MHz；
- CPI=5。

外设：

- 传输速率0.5 MB/s；
- 中断方式；
- 每32 bit数据产生一次中断；
- 每次ISR含18条指令；
- 其他中断开销相当于2条指令。

问题一：中断占用多少CPU时间？

#### 第一步：计算每次中断的数据量

$$
D=\frac{32}{8}=4\ \mathrm B
$$

#### 第二步：计算每秒中断次数

$$
N=\frac{0.5\times10^6}{4}
$$

$$
N=125000\ \mathrm{次/s}
$$

#### 第三步：计算每次中断周期数
总等效指令数：

$$
I=18+2=20
$$

每条指令平均5个周期：

$$
C=20\times5=100
$$

即一次中断消耗100个CPU周期。

#### 第四步：CPU占用率

$$
\eta= \frac{125000\times100}{500\times10^6}
$$

$$
\boxed{\eta=2.5\%}
$$

#### 第二问：改为DMA
新的条件：

- 设备速率5 MB/s；
- DMA每块5000 B；
- 每块预处理和后处理消耗500个时钟周期；
- 假设CPU和DMA没有访存冲突。

每秒DMA块数：

$$
N_{\text{DMA}} =\frac{5\times10^6}{5000}=1000
$$

每秒CPU周期开销：

$$
C_{\text{total}}=1000\times500 =500000
$$

占用率：

$$
\eta= \frac{500000}{500\times10^6}
$$

$$
\boxed{\eta=0.1\%}
$$

#### 本题总结
| 方式  | 设备速率     | CPU管理粒度 | CPU占用率 |
| --- | -------- | ------- | ------ |
| 中断  | 0.5 MB/s | 每4 B    | 2.5%   |
| DMA | 5 MB/s   | 每5000 B | 0.1%   |

这里DMA的数据传输速率提高了10倍，但CPU管理开销仍明显降低。

根本原因是：

DMA把CPU的管理粒度从每4 B一次变成每5000 B一次。

必须记住：

- 中断方式按每次中断计数；
- DMA方式按每个数据块计数；
- 指令条数要乘CPI；
- 已经给出时钟周期的开销不能重复乘CPI。

### 10.2 2016年第44题：串行帧与中断时间重叠
这是本章最值得理解的一道时间轴综合题。

#### 题目条件
CPU：

- 主频50 MHz；
- CPI=4。

外设D：

- 异步串行通信；
- 7位ASCII；
- 1位奇校验；
- 1位停止位；
- 设备每次启动后0.5 ms准备一个字符。

中断：

- 每字符产生一次中断；
- 中断响应10个时钟周期；
- ISR共20条指令；
- 第15条指令重新启动设备。

CPU需要读取1000个字符。

问题：

1. 每字符传多少位？每秒最多多少字符？
2. 总任务经过多少CPU周期？
3. CPU实际用于I/O多少周期？

#### 第一问：串行帧
异步串行通信除了数据位，还包含起始位。

所以：

$$
L=1+7+1+1
$$

$$
\boxed{L=10\ \mathrm{bit}}
$$

设备一次工作0.5 ms：

$$
N=\frac1{0.5\times10^{-3}}
$$

$$
\boxed{N=2000\ \mathrm{字符/s}}
$$

这里2000字符/s由设备准备速度决定。题目没有给线路bit/s，因此不能自行增加一个线路吞吐限制。

#### 第二问：设备工作对应多少CPU周期？
CPU频率：

$$
f=50\times10^6\ \mathrm{Hz}
$$

设备一次工作：

$$
T_D=0.5\times10^{-3}\ \mathrm s
$$

对应CPU周期数：

$$
C_D=fT_D
$$

$$
C_D=50\times10^6\times0.5\times10^{-3}
$$

$$
\boxed{C_D=25000}
$$

设备准备一个字符，相当于经过25000个CPU时钟周期。

#### 第三步：计算CPU一次完整中断服务时间
中断响应：

$$
C_0=10
$$

ISR执行20条指令，每条平均4周期：

$$
C_{\text{ISR}}=20\times4=80
$$

一次完整服务：

$$
C_{\text{service}}=10+80
$$

$$
\boxed{C_{\text{service}}=90}
$$

#### 第四步：计算下一次设备何时启动
题目最重要的条件是：

第15条ISR指令就重新启动设备，而不是等全部20条指令执行完。

因此：

$$
C_{\text{restart}}=10+15\times4
$$

$$
\boxed{C_{\text{restart}}=70}
$$

重新启动后，CPU还需要执行剩余5条ISR指令：

$$
C_{\text{tail}}=5\times4=20
$$

但这20周期可以与下一轮设备工作重叠。

时间轴：

```text
第一次设备工作
├────────────── 25000周期 ──────────────┤
                                       │
                                  中断响应10
                                       │
                                  ISR前15条60
                                       │
                                重新启动设备
                                       │
             ┌── 下一次设备工作25000周期 ───┐
             │                              │
          ISR后5条20                        │
             │                              │
         CPU可执行其他程序                  │
```

#### 第五步：计算1000字符任务总历时
如果从第一次启动设备开始计时，到最后一次ISR全部完成为止：

$$
C_{\text{total}} =1000\times25000 +999\times70 +90
$$

为什么是999次70周期？

因为前999次中断都需要重新启动下一轮设备。

最后一次中断完成后，不需要启动第1001个字符。

计算：

$$
1000\times25000=25000000
$$

$$
999\times70=69930
$$

最后一次中断：

$$
90
$$

总计：

$$
\boxed{C_{\text{total}}=25070020}
$$

约为：

$$
\boxed{2.507\times10^7\ \text{周期}}
$$

如果按照原题的近似口径，可写约25070000周期。

#### 第六步：计算CPU实际忙碌周期
CPU并不需要在设备0.5 ms工作期间一直等待。

真正用于中断响应和服务的周期是：

$$
C_{\text{CPU}}=1000\times90
$$

$$
\boxed{C_{\text{CPU}}=90000}
$$

#### 最终答案
| 指标           | 结果          |
| ------------ | ----------- |
| 每字符线路位数      | 10 bit      |
| 理想最大字符产生速率   | 2000字符/s    |
| 整个任务总历时      | 约25070020周期 |
| CPU实际I/O服务时间 | 90000周期     |

#### 本题最重要的知识
任务总历时不等于CPU忙碌时间。

外设可以与CPU并行工作。

因此遇到这种题，必须画时间轴，区分：

- 设备工作时间；
- CPU响应时间；
- ISR前段；
- 设备重新启动时刻；
- ISR后段；
- 可以重叠的部分。

不能把所有阶段简单地顺序相加。

### 10.3 2018年第43题：查询、中断、DMA综合
这道题把前三种I/O控制方式放在一起考。

#### 题目条件
CPU：

- 主频500 MHz；
- CPI=4。

设备：

- A：2 MB/s；
- B：40 MB/s；
- A、B接口各有一个32位数据缓冲寄存器。

#### 第一问：设备A采用定时查询
每次I/O至少执行10条指令。

问最长查询间隔和最小CPU占用率。

##### 第一步：缓冲容量

$$
D=32/8=4\ \mathrm B
$$

##### 第二步：最长查询间隔

$$
T_{\max}=\frac4{2\times10^6}
$$

$$
\boxed{T_{\max}=2\ \mu\mathrm s}
$$

##### 第三步：每次查询CPU周期

$$
C=10\times4=40
$$

##### 第四步：每秒至少查询次数

$$
N=\frac{2\times10^6}{4} =500000
$$

##### 第五步：CPU占用率

$$
\eta= \frac{500000\times40}{500\times10^6}
$$

$$
\boxed{\eta=4\%}
$$

#### 第二问：设备B采用中断方式
设备B：

$$
R=40\ \mathrm{MB/s}
$$

每次中断处理4 B。

每次中断至少消耗400个CPU周期。

能否持续工作？

##### 第一步：每秒中断次数

$$
N_{\text{int}} =\frac{40\times10^6}{4}
$$

$$
N_{\text{int}}=10^7
$$

##### 第二步：每秒需要多少CPU周期？

$$
C_{\text{needed}}=10^7\times400
$$

$$
C_{\text{needed}}=4\times10^9
$$

CPU每秒只有：

$$
C_{\text{available}}=500\times10^6
$$

理论CPU周期需求是预算的：

$$
\eta= \frac{4\times10^9}{500\times10^6}
$$

$$
\boxed{\eta=800\%}
$$

因此不能持续完成传输。

800%表示需要8倍的单核CPU周期预算，并不表示CPU真实占用率能达到800%。

##### 第二种判断方式
每4 B数据到达间隔：

$$
T_{\text{arrival}} =\frac4{40\times10^6}
$$

$$
T_{\text{arrival}}=0.1\ \mu\mathrm s
$$

一次中断服务时间：

$$
T_{\text{ISR}} =\frac{400}{500\times10^6}
$$

$$
T_{\text{ISR}}=0.8\ \mu\mathrm s
$$

因为：

$$
0.8>0.1
$$

即使CPU一直处理中断，也无法在下一份数据到达前处理完上一份数据。

#### 第三问：设备B改用DMA
条件：

- 每DMA块1000 B；
- 每块CPU预处理和后处理500周期；
- 设备速率40 MB/s。

每秒块数：

$$
N_{\text{DMA}} =\frac{40\times10^6}{1000}
$$

$$
N_{\text{DMA}}=40000
$$

每秒CPU开销：

$$
C_{\text{DMA}}=40000\times500
$$

$$
C_{\text{DMA}}=20\times10^6
$$

占用率：

$$
\eta= \frac{20\times10^6}{500\times10^6}
$$

$$
\boxed{\eta=4\%}
$$

#### 本题完整结果
| 问题            | 答案   |
| ------------- | ---- |
| A最长查询间隔       | 2 μs |
| A最小CPU时间占比    | 4%   |
| B逐4 B中断是否可行   | 不可持续 |
| B中断理论CPU需求    | 800% |
| B采用DMA的最大管理占比 | 4%   |

这道题告诉我们：

不能只看设备速度决定I/O方式，必须同时考虑每次处理的数据量、CPU处理成本和设备缓冲能力。

## 十一、2027王道八套卷综合题详解
### 11.1 第4套第44题：两种总线的读写性能比较
这是非常典型的总线综合计算题。

#### 已知条件
CPU时钟频率100 MHz，字长32 bit。

比较两种同步总线。

总线A：

- 数据宽64 bit；
- 地址数据分时复用；
- 每次事务先用1周期传地址；
- 再等待2周期；
- 每周期传输2个32位字；
- 最多连续传8个字。

总线B：

- 32位地址线和32位数据线分离；
- 每周期传1个32位字；
- 读：1周期地址、2周期等待、再传数据；
- 写：首周期地址与第1个字同时传送，之后等待2周期，其余字连续传输。

事务串行执行，不重叠。

求：

1. 理论峰值带宽；
2. 单字读速率；
3. 单字写速率；
4. 8字块60%读、40%写时的长期有效带宽。

#### 第一问：理论峰值
A每周期传输：

$$
64/8=8\ \mathrm B
$$

因此：

$$
B_A=8\times100\times10^6
$$

$$
\boxed{B_A=800\ \mathrm{MB/s}}
$$

B每周期传输：

$$
32/8=4\ \mathrm B
$$

所以：

$$
B_B=4\times100\times10^6
$$

$$
\boxed{B_B=400\ \mathrm{MB/s}}
$$

#### 第二问：单字读
一个字：

$$
32/8=4\ \mathrm B
$$

时钟周期：

$$
T=10\ \mathrm{ns}
$$

总线A单字读：

$$
N_A=1+2+1=4
$$

总线B单字读：

$$
N_B=1+2+1=4
$$

因此二者均为：

$$
R=\frac4{4\times10^{-8}}
$$

$$
\boxed{R=100\ \mathrm{MB/s}}
$$

#### 第三问：单字写
总线A仍需要4周期：

$$
R_A=\frac4{40\ \mathrm{ns}}
$$

$$
\boxed{R_A=100\ \mathrm{MB/s}}
$$

总线B首周期可以同时发送地址与首字。

因此：

$$
N_B=1+2=3
$$

$$
R_B=\frac4{30\ \mathrm{ns}}
$$

$$
\boxed{R_B\approx133.33\ \mathrm{MB/s}}
$$

这体现出地址线与数据线分离，在特定事务时序下可以允许部分操作重叠。

#### 第四问：8字块混合读写
每块数据：

$$
D=8\times4=32\ \mathrm B
$$

总线A每周期传2字，数据阶段需要：

$$
8/2=4
$$

完整事务：

$$
N_A=1+2+4=7
$$

因此：

$$
R_A=\frac{32}{7\times10\ \mathrm{ns}}
$$

$$
\boxed{R_A\approx457.14\ \mathrm{MB/s}}
$$

总线B：

读8字：

$$
N_{\text{read}}=1+2+8=11
$$

写8字：

$$
N_{\text{write}}=1+2+7=10
$$

读事务占60%，写事务占40%。

平均事务周期：

$$
\overline N=0.6\times11+0.4\times10
$$

$$
\overline N=10.6
$$

长期平均有效速率：

$$
R_B=\frac{32}{10.6\times10\ \mathrm{ns}}
$$

$$
\boxed{R_B\approx301.89\ \mathrm{MB/s}}
$$

#### 最终结果
| 性能指标    | 总线A         | 总线B         |
| ------- | ----------- | ----------- |
| 理论峰值    | 800 MB/s    | 400 MB/s    |
| 单字读     | 100 MB/s    | 100 MB/s    |
| 单字写     | 100 MB/s    | 133.33 MB/s |
| 8字块混合读写 | 457.14 MB/s | 301.89 MB/s |

本题最重要的技巧：

长期混合事务速率 = 总有效数据量 ÷ 总时间。

不能简单计算：

$$
0.6R_{\text{read}}+0.4R_{\text{write}}
$$

因为读写事务的耗时不同。

应先按照事务比例加权时间，再用总数据量除以总时间。

### 11.2 第5套第44题：DMA周期挪用与CPU性能
这道题非常适合与2020年DMA真题一起学习。

#### 题目条件
- 每条CPU指令使用两个主存总线周期；
- 第一个周期取指；
- 第二个周期进行一次数据访存；
- 总线宽8 bit；
- 每个总线周期250 ns；
- 磁盘每磁道16扇区；
- 每扇区512 B；
- 磁盘旋转一圈8.192 ms；
- DMA每次挪用一个总线周期。

求：

1. 磁盘不工作时主存总线空闲比例；
2. 8位总线时DMA使CPU吞吐下降多少；
3. 16位总线时下降多少。

#### 第一问：主存总线空闲比例
每条CPU指令：

```text
周期1：取指令
周期2：数据访存
```

两个周期都占用主存总线。

因此在题目规定CPU连续执行的模型下：

$$
\boxed{\eta_{\text{idle}}=0\%}
$$

特别注意：

如果另一题规定第二个周期是纯CPU内部执行，不占用主存总线，那么结论可能不同。

一定要以题目给出的访存时序为准。

#### 第二问：8位总线
先计算磁盘数据率。

一磁道数据量：

$$
D=16\times512=8192\ \mathrm B
$$

旋转时间：

$$
T=8.192\times10^{-3}\ \mathrm s
$$

数据率：

$$
R=\frac{8192}{0.008192}
$$

$$
\boxed{R=10^6\ \mathrm{B/s}}
$$

8位总线一次传：

$$
D_{\text{bus}}=1\ \mathrm B
$$

每秒DMA周期数：

$$
N=\frac{10^6}{1}=10^6
$$

每个周期250 ns。

DMA占用的总线时间：

$$
T_{\text{DMA}}=10^6\times250\times10^{-9}
$$

$$
T_{\text{DMA}}=0.25\ \mathrm s
$$

即DMA每秒使用25%的总线周期。

因为本题CPU连续工作且完全依赖这些总线周期：

$$
\boxed{\text{CPU吞吐下降}=25\%}
$$

#### 第三问：改成16位总线
一次DMA传：

$$
D_{\text{bus}}=2\ \mathrm B
$$

每秒DMA周期数：

$$
N=\frac{10^6}{2}=500000
$$

DMA占用时间：

$$
T_{\text{DMA}} =500000\times250\times10^{-9}
$$

$$
T_{\text{DMA}}=0.125\ \mathrm s
$$

所以：

$$
\boxed{\text{CPU吞吐下降}=12.5\%}
$$

#### 最终结果
| 总线宽度 | 每次DMA传输 | DMA占用率 | CPU吞吐下降 |
| ---- | ------- | ------ | ------- |
| 8位   | 1 B     | 25%    | 25%     |
| 16位  | 2 B     | 12.5%  | 12.5%   |

这道题为什么能把DMA总线占用率等同于CPU吞吐下降率？

因为题目明确规定：

- CPU持续执行；
- 每条指令必须占用两个总线周期；
- 原本没有空闲总线周期；
- CPU与DMA不能在同一共享总线周期同时访问；
- 忽略其他开销。

在这些特殊条件下，两者可以建立直接关系。

不能将这个结论推广到所有DMA系统。

## 十二、其他高价值综合考点
### 12.1 串行通信有效数据率
异步串行通信一帧可能包括：

```text
起始位 | 数据位 | 校验位 | 停止位
```

设：

- 起始位 $s$；
- 数据位 $d$；
- 校验位 $p$；
- 停止位 $t$。

总帧长：

$$
\boxed{L=s+d+p+t}
$$

如果线路比特率为 $R_b$ bit/s：

每秒字符率：

$$
\boxed{ N_{\text{char}}=\frac{R_b}{L} }
$$

有效数据比特率：

$$
\boxed{ R_{\text{payload}}=R_b\frac{d}{L} }
$$

#### 例题
每帧：

- 起始位1；
- 数据位8；
- 校验位1；
- 停止位1。

线路速率9600 bit/s。

帧长：

$$
L=1+8+1+1=11
$$

字符率：

$$
N=\frac{9600}{11}
$$

$$
\boxed{N\approx872.73\ \mathrm{字符/s}}
$$

有效比特率：

$$
R_{\text{payload}} =9600\times\frac8{11}
$$

$$
\boxed{R_{\text{payload}}\approx6981.82\ \mathrm{bit/s}}
$$

注意：波特率是每秒码元数。只有每码元携带1 bit时，波特率才直接等于bit/s。

### 12.2 中断合并与最低批量大小
这是对2018年大题很有价值的拓展。

假设：

- CPU主频500 MHz；
- 设备速率40 MB/s；
- 每4 B形成一个数据单位；
- 每次中断处理消耗160周期；
- CPU最多允许80%时间用于处理中断。

如果一次中断处理 $k$ 个数据单位，求最小 $k$。

原始中断次数：

$$
N_0=\frac{40\times10^6}{4}=10^7
$$

合并后：

$$
N_k=\frac{10^7}{k}
$$

CPU占用率：

$$
\eta=\frac{10^7\times160}{k\times500\times10^6}
$$

整理：

$$
\eta=\frac{3.2}{k}
$$

要求：

$$
\frac{3.2}{k}\le0.8
$$

所以：

$$
k\ge4
$$

最少：

$$
\boxed{k_{\min}=4}
$$

即每次中断至少处理：

$$
\boxed{16\ \mathrm B}
$$

但需要注意：

中断合并必须有足够的FIFO或其他缓冲机制。

如果设备只有一个4 B的单缓冲寄存器，不能凭空积累16 B数据。

### 12.3 中断屏蔽字与嵌套综合
王道第3套第44题给出了一个更完整的例子。

5个中断源：

$$
1,2,3,4,5
$$

响应优先级：

$$
1>2>3>4>5
$$

处理优先级：

$$
1>4>5>2>3
$$

屏蔽字顺序为1～5，1表示屏蔽。

要求设计全部中断服务程序的屏蔽字。

#### 解题方法
对于当前中断源：

- 高于当前处理优先级的源：填0；
- 当前中断源自身：填1；
- 低于当前处理优先级的源：填1。

结果：

| 正在处理的源 | 允许打断它的源 | 屏蔽字   |
| ------ | ------- | ----- |
| 1      | 无       | 11111 |
| 2      | 1、4、5   | 01100 |
| 3      | 1、4、5、2 | 00100 |
| 4      | 1       | 01111 |
| 5      | 1、4     | 01101 |

还要理解：

先被响应，不代表先完成处理。

例如中断2和4同时申请，响应优先级2高于4，所以CPU先进入中断2的ISR。

但4的处理优先级高于2。

如果2的ISR允许嵌套且4仍在等待，那么4可以打断2，先完成服务。

这说明：

- 响应优先级决定首次进入顺序；
- 处理优先级决定嵌套抢占关系；
- 最终完成顺序还受到具体中断到达时刻影响。

## 十三、本章必须掌握的公式总表
| 类型      | 公式                                                              | 用途      |
| ------- | --------------------------------------------------------------- | ------- |
| 时钟周期    | $T=1/f$                                                     | 频率与时间换算 |
| 寻址数量    | $N=2^n$                                                     | 地址线计算   |
| 一次数据量   | $D=W/8$                                                     | 位宽转换    |
| 理论带宽    | $B=WfM/8$                                                   | 单通道峰值带宽 |
| 多通道带宽   | $B=CWfM/8$                                                  | 独立通道合计  |
| 有效带宽    | $B_{\mathrm{eff}}=D_{\mathrm{total}}/T_{\mathrm{total}}$ | 完整事务性能  |
| 总线利用率   | $\eta=B_{\mathrm{eff}}/B_{\max}$                          | 效率计算    |
| 非突发时间   | $T=K(a+m+d)/f$                                              | 重复完整访问  |
| 突发时间    | $T=(a+m+Kd)/f$                                              | 共享启动开销  |
| 串行帧长    | $L=s+d+p+t$                                                 | 帧开销     |
| 字符传输率   | $N=R_b/L$                                                   | 串行字符率   |
| 查询最长间隔  | $T_{\max}=D/R$                                             | 防止缓冲覆盖  |
| 中断次数    | $N_{\mathrm{int}}=R/D$                                     | 中断频率    |
| 中断CPU占比 | $\eta_{\mathrm{int}}=RC/(Df)$                              | 中断开销    |
| DMA块数   | $N_{\mathrm{DMA}}=R/B$                                     | DMA频率   |
| DMA管理占比 | $\eta_{\mathrm{DMA}}=RC/(Bf)$                              | CPU管理时间 |
| 数据拍数    | $N_{\mathrm{bus}}=R/D_{\mathrm{bus}}$                     | DMA总线需求 |

使用这些公式时：

- $W$：数据宽度，单位bit；
- $f$：时钟频率，单位Hz；
- $M$：每时钟周期的数据传输次数；
- $C$：视公式上下文表示通道数或CPU周期数；
- $R$：设备传输速率，单位B/s；
- $D$：一次处理或传输的字节数；
- $B$：根据上下文表示带宽或DMA块大小。

考试时一定要写出单位，避免同一个字母代表不同物理量造成混淆。

## 十四、本章最容易失分的知识点
| 错误认识              | 正确结论             |
| ----------------- | ---------------- |
| 数据总线只能传操作数        | 指令、命令字、状态字也可以传   |
| 地址总线决定一次传多少数据     | 地址总线决定地址数量       |
| 控制总线只能单向传输        | 不同控制信号可以有不同方向    |
| CPU永远是主设备         | DMA控制器也可以成为主设备   |
| 一个总线周期等于一个时钟周期    | 总线周期可能包含多个时钟周期   |
| 并行总线一定比串行总线快      | 还取决于频率和协议开销      |
| PCIe ×16表示16位并行总线 | 表示16条串行Lane      |
| 同步总线不能插入等待        | 同步总线可以插入等待周期     |
| 异步握手一次只能传1 bit    | 可以传送整个数据单位       |
| 突发传输不需要地址         | 仍需要首地址           |
| 突发传输一定提高物理峰值      | 主要减少完整事务开销       |
| 地址/数据复用主要提高带宽     | 主要减少引脚和线路        |
| DDR有效传输率还要乘2      | 如果已给MT/s，不能重复乘2  |
| 全双工一定乘2           | 只有双方向合计才相加       |
| MMIO使用专用I/O指令     | 通常使用普通访存指令       |
| I/O端口就是物理USB插口    | 组成原理中的端口指接口寄存器   |
| 中断方式的数据不经过CPU     | 普通中断I/O通常仍由CPU搬运 |
| DMA完全不需要CPU       | CPU仍负责初始化和后处理    |
| DMA一个块只占一个总线周期    | 一个数据块通常包含多次传输    |
| DMA只能用于高速设备       | 低速设备也可以采用，只是未必划算 |
| DMA整个传输期间CPU不能访存  | 取决于总线共享方式        |
| DMA总线利用率就是CPU停顿率  | 两者是不同指标          |
| DMA完成中断表示CPU搬运数据  | 完成中断主要用于通知CPU    |
| 中断屏蔽字决定硬件响应优先级    | 主要控制允许哪些中断嵌套     |
| CPU收到外部中断立即停止当前指令 | 一般在合适的指令边界响应     |
| I/O任务总时间就是CPU工作时间 | CPU和设备可以并行工作     |

其中最值得重点防范的是五个概念对：

1. 时钟周期与总线周期；
2. 峰值带宽与有效带宽；
3. 中断请求与DMA请求；
4. CPU占用率与总线利用率；
5. 整个任务历时与CPU实际忙碌时间。

## 十六、考场上如何快速判断题型？
### 遇到总线题
按以下顺序检查：

第一步：问的是什么？

是理论带宽、实际有效速率、一个事务时间，还是一个数据块的传输时间？

第二步：一次传多少？

由数据宽度确定：

$$
D=\frac W8
$$

第三步：传输频率是多少？

判断是：

- 每时钟周期一次；
- 每时钟周期两次；
- 多周期才完成一次；
- 还是已经给出有效传输率。

第四步：有没有额外开销？

检查：

- 地址周期；
- 等待周期；
- 数据周期；
- 是否突发；
- 是否允许阶段重叠。

第五步：能不能并行？

检查：

- 多通道；
- 全双工；
- 多个独立事务；
- 分离事务；
- 是否串行执行。

最后再代入公式计算。

### 遇到I/O方式题
第一步：数据是谁搬的？

CPU逐次搬：查询或中断。

DMA硬件搬：DMA。

通道执行I/O程序：通道。

第二步：每次处理多少数据？

- 查询看缓冲容量；
- 中断看每次中断的数据量；
- DMA看块大小。

第三步：每秒发生多少次处理事件？

$$
N=\frac{R}{D}
$$

第四步：每次CPU消耗多少周期？

$$
C=I\times CPI+C_0
$$

第五步：计算CPU占用率。

$$
\eta=\frac{NC}{f}
$$

第六步：判断额外约束。

例如：

- 缓冲是否足够；
- 中断是否来得及处理；
- DMA与CPU是否争用总线；
- 设备与CPU是否能够重叠工作。

这套流程可以处理大部分未见过的I/O综合计算题。

## 十七、本章最终知识框架
真正学会本章，需要能够回答以下六个问题。

1\. 总线究竟在解决什么？

解决计算机各部件之间的连接、信息传输和资源共享问题。

2\. 总线带宽由什么决定？

主要由数据宽度、有效传输频率、通道数量以及协议开销决定。

3\. 突发传输为什么能提高效率？

因为不必对每个连续数据单位重复承担完整的寻址和事务启动开销。

4\. 为什么需要I/O接口？

因为CPU和外设在速度、格式、时序与控制方式上存在差异，需要接口进行协调。

5\. 中断与DMA最大的区别是什么？

不是有没有中断，而是谁负责数据搬运。

中断方式通常由CPU执行数据传送指令，DMA方式由DMA控制逻辑组织设备与主存之间的数据传输。

6\. 为什么一道I/O题可能有三个不同的时间或比例？

因为必须区分：

- 整个I/O任务经过的时间；
- CPU实际用于I/O管理的时间；
- 总线或主存被I/O操作占用的时间。

三者一般不相同。

### 建议的复习顺序
第一轮应彻底掌握总线分类、信号方向、同步与异步、仲裁和基本带宽计算。

第二轮集中练习2009、2012、2014、2019、2020、2023和2024年的总线计算真题，重点区分总线事务与数据通路峰值。

第三轮重点完成2009年第43题、2016年第44题、2018年第43题，建立CPU管理开销和设备工作时间两个独立的计算模型。

第四轮再做2027王道第4套总线综合题、第5套DMA周期挪用题，以及第3套中断优先级综合题。

本章最核心的三条公式是：

$$
\boxed{ \text{总线带宽} =\text{每次有效数据量} \times\text{每秒有效传输次数} }
$$

$$
\boxed{ \text{CPU的I/O时间占比} = \frac{\text{每秒I/O事件次数}\times\text{每次CPU周期开销}} {\text{CPU每秒周期数}} }
$$

$$
\boxed{ \text{完整任务时间} =\text{不可重叠阶段构成的关键路径时间} }
$$

前两条解决带宽和占用率，第三条解决最难的时间轴综合题。
