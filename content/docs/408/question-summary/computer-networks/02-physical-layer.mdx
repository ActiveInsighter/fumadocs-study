### 物理层的基本概念

**物理层究竟负责什么？** 物理层是计算机网络体系结构的最底层。 其核心任务：

**在物理连接上透明地传输原始比特流。** 例如发送端要发送： 01011010 物理层需要完成：

1. 将比特转换成电信号、光信号或无线电信号。
2. 让信号经过传输介质。
3. 在接收端识别信号。
4. 将信号恢复成比特序列。

物理层不需要理解这些比特表示什么。 它不知道：哪些比特属于源 MAC 地址；哪些比特属于目的 IP 地址；哪些比特属于 TCP 端口；哪些比特属于 HTTP 数据。 这些属于上层协议的工作。

**什么是透明传输？** 透明传输强调：

**传输机制不要求理解上层数据的具体内容。** 例如：发送端输入 101101。 接收端应恢复 101101。 物理层不需要判断这些比特是文本、图片还是程序。 注意：透明传输不意味着绝对不会发生误码。 实际物理信道仍可能受到噪声、衰减和干扰。

**物理层接口的四大特性** 这是典型的记忆辨析题。

| 特性 | 规定内容 | 判断关键词 |
|---|---|---|
| 机械特性 | 接口形状、尺寸、引脚数量及排列 | 长什么样 |
| 电气特性 | 电压、电平、电流、阻抗等 | 电信号如何表示 |
| 功能特性 | 每根信号线承担的功能 | 负责什么 |
| 过程特性 | 信号出现顺序和通信时序 | 先后顺序 |

**机械特性** 例如：插头形状；插头尺寸；引脚数量；引脚排列方式。 如果问：接口共有多少根引脚？ 属于机械特性。

**电气特性** 例如：高电平的电压范围；低电平的电压范围；信号阻抗；电流参数。 如果问：使用多少伏电压表示某种信号？ 属于电气特性。

**功能特性** 例如：第 1 根线负责发送；第 2 根线负责接收；第 3 根线负责时钟同步。 如果问：某根引脚具体负责什么？ 属于功能特性。

**过程特性** 例如：先发出请求信号；接收端返回允许信号；发送端开始传输。 如果问：通信过程中各信号应按照什么顺序出现？ 属于过程特性。

**【2012 年真题】** 题目：在物理层接口特性中，用于描述完成每种功能的事件发生顺序的是？ A. 机械特性 B. 功能特性 C. 过程特性 D. 电气特性

**答案：C**

解析：题干关键词是：事件发生顺序。 因此属于过程特性。

**【2018 年真题】** 题目：下列选项中，不属于物理层接口规范定义范畴的是？ A. 接口形状 B. 引脚功能 C. 物理地址 D. 信号电平

**答案：C**

解析：接口形状：机械特性；引脚功能：功能特性；信号电平：电气特性；物理地址：通常指 MAC 地址，属于数据链路层。

**易错总结** 机械看外形。 电气看电平。 功能看用途。 过程看时序。

**数据通信基础** **数据与信号的区别** 这是后面理解编码、调制的基础。

**数据 Data** 数据是信息的表示形式。 例如： 01010111 属于数字数据。

**信号 Signal** 信号是数据在传输介质中的具体物理表现。 例如：

- 高低电平
- 光脉冲
- 正弦电磁波
- 不同频率的载波

同一个二进制序列可以通过不同编码方式转换为不同物理信号。 因此：

**数据不等于信号。** **模拟数据与数字数据**

**模拟数据** 数据取值连续。 例如：模拟麦克风输出的连续电压变化。

**数字数据** 数据取值离散。 例如： 0 和 1。

**模拟信号与数字信号** **模拟信号** 信号参数随时间连续变化。 典型例子：正弦载波。

**数字信号** 信号在规定的离散状态之间变化。 例如：高电平与低电平。 注意：数字信号在真实物理系统中也需要一定上升时间，并不意味着实际波形可以无限陡峭。

**数据与信号的四种组合**

| 输入数据 | 输出信号 | 典型技术 |
|---|---|---|
| 数字数据 | 数字信号 | 线路编码 |
| 数字数据 | 模拟信号 | 数字调制 |
| 模拟数据 | 数字信号 | PCM |
| 模拟数据 | 模拟信号 | 模拟调制 |

最需要掌握的是：

1. 数字数据经过线路编码形成数字基带信号。
2. 数字数据经过数字调制形成模拟载波信号。
3. 模拟数据经过采样、量化、编码转换为数字数据。

**信源、信宿与信道** **信源** 产生信息并发送信息的设备。

**信宿** 接收信息的设备。

**信道** 传输信号的通路。 例如：主机 A 通过网线向主机 B 发送数据。 则：主机 A：信源；主机 B：信宿；网线及其对应通信通路：传输环境与信道；网线上的电信号：信号。

**单工、半双工与全双工**

| 通信方式 | 双方能否发送 | 能否同时发送 |
|---|---|---|
| 单工 | 仅一个方向可以发送 | 否 |
| 半双工 | 双方都可以发送 | 否 |
| 全双工 | 双方都可以发送 | 是 |

**单工** 通信方向固定。 例如某些单向广播系统。

**半双工** 双方都能发送，但不能同时发送。 典型理解：对讲机。

**全双工** 双方能够同时发送和接收。 例如现代交换式以太网中的全双工链路。

**重要区别** 双方都能发送，不等于全双工。 只有能够同时双向传输，才是全双工。

**串行与并行传输** **串行传输** 数据位按照时间顺序逐位传输。 例如： 1 → 0 → 1 → 1 → 0 特点：使用较少的信号线路；适合较长距离；易于控制多线之间的时序偏差。

**并行传输** 多个数据位通过多条线路同时传输。 例如 8 根数据线同时发送 8 bit。 特点：可以同时传输多个比特；需要更多线路；高速和长距离条件下容易出现信号线之间的时序偏差、串扰等问题。 不要认为并行传输一定比串行传输快。 实际性能还取决于时钟速率、线路数量和信号完整性。

**基带传输与频带传输** **基带传输** 直接使用适当的基带信号传输数字数据。 例如部分以太网物理层使用的线路编码信号。

**频带传输** 将数字数据调制到载波上，通过某个频率范围进行传输。 例如无线通信中的 PSK、QAM 等。 需要注意： Baseband 与 Broadband 是传输方式及频谱利用方式上的概念，不应简单理解为“低速”和“高速”。

## 信道速率、带宽与容量

### 码元、波特率与比特率

这是整章最基础、最重要的计算关系。 **什么是码元？** 码元 Symbol：

**通信系统能够区分的一个基本信号单元。** 一个码元可以有不同的状态。 例如某个通信系统采用 4 种信号状态：

| 状态 | 对应数据 |
|---|---|
| 状态 A | 00 |
| 状态 B | 01 |
| 状态 C | 10 |
| 状态 D | 11 |

此时：一个码元可以携带 2 bit。 因为： $\log_2 4=2$ 所以：

**一个码元不一定等于一个比特。** **码元状态数与信息量** 设一个码元具有 $M$ 种可区分状态。 在等概使用且每种状态对应固定长度二进制信息的常见考试模型中，每个码元最多携带： $\boxed{k=\log_2 M}$ bit。 常见结果：

| 码元状态数 | 每码元比特数 |
|---|---|
| 2 | 1 |
| 4 | 2 |
| 8 | 3 |
| 16 | 4 |
| 32 | 5 |
| 64 | 6 |
| 128 | 7 |
| 256 | 8 |

这张表建议熟记。 **什么是波特率？** 波特率 Baud Rate：

**每秒传输的码元数量。** 单位： Baud，波特。 记为： $R_s$ 例如：每秒传输 1000 个码元。 则： $R_s=1000\ \mathrm{Baud}$

**什么是比特率？** 比特率 Bit Rate：

**每秒传输的二进制比特数量。** 单位： bit/s。 记为： $R_b$ 例如：每秒传输 8000 bit。 则： $R_b=8000\ \mathrm{bit/s}$

**波特率与比特率的核心公式** 一个码元携带： $\log_2 M$ bit。 每秒传输： $R_s$ 个码元。 所以每秒传输的比特数为： $\boxed{R_b=R_s\log_2 M}$ 三个常见变形：

**求比特率** $R_b=R_s\log_2M$

**求波特率** $\boxed{R_s=\frac{R_b}{\log_2M}}$

**求状态数** $\boxed{M=2^{R_b/R_s}}$

**【2011 年真题】波特率计算** 题目：某通信链路的数据传输速率为 2400 bit/s，采用四相位调制，求波特率。 选项： A. 600 Baud B. 1200 Baud C. 4800 Baud D. 9600 Baud

**第一步：识别码元状态数** 四相位调制： $M=4$ 每个码元携带： $\log_2 4=2$ bit。

**第二步：求波特率** $R_s=\frac{2400}{2}$ 得到： $\boxed{R_s=1200\ \mathrm{Baud}}$

**答案：B** **这道题真正考查什么？** 考查的是：

**不同调制状态能够让一个码元携带多个比特。** 不能直接把 2400 bit/s 当成 2400 Baud。

**变式：反求状态数** 某链路码元速率为 2000 Baud，希望实现 12000 bit/s。 问至少需要多少种信号状态？

**第一步** $R_b=R_s\log_2M$ 代入： $12000=2000\log_2M$

**第二步** $\log_2M=6$

**第三步** $M=2^6$ 所以： $\boxed{M=64}$

**易错提醒** “至少多少种状态”要结合题意判断。 如果只要求整数状态数，可按照数学约束取整。 如果限定必须采用 $2^n$ 阶调制，则要取满足要求的调制阶数。 另外：状态数越多，并不意味着实际传输系统一定能可靠区分这些状态。 噪声会限制可实现的数据率。

**带宽、速率与吞吐量** **为什么带宽有两种含义？** 这是非常容易混淆的概念。

**第一种：频带宽度** 单位： Hz。 表示信道允许通过的频率范围。 例如：信道允许通过的频率范围为 100 kHz 到 105 kHz。 则： $W=105-100$ 得到： $W=5\ \mathrm{kHz}$ 这是奈奎斯特、香农公式中使用的带宽。

**第二种：网络数据传输能力** 单位： bit/s。 例如： 100 Mb/s。 表示链路的数据传输能力。

**Hz 与 bit/s 的区别**

| 单位 | 表示什么 |
|---|---|
| Hz | 频率或频带宽度 |
| Baud | 每秒传输的码元数量 |
| bit/s | 每秒传输的比特数量 |
| Byte/s | 每秒传输的字节数量 |

不能直接认为： 1 Hz = 1 bit/s。 两者之间需要考虑信道模型与调制方式。

**常见单位转换** 网络速率通常采用十进制前缀： $1\ \mathrm{kb/s}=10^3\ \mathrm{bit/s}$ $1\ \mathrm{Mb/s}=10^6\ \mathrm{bit/s}$ $1\ \mathrm{Gb/s}=10^9\ \mathrm{bit/s}$ 并且： $1\ \mathrm{Byte}=8\ \mathrm{bit}$ 因此：

$$
100\ \mathrm{Mb/s}
=
12.5\ \mathrm{MB/s}
$$

注意：这是单位换算，不代表实际应用一定能达到 12.5 MB/s 的有效传输速度。 还需要考虑各种协议开销。

**吞吐量** 吞吐量：单位时间内实际成功传输的数据量。 例如：链路标称速率为 100 Mb/s。 但由于拥塞、协议开销、设备限制等因素，实际吞吐量可能只有 60 Mb/s。

**吞吐量与链路速率的关系** 实际吞吐量一般不超过相关资源所允许的传输上界。 对于单一路径串联链路，忽略其他限制时： $\boxed{R_{\mathrm{throughput}}\le\min(R_1,R_2,\ldots,R_n)}$ 也就是：

**串联链路的端到端吞吐量受到最慢链路限制。** **【2014 年真题】** 下列因素中，不会影响信道数据传输速率的是： A. 信噪比 B. 频率带宽 C. 调制速率 D. 信号传播速度

**答案：D** **原因** 信号传播速度主要影响： $T_p=\frac{d}{v}$ 即传播时延。 它不会直接决定每秒能够传输多少比特。 需要区分：

- 数据传输速率：每秒发送多少比特。
- 信号传播速度：信号在介质中每秒前进多少距离。

### 奈奎斯特定理

本章第一大计算重点。 **奈奎斯特定理解决什么问题？** 考虑一个理想无噪声低通信道。 虽然没有噪声，但信道带宽有限。 因此码元变化速度不能无限增大。 在 408 常用的理想低通信道模型中： $\boxed{R_{s,\max}=2W}$ 其中：

- $W$：信道频带宽度，Hz。
- $R_{s,\max}$：最大码元速率，Baud。

注意其适用条件： **理想、带宽受限、低通信道模型。** 不能把该公式不加区分地应用到所有实际带通信道或无线系统中。

**推导最高数据率** 已知一个码元携带： $\log_2M$ bit。 最高码元速率： $R_{s,\max}=2W$ 因此： $C_N=R_{s,\max}\log_2M$ 得到： $\boxed{C_N=2W\log_2M}$ 这就是考研中常用的奈奎斯特最高数据率公式。

**各变量含义**

| 符号 | 含义 | 单位 |
|---|---|---|
| $C_N$ | 最大数据率 | bit/s |
| $W$ | 频带宽度 | Hz |
| $M$ | 码元状态数 | 无量纲 |

**奈奎斯特定理的三个结论** **结论一：带宽越大，最高数据率越高** 如果 $M$ 不变： $C_N\propto W$ 带宽增加一倍：最高数据率增加一倍。

**结论二：码元状态数越多，每码元携带的比特越多** 例如： 16 种状态： $\log_2 16=4$ 64 种状态： $\log_2 64=6$ 在相同码元速率下，64 元调制能够携带更多比特。

**结论三：增加状态数存在实际限制** 虽然数学公式中可以不断增加 $M$，但是：状态数越多，信号状态之间的差异通常越小。 在噪声存在的情况下，接收端更容易判决错误。 因此还必须考虑香农定理。

**【2009 年真题】QAM 与奈奎斯特** 题目：某无噪声链路带宽为 3 kHz，使用 4 个相位，每个相位具有 4 种振幅的 QAM 调制。 求最大数据传输速率。 选项： A. 12 kb/s B. 24 kb/s C. 48 kb/s D. 96 kb/s

**第一步：计算码元状态数** 4 个相位。 每个相位对应 4 种振幅。 所以： $M=4\times4$ $M=16$

**第二步：计算每码元比特数** $\log_2 16=4$

**第三步：套奈奎斯特公式** $C_N=2W\log_2M$ 代入： $C_N=2\times3000\times4$ 得到： $\boxed{C_N=24000\ \mathrm{bit/s}}$ 即： $\boxed{24\ \mathrm{kb/s}}$

**答案：B** **本题的关键** 看到： 4 个相位，每相位 4 种振幅。 必须先计算： $M=4\times4$ 而不是把 $M$ 当成 4。

**【2022 年真题】ASK 与奈奎斯特** 题目：无噪声信道带宽为 200 kHz，采用 4 个幅值的 ASK 调制。 求最大数据传输速率。

**第一步** $M=4$

**第二步** $\log_2M=2$

**第三步** $C_N=2\times200000\times2$ 得到： $\boxed{C_N=800\ \mathrm{kb/s}}$

**答案：C** **【2023 年真题】反求 QAM 阶数** 题目：某无噪声理想信道带宽为 4 MHz，采用 QAM 调制。 已知最高数据传输速率为 48 Mb/s。 问采用哪种 QAM？ 选项： A. QAM-16 B. QAM-32 C. QAM-64 D. QAM-128

**第一步：写公式** $C_N=2W\log_2M$

**第二步：代入**

$$
48\times10^6
=
2\times4\times10^6\log_2M
$$

**第三步：整理** $\log_2M=6$ 因此： $M=2^6=64$

**答案：C，QAM-64。** **解题模板** 若已知：信道带宽；目标数据率；求调制状态数。 直接使用： $\boxed{M=2^{C/(2W)}}$ 如果题目问至少需要多少种状态，则用不等式并检查允许的调制阶数。

### 香农定理

本章第二大计算重点。 **为什么需要香农定理？** 奈奎斯特定理主要讨论：带宽受限的理想无噪声信道。 但现实中存在：

- 热噪声
- 电磁干扰
- 信号衰减
- 各种随机干扰

即使不断增加调制阶数，接收端也不能无限可靠地区分信号。 香农定理考虑噪声对信道容量的限制。 对于常见的加性高斯白噪声信道模型： $\boxed{C_S=W\log_2\left(1+\frac{S}{N}\right)}$ 其中： $C_S$：香农容量；$W$：信道带宽；$S$：平均信号功率；$N$：平均噪声功率；$S/N$：线性信噪比。

**什么是信噪比？** 信噪比： $\mathrm{SNR}=\frac{S}{N}$ 表示信号功率与噪声功率的比值。 例如：信号功率为 100 W。 噪声功率为 1 W。 则： $\frac{S}{N}=100$ 信噪比越大，意味着相对于噪声，信号越强。 在香农模型中，信噪比越大，信道容量越高。

**为什么信噪比要用 dB？** 工程中经常使用分贝表示功率比。 公式： $\boxed{\mathrm{SNR}_{\mathrm{dB}}=10\log_{10}\left(\frac{S}{N}\right)}$ 反推： $\boxed{\frac{S}{N}=10^{\mathrm{SNR}_{\mathrm{dB}}/10}}$

**常见换算**

| dB | 线性信噪比 |
|---|---|
| 0 dB | 1 |
| 10 dB | 10 |
| 20 dB | 100 |
| 30 dB | 1000 |
| 40 dB | 10000 |

这张表建议熟记。 **最常见错误** 已知： 30 dB。 不能直接把 30 代入香农公式。 必须先计算： $\frac{S}{N}=10^{30/10}=1000$

**【2016 年真题】香农容量计算** 题目：某链路带宽为 8 kHz，信噪比为 30 dB。 实际数据率为理论最大数据率的 50%。 问实际速率约为多少？ 选项： A. 8 kb/s B. 20 kb/s C. 40 kb/s D. 80 kb/s

**第一步：dB 转线性值** $\frac{S}{N}=10^{30/10}$ 得到： $\frac{S}{N}=1000$

**第二步：香农公式** $C_S=8000\log_2(1001)$ 由于： $\log_2(1001)\approx9.967$ 所以： $C_S\approx79736\ \mathrm{bit/s}$ 约为： $C_S\approx80\ \mathrm{kb/s}$

**第三步：实际速率** 实际为理论最大值的 50%。 因此： $R\approx80\times0.5$ 得到： $\boxed{R\approx40\ \mathrm{kb/s}}$

**答案：C** **本题最容易犯的错误** 第一种：直接把 30 代入香农公式。 第二种：求出 80 kb/s 后直接选 D。 忽略题目要求：实际速率只有理论最大值的 50%。

**香农定理的物理意义** **结论一：带宽增加可以提高容量** 在信噪比不变的模型下： $C_S\propto W$ 带宽增大一倍，容量增大一倍。

**结论二：信噪比增加也可以提高容量** 但是信噪比在对数函数内部。 因此信噪比增加并不意味着容量按相同比例增加。 例如：信噪比从 100 增加到 1000。 增加了 10 倍。 但： $\log_2(101)\approx6.658$ $\log_2(1001)\approx9.967$ 容量只从约： $6.658W$ 增加到： $9.967W$ 并没有增加 10 倍。

**结论三：香农容量是理论极限** 当： $R<C_S$ 时，在相应信道模型及编码理论条件下，存在足够好的编码方案，使错误概率可以任意接近零。 但不能理解为：任何简单编码只要速率低于容量就绝对不会出错。 也不能理解为：任意有限长度的码字都能够保证绝对零错误。

### 奈奎斯特与香农联合计算

这部分是整章最值得彻底掌握的综合计算题型。 **两个公式的区别**

| 项目 | 奈奎斯特 | 香农 |
|---|---|---|
| 关注 | 带宽和码元状态 | 带宽和噪声 |
| 典型模型 | 理想无噪声低通信道 | 有噪声信道 |
| 带宽 | 需要 | 需要 |
| 状态数 $M$ | 需要 | 公式中不需要 |
| 信噪比 | 不需要 | 需要 |
| 结果 | 数据率上限 | 信道容量上限 |

在 408 常见简化模型中，如果题目同时给出了：信道带宽 $W$；调制状态数 $M$；信噪比 $S/N$。 需要同时检查两种限制。 $C_N=2W\log_2M$ $C_S=W\log_2(1+S/N)$ 因此： $\boxed{R_b\le\min(C_N,C_S)}$ 注意：这是给定调制状态数、理想低通码元速率限制以及香农容量共同形成的理论上界。 它不表示某个现实调制编码系统一定能达到这个上界。

**【2017 年真题】联合约束反求状态数** 题目：某信道在无噪声情况下的极限数据传输速率不小于信噪比为 30 dB 时的香农极限。 问信号状态数至少是多少？ 选项： A. 4 B. 8 C. 16 D. 32

**第一步：奈奎斯特** $C_N=2W\log_2M$

**第二步：香农** 30 dB 对应： $S/N=1000$ 因此： $C_S=W\log_2(1001)$

**第三步：建立不等式** 题目要求： $C_N\ge C_S$ 所以： $2W\log_2M\ge W\log_2(1001)$ 消去 $W$： $2\log_2M\ge\log_2(1001)$ 整理： $\log_2M\ge\frac{\log_2(1001)}{2}$ 于是： $M\ge\sqrt{1001}$ 因为： $\sqrt{1001}\approx31.64$ 所以最小整数状态数为： $\boxed{M=32}$

**答案：D** **这道题的重要价值** 它说明：增加调制状态数，能够提高奈奎斯特数据率上限。 但如果该上限已经高于香农容量，再增加调制状态数也不能突破香农极限。

**模拟题：反求最大码元速率** 题目：某信道带宽为 10 kHz。 信噪比为 30 dB。 使用 64 个幅值的 ASK 调制。 求极限码元速率。

**第一步：每码元比特数** $\log_2 64=6$

**第二步：奈奎斯特码元速率** $R_{s,N}=2W$ $R_{s,N}=20\ \mathrm{kBaud}$

**第三步：香农容量** $C_S=10000\log_2(1001)$ 得到： $C_S\approx99.67\ \mathrm{kb/s}$

**第四步：转换成码元速率** $R_{s,S}=\frac{C_S}{6}$ $R_{s,S}\approx16.61\ \mathrm{kBaud}$

**第五步：取更严格的限制** $R_s\le\min(20,16.61)$ 得到： $\boxed{R_s\lesssim16.61\ \mathrm{kBaud}}$ 站内模拟题选项给出的最接近答案为： 16.67 kBaud。 它来自将： $\log_2(1001)$ 粗略近似为 10。

**解题启示** 遇到联合约束：

1. 先把 dB 转为线性信噪比。
2. 计算奈奎斯特数据率。
3. 计算香农容量。
4. 取更小的数据率上界。
5. 如果问码元速率，再除以每码元比特数。

**综合变式：先判断是否可能实现** 某信道： $W=1\ \mathrm{MHz}$ $\mathrm{SNR}=20\ \mathrm{dB}$ 要求传输： $R=10\ \mathrm{Mb/s}$ 问：是否能够仅通过提高调制阶数达到目标？

**第一步：香农容量** 20 dB： $S/N=100$ 所以： $C_S=10^6\log_2(101)$ 得到： $C_S\approx6.658\ \mathrm{Mb/s}$

**第二步：判断** 目标： $10\ \mathrm{Mb/s}$ 但容量： $6.658\ \mathrm{Mb/s}$ 所以： $R>C_S$ 结论：

**不能。** 在给定信道模型和信噪比条件下，无论增加多少码元状态，都无法可靠地突破香农容量。 这是非常重要的判断题思路。

## 线路编码、调制与复用

### 数字基带编码

**编码的本质** 编码：将数字数据映射成能够在物理介质中传输的数字基带信号。 要重点研究：

1. 用绝对电平还是电平变化表示数据？
2. 是否需要码元中点跳变？
3. 是否容易恢复时钟？
4. 连续相同比特会不会产生同步问题？

**NRZ：不归零编码** NRZ： Non-Return-to-Zero。 典型规则：

- 1：高电平
- 0：低电平

在一个比特周期内，电平通常保持不变。 例如：数据： 001110 若采用高电平表示 1、低电平表示 0：电平序列：低、低、高、高、高、低。

**优点** 编码简单。 同一比特周期内不要求归零。

**缺点** 如果数据长期不变： 00000000 或者： 11111111 信号可能长时间没有跳变。 接收端难以从数据波形中恢复时钟。

**NRZI：反向不归零编码** NRZI： Non-Return-to-Zero Inverted。 其核心：

**通过是否发生电平跳变表示比特。** 本章内容采用以下约定：

- 0：发生跳变
- 1：不发生跳变

注意：不同协议或教材可能采用其他映射。

**示例** 初始电平：低。 数据： 0101 按照： 0 跳变，1 不跳变。 逐位分析：第 1 位是 0：低变高。 第 2 位是 1：保持高。 第 3 位是 0：高变低。 第 4 位是 1：保持低。 因此电平序列：高、高、低、低。

**本质区别** NRZ 看：绝对电平。 NRZI 看：电平是否变化。

**RZ：归零编码** RZ： Return-to-Zero。 典型特点：

**码元周期内会回到零电平或某个基准状态。** 例如：某个比特前半段为高电平。 后半段回到零电平。 这种变化能够提供更多时序信息。

**优点** 容易辅助时钟同步。

**缺点** 信号变化较频繁。 通常需要较多频谱资源。

**曼彻斯特编码** Manchester Encoding。 最重要特征： $\boxed{\text{每个比特周期中点必有一次跳变}}$ 这个跳变能够帮助接收端恢复时钟。

**一种常见编码约定**

- 0：中点从低电平跳到高电平。
- 1：中点从高电平跳到低电平。

<Callout type="warn" title="曼彻斯特编码的电平约定">

**曼彻斯特编码在不同标准及教材中存在不同的 0/1 映射方向。** 考试应优先根据题目给定的约定或明确指定的标准判断，不能只背某一个高低方向。

</Callout>

**示例** 按照上述约定，编码： 0110 逐位分析：第 1 位：0 低 → 高。 第 2 位：1 高 → 低。 第 3 位：1 高 → 低。 第 4 位：0 低 → 高。

**为什么能够同步？** 因为每个比特中点都必须发生跳变。 接收端可以利用这些周期性变化提取时钟信息。

**代价是什么？** 需要更多信号变化。 相比简单 NRZ，通常具有更高的频带开销。

**一个容易误解的问题** 资料有时说：曼彻斯特编码波特率是比特率的两倍。 这通常是把每个比特划分为两个半比特信号元素的教材模型。 如果题目单独问：每秒实际发生多少次电平跳变？ 则需要根据具体数据序列计算。 不能机械把实际跳变次数等同于两倍比特数。

**差分曼彻斯特编码** Differential Manchester Encoding。 核心特征：

1. 每个比特周期中间必跳变。
2. 比特开始位置是否跳变用于表示数据。

本章内容采用：

- 开始处跳变：0
- 开始处不跳变：1

**为什么叫差分？** 因为它不依赖某个时刻的绝对高低电平。 而依赖相邻信号状态之间的变化关系。

**与普通曼彻斯特的本质区别**

| 编码方式 | 中点跳变 | 如何判断数据 |
|---|---|---|
| 曼彻斯特 | 必须发生 | 看中点跳变方向 |
| 差分曼彻斯特 | 必须发生 | 看比特开始处是否跳变 |

**最重要的口诀** **普通曼彻斯特看中间。**

**差分曼彻斯特看开头。** **【2021 年真题】差分曼彻斯特解码** 站内真题提供一段差分曼彻斯特编码波形。 按题图对应约定：

- 起始跳变表示 0。
- 起始不跳变表示 1。

逐位观察码元开始位置。 站内解析得到： $\boxed{10111001}$ 对应：

**答案 A。** **为什么第一位容易错？** 因为差分曼彻斯特需要比较：当前比特开始处与前一状态之间是否发生跳变。 如果波形只截取了数据内部的一段，没有给出首个比特之前的电平或起始边界信息，第一位可能无法唯一确定。 因此：解图题必须检查初始条件。

**标准解题流程**

1. 标出所有码元边界。
2. 标出所有码元中点。
3. 确认中点是否必定跳变。
4. 根据题目约定判断开头是否跳变。
5. 逐位记录 0/1。
6. 检查第一个比特是否有足够的初始信息。

**【2015 年真题】识别编码方式** 站内真题给出：比特流： 01100111。 并展示两种编码波形。 题目要求判断两种编码方式。 站内解析指出：编码 1：每个比特周期的电平对应绝对高低状态。 所以是 NRZ。 编码 2：每个比特周期中点发生跳变。 所以是曼彻斯特。

**答案：A，NRZ 和曼彻斯特。** **识别方法** 先看：是否码元中点必跳变？ 如果是：优先考虑曼彻斯特或差分曼彻斯特。 如果不是：再判断：是按绝对电平表示数据，还是按是否跳变表示数据。

**模拟题：曼彻斯特与差分曼彻斯特综合** 站内模拟题给出相应波形，要求识别两个比特串。 根据题目采用的映射约定：普通曼彻斯特： 01111110。 差分曼彻斯特： 11000001。

**答案：C。** **为什么两种编码会得出不同数据？** 因为判别数据的位置不同：普通曼彻斯特：看中点跳变方向。 差分曼彻斯特：看码元起始边界是否跳变。 虽然二者都在中点跳变，但代表信息的规则并不一样。

**五种编码总结**

| 编码 | 主要依据 | 是否中点必跳变 | 同步特点 |
|---|---|---|---|
| NRZ | 绝对电平 | 否 | 长串相同比特同步较困难 |
| NRZI | 是否跳变 | 否 | 取决于比特模式 |
| RZ | 周期内归零 | 不一定 | 具有更多时序变化 |
| 曼彻斯特 | 中点跳变方向 | 是 | 自同步能力强 |
| 差分曼彻斯特 | 起始处是否跳变 | 是 | 自同步能力强 |

### 数字调制

**调制到底改变什么？** 一个简单的正弦载波可以写为： $s(t)=A\cos(2\pi ft+\varphi)$ 其中： $A$：振幅；$f$：频率；$\varphi$：初始相位。 数字调制就是：通过改变载波参数表示不同数字数据。

**ASK：幅移键控** ASK： Amplitude Shift Keying。 改变： $A$ 即振幅。 例如： 0 对应低振幅。 1 对应高振幅。 也可以使用多个不同幅值状态。

**记忆** ASK： Amplitude。 看振幅。

**FSK：频移键控** FSK： Frequency Shift Keying。 改变： $f$ 即频率。 例如二进制 FSK：

- 0：频率 $f_1$
- 1：频率 $f_2$

**【2024 年真题】** 题目：下列二进制数字调制方法中，需要两个不同频率载波的是？ A. ASK B. PSK C. FSK D. DPSK

**答案：C** 因为 FSK 通过不同频率表示数据。

**PSK：相移键控** PSK： Phase Shift Keying。 改变： $\varphi$ 即相位。

**BPSK** 有 2 个相位状态。 $M=2$ 每码元： $\log_2 2=1$ bit。

**QPSK** 有 4 个相位状态。 $M=4$ 每码元： $\log_2 4=2$ bit。

**8-PSK** 有 8 个相位状态。 每码元： $\log_2 8=3$ bit。

**DPSK：差分相移键控** DPSK： Differential Phase Shift Keying。 通过：

**相邻码元之间的相位变化关系** 表示数字数据。 与普通 PSK 相比： DPSK 更强调相对相位变化，而不是绝对相位状态。

**QAM：正交振幅调制** QAM： Quadrature Amplitude Modulation。 通常利用相互正交的两个载波分量，形成具有不同振幅、相位的信号状态。 最重要的考试结论：如果采用 $M$-QAM，则每个码元可以表示： $\log_2M$ bit。

**常见 QAM**

| 调制方式 | 状态数 | 每码元比特数 |
|---|---|---|
| 4-QAM | 4 | 2 |
| 16-QAM | 16 | 4 |
| 32-QAM | 32 | 5 |
| 64-QAM | 64 | 6 |
| 128-QAM | 128 | 7 |
| 256-QAM | 256 | 8 |

**QAM 的重要理解** 16-QAM：每码元携带 4 bit。 64-QAM：每码元携带 6 bit。 256-QAM：每码元携带 8 bit。 状态数越多，同样码元速率下比特率越高。 但状态密度增加会提高接收端的判决难度。

**ASK、FSK、PSK、QAM 总表**

| 调制方式 | 改变的参数 | 关键词 |
|---|---|---|
| ASK | 振幅 | 幅值变化 |
| FSK | 频率 | 频率变化 |
| PSK | 相位 | 相位变化 |
| DPSK | 相邻相位差 | 相位变化关系 |
| QAM | 正交分量，形成振幅与相位变化 | 多维信号状态 |

记忆： ASK 看幅值。 FSK 看频率。 PSK 看相位。 QAM 看组合状态。

### PCM 脉冲编码调制

**PCM 是什么？** PCM： Pulse Code Modulation。 用于把模拟信号转换成数字数据。 典型步骤： $\boxed{\text{采样}\rightarrow\text{量化}\rightarrow\text{编码}}$

**采样** 采样：在连续时间信号上按照固定时间间隔取得样本。 对于最高频率为 $f_{\max}$ 的理想带限信号，常用采样定理条件为： $\boxed{f_s\ge2f_{\max}}$ 其中： $f_s$ 是采样频率。 例如：最高频率为 4 kHz。 最低理论采样频率： $f_s=2\times4$ $\boxed{f_s=8\ \mathrm{kHz}}$ 注意：这里的奈奎斯特采样定理与信道最大码元速率定理属于不同问题。 不能混用公式。

**量化** 量化：把连续幅度值映射到有限个离散等级。 例如： 256 个量化等级。 那么每个样本需要： $\log_2 256=8$ bit。

**编码** 将量化结果转换成二进制数据。 如果：

- 每秒采样 $f_s$ 次。
- 每个样本编码 $n$ bit。

那么 PCM 数据率： $\boxed{R_{\mathrm{PCM}}=f_sn}$ 如果量化等级为 $Q$，使用固定长度二进制编码： $n=\lceil\log_2Q\rceil$

**典型例题：PCM 语音速率** 某语音系统：采样率： $f_s=8000\ \mathrm{Hz}$ 量化等级： $Q=256$ 求 PCM 数据率。

**第一步：每样本比特数** $n=\log_2 256$ $n=8$

**第二步：数据率** $R=8000\times8$ 得到： $\boxed{R=64000\ \mathrm{bit/s}}$ 即： $\boxed{64\ \mathrm{kb/s}}$ 注意：这是原始 PCM 编码的数据率。 如果添加额外协议首部、纠错冗余等，实际传输所需的数据率可能更高。

### 信道复用技术

**为什么需要复用？** 假设一条物理链路具有较高的数据传输能力。 多个用户都需要使用它。 如果每个用户独占整条链路，会造成资源浪费。 因此需要：

**通过不同方式让多个用户共享同一传输系统。** **频分复用 FDM** Frequency Division Multiplexing。 将总频带划分为多个子频带。 用户 A 使用频段 1。 用户 B 使用频段 2。 用户 C 使用频段 3。 不同用户能够同时传输。

**特征** 不同频率资源。 同一时间传输。 通常需要考虑保护频带。

**时分复用 TDM** Time Division Multiplexing。 通过不同时间片区分用户。 例如：时间片顺序： A、B、C、A、B、C、A、B、C。 同一物理信道在不同时间片服务不同用户。

**同步时分复用** 每个用户使用固定时隙。 缺点：某用户无数据时，其时隙可能浪费。

**统计时分复用** 根据用户实际需求动态分配发送机会。 优点：适合突发式业务。 能够提高资源利用率。 代价：需要调度和标识机制。

**波分复用 WDM** Wavelength Division Multiplexing。 主要用于光纤通信。 通过不同光波长区分通信通道。 可理解为光纤通信中的一种频分复用思想。

**区别** FDM：按频率划分。 WDM：通常按光波长划分。 二者具有密切联系。

**码分多址 CDMA** Code Division Multiple Access。 核心思想：

**不同用户采用不同码片序列，通过相关运算区分信号。** 多个用户可以在同一时间、同一频带上传输。 在 408 常见的理想同步正交模型中：不同用户的码片序列两两正交。

**CDMA 正交码原理** 假设用户 A、B 的码片序列为： $A=(1,1,1,1)$ $B=(1,1,-1,-1)$ 求内积：

$$
A\cdot B
=
1+1-1-1
$$

所以： $\boxed{A\cdot B=0}$ 表示：两组码片正交。 再计算： $A\cdot A=4$ $B\cdot B=4$ 因此：同一个用户的码片与自身相关性强。 不同正交用户之间的相关性为零。 利用这个特点，可以在接收端分离用户信号。

**CDMA 解码公式** 设接收到的混合码片序列为： $S$ 用户 $i$ 的码片为： $C_i$ 码片长度为： $m$ 则： $\boxed{r_i=\frac{S\cdot C_i}{m}}$ 在理想的等幅、同步、正交模型中： $r_i=1$：该用户发送 1；$r_i=-1$：该用户发送 0；$r_i=0$：该用户未发送。 注意：这是题设采用特定二进制映射时的判定规则。

**CDMA 综合例题** 假设四个用户： $A=(1,1,1,1)$ $B=(1,1,-1,-1)$ $C=(1,-1,1,-1)$ $D=(1,-1,-1,1)$ 它们两两正交。 现在： A 发送 1；B 发送 0；C 不发送；D 发送 1。 按照前面的编码约定：发送 1 对应正码片。 发送 0 对应负码片。 所以接收序列： $S=A-B+D$ 计算得： $S=(1,-1,1,3)$ 现在假设接收端只知道 $S$，不知道各用户发送内容。

**判断 A** $r_A=\frac{S\cdot A}{4}$ $r_A=\frac{1-1+1+3}{4}$ $r_A=1$ 所以 A 发送 1。

**判断 B** $r_B=\frac{S\cdot B}{4}$ $r_B=\frac{1-1-1-3}{4}$ $r_B=-1$ 所以 B 发送 0。

**判断 C** $r_C=\frac{S\cdot C}{4}$ $r_C=\frac{1+1+1-3}{4}$ $r_C=0$ 所以 C 未发送。

**判断 D** $r_D=\frac{S\cdot D}{4}$ $r_D=\frac{1+1-1+3}{4}$ $r_D=1$ 所以 D 发送 1。 最终： $\boxed{A=1,\quad B=0,\quad C=\text{未发送},\quad D=1}$

**CDMA 做题方法** 第一步：确认码片长度。 第二步：确认各用户码片序列是否正交。 第三步：对接收序列与每个用户码片求内积。 第四步：除以码片长度。 第五步：根据结果判断数据。

**站内模拟题勘误** 题目中有一道四站 CDMA 模拟题，当前题面只提供了三个站点的码片序列，并且部分码片与标准正交条件不一致。 因此无法依据现有条件唯一确定全部站点数据。 不能强行套用原卷选项。 正式做题时，应先核对题目条件是否完整。

## 时延、交换与流水线

### 网络中的四种时延

这是后续分组交换计算的基础。 **四种时延** 网络中的典型结点时延包括：

1. 发送时延
2. 传播时延
3. 处理时延
4. 排队时延

总时延：

$$
\boxed{
T=T_{\mathrm{send}}+T_{\mathrm{prop}}+
T_{\mathrm{proc}}+T_{\mathrm{queue}}
}
$$

**发送时延** 发送时延：

**发送设备将整个分组的所有比特推入链路所需的时间。** 公式： $\boxed{T_{\mathrm{send}}=\frac{L}{R}}$ 其中：

- $L$：分组长度，bit。
- $R$：链路发送速率，bit/s。

**示例** 分组长度： $L=1000\ \mathrm{B}$ 链路速率： $R=100\ \mathrm{Mb/s}$ 先换算： $L=8000\ \mathrm{bit}$ 所以： $T_{\mathrm{send}}=\frac{8000}{100\times10^6}$ 得到： $\boxed{T_{\mathrm{send}}=80\ \mu s}$ 即： $0.08\ \mathrm{ms}$

**传播时延** 传播时延：

**信号从链路一端传播到另一端所需要的时间。** 公式： $\boxed{T_{\mathrm{prop}}=\frac{d}{v}}$ 其中：

- $d$：传播距离。
- $v$：信号在介质中的传播速度。

**示例** 链路长度： $d=2000\ \mathrm{km}$ 传播速度： $v=2\times10^8\ \mathrm{m/s}$ 先换算： $d=2\times10^6\ \mathrm{m}$ 所以： $T_{\mathrm{prop}}=\frac{2\times10^6}{2\times10^8}$ 得到： $\boxed{T_{\mathrm{prop}}=0.01\ \mathrm{s}}$ 即： $\boxed{10\ \mathrm{ms}}$

**发送时延与传播时延的本质区别** 可以用水管理解。 发送时延：把一定体积的水送入管道需要多久。 传播时延：水流中的某个扰动沿管道传播到另一端需要多久。 这两件事可以同时发生。

**对比**

| 情况 | 发送时延 | 传播时延 |
|---|---|---|
| 数据量增加 | 增加 | 不变 |
| 链路发送速率增加 | 减少 | 不变 |
| 距离增加 | 不变 | 增加 |
| 信号传播速度增加 | 不变 | 减少 |

**特别重要** 一个分组发送完成时：不代表它已经到达接收端。 如果信号传播时延很大，最后一个比特仍需要继续传播。

**处理时延** 例如路由器：检查分组首部；查找路由表；执行差错检查；进行转发处理。 所消耗的时间。

**排队时延** 如果输出链路正在发送其他分组，新分组需要等待。 这部分时间就是排队时延。 特点：与链路负载密切相关；通常变化较大；网络拥塞时可能明显增加。

**综合例题** 一个分组：长度 1500 B。 链路速率 10 Mb/s。 距离 1000 km。 传播速度： $2\times10^8\ \mathrm{m/s}$ 处理时延 0.2 ms。 排队时延 0.5 ms。 求总时延。

**发送时延** $T_s=\frac{1500\times8}{10\times10^6}$ $T_s=1.2\ \mathrm{ms}$

**传播时延** $T_p=\frac{10^6}{2\times10^8}$ $T_p=5\ \mathrm{ms}$

**总时延** $T=1.2+5+0.2+0.5$ 得到： $\boxed{T=6.9\ \mathrm{ms}}$

**时延带宽积 BDP** **BDP 是什么？** BDP： Bandwidth-Delay Product。 对于一条单向链路： $\boxed{\mathrm{BDP}=R T_{\mathrm{prop}}}$ 单位： bit。 其含义：

**链路持续满速发送时，在一个单向传播时延内注入链路的数据量。** 可以理解为：传播过程中能够同时存在多少比特。

**示例** 链路速率： $R=100\ \mathrm{Mb/s}$ 单向传播时延： $T_p=10\ \mathrm{ms}$ 那么： $\mathrm{BDP}=100\times10^6\times0.01$ 得到： $\boxed{\mathrm{BDP}=10^6\ \mathrm{bit}}$ 即： $1\ \mathrm{Mbit}$ 或者： $125000\ \mathrm{B}$

**为什么单位是 bit？** 因为：

$$
\frac{\mathrm{bit}}{\mathrm{s}}\times\mathrm{s}
=
\mathrm{bit}
$$

**单向传播与 RTT 的区别** 单向传播时延： $T_p$ 往返时延 RTT：从发送方到接收方再返回发送方的总时间。 如果路径对称，且忽略其他时延： $RTT\approx2T_p$ 注意： BDP 在不同上下文中可能使用不同的时间尺度。 如果讨论单向链路内的在途比特：使用单向传播时延。 如果讨论 TCP 未确认数据量：通常考虑端到端 RTT。 不能机械混用。

**反求传播时延** 如果已知： $\mathrm{BDP}=1000\ \mathrm{bit}$ $R=100\ \mathrm{Mb/s}$ 那么： $T_p=\frac{\mathrm{BDP}}{R}$ $T_p=\frac{1000}{100\times10^6}$ 得到： $\boxed{T_p=10\ \mu s}$ 这是 2023 年分组流水线真题的重要步骤。

**电路交换、报文交换与分组交换** **三种交换方式的根本区别**

**电路交换** 先建立端到端电路，再传输数据。

**报文交换** 以完整报文为单位存储转发。

**分组交换** 将报文分成多个分组，逐分组存储转发。

**电路交换** 典型过程：

1. 建立连接
2. 传输数据
3. 释放连接

**优点** 连接建立后可以连续传输；传输资源相对稳定；传输时延比较可预测；适合持续通信。

**缺点** 建立连接需要时间；空闲时预留资源可能浪费；对突发业务资源利用率较低。

**时延公式** 如果建立时间为： $T_{\mathrm{setup}}$ 数据量： $L$ 电路速率： $R$ 端到端传播时延： $T_p$ 则：

$$
\boxed{
T=T_{\mathrm{setup}}+\frac{L}{R}+T_p
}
$$

这里假设电路建立后可按速率 $R$ 连续发送，并忽略其他开销。 **为什么不能乘链路数量？** 因为电路建立后：后续比特能够连续经过各段链路。 不需要每个中间结点先接收完整报文再发送。

**报文交换** 报文交换：中间结点必须接收完整报文，才能继续转发。 例如：主机 A → 路由器 → 主机 B。 报文大小： 8 Mb。 每条链路速率： 10 Mb/s。

**第一段链路** $T_1=\frac{8}{10}=0.8\ \mathrm{s}$ 路由器完整收到报文后，才能开始下一段传输。

**第二段链路** $T_2=0.8\ \mathrm{s}$ 因此： $T=0.8+0.8$ 得到： $\boxed{T=1.6\ \mathrm{s}}$ 忽略传播、处理和排队时延。

**报文交换缺点** 对于大报文：中间结点需要较大缓存。 并且必须等待整份报文接收完成。 导致较大的转发等待时间。

**分组交换** 分组交换：先把大报文划分为若干分组。 例如： 8 Mb 的报文。 每个分组： 10 kb。 那么： $N=\frac{8\times10^6}{10\times10^3}$ 得到： $N=800$ 个分组。

**为什么效率高？** 因为分组可以流水传输。 当第一个分组进入第二段链路时：发送端可以同时发送第二个分组。 因此不同链路能够同时处理不同分组。

**【2013 年真题】报文交换与分组交换** 题目：主机甲通过一个路由器连接主机乙。 两段链路速率均为： 10 Mb/s。 报文大小： 8 Mb。 分组大小： 10 kb。 忽略传播、首部和拆装时延。 求：报文交换与分组交换的总时间。

**第一问：报文交换** 完整报文在每条链路上的发送时间： $t=\frac{8\times10^6}{10\times10^6}$ $t=0.8\ \mathrm{s}$ 两段链路： $T_{\mathrm{message}}=2t$ 得到： $\boxed{T_{\mathrm{message}}=1600\ \mathrm{ms}}$

**第二问：分组交换** 分组数： $N=800$ 每个分组发送时间： $t=\frac{10\times10^3}{10\times10^6}$ $t=1\ \mathrm{ms}$ 两段等速链路： $T=(N+2-1)t$ $T=801\times1$ 得到： $\boxed{T_{\mathrm{packet}}=801\ \mathrm{ms}}$ 所以：

**答案：D，1600 ms、801 ms。** **为什么分组交换快？** 报文交换：第二段链路必须等待整份报文到达。 分组交换：第二段链路只需要等待第一个分组完整到达。 因此可以更早形成流水线。

### 分组交换流水线计算

这是本章最重要的综合计算模型之一。 **先理解流水线** 假设有： 3 条链路；4 个分组；每条链路传输一个分组需要 1 ms。 忽略传播与其他时延。 每个分组需要依次经过三条链路。 时间安排如下：

| 时间区间 | 链路 1 | 链路 2 | 链路 3 |
|---|---|---|---|
| 0～1 ms | P1 | 空闲 | 空闲 |
| 1～2 ms | P2 | P1 | 空闲 |
| 2～3 ms | P3 | P2 | P1 |
| 3～4 ms | P4 | P3 | P2 |
| 4～5 ms | 空闲 | P4 | P3 |
| 5～6 ms | 空闲 | 空闲 | P4 |

所以：全部 4 个分组经过 3 条链路： $T=6\ \mathrm{ms}$ 而不是： $4\times3=12\ \mathrm{ms}$

**等速、等长分组公式** 设： $N$：分组数量；$k$：链路数量；$P$：每个分组长度，bit；$R$：链路速率，bit/s。 单分组单链路发送时间： $t=\frac{P}{R}$ 第一个分组到达：需要经过 $k$ 条链路。 发送相关时间： $kt$ 后面还有： $N-1$ 个分组。 由于流水线稳定后每隔 $t$ 时间完成一个分组： $T=kt+(N-1)t$ 整理： $\boxed{T=(N+k-1)\frac{P}{R}}$ 这是必须熟练掌握的公式。

**适用条件**

1. 分组等长。
2. 链路等速。
3. 每个中间结点完整接收分组后才能转发。
4. 同一路径连续传输。
5. 不考虑额外排队、处理时间。
6. 若忽略传播时延，直接使用上式。

若存在传播时延：

$$
\boxed{
T=(N+k-1)\frac{P}{R}
+\sum_{i=1}^{k}T_{p,i}
}
$$

**【2010 年真题】分组首部与流水线** 题目：所有链路速率： 100 Mb/s。 每个分组总大小： 1000 B。 首部： 20 B。 文件大小： 980000 B。 最短路径包含 3 条等速链路。 忽略传播和拆装时延。 求文件全部传输完成时间。

**第一步：每个分组有效载荷** 分组总长： 1000 B。 首部： 20 B。 所以： $D=1000-20$ $\boxed{D=980\ \mathrm{B}}$

**第二步：分组数量** $N=\frac{980000}{980}$ 得到： $\boxed{N=1000}$

**第三步：每个分组的发送时间** 注意：链路发送的是完整分组。 包括首部。 所以： $P=1000\times8=8000\ \mathrm{bit}$ 发送时间： $t=\frac{8000}{100\times10^6}$ $\boxed{t=0.08\ \mathrm{ms}}$

**第四步：流水线总时间** 3 条链路： $k=3$ 因此： $T=(N+k-1)t$ 代入： $T=(1000+3-1)\times0.08$ $T=1002\times0.08$ 得到： $\boxed{T=80.16\ \mathrm{ms}}$

**答案：C。** **三个易错点** 第一：把每个分组的有效载荷错误地当作 1000 B。 第二：计算发送时间时只使用 980 B。 第三：把分组数乘以完整的三跳延迟。

**必须掌握的区分** 分组数量：用有效载荷计算。 链路发送时延：用包含首部的实际分组长度计算。

**【2023 年真题】BDP 与流水线联合** 题目：主机 H1 通过一个路由器连接 H2。 两条链路速率均为： 100 Mb/s。 每条链路的时延带宽积： 1000 bit。 文件大小： 1 MB。 每个分组长度： 1000 B。 题目规定： $1\ \mathrm{MB}=10^6\ \mathrm{B}$ 求全部传输完成的最短时间。

**第一步：分组数** $N=\frac{10^6}{1000}$ $\boxed{N=1000}$

**第二步：发送时延** $t_s=\frac{1000\times8}{100\times10^6}$ $\boxed{t_s=0.08\ \mathrm{ms}}$

**第三步：传播时延** 已知： $\mathrm{BDP}=RT_p$ 因此： $T_p=\frac{1000}{100\times10^6}$ $T_p=0.01\ \mathrm{ms}$ 每条链路传播时延： 0.01 ms。 两条链路： $T_{\mathrm{prop}}=0.02\ \mathrm{ms}$

**第四步：流水线** $T=(N+2-1)t_s+T_{\mathrm{prop}}$ 代入： $T=1001\times0.08+0.02$ 得到： $\boxed{T=80.10\ \mathrm{ms}}$

**答案：D。** **这道题综合了什么？**

1. 数据量与分组数换算。
2. 发送时延。
3. 时延带宽积。
4. 传播时延。
5. 多跳分组流水线。

这是非常值得反复练习的题型。 **不同速率链路的流水线** 等速公式不能直接用于不同速率链路。 假设： $N$ 个等长分组；$k$ 条串联链路；第 $i$ 条链路速率为 $R_i$；每个分组长度为 $P$。 定义： $t_i=\frac{P}{R_i}$ 第一个分组经过所有链路所需的发送相关时间： $T_{\mathrm{first}}=\sum_{i=1}^{k}t_i$ 后续分组的稳定完成节拍：由最慢链路决定。 因此：

$$
\boxed{
T=\sum_{i=1}^{k}t_i+
(N-1)\max(t_1,t_2,\ldots,t_k)
}
$$

若还需考虑传播时延：

$$
\boxed{
T=\sum_{i=1}^{k}\frac{P}{R_i}
+
(N-1)\max_i\left(\frac{P}{R_i}\right)
+
\sum_{i=1}^{k}T_{p,i}
}
$$

适用于线性路径、等长分组、逐包存储转发、连续发送且无额外排队和处理延迟的理想模型。 **进阶例题：非等速链路** 主机 A 通过路由器向主机 B 发送 5 个等长分组。 每个分组： 1000 B。 第一条链路： 10 Mb/s。 第二条链路： 5 Mb/s。 忽略传播时延。

**第一步：第一条链路** $t_1=\frac{8000}{10\times10^6}$ $t_1=0.8\ \mathrm{ms}$

**第二步：第二条链路** $t_2=\frac{8000}{5\times10^6}$ $t_2=1.6\ \mathrm{ms}$

**第三步：找到瓶颈** $\max(t_1,t_2)=1.6\ \mathrm{ms}$

**第四步：总时间** $T=t_1+t_2+(N-1)\max(t_1,t_2)$ $T=0.8+1.6+4\times1.6$ 得到： $\boxed{T=8.8\ \mathrm{ms}}$

**为什么不能直接把速率取最小值？** 因为：第一个分组必须经过全部链路。 它既要经历第一条链路的发送时间，也要经历第二条链路的发送时间。 瓶颈节拍只决定后续分组稳定输出的间隔。

**最后一个分组不满载怎么办？** 这是容易出现的新题变式。 例如：文件大小： 4500 B。 最大有效载荷： 1000 B。 每个分组首部： 20 B。 那么：前四个分组：每个有效载荷 1000 B。 总长： 1020 B。 最后一个分组：有效载荷 500 B。 总长： 520 B。 因此：分组长度不完全相等。 不能直接用等长流水线公式。

**最可靠方法** 逐包计算时间线。 对于第 $i$ 个分组在第 $j$ 条链路上的发送完成时刻，定义： $F_{i,j}$ 则：

$$
\boxed{
F_{i,j}
=
\max(F_{i-1,j},F_{i,j-1}+p_{j-1})
+p_j
}
$$

这个写法在传播延迟存在时还需要明确前一链路的传播到达条件。更通用、清晰的做法是定义实际到达及完成时刻：

$$
\boxed{
F_{i,j}
=
\max(F_{i-1,j},A_{i,j})
+\frac{P_i}{R_j}
}
$$

其中： $F_{i,j}$：分组 $i$ 在链路 $j$ 上发送完成的时刻；$A_{i,j}$：分组 $i$ 在该链路发送端完整可用的时刻；$F_{i-1,j}$：前一个分组占用该链路结束的时刻；$P_i$：分组 $i$ 的实际长度。 下一跳的完整到达时刻： $A_{i,j+1}=F_{i,j}+T_{p,j}$ 这样就能够处理：不同长度分组；不同速率链路；不同传播时延；排队等待。

**分组是否越小越好？** 不是。 较小分组能够更早形成流水线。 但是分组越小：同一文件需要的分组越多。 每个分组都有首部。 因此总首部开销也越大。 例如文件： 980000 B。 每包有效载荷： 980 B。 每包首部： 20 B。 需要： 1000 个分组。 总发送字节数： $1000\times1000=1000000\ \mathrm{B}$ 如果每包有效载荷改为： 480 B。 每包仍有： 20 B 首部。 就需要更多分组。 因此：

**分组越小，不一定总传输时间越短。** 需要综合考虑：流水线效率；首部开销；链路速率；分组数量；设备处理能力；丢包重传成本。

**数据报与虚电路** **分组交换的两种方式** 分组交换可以采用：

1. 数据报方式
2. 虚电路方式

**数据报方式** DataGram。 特点：

**无连接。** 发送前不需要建立端到端逻辑连接。 每个分组可以独立进行路由选择。 例如：分组 P1： A → R1 → R3 → B。 分组 P2： A → R2 → R4 → B。 不同分组可能走不同路径。

**特点** 不需要预先建立连接；分组可以独立选路；分组可能乱序到达；分组可能丢失；中间结点通常依据目的地址转发。 典型例子： IP 数据报网络。

**虚电路方式** Virtual Circuit。 特点：

**面向连接的分组交换。** 传输之前先建立逻辑连接。 然后分组沿对应逻辑路径转发。 最后释放虚电路。

**虚电路三个阶段**

1. 建立连接。
2. 传输分组。
3. 释放连接。

**主要特点** 先建立逻辑连接；建立时确定路径；中间结点维护虚电路状态；可通过虚电路标识 VCID 进行转发；同一虚电路的分组通常沿相同路径传输；通常能够保持顺序。

**虚电路与电路交换的区别** 这是高频陷阱。 虚电路不是物理专用电路。

| 特性 | 电路交换 | 虚电路 |
|---|---|---|
| 传输前建立连接 | 是 | 是 |
| 是否属于分组交换 | 否 | 是 |
| 是否存储转发分组 | 否 | 是 |
| 是否必须独占物理链路 | 典型电路交换预留资源 | 不必须 |
| 是否维护连接状态 | 是 | 是 |
| 是否天然保证可靠性 | 不等于端到端可靠 | 不保证 |
| 是否必须预留带宽 | 典型情况下预留 | 不必须 |

**最关键的结论** **面向连接不等于预留带宽。**

**面向连接不等于可靠传输。** **【2020 年真题】虚电路网络** 题目：下列关于虚电路网络的叙述，错误的是： A. 可以确保数据分组传输顺序 B. 需要为每条虚电路预分配带宽 C. 建立虚电路时需要进行路由选择 D. 依据虚电路号进行数据分组转发

**答案：B** **为什么？** 虚电路建立的是：逻辑转发关系。 并不是一定要预留固定带宽。 只有具体网络协议明确要求资源预留时，才需要预分配相关资源。

**瓶颈链路与吞吐量** **串联链路** 例如： A → R1 → R2 → B。 链路速率分别： 100 Mb/s。 10 Mb/s。 1000 Mb/s。 在单一路径、忽略其他因素的情况下： $R_{\max}=\min(100,10,1000)$ 得到： $\boxed{R_{\max}=10\ \mathrm{Mb/s}}$ 原因：第二条链路是瓶颈。

**并行路径** 如果中间有多条并行路径：可以在一定条件下通过多路径传输获得聚合吞吐量。 但整个网络仍受到源端出口、目的端入口等瓶颈限制。 例如：源端接入链路： 10 Mb/s。 中间三条并行路径容量： 1000 Mb/s。 100 Mb/s。 1 Mb/s。 目的端接入链路： 10 Mb/s。 即使中间理论聚合容量很大：源端与目的端仍各只有 10 Mb/s。 所以： $R_{\max}\le10\ \mathrm{Mb/s}$ 对于这个拓扑，若没有其他限制且中间通路可以提供足够容量，则最大吞吐量就是： $\boxed{10\ \mathrm{Mb/s}}$

**【2024 年真题】** 站内收录的相应拓扑吞吐量题，答案为：

**B，10 Mb/s。** **更一般的理解** 对于复杂多路径网络，不能简单地把全部链路速率求最小值。 应考虑：源到目的之间的路径组织与割集容量。 如果是多路径聚合传输问题，可以用最大流、最小割的思想分析理论吞吐量上界。

## 传输介质与物理层设备

### 传输介质

**导向与非导向传输介质** **导向传输介质** 信号沿实体介质传播。 包括：

- 双绞线
- 同轴电缆
- 光纤

**非导向传输介质** 通过自由空间传播。 包括：

- 无线电
- 微波
- 卫星通信
- 红外通信

**双绞线** 由两根绝缘铜导线绞合而成。

**为什么要绞合？** 主要是：降低电磁干扰与串扰。 常见： UTP：非屏蔽双绞线。 STP：屏蔽双绞线。

**特点** 成本较低；布线方便；常用于局域网；抗干扰性能与线缆类别、屏蔽、施工条件有关。

**【2019 年真题】** 100BaseT 快速以太网使用的导向传输介质是什么？ A. 双绞线 B. 单模光纤 C. 多模光纤 D. 同轴电缆

**答案：A** 原因： T 表示 Twisted Pair。 即双绞线。

**同轴电缆** 典型结构：

1. 中心导体
2. 绝缘层
3. 金属屏蔽层
4. 外护套

特点：屏蔽能力较好；抗电磁干扰能力较强；曾用于早期以太网；广泛用于有线电视等系统。

**光纤** 使用光信号传输数据。 典型结构：

- 纤芯
- 包层
- 外部保护层

通过折射率差异形成导光机制。 **主要优点** 支持很高的数据传输速率；适合长距离传输；抗电磁干扰能力强；衰减较小；电气隔离性能好。

**单模光纤与多模光纤**

| 特点 | 单模光纤 | 多模光纤 |
|---|---|---|
| 传播模式 | 单一主要模式 | 多种模式 |
| 纤芯 | 通常较细 | 通常较粗 |
| 模间色散 | 小 | 较明显 |
| 传输距离 | 通常更长 | 通常较短 |
| 典型应用 | 长距离、高速通信 | 较短距离连接 |

**经典易错点** 光纤传输速率高，不代表信号在光纤中的传播速度一定比铜缆中的电磁信号快。 光纤优势主要体现在：可利用频带资源；传输损耗；抗干扰能力；光通信系统支持的数据率。 而不是简单地说：光在光纤中传播得一定最快。

**无线传输** **无线电** 适用于广播和移动通信。

**微波** 常具有较强方向性。 很多地面微波链路需要视距传输。

**卫星通信** 传播距离较长。 传播时延可能明显增加。

**注意** 卫星通信的高传播时延主要由：传播距离大。 决定。 不能将其与链路数据率混淆。

### 物理层设备

**中继器 Repeater** 工作层：物理层。 主要作用：对数字信号进行再生与转发。

**工作过程**

1. 接收信号。
2. 判断数字信号状态。
3. 整形、恢复时序。
4. 重新发送标准信号。

**中继器不做什么？** 不依据 MAC 地址转发帧；不执行 IP 路由；不按网络层信息选择路径；不能依靠 MAC 地址隔离冲突域。

**中继器与放大器的区别** 放大器：通常对模拟波形进行放大，也可能放大噪声。 数字中继器：通常能够判决并再生数字信号。

**集线器 Hub** 本质： $\boxed{\text{Hub}=\text{多端口中继器}}$ 工作层：物理层。 假设： A、B、C、D 连接到一个传统 Hub。 A 发送物理信号。 Hub 将信号再生并发送到其他相关端口。 Hub 不会根据目的 MAC 地址判断应该只发送给 B。

**集线器重要特点**

1. 工作在物理层。
2. 不学习 MAC 地址。
3. 不维护二层交换机式 MAC 转发表。
4. 不隔离冲突域。
5. 不隔离广播域。
6. 传统共享式 Hub 使用半双工通信。
7. 各端口共享介质带宽。

**集线器的冲突域** 传统 Hub 连接的所有主机处于同一共享冲突域。 例如： A、B、C 三台主机连接到一个 Hub。 如果 A 和 B 同时发送：可能发生冲突。 因此：传统共享以太网需要使用相关介质访问控制机制处理冲突。

**物理拓扑与逻辑拓扑** Hub 网络通常：物理上是星形。 逻辑上具有总线式共享介质的特点。 这是经典概念题。

**集线器与交换机**

| 项目 | 集线器 | 二层交换机 |
|---|---|---|
| 工作层 | 物理层 | 数据链路层 |
| 处理对象 | 比特、信号 | 帧 |
| 是否学习 MAC | 否 | 是 |
| 是否根据 MAC 转发 | 否 | 是 |
| 冲突域 | 多端口共享 | 每端口通常独立 |
| 广播域 | 不隔离 | 默认不隔离 |
| 双工 | 传统共享半双工 | 常见全双工 |

**重要区别** 交换机可以隔离冲突域。 但普通二层交换机默认并不隔离同一 VLAN 内的广播域。

**网卡 NIC** Network Interface Card。 即网络适配器。 通常同时承担：

**物理层功能** 信号编码与解码；信号发送与接收；与传输介质连接。

**数据链路层功能** 以太网帧收发；MAC 地址相关功能；差错检测等。 因此：

**网卡不能简单归类为纯物理层设备。** **设备层次总表**

| 设备 | 典型工作层次 | 主要处理对象 |
|---|---|---|
| 中继器 | 物理层 | 物理信号 |
| 集线器 | 物理层 | 比特、物理信号 |
| 网卡 | 物理层和数据链路层 | 信号、帧 |
| 网桥 | 数据链路层 | 帧 |
| 二层交换机 | 数据链路层 | 帧 |
| 路由器 | 网络层 | IP 分组 |

记忆： Hub 看比特。 Switch 看 MAC。 Router 看 IP。

## 综合题与典型变式

### 模拟题精讲

**模拟题：8-PSK 与时延联合** 题目：无噪声信道带宽： $W=1\ \mathrm{MHz}$ 采用 8-PSK。 实际数据率为理论最大值的 50%。 传输数据块： 24 KB。 单向传播时延： 20 ms。 题目规定： $1\ \mathrm{KB}=1000\ \mathrm{B}$ 求总时延。

**第一步：每码元比特数** 8-PSK： $M=8$ 所以： $\log_2M=3$

**第二步：奈奎斯特数据率** $C_N=2\times10^6\times3$ $C_N=6\ \mathrm{Mb/s}$

**第三步：实际速率** $R=0.5\times6$ $R=3\ \mathrm{Mb/s}$

**第四步：计算数据量** $L=24\times1000\times8$ $L=192000\ \mathrm{bit}$

**第五步：发送时延** $T_s=\frac{192000}{3\times10^6}$ $T_s=64\ \mathrm{ms}$

**第六步：加上传播时延** $T=64+20$ 得到： $\boxed{T=84\ \mathrm{ms}}$

**答案：B。** **这道题的知识链** 奈奎斯特 → 调制速率 → 实际速率 → 发送时延 → 总时延。

**模拟题：中继器** 题目：数字信号传输距离过长导致衰减。 为了延长可靠传输距离，通常应使用什么设备？ A. 放大器 B. 中继器 C. 路由器 D. 交换机

**答案：B** 原因：数字信号需要判决、整形与再生。 中继器能够完成相应物理层处理。

**模拟题：集线器** 题目：关于集线器，下列说法正确的是： A. 可以直接实现不同速率以太网段间的普通帧缓存与速率转换 B. 传统集线器连接的网段工作在共享半双工环境 C. 能通过隔离冲突域减少广播风暴 D. 能识别目的 MAC 地址并过滤帧

**答案：B** 分析： A：普通传统 Hub 不具备交换机式缓存转发及速率适配功能。 C： Hub 不隔离冲突域。 D： Hub 不根据 MAC 地址选择转发端口。

**模拟题：CSMA/CD 最小帧长** 注意：这道题严格属于数据链路层。 但使用了物理层的传播时延知识。 题目：共享以太网最大距离： 1 km。 发送速率： 1 Gb/s。 传播速度： 200000 km/s。 求理想模型下最小帧长。

**第一步：单向传播时延** $T_p=\frac{1}{200000}$ $T_p=5\ \mu s$

**第二步：往返传播时延** $2T_p=10\ \mu s$

**第三步：碰撞检测约束** 发送方在最远端冲突信号返回之前不能已经结束发送。 因此： $\frac{L_{\min}}{R}\ge2T_p$ 所以： $L_{\min}\ge2RT_p$ 代入： $L_{\min}\ge2\times10^9\times5\times10^{-6}$ 得到： $\boxed{L_{\min}=10000\ \mathrm{bit}}$

**答案：A。** 注意：这是题设简化碰撞检测模型的结果。 不能直接视为所有千兆以太网的标准最小帧长。

### 综合强化题

以下是根据站内知识点和真题模型组合的强化题，不是历年原题。 **综合题一：信道容量 + 分组交换 + 传播时延** 某通信系统具有：频带宽度： $W=4\ \mathrm{MHz}$ 信噪比： 30 dB。 调制方式： 64-QAM。 某网络的两条链路实际传输速率均为： 20 Mb/s。 两条链路之间有一个路由器。 每条链路单向传播时延： 2 ms。 文件大小： 10 MB。 每分组： 1000 B。 忽略首部与其他开销。 求：

1. 奈奎斯特上限。
2. 香农容量。
3. 联合理论上界。
4. 每分组发送时延。
5. 文件传输总时间。

**第一问：奈奎斯特** 64-QAM： $\log_2 64=6$ 因此： $C_N=2\times4\times10^6\times6$ $\boxed{C_N=48\ \mathrm{Mb/s}}$

**第二问：香农** 30 dB： $S/N=1000$ 因此： $C_S=4\times10^6\log_2(1001)$ 得到： $\boxed{C_S\approx39.87\ \mathrm{Mb/s}}$

**第三问：联合理论上界** $C_{\max}\le\min(48,39.87)$ 得到： $\boxed{C_{\max}\le39.87\ \mathrm{Mb/s}}$ 这里香农容量限制更严格。

**第四问：单分组发送时延** 注意：链路实际速率是： 20 Mb/s。 因此： $t_s=\frac{1000\times8}{20\times10^6}$ $\boxed{t_s=0.4\ \mathrm{ms}}$ 不能直接使用 39.87 Mb/s。 因为那是理论容量上界，而题目已经明确给出了实际链路速率。

**第五问：总时间** 文件： 10 MB。 分组： 1000 B。 所以： $N=\frac{10\times10^6}{1000}$ $N=10000$ 两条等速链路： $k=2$ 总传播时延： $T_p=4\ \mathrm{ms}$ 于是： $T=(N+k-1)t_s+T_p$ $T=10001\times0.4+4$ 得到： $\boxed{T=4004.4\ \mathrm{ms}}$ 即： $\boxed{T=4.0044\ \mathrm{s}}$

**本题真正需要掌握的内容** 第一：理论信道容量与实际数据传输速率不是一回事。 第二：数据量和分组数量必须正确换算。 第三：存储转发需要使用流水线公式。 第四：传播时延需要单独补充。

**综合题二：非等速链路 + 首部 + 最后一包不足** 主机 A 经过一个路由器 R 向 B 发送文件。 文件大小： 4500 B。 最大有效载荷： 1000 B。 每包首部： 20 B。 第一条链路： 8 Mb/s。 第二条链路： 4 Mb/s。 每条链路单向传播时延： 1 ms。 求全部数据到达 B 的最短时间。

**第一步：划分分组** 文件： 4500 B。 每包最多 1000 B 有效数据。 所以需要： $N=5$ 前 4 个满载荷分组： $P_{\mathrm{full}}=1020\ \mathrm{B}$ 最后 1 个分组： $P_{\mathrm{last}}=520\ \mathrm{B}$

**第二步：计算第一条链路发送时延** 满载荷分组：

$$
t_{1,\mathrm{full}}
=
\frac{1020\times8}{8\times10^6}
$$

$t_{1,\mathrm{full}}=1.02\ \mathrm{ms}$ 最后一包： $t_{1,\mathrm{last}}=0.52\ \mathrm{ms}$

**第三步：第二条链路** 满载荷：

$$
t_{2,\mathrm{full}}
=
\frac{1020\times8}{4\times10^6}
$$

$t_{2,\mathrm{full}}=2.04\ \mathrm{ms}$ 最后一包： $t_{2,\mathrm{last}}=1.04\ \mathrm{ms}$

**第四步：逐包计算** 第一包：第一条链路发送完成： 1.02 ms。 传播至路由器： 1 ms。 所以： 2.02 ms 时完整到达路由器。 随后第二条链路发送： 2.04 ms。 完成发送时刻： 4.06 ms。 第二包：由于第二条链路仍被第一包占用，必须等待。 依次计算：

| 分组 | 第二条链路开始发送 | 第二条链路完成发送 |
|---|---|---|
| P1 | 2.02 ms | 4.06 ms |
| P2 | 4.06 ms | 6.10 ms |
| P3 | 6.10 ms | 8.14 ms |
| P4 | 8.14 ms | 10.18 ms |
| P5 | 10.18 ms | 11.22 ms |

最后一包第二条链路发送完成： 11.22 ms。 还需要传播： 1 ms。 因此： $T=11.22+1$ $\boxed{T=12.22\ \mathrm{ms}}$

**为什么本题有价值？** 因为它同时涉及：有效载荷；分组首部；最后一个不足长分组；不等速链路；存储转发；传播时延；瓶颈排队。 如果能够独立完成这道题，说明你已经真正理解分组流水线，而不是只会套公式。

## 易错辨析、公式与解题模板

### 全章最容易混淆的知识点

**码元不等于比特** 一个码元可以承载多个比特。 $R_b=R_s\log_2M$

**波特率不等于比特率** 波特率：每秒传输多少码元。 比特率：每秒传输多少比特。 只有每码元恰好携带 1 bit 时，二者数值才相同。

**Hz 不等于 bit/s** Hz：频带宽度。 bit/s：数据速率。 不能直接换算。

**奈奎斯特与香农不能混用** 奈奎斯特：看带宽和码元状态数。 香农：看带宽和信噪比。 题目同时给出两类约束：两者都要检查。

**dB 不能直接代入香农公式** 必须先转换为线性功率比： $S/N=10^{\mathrm{SNR}_{dB}/10}$

**发送时延不等于传播时延** 发送时延： $T_s=\frac{L}{R}$ 传播时延： $T_p=\frac{d}{v}$ 发送更快：不会自动提高信号在介质中的传播速度。

**单向 BDP 与 RTT 不要混淆** 单向链路的在途比特计算： $\mathrm{BDP}=RT_p$ TCP 未确认数据量分析：常需要考虑 RTT。

**曼彻斯特与差分曼彻斯特** 普通曼彻斯特：看中点跳变方向。 差分曼彻斯特：看开头是否跳变。 还必须确认 0/1 的编码约定。

**报文交换与分组交换都可能采用存储转发** 区别：报文交换以完整报文为转发单位。 分组交换以较小分组为转发单位。

**分组流水线不能简单乘链路数量** 等速、等长、无额外时延条件下： $T=(N+k-1)\frac{P}{R}$

**分组数量与发送长度不能混用** 分组数：通常根据文件数据量和有效载荷计算。 发送时延：使用实际传输的完整分组长度。

**虚电路不是专用物理电路** 虚电路：逻辑连接。 电路交换：典型情况下预留端到端通信资源。

**虚电路不一定预留带宽** 建立逻辑连接：不等于必须为其固定分配带宽。

**集线器不识别 MAC 地址** Hub：物理层。 Switch：数据链路层。 Router：网络层。

**光纤数据率高不等于传播速度一定更快** 数据率：每秒传输多少比特。 传播速度：信号每秒前进多少距离。 二者是不同物理量。

**全章公式总表**

| 知识点 | 公式 | 用途 |
|---|---|---|
| 每码元比特数 | $k=\log_2M$ | 码元信息量 |
| 比特率 | $R_b=R_s\log_2M$ | 速率换算 |
| 波特率 | $R_s=R_b/\log_2M$ | 反求码元速率 |
| 码元状态数 | $M=2^{R_b/R_s}$ | 反求状态数 |

| 奈奎斯特数据率 | $C_N=2W\log_2M$ | 无噪声容量上界 |
| 香农容量 | $C_S=W\log_2(1+S/N)$ | 有噪声容量 |
| dB 表示 | $\mathrm{SNR}_{dB}=10\log_{10}(S/N)$ | 信噪比换算 |
| dB 反推 | $S/N=10^{\mathrm{SNR}_{dB}/10}$ | 转线性信噪比 |
| 联合上界 | $R_b\le\min(C_N,C_S)$ | 综合限制 |
| 发送时延 | $T_s=L/R$ | 发送完整分组时间 |
| 传播时延 | $T_p=d/v$ | 信号传播时间 |
| 时延带宽积 | $\mathrm{BDP}=RT_p$ | 单向在途比特 |
| 等速分组流水线 | $T=(N+k-1)P/R$ | 多跳等长分组 |
| 不等速分组流水线 | $T=\sum_i P/R_i+(N-1)\max_i(P/R_i)$ | 多速率链路 |

| 理想采样条件 | $f_s\ge2f_{\max}$ | 采样率 |
| CDMA 解码 | $r_i=(S\cdot C_i)/m$ | 正交码相关 |

### 408 考场解题模板

**模板一：码元速率题** 看到：

- 波特率
- 比特率
- 调制阶数
- 码元状态数

立即写： $R_b=R_s\log_2M$ 然后判断需要求哪一个变量。

**模板二：奈奎斯特题** 看到：理想无噪声；信道带宽；码元状态数；最大数据率。 写： $C_N=2W\log_2M$ 反求状态数： $M=2^{C_N/(2W)}$

**模板三：香农题** 看到：

- 信噪比
- dB
- 噪声
- 理论信道容量

第一步： dB 转线性值。 第二步： $C_S=W\log_2(1+S/N)$ 第三步：如果有实际速率比例，再进行相应换算。

**模板四：联合容量题** 看到：

- 带宽
- 码元状态数
- 信噪比

第一步：奈奎斯特。 第二步：香农。 第三步：取更严格的上界。 第四步：若目标超过香农容量，直接判断无法在该信道模型下可靠实现。

**模板五：编码识图题** 第一步：判断是否每个比特中点必跳变。 第二步：如果中点必跳变，考虑曼彻斯特类编码。 第三步：普通曼彻斯特看中点方向。 第四步：差分曼彻斯特看起始跳变。 第五步：核对初始电平及 0/1 映射约定。

**模板六：时延题** 先识别：

- 数据长度
- 发送速率
- 距离
- 传播速度

分别计算： $T_s=\frac{L}{R}$ $T_p=\frac{d}{v}$ 最后按题目要求相加。

**模板七：分组流水线题** 第一步：计算分组有效载荷。 第二步：计算分组数量。 第三步：计算每个分组的实际发送长度。 第四步：计算单包发送时延。 第五步：判断链路是否等速。 第六步：判断分组是否等长。 第七步：等速等长用简式。 不等速等长用瓶颈节拍。 不等长用逐包时间线。 第八步：补充传播、处理及其他题设开销。

**模板八：设备辨析题** 先问：这个设备的转发功能依赖哪一层的信息？ 物理信号：中继器或 Hub。 MAC 地址：网桥或二层交换机。 IP 地址：路由器。

## 考前训练与全章总结

### 最后总结：本章真正需要形成的能力

学习本章时，最重要的是建立四套稳定的解题模型。 **第一套：信道容量模型** 掌握： $R_b=R_s\log_2M$ $C_N=2W\log_2M$ $C_S=W\log_2(1+S/N)$ 并且理解：码元、带宽、噪声分别限制什么。

**第二套：编码识图模型** 真正理解： NRZ 看绝对电平；NRZI 看是否跳变；曼彻斯特看中点跳变方向；差分曼彻斯特看起始边界是否跳变。 同时养成检查编码约定和初始条件的习惯。

**第三套：传输时间模型** 掌握： $T_s=L/R$ $T_p=d/v$ $\mathrm{BDP}=RT_p$ 以及： $T=(N+k-1)\frac{P}{R}$ 最关键的是：遇到多个分组、多个链路，不会机械地把所有单包端到端时间乘以分组数量。 而是理解流水线。

**第四套：网络结构模型** 掌握：

- 电路交换
- 报文交换
- 分组交换
- 数据报
- 虚电路
- 中继器
- Hub
- Switch
- Router

理解：连接、转发单位、资源预留、存储转发与工作层次之间的关系。
