# 重复子字符串：从字符串周期到 KMP 最小循环节

> 对应题目：[LeetCode 459. 重复的子字符串](https://leetcode.cn/problems/repeated-substring-pattern/)

给定一个非空字符串 `s`，判断它能否由某个更短的子串重复若干次得到。

例如：

```text
s = "abab"
```

可以写成：

```text
"ab" + "ab"
```

所以答案为 `true`。

而：

```text
s = "aba"
```

不存在这样的更短重复单元，因此答案为 `false`。

这道题表面上是在“找重复子串”，本质上是在研究字符串的**周期**。

如果存在长度为 $p$ 的字符串 `t`，使得：

$$
s=t^k
$$

其中 $k\ge 2$，那么 $p$ 就是 `s` 的一个周期长度。

---

## 1. 最直接的暴力思路

假设字符串长度为：

$$
n
$$

如果 `s` 由一个更短字符串重复组成，那么重复单元长度 $p$ 必须满足：

$$
p\mid n
$$

并且：

$$
1\le p\le \frac n2
$$

因此可以枚举所有可能的 $p$，再检查：

$$
s[i]=s[i\bmod p]
$$

是否对所有下标成立。

最坏情况下，需要枚举 $O(n)$ 个候选长度，每次验证 $O(n)$ 个字符，因此复杂度为：

$$
O(n^2)
$$

这个方法容易理解，但没有利用字符串本身的结构。

---

## 2. 方法一：双倍字符串与移动匹配

如果：

```text
s = abcabc
```

那么它内部存在周期结构：

![重复子串结构](https://file1.kamacoder.com/i/algo/20220728104518.png)

把字符串复制一份：

```text
s + s = abcabcabcabc
```

由于 `s` 本身具有周期，当第二份字符串相对第一份发生周期长度的偏移时，中间会重新出现完整的 `s`：

![双倍字符串中的移动匹配](https://file1.kamacoder.com/i/algo/20220728104931.png)

于是得到一个非常漂亮的判定结论：

> `s` 可以由重复子字符串构成，当且仅当 `s` 出现在 `(s + s)` 去掉首字符和尾字符之后的字符串中。

也就是判断：

```text
(s + s)[1 : 2n - 1]
```

是否包含 `s`。

---

## 3. 为什么必须“掐头去尾”

如果直接在：

```text
s + s
```

中查找 `s`，答案永远为真，因为：

- 第一个 `s` 就出现在下标 `0`；
- 第二个 `s` 还会出现在下标 `n`。

这些匹配并不能说明字符串存在周期。

删除首尾字符后，原本两个“显然存在”的匹配都被破坏，只保留由字符串周期导致的**跨边界匹配**。

例如：

```text
s = abcabc
s+s = abcabcabcabc
```

去掉首尾：

```text
bcabcabcab
```

其中仍然存在：

```text
abcabc
```

说明存在非零且小于 $n$ 的循环位移，使字符串与自己重合。

---

## 4. 移动匹配为什么成立

设 `s` 长度为 $n$。

如果 `s` 的最小周期长度为 $p$，那么：

$$
p<n
$$

且：

$$
n\bmod p=0
$$

并满足：

$$
s[i]=s[(i+p)\bmod n]
$$

所以把 `s` 循环左移 $p$ 位后，字符串仍然不变。

而 `s+s` 恰好包含 `s` 的所有循环位移，因此在位置 $p$ 处会出现一个新的 `s`。

因为：

$$
0<p<n
$$

这个匹配不会是开头或结尾的原始副本，所以“掐头去尾”后仍能找到它。

反过来，如果去掉首尾后的 `s+s` 中还能找到 `s`，就说明存在某个：

$$
0<p<n
$$

使字符串循环移动 $p$ 位后保持不变，从而存在周期结构。

原资料给出的几组对应关系可以直观看到这种“循环位移不改变字符串”的现象：

![移动匹配证明示意一](https://file1.kamacoder.com/i/algo/20240910115555.png)

![移动匹配证明示意二](https://file1.kamacoder.com/i/algo/20240910115819.png)

![移动匹配证明示意三](https://file1.kamacoder.com/i/algo/20240910120751.png)

![移动匹配证明示意四](https://file1.kamacoder.com/i/algo/20240910121236.png)

<Callout title="本质" type="info">
双倍字符串方法不是一个偶然的字符串技巧。

它利用的是：**周期字符串经过某个非零循环位移后仍与自身完全相同。**
</Callout>

## 5. 移动匹配的复杂度别写错

下面这种代码十分简洁：

```cpp
string t = s + s;
t.erase(t.begin());
t.erase(t.end() - 1);
return t.find(s) != string::npos;
```

但复杂度不能只看到几行代码就直接写成 $O(n)$。

关键在于：

```cpp
t.find(s)
```

底层采用什么子串搜索算法。

如果底层是朴素匹配，最坏复杂度可能达到：

$$
O(n^2)
$$

如果使用 KMP 等线性匹配算法，则搜索部分可以做到：

$$
O(n)
$$

此外，构造 `s+s` 本身还需要：

$$
O(n)
$$

额外空间。

<Callout title="复杂度意识" type="warning">
不要因为调用了一个库函数，就默认它是 $O(1)$ 或 $O(n)$。

真正的复杂度取决于该函数的实现。
</Callout>

## 6. 方法二：KMP 与最小循环节

上一节已经学习过 KMP。

定义前缀函数：

$$
\pi[i]
$$

表示：

```text
s[0 ... i]
```

的最长相等真前缀与真后缀的长度。

设：

$$
L=\pi[n-1]
$$

也就是整个字符串的最长相等前后缀长度。

那么：

$$
n-L
$$

就是最值得关注的候选周期长度。

记：

$$
p=n-L
$$

若：

$$
L>0
$$

且：

$$
n\bmod p=0
$$

则 `s` 一定可以由长度为 $p$ 的子串重复构成。

因此判定式为：

$$
\boxed{L>0\ \land\ n\bmod(n-L)=0}
$$

---

## 7. 为什么候选周期是 `n - L`

假设：

```text
s = abcabcabcabc
```

长度：

$$
n=12
$$

最长相等前后缀是：

```text
abcabcabc
```

长度：

$$
L=9
$$

因此：

$$
p=n-L=12-9=3
$$

而真正的最小重复单元正是：

```text
abc
```

原资料通过下图说明：当字符串由最小重复单元构成时，最长相等前后缀恰好会覆盖“除了一个最小周期以外”的其余部分。

![重复串与最长相等前后缀](https://file1.kamacoder.com/i/algo/20240913110841.png)

如果还能找到更长的相等前后缀，那么就意味着原先认为的重复单元还能继续拆小：

![更长前后缀意味着周期还能缩短](https://file1.kamacoder.com/i/algo/20240913114348.png)

![重复单元继续分解](https://file1.kamacoder.com/i/algo/20240913114818.png)

所以：

$$
n-L
$$

对应最小周期的候选长度。

---

## 8. 为什么还必须检查整除

只知道：

$$
p=n-L
$$

还不够。

因为最长相等前后缀只说明：

> 字符串前面和后面有一段相同内容。

它并不自动保证整个字符串能够被长度 $p$ 的块完整铺满。

例如，如果：

$$
n\bmod p\ne 0
$$

那么最后一定会留下一个“不完整周期”，无法写成若干个完全相同的块。

原资料中的可整除情况：

![周期长度可以整除字符串长度](https://file1.kamacoder.com/i/algo/20240910174249.png)

此时可以一段接一段推出所有长度为 $p$ 的块都相同。

而不可整除时：

![周期长度不能整除字符串长度](https://file1.kamacoder.com/i/algo/20240913115854.png)

即使存在较长的相等前后缀，也无法把整个字符串完整切分为相同块。

所以整除条件不是代码细节，而是数学条件。

## 9. 一个完整例子：`abcabcabcabc`

字符串：

```text
abcabcabcabc
```

长度：

$$
n=12
$$

前缀函数最后一个值：

$$
L=9
$$

于是：

$$
p=n-L=3
$$

检查：

$$
12\bmod 3=0
$$

因此最小循环节长度为：

$$
3
$$

重复单元为：

```text
abc
```

重复次数：

$$
\frac{12}{3}=4
$$

## 10. 再看一个反例

设：

```text
s = ababa
```

长度：

$$
n=5
$$

它的最长相等前后缀为：

```text
aba
```

因此：

$$
L=3
$$

候选周期：

$$
p=n-L=2
$$

但是：

$$
5\bmod2=1
$$

不能整除，所以它不能由长度为 $2$ 的子串完整重复得到。

这正说明为什么 KMP 解法必须同时判断：

```text
最长相等前后缀存在
+
候选周期能整除总长度
```

## 11. KMP 实现

### 构造前缀函数

维护 `j` 表示当前最长相等前后缀长度。

如果：

```text
s[i] == s[j]
```

则：

```text
j++
```

并记录：

```text
pi[i] = j
```

### 失配时回退

如果字符不同，则不断：

```text
j = pi[j - 1]
```

直到找到可以继续匹配的位置，或 `j == 0`。

### 求候选周期

构造完成后：

```text
L = pi[n - 1]
p = n - L
```

### 判断是否完整重复

只需判断：

```text
L > 0 && n % p == 0
```

## 12. 推荐代码模板

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n = static_cast<int>(s.size());
        vector<int> pi(n, 0);

        for (int i = 1, j = 0; i < n; ++i) {
            while (j > 0 && s[i] != s[j]) {
                j = pi[j - 1];
            }

            if (s[i] == s[j]) {
                ++j;
            }

            pi[i] = j;
        }

        int longestBorder = pi[n - 1];
        int period = n - longestBorder;

        return longestBorder > 0 && n % period == 0;
    }
};
```

### Java

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        int[] pi = new int[n];

        for (int i = 1, j = 0; i < n; i++) {
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = pi[j - 1];
            }

            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }

            pi[i] = j;
        }

        int longestBorder = pi[n - 1];
        int period = n - longestBorder;

        return longestBorder > 0 && n % period == 0;
    }
}
```

### Python

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        pi = [0] * n

        j = 0
        for i in range(1, n):
            while j > 0 and s[i] != s[j]:
                j = pi[j - 1]

            if s[i] == s[j]:
                j += 1

            pi[i] = j

        longest_border = pi[-1]
        period = n - longest_border

        return longest_border > 0 and n % period == 0
```

### 复杂度

构造前缀函数：

$$
O(n)
$$

最终判断：

$$
O(1)
$$

所以总时间复杂度：

$$
\boxed{O(n)}
$$

前缀数组需要：

$$
\boxed{O(n)}
$$

额外空间。

## 13. 两种方法怎么选

<Cards>
<Card title="双倍字符串法">
直观、短小，最适合快速理解“周期 = 循环位移后仍相同”。
</Card>
<Card title="KMP 法">
不需要显式构造 `s+s`，能直接求出最小周期候选，也更能体现前缀函数的真正用途。
</Card>
</Cards>

如果目标只是解题，双倍字符串法往往最容易想到。

如果目标是掌握字符串算法，KMP 法更值得吃透，因为它把：

- 最长相等前后缀；
- 周期；
- 最小循环节；

三个概念连接了起来。

## 14. 常见错误

### 错误一：只判断 `pi[n - 1] > 0`

有相等前后缀，不代表整个字符串一定由重复单元组成。

还必须满足：

$$
n\bmod(n-\pi[n-1])=0
$$

### 错误二：忘记排除字符串自身

“重复子字符串”必须比原字符串短，而且至少重复两次。

### 错误三：把所有 `find` 都当成线性复杂度

库函数复杂度依赖具体语言和实现，不能凭函数名猜复杂度。

### 错误四：背 `n - next[n-1]`，却不知道为什么

真正要记住的是：

> 最长相等前后缀覆盖的部分可以复用，剩下的长度才是候选最小周期。

## 15. 最终记忆模型

遇到“字符串是否由某个短串重复组成”，可以按下面顺序思考：

```text
重复字符串
   ↓
存在周期 p
   ↓
循环移动 p 位后字符串不变
   ↓
可以用 (s+s) 的中间部分判断
```

或者从 KMP 出发：

```text
前缀函数最后值 L
       ↓
候选周期 p = n - L
       ↓
检查 n % p == 0
       ↓
得到是否为重复子字符串
```

<Callout title="核心结论" type="success">
设字符串长度为 $n$，最长相等真前后缀长度为 $L$。

若：

$$
L>0
$$

并且：

$$
n\bmod(n-L)=0
$$

那么：

$$
n-L
$$

就是字符串的最小周期长度。
</Callout>
