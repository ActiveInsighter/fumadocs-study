# 字符串算法方法论总结：双指针、反转、原地修改与 KMP

到这里，字符串模块的核心题型已经全部覆盖。

如果只把这些题记成八套代码，过一段时间很容易忘记；真正值得保留下来的，是它们背后的几种**可迁移方法**：

1. 把字符串看成可线性访问的字符序列；
2. 用双指针完成交换、压缩、扩容与分段处理；
3. 用“整体反转 + 局部反转”完成顺序变换；
4. 对模式匹配使用前缀函数与 KMP；
5. 对重复结构从“最长相等前后缀”和“周期”角度思考。

本篇把这些方法重新串成一张完整知识图谱。

---

## 1. 字符串首先是一段字符序列

字符串可以理解为有限字符序列：

$$
s=s_0s_1\cdots s_{n-1}
$$

算法层面最常见的操作包括：

- 读取某个字符；
- 交换两个字符；
- 删除一段字符；
- 插入或替换字符；
- 翻转区间；
- 查找模式串；
- 判断周期结构。

不同语言对字符串的实现不同，所以“字符串”与“字符数组”不能完全等同。

### C / C++ 中的区别

C 风格字符串依赖结尾的：

```text
'\0'
```

例如：

```cpp
char s[] = "abc";
```

实际存储近似为：

```text
'a' 'b' 'c' '\0'
```

而 C++ 的 `std::string` 是一个完整的容器类型，可以直接通过：

```cpp
s.size()
```

获取长度，并提供查找、拼接、截取等接口。

---

## 2. `string` 和 `vector<char>` 为什么感觉很像

算法视角下，两者都支持下标访问：

```cpp
s[i]
```

也都可以遍历、交换字符。

但 `std::string` 针对字符串场景提供了更多语义化操作，例如：

```cpp
+
find
substr
append
```

所以处理文本时，通常直接使用字符串类型更自然。

不过必须建立一个意识：

> 高层 API 只是把实现细节封装起来了，并没有让时间复杂度消失。

---

## 3. 库函数：可以用，但要知道自己省略了什么

算法训练阶段最容易出现两种极端：

### 极端一：任何库函数都不用

这会让代码变得不必要地冗长。

### 极端二：任何关键步骤都交给库函数

例如题目考察翻转字符串，却直接写：

```cpp
reverse(s.begin(), s.end());
```

虽然可能 AC，但核心算法实际上没有练到。

更合适的判断标准是：

> 如果库函数正好完成题目想考察的核心操作，学习阶段优先自己实现；如果只是辅助步骤，而且已经理解其实现和复杂度，可以放心使用。

<Callout title="复杂度必须跟着 API 一起思考" type="warning">
在循环中频繁调用 `erase`、`insert`、`substr` 等函数，常常会把看似线性的代码变成 $O(n^2)$。
</Callout>

---

## 4. 字符串第一核心：相向双指针

最基本的字符串反转模板：

```text
left →         ← right
```

每次交换：

```text
s[left] ↔ s[right]
```

然后：

```text
left++
right--
```

直到：

$$
left\ge right
$$

这就是“反转字符串”的核心。

时间复杂度：

$$
O(n)
$$

额外空间：

$$
O(1)
$$

这个模板还能继续扩展到：

- 分段反转；
- 单词反转；
- 字符串旋转；
- 回文判断；
- 两端收缩类问题。

---

## 5. 字符串第二核心：快慢指针

另一个常见结构是：

```text
slow 负责写
fast 负责读
```

当我们要：

- 删除多余空格；
- 原地压缩字符；
- 移除某类元素；

时，经常可以让 `fast` 扫描整个字符串，而 `slow` 只在保留字符时前进。

这与数组中的“移除元素”完全同源。

例如把：

```text
"  hello   world  "
```

压缩为：

```text
"hello world"
```

可以在一次线性扫描中完成，而不是反复调用 `erase`。

如果每次 `erase` 都需要整体移动后续字符，那么在循环中反复删除最坏可能达到：

$$
O(n^2)
$$

而快慢指针可以做到：

$$
O(n)
$$

---

## 6. 字符串第三核心：从后向前原地扩容

“替换数字”这一类题很重要，因为它代表一种更一般的数组填充技巧。

假设某个字符原来占：

$$
1
$$

个位置，替换后需要占：

$$
k
$$

个位置。

如果从前向后写，每次扩容都可能覆盖尚未处理的数据，或者导致大量元素移动。

更好的办法是：

<Steps>
<Step>

### 先计算最终长度

统计会被替换的字符数，算出扩容后总长度。

</Step>

<Step>

### 一次性扩容

直接把容器扩展到最终大小。

</Step>

<Step>

### 从后向前填写

旧指针指向原字符串末尾，新指针指向扩容后末尾。

因为新空间位于后方，所以不会覆盖仍未读取的数据。

</Step>
</Steps>

这个技巧不仅适用于字符串，也适用于很多数组原地扩张问题。

---

## 7. 固定长度分段处理：把规律写进循环步长

在“反转字符串 II”中，规则是：

> 每 $2k$ 个字符为一组，只翻转这一组前 $k$ 个字符。

一个容易写复杂的方式是逐字符遍历，再维护计数器判断“现在位于第几个 $2k$ 区间”。

更自然的方式是直接让循环变量每次移动：

$$
2k
$$

即：

```cpp
for (int i = 0; i < n; i += 2 * k) {
    ...
}
```

这背后的通用思想是：

> 当题目明确按固定块处理数据时，让循环本身就按“块”移动，而不是按元素移动后再额外判断块边界。

---

## 8. 反转不只是“倒过来”

反转最有价值的地方，并不是单独把一个字符串逆序，而是组合多个反转来改变局部与整体的相对顺序。

### 模式一：先整体，再局部

“翻转字符串里的单词”可以这样完成：

原字符串：

```text
the sky is blue
```

整体反转：

```text
eulb si yks eht
```

再分别反转每个单词：

```text
blue is sky the
```

于是单词顺序翻转，而单词内部字符恢复正常。

### 模式二：先局部，再整体

字符串旋转也可以用三次反转完成。

例如右旋 $k$ 位：

```text
abcdefg
```

若 $k=2$，希望得到：

```text
fgabcde
```

可以：

1. 反转整个字符串；
2. 反转前 $k$ 个字符；
3. 反转剩余字符。

本质是利用：

$$
(AB)^R=B^RA^R
$$

其中 $R$ 表示反转。

<Callout title="反转技巧的本质" type="info">
反转是一种“改变块顺序，但可以通过再次局部反转恢复块内部顺序”的工具。
</Callout>

## 9. KMP：解决模式串匹配中的重复比较

如果要在长度为 $n$ 的文本串中查找长度为 $m$ 的模式串，朴素匹配在最坏情况下可能达到：

$$
O(nm)
$$

KMP 的核心思想是：

> 失配后，不让文本指针回退，而是利用模式串自身已经匹配出的前后缀关系，决定模式串应该回退到哪里。

真正的核心不是 `next` 数组这个名字，而是：

$$
\text{最长相等真前缀与真后缀}
$$

定义前缀函数：

$$
\pi[i]
$$

表示：

```text
pattern[0 ... i]
```

的最长相等真前后缀长度。

失配时：

```cpp
j = pi[j - 1];
```

意味着：

> 已经匹配成功的后缀中，有一部分与模式串开头相同，因此这部分信息可以直接保留。

最终复杂度为：

$$
O(n+m)
$$

---

## 10. 前缀、后缀和边界必须定义准确

对于：

```text
abcab
```

真前缀包括：

```text
a
ab
abc
abca
```

真后缀包括：

```text
b
ab
cab
bcab
```

最长相等真前后缀：

```text
ab
```

长度为：

$$
2
$$

“真”非常重要：前缀和后缀都不能等于字符串自身。

否则任何字符串都可以拿自己与自己匹配，前缀函数就失去意义。

---

## 11. KMP 不只用于 `strStr`

学会前缀函数以后，至少要建立两个应用模型。

<Cards>
<Card title="模式匹配">
在文本串中查找模式串，失配时利用前缀函数回退模式指针。
</Card>
<Card title="字符串周期">
根据整个字符串的最长相等前后缀长度，求候选最小周期。
</Card>
</Cards>

对于长度为 $n$ 的字符串，如果：

$$
L=\pi[n-1]
$$

那么候选最小周期是：

$$
p=n-L
$$

若进一步满足：

$$
L>0
$$

以及：

$$
n\bmod p=0
$$

则字符串由长度为 $p$ 的子串重复构成。

这就是“重复的子字符串”与 KMP 的连接点。

---

## 12. 八篇字符串内容应该怎么串起来

本模块可以整理成下面这条主线：

```text
反转字符串
   ↓
相向双指针
   ↓
分段反转
   ↓
原地替换 / 后向填充
   ↓
去空格 + 整体反转 + 局部反转
   ↓
字符串旋转（三次反转）
   ↓
KMP 模式匹配
   ↓
KMP + 周期 = 重复子字符串
```

它们并不是八个互相独立的技巧，而是逐步增加约束：

- 双指针处理位置关系；
- 反转处理块顺序；
- 原地填充处理长度变化；
- KMP 处理模式之间的结构复用。

| 题型特征 | 首先想到 |
| --- | --- |
| 两端字符交换 | 相向双指针 |
| 删除 / 压缩字符 | 快慢指针 |

| 左旋 / 右旋字符串 | 三次反转 |
| 子串匹配 | KMP / 前缀函数 |
| 判断重复周期 | 前缀函数 + 整除条件 |

## 14. 复杂度意识贯穿整个模块

字符串题很容易写出“看起来只有一层循环”的代码，却隐藏二次复杂度。

例如：

```cpp
for (...) {
    s.erase(...);
}
```

如果每次 `erase` 都需要搬移 $O(n)$ 个字符，而调用次数也是 $O(n)$，总复杂度可能达到：

$$
O(n^2)
$$

同理：

- 循环中 `insert`；
- 频繁拼接不可变字符串；
- 反复切片；
- 暴力子串匹配；

都要特别注意隐藏成本。

<Callout title="看到字符串 API 时多问一句" type="warning">
这个操作是否需要移动、复制或重新扫描一整段字符？

如果答案是“需要”，再把它放进循环里时，就必须重新计算总复杂度。
</Callout>

## 15. 一套通用字符串解题流程

<Steps>
<Step>

### 明确字符串是否允许原地修改

不同语言的字符串可变性不同。

例如 Python 字符串不可变，很多“原地修改”实际需要转换为列表。

</Step>

<Step>

### 判断长度是否变化

如果替换后长度不变，优先考虑直接覆盖。

如果长度缩短，考虑快慢指针。

如果长度增长，考虑“预扩容 + 从后往前”。

</Step>

<Step>

### 看是否存在两端关系

如果操作天然涉及首尾、回文、反转、两端比较，优先考虑相向双指针。

</Step>

<Step>

### 看是否存在“块”的顺序变化

如果目标只是改变若干连续块的相对顺序，考虑反转组合。

</Step>

<Step>

### 看是否存在模式复用

如果涉及模式串匹配、最长相等前后缀、重复周期，考虑 KMP / 前缀函数。

</Step>

<Step>

### 最后检查库函数复杂度

确认 `erase`、`insert`、`find`、切片、拼接等调用不会把整体复杂度放大。

</Step>
</Steps>

## 16. 最小模板集合

真正需要熟练到可以手写的模板并不多。



### C++


```cpp
// 1. 区间反转 [left, right]
void reverseRange(string& s, int left, int right) {
    while (left < right) {
        swap(s[left++], s[right--]);
    }
}

// 2. KMP 前缀函数
vector<int> prefixFunction(const string& s) {
    vector<int> pi(s.size(), 0);
    for (int i = 1, j = 0; i < static_cast<int>(s.size()); ++i) {
        while (j > 0 && s[i] != s[j]) {
            j = pi[j - 1];
        }
        if (s[i] == s[j]) {
            ++j;
        }
        pi[i] = j;
    }
    return pi;
}
```



### Java


```java
// 1. 区间反转 [left, right]
static void reverseRange(char[] s, int left, int right) {
    while (left < right) {
        char temp = s[left];
        s[left++] = s[right];
        s[right--] = temp;
    }
}

// 2. KMP 前缀函数
static int[] prefixFunction(String s) {
    int[] pi = new int[s.length()];

    for (int i = 1, j = 0; i < s.length(); i++) {
        while (j > 0 && s.charAt(i) != s.charAt(j)) {
            j = pi[j - 1];
        }
        if (s.charAt(i) == s.charAt(j)) {
            j++;
        }
        pi[i] = j;
    }

    return pi;
}
```



### Python


```python
# 1. 区间反转 [left, right]
def reverse_range(chars: list[str], left: int, right: int) -> None:
    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1


# 2. KMP 前缀函数
def prefix_function(s: str) -> list[int]:
    pi = [0] * len(s)
    j = 0

    for i in range(1, len(s)):
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]

        if s[i] == s[j]:
            j += 1

        pi[i] = j

    return pi
```

## 18. 学完这一章应该具备什么能力

不是记住每一道题的代码，而是看到陌生题时能够快速归类：

- “这是删除问题” → 快慢指针；
- “这是两端交换” → 相向双指针；
- “这是块顺序变化” → 反转组合；
- “这是长度扩张” → 从后向前填；
- “这是模式匹配” → KMP；
- “这是周期结构” → 最长相等前后缀 + 整除。

<Callout title="本章真正的目标" type="success">
字符串算法的关键不是熟悉多少 API，而是能够把字符序列的变化抽象成：

**指针移动、区间反转、结构复用和复杂度控制。**

当这些方法形成条件反射后，大量字符串题就会从“记忆题”变成“模型题”。
</Callout>
