# 二叉树的最小深度：为什么不能直接把 max 改成 min

> LeetCode 111 · Minimum Depth of Binary Tree

[题目链接](https://leetcode.cn/problems/minimum-depth-of-binary-tree/)

给定一棵二叉树，求它的**最小深度**。

最小深度是从根节点到最近**叶子节点**的最短路径所包含的节点数。

例如：

![111. 二叉树的最小深度](https://file1.kamacoder.com/i/algo/2021020315582586.png)

上图中最近的叶子节点是 `9`，所以最小深度为 `2`。

这道题和上一节“最大深度”看起来只有一个字不同，但它有一个非常典型的陷阱：

```text
最小深度不是“从根走到空指针的最短距离”，
而是“从根走到叶子节点的最短距离”。
```

<Callout title="核心陷阱" type="warn">

不能把最大深度中的：

```cpp
max(leftDepth, rightDepth)
```

机械替换成：

```cpp
min(leftDepth, rightDepth)
```

因为空子树返回 `0`，而“空子树”并不是一条合法的根到叶路径。

</Callout>

## 1. 先把叶子节点定义钉死

叶子节点必须满足：

```text
左孩子为空 AND 右孩子为空
```

代码就是：

```cpp
node->left == nullptr && node->right == nullptr
```

例如：

```text
1
 \
  2
   \
    3
```

节点 `1` 的左孩子为空，但它不是叶子；节点 `2` 也不是叶子；只有节点 `3` 是叶子。

因此这棵树的最小深度是 `3`，绝不可能是 `1`。

原题中最容易误解的情况正是这种单侧子树：

![最小深度误区](https://file1.kamacoder.com/i/algo/111.%E4%BA%8C%E5%8F%89%E6%A0%91%E7%9A%84%E6%9C%80%E5%B0%8F%E6%B7%B1%E5%BA%A6.png)

## 2. 为什么最大深度可以直接 max，最小深度却不能直接 min

最大深度的递推关系是：

$$
H(u)=1+\max(H(u.left),H(u.right))
$$

即使某一侧为空，它返回 `0`，`max` 仍然会选择存在的那一侧，因此不会出错。

最小深度则不同。

假设节点只有右子树：

```text
leftDepth = 0
rightDepth = 2
```

如果写成：

```cpp
1 + min(leftDepth, rightDepth)
```

就会得到：

$$
1+\min(0,2)=1
$$

这相当于把“不存在的左路径”错误地当成了最短路径。

所以，最小深度真正的递推关系应该分情况：

$$
D(u)=
\begin{cases}
0, & u=\varnothing \\
1+D(u.right), & u.left=\varnothing,\ u.right\neq\varnothing \\
1+D(u.left), & u.left\neq\varnothing,\ u.right=\varnothing \\
1+\min(D(u.left),D(u.right)), & \text{左右子树都存在}
\end{cases}
$$

<Cards>
  <Card title="最大深度">空分支不会干扰 `max`，所以可以直接比较。</Card>
  <Card title="最小深度">空分支会把 `min` 拉成 `0`，所以必须排除无效路径。</Card>
  <Card title="真正考点">不是 `max` 和 `min` 的区别，而是“候选路径是否合法”。</Card>
</Cards>

## 3. 解法一：后序递归

定义：

```cpp
int minDepth(TreeNode* root)
```

它表示：

> 返回以 `root` 为根的子树，从当前根节点到最近叶子节点的最短节点数。

### 递归三步法

### 1. 明确参数与返回值

参数是当前节点 `root`，返回当前子树的最小深度。

### 2. 明确终止条件

空树没有节点：

```cpp
if (root == nullptr) return 0;
```

### 3. 明确单层逻辑

先递归得到左右子树的最小深度，再判断两侧是否真正存在。

```cpp title="LeetCode 111 · 后序递归"
class Solution {
public:
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        int leftDepth = minDepth(root->left);
        int rightDepth = minDepth(root->right);

        if (root->left == nullptr && root->right != nullptr) {
            return rightDepth + 1;
        }

        if (root->left != nullptr && root->right == nullptr) {
            return leftDepth + 1;
        }

        return min(leftDepth, rightDepth) + 1;
    }
};
```

处理顺序是：

```text
左 → 右 → 中
```

因此本质上仍然是**后序遍历思想**。

## 4. 更紧凑的统一写法

因为非空子树的最小深度至少是 `1`，所以 `0` 可以看作“这一侧不存在子树”的特殊标记。

于是可以写成：

```cpp title="推荐记忆版"
class Solution {
public:
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        int left = minDepth(root->left);
        int right = minDepth(root->right);

        if (left == 0) return right + 1;
        if (right == 0) return left + 1;

        return min(left, right) + 1;
    }
};
```

这段代码很值得理解：

```text
left == 0
```

并不是说“左边有一条长度为 0 的合法路径”，而是说：

```text
左边不存在可以通向叶子的子树
```

因此必须选择右边。

<Callout title="递归设计的重要经验" type="idea">

递归返回值中的数字不一定都代表“可直接参与比较的真实答案”。

写 `min`、`max` 之前，要先确认每个状态是否合法。这个思想在动态规划里同样非常重要。

</Callout>

## 5. 解法二：前序 DFS

也可以从根节点开始向下传递当前深度。

此时函数可以定义为：

```cpp
void dfs(TreeNode* node, int depth)
```

其中 `depth` 表示当前节点的深度。

只有真正遇到叶子时，才更新最小值：

```cpp title="前序 DFS"
class Solution {
private:
    int answer = INT_MAX;

    void dfs(TreeNode* node, int depth) {
        if (node == nullptr) return;

        if (node->left == nullptr && node->right == nullptr) {
            answer = min(answer, depth);
            return;
        }

        if (node->left) {
            dfs(node->left, depth + 1);
        }
        if (node->right) {
            dfs(node->right, depth + 1);
        }
    }

public:
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        dfs(root, 1);
        return answer;
    }
};
```

这里的信息流和后序递归不同：

```text
后序递归：孩子 → 父节点，向上返回答案
前序 DFS：父节点 → 孩子，向下携带深度
```

## 6. DFS 还能做简单剪枝

如果当前已经找到最小深度 `answer`，而当前深度已经满足：

```text
depth >= answer
```

那么继续向下只会得到更长的路径，不可能改善答案。

因此可以提前停止：

```cpp
if (depth >= answer) return;
```

不过本题还有一种更加自然的方法：**BFS**。

## 7. 解法三：层序 BFS

BFS 按照深度从小到大访问节点：

```text
第 1 层
↓
第 2 层
↓
第 3 层
↓
...
```

因此：

> 第一个遇到的叶子节点，一定就是离根最近的叶子节点。

这使得 BFS 可以在找到第一个叶子时立即返回。

```cpp title="层序 BFS · 最符合题意"
class Solution {
public:
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;

        while (!q.empty()) {
            int size = q.size();
            ++depth;

            for (int i = 0; i < size; ++i) {
                TreeNode* node = q.front();
                q.pop();

                if (node->left == nullptr && node->right == nullptr) {
                    return depth;
                }

                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }

        return depth;
    }
};
```

## 8. 为什么 BFS 第一次遇到叶子就一定是最优解

BFS 的队列顺序保证：

```text
深度 d 的所有节点
一定先于
深度 d + 1 的所有节点被处理
```

如果在第 `d` 层第一次发现叶子，那么深度小于 `d` 的节点此前都已经检查过，而且都不是叶子。

因此：

$$
\text{minDepth}=d
$$

这其实就是**无权图最短路**思想在树上的一个特例。

把树看成图：

- 根节点是起点；
- 所有叶子节点构成目标集合；
- 每条父子边权重相同。

问题就变成：

```text
从起点到任意目标节点的最短距离
```

BFS 天然适合解决这种问题。

## 9. DFS 与 BFS 如何选择

| 方法 | 核心状态 | 最坏时间复杂度 | 额外空间 | 特点 |
| --- | --- | --- | --- | --- |
| 后序递归 | 子树最小深度 | $O(n)$ | $O(h)$ | 最适合训练递归返回值 |
| 前序 DFS | 当前深度 + 全局最优 | $O(n)$ | $O(h)$ | 可做深度剪枝 |
| 层序 BFS | 当前层数 | $O(n)$ | $O(w)$ | 第一个叶子即可返回 |

其中：

- $h$ 为树高；
- $w$ 为树的最大层宽。

对于“最近、最短、第一个到达”这类关键词，通常优先考虑 BFS。

## 10. 高频错误一：把空节点当作终点

错误理解：

```text
走到 nullptr 就完成一条路径
```

正确理解：

```text
走到叶子节点才完成一条根到叶路径
```

空指针只是说明某个孩子不存在。

## 11. 高频错误二：叶子判断用了 OR

错误：

```cpp
if (!node->left || !node->right)
```

这会把只有一个孩子的节点也当成叶子。

正确：

```cpp
if (!node->left && !node->right)
```

记忆：

```text
叶子 = 左空 AND 右空
```

## 12. 高频错误三：机械套用最大深度模板

### 最大深度

```cpp
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    return max(maxDepth(root->left),
               maxDepth(root->right)) + 1;
}
```

空分支的 `0` 不会干扰最大值。

### 最小深度

```cpp
int minDepth(TreeNode* root) {
    if (!root) return 0;

    int left = minDepth(root->left);
    int right = minDepth(root->right);

    if (left == 0) return right + 1;
    if (right == 0) return left + 1;

    return min(left, right) + 1;
}
```

必须先排除不存在的分支。

## 13. 边界用例检查

### 空树

```text
root = null
```

答案：`0`。

### 单节点树

```text
1
```

根节点本身就是叶子，答案：`1`。

### 单链树

```text
1
 \
  2
   \
    3
```

答案：`3`。

### 一侧浅、一侧深

```text
      1
     / \
    2   3
       /
      4
     /
    5
```

节点 `2` 是最近叶子，因此答案：`2`。

## 14. 从本题抽象出的通用模型

```text
题目要求“最短”
        ↓
先明确真正的终点状态
        ↓
只让合法路径参与比较
        ↓
如果状态天然按距离递增扩展
        ↓
优先考虑 BFS
```

这一思路会迁移到：

- 根到叶路径问题；
- 最近目标节点；
- 最短层数；
- 无权图最短路；
- 多源 BFS。

<Callout title="一句话记忆" type="success">

**最小深度的难点不是求 `min`，而是保证参与 `min` 的路径真的到达了叶子。**

递归时排除空分支；BFS 时第一个遇到的叶子就是答案。

</Callout>

impl Solution {
