# 二叉搜索树的最近公共祖先：用有序性把回溯问题变成单路搜索

> LeetCode 235 · Lowest Common Ancestor of a Binary Search Tree

[题目链接](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/)

给定一棵二叉搜索树（BST）以及其中两个不同节点 `p`、`q`，求它们的最近公共祖先（LCA）。题目保证 `p`、`q` 都存在于树中，且所有节点值唯一。

![二叉搜索树的最近公共祖先](https://file1.kamacoder.com/i/algo/20201018172243602.png)

<Callout title="本题真正的升级点" type="idea">

上一题“普通二叉树的最近公共祖先”需要**后序回溯 + 左右子树信息合并**；而这道题加入 BST 条件后，问题发生了本质变化：

> **不再需要同时搜索左右子树，只要利用大小关系判断目标节点位于哪一侧，就能一路向下。**

这正是“数据结构的额外性质，如何直接降低搜索成本”的典型例子。

</Callout>

## 1. 先回顾：普通二叉树为什么必须回溯

对于普通二叉树，当前节点无法根据节点值判断 `p`、`q` 在哪边。

因此只能分别询问左右子树：

```text
left  = 左子树是否找到 p / q / LCA
right = 右子树是否找到 p / q / LCA
```

然后再由当前节点合并信息。

这是一种典型的：

```text
搜索整棵相关子树 → 自底向上汇总答案
```

但 BST 不一样。

## 2. BST 的有序性给了我们“方向”

二叉搜索树满足：

```text
左子树所有节点值 < 当前节点值 < 右子树所有节点值
```

设当前节点为 `cur`。

如果：

```text
p.val < cur.val
q.val < cur.val
```

说明 `p`、`q` 都在 `cur` 的左子树中。

所以 LCA 也一定在左边，当前节点不可能是最近公共祖先。

同理，如果：

```text
p.val > cur.val
q.val > cur.val
```

那么两者都在右子树中，只需要继续向右。

因此每到一个节点，我们只有三种状态：

| 当前节点与 `p`、`q` 的关系 | 下一步 |
| --- | --- |
| `cur` 同时大于 `p`、`q` | 去左子树 |
| `cur` 同时小于 `p`、`q` | 去右子树 |
| 其他情况 | 当前节点就是 LCA |

<Callout title="一句话记忆" type="success">

**两个目标在同一侧，就继续往那一侧走；一旦两个目标被当前节点“分开”，当前节点就是最近公共祖先。**

</Callout>

## 3. 为什么“落在两者之间”就一定是公共祖先

假设为了方便有：

```text
p.val < q.val
```

如果当前节点满足：

$$
p.val \le cur.val \le q.val
$$

那么会出现三种情况：

1. `cur.val == p.val`：`cur` 就是 `p`；
2. `cur.val == q.val`：`cur` 就是 `q`；
3. `p.val < cur.val < q.val`：`p` 在左子树，`q` 在右子树。

无论是哪一种，`cur` 都同时是 `p`、`q` 的祖先。

而且这是从根向下搜索时**第一次**出现这种关系，所以它一定是最近的那个公共祖先。

![BST 中第一次落入目标区间的节点就是 LCA](https://file1.kamacoder.com/i/algo/20220926164214.png)

### 3.1 为什么不需要显式排序 `p`、`q`

当然可以先写：

```cpp
int low = min(p->val, q->val);
int high = max(p->val, q->val);
```

然后判断：

```cpp
if (root->val < low) ...
if (root->val > high) ...
```

但其实并不是必须的。

直接判断：

```cpp
root->val > p->val && root->val > q->val
```

以及：

```cpp
root->val < p->val && root->val < q->val
```

就天然兼容 `p`、`q` 的大小顺序。

## 4. 为什么第一次“分叉”就是最近公共祖先

这一步值得单独证明。

假设从根节点开始搜索。

只要 `p`、`q` 都在当前节点同一侧，我们就继续向下：

```text
cur
 └── 同一侧子树
      └── 更深节点
```

因此此前经过的每个节点虽然可能也是公共祖先，但都不可能是“最近”的，因为它们下面仍然存在一个同时包含 `p` 和 `q` 的子树。

当第一次来到某个节点 `x`，发现：

```text
p 和 q 不再位于 x 的同一侧
```

说明：

- 要么 `p`、`q` 分处左右子树；
- 要么 `x` 本身就是 `p` 或 `q`。

从 `x` 再往左，会丢掉右侧那个目标；往右则会丢掉左侧那个目标。

因此 `x` 已经是还能同时覆盖两个目标的最深节点，也就是 LCA。

![BST 最近公共祖先的单路搜索过程](https://file1.kamacoder.com/i/algo/20220926165141.png)

<Callout title="和普通二叉树 LCA 的本质区别" type="info">

普通二叉树：

```text
不知道目标在哪 → 左右都搜 → 回溯合并
```

二叉搜索树：

```text
知道目标在哪 → 每次只走一边 → 自顶向下直接定位
```

所以同样是 LCA，算法结构完全不同。

</Callout>

## 5. 递归法：函数返回值就是答案

递归函数可以定义为：

> 在以 `root` 为根的 BST 中寻找 `p`、`q` 的最近公共祖先。

### 5.1 终止条件

更稳健的写法保留空节点判断：

```cpp
if (root == nullptr) {
    return nullptr;
}
```

虽然题目保证 `p`、`q` 一定存在，但这个判断能让函数语义更完整，也方便代码迁移到其他题目。

### 5.2 单层逻辑

如果当前值比两个目标都大：

```cpp
if (root->val > p->val && root->val > q->val) {
    return lowestCommonAncestor(root->left, p, q);
}
```

说明两个目标都在左侧。

如果当前值比两个目标都小：

```cpp
if (root->val < p->val && root->val < q->val) {
    return lowestCommonAncestor(root->right, p, q);
}
```

说明两个目标都在右侧。

剩余情况就是：

```cpp
return root;
```

也就是当前节点刚好把两个目标分开，或者当前节点本身就是其中一个目标。

### 5.3 推荐递归实现

```cpp title="C++ · 递归"
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr) {
            return nullptr;
        }

        if (root->val > p->val && root->val > q->val) {
            return lowestCommonAncestor(root->left, p, q);
        }

        if (root->val < p->val && root->val < q->val) {
            return lowestCommonAncestor(root->right, p, q);
        }

        return root;
    }
};
```

## 6. 这里为什么不是后序遍历

这题很容易因为刚学完普通二叉树 LCA，而机械地继续套“后序遍历”。

但实际上本题没有：

```cpp
left = dfs(root->left);
right = dfs(root->right);
```

这样的左右结果合并过程。

每一层只会选择：

```text
左边
或
右边
或
当前节点就是答案
```

因此它本质上是**BST 上的定向搜索**，而不是“先遍历左右再处理根”的传统后序模型。

<Callout title="判断遍历顺序是否重要" type="idea">

如果一个递归节点必须等待**左右子树的返回结果**才能决策，前/中/后序往往非常重要。

如果当前节点已经能根据自身信息决定**只进入一棵子树**，它更接近“搜索路径”，而不是完整遍历。

</Callout>

## 7. 迭代法：这题最自然的写法

由于递归每层只进入一个孩子，所以完全可以直接改成 `while`。

```cpp title="C++ · 迭代"
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        TreeNode* cur = root;

        while (cur != nullptr) {
            if (cur->val > p->val && cur->val > q->val) {
                cur = cur->left;
            } else if (cur->val < p->val && cur->val < q->val) {
                cur = cur->right;
            } else {
                return cur;
            }
        }

        return nullptr;
    }
};
```

这段代码与普通 BST 搜索几乎完全一致：

```text
目标都小 → 左
目标都大 → 右
目标分叉 → 返回
```

## 8. 用区间写法理解会更统一

如果先定义：

```cpp
int low = min(p->val, q->val);
int high = max(p->val, q->val);
```

那么逻辑可以写成：

```text
cur.val < low   → 两个目标都在右边
cur.val > high  → 两个目标都在左边
low <= cur.val <= high → 当前节点就是 LCA
```

这相当于在 BST 中寻找：

> **从根开始，第一个落入闭区间 `[low, high]` 的节点。**

这个视角非常简洁。

```cpp title="C++ · 区间写法"
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        int low = std::min(p->val, q->val);
        int high = std::max(p->val, q->val);

        while (root != nullptr) {
            if (root->val < low) {
                root = root->right;
            } else if (root->val > high) {
                root = root->left;
            } else {
                return root;
            }
        }

        return nullptr;
    }
};
```

## 9. 手动模拟一次

仍以经典 BST 为例：

```text
        6
      /   \
     2     8
    / \   / \
   0   4 7   9
      / \
     3   5
```

### 9.1 `p = 2, q = 8`

从根 `6` 开始：

```text
2 < 6 < 8
```

两个目标被 `6` 分开，因此直接返回 `6`。

### 9.2 `p = 2, q = 4`

根节点 `6`：

```text
2 < 6
4 < 6
```

两者都在左子树，走到 `2`。

此时：

```text
cur == p
```

`2` 已经落入 `[2, 4]`，所以答案是 `2`。

### 9.3 `p = 3, q = 5`

搜索路径：

```text
6 → 左
2 → 右
4 → 分叉
```

因此 LCA 是 `4`。

## 10. 为什么这题只搜索一条边

这是一个非常重要的递归识别能力。

### 搜索一条路径

```cpp
if (条件) {
    return dfs(root->left);
}
return dfs(root->right);
```

特征：当前节点已经知道答案只可能在哪一边。

### 搜索整个树

```cpp
TreeNode* left = dfs(root->left);
TreeNode* right = dfs(root->right);

// 合并 left 和 right
```

特征：必须获得两边的信息才能判断。

本题显然属于第一类。

<Callout title="本题最值得带走的能力" type="success">

看到 BST 后，不要只是想到“中序遍历有序”。

BST 还提供了更直接的能力：

> **根据大小关系剪掉整棵不可能包含答案的子树。**

这比“遍历出有序序列再处理”更进一步。

</Callout>

## 11. 正确性证明

设当前节点为 `x`。

### 情况一：`x.val > p.val` 且 `x.val > q.val`

根据 BST 性质，`p`、`q` 都在 `x` 左子树，所以它们的 LCA 也一定在左子树。

因此向左搜索不会丢失答案。

### 情况二：`x.val < p.val` 且 `x.val < q.val`

同理，两个目标都在右子树，向右搜索安全。

### 情况三：其余情况

两个目标不在 `x` 的同一侧。

此时要么：

- 一个在左，一个在右；
- `x == p`；
- `x == q`。

所以 `x` 是公共祖先。

而算法是从根一路向下到达 `x` 的，之前每个祖先都还能继续进入一个同时包含两个目标的子树，因此 `x` 是最深的公共祖先。

故算法正确。

## 12. 复杂度分析

设树高为 $h$。

算法每层只访问一个节点，因此：

$$
T(h)=O(h)
$$

空间复杂度：

- 递归法：$O(h)$，来自递归调用栈；
- 迭代法：$O(1)$。

如果 BST 较平衡：

$$
h=O(\log n)
$$

如果 BST 极度退化成链表：

$$
h=O(n)
$$

所以不能无条件写成 $O(\log n)$。

<Callout title="复杂度最容易写错的地方" type="warning">

“这是二叉搜索树”并不代表树一定平衡。

普通 BST 最坏仍可能退化成链表，因此搜索、插入、LCA 等操作最坏复杂度都可能达到 $O(n)$。

</Callout>

## 13. 常见错误

<Accordions type="multiple">
<Accordion title="错误 1：仍然照搬普通二叉树 LCA，左右子树都递归">

这样通常也能做对，但浪费了 BST 的有序性。

本题最重要的训练目标正是：根据大小关系只搜索一条路径。

</Accordion>

<Accordion title="错误 2：只和 p 比较，不和 q 比较">

例如：

```cpp
if (root->val > p->val) {
    root = root->left;
}
```

这是错误的。

`p` 可能在左边，但 `q` 已经在右边，此时当前节点恰恰就是 LCA。

必须判断两个目标是否**同时**位于同一侧。

</Accordion>

<Accordion title="错误 3：认为 LCA 不能等于 p 或 q">

题目允许节点是自己的祖先。

如果 `p` 恰好是 `q` 的祖先，那么答案就是 `p`。

这也是为什么“当前节点落入目标区间”时可以直接返回。

</Accordion>

<Accordion title="错误 4：递归时写成 root->left = ...">

LCA 查询并不需要修改树结构。

应该写：

```cpp
return lowestCommonAncestor(root->left, p, q);
```

而不是：

```cpp
return root->left = lowestCommonAncestor(root->left, p, q);
```

后者虽然在某些输入下看起来结果还能返回正确节点，但它在语义上修改了原树，是不必要且危险的副作用。

</Accordion>
</Accordions>

## 14. 与普通二叉树 LCA 对比

| 维度 | 普通二叉树 LCA | BST LCA |
| --- | --- | --- |
| 能否判断目标方向 | 不能 | 能 |
| 是否需要同时搜索两侧 | 通常需要 | 不需要 |
| 核心结构 | 后序返回值合并 | 单路定向搜索 |
| 是否依赖回溯 | 是 | 否 |
| 时间复杂度 | $O(n)$ | $O(h)$ |
| 迭代实现 | 不自然 | 非常自然 |

这两题放在一起学习价值很高：

> **同一个问题，在数据结构多出“有序性”之后，算法可以从全树搜索降为路径搜索。**

## 15. 模板抽象：BST 中寻找“分界点”

这道题可以抽象为：

```cpp
while (root != nullptr) {
    if (两个目标都在左侧) {
        root = root->left;
    } else if (两个目标都在右侧) {
        root = root->right;
    } else {
        return root;
    }
}
```

这种“找分界点”的思想还会出现在：

- BST 中按值域寻找节点；
- 查找某个区间与搜索路径的第一次交汇点；
- 利用有序性剪枝的递归问题。

```rust title="Rust"
use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn lowest_common_ancestor(
        mut root: Option<Rc<RefCell<TreeNode>>>,
        p: Option<Rc<RefCell<TreeNode>>>,
        q: Option<Rc<RefCell<TreeNode>>>,
    ) -> Option<Rc<RefCell<TreeNode>>> {

            } else if val < p_val && val < q_val {
                root = node.borrow().right.clone();
            } else {
                return root;
            }
        }

        None
    }
}
```
