# 二叉树的迭代遍历：用栈手动模拟递归

递归遍历看起来非常自然，但它背后并不是特殊机制：每次递归调用都依赖**函数调用栈**保存现场。

既然递归本质上使用了栈，我们就可以自己维护一个显式栈，从而写出非递归版本。

<Callout title="这一篇真正要理解什么？" type="idea">

重点不是记三段代码，而是分清两个动作：

- **访问（visit）**：为了继续寻找后续节点而到达某个节点；
- **处理（process）**：真正把该节点加入答案，或执行题目要求的操作。

前序遍历中二者几乎同步，所以代码简单；中序遍历中二者明显不同，因此需要额外的 `cur` 指针。

</Callout>

## 1. 为什么显式栈可以替代递归

递归调用大致会保存：

```text
当前函数参数
当前局部变量
返回地址
下一步执行位置
```

例如：

```cpp
traversal(root->left);
process(root);
traversal(root->right);
```

当程序进入左子树时，当前节点并没有丢失，而是被调用栈记住。等左子树返回后，程序可以继续执行 `process(root)`。

迭代法所做的事情，就是把“哪些节点以后还要回来处理”显式保存到 `stack` 中。

## 2. 前序遍历：最直接的栈模拟

前序顺序为：

```text
根 → 左 → 右
```

因为根节点一被取出就可以立即处理，所以“访问”和“处理”同步发生。

### 核心过程

1. 根节点入栈；
2. 弹出栈顶节点并处理；
3. 先压入右孩子；
4. 再压入左孩子；
5. 重复直到栈为空。

为什么必须**先右后左**？

因为栈是后进先出：

```text
先压右，再压左
      ↓
左节点位于栈顶
      ↓
下一次先访问左节点
```

![二叉树前序遍历（迭代法）](https://file1.kamacoder.com/i/algo/%E4%BA%8C%E5%8F%89%E6%A0%91%E5%89%8D%E5%BA%8F%E9%81%8D%E5%8E%86%EF%BC%88%E8%BF%AD%E4%BB%A3%E6%B3%95%EF%BC%89.gif)

```cpp title="LeetCode 144 · 前序遍历（迭代）"
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        if (root == nullptr) return result;

        stack<TreeNode*> st;
        st.push(root);

        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();

            result.push_back(node->val);      // 根

            // 栈是 LIFO，所以顺序与真正访问顺序相反
            if (node->right != nullptr) st.push(node->right);
            if (node->left != nullptr) st.push(node->left);
        }

        return result;
    }
};
```

### 用一棵树手动模拟

```text
        1
       / \
      2   3
     / \
    4   5
```

栈状态可以写成：

| 步骤 | 弹出节点 | 处理结果 | 入栈 | 栈顶 → 栈底 |
| --- | ---: | --- | --- | --- |
| 初始 | - | `[]` | `1` | `1` |
| 1 | `1` | `[1]` | `3, 2` | `2, 3` |
| 2 | `2` | `[1,2]` | `5, 4` | `4, 5, 3` |
| 3 | `4` | `[1,2,4]` | - | `5, 3` |
| 4 | `5` | `[1,2,4,5]` | - | `3` |
| 5 | `3` | `[1,2,4,5,3]` | - | 空 |

最终得到：

```text
1 → 2 → 4 → 5 → 3
```

## 3. 中序遍历：为什么不能只改入栈顺序

中序顺序为：

```text
左 → 根 → 右
```

看起来似乎也只是顺序变化，但它和前序迭代有一个关键区别。

假设当前位于根节点 `1`：

```text
        1
       / \
      2   3
     / \
    4   5
```

为了找到最先应该处理的节点，我们必须先：

```text
访问 1
→ 访问 2
→ 访问 4
```

但真正的处理顺序却是：

```text
处理 4
→ 处理 2
→ 处理 5
→ 处理 1
→ 处理 3
```

所以：

> **中序遍历中，“访问到某节点”和“现在就处理某节点”不是一回事。**

显式栈负责保存“以后还要回来处理的祖先节点”，`cur` 指针负责不断向左寻找。

![二叉树中序遍历（迭代法）](https://file1.kamacoder.com/i/algo/%E4%BA%8C%E5%8F%89%E6%A0%91%E4%B8%AD%E5%BA%8F%E9%81%8D%E5%8E%86%EF%BC%88%E8%BF%AD%E4%BB%A3%E6%B3%95%EF%BC%89.gif)

### 中序遍历的固定模板

```cpp title="LeetCode 94 · 中序遍历（迭代）"
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        TreeNode* cur = root;

        while (cur != nullptr || !st.empty()) {
            // 1. 一路向左，并把沿途节点保存起来
            while (cur != nullptr) {
                st.push(cur);
                cur = cur->left;
            }

            // 2. 左侧已经走到底，栈顶就是当前该处理的节点
            cur = st.top();
            st.pop();
            result.push_back(cur->val);

            // 3. 转向右子树；随后又会继续向左走到底
            cur = cur->right;
        }

        return result;
    }
};
```

代码中最重要的是外层循环条件：

```cpp
while (cur != nullptr || !st.empty())
```

不能只写：

```cpp
while (cur != nullptr)
```

因为 `cur == nullptr` 只代表“当前已经向左走到底”，栈中可能还有大量祖先节点没有处理。

### 中序遍历可以背成一句动作口诀

```text
左到底 → 弹栈处理 → 转向右边 → 再左到底
```

这句话比死记具体变量名更有用。

## 4. 后序遍历：由“根右左”反转得到“左右根”

后序顺序是：

```text
左 → 右 → 根
```

如果直接用一个栈精确模拟“什么时候第二次回到节点”，代码会比前序复杂很多。

但可以利用一个非常漂亮的变换：

```text
目标：左 → 右 → 根
反转：根 → 右 → 左
```

而 `根 → 右 → 左` 与前序遍历高度相似，只需要调整孩子入栈顺序。

![前序到后序](https://file1.kamacoder.com/i/algo/20200808200338924.png)

具体步骤：

1. 按 `根 → 右 → 左` 生成结果；
2. 最后整体反转；
3. 得到 `左 → 右 → 根`。

```cpp title="LeetCode 145 · 后序遍历（迭代）"
class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> result;
        if (root == nullptr) return result;

        stack<TreeNode*> st;
        st.push(root);

        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();

            result.push_back(node->val);      // 先得到 根 → 右 → 左

            if (node->left != nullptr) st.push(node->left);
            if (node->right != nullptr) st.push(node->right);
        }

        reverse(result.begin(), result.end());
        return result;
    }
};
```

注意这里和前序遍历刚好相反：

| 目标 | 孩子压栈顺序 | 实际弹栈访问顺序 |
| --- | --- | --- |
| 前序 `根左右` | 先右、后左 | 根左右 |
| 构造后序的逆序 `根右左` | 先左、后右 | 根右左 |

最后反转：

```text
根右左
  ↓ reverse
左右根
```

<Callout title="这不是唯一的后序迭代写法" type="info">

还可以使用“双栈法”、记录 `prev` 指针、给节点增加访问状态等方法直接完成后序遍历。这里先掌握最简洁的“根右左 + 反转”。下一篇统一迭代法会进一步解决三种遍历代码风格不统一的问题。

</Callout>

## 5. 三种迭代写法为什么看起来不统一

递归版本非常整齐：

```text
前序：根 左 右
中序：左 根 右
后序：左 右 根
```

但普通迭代版本中：

- 前序：一个栈即可直接处理；
- 中序：需要 `cur + stack`；
- 后序：常用变换后反转。

根本原因就在于：**节点的“访问顺序”和“处理顺序”并不总是一致。**

### 前序遍历

```text
访问根 → 处理根
```

节点第一次遇到时就可以处理，所以逻辑最直接。

### 中序遍历

```text
第一次访问根
→ 先去左子树
→ 再回来处理根
```

节点需要“先保存，之后再处理”。

### 后序遍历

```text
第一次访问根
→ 左子树
→ 右子树
→ 最后才能处理根
```

同一个节点甚至需要等两棵子树都结束后才能处理，因此若直接模拟递归现场，状态会更多。

## 6. 从递归代码反推中序迭代

中序递归代码：

```cpp
void inorder(TreeNode* root) {
    if (root == nullptr) return;

    inorder(root->left);
    process(root);
    inorder(root->right);
}
```

迭代法可以把它逐句翻译：

| 递归语义 | 迭代动作 |
| --- | --- |
| `inorder(root->left)` | 不断 `cur = cur->left`，同时把祖先压栈 |
| 左子树返回 | 从栈中弹出最近的祖先 |
| `process(root)` | 处理弹出的节点 |
| `inorder(root->right)` | `cur = cur->right` |

这也是理解中序迭代最可靠的方法，而不是把它当成一段完全陌生的模板。

## 7. 复杂度分析

设二叉树有 $n$ 个节点，高度为 $h$。

三种迭代遍历中，每个节点都只会进行常数次入栈、出栈或访问，因此：

$$
T(n)=O(n)
$$

空间复杂度取决于栈中同时保存的节点数量。

通常可以写成：

$$
S(n)=O(h)
$$

对于不同树形：

| 树形 | 高度 | 栈空间 |
| --- | ---: | ---: |
| 平衡二叉树 | $O(\log n)$ | 通常 $O(\log n)$ |
| 退化链状树 | $O(n)$ | 最坏 $O(n)$ |

需要注意：本文“后序 = 根右左 + 反转”的实现除了栈之外，还保存了长度为 $n$ 的输出数组；如果题目把返回结果本身不计入额外空间，则辅助栈仍按其峰值分析。

## 8. 常见错误

### 错误 1：前序遍历先压左孩子

如果这样写：

```cpp
st.push(node->left);
st.push(node->right);
```

因为栈后进先出，右孩子会先被访问，结果变成 `根 → 右 → 左`。

### 错误 2：把空节点直接压栈，却没有统一的空节点处理策略

普通写法最简单的原则是：

```cpp
if (node->left) st.push(node->left);
```

即空节点不入栈。

### 错误 3：中序循环条件只检查 `cur`

```cpp
while (cur != nullptr)  // 错误：可能提前退出
```

正确条件必须同时考虑栈里是否还有待处理节点：

```cpp
while (cur != nullptr || !st.empty())
```

### 错误 4：后序反转前生成的顺序写错

想得到：

```text
左 → 右 → 根
```

反转前必须是：

```text
根 → 右 → 左
```

不是普通前序的 `根 → 左 → 右`。

## 9. 三种迭代遍历速查

| 遍历 | 顺序 | 核心结构 | 关键动作 |
| --- | --- | --- | --- |
| 前序 | 根 → 左 → 右 | `stack` | 弹出即处理；先压右后压左 |
| 中序 | 左 → 根 → 右 | `cur + stack` | 一路向左；弹栈处理；转右 |
| 后序 | 左 → 右 → 根 | `stack + reverse` | 先生成根右左，再反转 |

<Callout title="最终应该形成的理解" type="success">

迭代遍历不是“递归的另一套完全不同代码”，而是把原本由系统调用栈维护的状态显式化。

真正掌握后，你应该能从递归执行过程解释每一次 `push`、`pop`、`cur` 移动为什么存在。

</Callout>

```java tab="Java" tab-group="binary-tree-iterative"
// 前序遍历顺序：中-左-右，入栈顺序：中-右-左
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null){
            return result;
        }
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);
        while (!stack.isEmpty()){
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.right != null){
                stack.push(node.right);
            }
            if (node.left != null){
                stack.push(node.left);
            }
        }
        return result;
    }
}

// 中序遍历顺序: 左-中-右 入栈顺序： 左-右
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null){
            return result;
        }
        Stack<TreeNode> stack = new Stack<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()){
           if (cur != null){
               stack.push(cur);
               cur = cur.left;
           }else{
               cur = stack.pop();
               result.add(cur.val);
               cur = cur.right;
           }
        }
        return result;
    }
}

// 后序遍历顺序 左-右-中 入栈顺序：中-左-右 出栈顺序：中-右-左， 最后翻转结果
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null){
            return result;
        }
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);
        while (!stack.isEmpty()){
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.left != null){
                stack.push(node.left);
            }
            if (node.right != null){
                stack.push(node.right);
            }
        }
        Collections.reverse(result);
        return result;
    }
}
```

```python tab="Python"
# 前序遍历-迭代-LC144_二叉树的前序遍历
class Solution:
    def preorderTraversal(self, root: TreeNode) -> List[int]:
        # 根节点为空则返回空列表
        if not root:
            return []
        stack = [root]
        result = []
        while stack:
            node = stack.pop()
            # 中节点先处理
            result.append(node.val)
            # 右孩子先入栈
            if node.right:
                stack.append(node.right)
            # 左孩子后入栈
            if node.left:
                stack.append(node.left)
        return result

# 中序遍历-迭代-LC94_二叉树的中序遍历
class Solution:
    def inorderTraversal(self, root: TreeNode) -> List[int]:

        if not root:
            return []
        stack = []  # 不能提前将root节点加入stack中

        result = []
        cur = root
        while cur or stack:
            # 先迭代访问最底层的左子树节点
            if cur:
                stack.append(cur)
                cur = cur.left
            # 到达最左节点后处理栈顶节点
            else:
                cur = stack.pop()
                result.append(cur.val)
                # 取栈顶元素右节点
                cur = cur.right
        return result

# 后序遍历-迭代-LC145_二叉树的后序遍历
class Solution:
    def postorderTraversal(self, root: TreeNode) -> List[int]:
        if not root:
            return []
        stack = [root]
        result = []
        while stack:
            node = stack.pop()
            # 中节点先处理
            result.append(node.val)
            # 左孩子先入栈
            if node.left:
                stack.append(node.left)
            # 右孩子后入栈
            if node.right:
                stack.append(node.right)
        # 将最终的数组翻转
        return result[::-1]

class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        values = []
        stack = []
        popped_nodes = set() # 记录值已经被收割了的 nodes，这是关键，已经被收割的节点还在树中，还会被访问到，但逻辑上已经等同于 null 节点。
        current = root

        while current or stack:
            if current: # 一次处理完一个节点和他的左右儿子节点，不处理孙子节点，孙子节点由左右儿子等会分别处理。
                stack.append(current) # 入栈自己

                if current.right:
                    stack.append(current.right) # 入栈右儿子

                if current.left: # 因为栈是后进先出，后序是‘左右中’，所以后加左儿子
                    stack.append(current.left) # 入栈左儿子

                current = None # 会导致后面A处出栈
                continue

            node = stack.pop() # A处，出的是左儿子，如果无左儿子，出的就是右儿子，如果连右儿子也没有，出的就是自己了。

            # 如果 node 是叶子节点，就可以收割了；如果左右儿子都已经被收割了，也可以收割
            if (node.left is None or node.left in popped_nodes) and \
                (node.right is None or node.right in popped_nodes):
                popped_nodes.add(node)
                values.append(node.val)
                continue

            current = node # 不符合收割条件，说明 node 下还有未入栈的儿子，就去入栈

        return values
```

```go tab="Go"
func preorderTraversal(root *TreeNode) []int {
    ans := []int{}

	if root == nil {
		return ans
	}

	st := list.New()
    st.PushBack(root)

    for st.Len() > 0 {
        node := st.Remove(st.Back()).(*TreeNode)

        ans = append(ans, node.Val)
        if node.Right != nil {
            st.PushBack(node.Right)
        }
        if node.Left != nil {
            st.PushBack(node.Left)
        }
    }
    return ans
}

func postorderTraversal(root *TreeNode) []int {
    ans := []int{}

	if root == nil {
		return ans
	}

	st := list.New()
    st.PushBack(root)

    for st.Len() > 0 {
        node := st.Remove(st.Back()).(*TreeNode)

        ans = append(ans, node.Val)
        if node.Left != nil {
            st.PushBack(node.Left)
        }
        if node.Right != nil {
            st.PushBack(node.Right)
        }
    }
    reverse(ans)
    return ans
}

func reverse(a []int) {
    l, r := 0, len(a) - 1
    for l < r {
        a[l], a[r] = a[r], a[l]
        l, r = l+1, r-1
    }
}

func inorderTraversal(root *TreeNode) []int {
    ans := []int{}
    if root == nil {
        return ans
    }

    st := list.New()
    cur := root

    for cur != nil || st.Len() > 0 {
        if cur != nil {
            st.PushBack(cur)
            cur = cur.Left
        } else {
            cur = st.Remove(st.Back()).(*TreeNode)
            ans = append(ans, cur.Val)
            cur = cur.Right
        }
    }

    return ans
}
```

```javascript tab="JavaScript"
// 入栈 右 -> 左
// 出栈 中 -> 左 -> 右
var preorderTraversal = function(root, res = []) {
    if(!root) return res;
    const stack = [root];

        cur = stack.pop();
        res.push(cur.val);
        cur.right && stack.push(cur.right);

    }
    return res;
```

```swift tab="Swift"
    guard let root = root else { return result }

            stack.append(node)
        }

    }

  }
```

```rust tab="Rust"
impl Solution {
    //前序
    pub fn preorder_traversal(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        let mut res = vec![];
        let mut stack = vec![root];
        while !stack.is_empty() {
            if let Some(node) = stack.pop().unwrap() {
                res.push(node.borrow().val);
                stack.push(node.borrow().right.clone());
                stack.push(node.borrow().left.clone());
            }
        }
        res
    }
    //中序
    pub fn inorder_traversal(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        let mut res = vec![];
        let mut stack = vec![];
        let mut node = root;

        while !stack.is_empty() || node.is_some() {
            while let Some(n) = node {
                node = n.borrow().left.clone();
                stack.push(n);
            }
            if let Some(n) = stack.pop() {
                res.push(n.borrow().val);
                node = n.borrow().right.clone();
            }
        }
        res
    }

        let mut res = vec![];
        let mut stack = vec![root];

                res.push(node.borrow().val);
                stack.push(node.borrow().left.clone());
                stack.push(node.borrow().right.clone());
            }
        }
        res.into_iter().rev().collect()
    }
```
