# 一和零

> LeetCode 474 · Ones and Zeroes

给定一个二进制字符串数组 `strs`，以及两个整数 `m` 和 `n`。

需要从 `strs` 中选出一个尽可能大的子集，使得其中所有字符串包含的 `0` 总数不超过 `m`，包含的 `1` 总数不超过 `n`。

例如：

```text
strs = ["10", "0001", "111001", "1", "0"]
m = 5
n = 3
```

可以选择：

```text
{"10", "0001", "1", "0"}
```

其中恰好包含 $5$ 个 `0` 和 $3$ 个 `1`，子集大小为 $4$，因此答案为：

```text
4
```

<Callout type="info" title="这是一道二维容量的 01 背包">
每个字符串只能选一次，因此仍然是 01 背包；不同之处只是每件“物品”同时消耗两种资源：`0` 的数量和 `1` 的数量。可以把它理解为背包容量从一维 $W$ 扩展为了二维 $(m,n)$。
</Callout>

## 1. 先把题目翻译成背包语言

对于任意字符串 `s`，记：

$$
zero(s)=s\text{ 中 }0\text{ 的个数}
$$

$$
one(s)=s\text{ 中 }1\text{ 的个数}
$$

如果选择这个字符串，就需要消耗：

$$
(zero(s),\ one(s))
$$

两种容量。

而选中一个字符串所获得的“价值”始终都是：

$$
1
$$

因为题目要求最大化的是选中字符串的数量。

于是可以建立下面的对应关系：

| 原题元素 | 背包模型 |
| --- | --- |
| 一个二进制字符串 | 一件物品 |
| `0` 的数量 | 第一维重量 |
| `1` 的数量 | 第二维重量 |
| `m` | 第一维容量 |
| `n` | 第二维容量 |
| 选中一个字符串 | 获得价值 $1$ |
| 每个字符串最多选一次 | 01 背包 |

这也是本题最关键的建模过程。

![01 背包关系示意](https://file1.kamacoder.com/i/algo/20210117171307407-20230310132423205.png)

<Callout type="warning" title="为什么不是多重背包">
`m` 和 `n` 只是两种容量，不是“某种物品有 m 个、另一种物品有 n 个”。真正的物品是 `strs` 中的字符串，而每个字符串在数组中只出现并处理一次，所以本质仍是 01 背包。
</Callout>

## 2. 状态定义：容量变成两个维度

定义：

$$
\boxed{dp[i][j]=\text{最多使用 }i\text{ 个 }0\text{ 和 }j\text{ 个 }1\text{ 时，能够选出的最大字符串数量}}
$$

其中：

$$
0\le i\le m
$$

$$
0\le j\le n
$$

最终答案就是：

$$
\boxed{dp[m][n]}
$$

注意这里没有再额外设置“物品编号”这一维，因为我们直接采用了 01 背包的一维压缩思想，只不过容量本身有两个维度，因此最终得到一个二维数组。

## 3. 状态转移：选或不选当前字符串

假设当前字符串中：

$$
zeroNum=z
$$

$$
oneNum=o
$$

现在考虑状态 `dp[i][j]`。

### 3.1 不选择当前字符串

那么状态保持原样：

$$
dp[i][j]
$$

### 3.2 选择当前字符串

选择它以后，需要先为它腾出：

$$
z\text{ 个 }0
$$

和：

$$
o\text{ 个 }1
$$

因此之前能够使用的容量为：

$$
(i-z,\ j-o)
$$

选入当前字符串后，字符串数量增加 $1$：

$$
dp[i-z][j-o]+1
$$

于是得到转移方程：

$$
\boxed{dp[i][j]=\max\left(dp[i][j],\ dp[i-z][j-o]+1\right)}
$$

这与普通 01 背包：

$$
dp[j]=\max(dp[j],dp[j-w]+v)
$$

完全同构，只是重量由一个数 $w$ 变成了一个二维向量 $(z,o)$。

## 4. 初始化为什么全部为 0

当一个字符串都没有处理时，无论容量是多少，最多能够选出的字符串数量都是 $0$。

因此直接初始化：

```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

即可。

这里不存在“无法到达状态必须设为负无穷”的问题，因为题目求的是“容量不超过限制时最多选多少个”，即使什么都不选也是合法方案。

因此所有状态初始化为 $0$ 与状态含义完全一致。

## 5. 为什么两个容量都必须倒序遍历

这是本题最重要的实现细节。

普通 01 背包在压缩成一维后，需要让容量倒序：

```text
大容量 → 小容量
```

原因是防止当前物品在同一轮被重复使用。

本题有两个容量维度，因此两个维度都必须满足同样的要求：

```cpp
for (int i = m; i >= zeroNum; --i) {
    for (int j = n; j >= oneNum; --j) {
        ...
    }
}
```

### 5.1 如果正序会发生什么

假设当前字符串只包含一个 `0`：

```text
"0"
```

它的资源消耗是：

$$
(1,0)
$$

如果第一维容量正序更新，那么先得到：

$$
dp[1][0]=dp[0][0]+1=1
$$

接着计算 `dp[2][0]` 时，就可能立刻使用刚刚更新后的 `dp[1][0]`：

$$
dp[2][0]=dp[1][0]+1=2
$$

这相当于同一个字符串使用了两次，违反了 01 背包“一件物品最多一次”的约束。

因此必须倒序。

<Callout type="tip" title="两个容量维度谁先遍历都可以">
`0` 容量和 `1` 容量地位完全对称。只要两个方向都从大到小更新，先循环 `m` 再循环 `n`，或先循环 `n` 再循环 `m` 都可以。
</Callout>

## 6. 完整推导过程

以：

```text
strs = ["10", "0001", "111001", "1", "0"]
m = 3
n = 3
```

为例。

### 6.1 处理 `"10"`

它消耗：

$$
(1,1)
$$

因此所有满足：

$$
i\ge1,\quad j\ge1
$$

的状态，都可以尝试：

$$
dp[i][j]=\max(dp[i][j],dp[i-1][j-1]+1)
$$

### 6.2 处理 `"0001"`

它消耗：

$$
(3,1)
$$

只有第一维容量至少为 $3$、第二维容量至少为 $1$ 时才能选择。

例如：

$$
dp[3][2]
$$

可以尝试由：

$$
dp[0][1]+1
$$

转移而来。

### 6.3 继续处理其他字符串

每次都只需要统计当前字符串中的 `0` 和 `1` 数量，然后执行同样的倒序更新。

## 7. C++ 实现

```cpp
class Solution {
public:
    int findMaxForm(vector<string>& strs, int m, int n) {
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (const string& s : strs) {
            int zeroNum = 0;
            int oneNum = 0;

            for (char c : s) {
                if (c == '0') {
                    ++zeroNum;
                } else {
                    ++oneNum;
                }
            }

            for (int i = m; i >= zeroNum; --i) {
                for (int j = n; j >= oneNum; --j) {
                    dp[i][j] = max(
                        dp[i][j],
                        dp[i - zeroNum][j - oneNum] + 1
                    );
                }
            }
        }

        return dp[m][n];
    }
};
```

## 8. 复杂度分析

设：

$$
k=|strs|
$$

每个字符串长度最多记作 $L$。

统计每个字符串中 `0` 和 `1` 的总成本为：

$$
O(kL)
$$

DP 更新成本为：

$$
O(kmn)
$$

因此总体时间复杂度可以写成：

$$
O(kL+kmn)
$$

通常简写为：

$$
\boxed{O(kmn)}
$$

空间复杂度为：

$$
\boxed{O(mn)}
$$

## 9. 与前面几类 01 背包题的关系

到这里，可以把常见 01 背包变形统一起来：

| 问题 | `dp` 含义 | 转移目标 |
| --- | --- | --- |
| 纯 01 背包 | 最大价值 | `max` |
| 分割等和子集 | 是否能恰好凑出 | 可达性 |
| 最后一块石头的重量 II | 尽量接近目标容量 | 最大可装重量 |
| 目标和 | 恰好凑出目标的方案数 | 累加方案数 |
| 一和零 | 两维容量下最多选多少件 | `max` |

本题真正新增的知识点不是新的背包类型，而是：

$$
\boxed{\text{背包容量可以是多维的}}
$$

如果每件物品同时消耗 $d$ 种资源，那么状态往往也会增加到 $d$ 个容量维度。

## 10. 为什么“二维容量”不是“二维 DP 的物品维度”

这是非常容易混淆的一点。

经典二维 01 背包可能定义：

$$
dp[i][j]=\text{前 }i\text{ 件物品、容量 }j\text{ 的最优值}
$$

其中二维分别表示：

```text
物品编号 × 背包容量
```

而本题的 `dp[i][j]` 中：

```text
0 的容量 × 1 的容量
```

物品维度已经通过滚动数组压缩掉了。

因此虽然二者都是二维数组，含义完全不同。

<Callout type="info" title="判断维度时先问：每个下标到底表示什么">
不要根据 `dp` 数组是二维还是三维来判断题型。动态规划的核心永远是状态含义。只要把每个下标代表的条件说清楚，状态转移通常就会自然出现。
</Callout>

## 11. 一种更直观的三维状态

如果暂时不做状态压缩，也可以定义：

$$
dp[k][i][j]
$$

表示：

> 只考虑前 $k$ 个字符串，在最多使用 $i$ 个 `0` 和 $j$ 个 `1` 的条件下，最多能选择多少个字符串。

那么对于第 $k$ 个字符串，假设它包含 $z$ 个 `0` 和 $o$ 个 `1`：

$$
dp[k][i][j]
=
\max\left(
  dp[k-1][i][j],
  dp[k-1][i-z][j-o]+1
\right)
$$

这个三维状态更容易从“选 / 不选”理解，但空间复杂度会变成：

$$
O(kmn)
$$

进一步观察可以发现，第 $k$ 层只依赖第 $k-1$ 层，因此物品维度可以被压缩掉，最终就是前面的二维写法。

## 12. 常见错误

### 错误一：把它理解成多重背包

错误原因通常是把 `m` 和 `n` 当成了物品数量。

实际上：

```text
m、n = 两种容量
strs 中每个字符串 = 一件物品
```

### 错误二：容量正序遍历

这样会让当前字符串在一轮中被重复使用，悄悄把 01 背包变成完全背包。

### 错误三：把“价值”理解成字符串长度

本题目标是最大化“选了多少个字符串”，所以每件物品价值恒为：

$$
1
$$

字符串长度只会影响它消耗多少个 `0` 和 `1`，并不是价值。

### 错误四：忘记这是“至多”容量

`dp[m][n]` 表示最多使用 `m` 个 `0`、`n` 个 `1`，不要求两种资源必须全部恰好用完。

所以初始化全部为 $0$ 是合法的。

## 13. 迁移模板：多维 01 背包

以后如果看到题目具有以下结构：

> 每个对象只能选一次；每个对象会消耗多种资源；所有资源都有各自上限；要求最大化收益。

就应该联想到多维 01 背包。

二维版本模板：

```cpp
vector<vector<int>> dp(capacity1 + 1,
                       vector<int>(capacity2 + 1, 0));

for (const auto& item : items) {
    int cost1 = ...;
    int cost2 = ...;
    int value = ...;

    for (int i = capacity1; i >= cost1; --i) {
        for (int j = capacity2; j >= cost2; --j) {
            dp[i][j] = max(
                dp[i][j],
                dp[i - cost1][j - cost2] + value
            );
        }
    }
}
```

核心规律只有一句：

$$
\boxed{\text{每件物品只能选一次 }\Longrightarrow\text{ 所有被压缩的容量维度都倒序更新}}
$$

## 其他语言版本

```java label="Java"
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        int[][] dp = new int[m + 1][n + 1];

        for (String s : strs) {
            int zeros = 0;
            int ones = 0;

            for (char c : s.toCharArray()) {
                if (c == '0') {
                    zeros++;
                } else {
                    ones++;
                }
            }

            for (int i = m; i >= zeros; --i) {
                for (int j = n; j >= ones; --j) {
                    dp[i][j] = Math.max(
                        dp[i][j],
                        dp[i - zeros][j - ones] + 1
                    );
                }
            }
        }

        return dp[m][n];
    }
}
```

```python label="Python"
class Solution:
    def findMaxForm(self, strs: list[str], m: int, n: int) -> int:
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for s in strs:
            zeros = s.count("0")
            ones = len(s) - zeros

            for i in range(m, zeros - 1, -1):
                for j in range(n, ones - 1, -1):
                    dp[i][j] = max(
                        dp[i][j],
                        dp[i - zeros][j - ones] + 1
                    )

        return dp[m][n]
```

```go label="Go"
func findMaxForm(strs []string, m int, n int) int {
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }

    for _, s := range strs {
        zeros, ones := 0, 0
        for _, c := range s {
            if c == '0' {
                zeros++
            } else {
                ones++
            }
        }

        for i := m; i >= zeros; i-- {
            for j := n; j >= ones; j-- {
                candidate := dp[i-zeros][j-ones] + 1
                if candidate > dp[i][j] {
                    dp[i][j] = candidate
                }
            }
        }
    }

    return dp[m][n]
}
```

## 总结

“一和零”是理解多维背包最经典的一道题。

需要记住的不是某段代码，而是下面的抽象过程：

1. 每个字符串是一件只能选择一次的物品，因此是 01 背包；
2. `0` 和 `1` 是两类独立资源，因此背包容量有两个维度；
3. 每选中一个字符串，收益为 $1$；
4. 状态定义为二维容量下能选出的最大物品数；
5. 两个容量维度都必须倒序，保证当前字符串只被使用一次。

最终核心转移只有：

$$
\boxed{dp[i][j]=\max\left(dp[i][j],dp[i-z][j-o]+1\right)}
$$

从这道题开始，背包问题就不应再被理解成“只有重量和容量”的固定模板，而应该理解成：

> 在有限资源约束下，对一组可选决策进行最优组合。
