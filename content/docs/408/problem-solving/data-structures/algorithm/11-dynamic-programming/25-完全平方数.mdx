# 279. 完全平方数

[LeetCode 279：完全平方数](https://leetcode.cn/problems/perfect-squares/)

给定正整数 `n`，找到若干个完全平方数，使它们的和等于 `n`，并返回所需完全平方数的**最少数量**。

完全平方数包括：

$$
1,4,9,16,25,\dots
$$

例如：

```text
n = 12
```

可以表示为：

$$
12=4+4+4
$$

因此答案为：

$$
\boxed{3}
$$

而：

```text
n = 13
```

可以表示为：

$$
13=4+9
$$

所以答案为：

$$
\boxed{2}
$$

<Callout type="info" title="先识别模型">
每个完全平方数都可以使用任意多次，目标是恰好凑出 `n`，并使使用的物品数量最少。因此本题本质上就是一个“完全背包 + 最小物品数”问题。
</Callout>

## 1. 为什么它是完全背包

把所有不超过 `n` 的完全平方数看成物品：

$$
1^2,2^2,3^2,\dots,\lfloor\sqrt n\rfloor^2
$$

那么：

- 每个平方数就是一种物品；
- 平方数的值就是物品“重量”；
- 背包容量是 `n`；
- 每种平方数可以重复使用；
- 要求恰好装满背包；
- 目标是使用物品数量最少。

所以模型可以概括为：

$$
\boxed{\text{完全背包最小值问题}}
$$

它和“零钱兑换”几乎是同一个模型，只不过硬币面额变成了：

$$
1^2,2^2,3^2,\dots
$$

## 2. 状态定义

定义：

$$
\boxed{dp[j]=\text{凑成整数 }j\text{ 所需完全平方数的最少数量}}
$$

最终答案就是：

$$
\boxed{dp[n]}
$$

这一定义非常重要，因为后面的初始化和状态转移都必须围绕它展开。

## 3. 状态转移

假设当前选择一个完全平方数：

$$
i^2
$$

若已经知道：

$$
dp[j-i^2]
$$

表示凑出 `j - i^2` 的最少数量，那么再加入一个 `i^2` 后，就可以得到 `j`：

$$
dp[j-i^2]+1
$$

因此：

$$
\boxed{dp[j]=\min(dp[j],dp[j-i^2]+1)}
$$

这和零钱兑换中的：

$$
dp[j]=\min(dp[j],dp[j-coin]+1)
$$

完全一致。

<Callout type="tip" title="迁移能力比记题更重要">
以后看到“若干候选值可以无限重复使用，要求恰好凑出目标，并使使用数量最少”，都可以优先往这一类完全背包模型上思考。
</Callout>

## 4. 初始化为什么是 `dp[0] = 0`

为了凑出 `0`，什么都不选即可：

$$
\boxed{dp[0]=0}
$$

对于其余位置，因为一开始不知道最优值，应初始化为一个足够大的数：

$$
\boxed{dp[j]=+\infty\quad(j>0)}
$$

例如可以写：

```cpp
const int INF = n + 1;
vector<int> dp(n + 1, INF);
dp[0] = 0;
```

为什么 `n + 1` 足够大？

因为最坏情况下总可以用：

$$
1^2+1^2+\cdots+1^2
$$

凑出 `n`，最多使用 `n` 个平方数。

所以合法答案一定满足：

$$
dp[n]\le n
$$

于是 `n + 1` 足以表示“无穷大”。

## 5. 为什么一定有解

因为：

$$
1=1^2
$$

总可以重复使用 `1`：

$$
n=\underbrace{1+1+\cdots+1}_{n\text{ 个}}
$$

因此本题和普通零钱兑换稍有不同：本题不存在“完全无法凑出”的情况。

最终 `dp[n]` 一定会被更新。

## 6. 遍历顺序：先物品还是先背包

本题求的是**最少数量**，不是方案个数。

因此只要保证完全背包的容量是正序更新，下面两种写法都可以得到正确答案。

### 写法一：外层遍历平方数

```cpp
for (int i = 1; i * i <= n; ++i) {
    int square = i * i;
    for (int j = square; j <= n; ++j) {
        dp[j] = min(dp[j], dp[j - square] + 1);
    }
}
```

这里的含义是：

> 依次允许使用每一种完全平方数，并更新所有可达到的容量。

### 写法二：外层遍历目标值

```cpp
for (int j = 1; j <= n; ++j) {
    for (int i = 1; i * i <= j; ++i) {
        dp[j] = min(dp[j], dp[j - i * i] + 1);
    }
}
```

这里的含义是：

> 对每一个目标值 `j`，枚举最后使用的是哪个完全平方数。

由于本题只求最小值，不区分不同选择顺序，因此两种都成立。

<Callout type="warning" title="不要把这个结论推广到所有完全背包题">
如果题目要求统计方案数，那么“组合”与“排列”会受到循环顺序影响；而本题求的是最小值，所以循环外层的选择不会改变答案。
</Callout>

## 7. 为什么容量必须正序

完全背包允许同一个平方数使用多次。

假设当前平方数是：

$$
4
$$

当我们正序遍历：

```text
j = 4, 5, 6, ..., n
```

计算 `dp[8]` 时，可以继续使用刚刚更新过的 `dp[4]`：

$$
dp[8]\leftarrow dp[4]+1
$$

这样就表示：

$$
8=4+4
$$

即同一个物品被重复使用。

如果像 01 背包一样倒序更新，则当前平方数在一轮中最多只能使用一次，会错误地把问题变成 01 背包。

因此：

$$
\boxed{\text{完全背包：容量正序}}
$$

## 8. 手推 `n = 5`

初始：

```text
dp = [0, ∞, ∞, ∞, ∞, ∞]
```

### `j = 1`

只有：

$$
1^2=1
$$

所以：

$$
dp[1]=dp[0]+1=1
$$

### `j = 2`

仍然只能选择 `1`：

$$
dp[2]=dp[1]+1=2
$$

### `j = 3`

$$
dp[3]=dp[2]+1=3
$$

### `j = 4`

可以选择 `1` 或 `4`：

$$
dp[4]=\min(dp[3]+1,dp[0]+1)
$$

所以：

$$
\boxed{dp[4]=1}
$$

### `j = 5`

可以使用：

$$
5=4+1
$$

因此：

$$
\boxed{dp[5]=2}
$$

最终：

```text
dp = [0, 1, 2, 3, 1, 2]
```

## 9. 推荐写法

直接使用“外层目标值、内层平方数”的形式，可读性非常强：

```cpp
class Solution {
public:
    int numSquares(int n) {
        const int INF = n + 1;
        vector<int> dp(n + 1, INF);
        dp[0] = 0;

        for (int j = 1; j <= n; ++j) {
            for (int i = 1; i * i <= j; ++i) {
                dp[j] = min(dp[j], dp[j - i * i] + 1);
            }
        }

        return dp[n];
    }
};
```

## 10. 复杂度分析

对每一个 `j`，最多枚举：

$$
\lfloor\sqrt j\rfloor
$$

个平方数。

因此时间复杂度为：

$$
\boxed{O(n\sqrt n)}
$$

空间复杂度为：

$$
\boxed{O(n)}
$$

## 11. 与零钱兑换的统一视角

把两道题放在一起：

| 问题 | 物品 | 是否可重复 | 目标 | 状态转移 |
| --- | --- | --- | --- | --- |
| 零钱兑换 | 各种硬币 | 是 | 最少硬币数 | `dp[j] = min(dp[j], dp[j-coin] + 1)` |
| 完全平方数 | $1^2,2^2,\dots$ | 是 | 最少平方数个数 | `dp[j] = min(dp[j], dp[j-square] + 1)` |

它们本质上只差“物品集合”的生成方式。

零钱兑换的物品来自输入：

```text
coins
```

完全平方数的物品来自：

$$
\{1^2,2^2,\dots,\lfloor\sqrt n\rfloor^2\}
$$

所以如果已经真正掌握零钱兑换，本题应该被视为同一模板的迁移，而不是一道全新的题。

## 12. 常见错误

### 错误一：把容量倒序

```cpp
for (int j = n; j >= square; --j)
```

这样会限制每个平方数只能使用一次，与题意不符。

### 错误二：全部初始化为 `0`

如果写：

```cpp
vector<int> dp(n + 1, 0);
```

则状态转移：

```cpp
dp[j] = min(dp[j], dp[j - square] + 1);
```

永远会保留 `0`，完全无法得到正确最小值。

### 错误三：把问题误认为组合计数

本题不是：

```cpp
dp[j] += dp[j - square];
```

而是：

```cpp
dp[j] = min(dp[j], dp[j - square] + 1);
```

因为状态含义是“最少数量”，而不是“方案数”。

### 错误四：机械记忆循环顺序

本题外层先物品还是先容量都可以。

真正不能错的是：

- 这是完全背包；
- 当前物品允许重复使用；
- 因此容量必须正序；
- 状态求的是最小值。

## 13. 一眼识别模板

以后如果题目满足：

1. 有一组正整数候选值；
2. 每个候选值可使用无限次；
3. 需要恰好组成目标值；
4. 求使用元素的最少数量；

可优先尝试：

```cpp
vector<int> dp(target + 1, INF);
dp[0] = 0;

for (int item : items) {
    for (int j = item; j <= target; ++j) {
        dp[j] = min(dp[j], dp[j - item] + 1);
    }
}
```

完全平方数只需要先生成：

```cpp
for (int i = 1; i * i <= n; ++i) {
    int item = i * i;
}
```

即可套入这个模板。

## 15. 本题总结

本题最重要的并不是“平方数”本身，而是完成模型识别：

$$
\boxed{\text{平方数}=\text{物品},\quad n=\text{背包容量}}
$$

每个平方数可以无限使用，所以属于完全背包；目标是使用数量最少，因此使用最小值转移：

$$
\boxed{dp[j]=\min(dp[j],dp[j-i^2]+1)}
$$

如果已经掌握“零钱兑换”，那么完全平方数应当被看成同一个模型的自然变形。
