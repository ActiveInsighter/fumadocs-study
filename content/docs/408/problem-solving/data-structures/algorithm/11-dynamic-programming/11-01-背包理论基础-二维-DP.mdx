# 01 背包理论基础：二维 DP

01 背包是整个背包问题体系的起点。后面的分割等和子集、最后一块石头的重量 II、目标和、一和零等问题，本质上都可以看成它的变形。

原始背包问题分类示意图：

![背包问题分类](https://file1.kamacoder.com/i/algo/20210117171307407.png)

<Callout type="info" title="01 背包最重要的限制">
有 $n$ 件物品，第 $i$ 件物品重量为 $weight[i]$、价值为 $value[i]$。背包容量为 $W$。**每件物品最多只能选择一次**，目标是在总重量不超过 $W$ 的条件下，使总价值最大。
</Callout>

这一篇先使用二维 DP 把状态的来源讲清楚。下一篇再将二维状态压缩成一维滚动数组。

## 1. 为什么需要动态规划

对于每件物品，我们只有两个决策：

- 选；
- 不选。

如果直接枚举所有选择方案，每件物品都有两种状态，因此最多需要检查：

$$
2^n
$$

种组合。

暴力搜索的时间复杂度为：

$$
O(2^n)
$$

动态规划的作用，就是把大量重复出现的“前若干件物品 + 某个剩余容量”的子问题保存下来，只求一次。

## 2. 示例

设背包容量为：

$$
W=4
$$

共有三件物品：

| 物品 | 重量 | 价值 |
| --- | ---: | ---: |
| 物品 0 | 1 | 15 |
| 物品 1 | 3 | 20 |
| 物品 2 | 4 | 30 |

我们希望求出容量为 $4$ 时能够取得的最大价值。

## 3. 状态定义：为什么二维数组正合适

二维 DP 需要同时记录两个维度：

1. 已经允许使用到哪一件物品；
2. 当前背包容量是多少。

状态表可以理解为：

![01 背包二维状态表](https://file1.kamacoder.com/i/algo/20210110103003361.png)

定义：

$$
\boxed{dp[i][j]=\text{从物品 }0\sim i\text{ 中任意选择，容量为 }j\text{ 时的最大价值}}
$$

这里：

- $i$ 表示“允许使用的最后一件物品编号”；
- $j$ 表示“背包容量上限”；
- $dp[i][j]$ 表示在这个限制下的最优答案。

<Callout type="warning" title="状态不是‘恰好装满’">
这里的 $dp[i][j]$ 表示总重量**不超过** $j$ 时的最大价值，不要求恰好把容量 $j$ 填满。这个区别会直接影响初始化方式。
</Callout>

## 4. 从第一行理解状态含义

先只考虑物品 0：

![只考虑物品 0](https://file1.kamacoder.com/i/algo/20240730113455.png)

因为物品 0 的重量为 $1$、价值为 $15$：

- 容量 $0$：装不下，价值为 $0$；
- 容量 $1$：可以装物品 0，价值为 $15$；
- 容量 $2,3,4$：虽然容量更大，但物品 0 只有一件，所以价值仍然只能是 $15$。

因此第一行为：

$$
[0,15,15,15,15]
$$

再允许使用物品 1：

![加入物品 1 后的状态](https://file1.kamacoder.com/i/algo/20240730114228.png)

例如：

$$
dp[1][4]=35
$$

表示：

> 从物品 0、物品 1 中任意选择，在容量不超过 4 的条件下，最大价值为 35。

此时最优选择是同时放入物品 0 和物品 1。

## 5. 状态转移：只有“选”和“不选”两条路

现在考虑如何求：

$$
dp[i][j]
$$

对于当前物品 $i$，最终只有两种可能。

### 5.1 不选物品 $i$

如果不选它，那么答案完全由前面的物品决定：

$$
\boxed{dp[i-1][j]}
$$

例如求 $dp[1][4]$ 时，不选物品 1，就直接继承：

$$
dp[0][4]
$$

推导方向如下：

![不选择当前物品](https://file1.kamacoder.com/i/algo/20240730174246.png)

### 5.2 选择物品 $i$

如果选择物品 $i$，首先必须满足：

$$
j\ge weight[i]
$$

放入物品 $i$ 后，剩余容量为：

$$
j-weight[i]
$$

由于物品 $i$ 已经被选过一次，剩余空间只能从前 $i-1$ 件物品中继续选择，所以对应状态是：

$$
dp[i-1][j-weight[i]]
$$

再加上当前物品价值：

$$
\boxed{dp[i-1][j-weight[i]]+value[i]}
$$

推导方向如下：

![选择当前物品](https://file1.kamacoder.com/i/algo/20240730174436.png)

### 5.3 取两种方案中的最大值

于是当 $j\ge weight[i]$ 时：

$$
\boxed{
dp[i][j]=\max\left(dp[i-1][j],\ dp[i-1][j-weight[i]]+value[i]\right)
}
$$

如果当前容量连物品 $i$ 都装不下，即：

$$
j<weight[i]
$$

那么只能不选：

$$
\boxed{dp[i][j]=dp[i-1][j]}
$$

<Callout type="tip" title="记公式不如记决策">
01 背包二维转移真正应该记住的是：**当前物品选还是不选**。一旦状态定义明确，公式几乎可以现场推出来。
</Callout>

## 6. 为什么“选择当前物品”要看上一行

这是 01 背包最关键的一点。

选择物品 $i$ 时使用的是：

$$
dp[i-1][j-weight[i]]
$$

而不是：

$$
dp[i][j-weight[i]]
$$

原因是每件物品只能选择一次。

如果继续从第 $i$ 行取状态，就意味着“已经允许使用物品 $i$ 的状态”又继续加入物品 $i$，可能造成同一件物品重复使用。

因此二维 01 背包通过“**从上一行转移到当前行**”天然保证了一件物品最多使用一次。

## 7. 初始化

初始化必须从状态定义出发。

### 7.1 容量为 0

容量为 $0$ 时，不可能放入任何正重量物品：

$$
\boxed{dp[i][0]=0}
$$

![容量为 0 的初始化](https://file1.kamacoder.com/i/algo/2021011010304192.png)

### 7.2 第一件物品

对于第一行：

$$
dp[0][j]
$$

只允许使用物品 0。

若：

$$
j<weight[0]
$$

装不下，因此：

$$
dp[0][j]=0
$$

若：

$$
j\ge weight[0]
$$

可以放入唯一的一件物品 0：

$$
\boxed{dp[0][j]=value[0]}
$$

初始化结果如下：

![第一行初始化](https://file1.kamacoder.com/i/algo/20210110103109140.png)

代码可以写成：

```cpp
vector<vector<int>> dp(n, vector<int>(W + 1, 0));

for (int j = weight[0]; j <= W; ++j) {
    dp[0][j] = value[0];
}
```

其余位置初始为 $0$ 即可，因为后续都会被正常递推覆盖。

## 8. 遍历顺序

二维状态的依赖关系是：

$$
dp[i][j]\leftarrow dp[i-1][j]
$$

以及：

$$
dp[i][j]\leftarrow dp[i-1][j-weight[i]]
$$

也就是说，第 $i$ 行只依赖第 $i-1$ 行。

依赖方向示意：

![二维 01 背包依赖关系](https://file1.kamacoder.com/i/algo/2021011010314055.png)

因此最自然的写法是：

```cpp
for (int i = 1; i < n; ++i) {
    for (int j = 0; j <= W; ++j) {
        if (j < weight[i]) {
            dp[i][j] = dp[i - 1][j];
        } else {
            dp[i][j] = max(
                dp[i - 1][j],
                dp[i - 1][j - weight[i]] + value[i]
            );
        }
    }
}
```

### 二维 DP 中能不能先遍历容量

可以。

因为无论按什么顺序访问当前表格，只要计算 $dp[i][j]$ 时，第 $i-1$ 行已经是完整有效的，状态就不会互相污染。

例如下面也成立：

```cpp
for (int j = 0; j <= W; ++j) {
    for (int i = 1; i < n; ++i) {
        if (j < weight[i]) {
            dp[i][j] = dp[i - 1][j];
        } else {
            dp[i][j] = max(
                dp[i - 1][j],
                dp[i - 1][j - weight[i]] + value[i]
            );
        }
    }
}
```

不过从“先增加可用物品，再处理所有容量”的语义来看，**外层遍历物品更直观**。

## 10. C++ 完整实现

输入格式约定：

- 第一行：物品数 $n$ 与背包容量 $W$；
- 第二行：$n$ 个物品重量；
- 第三行：$n$ 个物品价值。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, W;
    cin >> n >> W;

    vector<int> weight(n), value(n);
    for (int &x : weight) cin >> x;
    for (int &x : value) cin >> x;

    if (n == 0) {
        cout << 0 << '\n';
        return 0;
    }

    vector<vector<int>> dp(n, vector<int>(W + 1, 0));

    // 只允许使用物品 0。
    for (int j = weight[0]; j <= W; ++j) {
        dp[0][j] = value[0];
    }

    for (int i = 1; i < n; ++i) {
        for (int j = 0; j <= W; ++j) {
            // 不选择物品 i。
            dp[i][j] = dp[i - 1][j];

            // 如果装得下，再尝试选择物品 i。
            if (j >= weight[i]) {
                dp[i][j] = max(
                    dp[i][j],
                    dp[i - 1][j - weight[i]] + value[i]
                );
            }
        }
    }

    cout << dp[n - 1][W] << '\n';
    return 0;
}
```

## 11. 复杂度

设物品数量为 $n$，背包容量为 $W$。

需要计算 $n(W+1)$ 个状态，因此：

$$
\boxed{T(n,W)=O(nW)}
$$

二维数组需要：

$$
\boxed{S(n,W)=O(nW)}
$$

相比暴力枚举的 $O(2^n)$，时间复杂度已经发生本质变化。

不过观察转移式会发现：

$$
dp[i][j]
$$

只依赖上一行：

$$
dp[i-1][*]
$$

所以整张二维表其实没有必要永久保留。这正是下一篇“滚动数组”的来源。

## 12. 高频易错点

### 易错点 1：把状态理解成“恰好装满”

本题状态是“容量上限为 $j$”，而不是“恰好使用 $j$ 容量”。两种状态定义的初始化完全不同。

### 易错点 2：选择当前物品时仍使用当前行

错误思路：

```text
dp[i][j - weight[i]] + value[i]
```

这可能重复选择物品 $i$。

正确状态必须来自上一行：

```text
dp[i - 1][j - weight[i]] + value[i]
```

### 易错点 3：只记公式，不理解“选 / 不选”

如果忘记公式，直接重新问自己：

> 对于物品 $i$，最优方案最终有没有选择它？

两种情况一拆，转移式自然出现。

### 易错点 4：机械背初始化

初始化必须和状态含义一致。当前状态表示“最大价值”，且所有价值为非负数，所以大量位置初始化为 $0$ 很自然；若题目状态改成“必须恰好装满”，就不能照搬。

## 13. 从二维 DP 提炼出的通用模板

以后遇到“每个元素最多使用一次”的选择型问题，可以先尝试问四个问题：

1. `dp[i][j]` 中，$i$ 是否表示“前 $i$ 个元素”？
2. 当前元素是否只有“选 / 不选”两类决策？
3. 选择当前元素以后，剩余问题是否必须来自“上一层”？
4. 当前二维状态是否只依赖上一层，从而可以进一步压缩空间？

如果答案大多为“是”，问题通常已经非常接近 01 背包。

## 14. 本篇结论

二维 01 背包的核心只有一句：

$$
\boxed{
\text{当前最优值}=\max(\text{不选当前物品},\ \text{选择当前物品})
}
$$

对应为：

$$
\boxed{
dp[i][j]=\max\left(dp[i-1][j],\ dp[i-1][j-weight[i]]+value[i]\right)
}
$$

真正需要理解的是：**为什么选择当前物品以后要退回上一层**。它正是“每件物品只能使用一次”在状态转移中的数学表达。

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int W = sc.nextInt();

        int[] weight = new int[n];
        int[] value = new int[n];
        for (int i = 0; i < n; i++) weight[i] = sc.nextInt();
        for (int i = 0; i < n; i++) value[i] = sc.nextInt();

        if (n == 0) {
            System.out.println(0);
            return;
        }

        int[][] dp = new int[n][W + 1];
        for (int j = weight[0]; j <= W; j++) {
            dp[0][j] = value[0];
        }

        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= W; j++) {
                dp[i][j] = dp[i - 1][j];
                if (j >= weight[i]) {
                    dp[i][j] = Math.max(
                        dp[i][j],
                        dp[i - 1][j - weight[i]] + value[i]
                    );
                }
            }
        }

        System.out.println(dp[n - 1][W]);
    }
}
