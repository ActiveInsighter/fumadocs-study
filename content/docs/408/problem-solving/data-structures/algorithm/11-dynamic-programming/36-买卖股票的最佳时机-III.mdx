# 123. 买卖股票的最佳时机 III

[LeetCode 123：买卖股票的最佳时机 III](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/)

给定股票每天的价格 `prices[i]`，最多可以完成 **两笔交易**，并且任意时刻最多只能持有一股股票。求最大利润。

例如：

```text
prices = [3, 3, 5, 0, 0, 3, 1, 4]
```

可以选择：

- $0$ 买入，$3$ 卖出；
- $1$ 买入，$4$ 卖出。

总利润为：

$$
(3-0)+(4-1)=6
$$

<Callout type="info" title="这道题的本质：给股票状态机增加“交易阶段”">
前两道股票题只需要记录“持有 / 不持有”。现在“不持有”还不够，因为第一次卖出后的不持有，与第二次卖出后的不持有代表不同的交易进度。于是必须把“已经进行到第几笔交易”编码进状态。
</Callout>

## 1. 为什么两个状态已经不够

在“任意多次交易”中，只要知道：

- 当前持有；
- 当前不持有；

就足以决定未来操作。

但本题最多只能交易两次。

假设今天不持有股票，它可能是：

1. 还一次都没有买；
2. 已完成第一笔交易；
3. 已完成第二笔交易。

这三个状态未来能够执行的动作不同。

因此必须进一步区分 **交易阶段**。

## 2. 状态设计

可以定义五种状态：

$$
0:\text{没有进行任何操作}
$$

$$
1:\text{第一次买入后，当前持有股票}
$$

$$
2:\text{第一次卖出后，当前不持有股票}
$$

$$
3:\text{第二次买入后，当前持有股票}
$$

$$
4:\text{第二次卖出后，当前不持有股票}
$$

于是：

$$
dp[i][j]
=
\text{第 }i\text{ 天结束时处于状态 }j\text{ 的最大现金}
$$

状态链可以理解为：

```text
未操作
   │ 第一次买入
   ▼
第一次持有
   │ 第一次卖出
   ▼
第一次卖出
   │ 第二次买入
   ▼
第二次持有
   │ 第二次卖出
   ▼
第二次卖出
```

每个状态还可以通过“今天什么都不做”保持原状态。

## 3. 第一次买入状态

第 $i$ 天结束时处于第一次买入后的持有状态，有两种来源。

### 3.1 昨天已经第一次买入

今天继续持有：

$$
dp[i-1][1]
$$

### 3.2 今天第一次买入

此前没有进行交易，因此：

$$
-prices[i]
$$

所以：

$$
\boxed{
dp[i][1]
=
\max(dp[i-1][1],-prices[i])
}
$$

这和“最多一次交易”的持有状态完全一样。

## 4. 第一次卖出状态

第 $i$ 天结束时已经完成第一次卖出：

- 昨天已经卖出，今天不操作；
- 昨天第一次持有，今天卖出。

因此：

$$
\boxed{
dp[i][2]
=
\max(
    dp[i-1][2],
    dp[i-1][1]+prices[i]
)
}
$$

## 5. 第二次买入状态

这是本题最关键的一步。

第 $i$ 天结束时已经完成第二次买入，有两种来源。

### 5.1 昨天已经第二次买入

今天继续持有：

$$
dp[i-1][3]
$$

### 5.2 今天进行第二次买入

要进入第二次买入，必须已经完成第一次卖出。

因此需要从：

$$
dp[i-1][2]
$$

转移，并支付今天的股票价格：

$$
dp[i-1][2]-prices[i]
$$

所以：

$$
\boxed{
dp[i][3]
=
\max(
    dp[i-1][3],
    dp[i-1][2]-prices[i]
)
}
$$

<Callout type="success" title="为什么第二次买入不是 -prices[i]？">
因为第二次买入之前已经允许完成第一笔交易。第一笔交易赚到的利润必须保留下来，所以第二次买入后的现金是“第一次卖出后的最大现金 - 当前股价”。这就是交易阶段状态存在的意义。
</Callout>

## 6. 第二次卖出状态

同理：

- 昨天已经完成第二次卖出；
- 昨天处于第二次持有，今天卖出。

因此：

$$
\boxed{
dp[i][4]
=
\max(
    dp[i-1][4],
    dp[i-1][3]+prices[i]
)
}
$$

## 7. 四条核心转移

把无操作状态省略后，需要牢牢记住的是：

$$
\boxed{
dp[i][1]=\max(dp[i-1][1],-prices[i])
}
$$

$$
\boxed{
dp[i][2]=\max(dp[i-1][2],dp[i-1][1]+prices[i])
}
$$

$$
\boxed{
dp[i][3]=\max(dp[i-1][3],dp[i-1][2]-prices[i])
}
$$

$$
\boxed{
dp[i][4]=\max(dp[i-1][4],dp[i-1][3]+prices[i])
}
$$

可以压缩成一个非常有规律的结构：

```text
第一次买：max(保持, 0          - price)
第一次卖：max(保持, 第一次买   + price)
第二次买：max(保持, 第一次卖   - price)
第二次卖：max(保持, 第二次买   + price)
```

也就是：

$$
\boxed{
\text{买入做减法，卖出做加法；每一阶段只能从上一个阶段转移而来}
}
$$

## 8. 初始化为什么容易困惑

第 $0$ 天：

$$
dp[0][0]=0
$$

第一次买入：

$$
dp[0][1]=-prices[0]
$$

第一次卖出可以初始化为：

$$
dp[0][2]=0
$$

第二次买入通常初始化为：

$$
dp[0][3]=-prices[0]
$$

第二次卖出：

$$
dp[0][4]=0
$$

于是：

```text
[0, -prices[0], 0, -prices[0], 0]
```

### 为什么第一天就可以处于“第二次买入”状态？

这里最容易产生误解。

“最多两次交易”并不要求一定完成两次交易。

为了统一递推，我们允许前面的某些交易是 **零利润的空交易**。例如同一天买入又卖出，利润为 $0$，于是仍然可以在第 $0$ 天把“第二次买入”初始化成：

$$
-prices[0]
$$

这样不会制造虚假利润，只是让“最多两次”能够统一表示成“走到第二次卖出状态”。

<Callout type="warning" title="“第二次买入”状态不意味着真的必须已经完成一笔有收益的交易">
动态规划状态描述的是允许达到的最优现金。为了表达“至多两次交易”，可以把未使用的交易次数看作利润为 0 的空操作。这样最终直接读取第二次卖出状态仍然正确。
</Callout>

## 9. 手算示例

以：

```text
prices = [3, 3, 5, 0, 0, 3, 1, 4]
```

为例。

原资料中的状态示意图如下：

![买卖股票的最佳时机 III 状态变化](https://file1.kamacoder.com/i/algo/20201228181724295-20230310134201291.png)

我们使用四个有效交易状态：

| 天数 | 价格 | 第一次买 `buy1` | 第一次卖 `sell1` | 第二次买 `buy2` | 第二次卖 `sell2` |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 | 3 | -3 | 0 | -3 | 0 |
| 1 | 3 | -3 | 0 | -3 | 0 |
| 2 | 5 | -3 | 2 | -3 | 2 |
| 3 | 0 | 0 | 2 | 2 | 2 |
| 4 | 0 | 0 | 2 | 2 | 2 |
| 5 | 3 | 0 | 3 | 2 | 5 |
| 6 | 1 | 0 | 3 | 2 | 5 |
| 7 | 4 | 0 | 4 | 2 | 6 |

最终：

$$
\boxed{6}
$$

观察第 $3$ 天价格为 $0$ 时：

$$
buy2=2
$$

含义是：

> 第一笔交易已经赚了 $2$，再以 $0$ 元买入第二次股票，因此第二次持有状态仍保留 $2$ 元现金。

这正是多阶段股票 DP 最重要的思想。

## 10. C++：二维 DP

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        vector<vector<int>> dp(n, vector<int>(5, 0));

        dp[0][1] = -prices[0];
        dp[0][3] = -prices[0];

        for (int i = 1; i < n; ++i) {
            dp[i][0] = dp[i - 1][0];
            dp[i][1] = max(dp[i - 1][1], -prices[i]);
            dp[i][2] = max(dp[i - 1][2], dp[i - 1][1] + prices[i]);
            dp[i][3] = max(dp[i - 1][3], dp[i - 1][2] - prices[i]);
            dp[i][4] = max(dp[i - 1][4], dp[i - 1][3] + prices[i]);
        }

        return dp[n - 1][4];
    }
};
```

时间复杂度：

$$
O(n)
$$

空间复杂度：

$$
O(n)
$$

因为状态数始终只有常数个。

## 11. 为什么最终返回 `dp[n - 1][4]`

题目要求的是“最多两次交易”，并不是“必须恰好两次交易”。

因为初始化允许未使用交易次数对应零利润，所以：

$$
dp[n-1][4]
$$

已经包含了：

- 0 次交易；
- 1 次交易；
- 2 次交易；

中的最优情况。

因此可以直接返回第二次卖出状态。

## 12. 空间压缩：四变量状态机

每天只依赖前一天，所以二维数组可以压缩为四个变量：

- `buy1`：第一次买入后的最大现金；
- `sell1`：第一次卖出后的最大现金；
- `buy2`：第二次买入后的最大现金；
- `sell2`：第二次卖出后的最大现金。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int buy1 = -prices[0];
        int sell1 = 0;
        int buy2 = -prices[0];
        int sell2 = 0;

        for (int i = 1; i < prices.size(); ++i) {
            int prevBuy1 = buy1;
            int prevSell1 = sell1;
            int prevBuy2 = buy2;
            int prevSell2 = sell2;

            buy1 = max(prevBuy1, -prices[i]);
            sell1 = max(prevSell1, prevBuy1 + prices[i]);
            buy2 = max(prevBuy2, prevSell1 - prices[i]);
            sell2 = max(prevSell2, prevBuy2 + prices[i]);
        }

        return sell2;
    }
};
```

空间复杂度：

$$
O(1)
$$

## 13. 能不能直接原地顺序更新四个变量

你可能会看到这种写法：

```cpp
buy1 = max(buy1, -price);
sell1 = max(sell1, buy1 + price);
buy2 = max(buy2, sell1 - price);
sell2 = max(sell2, buy2 + price);
```

在本题中它仍然可以得到正确答案，因为同一天完成“卖出再买入”只会产生 $0$ 的额外变化，不会凭空制造利润。

但从状态转移的严格语义看，每个状态本来依赖的是“前一天”的状态。

因此学习阶段更推荐显式保存旧值：

```text
prevBuy1
prevSell1
prevBuy2
prevSell2
```

这样逻辑和公式一一对应，也更容易迁移到带冷冻期等不能随意同日转移的问题。

## 14. 从一次交易到两次交易：状态如何扩展

### 最多一次交易

只有：

```text
第一次买入
第一次卖出
```

转移：

$$
buy_1=\max(buy_1,-price)
$$

$$
sell_1=\max(sell_1,buy_1+price)
$$

### 最多两次交易

继续追加：

```text
第二次买入
第二次卖出
```

于是：

$$
buy_2=\max(buy_2,sell_1-price)
$$

$$
sell_2=\max(sell_2,buy_2+price)
$$

所以从结构上看，本题只是把状态链继续延长。

<Callout type="info" title="这就是下一题“最多 k 次交易”的雏形">
如果最多允许 $k$ 次交易，那么就会出现 $2k$ 个买卖状态：`buy1 → sell1 → buy2 → sell2 → ... → buyk → sellk`。下一题只需要把这里的四个状态推广成循环即可。
</Callout>

## 15. 一个统一公式

把第 $t$ 次交易记为：

$$
buy_t
$$

和：

$$
sell_t
$$

则可以写成：

对于第一次买入：

$$
\boxed{
buy_1(i)=\max(buy_1(i-1),-prices[i])
}
$$

对于第 $t$ 次买入，其中 $t\ge 2$：

$$
\boxed{
buy_t(i)=\max(buy_t(i-1),sell_{t-1}(i-1)-prices[i])
}
$$

对于任意第 $t$ 次卖出：

$$
\boxed{
sell_t(i)=\max(sell_t(i-1),buy_t(i-1)+prices[i])
}
$$

这已经几乎就是“最多 $k$ 次交易”的通式。

## 16. 高频易错点

### 易错点一：第二次买入仍然写成 `-prices[i]`

这样会丢失第一笔交易的利润。

正确来源是：

$$
sell_1-price
$$

### 易错点二：只用“持有 / 不持有”两个状态

两个状态无法记录已经用了几次交易，因此无法限制“最多两次”。

### 易错点三：把交易次数理解成操作次数

一笔完整交易包含：

```text
买入 + 卖出
```

最多两笔交易意味着最多进行两次完整买卖，而不是只能操作两次。

### 易错点四：第二次买入必须真的发生在第一次卖出后的第二天

不需要。

状态表示的是最大现金，不要求每个阶段之间必须间隔一天。只要不同时持有多股，同一天完成卖出和再次买入不会额外获利。

### 易错点五：最后取四个状态中的最大值

理论上可以比较，但没有必要。

由于卖出状态已经允许少做交易，最终直接返回：

$$
sell_2
$$

即可。

## 17. 与前两道股票题放在一起看

| 题目 | 交易限制 | 状态设计 | 买入时的来源 |
| --- | --- | --- | --- |
| 121 | 最多 1 次 | `hold / cash` | 初始现金 `0` |
| 122 | 任意多次 | `hold / cash` | 上一次不持有状态 |
| 123 | 最多 2 次 | `buy1 / sell1 / buy2 / sell2` | 上一个交易阶段 |

可以看到，股票 DP 的核心问题始终是：

$$
\boxed{
\text{当前状态允许从哪些前驱状态转移而来？}
}
$$

交易规则不同，本质上只是状态图不同。

    public int maxProfit(int[] prices) {
        int buy1 = -prices[0];
        int sell1 = 0;

}
