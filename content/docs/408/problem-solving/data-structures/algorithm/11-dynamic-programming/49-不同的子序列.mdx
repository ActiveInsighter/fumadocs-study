# 115. 不同的子序列

[LeetCode 115：不同的子序列](https://leetcode.cn/problems/distinct-subsequences/)

给定两个字符串 `s` 和 `t`，统计 `s` 的所有子序列中，等于 `t` 的子序列共有多少个。

子序列允许删除任意字符，但必须保持剩余字符的相对顺序。

例如：

```text
s = "rabbbit"
t = "rabbit"
```

通过删除 `s` 中不同位置的一个 `b`，可以得到多个不同的 `rabbit`，因此答案不是简单的 `true / false`，而是一个**方案数**。

![不同的子序列示例](https://file1.kamacoder.com/i/algo/115.%E4%B8%8D%E5%90%8C%E7%9A%84%E5%AD%90%E5%BA%8F%E5%88%97%E7%A4%BA%E4%BE%8B.jpg)

<Callout type="info" title="这题是判断子序列的计数升级版">
上一题只问 `t` 能不能从 `s` 中选出来，本题则问一共有多少种选法。状态从布尔值升级成方案数，但核心仍然是：扫描 `s`，对当前字符决定“使用”还是“跳过”。
</Callout>

## 1. 问题的本质：从 `s` 中选位置

设：

```text
s = "babgbag"
t = "bag"
```

我们真正选择的不是字符本身，而是 `s` 中的一组下标：

$$
i_1<i_2<\cdots<i_{|t|}
$$

并且满足：

$$
s[i_k]=t[k]
$$

因此，不同的下标组合就是不同的子序列方案。

这也解释了为什么即使两个相同字符看起来没有区别，只要它们来自 `s` 中不同的位置，就必须算作不同方案。

## 2. 为什么不能用双指针

判断子序列时，双指针只需要找到一条可行匹配链即可。

但本题需要统计所有匹配链。

例如：

```text
s = "bagg"
t = "bag"
```

最后两个 `g` 都可以作为 `t` 的最后一个字符，因此至少存在两条不同选择路径。

双指针一旦贪心地选中某个位置，就会丢掉其他方案。

所以需要动态规划保存“截至当前位置一共有多少种选法”。

## 3. 状态定义

定义：

$$
\boxed{
dp[i][j]
=
\text{用 }s\text{ 的前 }i\text{ 个字符构造 }t\text{ 的前 }j\text{ 个字符的方案数}
}
$$

也就是：

```text
s[0 ... i-1]
t[0 ... j-1]
```

最终答案为：

$$
\boxed{dp[|s|][|t|]}
$$

这个定义比“以某个字符结尾”更推荐，因为它天然兼容空字符串边界。

## 4. 最关键的一步：看 `s[i-1]` 用不用

对于状态 `dp[i][j]`，我们只需要讨论 `s` 当前最后一个字符：

```text
s[i - 1]
```

它只有两种命运：

1. 用它去匹配 `t[j-1]`；
2. 不用它，直接跳过。

这正是本题转移公式的来源。

## 5. 当前字符相等时：两个分支都要算

如果：

$$
s[i-1]=t[j-1]
$$

此时不能因为字符相等就强制匹配。

### 分支一：使用 `s[i-1]`

既然当前两个字符完成匹配，那么前面的部分需要完成：

```text
s 的前 i-1 个字符 -> t 的前 j-1 个字符
```

方案数为：

$$
dp[i-1][j-1]
$$

### 分支二：不使用 `s[i-1]`

即使字符相等，我们仍然可以跳过当前 `s[i-1]`。

那么问题退化为：

```text
s 的前 i-1 个字符 -> t 的前 j 个字符
```

方案数为：

$$
dp[i-1][j]
$$

因此：

$$
\boxed{
dp[i][j]=dp[i-1][j-1]+dp[i-1][j]
}
$$

<Callout type="warning" title="字符相等 ≠ 必须使用">
这是本题最容易写错的地方。因为题目统计的是“所有子序列方案”，所以当前字符即使可以匹配，也仍然存在“跳过它”的合法方案。
</Callout>

### 一个最小例子

```text
s = "bagg"
t = "bag"
```

扫描到最后一个 `g` 时：

```text
当前 g 可以用
当前 g 也可以不用
```

于是方案数必须把两部分相加。

## 6. 当前字符不相等时：只能跳过 `s[i-1]`

如果：

$$
s[i-1]\ne t[j-1]
$$

当前 `s[i-1]` 无法承担 `t[j-1]` 的匹配任务，所以只能忽略它。

于是：

$$
\boxed{
dp[i][j]=dp[i-1][j]
}
$$

注意，这里不能写成跳过 `t[j-1]`。

因为题目要求构造完整的 `t`，`t` 中的字符不能随意删除；允许被选择或跳过的是 `s` 中的字符。

## 7. 完整状态转移

综合两种情况：

$$
\boxed{
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+dp[i-1][j], & s[i-1]=t[j-1]\\
dp[i-1][j], & s[i-1]\ne t[j-1]
\end{cases}}
$$

可以把它记成一句话：

> 相等时 = 用当前字符的方案 + 不用当前字符的方案；不等时 = 只能不用当前字符。

## 8. 初始化：为什么 `dp[i][0] = 1`

初始化是本题第二个高频错误点。

### `t` 为空字符串

当：

$$
j=0
$$

目标字符串为空。

不管 `s` 有多少个字符，都只有一种办法构造空字符串：

```text
一个字符都不选
```

所以：

$$
\boxed{dp[i][0]=1}
$$

包括：

$$
dp[0][0]=1
$$

### `s` 为空但 `t` 非空

当：

$$
i=0,
\qquad j>0
$$

空字符串无法构造非空字符串，因此：

$$
\boxed{dp[0][j]=0}
$$

最终边界为：

$$
\boxed{
dp[i][0]=1,
\qquad
dp[0][j]=0\;(j>0)
}
$$

<Callout type="tip" title="计数 DP 中的 dp[0] 往往代表空方案">
背包计数、字符串计数等问题中，经常需要把“什么都不选”视作一种合法方案。这里的 `dp[i][0]=1` 与背包计数中的 `dp[0]=1` 本质非常接近。
</Callout>

## 9. 遍历顺序

`dp[i][j]` 依赖：

$$
dp[i-1][j-1]
$$

和：

$$
dp[i-1][j]
$$

即左上方和正上方。

![不同子序列 DP 依赖方向](https://file1.kamacoder.com/i/algo/20221222165412.png)

因此二维 DP 正常按照：

```text
i 从小到大
j 从小到大
```

即可。

## 10. 手推一个例子

设：

```text
s = "baegg"
t = "bag"
```

原题状态表示意如下：

![不同的子序列 DP 表](https://file1.kamacoder.com/i/algo/115.%E4%B8%8D%E5%90%8C%E7%9A%84%E5%AD%90%E5%BA%8F%E5%88%97.jpg)

可以重点观察最后的两个 `g`。

因为每一个 `g` 都可能作为 `t` 的最后一个字符，所以当字符相等时，方案数会发生累加，而不是覆盖。

## 11. 二维 DP 标准代码

```cpp
class Solution {
public:
    int numDistinct(string s, string t) {
        int n = s.size();
        int m = t.size();

        vector<vector<unsigned long long>> dp(
            n + 1,
            vector<unsigned long long>(m + 1, 0)
        );

        for (int i = 0; i <= n; ++i) {
            dp[i][0] = 1;
        }

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                dp[i][j] = dp[i - 1][j];

                if (s[i - 1] == t[j - 1]) {
                    dp[i][j] += dp[i - 1][j - 1];
                }
            }
        }

        return static_cast<int>(dp[n][m]);
    }
};
```

时间复杂度：

$$
\boxed{O(|s||t|)}
$$

空间复杂度：

$$
\boxed{O(|s||t|)}
$$

## 12. 一个非常实用的剪枝

如果：

$$
|s|<|t|
$$

那么 `s` 无论如何删除，都不可能得到更长的 `t`。

因此可以直接返回：

```cpp
if (s.size() < t.size()) return 0;
```

此外，在二维循环中，如果：

$$
j>i
$$

也没有必要计算，因为 `s` 的前 `i` 个字符不可能构造长度为 `j` 的字符串。

所以内层可以写成：

```cpp
for (int j = 1; j <= min(i, m); ++j)
```

## 13. 一维压缩

二维转移：

$$
dp[i][j]
\leftarrow
dp[i-1][j]
\text{ 和 }
dp[i-1][j-1]
$$

只依赖上一行，所以可以压缩成一维：

$$
\boxed{dp[j]=\text{当前扫描过的 }s\text{ 前缀构造 }t\text{ 前 }j\text{ 个字符的方案数}}
$$

初始化：

$$
dp[0]=1
$$

其他位置为 $0$。

当：

$$
s[i-1]=t[j-1]
$$

更新：

$$
\boxed{dp[j]\mathrel{+}=dp[j-1]}
$$

## 14. 为什么一维 DP 必须倒序

这是这道题最值得掌握的空间压缩技巧。

二维公式使用的是：

$$
dp[i-1][j-1]
$$

也就是“上一行”的左上角。

如果一维数组从左往右更新：

```cpp
for (int j = 1; j <= m; ++j)
```

那么 `dp[j-1]` 已经被当前这一轮 `s[i-1]` 修改过。

这会导致同一个 `s[i-1]` 被重复使用多次。

因此必须：

$$
\boxed{j\text{ 从大到小遍历}}
$$

从而保证读取到的 `dp[j-1]` 仍然属于上一轮状态。

<Callout type="warning" title="倒序的本质不是口诀，而是防止重复使用当前字符">
这和 01 背包容量倒序完全同源：每个 `s` 中的位置只能使用一次，所以压缩状态后必须避免当前轮刚写入的值再次参与本轮更新。
</Callout>

## 15. 一维 DP 代码

```cpp
class Solution {
public:
    int numDistinct(string s, string t) {
        if (s.size() < t.size()) return 0;

        vector<unsigned long long> dp(t.size() + 1, 0);
        dp[0] = 1;

        for (char c : s) {
            for (int j = static_cast<int>(t.size()); j >= 1; --j) {
                if (c == t[j - 1]) {
                    dp[j] += dp[j - 1];
                }
            }
        }

        return static_cast<int>(dp[t.size()]);
    }
};
```

复杂度变为：

$$
T=O(|s||t|)
$$

$$
S=O(|t|)
$$

## 16. 它和 01 背包计数为什么很像

把 `s` 的每个字符看作一个“只能使用一次的物品”。

对于当前字符：

- 不选；
- 如果字符匹配，则选它推进 `t` 的匹配长度。

于是：

$$
dp[j]+=dp[j-1]
$$

这与 01 背包中的计数转移：

$$
dp[j]+=dp[j-w]
$$

具有相同结构。

区别只是这里的“容量”不是数值，而是目标字符串的前缀长度。

这也是为什么一维压缩同样要倒序。

## 17. 与上一题“判断子序列”的区别

| 问题 | 状态保存什么 | 字符相等时 | 字符不等时 |
| --- | --- | --- | --- |
| 判断子序列 | 是否 / 匹配长度 | 继续匹配 | 跳过源串字符 | 
| 不同的子序列 | 方案数 | **用 + 不用** | 只能不用 |

最核心的变化是：

> 从“是否存在一条路径”升级成“统计所有路径”。

因此原本的选择分支不再取 `max` 或布尔值，而是进行**加法计数**。

## 18. 与最长公共子序列的区别

LCS 的目标是：

```text
最大长度
```

本题的目标是：

```text
构造固定目标 t 的方案数
```

所以当字符不等时，LCS 会在两个方向取最大值：

$$
\max(dp[i-1][j],dp[i][j-1])
$$

而本题只能删除 `s` 中字符，因此：

$$
dp[i][j]=dp[i-1][j]
$$

再次说明：

> 二维字符串 DP 的公式，最终都来自“允许对哪个字符串做什么操作”。

## 19. 常见错误

### 错误一：相等时只写左上角

错误：

```cpp
dp[i][j] = dp[i - 1][j - 1];
```

这样会漏掉“不使用当前 `s[i-1]`”的所有方案。

正确是：

$$
dp[i][j]=dp[i-1][j-1]+dp[i-1][j]
$$

### 错误二：`dp[i][0]` 初始化成 0

空字符串的构造方案不是 $0$，而是：

```text
什么都不选
```

这一种方案。

所以：

$$
dp[i][0]=1
$$

### 错误三：一维数组正序更新

正序会让同一个 `s` 字符在一轮中被使用多次。

必须倒序：

```cpp
for (int j = m; j >= 1; --j)
```

### 错误四：把“字符相同”误解成“位置相同”

题目统计的是位置选择方案。

`s` 中两个相同字符来自不同下标时，它们是不同选择。

## 20. 解题模板

遇到类似题目，可以按下面顺序判断：

```text
1. 是否在一个源序列中选择若干位置？
2. 每个位置是否最多使用一次？
3. 目标是否要求保持顺序？
4. 是判断存在性、求最优值，还是统计方案数？
```

如果是：

```text
源串中选位置 + 保序 + 每个位置一次 + 统计方案数
```

就应该高度警觉：

$$
\boxed{
\text{计数型二维字符串 DP / 01 背包式倒序压缩}
}
$$

## 21. 本题总结

这道题真正需要记住的不是代码，而是以下四点：

1. `dp[i][j]` 表示源串前 `i` 个字符构造目标串前 `j` 个字符的方案数；
2. 字符相等时，当前字符有“用”和“不用”两个分支，所以要相加；
3. `dp[i][0]=1` 代表构造空串只有一种方式；
4. 一维压缩必须倒序，本质是避免同一个源字符被重复使用。

最终二维转移：

$$
\boxed{
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+dp[i-1][j], & s[i-1]=t[j-1]\\
dp[i-1][j], & s[i-1]\ne t[j-1]
\end{cases}}
$$

一维转移：

$$
\boxed{
\text{若 }s[i-1]=t[j-1],\quad dp[j]+=dp[j-1]
}
$$

到这里，你已经从“子序列是否存在”进一步进入了“子序列方案计数”这一类 DP。

## 其他语言版本



### Java


```java
class Solution {
    public int numDistinct(String s, String t) {
        long[] dp = new long[t.length() + 1];
        dp[0] = 1;

        for (int i = 0; i < s.length(); i++) {
            for (int j = t.length(); j >= 1; j--) {
                if (s.charAt(i) == t.charAt(j - 1)) {
                    dp[j] += dp[j - 1];
                }
            }
        }

        return (int) dp[t.length()];
    }
}
```



### Python

```python
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        dp = [0] * (len(t) + 1)
        dp[0] = 1

        for ch in s:
            for j in range(len(t), 0, -1):
                if ch == t[j - 1]:
                    dp[j] += dp[j - 1]

        return dp[-1]
```
