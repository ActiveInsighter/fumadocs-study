# 392. 判断子序列

[LeetCode 392：判断子序列](https://leetcode.cn/problems/is-subsequence/)

给定字符串 `s` 和 `t`，判断 `s` 是否是 `t` 的子序列。

子序列允许从原字符串中删除若干字符，但不能改变剩余字符的相对顺序。

例如：

```text
s = "abc"
t = "ahbgdc"
```

可以从 `t` 中依次找到：

```text
a -> b -> c
```

因此返回：

```text
true
```

而：

```text
s = "axc"
t = "ahbgdc"
```

无法按顺序匹配 `a -> x -> c`，所以返回：

```text
false
```

<Callout type="info" title="这题本身双指针更简单，但 DP 非常值得学">
如果只解决这一题，双指针可以做到 $O(|t|)$。但动态规划版本能够非常自然地连接到最长公共子序列、不同的子序列、删除操作和编辑距离，因此在 DP 学习路线里非常重要。
</Callout>

## 1. 先看最直接的思路：双指针

维护两个指针：

```text
i -> s
j -> t
```

遍历 `t`：

- 如果 `s[i] == t[j]`，说明当前字符匹配成功，`i++`；
- 无论是否匹配，`j` 都继续向右。

当：

$$
i=|s|
$$

说明 `s` 的所有字符都已经按顺序匹配完成。

```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0;

        for (char c : t) {
            if (i < s.size() && s[i] == c) {
                ++i;
            }
        }

        return i == s.size();
    }
};
```

复杂度：

$$
T=O(|t|),\qquad S=O(1)
$$

但这一章重点仍然放在动态规划，因为它揭示了编辑距离类问题的状态结构。

## 2. 为什么它属于“编辑距离”体系

为了让 `s` 成为 `t` 的子序列，我们可以把问题理解为：

> 是否能够只通过删除 `t` 中的一些字符，使它保留下来的字符序列恰好包含完整的 `s`？

这里允许的操作只有一种：

```text
删除 t 中的字符
```

因此它可以看作编辑距离问题的极简版本。

后续问题会逐渐加入：

- 两边都可以删除；
- 插入；
- 替换；
- 统计方案数。

所以这一题很适合建立二维字符串 DP 的直觉。

## 3. 状态定义

定义：

$$
\boxed{
dp[i][j]
=
s[0\ldots i-1]\text{ 与 }t[0\ldots j-1]\text{ 的最长公共子序列长度}
}
$$

但和标准 LCS 不同的是，本题有一个额外方向性：

> 我们只关心能否把 `s` 完整地从 `t` 中匹配出来。

因此当字符不匹配时，只需要考虑“跳过 `t` 当前字符”，而不需要跳过 `s` 当前字符。

最终如果：

$$
\boxed{dp[|s|][|t|]=|s|}
$$

就说明 `s` 的所有字符都能按顺序出现在 `t` 中。

## 4. 字符相等时怎么转移

如果：

$$
s[i-1]=t[j-1]
$$

那么这一对字符可以匹配。

于是：

$$
\boxed{dp[i][j]=dp[i-1][j-1]+1}
$$

含义是：

> 前面的匹配长度再加上当前这一对字符。

## 5. 字符不相等时为什么只看左边

如果：

$$
s[i-1]\ne t[j-1]
$$

由于目标是判断 `s` 是否能从 `t` 中抽出来，所以当前的 `t[j-1]` 可以直接忽略。

相当于删除它：

$$
\boxed{dp[i][j]=dp[i][j-1]}
$$

完整转移为：

$$
\boxed{
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+1, & s[i-1]=t[j-1]\\
dp[i][j-1], & s[i-1]\ne t[j-1]
\end{cases}
}
$$

<Callout type="warning" title="它和最长公共子序列只差一个分支，但语义不同">
标准 LCS 在字符不相等时使用 $\max(dp[i-1][j],dp[i][j-1])$，因为两个字符串都允许跳过字符。本题只需要从 `t` 中删除，因此只保留 `dp[i][j-1]`。
</Callout>

## 6. 初始化

状态表大小为：

$$
(|s|+1)\times(|t|+1)
$$

第 $0$ 行表示 `s` 为空字符串，第 $0$ 列表示 `t` 为空字符串。

最长公共子序列长度显然均为 $0$：

$$
\boxed{dp[0][j]=0}
$$

$$
\boxed{dp[i][0]=0}
$$

## 7. 遍历顺序

状态依赖：

$$
dp[i-1][j-1]
$$

和：

$$
dp[i][j-1]
$$

因此按：

```text
从上到下
从左到右
```

遍历即可。

$$

$$

说明 `s` 是 `t` 的子序列。

## 9. 二维 DP 标准代码

```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int n = s.size();
        int m = t.size();

        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                if (s[i - 1] == t[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = dp[i][j - 1];
                }
            }
        }

        return dp[n][m] == n;
    }
};
```

复杂度：

$$
T=O(|s||t|)
$$

$$
S=O(|s||t|)
$$

## 10. 一个更直接的布尔 DP 定义

其实本题还可以把状态直接定义成真假：

$$
\boxed{dp[i][j]=s\text{ 的前 }i\text{ 个字符是否是 }t\text{ 的前 }j\text{ 个字符的子序列}}
$$

初始化：

$$
dp[0][j]=true
$$

因为空字符串是任何字符串的子序列。

而：

$$
dp[i][0]=false\quad(i>0)
$$

转移：

如果当前字符相等：

$$
dp[i][j]=dp[i-1][j-1]\lor dp[i][j-1]
$$

如果不相等：

$$
dp[i][j]=dp[i][j-1]
$$

实际上，因为即使当前字符相等，也可以选择跳过 `t[j-1]`，所以写成上式更完整。

不过为了衔接后面的 LCS / 编辑距离体系，本章仍以“匹配长度”定义作为主线。

## 11. 一维压缩怎么做

如果把 `t` 放在外层遍历，把 `s` 的匹配长度作为一维状态，可以定义：

$$
dp[j]=\text{当前扫描到的 }t\text{ 前缀中，能匹配 }s\text{ 前 }j\text{ 个字符的最大长度}
$$

更直接的写法是保留原始 LCS 长度语义。

由于更新 `dp[j]` 时需要上一轮的 `dp[j-1]`，所以必须**倒序遍历 `j`**，避免本轮刚更新的值被重复使用。

```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        vector<int> dp(s.size() + 1, 0);

        for (char c : t) {
            for (int j = s.size(); j >= 1; --j) {
                if (c == s[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                }
            }
        }

        return dp[s.size()] == s.size();
    }
};
```

空间复杂度下降为：

$$
S=O(|s|)
$$

不过对于这道题本身，双指针仍然是更简单、更优雅的方案。

## 12. 为什么双指针比 DP 更适合单次判断

设：

$$
n=|s|,\qquad m=|t|
$$

二维 DP：

$$
O(nm)
$$

双指针：

$$
O(m)
$$

而且双指针只需要常数空间。

因此如果面试题只是单独问：

> 判断一次 `s` 是否为 `t` 的子序列。

优先使用双指针。

但如果你正在学习动态规划，那么这道题的 DP 价值在于：

> 它展示了“编辑操作受到方向限制”时，二维字符串 DP 如何删掉不必要的转移分支。

## 13. 进阶：如果有海量 `s` 查询怎么办

题目进阶会问：

> 如果有大量字符串 `s1, s2, ..., sk`，都要判断它们是否为同一个 `t` 的子序列，该怎么办？

如果每次都双指针扫描完整 `t`，总复杂度可能很高。

可以预处理：

```text
每个字符在 t 中出现的所有位置
```

例如：

```text
t = "abacaba"

a -> [0, 2, 4, 6]
b -> [1, 5]
c -> [3]
```

然后对每个 `s` 中的字符，利用二分搜索寻找“严格大于上一次匹配位置”的最靠左位置。

如果：

$$
|t|=m
$$

预处理为 $O(m)$，单个查询大约可以做到：

$$
O(|s|\log m)
$$

这说明：

> 同一个问题，在“单次查询”和“海量查询”两个场景下，最优算法可能完全不同。

## 14. 和最长公共子序列的对比

| 问题 | 字符相等 | 字符不等 | 谁可以被跳过 |
| --- | --- | --- | --- |
| 判断子序列 | `dp[i-1][j-1] + 1` | `dp[i][j-1]` | 只跳过 `t` |
| 最长公共子序列 | `dp[i-1][j-1] + 1` | `max(dp[i-1][j], dp[i][j-1])` | 两边都可以跳过 |

这一张表非常重要。

它告诉你：

> 状态转移不是死记公式，而是由“允许做什么操作”决定的。

## 15. 常见错误

### 错误一：字符不等时写成 LCS 的转移

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

虽然最终很多情况下也能得到最长公共子序列，但它没有体现本题“只从 `t` 中跳过字符”的方向性，也失去了作为编辑距离入门题的意义。

### 错误二：忘记空字符串

如果：

```text
s = ""
```

那么答案永远是：

```text
true
```

因为空字符串是任意字符串的子序列。

### 错误三：把子序列理解成子串

```text
"ace"
```

是：

```text
"abcde"
```

的子序列，但不是子串。

子串要求连续，子序列不要求连续。

## 16. 学习路线中的位置

可以把接下来的字符串 DP 看成逐步增加操作自由度：

```text
判断子序列
    ↓
不同的子序列
    ↓
两个字符串的删除操作
    ↓
编辑距离
```

其中本题最简单：

```text
只允许跳过 t 的字符
```

后面会逐步加入：

```text
计数、双方删除、插入、替换
```



### 双指针

单次判断的首选。时间复杂度 $O(|t|)$，空间复杂度 $O(1)$。


### 动态规划

适合训练二维字符串 DP，并帮助理解编辑距离系列中“操作决定转移”的思想。


### 进阶预处理

当同一个 `t` 面对大量 `s` 查询时，预处理字符位置并二分查找更加合适。

## 18. 一句话总结

判断子序列的本质是：

$$
\boxed{\text{能否在 }t\text{ 中按顺序匹配完 }s\text{ 的全部字符}}
$$

单次判断时，双指针最优；从动态规划视角看，它又可以理解为：

$$
\boxed{\text{字符不匹配时，只允许删除 }t\text{ 当前字符}}
$$

这正是后续编辑距离系列最值得建立的第一层状态直觉。
