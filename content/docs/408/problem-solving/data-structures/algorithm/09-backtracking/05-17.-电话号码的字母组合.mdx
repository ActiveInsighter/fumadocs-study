# 17. 电话号码的字母组合

给定一个只包含数字 `2`～`9` 的字符串，返回它能够表示的所有字母组合。

![17.电话号码的字母组合](https://file1.kamacoder.com/i/algo/2020102916424043.png)

例如：

```text
输入：digits = "23"
输出：["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

<Callout title="这道题最重要的不是写出回溯，而是看清搜索对象">

`77. 组合`是在**同一个集合**里不断向后选；本题则是在**多个不同集合**中，每个集合恰好选一个元素。

如果：

$$
2\rightarrow\{a,b,c\},\qquad 3\rightarrow\{d,e,f\}
$$

那么答案本质上就是两个集合的笛卡尔积：

$$
\{a,b,c\}\times\{d,e,f\}
$$

回溯只是用递归把任意长度的笛卡尔积写出来。

</Callout>

## 1. 为什么普通 for 循环不够？

若输入是 `"23"`，确实可以写两层循环：

```cpp
for (char a : "abc") {
    for (char b : "def") {
        // ...
    }
}
```

但如果输入长度变成 $m$，循环层数也必须变成 $m$。

输入长度是运行时才知道的，我们不可能预先写好任意层嵌套循环。

这正是回溯擅长解决的问题：

> 用递归深度表示“当前写到了第几层循环”。

所以：

$$
\text{第 }index\text{ 层递归}
\Longleftrightarrow
\text{处理 digits[index] 对应的字符集合}
$$

## 2. 数字如何映射到字母？

最直接的方式是建立一个长度为 10 的映射表：

```cpp
const string letterMap[10] = {
    "",     // 0
    "",     // 1
    "abc",  // 2
    "def",  // 3
    "ghi",  // 4
    "jkl",  // 5
    "mno",  // 6
    "pqrs", // 7
    "tuv",  // 8
    "wxyz"  // 9
};
```

这样数字字符 `'7'` 可以先转成整数：

```cpp
int digit = digits[index] - '0';
```

再得到当前可选字符集合：

```cpp
const string& letters = letterMap[digit];
```

## 3. 搜索树如何理解？

以 `digits = "23"` 为例：

![17. 电话号码的字母组合](https://file1.kamacoder.com/i/algo/20201123200304469.png)

根节点表示空字符串。

第一层处理数字 `2`，有：

$$
a,b,c
$$

三个分支；第二层处理数字 `3`，每个节点再产生：

$$
d,e,f
$$

三个分支。

叶子节点恰好就是所有完整答案。

### 深度和宽度

如果输入长度为 $m$：

- 搜索树深度固定为 $m$；
- 每一层的分支数由当前按键对应的字母数量决定；
- `7` 和 `9` 有 4 个字母，其余 `2,3,4,5,6,8` 有 3 个字母。

## 4. 这里为什么不是 `startIndex`？

这是本题最容易和组合问题混淆的地方。

在 `77. 组合` 中：

```text
候选都来自同一个集合 [1, 2, ..., n]
```

为了避免重复组合，下一层只允许从当前元素后面继续，所以需要 `startIndex`。

而在本题中：

```text
第 0 层：只能从 digits[0] 对应的字母集合中选
第 1 层：只能从 digits[1] 对应的字母集合中选
第 2 层：只能从 digits[2] 对应的字母集合中选
...
```

每层对应的是**不同集合**，因此状态不是“从集合哪里开始”，而是：

$$
index=\text{当前处理 digits 的第几个位置}
$$

<Callout type="warn" title="两个参数的语义完全不同">

- `startIndex`：同一候选集合中，为了避免回头选而记录“从哪里开始”；
- `index`：多个候选集合之间，记录“当前轮到哪个集合”。

名字看起来都像下标，但搜索语义不同。

</Callout>

## 5. 回溯三部曲

### ① 递归参数

需要：

```cpp
void backtracking(const string& digits, int index)
```

同时维护：

- `path`：已经构造出的部分字符串；
- `result`：最终答案。

`index` 同时表示：

$$
\text{递归深度}=\text{当前待处理的数字位置}
$$

### ② 终止条件

当：

$$
index=digits.size()
$$

说明每个数字都已经选过一个字母，当前 `path` 一定是一个完整结果：

```cpp
if (index == digits.size()) {
    result.push_back(path);
    return;
}
```

### ③ 单层搜索

本层只枚举当前数字对应的字母：

```cpp
int digit = digits[index] - '0';
const string& letters = letterMap[digit];

for (char ch : letters) {
    path.push_back(ch);
    backtracking(digits, index + 1);
    path.pop_back();
}
```

下一层一定处理 `digits[index + 1]`。

## 6. 完整 C++ 实现

```cpp title="C++：显式回溯"
class Solution {
private:
    const string letterMap[10] = {
        "", "", "abc", "def", "ghi",
        "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    vector<string> result;
    string path;

    void backtracking(const string& digits, int index) {
        if (index == digits.size()) {
            result.push_back(path);
            return;
        }

        int digit = digits[index] - '0';
        const string& letters = letterMap[digit];

        for (char ch : letters) {
            path.push_back(ch);                 // 选择
            backtracking(digits, index + 1);   // 进入下一个集合
            path.pop_back();                   // 撤销选择
        }
    }

public:
    vector<string> letterCombinations(string digits) {
        result.clear();
        path.clear();

        if (digits.empty()) return result;

        backtracking(digits, 0);
        return result;
    }
};
```

## 7. 手动模拟 `"23"`

初始状态：

$$
path="",\quad index=0
$$

第一层处理 `2 -> abc`。

选择 `a`：

$$
path="a",\quad index=1
$$

第二层处理 `3 -> def`，依次得到：

```text
ad
ae
af
```

然后回溯到：

$$
path=""
$$

继续选择 `b`、`c`，最终得到 9 个叶子节点。

关键变化可以概括为：

```text
选择字符 -> index + 1 -> 处理下一组字符 -> 撤销字符
```

## 8. 为什么每层都要从当前字符集合的第一个字母开始？

例如第二层处理数字 `3` 时，无论第一层选择的是 `a`、`b` 还是 `c`，第二层都应该完整枚举：

$$
d,e,f
$$

所以代码必须始终写成：

```cpp
for (char ch : letters)
```

而不是把上一层的循环位置传下来。

否则就会把本来彼此独立的集合错误地绑定在一起，导致漏解。

## 9. 从数学上看：这是笛卡尔积

若输入为：

$$
d_1d_2\cdots d_m
$$

每个数字对应字符集合：

$$
S_1,S_2,\dots,S_m
$$

那么答案集合就是：

$$
S_1\times S_2\times\cdots\times S_m
$$

每个答案恰好是：

$$
(c_1,c_2,\dots,c_m),\qquad c_i\in S_i
$$

回溯过程实际上是在逐坐标构造这个有序元组。

这个视角很重要，因为很多题虽然表面不是“电话号码”，本质却都是：

> 第 1 组选一个，第 2 组选一个，……，第 $m$ 组选一个。

这类问题通常都可以使用 `index` 型回溯。

## 10. 复杂度：为什么是 $3^a4^b$？

设输入中：

- 有 $a$ 个数字对应 3 个字母；
- 有 $b$ 个数字对应 4 个字母。

那么叶子节点数量就是：

$$
3^a4^b
$$

每个结果字符串长度为：

$$
a+b
$$

如果把构造并保存完整字符串的成本也算上，总输出量为：

$$
O\left((a+b)3^a4^b\right)
$$

若只讨论搜索树分支数量，经常简写为：

$$
O(3^a4^b)
$$

递归栈和当前路径长度最多为：

$$
O(a+b)
$$

而最终结果本身需要：

$$
O\left((a+b)3^a4^b\right)
$$

空间。

<Callout title="复杂度分析时要区分额外空间和输出空间">

很多回溯题的答案本身可能指数级增长。即使算法已经无法再优化输出数量，递归栈通常仍只有线性深度。

因此最好分别写：

- 额外空间：递归栈 + 当前路径；
- 输出空间：所有答案本身。

</Callout>

## 11. 为什么不推荐把回溯“藏”在字符串拼接里？

也可以写成：

```cpp
void dfs(const string& digits, int index, string current) {
    // ...
    dfs(digits, index + 1, current + ch);
}
```

这种写法逻辑上没有错，因为每次递归都获得了一个新的字符串副本，返回以后旧的 `current` 自然恢复。

但学习回溯时，更推荐显式写出：

```cpp
path.push_back(ch);
...
path.pop_back();
```

因为它更清楚地体现：

$$
\text{选择}\rightarrow\text{递归}\rightarrow\text{撤销选择}
$$

以后遇到数组、棋盘、集合等更复杂状态时，也更容易迁移。

## 12. 空输入与非法输入

LeetCode 本题约束保证 `digits` 只包含 `2`～`9`。

对于空字符串，标准返回值是空数组：

```cpp
if (digits.empty()) return {};
```

如果在真实工程或面试扩展题中输入可能包含 `0`、`1` 或其他字符，则需要先明确产品语义：

- 是直接返回空结果；
- 忽略非法字符；
- 还是抛出错误。

不能直接照搬竞赛题的输入假设。

## 13. 和前面组合题的对照

| 问题 | 每层从哪里选 | 控制递归推进的状态 | 是否需要 `startIndex` |
| --- | --- | --- | --- |
| 77. 组合 | 同一个集合 $1\sim n$ | 已选数量 + 起始位置 | 需要 |
| 216. 组合总和 III | 同一个集合 $1\sim9$ | 已选数量 + 起始位置 + 当前和 | 需要 |
| 17. 电话号码字母组合 | 每层一个不同字符集合 | 当前数字位置 `index` | 不需要 |

这张表比记代码更重要。

当你能先判断“每层是在同一个集合继续选，还是切换到下一个集合”，递归参数通常就自然确定了。

## 14. 回溯模板的另一种形态

同一集合中的组合常写成：

```text
backtrack(startIndex):
    for i from startIndex ...
        choose(i)
        backtrack(i + 1)
        undo(i)
```

多个集合之间的组合则更像：

```text
backtrack(index):
    if index == 集合数量:
        收集答案
        return

    for x in 当前第 index 个集合:
        choose(x)
        backtrack(index + 1)
        undo(x)
```

这是本题最值得迁移到其他题目的结构。

### Java

```java
class Solution {

    //设置全局列表存储最后的结果
    List<String> list = new ArrayList<>();

    public List<String> letterCombinations(String digits) {
        if (digits == null || digits.length() == 0) {
            return list;
        }
        //初始对应所有的数字，为了直接对应2-9，新增了两个无效的字符串""
        String[] numString = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        //迭代处理
        backTracking(digits, numString, 0);
        return list;

    }

    //每次迭代获取一个字符串，所以会涉及大量的字符串拼接，所以这里选择更为高效的 StringBuilder
    StringBuilder temp = new StringBuilder();

    //比如digits如果为"23",num 为0，则str表示2对应的 abc
    public void backTracking(String digits, String[] numString, int num) {
        //遍历全部一次记录一次得到的字符串
        if (num == digits.length()) {
            list.add(temp.toString());
            return;
        }
        //str 表示当前num对应的字符串
        String str = numString[digits.charAt(num) - '0'];
        for (int i = 0; i < str.length(); i++) {
            temp.append(str.charAt(i));
            //递归，处理下一层
            backTracking(digits, numString, num + 1);
            //剔除末尾的继续尝试
            temp.deleteCharAt(temp.length() - 1);
        }
    }
}
```

```go
var (
    m []string
    path []byte
    res []string
)
func letterCombinations(digits string) []string {
    m = []string{"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"}
    path, res = make([]byte, 0), make([]string, 0)
    if digits == "" {
        return res
    }
    dfs(digits, 0)
    return res
}
func dfs(digits string, start int) {
    if len(path) == len(digits) {  //终止条件，字符串长度等于digits的长度
        tmp := string(path)
        res = append(res, tmp)
        return
    }
    digit := int(digits[start] - '0')  // 将index指向的数字转为int（确定下一个数字）
    str := m[digit-2]   // 取数字对应的字符集（注意和map中的对应）
    for j := 0; j < len(str); j++ {
        path = append(path, str[j])
        dfs(digits, start+1)
        path = path[:len(path)-1]
    }
}
```

```javascript
var letterCombinations = function(digits) {
    const k = digits.length;
    const map = ["","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"];
    if(!k) return [];
    if(k === 1) return map[digits].split("");

    const res = [], path = [];
    backtracking(digits, k, 0);
    return res;

    function backtracking(n, k, a) {
        if(path.length === k) {

            return;
        }
        for(const v of map[n[a]]) {
            path.push(v);
            backtracking(n, k, a + 1);
            path.pop();
        }
    }
};
```

```typescript
function letterCombinations(digits: string): string[] {
    if (digits === '') return [];
    const strMap: { [index: string]: string[] } = {
        1: [],
        2: ['a', 'b', 'c'],
        3: ['d', 'e', 'f'],
        4: ['g', 'h', 'i'],
        5: ['j', 'k', 'l'],
        6: ['m', 'n', 'o'],
        7: ['p', 'q', 'r', 's'],
        8: ['t', 'u', 'v'],
        9: ['w', 'x', 'y', 'z'],
    }
    const resArr: string[] = [];
    function backTracking(digits: string, curIndex: number, route: string[]): void {
        if (curIndex === digits.length) {
            resArr.push(route.join(''));
            return;
        }
        let tempArr: string[] = strMap[digits[curIndex]];
        for (let i = 0, length = tempArr.length; i < length; i++) {
            route.push(tempArr[i]);
            backTracking(digits, curIndex + 1, route);
            route.pop();
        }
    }
    backTracking(digits, 0, []);
    return resArr;
};
```

```c
    for(i = 0; i < strlen(letters); i++) {
        path[pathTop++] = letters[i];
        //递归，处理下一层数字
        backTracking(digits, index+1);
        pathTop--;
    }
}

char ** letterCombinations(char * digits, int* returnSize){
    //初始化path和result
    path = (char*)malloc(sizeof(char) * strlen(digits));
    result = (char**)malloc(sizeof(char*) * 300);

    *returnSize = 0;
    //若digits数组中元素个数为0，返回空集
    if(strlen(digits) == 0)
        return result;
    pathTop = resultTop = 0;
    backTracking(digits, 0);
    *returnSize = resultTop;

    return result;
}
```

```swift
func letterCombinations(_ digits: String) -> [String] {
    // 按键与字母串映射
    let letterMap = [
        "",
        "", "abc", "def",
        "ghi", "jkl", "mno",
        "pqrs", "tuv", "wxyz"
    ]
    // 把输入的按键字符串转成Int数组
    let baseCode = ("0" as Character).asciiValue!
    let digits = digits.map { c in
        guard let code = c.asciiValue else { return -1 }
        return Int(code - baseCode)
    }.filter { $0 >= 0 && $0 <= 9 }
    guard !digits.isEmpty else { return [] }

    var result = [String]()
    var s = ""
    func backtracking(index: Int) {
        // 结束条件：收集结果
        if index == digits.count {
            result.append(s)
            return
        }

        // 遍历当前按键对应的字母串
        let letters = letterMap[digits[index]]
        for letter in letters {
            s.append(letter) // 处理
            backtracking(index: index + 1) // 递归，记得+1
            s.removeLast() // 回溯
        }
    }
    backtracking(index: 0)
    return result
}
```

```scala
object Solution {
  import scala.collection.mutable
  def letterCombinations(digits: String): List[String] = {
    var result = mutable.ListBuffer[String]()
    if(digits == "") return result.toList // 如果参数为空，返回空结果集的List形式
    var path = mutable.ListBuffer[Char]()
    // 数字和字符的映射关系
    val map = Array[String]("", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz")

    def backtracking(index: Int): Unit = {
      if (index == digits.size) {
        result.append(path.mkString)  // mkString语法：将数组类型直接转换为字符串
        return
      }
      var digit = digits(index) - '0' // 这里使用toInt会报错！必须 -'0'
      for (i <- 0 until map(digit).size) {
        path.append(map(digit)(i))
        backtracking(index + 1)
        path = path.take(path.size - 1)
      }
    }

    backtracking(0)
    result.toList
  }
}
```

```ruby
def letter_combinations(digits)
  letter_map = {
    2 => ['a','b','c'],

def backtracking(result, letter_map, digits, path, index)
  if path.size == digits.size
    result << path.join('')
    return
  end

  hash[digits[index].to_i].each do |chr|
    path << chr
    #index + 1代表处理下一个数字
    backtracking(result, letter_map, digits, path, index + 1)
    #回溯，撤销处理过的数字
    path.pop
  end
end
```

```csharp
public class Solution
{
    public IList<string> res = new List<string>();
    public string s;
    public string[] letterMap = new string[10] { "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz" };

    {
        if (index == digits.Length)
        {
            res.Add(s);
            return;
        }
        int digit = digits[index] - '0';
        string letters = letterMap[digit];
        for (int i = 0; i < letters.Length; i++)

            s += letters[i];
            BackTracking(digits, index + 1);
            s = s.Substring(0, s.Length - 1);
        }
    }
```
