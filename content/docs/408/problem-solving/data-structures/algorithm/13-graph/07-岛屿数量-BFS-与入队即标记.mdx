# 岛屿数量：BFS 与入队即标记

> **卡码网 99. 岛屿数量 · BFS 解法**
>
> 给定一个由 `0`（水）和 `1`（陆地）组成的网格，陆地只通过上、下、左、右四个方向连通，求岛屿数量。

[题目链接（ACM 模式）](https://kamacoder.com/problempage.php?pid=1171)

上一节使用 DFS 把一座岛屿完整访问掉。

这一节改用 BFS，但整体思路完全不变：

> **外层遍历负责发现新的连通块，BFS 负责标记这个连通块中的全部节点。**

<Callout type="warning" title="本题最重要的 BFS 细节">

**节点一旦进入队列，就应该立刻标记为已访问。**

不要等到出队时才标记。

这是写对 BFS 模板最值得建立的习惯之一。

</Callout>

## 2. BFS 在这里做的事情是什么

当外层循环发现一个新的未访问陆地 `(x,y)` 时：

```text
answer += 1
```

然后把 `(x,y)` 放入队列。

BFS 不断取出队首节点，检查它四周的相邻陆地；只要发现新的未访问陆地，就继续放入队列。

直到队列为空，这一座岛屿上的所有陆地就都处理完了。

过程类似：

```text
发现起点
   ↓
起点入队
   ↓
弹出队首
   ↓
寻找四方向新陆地
   ↓
新陆地入队并立刻标记
   ↓
队列非空？ ──是──> 继续
   │
   否
   ↓
当前岛屿处理完毕
```

## 3. BFS 与 DFS 在这道题上为什么等价

DFS 与 BFS 的搜索顺序不同：

- DFS：优先一直向深处走；
- BFS：优先一层一层扩展。

但本题只要求：

> **把一个连通块中的所有节点全部访问到。**

并不关心访问顺序。

因此两者都可以正确求解。

| 对比项 | DFS | BFS |
| --- | --- | --- |
| 核心数据结构 | 递归栈 / 手写栈 | FIFO 队列 |
| 搜索方式 | 深入后回退 | 分层扩展 |
| 本题结果 | 相同 | 相同 |
| 时间复杂度 | $O(NM)$ | $O(NM)$ |
| 大网格递归风险 | 有 | 无递归栈风险 |

<Callout type="info" title="选择 DFS 还是 BFS？">

对“统计连通块”这种问题，没有必要纠结谁更高级。

- 递归 DFS 通常代码短；
- BFS 不依赖递归深度；
- 后续若问题加入“最少步数”，BFS 往往更自然。

</Callout>

## 4. 标准 BFS 模板

四方向数组：

```cpp
const int dir[4][2] = {
    {0, 1},
    {1, 0},
    {0, -1},
    {-1, 0}
};
```

BFS：

```cpp
void bfs(
    const vector<vector<int>>& grid,
    vector<vector<bool>>& visited,
    int startX,
    int startY
) {
    queue<pair<int, int>> q;

    q.push({startX, startY});
    visited[startX][startY] = true;

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (int i = 0; i < 4; ++i) {
            int nx = x + dir[i][0];
            int ny = y + dir[i][1];

            if (nx < 0 || nx >= grid.size() ||
                ny < 0 || ny >= grid[0].size()) {
                continue;
            }

            if (grid[nx][ny] == 1 && !visited[nx][ny]) {
                visited[nx][ny] = true;
                q.push({nx, ny});
            }
        }
    }
}
```

最值得关注的是这两句的顺序：

```cpp
visited[nx][ny] = true;
q.push({nx, ny});
```

逻辑含义是：

> 一旦决定让这个节点进入 BFS 搜索队列，就立即把它“预约”为已访问。

## 5. 为什么必须“入队即标记”

很多初学者会写成：

```cpp
q.push(start);

while (!q.empty()) {
    auto cur = q.front();
    q.pop();

    visited[cur.x][cur.y] = true;

    // 扩展相邻节点……
}
```

也就是：**出队时才标记**。

问题在于：一个节点从第一次入队，到真正轮到它出队之间，可能还会被其他节点再次发现。

源文给出的重复入队示意：

![出队才标记会导致重复入队](https://file1.kamacoder.com/i/algo/20250124094043.png)

考虑一个小区域：

```text
A B
C D
```

假设 `A` 先处理，`B` 和 `C` 都进入队列。

接下来处理 `B`：

```text
B 发现 D
D 入队
```

此时如果 `D` 尚未标记，随后处理 `C` 时：

```text
C 也发现 D
D 再次入队
```

于是队列可能变成：

```text
[D, D]
```

同一个节点被重复加入。

### 正确做法

第一次发现 `D` 时立即：

```cpp
visited[D] = true;
q.push(D);
```

那么 `C` 再看到 `D` 时就会直接跳过。

因此：

> **visited 不应该理解为“已经出队处理完成”，而应该理解为“已经被发现并纳入搜索”。**

---

## 6. 入队标记带来的一个重要不变量

采用正确写法后，可以保证：

> 队列中的每个节点都是已经标记过的节点，并且普通 BFS 中每个节点最多入队一次。

也就是：

```text
未发现
  ↓
第一次被某个节点发现
  ↓
立刻 visited = true
  ↓
入队
  ↓
以后其他路径再次遇到它 → 跳过
```

这个不变量会让 BFS 的：

- 正确性；
- 时间复杂度；
- 空间复杂度；

都更加容易分析。

## 7. 完整 C++ 推荐实现

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

const int dir[4][2] = {
    {0, 1},
    {1, 0},
    {0, -1},
    {-1, 0}
};

void bfs(
    const vector<vector<int>>& grid,
    vector<vector<bool>>& visited,
    int startX,
    int startY
) {
    int n = grid.size();
    int m = grid[0].size();

    queue<pair<int, int>> q;
    q.push({startX, startY});
    visited[startX][startY] = true;

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (int i = 0; i < 4; ++i) {
            int nx = x + dir[i][0];
            int ny = y + dir[i][1];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) {
                continue;
            }

            if (grid[nx][ny] == 1 && !visited[nx][ny]) {
                visited[nx][ny] = true;
                q.push({nx, ny});
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<vector<int>> grid(n, vector<int>(m));
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> grid[i][j];
        }
    }

    vector<vector<bool>> visited(n, vector<bool>(m, false));

    int answer = 0;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (grid[i][j] == 1 && !visited[i][j]) {
                ++answer;
                bfs(grid, visited, i, j);
            }
        }
    }

    cout << answer << '\n';
    return 0;
}
```

## 8. 外层双循环与 BFS 如何配合

完整逻辑实际上分为两层。

### 第一层：寻找新连通块

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = 0; j < m; ++j) {
        if (grid[i][j] == 1 && !visited[i][j]) {
            ++answer;
            bfs(...);
        }
    }
}
```

### 第二层：吃掉整个连通块

```cpp
bfs(startX, startY)
```

会把与起点连通的所有陆地全部访问。

于是：

$$
\text{BFS 启动次数}=\text{岛屿数量}
$$

这和 DFS 版本完全一致。

---

## 9. 正确性分析

### 9.1 BFS 能访问整座岛

从某个岛屿上的起点开始，BFS 会访问所有四方向相邻的未访问陆地。

这些新陆地又会继续扩展自己的相邻陆地。

由于同一岛屿内部任意两个节点之间都存在四方向路径，因此最终整座岛都会进入 BFS。

### 9.2 BFS 不会跨过水域

只有满足：

```cpp
grid[nx][ny] == 1
```

的节点才能进入队列。

因此水域永远不会成为搜索节点，BFS 不可能穿过海水连接两座独立岛屿。

### 9.3 每座岛只计数一次

某座岛第一次被发现后，其中所有陆地都会被标记。

以后外层循环再次扫描到这些节点时：

```cpp
visited[i][j] == true
```

不会再次执行 `answer++`。

所以最终答案正确。

---

## 10. 时间复杂度与空间复杂度

设网格大小为 $N\times M$。

### 时间复杂度

正确使用“入队即标记”后，每个格子最多入队一次。

每个陆地格子只检查四个方向，因此：

$$
T(N,M)=O(NM)
$$

### 空间复杂度

`visited` 数组占用：

$$
O(NM)
$$

队列最坏也可能同时保存 $O(NM)$ 个节点，因此总辅助空间：

$$
O(NM)
$$

## 11. 错误写法：出队时才标记

下面这段代码要特别警惕：

```cpp
void bfs(...) {
    queue<pair<int, int>> q;
    q.push({x, y});

    while (!q.empty()) {
        auto [cx, cy] = q.front();
        q.pop();

        visited[cx][cy] = true; // 太晚了

        for (...) {
            if (!visited[nx][ny] && grid[nx][ny] == 1) {
                q.push({nx, ny});
            }
        }
    }
}
```

它的问题不是“一定算错答案”。

很多情况下最后结果仍然可能正确，但在节点真正出队前，它可能被多个邻居重复放入队列，导致：

- 重复入队；
- 重复出队；
- 队列变大；
- 常数开销明显增加；
- 在更复杂图上性能恶化。

因此标准 BFS 应建立统一习惯：

```cpp
if (!visited[v]) {
    visited[v] = true;
    q.push(v);
}
```

## 12. “入队即标记”与最短路有什么关系

虽然本题只统计连通块，但同一个细节在无权最短路中更加重要。

BFS 按层扩展：

$$
L_0,L_1,L_2,\dots
$$

某节点第一次被发现时，它已经通过当前最短层数到达。

因此通常写：

```cpp
dist[v] = dist[u] + 1;
visited[v] = true;
q.push(v);
```

也就是说：

> **第一次发现节点的时刻，就是确定它最短层数的时刻。**

这就是为什么 BFS 模板中“发现即标记”不仅是性能优化，更是一种统一的搜索状态定义。

## 13. 可不可以不用 visited

与 DFS 一样，如果允许修改原网格，可以在节点入队时直接把它改成 `0`：

```cpp
if (grid[nx][ny] == 1) {
    grid[nx][ny] = 0;
    q.push({nx, ny});
}
```

此时：

```text
1 = 未访问陆地
0 = 水域 / 已访问陆地
```

注意仍然要在 **入队时修改**，而不是等出队后再修改。

否则重复入队问题依然存在。

## 14. DFS / BFS 两种写法该如何记忆

不要分别背两整套代码，只记住统一骨架：

```text
扫描所有节点
  ↓
遇到“符合条件 + 未访问”的节点
  ↓
答案 +1
  ↓
从该点搜索整个连通块
```

区别只在“搜索整个连通块”这一小块：

### DFS

```text
递归 / 栈
```

### BFS

```text
队列
```

## 15. 一套可迁移的二维网格 BFS 模板

以后遇到迷宫、最少移动次数、腐烂传播、扩散模拟等问题，可以从下面模板改：

```cpp
queue<pair<int, int>> q;
q.push(start);
visited[start.first][start.second] = true;

while (!q.empty()) {
    auto [x, y] = q.front();
    q.pop();

    for (auto [dx, dy] : directions) {
        int nx = x + dx;
        int ny = y + dy;

        if (越界) continue;
        if (不能进入) continue;
        if (visited[nx][ny]) continue;

        visited[nx][ny] = true;
        q.push({nx, ny});
    }
}
```

如果题目求最短距离，再增加：

```cpp
dist[nx][ny] = dist[x][y] + 1;
```

即可得到无权网格最短路的标准框架。

````code-tabs
```python label="Python"
import sys
from collections import deque

input = sys.stdin.readline

DIR = ((0, 1), (1, 0), (0, -1), (-1, 0))

n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]
visited = [[False] * m for _ in range(n)]


def bfs(sx: int, sy: int) -> None:
    queue = deque([(sx, sy)])
    visited[sx][sy] = True

    while queue:
        x, y = queue.popleft()

        for dx, dy in DIR:
            nx = x + dx
            ny = y + dy

            if not (0 <= nx < n and 0 <= ny < m):
                continue

            if grid[nx][ny] == 1 and not visited[nx][ny]:
                visited[nx][ny] = True
                queue.append((nx, ny))


answer = 0

for i in range(n):
    for j in range(m):
        if grid[i][j] == 1 and not visited[i][j]:
            answer += 1
            bfs(i, j)

print(answer)

```go label="Go"
package main

import (
    "bufio"
    "fmt"
    "os"
)

type Point struct {
    x, y int
}

var dir = [4][2]int{{0, 1}, {1, 0}, {0, -1}, {-1, 0}}

func bfs(grid [][]int, visited [][]bool, sx, sy int) {
    n := len(grid)
    m := len(grid[0])

    queue := make([]Point, 0)
    queue = append(queue, Point{sx, sy})
    visited[sx][sy] = true

    for head := 0; head < len(queue); head++ {
        cur := queue[head]

        for _, d := range dir {
            nx := cur.x + d[0]
            ny := cur.y + d[1]

            if nx < 0 || nx >= n || ny < 0 || ny >= m {
                continue
            }

            if grid[nx][ny] == 1 && !visited[nx][ny] {
                visited[nx][ny] = true
                queue = append(queue, Point{nx, ny})
            }
        }
    }
}

func main() {
    in := bufio.NewReader(os.Stdin)
    out := bufio.NewWriter(os.Stdout)
    defer out.Flush()

    var n, m int
    fmt.Fscan(in, &n, &m)

    grid := make([][]int, n)
    visited := make([][]bool, n)

    for i := 0; i < n; i++ {
        grid[i] = make([]int, m)
        visited[i] = make([]bool, m)
        for j := 0; j < m; j++ {
            fmt.Fscan(in, &grid[i][j])
        }
    }

    answer := 0

    for i := 0; i < n; i++ {
        for j := 0; j < m; j++ {
            if grid[i][j] == 1 && !visited[i][j] {
                answer++
                bfs(grid, visited, i, j)
            }
        }
    }

    fmt.Fprintln(out, answer)
}
````
