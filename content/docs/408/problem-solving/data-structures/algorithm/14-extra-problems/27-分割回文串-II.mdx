# 132. 分割回文串 II

[LeetCode 132：分割回文串 II](https://leetcode.cn/problems/palindrome-partitioning-ii/)

给定字符串 `s`，把它分割成若干子串，并要求每个子串都是回文串。

返回使所有子串均为回文时的 **最少分割次数**。

例如：

```text
输入：s = "aab"
输出：1
解释："aa" | "b"
```

```text
输入：s = "a"
输出：0
```

```text
输入：s = "ab"
输出：1
```

## 一、与“分割回文串 I”的区别

在普通的回文分割问题中，常见目标是：

> 枚举所有合法分割方案。

这类问题通常使用回溯。

而本题只问：

> **最少切几刀？**

这已经从“枚举方案”变成了“最优化问题”。

如果仍然枚举所有分割方式，最坏会面对指数级搜索空间。

因此更适合使用动态规划。

## 二、这道题实际上有两个子问题

要决定在哪里切，必须不断回答：

```text
s[l..r] 是不是回文？
```

与此同时，还要回答：

```text
s[0..i] 最少需要切几次？
```

因此一个非常自然的两阶段结构是：

1. 预处理所有回文区间；
2. 在这些合法回文区间上做最少分割 DP。

也就是：

```text
回文判定 DP
        ↓
最少切割 DP
```

## 三、第一阶段：预处理所有回文区间

定义：

$$
pal[i][j]
$$

表示：

$$
s[i\ldots j]
$$

是否为回文串。

状态转移与最长回文子串一模一样：

$$
pal[i][j]
=
(s[i]=s[j])\land
\left((j-i\le1)\lor pal[i+1][j-1]\right)
$$

由于：

$$
pal[i][j]
$$

依赖：

$$
pal[i+1][j-1]
$$

所以 `i` 应从后往前遍历。

```cpp
vector<vector<bool>> pal(n, vector<bool>(n, false));

for (int i = n - 1; i >= 0; --i) {
    for (int j = i; j < n; ++j) {
        if (s[i] == s[j] &&
            (j - i <= 1 || pal[i + 1][j - 1])) {
            pal[i][j] = true;
        }
    }
}
```

## 四、第二阶段：定义最少分割次数

定义：

$$
dp[i]
$$

表示前缀：

$$
s[0\ldots i]
$$

全部分割成回文子串时，需要的最少切割次数。

例如：

```text
s = "aab"
```

则：

```text
dp[0]："a"   -> 0
dp[1]："aa"  -> 0
dp[2]："aab" -> 1
```

## 五、先看一个极其重要的特殊情况

如果整个前缀：

$$
s[0\ldots i]
$$

本身就是回文串，那么根本不需要切：

$$
dp[i]=0
$$

因此每次计算 `dp[i]` 时，优先判断：

```cpp
if (pal[0][i]) {
    dp[i] = 0;
    continue;
}
```

这个判断不仅简洁，而且避免处理“左边没有前缀”这一特殊边界。

## 六、一般情况：枚举最后一刀切在哪里

假设最后一次切割发生在位置 `j` 后面：

```text
0 ........ j | j+1 ........ i
```

右侧最后一段是：

$$
s[j+1\ldots i]
$$

如果它是回文：

$$
pal[j+1][i]=true
$$

那么：

- 左边 `s[0..j]` 的最少切割次数已经是 `dp[j]`；
- 再加上最后这一刀。

于是得到候选答案：

$$
dp[j]+1
$$

所以：

$$
dp[i]
=
\min_{0\le j<i,\ pal[j+1][i]}
(dp[j]+1)
$$

如果 `pal[0][i] = true`，则直接取 $0$。

> [!IMPORTANT]
> 这里枚举的是“最后一段从哪里开始”，而不是要求左边 `[0,j]` 本身必须是一个回文串。左边可能已经被切成很多段，它的最优值已经被 `dp[j]` 汇总好了。

## 七、为什么 `dp[i]` 可以初始化成 `i`

长度为：

$$
i+1
$$

的前缀，最坏情况下每个字符单独成为一个回文串。

例如：

```text
abcd
```

可以切成：

```text
a | b | c | d
```

需要：

$$
4-1=3
$$

次切割。

一般地：

$$
dp[i]\le i
$$

因此可直接初始化：

```cpp
for (int i = 0; i < n; ++i) {
    dp[i] = i;
}
```

这比初始化成一个极大值更贴合状态含义。

## 八、完整 C++ 实现

```cpp
class Solution {
public:
    int minCut(string s) {
        int n = s.size();

        // 1. pal[i][j] 表示 s[i..j] 是否为回文串
        vector<vector<bool>> pal(n, vector<bool>(n, false));

        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                if (s[i] == s[j] &&
                    (j - i <= 1 || pal[i + 1][j - 1])) {
                    pal[i][j] = true;
                }
            }
        }

        // 2. dp[i] 表示 s[0..i] 的最少切割次数
        vector<int> dp(n);
        for (int i = 0; i < n; ++i) {
            dp[i] = i;
        }

        for (int i = 0; i < n; ++i) {
            if (pal[0][i]) {
                dp[i] = 0;
                continue;
            }

            for (int j = 0; j < i; ++j) {
                if (pal[j + 1][i]) {
                    dp[i] = min(dp[i], dp[j] + 1);
                }
            }
        }

        return dp[n - 1];
    }
};
```

## 九、用 `aab` 手推一遍

字符串：

```text
a a b
0 1 2
```

首先得到回文关系：

```text
"a"  -> 回文
"aa" -> 回文
"aab" -> 非回文
"b"  -> 回文
```

然后计算：

### `i = 0`

```text
s[0..0] = "a"
```

整个前缀就是回文：

$$
dp[0]=0
$$

### `i = 1`

```text
s[0..1] = "aa"
```

也是回文：

$$
dp[1]=0
$$

### `i = 2`

```text
s[0..2] = "aab"
```

不是回文。

枚举最后一刀：

#### `j = 0`

最后一段：

```text
s[1..2] = "ab"
```

不是回文，跳过。

#### `j = 1`

最后一段：

```text
s[2..2] = "b"
```

是回文。

候选：

$$
dp[1]+1=1
$$

所以：

$$
dp[2]=1
$$

最终答案为 $1$。

## 十一、为什么不能简单“遇到最长回文就切”

这题看起来很像可以贪心：

> 每次取当前能得到的最长回文前缀，是不是就能让切割次数最少？

不一定。

局部选择一个较长回文段，可能导致后面的后缀需要更多切割。

本题的目标依赖整个前缀的全局组合，因此需要比较所有合法的“最后一段”。

动态规划恰好把这种全局最优关系保存为：

$$
dp[i]
$$

> [!TIP]
> 当“当前选择会影响剩余部分最优解”，且不存在明显贪心交换性质时，优先考虑 DP，而不是凭“尽量长”或“尽量短”做局部决策。

## 十二、复杂度分析

### 回文预处理

状态数量：

$$
O(n^2)
$$

每个状态 $O(1)$ 转移。

### 最少切割 DP

外层枚举 `i`，内层枚举 `j`：

$$
O(n^2)
$$

因此总时间复杂度：

$$
O(n^2)
$$

空间主要来自 `pal` 二维表：

$$
O(n^2)
$$

总结：

- 时间复杂度：$O(n^2)$
- 空间复杂度：$O(n^2)$

## 十三、另一种更统一的状态设计

还可以把 `dp` 定义成：

$$
dp[i]=s[0\ldots i-1]
$$

的最少回文段数量。

这样：

$$
dp[0]=0
$$

如果：

$$
pal[j][i-1]=true
$$

则：

$$
dp[i]=\min(dp[i],dp[j]+1)
$$

最后答案是：

$$
dp[n]-1
$$

因为若分成 $k$ 段，只需要：

$$
k-1
$$

刀。

这个版本把“空前缀”纳入状态，有时写边界会更统一；但若按原题直接定义“切割次数”，前面的写法更直观。

## 十四、和其他回文题建立联系

### 647. 回文子串

核心是计算：

$$
pal[i][j]
$$

并统计有多少个 `true`。

### 5. 最长回文子串

同样计算回文区间，但目标变成维护最大：

$$
j-i+1
$$

### 131. 分割回文串

利用回文判定，通过回溯枚举所有切割方案。

### 132. 分割回文串 II

利用回文判定，通过 DP 计算最少切割次数。

可以把这几题看成同一条知识链：

```text
判断回文区间
   ↓
统计 / 最长 / 枚举 / 最优化
```

## 十五、常见错误

### 1. 把 `dp[i]` 理解成“回文段数量”

本解法中：

$$
dp[i]
$$

表示的是 **切割次数**。

例如整个前缀已经是回文：

```text
"abba"
```

对应：

$$
dp[3]=0
$$

而不是 $1$。

### 2. 最后一段不是回文也参与转移

只有：

```text
pal[j + 1][i] == true
```

时，`dp[j] + 1` 才是合法候选。

### 3. 回文表遍历方向写反

`pal[i][j]` 依赖 `pal[i+1][j-1]`，所以必须保证内部区间先被计算。

### 4. 忘记整个前缀就是回文的情况

若：

```text
pal[0][i] == true
```

答案必须直接是 $0$。

## 十六、可直接记忆的模板

本题可以浓缩成两个公式。

### 回文区间

$$
pal[i][j]
=
(s[i]=s[j])\land
\left(j-i\le1\lor pal[i+1][j-1]\right)
$$

### 最少分割

$$
dp[i]
=
\begin{cases}
0, & pal[0][i]=true\\
\min(dp[j]+1), & pal[j+1][i]=true
\end{cases}
$$

理解这两个状态的连接方式，比死记完整代码更重要。

## 其他语言版本

```java label="Java"
class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];

        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)
                        && (j - i <= 1 || pal[i + 1][j - 1])) {
                    pal[i][j] = true;
                }
            }
        }

        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            dp[i] = i;
        }

        for (int i = 0; i < n; i++) {
            if (pal[0][i]) {
                dp[i] = 0;
                continue;
            }

            for (int j = 0; j < i; j++) {
                if (pal[j + 1][i]) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }

        return dp[n - 1];
    }
}
```

```python label="Python"
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        pal = [[False] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 1 or pal[i + 1][j - 1]):
                    pal[i][j] = True

        dp = list(range(n))

        for i in range(n):
            if pal[0][i]:
                dp[i] = 0
                continue

            for j in range(i):
                if pal[j + 1][i]:
                    dp[i] = min(dp[i], dp[j] + 1)

        return dp[-1]
```

```go label="Go"
func minCut(s string) int {
    n := len(s)
    pal := make([][]bool, n)
    for i := range pal {
        pal[i] = make([]bool, n)
    }

    for i := n - 1; i >= 0; i-- {
        for j := i; j < n; j++ {
            if s[i] == s[j] && (j-i <= 1 || pal[i+1][j-1]) {
                pal[i][j] = true
            }
        }
    }

    dp := make([]int, n)
    for i := 0; i < n; i++ {
        dp[i] = i
    }

    for i := 0; i < n; i++ {
        if pal[0][i] {
            dp[i] = 0
            continue
        }

        for j := 0; j < i; j++ {
            if pal[j+1][i] && dp[j]+1 < dp[i] {
                dp[i] = dp[j] + 1
            }
        }
    }

    return dp[n-1]
}
```
