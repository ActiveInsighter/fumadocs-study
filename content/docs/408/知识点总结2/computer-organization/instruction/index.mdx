---
title: "指令系统"
description: "指令格式、寻址方式、汇编与机器指令。"
---

指令系统位于软件和硬件的边界：编译器把高级语言转换为指令，CPU 再按照指令编码完成取指、译码和执行。复习时应把“**指令格式—寻址方式—数据通路—控制信号**”串联起来。

| 内容 | 重点 |
| --- | --- |
| [格式和寻址方式](/docs/408/知识点总结2/computer-organization/instruction/format/) | 操作码/地址码、扩展操作码、各类寻址方式 |
| [数据对齐方式](/docs/408/知识点总结2/computer-organization/instruction/alignment/) | 边界对齐、大端与小端 |
| [指令集种类](/docs/408/知识点总结2/computer-organization/instruction/concepts/) | RISC/CISC、ISA、不同汇编语法 |
| [高级语言和机器码](/docs/408/知识点总结2/computer-organization/instruction/high_low_language/) | 编译、汇编、链接、函数调用 |
| [指令操作码](/docs/408/知识点总结2/computer-organization/instruction/instruction_ops/) | 数据传送、算术逻辑、控制转移与栈操作 |

> **复习提示：** 408 常把寻址方式、机器级代码和 CPU 数据通路放在同一道题中考查，不能只记定义。
