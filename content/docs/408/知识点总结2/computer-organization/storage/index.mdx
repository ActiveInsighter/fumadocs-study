title: "存储系统"
description: "主存、Cache、外存与虚拟存储器。"

存储系统围绕“**容量、速度、成本**”三者的权衡展开。寄存器、Cache、主存和外存构成层次结构，局部性原理使较小的高速存储器能够显著降低平均访问时间。

| 内容 | 重点 |
| --- | --- |
| [存储系统](/docs/408/知识点总结2/computer-organization/storage/defs/) | RAM/ROM、SRAM/DRAM、存储层次 |
| [多模块存储器](/docs/408/知识点总结2/computer-organization/storage/memory/) | 交叉编址、带宽、位扩展与字扩展 |
| [外存](/docs/408/知识点总结2/computer-organization/storage/storage/) | 磁盘结构、CHS、访问时间、RAID、SSD |
| [Cache](/docs/408/知识点总结2/computer-organization/storage/cache/) | 映射、地址结构、替换算法、写策略 |
| [虚拟存储器](/docs/408/知识点总结2/computer-organization/storage/virtual/) | 页表、TLB、地址翻译、缺页与完整访存流程 |

> **复习提示：** Cache 与虚拟存储器是本章核心。做综合题时先判断题目给的是虚拟地址还是物理地址，再依次分析 TLB、页表和 Cache。
