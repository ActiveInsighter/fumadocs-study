本章讨论 CPU、主存和外设之间如何交换数据。总线解决“**怎么连接、何时传、一次传多少**”，I/O 系统进一步解决处理器与低速外设之间的速度与控制差异。

| 内容 | 重点 |
| --- | --- |
| [总线](/docs/408/知识点总结2/computer-organization/bus/bus/) | 总线类型、总线事务、同步/异步定时、带宽 |
| [I/O 系统](/docs/408/知识点总结2/computer-organization/bus/io/) | I/O 接口与端口、程序查询、中断、DMA、通道 |

> **复习提示：** 比较 I/O 方式时重点看“数据由谁搬运”“CPU 是否等待”“一次中断对应多少数据”“是否可以与 CPU 并行”。
