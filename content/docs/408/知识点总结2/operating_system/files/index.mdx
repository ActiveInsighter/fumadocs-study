文件管理负责把外存中的块组织成用户可理解的文件与目录，同时维护文件元数据、访问权限和空闲空间。

<InlineSvg src="/images/operating-system/operating-system-files-001.svg" alt={"文件、目录与文件系统知识框架"} />

| 内容 | 重点 |
| --- | --- |
| [文件](/docs/408/知识点总结2/operating_system/files/file/) | 文件属性、逻辑结构、连续/链接/索引分配、inode |
| [目录](/docs/408/知识点总结2/operating_system/files/dir/) | 目录结构、路径、目录项、硬链接与符号链接 |
| [文件系统](/docs/408/知识点总结2/operating_system/files/file_system/) | 文件系统布局、空闲空间管理、VFS 与挂载 |

> **复习提示：** 做索引文件题时，先确定一个索引块能存多少个块号，再逐级计算直接、一级间接、二级间接等索引可覆盖的最大文件范围。
