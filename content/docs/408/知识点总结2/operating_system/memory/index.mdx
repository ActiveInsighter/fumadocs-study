---
title: "内存管理"
description: "内存分配、地址转换、分页与虚拟内存。"
---

内存管理解决三个核心问题：**程序的地址放在哪里、逻辑地址如何转换为物理地址、物理内存不足时如何运行更大的程序**。

<InlineSvg src="/images/operating-system/operating-system-memory-001.svg" alt={"内存管理与虚拟内存知识框架"} />

| 内容 | 重点 |
| --- | --- |
| [内存管理概念](/docs/408/知识点总结2/operating_system/memory/concepts/) | 连续分配、分页/分段、页表、地址转换、内存保护与共享 |
| [虚拟内存管理](/docs/408/知识点总结2/operating_system/memory/management/) | 请求分页、驻留集、抖动、页框分配、页面置换算法 |

> **复习提示：** 地址转换题先划分地址字段，再明确页表/TLB 中保存的是“页号到页框号”的映射；缺页后由操作系统介入，普通页表命中时不需要操作系统逐次参与。
