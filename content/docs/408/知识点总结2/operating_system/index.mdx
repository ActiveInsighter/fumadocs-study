操作系统位于应用程序与硬件之间，核心任务是**管理资源、提供抽象、协调并发执行并保护系统**。408 复习时，应围绕“程序如何运行”这条主线，把进程、内存、文件与 I/O 串联起来。

## 建议的知识主线

1. **程序如何进入内核**：用户态/内核态、异常、中断、系统调用。
2. **CPU 如何分配**：进程与线程、状态转换、调度与上下文切换。
3. **并发如何正确执行**：互斥、同步、信号量、经典同步问题与死锁。
4. **地址如何变成实际访存**：逻辑地址、页表、TLB、缺页与页面置换。
5. **数据如何持久保存**：文件、目录、文件系统与磁盘空间管理。
6. **外设如何与系统协同**：I/O 控制、缓冲、设备分配与磁盘调度。

> **真题考察：** 操作系统是 408 的核心组成部分，选择题与综合题都会覆盖。高频综合内容通常集中在进程同步、处理机调度、虚拟内存、文件系统和磁盘管理等主题。

> **复习提示：** 内存管理与计算机组成原理中的存储系统紧密相关，I/O 管理与总线和输入输出系统紧密相关。综合题中应区分“硬件完成的地址/数据传送”与“操作系统负责的策略和管理”。
