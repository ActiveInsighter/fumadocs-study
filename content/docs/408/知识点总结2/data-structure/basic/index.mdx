本章用于建立整门数据结构的分析框架：**先看逻辑结构和存储结构，再分析操作与算法复杂度**。

| 内容 | 重点 |
| --- | --- |
| [数据结构基本概念](/docs/408/知识点总结2/data-structure/basic/ds/) | 逻辑结构、存储结构、数据类型与抽象数据类型 |
| [算法基本概念](/docs/408/知识点总结2/data-structure/basic/algorithm/) | 算法特性、时间复杂度、空间复杂度 |
| [算法设计题框架](/docs/408/知识点总结2/data-structure/basic/alg_design/) | 数组、链表、树、图的常用解题模板 |

> **复习提示：** 复杂度分析的关键是先确定“基本操作”与输入规模，再统计其执行次数的数量级；算法设计题则要同时满足正确性和题目给定的时间/空间约束。
