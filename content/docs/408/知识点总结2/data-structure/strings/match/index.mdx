**字符串模式匹配** 是计算机科学中的基础问题，主要是在一个 **主字符串** 中查找一个 **子字符串** 模式。

### 串概念

在介绍模式匹配算法之前，需要能够区分关于串的几个概念：

- **主串**（Str / 主字符串）：待搜索的那一整段字符串。
- **子串**（Substr / 子字符串）：主串中的某一段字符串
- **模式串**（Pattern / 模式字符串）：要在主串中查找的目标。

以及以下几个关于 **模式匹配** 的术语：

- **匹配**：在主串中找到与模式串完全相同的子串
- **匹配位置**：模式串在主串中出现的起始位置
- **失配**：当前字符不匹配

**模式匹配算法** 就是将 **模式串** 与 **主串** 相匹配，企图找到主串中的某个和 **子串** 和 **模式串** 完全相同。

### 简单模式匹配算法

**简单模式匹配算法**（即暴力匹配 / 朴素匹配）的 **基本思想** 是：逐个检查 **主串** 的每一个位置，判断 **从该位置开始的子串** 是否与 **模式串** 完全相同。

**算法描述：**

1. 从 **主串** 的第一个字符开始，尝试与 **模式串** 匹配。
2. 如果当前字符匹配，则继续比较下一个字符，依此类推。
3. 如果在某一位置发生不匹配，则将 **模式串** 移动到 **主串** 的下一个起始位置，重新匹配。
4. 如果某一段 **子串** 与 **模式串** 完全相同，则返回该 **子串在主串中的起始位置**。
5. 如果扫描完整个 **主串** 都没有找到匹配的 **子串**，则返回 -1。
```
int simplePatternMatching(const char* mainStr, const char* pattern) {
    int m = strlen(mainStr);
    int n = strlen(pattern);

    // 如果主字符串的长度小于模式字符串的长度，直接返回 -1
    if (m < n) return -1;

    for (int i = 0; i <= m - n; i++) {
        int j;
        for (j = 0; j < n; j++) {
            if (mainStr[i + j] != pattern[j]) {
                break;
            }
        }
        // 如果 j 等于模式串的长度，说明已经找到匹配
        if (j == n) return i;
    }
    return -1;  // 没有找到匹配
}
```

简单模式匹配算法的**核心思路**是依次尝试主串中的每个可能起点，并与模式串逐字符比较。例如，主串 `abaaabc` 和模式串 `abc` 进行简单模式匹配的过程如下：

### KMP 算法

> **真题考察**
> - 选择题：2015 年第 8 题、2019 年第 9 题、2024 年第 6 题

与 **简单模式匹配算法** 不同， **KMP 算法** 在发现不匹配的字符时能够避免不必要的比较，从而提高效率。

#### 前后缀

**简单模式匹配** 时间复杂度过高，因为每一次匹配失败都得从下一个位置重新开始。这就没有充分应用 **模式串** 的特性，比如对于字符串 `abcdabc`，我们可以发现：

- 其 **真前缀**（不含完整字符串本身）包含`a`, `ab`, `abc`, `abcd` 等
- 其 **真后缀**（不含完整字符串本身）包含`c`, `bc`, `abc`, `dabc` 等

`abc` 是在其 **前缀** 和 **后缀** 中都包含的部分，在字符串匹配时，我们可以充分利用该信息，匹配失败时，我们可以不用从下一个位置开始，而是从 **模式串内部的某个位置** 开始。

KMP 的核心是利用模式串自身的前后缀信息，在失配时避免主串指针回退。教材常使用经典 `next` 数组；现代实现则常使用 **LPS（longest proper prefix which is also suffix）/前缀函数**。二者含义与下标约定不同，但表达的是同一类失配跳转信息。

#### 算法描述

1. 构建 **部分匹配表**（**next 数组**）：`next[i]` 表示：当 **模式串** 在第 i 位 **匹配失败** 时，下一次 **应该跳到的模式串位置**。
2. 不断进行 **模式匹配**，直到匹配成功或 **主串** 结束。

#### next 数组计算

如果 **模式串** 为 `pattern`，用通俗的话来说，`next[k]` 就是第 k 个字符的 **前缀字符串** `pattern[0:k-1]`（pattern 的前 k 个字符构成的子串，不包含当前字符）的最长相同 **前缀** 和 **后缀** 的长度。

以 `ababac` 字符串为例，可以得到以下的 next 数组：

| 模式串（pattern） | a | b | a | b | a | c |
| --- | --- | --- | --- | --- | --- | --- |
| 下标（index） | 0 | 1 | 2 | 3 | 4 | 5 |
| pattern[0:index] 的相同前后缀长度 | 0 | 0 | 1 | 2 | 3 | 0 |
| next | -1 | 0 | 0 | 1 | 2 | 3 |

本页纸笔推导采用一种常见的 **0 基经典 `next` 约定**：`next[0]=-1`。不同教材还可能使用 1 基下标或其他偏移定义，计算前应先确认题目约定。

以 c 字符为例，我们需要计算 `next[5]`，所以需要统计 c 的 **前缀字符串** ababa 的最长相同 **前缀** 和 **后缀** 的长度，可以观察到，最长的相同 **前缀** 和 **后缀** 为 aba，长度为 3，所以 `next[5] = 3`。

#### 使用 next 调整位置

用 `i` 表示 **主串** 当前下标，用 `j` 表示 **模式串** 当前下标：

- 如果 `main[i] == pattern[j]`，将 `i` 和 `j` 向后向后移动一位。
- 如果 `main[i] != pattern[j]`：
  - 如果 `j == 0`，将 `i` 向后移动一位。
  - 如果 `j != 0`，将 `j` 移动到 `next[j]`。

#### 算法实现

下面给出使用 **LPS 数组** 的现代实现。注意：这里的 `lps[0]=0`，与上一节用于纸笔模拟的经典 `next[0]=-1` **不是同一个数组定义**，不要直接混用数值。

```c
void computeLPS(const char *pattern, int m, int lps[]) {
    int len = 0;
    lps[0] = 0;

    for (int i = 1; i < m; ) {
        if (pattern[i] == pattern[len]) {
            lps[i++] = ++len;
        } else if (len > 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }
}

int KMP(const char *text, const char *pattern) {
    int n = strlen(text), m = strlen(pattern);
    if (m == 0) return 0;

    int lps[m];
    computeLPS(pattern, m, lps);

    int i = 0, j = 0;
    while (i < n) {
        if (text[i] == pattern[j]) {
            ++i; ++j;
            if (j == m) return i - m;
        } else if (j > 0) {
            j = lps[j - 1];
        } else {
            ++i;
        }
    }
    return -1;
}
```

KMP 预处理模式串和扫描主串都只做线性级别的指针推进，因此时间复杂度为 $O(n+m)$，额外空间复杂度为 $O(m)$。

#### 修正后的 next 数组

在经典 `next` 数组基础上，还可以进一步构造**修正后的 next 数组**。

修正后的 `next` 数组通常称为 **nextval 数组**，其目的是避免某些失配情况下的冗余比较。

`nextval` 数组是为了修正 `next` 数组存在的以下 **问题**：当 `pattern[j] == pattern[next[j]]` 时，如果直接使用 `next[j]`，会导致 **重复比较已经失败过的字符**。

为了解决这个问题，定义了 `nextval`：其核心思想是：避免跳转到与当前位置字符相同的地方，减少无意义的重复比较。

- 如果 `pattern[j] == pattern[next[j]]` → 则 `nextval[j] = nextval[next[j]]`
- 否则 → `nextval[j] = next[j]`

下面的 `nextval` 规则继续沿用经典 `next[0]=-1` 约定：
```
if (next[i] == -1) {
    nextval[i] = -1;
} else {
    int k = next[i];
    while (k != -1 && pattern[i] == pattern[k]) {
        k = nextval[k]; // 向前继续跳
    }
    nextval[i] = k;
}
```

需要注意，`nextval` 的计算过程是迭代向前的，因为我们希望减少无意义的比较，所以要争取找到一个不同的字符。

<InlineSvg src="/images/data-structure/data-structure-strings-match-004.svg" alt={"图示"} />

以字符串 ababaa 为例，我们首先可以计算出其 **next 数组**：

| pattern | a | b | a | b | a | a |
| --- | --- | --- | --- | --- | --- | --- |
| index | 0 | 1 | 2 | 3 | 4 | 5 |
| **next** | -1 | 0 | 0 | 1 | 2 | 3 |

然后计算出 **nextval 数组**：

| pattern | a | b | a | b | a | a |
| --- | --- | --- | --- | --- | --- | --- |
| index | 0 | 1 | 2 | 3 | 4 | 5 |
| **nextval** | -1 | 0 | -1 | 0 | -1 | 3 |

- `nextval[0] = -1`
- `nextval[1] = 0`（`pattern[1] = b, pattern[next[1]] = pattern[0] = a`，不相等，保留原值）
- `pattern[2] = a, pattern[next[2]] = pattern[0] = a`，相等，优化：`nextval[2] = nextval[0] = -1`
- `pattern[3] = b, pattern[next[3]] = pattern[1] = b`，相等，优化：`nextval[3] = nextval[1] = 0`
- `pattern[4] = a, pattern[next[4]] = pattern[2] = a`，相等，优化：`nextval[4] = nextval[2] = -1`
- `nextval[5] = 3`（`pattern[5] = a, pattern[next[5]] = pattern[3] = b`，不相等，保留原值）

现代实现常直接使用 LPS/前缀函数；`nextval` 主要用于经典 `next` 定义下进一步减少重复字符造成的无效比较。
