---

应用层直接服务用户程序。复习时既要记住典型协议使用的传输层服务与端口，也要理解各协议的交互流程，例如 DNS 解析、FTP 双连接、邮件发送/接收和 HTTP 请求/响应。

| 内容 | 重点 |
| --- | --- |
| [网络应用模型](/docs/408/知识点总结2/computer_network/application/model/) | C/S 与 P2P |
| [DNS](/docs/408/知识点总结2/computer_network/application/dns/) | 域名层次、服务器类型、递归与迭代查询、缓存 |
| [FTP](/docs/408/知识点总结2/computer_network/application/ftp/) | 控制连接、数据连接、主动/被动模式 |
| [电子邮件](/docs/408/知识点总结2/computer_network/application/mail/) | 用户代理、SMTP、POP3/IMAP、MIME |
| [万维网](/docs/408/知识点总结2/computer_network/application/www/) | URL、HTTP、无状态、连接方式与报文 |

> **复习提示：** 应用层协议题常考“使用 TCP 还是 UDP、默认端口、连接数量、谁主动建立连接、请求/响应的先后关系”。
