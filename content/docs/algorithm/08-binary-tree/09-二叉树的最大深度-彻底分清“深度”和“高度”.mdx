# 二叉树的最大深度：彻底分清“深度”和“高度”

> LeetCode 104 · Maximum Depth of Binary Tree

[题目链接](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

给定一棵二叉树，求从根节点到最远叶子节点的最长路径所包含的**节点数**。

例如：

![104. 二叉树的最大深度](https://file1.kamacoder.com/i/algo/20210203153031914-20230310121809902.png)

这棵树一共有 3 层，因此最大深度为 `3`。

这道题代码很短，但它是理解树形递归的关键题之一，因为它同时连接了三种重要模型：

```text
后序递归：向上返回“子树高度”
前序递归：向下携带“当前深度”
层序 BFS：直接统计“层数”
```

<Callout title="最重要的概念关系" type="idea">

对于根节点：

```text
根节点的高度 = 整棵树的最大深度
```

所以虽然题目问“最大深度”，最简洁的递归解法实际上是在**计算根节点的高度**。

</Callout>

## 1. 深度和高度到底有什么区别

先固定本文采用的“按节点数计数”口径：

- 根节点深度为 `1`；
- 叶子节点高度为 `1`；
- 空树高度为 `0`。

### 节点深度

某个节点的深度表示：

> 从根节点到这个节点的路径上有多少个节点。

它天然是从上往下数：

```text
root
深度 1
  ↓
深度 2
  ↓
深度 3
```

### 节点高度

某个节点的高度表示：

> 从这个节点到它最远叶子节点的最长路径包含多少个节点。

它天然是从下往上汇总：

```text
叶子高度 = 1
父节点高度 = max(左右孩子高度) + 1
```

### 为什么根节点特殊

根节点到最远叶子的最长路径，既是：

- 整棵树的最大深度；
- 根节点自身的高度。

因此：

$$
\text{maxDepth}(T)=\text{height}(root)
$$

<Cards>
  <Card title="求深度">通常从根向下传当前层数，适合前序 / 回溯。</Card>
  <Card title="求高度">通常等左右子树结果返回后再计算当前节点，适合后序。</Card>
  <Card title="求整树最大深度">既可以求根高度，也可以遍历所有节点维护最大深度。</Card>
</Cards>

## 2. 最推荐的解法：后序递归求高度

定义函数：

```cpp
int maxDepth(TreeNode* root)
```

它的语义可以直接理解为：

> 返回以 `root` 为根的这棵子树的高度。

如果 `root` 为空：

```cpp
return 0;
```

如果不为空，它的高度由左右子树决定：

```text
当前高度 = max(左子树高度, 右子树高度) + 1
```

也就是：

$$
H(u)=1+\max(H(u.left),H(u.right))
$$

空节点满足：

$$
H(\varnothing)=0
$$

于是代码非常自然：

```cpp title="LeetCode 104 · 后序递归"
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        int leftHeight = maxDepth(root->left);
        int rightHeight = maxDepth(root->right);

        return max(leftHeight, rightHeight) + 1;
    }
};
```

## 3. 为什么这是“后序”思想

后序顺序是：

```text
左 → 右 → 中
```

上面的代码恰好也是：

```cpp
int leftHeight = maxDepth(root->left);   // 左
int rightHeight = maxDepth(root->right); // 右
return max(leftHeight, rightHeight) + 1; // 中
```

当前节点的答案依赖两个孩子先返回结果，因此是典型的：

```text
先解决子问题 → 再合并得到当前问题
```

这类递归也常被称为**自底向上**。

<Callout title="树形 DP 的雏形" type="success">

这段代码虽然只有几行，但已经具备树形动态规划最基本的结构：

```text
状态：当前节点的高度
转移：max(左状态, 右状态) + 1
边界：空节点为 0
```

后面学习平衡二叉树、直径、最大路径和时，会反复使用这种“子树返回信息 → 当前节点合并”的结构。

</Callout>

## 4. 用递归三步法完整推一遍

### 1. 明确函数语义

```cpp
int getHeight(TreeNode* node)
```

返回以 `node` 为根的子树高度。

### 2. 明确终止条件

空树没有任何节点：

```cpp
if (node == nullptr) return 0;
```

### 3. 明确单层逻辑

分别获得左右子树高度：

```cpp
int leftHeight = getHeight(node->left);
int rightHeight = getHeight(node->right);
```

当前节点比更高的那棵子树多一层：

```cpp
return max(leftHeight, rightHeight) + 1;
```

完整展开版：

```cpp title="展开版 · 更适合学习递归语义"
class Solution {
public:
    int getHeight(TreeNode* node) {
        if (node == nullptr) return 0;

        int leftHeight = getHeight(node->left);
        int rightHeight = getHeight(node->right);
        int height = max(leftHeight, rightHeight) + 1;

        return height;
    }

    int maxDepth(TreeNode* root) {
        return getHeight(root);
    }
};
```

## 5. 手动模拟一次：返回值是怎么“向上长出来”的

以这棵树为例：

```text
        3
       / \
      9  20
         / \
        15  7
```

先递归到叶子 `9`：

```text
9.left  = null → 0
9.right = null → 0
H(9) = max(0, 0) + 1 = 1
```

同理：

```text
H(15) = 1
H(7)  = 1
```

因此：

```text
H(20) = max(1, 1) + 1 = 2
```

最后：

```text
H(3) = max(1, 2) + 1 = 3
```

关键不是“递归走了多深”，而是：

> 每个节点都从左右孩子那里拿到一个已经计算好的高度，再生成自己的高度。

## 6. 第二条路线：前序遍历真正统计“当前深度”

如果我们想从“深度”的定义本身出发，可以让递归参数携带当前节点深度：

```cpp
void dfs(TreeNode* node, int depth)
```

进入一个节点时，就已经知道它位于第几层，因此可以立即更新最大值：

```cpp
result = max(result, depth);
```

代码如下：

```cpp title="前序递归 · 向下传递 depth"
class Solution {
public:
    int result = 0;

    void dfs(TreeNode* node, int depth) {
        if (node == nullptr) return;

        result = max(result, depth);  // 中
        dfs(node->left, depth + 1);   // 左
        dfs(node->right, depth + 1);  // 右
    }

    int maxDepth(TreeNode* root) {
        dfs(root, 1);
        return result;
    }
};
```

这里的遍历顺序是：

```text
中 → 左 → 右
```

所以是前序思想。

## 7. 为什么前序求的是“深度”，后序求的是“高度”

这是二叉树学习中非常值得固定的一组对照：

| 维度 | 前序方案 | 后序方案 |
| --- | --- | --- |
| 信息流向 | 父节点 → 子节点 | 子节点 → 父节点 |
| 典型参数 | `depth` | 无需额外 depth |
| 典型返回值 | 通常无 / 只遍历 | 子树高度 |
| 当前节点何时处理 | 进入节点时 | 左右子树返回后 |
| 思考方向 | 从根往下 | 从叶往上 |

可以记成：

```text
深度：父亲告诉孩子“你在第几层”
高度：孩子告诉父亲“我下面有多高”
```

<Callout title="比背遍历顺序更有用的判断法" type="idea">

做递归题时先问：

```text
当前节点需要的信息，是从父节点带下来，还是从孩子返回上来？
```

- 从父节点带下来：更像前序；
- 从孩子返回上来：更像后序。

这比单纯背“前中后序模板”更容易迁移到新题。

</Callout>

## 8. 显式回溯写法：为什么会有 `depth++` 和 `depth--`

为了展示“深度随路径变化”的本质，也可以写成：

```cpp title="显式回溯"
class Solution {
public:
    int result = 0;

    void dfs(TreeNode* node, int depth) {
        if (node == nullptr) return;

        result = max(result, depth);

        if (node->left) {
            ++depth;
            dfs(node->left, depth);
            --depth;  // 回到当前节点时恢复现场
        }

        if (node->right) {
            ++depth;
            dfs(node->right, depth);
            --depth;
        }
    }

    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        dfs(root, 1);
        return result;
    }
};
```

这里的 `depth` 表示**当前递归路径上的状态**。

进入孩子：

```text
depth + 1
```

返回父节点：

```text
depth - 1
```

这就是最典型的回溯：

```text
做选择 → 递归 → 撤销选择
```

不过如果直接把 `depth + 1` 作为值传递：

```cpp
dfs(node->left, depth + 1);
```

那么每层函数都有自己的参数副本，就不需要手动 `--depth`。

## 9. 第三条路线：BFS 直接数层

最大深度也可以理解为：

```text
二叉树一共有多少层
```

这与层序遍历完全一致。

![层序遍历统计树深度](https://file1.kamacoder.com/i/algo/20200810193056585.png)

只要每处理完一整层：

```cpp
++depth;
```

最终 `depth` 就是最大深度。

```cpp title="层序 BFS"
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        queue<TreeNode*> q;
        q.push(root);

        int depth = 0;

        while (!q.empty()) {
            int size = q.size();
            ++depth;

            for (int i = 0; i < size; ++i) {
                TreeNode* node = q.front();
                q.pop();

                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }

        return depth;
    }
};
```

## 10. BFS 中为什么一定要提前保存 `size`

假设当前层有 `3` 个节点。

处理它们时，孩子会不断进入队列。如果直接写：

```cpp
for (int i = 0; i < q.size(); ++i)
```

那么 `q.size()` 会在循环过程中变化，当前层和下一层就混在一起。

正确做法是进入这一层之前冻结边界：

```cpp
int size = q.size();
```

然后只处理这 `size` 个旧节点。

因此层序模板的核心不是“用了队列”，而是：

```text
每轮 while 都严格对应一整层
```

## 11. 三种解法该怎么选

### 后序递归

最推荐。

```text
左高度
右高度
取 max + 1
```

优点：代码最短、语义最稳定，也是后续很多树形递归题的基础。

### 前序递归

当题目更强调“路径上的层数”或需要沿路径携带状态时很自然。

```text
进入节点时知道当前 depth
然后继续向下传 depth + 1
```

它能很好地连接到回溯思想。

### 层序 BFS

当问题本身与“层”高度相关时非常直观。

```text
每完成一层，depth + 1
```

如果后续问题还要求逐层统计信息，BFS 往往更方便。

## 12. 一个重要对比：最大深度和最小深度不是完全同一道题

最大深度的后序递归：

```cpp
return max(leftHeight, rightHeight) + 1;
```

很自然。

但最小深度不能无脑改成：

```cpp
return min(leftDepth, rightDepth) + 1;
```

原因在于：如果一个孩子为空，`0` 并不代表已经到达叶子。

例如：

```text
    1
     \
      2
```

如果直接取：

```text
min(0, 1) + 1 = 1
```

会错误地认为根节点就是叶子。

真正的叶子必须满足：

```text
left == null && right == null
```

<Callout title="这一点非常重要" type="warning">

“最大”允许选择更长的非空路径，所以空子树的 `0` 不会造成问题；

“最小”却不能把不存在的路径当成合法根到叶路径。

这就是 104 与 111 看似只差 `max/min`，实际上边界处理不同的原因。

</Callout>

## 13. 复杂度分析

设节点总数为 $n$，树高为 $h$，最大宽度为 $w$。

### 三种方法的时间复杂度

每个节点最多访问一次：

$$
O(n)
$$

### 递归 DFS 空间复杂度

递归栈深度与树高相关：

$$
O(h)
$$

- 平衡树：$O(\log n)$；
- 链状树：$O(n)$。

### BFS 空间复杂度

队列最大规模与树的最大宽度相关：

$$
O(w)
$$

最坏可达到：

$$
O(n)
$$

## 14. 一个更通用的递归分类：向下传 vs 向上收

树题可以先粗略分成两类信息流。

### 类型 A：向下传状态

典型形式：

```cpp
void dfs(TreeNode* node, State state)
```

父节点把状态交给孩子：

```text
当前深度
当前路径和
当前路径字符串
已经选择的节点
```

这类题经常带有前序 / 回溯味道。

### 类型 B：向上返回状态

典型形式：

```cpp
State dfs(TreeNode* node)
```

孩子计算好结果后返回给父亲：

```text
子树高度
子树节点数
是否平衡
子树最大值
```

这类题经常带有后序 / 树形 DP 味道。

最大深度恰好可以用两种方式都做，因此特别适合建立这组框架。

## 15. 常见错误

### 错误 1：把“深度”和“高度”当成完全同一个概念

对于根节点，两者数值确实恰好相同；但对普通节点并不一样。

```text
深度看上方：离根多远
高度看下方：离最远叶子多远
```

### 错误 2：空树返回 `1`

按“节点数”口径：

```text
空树深度 = 0
单节点树深度 = 1
```

所以边界必须是：

```cpp
if (root == nullptr) return 0;
```

### 错误 3：后序递归漏掉 `+1`

左右返回的是**子树高度**，当前节点自身还占一层：

```cpp
max(leftHeight, rightHeight) + 1
```

### 错误 4：前序递归共享 `depth` 却不回溯

如果手动修改同一个变量：

```cpp
++depth;
dfs(...);
```

返回后必须恢复：

```cpp
--depth;
```

否则从左子树出来以后，右子树会继承错误层数。

### 错误 5：BFS 不保存本层 `size`

这会导致当前层与下一层边界混乱，无法正确统计层数。

## 16. 扩展：N 叉树的最大深度

> LeetCode 559 · Maximum Depth of N-ary Tree

[题目链接](https://leetcode.cn/problems/maximum-depth-of-n-ary-tree/)

![559. N 叉树的最大深度](https://file1.kamacoder.com/i/algo/2021020315313214.png)

二叉树的递推式：

$$
H(u)=1+\max(H(u.left),H(u.right))
$$

到了 N 叉树，只是把“两棵子树取最大”扩展成“所有孩子取最大”：

$$
H(u)=1+\max_{v\in children(u)}H(v)
$$

所以算法思想完全没有变化。

### N 叉树递归

```cpp title="LeetCode 559 · 递归"
class Solution {
public:
    int maxDepth(Node* root) {
        if (root == nullptr) return 0;

        int childMax = 0;
        for (Node* child : root->children) {
            childMax = max(childMax, maxDepth(child));
        }

        return childMax + 1;
    }
};
```

### N 叉树层序 BFS

```cpp title="LeetCode 559 · 层序 BFS"
class Solution {
public:
    int maxDepth(Node* root) {
        if (root == nullptr) return 0;

        queue<Node*> q;
        q.push(root);

        int depth = 0;

        while (!q.empty()) {
            int size = q.size();
            ++depth;

            for (int i = 0; i < size; ++i) {
                Node* node = q.front();
                q.pop();

                for (Node* child : node->children) {
                    if (child) q.push(child);
                }
            }
        }

        return depth;
    }
};
```

## 17. 二叉树和 N 叉树为什么可以统一

如果把“孩子集合”统一记作 `children(u)`，那么最大深度问题根本不依赖“二叉”这个条件：

$$
H(u)=
\begin{cases}
0, & u=\varnothing \\
1+\max\limits_{v\in children(u)}H(v), & u\ne\varnothing
\end{cases}
$$

因此本题真正学习的是一个非常普遍的树结构规律：

```text
父节点的高度
= 所有孩子高度中的最大值 + 1
```

二叉树只是每个节点最多有两个孩子而已。

## 18. 进一步迁移：哪些题适合“先拿左右返回值”

掌握最大深度后，可以开始识别下面这类代码骨架：

```cpp
ReturnType dfs(TreeNode* node) {
    if (node == nullptr) return base;

    auto left = dfs(node->left);
    auto right = dfs(node->right);

    return combine(left, right, node);
}
```

它会出现在：

- 最小 / 最大深度；
- 平衡二叉树；
- 二叉树直径；
- 节点个数；
- 最大路径和；
- 最近公共祖先的部分解法；
- 各种树形 DP。

最大深度就是最简单的 `combine`：

```cpp
max(left, right) + 1
```

## 19. 三种方法的统一理解

虽然代码长相不同，但它们其实都在统计同一个量。

### 后序递归

```text
每个节点返回“我下面最多还能走几层”
```

### 前序递归

```text
每走到一个节点就知道“我现在已经走到第几层”
```

### BFS

```text
每处理完一整批同层节点，就说明又完成了一层
```

因此最大深度既可以：

```text
从叶子向根推出来
```

也可以：

```text
从根向叶子数出来
```

```text
题目要树的最大深度
        ↓
最简洁？
        ↓
后序递归：max(left, right) + 1
        ↓
题目同时涉及路径状态？
        ↓
前序 DFS：向下传 depth
        ↓
题目明显按层统计？
        ↓
BFS：每处理一层 depth++
```

<Callout title="一句话记忆" type="success">

**深度适合从根往下数，高度适合从叶往上算；而根节点的高度恰好就是整棵树的最大深度。**

</Callout>

impl Solution {
    pub fn max_depth(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        match root {
            None => 0,
            Some(node) => {
                let node = node.borrow();
                let left = Self::max_depth(node.left.clone());
                let right = Self::max_depth(node.right.clone());
                left.max(right) + 1
            }
        }
    }
