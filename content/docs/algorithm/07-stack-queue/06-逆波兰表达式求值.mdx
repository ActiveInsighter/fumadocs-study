# 150. 逆波兰表达式求值

<Cards>
  <Card title="题目" href="https://leetcode.cn/problems/evaluate-reverse-polish-notation/">
    LeetCode 150 · Evaluate Reverse Polish Notation
  </Card>
</Cards>

给定一个字符串数组 `tokens`，表示一个逆波兰表达式。

要求计算表达式结果。

支持：

```text
+
-
*
/
```

例如：

```text
["2", "1", "+", "3", "*"]
```

对应：

$$
(2+1)\times3=9
$$

输出：

```text
9
```

再例如：

```text
["4", "13", "5", "/", "+"]
```

对应：

$$
4+\frac{13}{5}=6
$$

按题目整数除法规则得到：

```text
6
```

<Callout type="info" title="逆波兰表达式为什么特别适合栈">
后缀表达式的运算符出现在操作数后面。

当遇到一个运算符时，它所需要的两个操作数正好就是：

> **最近压入、尚未被使用的两个数字。**

这正是栈的 LIFO 顺序。
</Callout>

---

# 1. 什么是逆波兰表达式

普通中缀表达式：

```text
(2 + 1) * 3
```

逆波兰表达式（后缀表达式）：

```text
2 1 + 3 *
```

特点：

> 运算符写在操作数之后。

---

## 2. 为什么后缀表达式不需要括号

中缀表达式：

```text
2 + 1 * 3
```

需要依赖：

```text
运算符优先级
```

如果想表示：

```text
(2 + 1) * 3
```

必须写括号。

而后缀表达式：

```text
2 1 + 3 *
```

运算顺序已经由排列本身确定。

所以不需要：

- 括号；
- 运算符优先级规则。

这也是后缀表达式在编译器和表达式计算中的重要价值。

---

# 3. 栈计算后缀表达式的规则

从左到右扫描 `tokens`。

### 如果是数字

直接入栈。

### 如果是运算符

从栈中弹出两个数：

```text
右操作数 b
左操作数 a
```

计算：

$$
a\ operator\ b
$$

然后把结果重新压栈。

---

# 4. 为什么先弹出来的是右操作数

这是本题最容易写错的地方。

例如：

```text
4 13 5 / +
```

处理：

```text
13 5 /
```

栈中：

```text
top
 ↓
 5
13
 4
```

第一个 pop：

```text
5
```

它应该是：

$$
b
$$

第二个 pop：

```text
13
```

它应该是：

$$
a
$$

所以计算：

$$
13/5
$$

不是：

$$
5/13
$$

因此标准写法：

```cpp
int b = st.top();
st.pop();

int a = st.top();
st.pop();

st.push(a / b);
```

<Callout type="warning" title="减法和除法尤其要注意顺序">
加法、乘法满足交换律，写反了可能暂时看不出 bug。

但：

$$
a-b\ne b-a
$$

$$
a/b\ne b/a
$$

所以必须明确：

```text
第一次 pop = 右操作数
第二次 pop = 左操作数
```
</Callout>

# 5. 示例完整推演

表达式：

```text
2 1 + 3 *
```

初始：

```text
[]
```

读取 `2`：

```text
[2]
```

读取 `1`：

```text
[2, 1]
```

读取 `+`：

弹出：

```text
b = 1
a = 2
```

计算：

$$
2+1=3
$$

压回：

```text
[3]
```

读取 `3`：

```text
[3, 3]
```

读取 `*`：

$$
3\times3=9
$$

压回：

```text
[9]
```

最终：

```text
9
```

# 6. 标准解法

```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<long long> st;

        for (const string& token : tokens) {
            if (
                token == "+" ||
                token == "-" ||
                token == "*" ||
                token == "/"
            ) {
                long long b = st.top();
                st.pop();

                long long a = st.top();
                st.pop();

                if (token == "+") {
                    st.push(a + b);
                } else if (token == "-") {
                    st.push(a - b);
                } else if (token == "*") {
                    st.push(a * b);
                } else {
                    st.push(a / b);
                }
            } else {
                st.push(stoll(token));
            }
        }

        return static_cast<int>(st.top());
    }
};
```

# 7. 为什么用 `long long`

题目最终结果通常保证在 32 位范围内。

但中间计算可能暂时变大。

例如：

```text
大整数乘法
```

如果全程用 `int`，某些数据范围下存在溢出风险。

使用：

```cpp
long long
```

更稳妥。

最终再：

```cpp
static_cast<int>
```

返回。

---

# 8. 如何判断 token 是数字还是运算符

因为题目运算符只有：

```text
+
-
*
/
```

最稳妥方法是直接判断：

```cpp
token == "+"
...
```

如果都不是，则把它当作整数。

不要简单判断：

```text
token[0] 是否是数字
```

因为负数例如：

```text
"-11"
```

第一个字符是：

```text
'-'
```

但它并不是减号运算符。

---

# 9. 为什么 `"-11"` 不会和 `"-"` 混淆

因为 token 是完整字符串。

减号运算符：

```text
"-"
```

长度为 1。

负数：

```text
"-11"
```

是另一个完整 token。

直接比较：

```cpp
token == "-"
```

就不会混淆。

---

# 10. 为什么表达式合法时最终只剩一个元素

每个数字：

```text
栈大小 +1
```

每个二元运算符：

```text
弹出 2 个
压回 1 个
```

净变化：

```text
栈大小 -1
```

一个合法二元表达式最终会把所有中间结果逐步归约成一个最终值。

所以扫描结束后：

```text
stack size == 1
```

这个唯一值就是答案。

---

# 11. 逆波兰表达式和表达式树

例如后缀表达式：

```text
2 1 + 3 *
```

对应表达式树：

```text
      *
     / \
    +   3
   / \
  2   1
```

后缀遍历顺序：

```text
左子树
右子树
根
```

正好是：

```text
2 1 + 3 *
```

所以逆波兰表达式本质上就是：

> 表达式树的后序遍历结果。

这也解释了为什么栈可以自然计算它。

---

# 12. 为什么栈适合“归约”

整个过程可以理解成：

```text
读取 token
      ↓
形成一个局部完整表达式
      ↓
把局部表达式压缩成一个结果
      ↓
结果继续参与更高层表达式
```

例如：

```text
2 1 +
```

归约为：

```text
3
```

然后：

```text
3 3 *
```

再归约成：

```text
9
```

栈特别适合保存：

> 尚未被更高层运算消费的中间结果。

---

# 13. 时间复杂度

每个 token 只扫描一次。

每个数字最多：

```text
push 一次
```

每个操作数作为中间值最多：

```text
pop 一次
```

因此时间复杂度：

$$
O(n)
$$

空间复杂度最坏：

$$
O(n)
$$

例如前面连续很多数字，还没遇到足够运算符。

---

# 14. 除法规则

题目要求整数除法：

> 向 0 截断。

例如：

$$
6/(-4)=-1
$$

不是：

$$
-2
$$

C++、Java 中整数除法本身通常符合向 0 截断。

Python 的：

```python
//
```

是向负无穷取整，不完全相同。

例如：

```python
-6 // 4 == -2
```

但题目需要：

```text
-1
```

所以 Python 需要：

```python
int(a / b)
```

来实现向 0 截断。

---

# 15. Python 中为什么不能直接 `int(a / b)` 处理超大整数吗

在这道题的数据范围内通常没有问题。

如果需要完全避免浮点转换，可以写整数版本：

```python
sign = -1 if (a < 0) ^ (b < 0) else 1
value = abs(a) // abs(b)
result = sign * value
```

这样严格使用整数运算。

---

# 16. 可以不用 `stack` 类吗

完全可以。

任何支持：

```text
push_back
pop_back
back
```

的动态数组都可以作为栈。

例如 C++：

```cpp
vector<long long> st;
```

使用：

```cpp
st.push_back(...)
st.back()
st.pop_back()
```

很多语言中：

```text
数组 / 列表
```

就是最常见的栈实现。

# 17. 常见错误

### 错误一：操作数顺序反了

错误：

```cpp
a = 第一次 pop
b = 第二次 pop
```

对于 `-`、`/` 会直接出错。

正确：

```text
第一次 pop = b
第二次 pop = a
```

---

### 错误二：把负数当成减号

必须比较完整 token。

---

### 错误三：运算后忘记把结果压回栈

局部表达式必须归约成一个新的操作数，继续参与后续运算。

---

### 错误四：Python 使用 `//`

负数除法语义可能与题目不同。

  ### Java

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String token : tokens) {
            switch (token) {
                case "+" -> {
                    int b = stack.pop();
                    int a = stack.pop();
                    stack.push(a + b);
                }
                case "-" -> {
                    int b = stack.pop();
                    int a = stack.pop();
                    stack.push(a - b);
                }
                case "*" -> {
                    int b = stack.pop();
                    int a = stack.pop();
                    stack.push(a * b);
                }
                case "/" -> {
                    int b = stack.pop();
                    int a = stack.pop();
                    stack.push(a / b);
                }
                default -> stack.push(
                    Integer.parseInt(token)
                );
            }
        }

        return stack.peek();
    }
}
```

  ### Python

```python
from typing import List

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []

        for token in tokens:
            if token in {"+", "-", "*", "/"}:
                b = stack.pop()
                a = stack.pop()

                if token == "+":
                    stack.append(a + b)
                elif token == "-":
                    stack.append(a - b)
                elif token == "*":
                    stack.append(a * b)
                else:
                    sign = -1 if (a < 0) ^ (b < 0) else 1
                    value = abs(a) // abs(b)
                    stack.append(sign * value)
            else:
                stack.append(int(token))

        return stack[-1]
```

  ### Go

```go
func evalRPN(tokens []string) int {
    stack := make([]int, 0)

    for _, token := range tokens {
        switch token {
        case "+", "-", "*", "/":
            b := stack[len(stack)-1]
            stack = stack[:len(stack)-1]

            a := stack[len(stack)-1]
            stack = stack[:len(stack)-1]

            var result int

            switch token {
            case "+":
                result = a + b
            case "-":
                result = a - b
            case "*":
                result = a * b
            case "/":
                result = a / b
            }

            stack = append(stack, result)

        default:
            value, _ := strconv.Atoi(token)
            stack = append(stack, value)
        }
    }

    return stack[len(stack)-1]
}
```

# 20. 本题总结

逆波兰表达式求值的标准模板：

```text
数字：
    入栈

运算符：
    b = pop
    a = pop
    result = a op b
    result 入栈
```

需要特别记住：

```text
第一次弹出的是右操作数
第二次弹出的是左操作数
```

栈在这里保存的不是“字符”，而是：

> **最近生成、尚未参与更高层运算的中间结果。**

这正是栈处理表达式归约的经典应用。
