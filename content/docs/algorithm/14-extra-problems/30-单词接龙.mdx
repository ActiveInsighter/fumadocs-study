# 127. 单词接龙

[LeetCode 127：单词接龙](https://leetcode.cn/problems/word-ladder/)

给定起始单词 `beginWord`、目标单词 `endWord` 和字典 `wordList`。每次只能修改一个字母，并且转换后的单词必须出现在字典中。要求返回从起点到终点的 **最短转换序列长度**；若无法到达，返回 `0`。

例如：

```text
beginWord = "hit"
endWord   = "cog"
wordList  = ["hot","dot","dog","lot","log","cog"]
```

一种最短转换过程为：

```text
hit -> hot -> dot -> dog -> cog
```

因此答案为 `5`。

![](https://file1.kamacoder.com/i/algo/20210827175432.png)

> [!NOTE]
> 本题真正考查的并不是字符串操作，而是：**如何把字符串状态转换成一张图，再在无权图上求最短路。**

## 一、建模：单词就是图中的节点

把每一个合法单词看成一个节点。

如果两个单词：

- 长度相同；
- 恰好只有一个位置上的字符不同；

那么就在它们之间连一条边。

例如：

```text
hit <-> hot
hot <-> dot
hot <-> lot
```

因为一次转换只允许修改一个字符，所以每次转换就等价于：

> 从图中的一个节点走到某个相邻节点。

题目要求最少经过多少个单词，本质上就是求：

> `beginWord` 到 `endWord` 的无权最短路径。

## 二、为什么应该使用 BFS

无权图最短路的标准工具就是 BFS。

BFS 会按照距离分层扩展：

```text
第 0 层：起点
第 1 层：一步能够到达的节点
第 2 层：两步能够到达的节点
...
```

因此第一次搜索到 `endWord` 时，得到的一定是最短路径。

如果把起点单词自身算作序列中的第一个单词，则可以定义：

$$
dist(beginWord)=1
$$

每经过一次转换：

$$
dist(next)=dist(cur)+1
$$

于是第一次到达 `endWord` 时直接返回对应的 `dist` 即可。

> [!TIP]
> DFS 也能枚举所有可能路径，但必须继续搜索并比较不同路径长度；BFS 天生具有“第一次到达即最短”的性质，因此更符合本题结构。

## 三、难点：不显式建立整张图

最直接的做法是两两比较所有单词，看它们是否只差一个字符。

假设：

- 字典中有 $N$ 个单词；
- 每个单词长度为 $L$。

两两比较需要大约：

$$
O(N^2L)
$$

这通常没有必要。

更好的做法是：

> 对当前单词的每一个位置，尝试将该位置修改为 `a` 到 `z`，直接生成所有可能的一步邻居。

若单词长度为 $L$，那么最多生成：

$$
26L
$$

个候选单词。

例如当前单词为：

```text
hot
```

可以依次生成：

```text
aot, bot, ..., zot
hat, hbt, ..., hzt
hoa, hob, ..., hoz
```

然后只需要判断候选字符串是否存在于字典集合中。

因此应先把 `wordList` 放入哈希集合：

```cpp
unordered_set<string> words(wordList.begin(), wordList.end());
```

平均查询复杂度可以看作 $O(1)$。

## 四、访问标记为什么不可缺少

这张图是无向图。

例如：

```text
hit -> hot
```

那么也存在：

```text
hot -> hit
```

如果不记录已经访问过的单词，就可能在两个节点之间不断来回，造成重复搜索甚至死循环。

因此每个单词第一次入队时就应立刻标记为已访问。

一个非常实用的写法是：

> 直接把已经使用过的单词从 `wordSet` 中删除。

这样 `wordSet` 同时承担：

1. 判断候选单词是否合法；
2. 判断该单词是否尚未访问。

## 五、标准 BFS 写法

### 1. 特判终点是否存在

题目规定中间转换单词必须来自 `wordList`，目标单词也必须在其中。

因此：

```cpp
if (!wordSet.count(endWord)) return 0;
```

### 2. 起点入队

令起点的序列长度为 $1$：

```cpp
queue<pair<string, int>> q;
q.push({beginWord, 1});
```

### 3. 枚举当前节点的所有邻居

对于每个位置 `i`：

```cpp
for (char c = 'a'; c <= 'z'; ++c)
```

生成候选单词。

如果候选词恰好是终点，则返回：

$$
step+1
$$

如果候选词存在于 `wordSet`，则说明它：

- 是合法字典单词；
- 还没有访问过。

于是将其加入队列，并从集合中删除。

## 六、C++ 推荐实现

```cpp
class Solution {
public:
    int ladderLength(string beginWord, string endWord,
                     vector<string>& wordList) {
        unordered_set<string> wordSet(wordList.begin(), wordList.end());

        if (!wordSet.count(endWord)) return 0;

        queue<pair<string, int>> q;
        q.push({beginWord, 1});

        // beginWord 即使出现在字典中，也不应再次访问
        wordSet.erase(beginWord);

        while (!q.empty()) {
            auto [word, step] = q.front();
            q.pop();

            for (int i = 0; i < static_cast<int>(word.size()); ++i) {
                string next = word;
                char original = next[i];

                for (char c = 'a'; c <= 'z'; ++c) {
                    if (c == original) continue;
                    next[i] = c;

                    if (next == endWord) {
                        return step + 1;
                    }

                    if (wordSet.count(next)) {
                        q.push({next, step + 1});
                        wordSet.erase(next);
                    }
                }
            }
        }

        return 0;
    }
};
```

## 七、为什么“入队时标记”而不是“出队时标记”

这是 BFS 中一个非常重要的细节。

假设同一层中的两个节点都能走到同一个新节点 `x`。

如果直到 `x` 出队时才标记，那么两个父节点都可能把 `x` 加入队列，造成重复状态。

正确做法是：

```text
发现 x
-> 立刻标记 x
-> 再把 x 入队
```

也就是：

> **一个状态只能第一次被发现时入队。**

这也是许多 BFS 题的通用规则。

## 八、复杂度分析

设：

- 字典中共有 $N$ 个单词；
- 每个单词长度为 $L$。

每个单词最多只会被真正访问一次。

访问某个单词时，需要枚举：

$$
26L
$$

种字符替换。

如果把字符串复制和哈希的成本也计入，则更严格地说复杂度接近：

$$
O(NL^2\cdot 26)
$$

在常见题解分析中，也通常把一次字符串哈希/构造视作常数级简化，写成：

$$
O(NL\cdot 26)
$$

空间复杂度主要来自哈希集合和 BFS 队列：

$$
O(N)
$$

若计入字符串存储，则为：

$$
O(NL)
$$

## 九、进一步优化：双向 BFS

普通 BFS 从 `beginWord` 一侧不断扩展。

如果搜索树的分支因子较大，节点数量会快速增长。

双向 BFS 同时从：

```text
beginWord
endWord
```

两端向中间扩展。

并且每轮优先扩展节点数较少的一侧。

直观上，如果最短路径长度为 $d$，普通 BFS 可能需要扩展到深度 $d$；双向 BFS 大约只需要两侧各扩展到：

$$
\frac d2
$$

当分支很多时，实际搜索节点数会明显减少。

### 双向 BFS 的核心判断

若从当前一侧生成的 `next` 已经存在于另一侧集合中，则两端搜索相遇。

此时得到最短转换长度。

> [!IMPORTANT]
> 双向 BFS 的优势主要体现在搜索空间，而不是改变最坏情况下的大 $O$ 上界。考研/面试中更重要的是理解它为什么能减少实际扩展节点数。

## 十、常见错误

### 错误 1：把边数当成答案

题目要求的是序列中的 **单词数**。

例如：

```text
hit -> hot -> dot -> dog -> cog
```

共有 $4$ 条边，但答案是：

```text
5
```

所以通常令起点距离直接初始化为 $1$。

### 错误 2：没有判断 `endWord` 是否在字典中

如果 `endWord` 不在 `wordList` 中，则按照题意无法完成转换，应直接返回 `0`。

### 错误 3：允许同一字符替换成自身

例如：

```text
hot -> hot
```

这不是有效转换。

虽然访问集合通常能避免严重后果，但跳过原字符更干净：

```cpp
if (c == original) continue;
```

### 错误 4：使用 DFS 求最短路

DFS 更擅长：

- 枚举路径；
- 判断是否存在某条路径；
- 回溯组合。

无权图最短路优先想到 BFS。

## 十一、方法总结

本题可以抽象成如下模板：

```text
状态             -> 图节点
一次合法变化     -> 图边
最少变化次数     -> 无权图最短路
第一次到达终点   -> 最短答案
```

遇到类似题目时，如果题目出现：

- 最少操作次数；
- 每次只能执行一种局部变化；
- 每个状态可以生成若干下一状态；

就应该考虑把问题建模成 **状态图上的 BFS**。

```java tab="Java"
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> words = new HashSet<>(wordList);
        if (!words.contains(endWord)) return 0;

        Queue<String> queue = new ArrayDeque<>();
        queue.offer(beginWord);
        words.remove(beginWord);

        int step = 1;

        while (!queue.isEmpty()) {
            int size = queue.size();

            while (size-- > 0) {
                String word = queue.poll();
                char[] chars = word.toCharArray();

                for (int i = 0; i < chars.length; i++) {
                    char original = chars[i];

                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;
                        chars[i] = c;
                        String next = new String(chars);

                        if (next.equals(endWord)) return step + 1;

                        if (words.remove(next)) {
                            queue.offer(next);
                        }
                    }

                    chars[i] = original;
                }
            }

            step++;
        }

        return 0;
    }
}
```

```python tab="Python"
from collections import deque
from typing import List


class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        words = set(wordList)
        if endWord not in words:
            return 0

        q = deque([(beginWord, 1)])
        words.discard(beginWord)

        while q:
            word, step = q.popleft()

            for i in range(len(word)):
                for code in range(ord('a'), ord('z') + 1):
                    c = chr(code)
                    if c == word[i]:
                        continue

                    nxt = word[:i] + c + word[i + 1:]

                    if nxt == endWord:
                        return step + 1

                    if nxt in words:
                        words.remove(nxt)
                        q.append((nxt, step + 1))

        return 0
```

```go tab="Go"
func ladderLength(beginWord string, endWord string, wordList []string) int {
    words := make(map[string]bool)
    for _, word := range wordList {
        words[word] = true
    }

    if !words[endWord] {
        return 0
    }

    type node struct {
        word string
        step int
    }

    q := []node{{beginWord, 1}}
    delete(words, beginWord)

    for len(q) > 0 {
        cur := q[0]
        q = q[1:]

        bytes := []byte(cur.word)

        for i := 0; i < len(bytes); i++ {
            original := bytes[i]

            for c := byte('a'); c <= byte('z'); c++ {
                if c == original {
                    continue
                }

                bytes[i] = c
                next := string(bytes)

                if next == endWord {
                    return cur.step + 1
                }

                if words[next] {
                    delete(words, next)
                    q = append(q, node{next, cur.step + 1})
                }
            }

            bytes[i] = original
        }
    }

    return 0
}
```

```javascript tab="JavaScript"
var ladderLength = function(beginWord, endWord, wordList) {
    const words = new Set(wordList);
    if (!words.has(endWord)) return 0;

    const queue = [[beginWord, 1]];
    let head = 0;
    words.delete(beginWord);

    while (head < queue.length) {
        const [word, step] = queue[head++];

        for (let i = 0; i < word.length; i++) {
            for (let code = 97; code <= 122; code++) {
                const c = String.fromCharCode(code);
                if (c === word[i]) continue;

                const next = word.slice(0, i) + c + word.slice(i + 1);

                if (next === endWord) return step + 1;

                if (words.has(next)) {
                    words.delete(next);
                    queue.push([next, step + 1]);
                }
            }
        }
    }

    return 0;
};
```
