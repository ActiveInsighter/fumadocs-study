# 35. 搜索插入位置

[LeetCode 35：搜索插入位置](https://leetcode.cn/problems/search-insert-position/)

给定一个严格递增数组 `nums` 和目标值 `target`：

- 如果 `target` 已经存在，返回它的下标；
- 如果不存在，返回它按升序插入后应该出现的位置。

例如：

```text
nums = [1, 3, 5, 6]
```

不同目标值对应：

```text
target = 5 -> 2
target = 2 -> 1
target = 7 -> 4
target = 0 -> 0
```

![搜索插入位置的四种情况](https://file1.kamacoder.com/i/algo/20201216232148471.png)

> [!IMPORTANT]
> 这道题最值得掌握的不是“找到 target”，而是把问题统一为：**寻找第一个大于等于 `target` 的位置。**

## 一、插入位置到底是什么

对于有序数组，正确插入位置 `i` 必须满足：

```text
i 左边的元素都 < target
i 位置及右边的元素都 >= target
```

因此答案就是：

$$
\min\{i\mid nums[i]\ge target\}
$$

如果不存在任何元素满足：

$$
nums[i]\ge target
$$

那么答案就是数组长度：

$$
n
$$

这其实正是经典的：

```text
lower_bound(target)
```

## 二、为什么线性扫描也能做

最直观的办法是从左向右寻找第一个：

```cpp
nums[i] >= target
```

一旦找到，`i` 就是答案。

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for (int i = 0; i < nums.size(); ++i) {
            if (nums[i] >= target) {
                return i;
            }
        }

        return nums.size();
    }
};
```

时间复杂度：

$$
O(n)
$$

空间复杂度：

$$
O(1)
$$

这个思路非常重要，因为它直接揭示了答案的数学定义。

二分查找只是利用“有序性”，把寻找第一个满足条件的位置从 $O(n)$ 优化到：

$$
O(\log n)
$$

## 三、为什么有序数组应该想到二分

数组已经严格递增，所以对于条件：

```text
nums[i] >= target
```

它具有单调性。

例如：

```text
nums   = [1, 3, 5, 6, 9]
target = 6
```

条件：

```text
nums[i] >= 6
```

对应真假序列：

```text
false false false true true
```

目标就是找到：

```text
第一个 true
```

这种“左边一段 false，右边一段 true”的边界问题，是二分查找最典型的使用场景。

![二分查找示意](https://file1.kamacoder.com/i/algo/202012162326354.png)

## 四、推荐模板：左闭右开区间 `[left, right)`

对于“找第一个满足条件的位置”，推荐把搜索区间定义为：

$$
[left,right)
$$

初始化：

```cpp
int left = 0;
int right = nums.size();
```

这里 `right = n` 很重要，因为答案本身就可能是：

```text
n
```

例如：

```text
nums   = [1, 3, 5, 6]
target = 7
```

应该插到末尾：

```text
下标 4
```

如果搜索空间从一开始就完全排除了 `n`，处理末尾插入会更绕。

## 五、二分更新规则

每次取：

```cpp
int mid = left + (right - left) / 2;
```

### 情况 1：`nums[mid] < target`

说明 `mid` 一定不是答案。

不仅 `mid` 不是答案，它左边所有位置也不可能是答案，因为数组有序。

所以：

```cpp
left = mid + 1;
```

### 情况 2：`nums[mid] >= target`

此时 `mid` 可能就是我们寻找的第一个位置。

因此不能直接丢掉 `mid`，应该：

```cpp
right = mid;
```

不断压缩后，最终：

```text
left == right
```

这个位置就是第一个满足：

```text
nums[i] >= target
```

的位置。

## 六、最推荐的完整写法

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return left;
    }
};
```

时间复杂度：

$$
O(\log n)
$$

空间复杂度：

$$
O(1)
$$

> [!TIP]
> 这个版本不仅适用于“数组中没有重复元素”。即使数组有重复值，它仍会返回第一个大于等于 `target` 的位置，也就是标准 `lower_bound`。

## 七、完整推演：`target = 2`

考虑：

```text
nums = [1, 3, 5, 6]
target = 2
```

初始：

```text
left  = 0
right = 4
搜索区间 = [0, 4)
```

### 第一次

```text
mid = 2
nums[2] = 5
```

因为：

```text
5 >= 2
```

所以 `mid = 2` 仍然可能是答案：

```text
right = 2
```

区间变为：

```text
[0, 2)
```

### 第二次

```text
mid = 1
nums[1] = 3
```

因为：

```text
3 >= 2
```

继续：

```text
right = 1
```

区间：

```text
[0, 1)
```

### 第三次

```text
mid = 0
nums[0] = 1
```

因为：

```text
1 < 2
```

所以：

```text
left = 1
```

此时：

```text
left == right == 1
```

返回：

```text
1
```

正好是 `2` 应该插入的位置。

## 八、为什么循环结束后的 `left` 一定是答案

二分过程中始终维持两个事实：

```text
left 左边的位置全部已经确定 < target
right 及其右边的候选边界不会比真正答案更靠左
```

进一步理解，可以把区间外看成：

```text
[0, left)     -> 已确定不是答案，值都 < target
[right, n)    -> 已进入 >= target 的一侧
[left, right) -> 仍待确定
```

当：

```text
left == right
```

未知区间为空，两侧边界恰好相遇于第一个满足条件的位置。

因此：

```cpp
return left;
```

不需要额外分类讨论四种插入场景。

## 九、另一种合法模板：左闭右闭 `[left, right]`

也可以定义搜索区间为：

$$
[left,right]
$$

此时初始化：

```cpp
int left = 0;
int right = nums.size() - 1;
```

由于 `right` 是有效下标，所以循环条件应为：

```cpp
while (left <= right)
```

当：

```cpp
nums[mid] < target
```

丢弃：

```text
[left, mid]
```

所以：

```cpp
left = mid + 1;
```

当：

```cpp
nums[mid] > target
```

丢弃：

```text
[mid, right]
```

所以：

```cpp
right = mid - 1;
```

如果等于就直接返回。

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                return mid;
            }
        }

        return left;
    }
};
```

循环结束时：

```text
right < left
```

而 `left` 正好就是插入位置。

## 十、两套二分模板为什么不能混写

这是最常见的错误来源。

### 左闭右闭

定义：

$$
[left,right]
$$

因此：

```cpp
while (left <= right)
```

若排除 `mid`：

```cpp
right = mid - 1;
left = mid + 1;
```

### 左闭右开

定义：

$$
[left,right)
$$

因此：

```cpp
while (left < right)
```

若 `mid` 仍可能是答案：

```cpp
right = mid;
```

> [!WARNING]
> 不要背“`while` 到底写 `<` 还是 `<=`”。先确定区间定义，再让所有边界更新都服从这个定义。

## 十一、为什么使用 `left + (right - left) / 2`

数学上：

$$
\frac{left+right}{2}
$$

和：

$$
left+\frac{right-left}{2}
$$

等价。

但在固定宽度整数类型中：

```cpp
(left + right) / 2
```

理论上可能在 `left + right` 时发生溢出。

因此更稳妥的写法是：

```cpp
int mid = left + (right - left) / 2;
```

## 十二、四种情况其实已经统一了

原题常把情况分为：

1. `target` 比所有元素都小；
2. `target` 等于某个元素；
3. `target` 应插在两个元素之间；
4. `target` 比所有元素都大。

但 `lower_bound` 模型可以统一处理。

例如：

```text
nums = [1, 3, 5, 6]
```

| `target` | 第一个 `>= target` 的位置 | 答案 |
| --- | ---: | ---: |
| `0` | `0` | `0` |
| `5` | `2` | `2` |
| `4` | `2` | `2` |
| `7` | 不存在，对应 `n` | `4` |

所以真正值得记忆的不是四种分支，而是：

$$
\boxed{\text{答案 = 第一个 } nums[i]\ge target \text{ 的位置}}
$$

## 十三、和上一题二分边界的联系

在“查找元素的第一个和最后一个位置”中，左边界也是：

```text
lower_bound(target)
```

而本题本身就是一个完整的 `lower_bound` 模板题。

因此建议把这两道题联系起来：

```text
搜索插入位置
    ↓
掌握 lower_bound
    ↓
进一步解决重复元素的左右边界
```

这比把每一道二分题单独背代码更有效。

## 十四、常见错误

### 1. `right = nums.size()` 却写 `left <= right`

若定义：

```text
[left, right)
```

那么 `right = n` 不是有效数组下标。

此时必须使用：

```cpp
while (left < right)
```

否则可能访问：

```cpp
nums[n]
```

造成越界。

### 2. `nums[mid] >= target` 时写 `right = mid - 1`

在 `lower_bound` 的左闭右开模板中，`mid` 自己可能就是答案，所以不能直接删除。

正确是：

```cpp
right = mid;
```

### 3. 找不到时返回 `-1`

本题不是普通的“存在性查找”。

即使不存在，也必须返回合法插入位置。

例如：

```text
nums   = [1, 3, 5, 6]
target = 7
```

答案是：

```text
4
```

而不是：

```text
-1
```

## 十五、模板总结

以后看到下面这种描述：

```text
有序数组
找第一个 >= x
找第一个 > x
找最后一个 < x
找最后一个 <= x
```

应立即想到“二分边界”，而不是普通二分查找。

其中最基础的一条就是：

```cpp
// 第一个 >= target 的位置
int lowerBound(const vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size();

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

这道题的答案就是：

```cpp
return lowerBound(nums, target);
```
