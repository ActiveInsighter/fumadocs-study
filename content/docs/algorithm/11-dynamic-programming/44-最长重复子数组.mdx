# 718. 最长重复子数组

[LeetCode 718：最长重复子数组](https://leetcode.cn/problems/maximum-length-of-repeated-subarray/)

给定两个整数数组 `nums1` 和 `nums2`，求它们的**最长公共连续子数组**长度。

例如：

```text
nums1 = [1, 2, 3, 2, 1]
nums2 = [3, 2, 1, 4, 7]
```

最长公共连续片段是：

```text
[3, 2, 1]
```

因此答案为：

$$
\boxed{3}
$$

<Callout type="warning" title="子数组必须连续">
本题不是最长公共子序列。公共子数组要求两个数组中选出的元素都必须连续，因此一旦当前位置元素不相等，当前连续匹配长度就必须中断。
</Callout>

## 1. 暴力思路为什么会重复计算

最直接的方法是：

1. 枚举 `nums1` 的起点 $i$；
2. 枚举 `nums2` 的起点 $j$；
3. 从两个起点同时向后比较，直到元素不同。

最坏情况下，需要大量重复比较，复杂度可以达到：

$$
O(nm\min(n,m))
$$

动态规划的意义，就是把“两个位置之前已经连续匹配了多长”保存下来。

## 2. 最关键的状态定义

定义：

$$
\boxed{
dp[i][j]=
\text{以 }nums1[i-1]\text{ 和 }nums2[j-1]\text{ 同时结尾的最长公共连续子数组长度}
}
$$

这里有两个关键词：

- **同时结尾**；
- **连续**。

为什么索引写成 `i - 1` 和 `j - 1`？

因为这样可以额外增加第 0 行和第 0 列作为哨兵，使边界统一为 0，从而避免大量特殊判断。

矩阵尺寸为：

$$
(n+1)\times(m+1)
$$

其中：

$$
dp[0][j]=0,\qquad dp[i][0]=0
$$

## 3. 状态转移为什么只看左上角

如果：

$$
nums1[i-1]=nums2[j-1]
$$

那么当前两个元素可以接在前面的公共连续片段之后。

前一个匹配位置必须同时向前退一位：

$$
(i-1,j-1)
$$

因此：

$$
\boxed{
dp[i][j]=dp[i-1][j-1]+1
}
$$

如果当前两个元素不相等，则以它们同时结尾的公共连续子数组不存在：

$$
\boxed{dp[i][j]=0}
$$

所以完整转移是：

$$
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+1, & nums1[i-1]=nums2[j-1] \\
0, & nums1[i-1]\ne nums2[j-1]
\end{cases}
$$

<Callout type="info" title="为什么不是来自上方或左方">
如果从 `dp[i-1][j]` 或 `dp[i][j-1]` 转移，就意味着允许跳过某个数组中的元素，这会把问题变成“最长公共子序列”，不再满足连续要求。
</Callout>

## 4. 一个几何视角：只沿对角线延伸

把两个数组分别放在二维表的行和列上。

如果当前位置相等，公共连续片段只能沿：

```text
左上 -> 右下
```

继续增长。

也就是说，本题本质上是在二维匹配矩阵中寻找最长的连续相等对角线。

原题示意如下：

![718. 最长重复子数组 DP 表](https://file1.kamacoder.com/i/algo/2021011215282060.jpg)

这个视角非常重要，因为它直接解释了：

$$
dp[i][j]\leftarrow dp[i-1][j-1]
$$

## 5. 初始化

第 0 行表示 `nums1` 还没有元素；第 0 列表示 `nums2` 还没有元素。

不存在非空公共连续子数组，因此：

$$
\boxed{dp[0][j]=0}
$$

$$
\boxed{dp[i][0]=0}
$$

借助这一层哨兵，即使比较两个数组的第一个元素，也可以直接写：

$$
dp[1][1]=dp[0][0]+1
$$

无需额外特判。

## 6. 遍历顺序

因为每个状态依赖左上角：

$$
dp[i-1][j-1]
$$

所以二维 DP 中只要保证上一行已经计算完成即可。

最自然的遍历方式：

```cpp
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        ...
    }
}
```

外层和内层交换也可以。

## 7. 为什么答案不能直接取 `dp[n][m]`

`dp[n][m]` 只表示：

> 必须同时以 `nums1[n-1]` 和 `nums2[m-1]` 结尾的公共连续子数组长度。

但真正的最长公共片段可能在任何位置结束。

所以答案是：

$$
\boxed{
\max_{1\le i\le n,\,1\le j\le m} dp[i][j]
}
$$

因此计算过程中必须同步维护最大值。

## 8. 二维 DP 标准写法

```cpp
class Solution {
public:
    int findLength(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        int m = nums2.size();

        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        int ans = 0;

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    ans = max(ans, dp[i][j]);
                }
            }
        }

        return ans;
    }
};
```

复杂度：

$$
\text{时间复杂度}=O(nm)
$$

$$
\text{空间复杂度}=O(nm)
$$

## 9. 为什么可以压缩为一维 DP

观察转移：

$$
dp[i][j]\leftarrow dp[i-1][j-1]
$$

当前行的 `dp[j]` 只依赖上一行的 `dp[j-1]`。

因此可以把二维数组压缩为：

```text
dp[j]
```

其中 `dp[j]` 在更新前代表上一行状态。

但是这里存在一个非常关键的问题：**覆盖**。

## 10. 一维数组为什么必须倒序遍历

假设正序更新：

```text
j = 1, 2, 3, ...
```

当计算 `dp[j]` 时，需要的是上一行的：

$$
dp[j-1]
$$

但如果 `j-1` 已经在当前行被更新过，那么拿到的就是“本行新值”，状态被污染。

因此必须从右往左：

```text
m -> m-1 -> ... -> 1
```

这样计算 `dp[j]` 时，`dp[j-1]` 仍然保存的是上一行值。

原题滚动数组示意：

![718. 最长重复子数组滚动数组示意](https://file1.kamacoder.com/i/algo/2021011215282060-20230310134554486.jpg)

<Callout type="warning" title="不相等时一定要清零">
如果 `nums1[i-1] != nums2[j-1]`，必须执行 `dp[j] = 0`。因为状态表示“以当前位置同时结尾的连续匹配长度”，连续关系一旦断开，旧值绝不能保留。
</Callout>

## 11. 一维滚动数组写法

```cpp
class Solution {
public:
    int findLength(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        int m = nums2.size();

        vector<int> dp(m + 1, 0);
        int ans = 0;

        for (int i = 1; i <= n; ++i) {
            for (int j = m; j >= 1; --j) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                } else {
                    dp[j] = 0;
                }
                ans = max(ans, dp[j]);
            }
        }

        return ans;
    }
};
```

复杂度：

$$
\text{时间复杂度}=O(nm)
$$

$$
\text{空间复杂度}=O(m)
$$

如果希望进一步减少常数空间，可以让较短的数组作为 `dp` 维度，使空间复杂度变成：

$$
O(\min(n,m))
$$

## 12. 和最长公共子序列的根本区别

这两道题非常容易混淆。

### 最长重复子数组

要求连续。

如果当前位置相等：

$$
dp[i][j]=dp[i-1][j-1]+1
$$

如果不相等：

$$
dp[i][j]=0
$$

### 最长公共子序列

允许跳过元素。

当当前位置不相等时，仍可以继承：

$$
\max(dp[i-1][j],dp[i][j-1])
$$

因此两者最核心的区别是：

$$
\boxed{
\text{连续问题断开后归零；子序列问题可以跳过并继承历史最优}
}
$$

## 13. 为什么状态定义一定要强调“结尾”

假设我们只定义：

> `dp[i][j]` 表示前 `i` 和前 `j` 个元素中的最长公共连续子数组长度。

那么这个状态只告诉你历史最大值，却不知道这个最长片段是否恰好延伸到当前位置。

而连续问题要判断“还能不能继续接”，必须知道：

> 上一个公共片段是不是刚好以 `i-1`、`j-1` 结束。

所以“以某位置结尾”是连续子数组 DP 中的核心状态设计方式。

## 14. 高频错误

### 错误一：不相等时不清零

错误写法：

```cpp
if (nums1[i - 1] == nums2[j - 1]) {
    dp[j] = dp[j - 1] + 1;
}
```

如果不相等时什么都不做，旧状态会被错误保留，等价于允许跨过不匹配位置。

正确逻辑：

```cpp
else {
    dp[j] = 0;
}
```

### 错误二：一维优化仍然正序遍历

正序会让：

$$
\text{上一行状态}\rightarrow\text{本行状态}
$$

发生覆盖。

所以必须倒序。

### 错误三：把转移写成上方或左方最大值

如果出现：

```cpp
max(dp[i - 1][j], dp[i][j - 1])
```

你实际上已经在写最长公共子序列，而不是最长重复子数组。

## 15. 一个更统一的理解

本题和上一题“最长连续递增序列”有共同结构：

- 都要求连续；
- 当前状态只能由“紧邻的前一个合法状态”继续延伸；
- 一旦条件不满足，连续长度立刻清零或重置。

一维 LCIS 中是：

$$
i-1\rightarrow i
$$

二维最长重复子数组中是：

$$
(i-1,j-1)\rightarrow(i,j)
$$

这就是“连续型 DP”的共同特征。

## 16. 记忆模板

遇到两个序列的“最长公共连续片段”问题，可以优先套：

$$
\boxed{
\text{相等：左上角}+1
}
$$

$$
\boxed{
\text{不等：归零}
}
$$

并在所有状态中取最大值。

class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int[] dp = new int[nums2.length + 1];
        int ans = 0;

        for (int i = 1; i <= nums1.length; i++) {
            for (int j = nums2.length; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;

                    dp[j] = 0;
                }
                ans = Math.max(ans, dp[j]);
            }
        }

        return ans;
    }
}
