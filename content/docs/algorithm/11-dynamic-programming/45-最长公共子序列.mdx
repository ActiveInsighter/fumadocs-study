# 1143. 最长公共子序列

[LeetCode 1143：最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)

给定两个字符串 `text1` 和 `text2`，返回它们的**最长公共子序列**长度。

所谓子序列，是指可以从原字符串中删除若干字符，但**不能改变剩余字符的相对顺序**。

例如：

```text
text1 = "abcde"
text2 = "ace"
```

公共子序列 `"ace"` 的长度为 $3$，因此答案是：

$$
\boxed{3}
$$

<Callout type="warning" title="子序列不要求连续，但顺序不能改变">
`"ace"` 是 `"abcde"` 的子序列；`"aec"` 不是，因为字符的相对顺序发生了改变。这个“可以跳过、不能换序”的约束，正是本题状态转移的核心。
</Callout>

## 1. 本题和最长重复子数组到底差在哪里

上一题“最长重复子数组”要求公共部分**连续**，因此状态通常定义为：

> 以两个当前位置同时结尾的最长公共连续片段长度。

一旦当前元素不相等，连续关系立刻中断：

$$
dp[i][j]=0
$$

但最长公共子序列允许跳过字符。

例如：

```text
text1 = a b c d e
text2 = a   c   e
```

虽然 `a`、`c`、`e` 在 `text1` 中并不连续，但仍然构成合法公共子序列。

因此本题在字符不相等时，不能简单归零，而要考虑：

- 放弃 `text1` 当前字符；
- 或放弃 `text2` 当前字符。

这正是 LCS 与“公共连续子数组”最本质的区别。

## 2. 状态定义

设：

$$
\boxed{
dp[i][j]
=
text1[0\ldots i-1]\text{ 与 }text2[0\ldots j-1]\text{ 的最长公共子序列长度}
}
$$

也就是说：

- `i` 表示考虑 `text1` 的前 $i$ 个字符；
- `j` 表示考虑 `text2` 的前 $j$ 个字符。

为什么不直接定义到 `text1[i]` 和 `text2[j]`？

因为多留出第 $0$ 行、第 $0$ 列后，空字符串边界可以统一处理：

$$
dp[0][j]=0,\qquad dp[i][0]=0
$$

整个状态表尺寸就是：

$$
(n+1)\times(m+1)
$$

其中 $n=|text1|$，$m=|text2|$。

## 3. 状态转移：当前两个字符相等

如果：

$$
text1[i-1]=text2[j-1]
$$

那么当前两个字符可以共同接到之前的公共子序列末尾。

之前对应的是两个前缀都缩短一个字符：

$$
text1[0\ldots i-2]
$$

与：

$$
text2[0\ldots j-2]
$$

所以：

$$
\boxed{
dp[i][j]=dp[i-1][j-1]+1
}
$$

这表示：

> 既然两个当前字符相同，就把它们作为一对新的匹配字符接到已有 LCS 后面。

## 4. 状态转移：当前两个字符不相等

如果：

$$
text1[i-1]\ne text2[j-1]
$$

那么这两个字符不可能同时作为同一个公共子序列的末尾匹配字符。

但最优答案仍可能存在于两个更小的前缀问题中。

### 情况一：不使用 `text1[i - 1]`

那么答案来自：

$$
dp[i-1][j]
$$

### 情况二：不使用 `text2[j - 1]`

那么答案来自：

$$
dp[i][j-1]
$$

取二者最大值：

$$
\boxed{
dp[i][j]=\max(dp[i-1][j],\ dp[i][j-1])
}
$$

于是完整状态转移为：

$$
\boxed{
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+1, & text1[i-1]=text2[j-1] \\
\max(dp[i-1][j],dp[i][j-1]), & text1[i-1]\ne text2[j-1]
\end{cases}
}
$$

<Callout type="info" title="为什么字符相等时不需要再和上方、左方取最大值">
在经典 LCS 定义下，当 `text1[i-1] == text2[j-1]` 时，总能存在一个最优公共子序列包含这对相同字符，因此直接使用 `dp[i-1][j-1] + 1` 即可。即使某个最优解不使用它们，也不会得到更大的长度。
</Callout>

## 5. 从二维表理解三个依赖方向

状态 `dp[i][j]` 可能依赖：

- 左上：`dp[i - 1][j - 1]`；
- 上方：`dp[i - 1][j]`；
- 左方：`dp[i][j - 1]`。

原题依赖方向示意：

![最长公共子序列的状态转移方向](https://file1.kamacoder.com/i/algo/20210204115139616.jpg)

因此只要按照：

```text
从上到下
从左到右
```

填表，就能保证所依赖的状态已经计算完成。

## 6. 初始化为什么全部为 0

空字符串和任何字符串都没有非空公共子序列，因此：

$$
\boxed{dp[0][j]=0}
$$

$$
\boxed{dp[i][0]=0}
$$

其他位置最终都会被状态转移覆盖，所以直接把整个数组初始化为 $0$ 最方便。

## 7. 示例推导

考虑：

```text
text1 = "abcde"
text2 = "ace"
```

原题 DP 表如下：

![abcde 与 ace 的最长公共子序列 DP 表](https://file1.kamacoder.com/i/algo/20210210150215918.jpg)

沿着状态表观察：

- `a == a`，长度从 $0$ 变成 $1$；
- `c == c`，在前一个公共序列后接上 `c`，得到 $2$；
- `e == e`，继续得到 $3$。

最终：

$$
dp[5][3]=3
$$

因为本题的状态定义本身就是“两个完整前缀的最优值”，所以答案直接是右下角：

$$
\boxed{dp[n][m]}
$$

这和“最长重复子数组”不同：后者的状态是“以当前位置结尾”，所以需要在所有状态中取最大值。

## 8. 二维 DP 标准代码

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.size();
        int m = text2.size();

        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n][m];
    }
};
```

复杂度：

$$
\text{时间复杂度}=O(nm)
$$

$$
\text{空间复杂度}=O(nm)
$$

## 9. 一维空间压缩

二维转移为：

$$
dp[i][j]
\leftarrow
\begin{cases}
dp[i-1][j-1] \\
dp[i-1][j] \\
dp[i][j-1]
\end{cases}
$$

如果只保留一维数组：

```text
dp[j]
```

那么在更新当前行时：

- 更新前的 `dp[j]` 是旧的 `dp[i - 1][j]`；
- 更新后的 `dp[j - 1]` 是新的 `dp[i][j - 1]`；
- 还需要额外保存旧的 `dp[i - 1][j - 1]`。

因此用变量 `prev` 保存左上角。

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.size();
        int m = text2.size();

        vector<int> dp(m + 1, 0);

        for (int i = 1; i <= n; ++i) {
            int prev = 0;

            for (int j = 1; j <= m; ++j) {
                int oldDpJ = dp[j];

                if (text1[i - 1] == text2[j - 1]) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }

                prev = oldDpJ;
            }
        }

        return dp[m];
    }
};
```

空间复杂度降为：

$$
O(m)
$$

如果希望进一步减少空间，可以让较短字符串作为第二维，使复杂度变成：

$$
O(\min(n,m))
$$

<Callout type="warning" title="一维压缩不能直接写 dp[j - 1] + 1">
当从左向右遍历时，`dp[j - 1]` 已经被更新成当前行的 `dp[i][j - 1]`，不再是旧的 `dp[i - 1][j - 1]`。所以必须额外保存左上角旧值。
</Callout>

## 10. 如何恢复一个具体的最长公共子序列

如果题目不仅要求长度，还要求输出某个具体 LCS，就可以保留二维 `dp` 表并从右下角反向回溯。

设当前位置为 `(i, j)`：

### 当前字符相等

如果：

$$
text1[i-1]=text2[j-1]
$$

那么这个字符可以加入答案，并移动到：

$$
(i-1,j-1)
$$

### 当前字符不相等

比较：

$$
dp[i-1][j]
$$

和：

$$
dp[i][j-1]
$$

向值更大的方向移动。

回溯得到的字符顺序是反的，最后再翻转即可。

<Callout type="info" title="LCS 可能不唯一">
如果 `dp[i-1][j] == dp[i][j-1]`，两条方向都可能导向长度相同的最优解。因此最长公共子序列的长度唯一，但具体字符串不一定唯一。
</Callout>

## 11. 与最长重复子数组的统一对比

| 对比项 | 最长重复子数组 | 最长公共子序列 |
| --- | --- | --- |
| 是否要求连续 | 是 | 否 |
| 状态核心 | 以当前位置同时结尾 | 两个前缀的最优解 |
| 相等时 | `左上 + 1` | `左上 + 1` |
| 不等时 | 归零 | `max(上, 左)` |
| 最终答案 | 所有状态最大值 | `dp[n][m]` |

真正需要记住的不是两条公式，而是：

> **连续问题不允许“跳过”，子序列问题允许通过舍弃当前元素保留历史最优解。**

## 12. 常见错误

### 错误一：字符不相等就置零

这是最长公共**子数组**的写法，不是最长公共**子序列**。

LCS 在字符不相等时应当保留：

$$
\max(dp[i-1][j],dp[i][j-1])
$$

### 错误二：状态定义和下标错一位

如果定义的是“前 $i$ 个字符”，实际访问字符时应使用：

```cpp
text1[i - 1]
```

而不是：

```cpp
text1[i]
```

### 错误三：一维压缩丢失左上角

`dp[j - 1]` 在当前行已经更新，所以必须用额外变量保存旧的左上角。

### 错误四：把子串和子序列混淆

- **子串 / 子数组**：连续；
- **子序列**：不要求连续，但保持相对顺序。

这是字符串 DP 中最重要的一组概念区分。

## 13. 方法总结

遇到两个序列的“最大公共匹配”问题时，可以优先思考：

1. 状态是否应该描述两个前缀；
2. 当前两个元素相等时，是否能从左上角扩展；
3. 当前两个元素不等时，是否允许舍弃其中一个元素；
4. 如果允许，就很可能出现：

$$
\max(dp[i-1][j],dp[i][j-1])
$$

这套结构不仅用于字符串，也可以用于整数数组、几何连线等看起来完全不同的问题。

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int n = text1.length();
        int m = text2.length();
        int[][] dp = new int[n + 1][m + 1];

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n][m];
    }
}

```go tab="Go"
func longestCommonSubsequence(text1 string, text2 string) int {
    n, m := len(text1), len(text2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1)
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if text1[i-1] == text2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else if dp[i-1][j] > dp[i][j-1] {
                dp[i][j] = dp[i-1][j]
            } else {
                dp[i][j] = dp[i][j-1]
            }
        }
    }

    return dp[n][m]
}
```

impl Solution {
    pub fn longest_common_subsequence(text1: String, text2: String) -> i32 {
        let a = text1.as_bytes();
        let b = text2.as_bytes();
        let n = a.len();
        let m = b.len();
        let mut dp = vec![vec![0i32; m + 1]; n + 1];

        for i in 1..=n {
            for j in 1..=m {
                if a[i - 1] == b[j - 1] {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = dp[i - 1][j].max(dp[i][j - 1]);
                }
            }
        }

        dp[n][m]
    }
}
