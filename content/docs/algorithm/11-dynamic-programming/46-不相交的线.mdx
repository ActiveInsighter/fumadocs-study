# 1035. 不相交的线

[LeetCode 1035：不相交的线](https://leetcode.cn/problems/uncrossed-lines/)

给定两个整数数组 `nums1` 和 `nums2`，分别按顺序写在两条水平线上。

可以连接满足：

$$
nums1[i]=nums2[j]
$$

的两个位置，但要求所有连线之间**不能相交**，并且每个位置最多参与一条连线。

求最多可以画多少条线。

原题示意图：

![1035. 不相交的线](https://file1.kamacoder.com/i/algo/2021032116363533.png)

这道题表面上是一个几何连线问题，实际上是非常典型的**最长公共子序列（LCS）模型**。

## 1. 最关键的观察：不相交意味着相对顺序一致

假设在 `nums1` 中选择了两个位置：

$$
i_1<i_2
$$

如果对应到 `nums2` 中的位置是：

$$
j_1>j_2
$$

那么两条连线必然发生交叉。

因此，只要连线不相交，就必须满足：

$$
\boxed{
i_1<i_2\Longrightarrow j_1<j_2
}
$$

也就是说，所有被匹配的数字在两个数组中的**相对顺序必须一致**。

而这恰好就是“公共子序列”的定义。

<Callout type="info" title="从几何约束到序列约束">
“不相交”并不是一个真正需要几何算法处理的条件。它实际上是在强制两个数组的匹配下标同时递增，因此问题本质变成：找尽可能长的一组值相同、相对顺序一致的匹配。
</Callout>

## 2. 用例理解为什么会相交

考虑：

```text
nums1 = [1, 4, 2]
nums2 = [1, 2, 4]
```

如果先连接：

```text
nums1[1] = 4
nums2[2] = 4
```

又希望连接：

```text
nums1[2] = 2
nums2[1] = 2
```

在 `nums1` 中：

$$
1<2
$$

但在 `nums2` 中：

$$
2>1
$$

次序反转，因此两条线相交。

原题中的相交示意：

![不相交连线与顺序关系](https://file1.kamacoder.com/i/algo/20210914145158.png)

所以合法匹配只能保持同样的相对顺序，例如：

```text
[1, 4]
```

或：

```text
[1, 2]
```

最大长度都是 $2$。

## 3. 严格归约为最长公共子序列

我们可以从两个方向理解这个等价关系。

### 方向一：任意一组不相交连线都对应公共子序列

设连线连接了：

$$
(i_1,j_1),(i_2,j_2),\ldots,(i_k,j_k)
$$

因为线不相交，所以可以按照 `nums1` 下标排序后得到：

$$
i_1<i_2<\cdots<i_k
$$

同时必然有：

$$
j_1<j_2<\cdots<j_k
$$

而每一条线又要求：

$$
nums1[i_t]=nums2[j_t]
$$

因此这些值组成两个数组的一个公共子序列，长度为 $k$。

### 方向二：任意公共子序列都能画成不相交连线

如果两个数组存在长度为 $k$ 的公共子序列，那么对应下标天然满足：

$$
i_1<i_2<\cdots<i_k
$$

和：

$$
j_1<j_2<\cdots<j_k
$$

按照这些位置逐对连接，线段不会交叉。

所以：

$$
\boxed{
\text{最大不相交连线数}=\text{LCS}(nums1,nums2)
}
$$

这一步完成后，题目就完全转化为上一节的最长公共子序列问题。

## 4. 状态定义

定义：

$$
\boxed{
dp[i][j]
=
nums1\text{ 前 }i\text{ 个元素与 }nums2\text{ 前 }j\text{ 个元素最多能画的线数}
}
$$

等价地，它就是两个前缀的最长公共子序列长度。

由于使用“前 $i$ 个元素”定义，所以当前比较元素是：

```text
nums1[i - 1]
nums2[j - 1]
```

## 5. 状态转移

### 当前两个元素相同

如果：

$$
nums1[i-1]=nums2[j-1]
$$

可以把它们连接起来，并接在前面已经完成的最优匹配后面：

$$
\boxed{
dp[i][j]=dp[i-1][j-1]+1
}
$$

### 当前两个元素不同

如果：

$$
nums1[i-1]\ne nums2[j-1]
$$

当前这两个位置无法彼此连线。

最优方案只能至少舍弃其中一个：

- 不考虑 `nums1[i - 1]`：`dp[i - 1][j]`；
- 不考虑 `nums2[j - 1]`：`dp[i][j - 1]`。

因此：

$$
\boxed{
dp[i][j]=\max(dp[i-1][j],dp[i][j-1])
}
$$

完整转移式：

$$
\boxed{
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+1, & nums1[i-1]=nums2[j-1] \\
\max(dp[i-1][j],dp[i][j-1]), & nums1[i-1]\ne nums2[j-1]
\end{cases}
}
$$

## 6. 初始化与遍历顺序

当任一数组前缀为空时，不可能连线：

$$
dp[0][j]=0
$$

$$
dp[i][0]=0
$$

每个状态只依赖：

- 左上；
- 上方；
- 左方。

因此按照二维表从上到下、从左到右计算即可。

## 7. 二维 DP 标准代码

```cpp
class Solution {
public:
    int maxUncrossedLines(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        int m = nums2.size();

        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n][m];
    }
};
```

复杂度：

$$
\text{时间复杂度}=O(nm)
$$

$$
\text{空间复杂度}=O(nm)
$$

## 8. 一维空间压缩

与 LCS 完全相同，可以只保存一行。

关键是额外保存旧的左上角状态：

```cpp
class Solution {
public:
    int maxUncrossedLines(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        int m = nums2.size();

        vector<int> dp(m + 1, 0);

        for (int i = 1; i <= n; ++i) {
            int prev = 0;

            for (int j = 1; j <= m; ++j) {
                int oldDpJ = dp[j];

                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }

                prev = oldDpJ;
            }
        }

        return dp[m];
    }
};
```

空间复杂度：

$$
O(m)
$$

若始终让较短数组作为第二维，可以进一步写成：

$$
O(\min(n,m))
$$

## 9. 为什么不能使用贪心“看到相同就连”

考虑：

```text
nums1 = [1, 3, 2, 4]
nums2 = [1, 2, 3, 4]
```

如果在局部遇到相同元素就立即决定连线，很容易因为选择了某个位置而阻塞后续更优匹配。

本题的核心困难在于：

> 一条线的选择会影响后续所有位置能否保持相对顺序。

这种“当前选择影响后续可行状态”的结构非常适合用 DP 记录两个前缀的最优答案。

## 10. 这类题最重要的识别信号

以后看到类似描述：

- 两个序列；
- 只有值相同时才能匹配；
- 每个位置只能匹配一次；
- 匹配关系不能交叉；
- 要求最大匹配数量；

应立刻尝试把“不交叉”翻译成：

$$
\boxed{\text{匹配下标必须保持相同相对顺序}}
$$

然后判断是否就是 LCS。

<Callout type="success" title="重要建模能力">
动态规划题经常不会直接告诉你“求最长公共子序列”。真正重要的是把题目的业务描述、几何描述或操作描述转换成一个熟悉的状态模型。本题就是非常典型的“披着连线外衣的 LCS”。
</Callout>

## 11. 与几种相似问题的区别

| 问题 | 是否保序 | 是否连续 | 常见状态 |
| --- | --- | --- | --- |
| 最长重复子数组 | 是 | 是 | 同时以当前位置结尾 |
| 最长公共子序列 | 是 | 否 | 两个前缀的最优值 |
| 不相交的线 | 是 | 否 | 本质就是 LCS |
| 普通二分图最大匹配 | 通常不要求 | 不适用 | 图匹配算法 |

这里尤其容易误判成“二分图匹配”。

普通二分图最大匹配允许任意交叉关系，而本题额外要求**匹配顺序单调**，这正是 LCS 的结构。

## 12. 方法总结

本题可以浓缩成三步：

### 第一步：把“不相交”转化为下标关系

$$
i_1<i_2\Longrightarrow j_1<j_2
$$

### 第二步：发现匹配值必须相同

$$
nums1[i_t]=nums2[j_t]
$$

### 第三步：得到公共子序列

于是：

$$
\boxed{
\text{最大不相交连线数}=\text{最长公共子序列长度}
}
$$

真正值得掌握的不是把上一题代码复制过来，而是理解**为什么两个看似不同的问题拥有完全相同的状态空间和转移关系**。

```java tab="Java"
class Solution {
    public int maxUncrossedLines(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int m = nums2.length;
        int[][] dp = new int[n + 1][m + 1];

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n][m];
    }
}
```

```go tab="Go"
func maxUncrossedLines(nums1 []int, nums2 []int) int {
    n, m := len(nums1), len(nums2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1)
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if nums1[i-1] == nums2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else if dp[i-1][j] > dp[i][j-1] {
                dp[i][j] = dp[i-1][j]
            } else {
                dp[i][j] = dp[i][j-1]
            }
        }
    }

    return dp[n][m]
}
```
