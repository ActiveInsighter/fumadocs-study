## 一、使用方法

1. **先学逻辑词**：优先识别转折、因果、让步、条件等关系，掌握句间意义走向。
2. **重点辨析易混词**：对比词性、语义轻重、感情色彩和搭配，而不是只看是否眼熟。
3. **背动词短语与实词**：把动词、介词和常见宾语一起记忆，如 `take into account`。
4. **最后回顾熟词僻义**：尤其是 `address`、`subject`、`account for`、`yield` 等语境意义。

建议每天复习约 25～30 个新词或短语，并在第 2 天、第 7 天、第 14 天快速回顾；先看中文释义，再用真题语境巩固。

## 二、完形填空解题方法

**判断顺序：语法结构 → 语义逻辑 → 搭配习惯 → 代入复核。** 一个选项必须同时符合所在句子的语法、上下文意思和表达习惯。

<Steps>

  <Step>

  ### 通读文章，确定主题

  结合首段及上下文判断文章讨论的主题、态度和时间线；不要预设所有空格都属于同一种题型。

  </Step>

  <Step>

  ### 看空格位置，限定词性与句法

  先判断空格需要谓语、名词、修饰语还是连接成分，注意主谓一致、时态、介词及固定搭配。

  </Step>

  <Step>

  ### 比较选项，寻找上下文证据

  利用同义复现、转折、因果、并列、指代等线索排除不合语境的答案。

  </Step>

  <Step>

  ### 代入全文，检查连贯性

  优先选择最准确、最自然的表达；“词义更宽泛”“看起来更简单”不能单独作为正确理由。

  </Step>

</Steps>

<Callout type="warn" title="不要机械套用经验口诀">

“没有转折词就是顺承”“抽象词更可能正确”“选项范围越大越好”等说法都不是普遍规则。**隐含对比、否定、语篇态度和固定搭配**也会改变答案方向。

</Callout>

## 三、逻辑信号词

信号词提示上下句的**关系**，但不能跳过语境。下面按主要功能整理；部分词（如 `while`、`since`、`as`）具有多种用法。

### 转折关系（前后相反）
转折通常标志观点、评价或叙述方向改变；`however` 常连接句子，`but` 常连接分句。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★★ | **however** | adv. 然而；不过；无论如何 |
| ★ | **but** | conj. 但是；而；prep. 除了 |
| ★ | **yet** | adv.还没有；现在；早晚；又 conj.但是；然而 |
| ★★ | **whereas** | conj.然而；鉴于 |
| — | **nevertheless** | adv.尽管如此；不过；然而 |
| — | **nonetheless** | adv. 尽管如此；然而 |
| — | **in contrast** | 相比之下；相反 |
| — | **on the contrary** | 恰恰相反；正相反 |

### 让步关系（虽然…但是）
`although / though / even though` 引导让步；`despite / in spite of` 后接名词、代词或动名词。标准书面语中不要把 `although ... but ...` 当作固定搭配。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★ | **although** | conj.虽然；不过 |
| ★★★ | **though** | conj.虽然；不过 adv.不过 |
| — | **even if** | 即使；纵然 |
| — | **even though** | 即使；尽管 |
| ★★★ | **while** | conj. 当……时；而；尽管；n. 一段时间 |
| ★ | **despite** | prep. 尽管；不管 |
| — | **in spite of** | 尽管；不顾 |

### 因果关系（因为…所以）
`because / since / as / for` 可以引出原因；`therefore / thus / hence / consequently` 更常引出结果。`so that` 多表示目的，也可表示结果。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★ | **because** | conj. 因为；由于 |
| ★★★ | **since** | prep.从……以来 conj.自……以来；因为 |
| — | **as** | conj. 因为；由于；随着；当……时 |
| — | **for** | conj. 因为（较正式，常用于补充理由） |
| ★★★ | **therefore** | adv.因此；所以 |
| ★★ | **thus** | adv.以此方式；因此 |
| ★ | **hence** | adv.因此；由此 |
| — | **so** | conj./adv. 因此；所以；这样 |
| — | **as a result** | 结果；因此 |
| — | **consequently** | adv.因此；所以 |
| — | **in that** | conj. 因为；由于 |
| — | **so that** | 以便；为了（目的）；结果是（结果） |

### 并列关系（A 和 B 并列）
并列强调信息同向或平行；`meanwhile` 也可能表现对照，要结合前后句判断。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| — | **and** | conj. 和；并且 |
| ★ | **likewise** | adv.同样地；也；而且 |
| — | **similarly** | adv. 同样地；类似地 |
| ★ | **meanwhile** | adv.同时；对比之下 |
| — | **as well as** | 和；也；不仅……而且 |
| ★★ | **also** | adv.而且；也 |

### 递进关系（不但…而且）
在原有内容上补充、强化或解释。`in fact` 常用于进一步强调或纠正前面的说法。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| — | **in fact** | 事实上；实际上（强调、解释或纠正，未必表示转折） |
| ★★ | **moreover** | adv.此外；而且 |
| ★ | **furthermore** | adv.此外；而且 |
| ★★ | **indeed** | adv.确实；其实 |
| ★★ | **besides** | prep.除……之外 adv.再说；此外 |
| — | **in addition** | 另外；此外 |

### 条件关系（如果…就）
`unless` 约等于“如果不 / 除非”；`provided (that)` 表示条件，`in case` 常带有预防意味；`otherwise / or else` 引出不满足条件时的结果。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★ | **otherwise** | adv.否则；除此之外 |
| — | **or else** | 否则；要不然 |
| ★★★ | **if** | conj.如果；当；是否 |
| ★★★ | **unless** | conj.除非；如果不 |
| — | **as long as** | 只要 |
| — | **so long as** | 只要 |
| — | **provided** | conj.如果；假如 |
| — | **in case** | conj. 万一；假使；以防 |

### 举例关系（比如）
后面通常是前文观点的具体例证；`such as` 常用于列举名词性例子。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| — | **for example** | 例如；比如 |
| — | **for instance** | 例如；比如 |
| — | **such as** | 例如；诸如 |

### 对比关系（与…不同）
对照是“差异比较”，不一定构成完全相反的观点。`instead of` 后接名词、代词或动名词，表示“而不是”。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★ | **instead of** | 代替；而不是 |
| — | **rather than** | 而不是；与其……不如 |
| — | **contrary to** | 与……相反；不同于 |
| ★ | **unlike** | prep.不像；与……不同 adj.不同；相异 |
| — | **in contrast to** | 与……相比；与……相反 |

### 时间关系（当…时）
同一个时间词也可能表示条件或让步：如 `once` 可表示“一旦”。

| 原稿标记 | 单词 / 短语 | 词性与常用含义 |
| :---: | :--- | :--- |
| ★★★ | **when** | adv.&pron.什么时候 conj.在……时候；刚……就 |
| ★★★ | **until** | conj./prep.直到……为止 |
| ★★ | **before** | prep.在……以前 conj.在……以前 |
| — | **after** | prep.在……以后 conj.在……以后 adv.后来 |
| ★★★ | **once** | adv.一次；曾经 conj.一旦 |
| — | **whenever** | conj.无论何时，随时；每当 |

### 容易混淆的逻辑词

<Accordions>

  <Accordion title="since / as / while：一个词，多个逻辑功能">

  - `since`：可以表示“自从”（时间）或“既然 / 因为”（原因）。
  - `as`：可以表示“当……时 / 随着”（时间）或“因为”（原因），也可能表达“按照……方式”。
  - `while`：可以表示“当……时”（时间）、“虽然”（让步）或“然而”（对比）。

  **判断依据：**&#x2060;看前后分句的时态、语义是否相反，以及作者是否在解释原因。

  </Accordion>
  <Accordion title="however / therefore / moreover：逻辑方向不同">

  - `however`：转折或对比——“然而”。
  - `therefore`：得出结论——“因此”。
  - `moreover`：补充并加强——“此外，而且”。

  这些词不能只因为都是句首副词而相互替换。

  </Accordion>
  <Accordion title="unless / only if / even if：条件强弱与含义不同">

  - `unless`：除非；如果不。
  - `only if`：只有……才……，表示必要条件。
  - `even if`：即使……也……，强调不受条件影响。

  </Accordion>

</Accordions>

## 四、传统“红花 / 绿叶”词表

原稿将部分选项分成“红花词”（经验上倾向考虑）与“绿叶词”（经验上倾向排除）。这只是**不同备考讲义的历史分类**，并不代表单词本身天然“该选”或“不该选”。

<Callout type="warn" title="不要把红花、绿叶当作押题概率">

原始资料中甚至有同一词在不同名单出现的情况（例如 `since`、`until`、`instead of`）。本版保留两类名单便于对照，但移除“必选率最高”“95% 不选”等缺乏逐题统计支持的结论。**真正的选择依据永远是语法、语义和上下文。**

</Callout>
