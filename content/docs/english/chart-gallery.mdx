所有图表都基于 shadcn/ui 的 `ChartContainer` 与 Recharts 3 构建，并共享同一套设计 token（`styles/tokens/charts.css`）。作者只写**数据**和少量语义参数，颜色、标记规格、动效、图例开关、提示框、导出和数据表都由组件统一提供。

每个示例右上角都可以切换 **预览 / 代码**；图表右上角的工具按钮可以切换为数据表，或下载 SVG、PNG、CSV。

## 性能 vs 成本

这是最核心的场景：横轴是**对数刻度**的成本，纵轴是得分，每条曲线是同一模型在不同努力档位（low → max）下的运行点。档位标签会按像素空间自动避让，避免与点、线以及其他标签重叠。当数据离零较远时，Y 轴会自动加上断轴标记，并保留零基线。

## 状态与降级

```mdx preview title="空数据：保留高度，不跳动"
<StudyBarChart
  title="本周暂无记录"
  data={[]}
  xKey="day"
  series={[{ key: "count", label: "题数" }]}
  emptyMessage="本周还没有打卡记录"
  height={200}
/>
```

- **加载 / 水合**：服务端会输出标题、说明和一份屏幕阅读器可读的数据表；图形区域预留固定高度，在第一次进入视口时才挂载，所以入场动效能被看到，也不会造成布局偏移。
- **渲染出错**：错误边界只替换当前图表，并提供“改为查看数据表”，不会影响整页。
- **减少动态效果**：`prefers-reduced-motion` 或省流模式下关闭所有补间，直接显示最终状态。
- **打印 / 强制配色**：`pattern: "dots" | "hatch"` 提供纹理通道；强制配色模式下图例描边改用系统色。

## 设计 token

| Token | 作用 |
| --- | --- |
| `--chart-1` … `--chart-8` | 分类色，固定顺序；第 9 个系列使用 `--chart-other`，不会生成新颜色 |
| `--chart-seq-1` … `--chart-seq-6` | 单色相顺序色阶（树图按数值着色、漏斗图） |
| `--chart-editorial-*` | editorial 主题的纸感柔色填充，配合墨色描边 |
| `--chart-ink` / `--chart-muted` / `--chart-grid` / `--chart-axis` | 图表内的文字、网格和轴线层级 |
| `--chart-tooltip-*` | 墨色提示框 |
| `--chart-font-*` | 标题 16px、刻度 12px、点标签 11.5px 等字号层级 |
| `--chart-line-width` / `--chart-mark-radius` / `--chart-bar-radius` | 线宽 2px（tradeoff 图为 3px）、点半径、柱的数据端圆角 |
| `--chart-draw` / `--chart-fade` / `--chart-ease` | 线条绘制时长、淡入时长、ease-out-quart 缓动 |

分类色板已用 dataviz 校验脚本在浅色（#fff）和深色（#000）两个表面上分别检查：亮度区间、色度下限、相邻色对的色觉差异 ΔE ≥ 8、正常视觉 ΔE ≥ 15，以及 ≥ 3:1 的对比度。前 3 个颜色还通过了“所有色对”检查。深色模式是单独选定的一组色阶，不是简单反色。

## 交互与无障碍约定

- **图例**：多于一个系列时显示，点击可隐藏 / 显示系列，按钮带 `aria-pressed`，最后一个可见系列无法隐藏。
- **提示框**：折线和面积图为十字准线加全系列数值，柱、点、扇区按单个标记显示；堆叠图额外给出合计。提示框跟随指针，不做位移补间。
- **键盘**：Recharts 的 `accessibilityLayer` 支持方向键遍历类别；tradeoff 图的每个点都可以用 Tab 聚焦，← → 在同一系列内移动，↑ ↓ 切换系列，Esc 关闭提示框。
- **触摸**：点击标记即显示提示框；tradeoff 图的命中区域半径至少 14px。
- **语义**：`figure` 加 `figcaption`；`summary` 属性会作为一句结论朗读给屏幕阅读器；每张图都附带一份 `sr-only` 数据表，切换后即为可见的表格。
- **导出**：SVG 会把计算后的颜色（包括 `var()`、`oklch()`、`color-mix()`）内联为 rgb，并重绘标题、图例和脚注；PNG 为 2× 位图；CSV 带 BOM，方便表格软件识别中文。导出文件不嵌入网页字体，会回退到系统无衬线字体。

## 写给 AI 的用法约定

1. 只传数据和语义参数：`data`、`xKey`、`series`、`format`。不要手写颜色，除非某个系列需要和别处保持同色（可写 `color: "2"`）。
2. `format` 可用的预设有 `number`、`integer`、`compact`、`percent`（数值已是百分数）、`ratio`（0–1 小数）、`usd`、`cny`、`multiplier`、`minutes`，也可以写成 `{ suffix: " 分", digits: 0 }`。
3. 比较不同成本档位时用 `StudyTradeoffChart`，横轴默认就是对数刻度；同一主题有多组基准时，用 `StudyChartSwitcher` 包起来。
4. 写一句 `summary`，概括这张图的结论；脚注写数据来源和误差说明。
5. 分类超过 8 个时先合并为“其他”，或者拆成多张小图，不要追加颜色。
