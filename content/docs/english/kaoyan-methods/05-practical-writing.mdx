原书从第 79 页进入**写作 A 节——应用文写作**。本部分涉及的考试说明出自**2025 版英语（一）考试大纲**；它反映原书当时引用的规则，备考其他年度须对照正式大纲与当年试卷要求。

| 所在部分 | Section III, Part A |

### 70.1 评分维度不能只理解成“词汇越难越高分”

<Cards>
<Card title="内容完整">
    覆盖题目要求的所有事项，先完成交际任务，再考虑文采。
</Card>
<Card title="语言准确">
    时态、搭配、冠词、单复数、拼写、标点等基本错误尽量避免。
</Card>
<Card title="结构清楚">
    写作目的清晰，正文分段合理，句间衔接自然。
</Card>
<Card title="格式与语体得当">
    按对象与用途选择称呼、结尾和语气；正式公告与私人感谢信不能用同一套表达。
</Card>
</Cards>

**原书列出的五项考查要求，可以压缩为五个可操作问题：**

1. **切题吗？** 要求邀请、致歉、建议信还是告知？题目规定的所有要点都出现了吗？
2. **语言够用吗？** 词汇和句式能否准确传达所需信息？适度变化即可，不为“炫技”牺牲准确性。
3. **有基础错误吗？** 检查单复数、第三人称、时态、主谓一致、冠词和拼写。
4. **读者能顺畅理解吗？** 开头点明目的，正文按任务排序，结尾有明确的结束或行动提示。
5. **身份与语气合适吗？** 写给同学可以亲切；写给学校或机构应更正式、礼貌、具体。

<Callout type="warn" title="写作优先级：任务完成度高于辞藻复杂度">

原书提醒关注丰富词汇与句式，但“使用高级词”不是脱离语境的独立目标。对一篇约 100 词的应用文，**覆盖题意、避免信息遗漏和使用自然准确的表达**，通常比堆砌长难句更稳妥。

</Callout>

### 70.2 应用文构思：一张三段式提纲

<Steps>
<Step>

### 第一段：交代写作目的

直接说明 `I am writing to ...`（我写信是为了……）或者在公告中直接写明事项。开头不必冗长铺垫。

</Step>
<Step>

### 第二段：逐项完成任务

按照题目要求展开**时间、地点、活动、原因、要求、建议、后续步骤**等具体信息。不是每篇都需要这些元素；应由题目决定。

</Step>
<Step>

### 第三段：自然收尾

按体裁提出回应、表达感谢、重申请求或简要祝愿。结尾不重复正文，也不额外添加无关信息。

</Step>
</Steps>

## 七十一、应用文评分标准：六档如何区分？（原书第 79—80 页）

原书介绍的 A 节评分主要看：**内容要点、文章组织、语言准确性、文体格式及语体恰当性**。以下按书中给出的档次压缩提炼，同时保留各档分值与核心差异。

| 档次 | 分数 | 内容完成度 | 语言与组织 | 读者效果 |
| --- | ---: | --- | --- | --- |
| 第五档 | **9—10** | 要点**全部覆盖且有效展开** | 用词准确、表达丰富而自然；衔接有效、层次清晰；格式语体贴切 | 完全达到交际目的 |
| 第四档 | **7—8** | 全部要点覆盖，个别未充分展开 | 用词和句式较丰富，偶有复杂表达错误；总体连贯，格式得体 | 达到交际目的 |
| 第三档 | **5—6** | 涵盖大多数要点，但有遗漏 | 表达基本够用，有错误但大体可理解；结构与格式基本合理 | 基本达到交际目的 |
| 第二档 | **3—4** | 漏掉部分重要内容，或存在无关信息 | 结构单调、错误较多，连贯和文体存在明显问题 | 信息传递不够清晰 |
| 第一档 | **1—2** | 主要任务基本未完成，偏题严重 | 语言错误很多、缺少组织或格式，难以理解 | 未达到交际目的 |
| 零档 | **0** | 与题目无关，或几乎无可评价内容 | 内容无法辨认、语言过少等 | 无法评价 |

### 71.1 原书评分原则：五项实际影响

<Accordions>
<Accordion title="① 题目给出的提示语能不能原样照抄？" id="ky-method-71-80-write1">

可以合理使用**个别关键词**，但不能靠照抄整句或成段提示充当自己的作文。原书指出，大量套用提示内容会影响评分。真正需要展示的是**按要求组织信息并进行适当表达**的能力。

</Accordion>
<Accordion title="② 是先给总分，还是把每项机械相加？" id="ky-method-71-80-write2">

据原书介绍，阅卷先依据**内容与语言整体表现**判定所属档次，再在该档次中确定分数。考前训练可以按“内容—语言—结构—格式”分别检查，但不应误以为每一项都有固定公开的独立加分额。

</Accordion>
<Accordion title="③ 词数不是 100，是否直接判零分？" id="ky-method-71-80-write3">

不是。原书规定“约 100 词”，篇幅明显不合要求时会**酌情扣分**。对考场写作，更合理的做法是先完成所有内容要点，再控制篇幅，避免过短而信息不足或过长而偏离重点。

</Accordion>
<Accordion title="④ 英式拼写与美式拼写能否混用？" id="ky-method-71-80-write4">

原书说明**英式、美式拼写及词汇用法均可接受**。写作时建议一篇文章风格尽量统一，但不要把合法的英美差异误判为错误。标点与拼写错误是否扣分，要结合它们对读者理解的影响。

</Accordion>
<Accordion title="⑤ 书写不好会有什么影响？" id="ky-method-71-80-write5">

如果字迹差到妨碍理解，按原书引用的评分原则可能**降低一个档次**。书写整洁、字母清楚、改动可辨，本身就是应试表达的基本保障；无需刻意追求花体。

</Accordion>
</Accordions>

### 71.2 目标 9—10 分：把抽象标准变成检查清单

- [ ] **任务**：题目要求的身份、目的、对象和全部内容点都已回应。
- [ ] **信息**：时间、地点、原因、请求、联系方式等必须要素没有缺失（仅检查题目实际要求的项）。
- [ ] **结构**：开头交代目的，中间有序安排内容，结尾得体收束。
- [ ] **表达**：句法以准确为先；有适当句式变化和自然衔接。
- [ ] **语体**：称呼、感谢／请求措辞、结束语符合收件人身份与场景。
- [ ] **语言细节**：检查主谓一致、代词指向、动词时态、冠词、拼写和标点。
- [ ] **篇幅及书写**：词数满足当年题目要求，书写清晰。

<Callout type="idea" title="从 5—6 分向 7—8 分提高的关键">

与其增加陌生的“高级词”，不如补齐遗漏要点，修复影响理解的错误，理顺段落间关系，并使语气与收件人匹配。**先确保读者能得到所需信息，再谈表达多样性。**

</Callout>

## 七十二、本章复习索引：从句、特殊结构与写作评分（原书第 71—80 页）

### 72.1 各类结构遇到时的第一反应

| 看见的标志 | 第一步要问 | 常用翻译处理 |
| --- | --- | --- |
| `It seems ... that ...` | `it` 是形式主语吗？ | 把 `that` 从句译为真正评价对象 |
| `believe / show that ...` | `that` 说明哪个动词的内容？ | 保留“认为／表明……”的支配关系 |
| `the idea / truth that ...` | 是解释内容，还是限定名词？ | 内容长则提前或冒号解释 |
| `N + which / who / where ...` | 修饰哪个先行词？ | 短前置、长后置，或另起句 |
| `if / though / because / so ... that` | 是条件、让步、原因还是结果？ | 优先按中文逻辑重排 |
| `be + past participle` | 施动者是否重要、已知？ | 选中文主动、被动或无标记句 |
| `N + being / done / adj.` | 是独立主格吗？表达什么关系？ | 按原因、时间、伴随等补关系 |
| `never before has ...` | 是否否定词引起倒装？ | 恢复句意并突出“从未” |
| `It is ... that ...` | 是否强调构式？重点在哪？ | 用“正是……才……”等表达 |
| 两个逗号间的补充语 | 修饰前后哪一部分？ | 视语义融入、顺译、前置或后置 |

### 72.4 五道复盘题：判断错误究竟出在哪一层

<Accordions>
<Accordion title="① It seemed inconceivable that ... 能否把 it 译成“它似乎”？" id="ky-method-71-80-check1">

通常不能。此时 `it` 是形式主语，真正被评价的是 `that` 从句的内容。中文可译成“……这件事似乎令人难以置信”。

</Accordion>
<Accordion title="② the idea that ... 与 the idea which ...，都译成“……的观点”即可吗？" id="ky-method-71-80-check2">

不能只靠一个“的”字区分。先确认从句是否在说明观点**内容**（同位语），还是在识别或修饰某个观点（定语）。再决定前移、后置或加冒号。

</Accordion>
<Accordion title="③ Never before has it ... 的得分点在哪里？" id="ky-method-71-80-check3">

突出“以前从未如此……”的否定比较；助动词倒装是英文形式，中文不需要复制，但必须保留强调程度。

</Accordion>
<Accordion title="④ is defined as 能否一律译成“被定义为”？" id="ky-method-71-80-check4">

可以在需要时译成“定义为”，也可译成“……的定义是……”。选择取决于上下文信息重点；不要因为出现被动语态就必须加入汉语“被”字。

</Accordion>
<Accordion title="⑤ A 节作文为什么不建议把 100 词写成密集长难句？" id="ky-method-71-80-check5">

应用文先要让目标读者准确获取信息。词句过于复杂容易引发错误，也会挤占必要内容空间。更好的顺序是：任务要点齐全 → 语体格式正确 → 语言准确自然 → 适度变化。

</Accordion>
</Accordions>

### 73.2 看到题目，先把它翻译成“沟通任务”

| 任务动词 | 写作任务 | 必须回答读者什么问题 |
| --- | --- | --- |
| suggest / propose | 建议 | 要解决什么问题？有什么**具体、可执行**的办法？ |
| invite | 邀请 | 邀请对方做什么？活动情况和参与方式是什么？ |
| recommend | 推荐 | 推荐谁或什么？至少给出与收信人需求有关的理由。 |
| reply / respond | 答复 | 对方问了什么？每个问题是否得到明确回答？ |
| apologize | 道歉 | 为何致歉？如何补救？ |
| apply | 申请 | 申请什么？资格、能力或动机如何匹配？ |
| announce / recruit | 通知／招募 | 面向谁？什么事？何时、何地、如何参与？ |

**复习重点**：通用句型只能帮你“把信息说出来”，不能代替题目要求本身。

## 七十四、应用文五步写作法：由任务要点推导到成文（原书第 81 页）

<Steps>
<Step>

  ### 第一步：审题——做一张“任务卡”

  圈出 **Who（写给谁）／Why（为什么写）／What（必须写什么）／How（语气与格式）／Length（词数）**。先分辨题目里已经给定的事实和留给考生合理补充的信息。

</Step>
<Step>

  ### 第二步：构思——先决定信息顺序

  通常按“回应来信或说明目的 → 依次落实任务信息 → 礼貌收束”的三段式构思。并非所有邮件必须三段，但每段要承担明确功能。

</Step>
<Step>

  ### 第三步：创作——先写准确、完整的基础稿

  优先使用自己能控制的时态、搭配和句型，避免因追求长句而漏答题。尤其要确保**回复性邮件逐问作答**。

</Step>
<Step>

  ### 第四步：优化——只在确实提高质量时替换表达

  优先优化信息衔接、句子重复、搭配自然度和语气。**高级不等于生僻、被动、倒装或插入语越多越好**。

</Step>
<Step>

  ### 第五步：检查——从读者视角验收

  逐项确认任务要点、称呼署名、代词指代、时态、单复数、拼写和篇幅。检查有无“看似很漂亮却没有提供信息”的套话。

</Step>
</Steps>

<Callout type="idea" title="限时训练用：30 秒审题卡">

**收件人是谁？** → **我为什么写？** → **题目要我交代哪两三件事？** → **要对方采取什么行动？** → **署名有什么硬性要求？**

</Callout>

## 七十五、2025 年英语（一）应用文 Q51：给 Paul 的回复（原书第 81—83 页）

### 75.1 完整理解题目与原始来信

> **题目情境（2025）**：Read the following email from your classmate Paul and write him a reply. Write your answer in about 100 words; sign as **Li Ming**. （10 分）
>
> Dear Li Ming,
>
> I was really excited to hear that you'd invite some young craftsmen to demonstrate their innovative craft-making on campus. May I know more about what they'll show? Also, I'd like to help with your preparation work. Please let me know what I can do.
>
> Yours,
>
> Paul

| 原文中的信号 | 实际要回应的任务 | 能否遗漏 |
| --- | --- | --- |
| `May I know more about what they'll show?` | **说明工艺师将展示什么**：作品类别、制作过程、创新理念等 | 不可遗漏 |
| `I'd like to help with your preparation work.` | **接纳帮助并安排可执行工作**：布置展区、设计海报、联络、宣传等 | 不可遗漏 |
| `your classmate Paul` | 语气友好自然，不必像行政公文一样堆叠敬语 | 必须匹配 |
| `about 100 words` / `Li Ming` | 控制篇幅，按指令落款 | 必须遵守 |

### 75.2 逐步构思：三段直接覆盖两个问题

<Cards>
<Card title="第 1 段 · 回应来信">
    感谢 Paul 对活动的关注和主动帮忙，简短交代将介绍活动情况。
</Card>
<Card title="第 2 段 · 完成两个任务">
    先解释展示内容，再明确 Paul 可协助的具体事项；这是全信得分主体。
</Card>
<Card title="第 3 段 · 友好结尾">
    对帮助表示欢迎，并交代后续信息或联系方式。
</Card>
</Cards>

### 75.3 优化范文：自然、具体、适配同学身份

Dear Paul,

Thanks for your interest in the craft demonstrations and for offering to help. I'm happy to share a few details.

The young craftspeople will display paper cuttings, clay sculptures and bamboo weaving. They will also demonstrate how these crafts are made and explain the new ideas behind their designs. Could you help set up the exhibition area and design a poster? It would also be great if you could share the event details with our classmates. I'll send you the schedule once it's confirmed.

I'm glad you'll be involved, and I look forward to working with you.

Yours,

Li Ming

<Accordions>
<Accordion title="范文译文：如何处理两项任务？" id="ky-method-2025-reply-translation">

  亲爱的保罗：

  感谢你关注这次手工艺展示并主动提出帮忙。我很乐意介绍一些细节。

  年轻工艺师们将展示剪纸、泥塑和竹编作品。他们还将现场演示制作过程，并解释设计中的新想法。你能帮忙布置展区并设计海报吗？如果你能向同学们宣传活动，也会很有帮助。日程一经确认，我就会发给你。

</Accordion>
<Accordion title="得分拆解：每句话有哪些功能？" id="ky-method-2025-reply-function">

  - `Thanks for ... and for ...`：简要回应对方的两项善意。
  - `will display` / `will also demonstrate`：说明**作品**和**展示活动**，信息不重复。
  - `Could you help ...?`：把帮助转化为可执行的请求。
  - `I'll send ... once ...`：约定后续事项，不随意编造已确定的日期。
  - `Yours, Li Ming`：与同学关系匹配；此题明确要求该署名。

</Accordion>
</Accordions>

### 75.4 原书例文的优点与需要修正的表达

原书采用“背景致谢—展示内容与协助工作—结尾欢迎”的结构，**覆盖要点是正确的**。以下是对其措辞的教学性优化，不代表真题唯一范文。

| 原书／基础表达 | 建议表达 | 修改理由 |
| --- | --- | --- |
| `show the making process of the handicrafts` | `demonstrate how the crafts are made` | 更紧凑、更符合现场展示语境。 |
| `advertise among students` | `promote the event among students` | 指宣传活动时搭配更自然。 |
| `make the poster` | `design a poster` | 根据任务内容选动词，海报“设计”更明确。 |
| `will definitely be held successfully` | `will be a success` | 减少不必要的被动结构与副词堆叠。 |
| `furnish you with further details` | `share a few more details` | 前者语法可成立，但对同学过于正式，后者贴近邮件语域。 |

## 七十六、从基础稿到高质量稿：优化的是表达效果（原书第 83—85 页）

原书把多组句子作“词汇升级＋句式升级”，可以作为对比训练，但并不是所有替换都提升了文章质量。

### 76.1 五种真正有价值的优化

| 优化目标 | 基础写法 | 更合适的写法 | 价值 |
| --- | --- | --- | --- |
| 减少名词重复 | `The crafts will ... The crafts will ...` | `They will also ...` | 指代清晰、句子更流畅。 |
| 列举具体信息 | `many innovative crafts` | `a range of crafts, including paper cutting and pottery` | 增加可验证的内容。 |
| 表达礼貌请求 | `You can make a poster.` | `Could you help design a poster?` | 从命令／安排变成礼貌邀请。 |
| 衔接并列任务 | `They will demonstrate the process. They will explain the ideas.` | `They will demonstrate the process and explain their ideas.` | 合并关联动作，不损失信息。 |
| 说明时间条件 | `I will tell you the time.` | `I'll send you the schedule once it's confirmed.` | 交代时间前提，避免凭空确认事实。 |

### 76.2 原书几种“升级”应怎样看待？

<Accordions>
<Accordion title="① in which 定语从句是否比两个简短动词结构更好？" id="ky-method-p83-in-which">

  例：`I was glad to receive your email, in which you expressed interest in the event.` 语法和语义基本成立，但对应这类同学间邮件，`I'm glad you're interested in the event` 往往更直接。长句不是自动加分项。

</Accordion>
<Accordion title="② 被动句 Your willingness ... is deeply appreciated 是否更礼貌？" id="ky-method-p83-passive">

  可以理解，但抽象名词 `willingness`＋被动谓语的句式偏重。`Thanks for offering to help` 更自然亲切。**评价的依据应是语域和清晰程度，不是语态形式**。

</Accordion>
<Accordion title="③ not only ... but also ... 什么时候适用？" id="ky-method-p84-not-only">

  当你确实需要强调双重任务时适用：`They will not only show their work but also explain how they make it.` 但普通并列 `They will display ... and demonstrate ...` 已经很清楚，没有必要篇篇使用强调结构。

</Accordion>
<Accordion title="④ multi-angle demonstration 是通用高分搭配吗？" id="ky-method-p84-multi-angle">

  不是。`give a multi-angle demonstration of ...` 虽能推断含义，但对手工艺展览而言较生硬。可改为 `show a variety of crafts`、`demonstrate several craft techniques`，用准确具体的信息替代抽象修饰语。

</Accordion>
<Accordion title="⑤ our event, I believe, will undoubtedly achieve great success 有必要吗？" id="ky-method-p84-insertion">

  插入语放在主谓之间无明显语法错误，但在约 100 词的邮件里既占字数，也容易显得刻意。`I believe the event will be a success with your help` 已足以完成沟通。

</Accordion>
</Accordions>

<Callout type="success" title="优化的顺序，不是先找高级替换词">

**要点完整 → 用词准确 → 语气匹配 → 衔接顺畅 → 适度句式变化。** 对于 10 分应用文，先达到前四项，通常比堆砌复杂句更值得投入时间。

</Callout>

## 七十七、书信的四个核心格式：称呼、正文、结束语、署名（原书第 85—86 页）

原书提到完整商务书信还可能包含地址、日期、信头等，但在本书列举的考研任务中，**通常不要求写这些部分**，必须按题目指令处理。

### 77.1 把原书称呼示意图转换为可检索表格

| 收信对象 | 推荐称呼 | 注意事项 |
| --- | --- | --- |
| 熟悉的同学或朋友 | `Dear Paul,` / `Dear Tom,` | 使用名即可，语气自然。 |
| 已知姓氏的老师／教授 | `Dear Professor Smith,` | 比随意直呼其名更稳妥。 |
| 已知姓氏、带博士头衔的人士 | `Dear Dr. Smith,` | 英文 `Dr.` 与姓名之间留空格。 |
| 未知姓名、较正式收信人 | `Dear Sir or Madam,` | 无明确身份时才使用；最好能确定职务就用职务。 |
| 某组织全体成员 | `Dear Team,` / `Dear Committee Members,` | 比无差别写 `Dear friends` 更精确。 |
| 学生群体 | `Dear Students,` | 更适合通知类或公开通信。 |

教材图中出现 `To whom it may concern`。这一表达可用于无法识别具体收件人的正式推荐或证明材料，**不应作为所有未知收件人的首选邮件称呼**。

### 77.2 标准组成与排版原则

| 部分 | 作用 | 推荐写法 |
| --- | --- | --- |
| Salutation 称呼 | 明确对谁说话 | 独立一行，末尾逗号。 |
| Body 正文 | 兑现写作任务 | 可分 2—3 段；每段各司其职。 |
| Complimentary close 结束语 | 礼貌收束 | 独立一行，后接逗号。 |
| Signature 署名 | 交代作者身份 | 独立一行；遵守题目要求的名字。 |

```text title="英语一应用文邮件格式示意"
Dear Professor Smith,

I am writing to ...

[Main information and requested details.]

Thank you for your consideration.

Yours sincerely,
Li Ming
```

**齐头式与缩进式**都可以表达完整结构。原书偏好缩进式、末尾右对齐，现代英文邮件常用统一左对齐；备考最稳妥的做法是**保持全文一致、清晰易读**，不必为了模仿印刷范文硬插 5 个字符的段首空格。

### 77.3 结束语按关系选择

| 结束语 | 常见语境 | 使用建议 |
| --- | --- | --- |
| `Yours sincerely,` / `Sincerely,` | 较正式、已知对方身份 | 稳妥通用。 |
| `Yours faithfully,` | 英式正式书信中常搭配 `Dear Sir or Madam` | 可了解，但不是所有邮件都必须用。 |
| `Best regards,` | 半正式邮件 | 适合一般交流，但以试题语气为准。 |
| `Yours,` | 熟悉的同学、朋友 | 自然简洁。 |
| `Yours respectfully,` | 极正式的尊敬语境 | 不必为显示高级而滥用。 |
| `Lovingly yours,` | 私人亲密通信 | **不适合**写给校长或教授。 |

<Callout type="warn" title="三类格式失分陷阱">

1. 题目明确要求 `Li Ming`，就不能署真实姓名。
2. 题目明确说 `Do not write the address`，就不能自行加收件地址。
3. 日期、机构头衔、活动地点等**没有给定的事实**，若需要为示例补全，应把它们视为合理的练习设定，而非“真题提供的资料”。

</Callout>

## 七十八、建议信：2014 年英语（一）Q51（原书第 86—87 页）

### 78.1 真题任务及思路

> **2014 年应用文**：Write a letter of about 100 words to the president of your university, **suggesting how to improve students' physical condition**. Include details you consider necessary. Sign `Li Ming`, and **do not write the address**.（10 分）

这里的 `physical condition` 应理解为**学生身体健康／体质水平**，不能只讲学校宿舍环境，更不能把建议写成对校长的泛泛赞美。

<Steps>
<Step>

  ### 提出写信目的

  说明自己是本校学生，并提出改进学生体质的建议。

</Step>
<Step>

  ### 给出 2—3 项不同层面的行动

  可从场地资源、体育活动、健康知识入手。每条建议最好包含一个具体做法，而非连续罗列口号。

</Step>
<Step>

  ### 感谢对方考虑

  礼貌收尾，不必无端要求校长立即回复。

</Step>
</Steps>

### 78.2 优化示范：让建议具体可执行

Dear President,

As a student at our university, I would like to suggest several ways to improve students' physical fitness.

First, please consider extending the opening hours of the sports center so more students can exercise after class. Second, the university could organize weekly activities, such as running clubs and basketball games, to encourage regular participation. Finally, short workshops on healthy habits would help students understand the benefits of exercise and balanced diets.

I hope these suggestions will be useful. Thank you for considering them.

Yours sincerely,

Li Ming

<Accordions>
<Accordion title="参考译文" id="ky-method-2014-suggestion-cn">

  尊敬的校长：

  作为本校学生，我想提出几条改善学生体质的建议。

  首先，希望考虑延长体育中心的开放时间，以便更多学生在课后锻炼。其次，学校可以定期组织跑步俱乐部、篮球比赛等活动，鼓励大家坚持运动。最后，开设简短的健康习惯讲座，有助于学生了解锻炼和平衡饮食的益处。

  希望这些建议有所帮助。感谢您的考虑。

  李明

</Accordion>
<Accordion title="原书模板中哪些表达不适合机械套用？" id="ky-method-2014-suggestion-critique">

  - `the constitution of students is getting increasingly worse`：虽可猜到意思，但搭配生硬；写**体质**通常可用 `students' physical fitness`，如 `some students lack regular exercise`。
  - `First and foremost ... What's more ... Last but not least ...`：三点建议可以这样连，但重复背诵容易千篇一律；`First / Second / Finally` 足够清晰。
  - `our university is supposed to ...`：可能给人要求对方履责的强硬感；建议信可用 `could`、`might consider` 缓和语气。
  - `reply at your earliest convenience`：除非题目要求获得回复，否则不必硬加催促。

</Accordion>
</Accordions>

### 78.3 建议信可迁移句型

| 功能 | 稳妥表达 | 适用条件 |
| --- | --- | --- |
| 提出建议 | `I would like to suggest ...` | 开头说明目的。 |
| 委婉建议 | `You might consider ...` / `The university could ...` | 写给上级、教师或陌生人。 |
| 表明理由 | `This would allow students to ...` | 把建议和效果联系起来。 |
| 感谢考虑 | `Thank you for considering these suggestions.` | 语气礼貌且不强求回复。 |

## 七十九、邀请信：2022 年英语（一）Q51（原书第 87—88 页）

### 79.1 本题邀请的不是“来参观”，而是“组队参赛”

> **2022 年应用文**：Write an email to a professor at a British university, **inviting him/her to organize a team** for the international innovation contest to be held at your university. About 100 words; sign `Li Ming`.（10 分）

| 要素 | 要求 |
| --- | --- |
| 对象 | 英国某高校教授，语气正式、尊重。 |
| 行为 | 邀请教授**组织一支队伍**，参与本校举办的国际创新竞赛。 |
| 活动 | 国际创新竞赛；说明参与形式和意义，可给出必要的联络安排。 |
| 不得偏题 | 不能只邀请教授出席开幕式、担任观众或泛泛发表演讲。 |

### 79.2 优化范文：突出行动请求

Dear Professor Smith,

I am writing on behalf of the organizing committee to invite you to form a team for the international innovation contest at our university.

The competition will bring together students from different countries to develop practical solutions to real-world problems. We would be honored if you could select interested students from your university and guide them in preparing a project. Further details about the schedule and registration will be sent once they are finalized.

Please let us know whether you would be willing to participate. We look forward to hearing from you.

Yours sincerely,

Li Ming

<Accordions>
<Accordion title="中文译文与得分逻辑" id="ky-method-2022-invitation-cn">

  尊敬的史密斯教授：

  我谨代表组委会邀请您组织队伍，参加在我校举办的国际创新竞赛。

  期待您告知是否愿意参与，盼复。

  **对应题干的关键动作**：`invite you to form a team`；`select interested students`；`guide them in preparing a project`。

</Accordion>

  原书模板加入了 `March 1st, 2022`、`the Activity Center of Peking University` 和一个具体的商业模式主题。**这些细节不是本页真题写作指令所给定的事实**，属于教材为了示范而补写的情景。备考可学习“补充活动信息”的方法，但不能据此认定真题已经指定日期、地点与主题。

  若考题未要求具体日期、且自己无法确定，写 `We will share the schedule once it is confirmed` 同样能够合理交代后续安排。

</Accordion>
</Accordions>

### 79.3 邀请信应写清的四种信息

- **邀请动作**：`invite you to join / organize / speak at ...`；动词要与题目一致。
- **活动价值**：对收信人为何重要，不应只说 `Your participation is important`。
- **参与安排**：明确需要组队、准备项目、回复意向等操作。
- **回复请求**：`Please let us know if you would be interested.` 比单纯 `Look forward to your reply` 更具体。

## 八十、推荐信：2017 年英语（一）Q51（原书第 88—89 页）

### 80.1 题目要求与原书例文的局限

> **2017 年应用文**：Write an email to **James Cook, a newly-arrived Australian professor**, recommending **some tourist attractions in your city** and giving reasons. Sign `Li Ming`; **do not write the address**.（10 分）

这里至少涉及三项：**新来的外籍教授**、**当地旅游景点**、**推荐理由**。原书例文主要介绍秦始皇帝陵博物院，同时用了 `a little bird whispered to me` 作为开头。后者偏随意甚至突兀，写给初来乍到的教授不够自然。

<Callout type="info" title="示例设定和题目事实要区分">

原题没有指定你所在的城市。下文为了示范“多个景点＋不同理由”，**假设所在地为西安**；兵马俑和城墙是范文选用的素材，不是试题原文指定的答案。

</Callout>

### 80.2 优化范文：两个景点、两个不重复的理由

Dear Professor Cook,

Welcome to our city! As you have just arrived, I'd like to recommend two places in Xi'an that may help you discover its history and culture.

First, the Emperor Qinshihuang's Mausoleum Site Museum is well worth visiting. Its terracotta figures offer a remarkable glimpse into ancient Chinese craftsmanship. I also recommend the Xi'an City Wall, where you can enjoy views of the city while learning about its past. Both places are popular introductions to local heritage.

I hope these suggestions help you explore the city. Please let me know if you would like more information.

Yours sincerely,

Li Ming

<Accordions>
<Accordion title="为什么本例比套用“听说您很感兴趣”更适配？" id="ky-method-2017-recommend-logic">

  - `As you have just arrived`：直接利用题目给定的“新来”身份，不猜测对方爱好。
  - `recommend two places`：落实复数 `some tourist attractions`，而非只介绍一个地点。
  - `craftsmanship` 与 `views of the city`：两个景点有不同推荐理由，而不重复空泛的 `It is famous`。
  - `Please let me know ...`：提供进一步交流的机会，符合推荐信目的。

</Accordion>
<Accordion title="参考译文" id="ky-method-2017-recommend-cn">

  尊敬的库克教授：

  欢迎来到我们这座城市！您刚到这里，我想推荐西安的两个景点，帮助您了解本地历史与文化。

  首先，秦始皇帝陵博物院很值得一游。兵马俑让人得以窥见中国古代精湛的工艺。我还推荐西安城墙，您可以一边欣赏城市景观，一边了解这里的过去。这两处都是认识本地文化遗产的好去处。

  希望这些建议能帮助您探索这座城市。如需更多信息，欢迎联系我。

  李明

</Accordion>
</Accordions>

### 80.3 推荐理由的组织方法

| 推荐对象 | 更有说服力的理由 | 较弱、应避免的理由 |
| --- | --- | --- |
| 历史景点 | 历史故事、工艺、文化价值、参观体验 | `It's very famous.` |
| 当地自然景点 | 季节、环境、交通或体验特色 | `It's very beautiful.` 但无具体说明 |
| 书籍／电影 | 主题与收信人的兴趣吻合、内容特色 | `Everyone loves it.` |
| 人员／志愿者 | 具体能力、经历、适配岗位的表现 | 只有 `excellent`、`hard-working` 等空泛形容词 |

**通用结构**：推荐对象 → 每个对象的独特优点 → 为什么对**这位读者**有价值。

## 八十一、答复信：2019 年英语（一）Q51（原书第 89—90 页）

### 81.1 题目与真实信息边界

> **2019 年应用文**：Suppose you are working for the **“Aiding Rural Primary Schools”** project of your university. Write an email to answer the inquiry from **an international student volunteer**, specifying details of the project. About 100 words; sign `Li Ming`.（10 分）

| 题目给定 | 可以合理组织的信息 | 不能误当成已知事实 |
| --- | --- | --- |
| 写信人参与学校“援助乡村小学”项目 | 项目目标、主要志愿工作、参与方式、联系方式 | 具体开始日期、持续月份、地点、报名截止日均未给出 |
| 收信人是国际学生志愿者 | 课程支持、语言准备、工作条件 | 对方的个人姓名、汉语水平、可用时间等未给出 |
| 要回复对方询问 | 逐条介绍重要细节，写清项目如何运行 | 题干未提供对方邮件全文，不能凭空断言其问了哪两道具体问题 |

### 81.2 优化示范：用清晰的信息替代夸张套语

Dear Volunteer,

Thank you for your interest in our university's Aiding Rural Primary Schools project. I'm pleased to share some information.

The project aims to support pupils in rural areas through reading activities and classroom assistance. Volunteers may help teachers prepare lessons and organize English games for children. Before joining, participants will receive an introduction to the school and their responsibilities. If you are interested, please reply with your available dates and any relevant teaching experience. Our team will then contact you about the next steps.

I hope this answers your questions, and we look forward to hearing from you.

Yours sincerely,

Li Ming

### 81.3 答复信的“问题—回答”结构

| 读者提问类型 | 对应写法 | 最常见遗漏 |
| --- | --- | --- |
| 时间安排 | `The program will begin ...` / `The schedule is being finalized.` | 在时间未确认时编造具体日期。 |
| 工作内容 | `Volunteers will help ...` | 只说“意义重大”，不写做什么。 |
| 参与条件 | `Applicants should ...` | 未交代为何需要此项条件。 |
| 报名方式 | `Please send ... to ...` | 要对方参加，却不说明下一步。 |
| 补充问题 | `Please feel free to ask if you need ...` | 结尾只说感谢，忽略继续沟通的可能。 |

<Callout type="idea" title="回信法则：保留原邮件的提问顺序">

有完整来信时，先标出每一个问句，再按相同顺序作答。这样比随意套用“非常高兴收到您的信……期待您的回复”更不容易漏点。

</Callout>

## 八十三、道歉信：先说明错误，再提出能执行的补救（原书第 91 页）

### 83.1 道歉信考什么？

道歉信（*letter of apology*）要完成的不是反复表达愧疚，而是一次有效的沟通：**准确承认问题 → 说明实际影响 → 提出补救方案 → 礼貌结束**。收信人首先想知道发生了什么、接下来如何解决；长篇自责不能代替行动。

<Steps>
<Step>

### 交代事件、明确道歉

直接点明错误与对象，例如 `I'm sorry I forgot to return your CD before leaving Canada.`。避免 `I'm sorry about everything` 这种含糊说法。

</Step>
<Step>

### 说明补救办法

应优先提出**可操作、与损失相匹配**的解决方案，例如邮寄归还、赔偿损失、重新安排时间。可以提供选择，但不要把全部责任推给收信人。

</Step>
<Step>

### 再次致歉、确认后续

`Please let me know whether you'd prefer me to mail it back or replace it.` 既尊重对方，也说明下一步行动。

</Step>
</Steps>

| 写作位置 | 必须完成的任务 | 自然句式 | 警惕的写法 |
| --- | --- | --- | --- |
| 开头 | 就具体行为道歉 | `I sincerely apologize for ...` | 空泛而冗长地表露“内心极度愧疚” |
| 中间 | 提供补救并承担责任 | `I'll send it back by post.` | 只说 `I'll try my best.` |
| 结尾 | 请对方确认并再次道歉 | `Please accept my apologies.` | 强求对方立即原谅，或重复五六次道歉 |

### 83.2 2008 年英语（一）应用文 Q51：忘还房东的 CD

**题目关键信息**：从加拿大回来后，发现行李中有房东 **Bob** 的音乐 CD；写信给 Bob，必须完成两件事：**道歉（make an apology）**、**提出解决办法（suggest a solution）**。题目要求约 100 词，署名 `Li Ming`，不写地址。

<Tabs items={['优化示范信','中文译文','逐项分析']} defaultIndex={0}>
<Tab value="优化示范信">

Dear Bob,

I'm writing to apologize for accidentally bringing your music CD home with me. I found it in my luggage after returning from Canada and realized that I had forgotten to give it back to you.

I'm very sorry for my carelessness. I'll be happy to mail the CD to you as soon as possible. If that is inconvenient, I can also buy you a replacement. Please let me know which option you would prefer, and I'll make the necessary arrangements right away.

Once again, I'm sorry for the trouble I've caused. Thank you for your understanding.

Yours sincerely,

Li Ming

</Tab>
<Tab value="中文译文">

亲爱的鲍勃：

我写信是想为误把您的音乐 CD 带回家而道歉。从加拿大回来后，我在行李里发现了它，才意识到自己忘记把它还给您。

很抱歉因为我的疏忽造成了不便。我愿意尽快把 CD 邮寄给您；如果这样不方便，我也可以购买一张新的作为补偿。请告诉我您更倾向于哪种方式，我会立即安排。

再次为给您带来的麻烦表示歉意。感谢您的理解。

您真诚的

李明

</Tab>
<Tab value="逐项分析">

- **事件准确**：`accidentally bringing your music CD home` 说明误带物品，没有改变成“弄丢”或“损坏”。
- **补救明确**：归还原物和购买替代品是两种供对方选择的方案，满足 *suggest a solution*。
- **语气合适**：`I'm very sorry for my carelessness` 比教材 `I'm consumed with a deep sense of guilt` 更简洁得体。
- **行为负责**：`I'll make the necessary arrangements` 告诉对方“由我处理”，不是仅要求对方解决。
- **题干边界**：没有虚构 Bob 的收货地址、具体快递公司或商品价格。

</Tab>
</Tabs>

<Callout type="warn" title="原书模板的几个表达需要修正">

- `I feel awfully sorry that when I unpacked ...` 后接的是发现事件的时间，而不是清楚的道歉对象；写 `I'm sorry I forgot to return your CD` 更直接。
- `sending it back to you by express` 不如 `sending it back by express delivery` / `mailing it back to you` 自然。
- `I have come up with two solutions` 并非错误，但不要在只有一项可行补救时机械硬凑两项。
- 邮寄归还与购买新 CD 的选择是范文设计的补救措施，不能理解为题目已经安排了快递或网络购物。

</Callout>

### 83.3 高频写作词块

| 英语表达 | 用法与含义 |
| --- | --- |
| `apologize to sb. for (doing) sth.` | 因做某事向某人道歉；`to` 指受道歉的人，`for` 指原因 |
| `make up for sth.` | 弥补某事，如损失、不便 |
| `send sth. back` / `mail sth. back` | 把物品寄回去 |
| `replace sth.` / `buy a replacement` | 更换、补购替代品 |
| `take responsibility for sth.` | 对某事承担责任 |
| `cause inconvenience` | 造成不便；更亲切的书信中也可以用 `cause trouble` |

## 八十四、申请与请求信：2006 年“希望工程”资助请求（原书第 92 页）

### 84.1 申请信的核心不是套用 `apply for`，而是说清申请事项

申请信可能是申请职位、课程、奖学金、志愿机会，也可能是**请求机构提供协助**。应先判断读者需要批准哪件事、提供哪项帮助，而不是所有申请都套用 `apply for the permission to ...`。

| 类型 | 更恰当的动词 | 常见任务要点 |
| --- | --- | --- |
| 求职 | `apply for a position` | 职位、资格、经历、希望获得面试 |
| 课程／学校 | `apply for admission to ...` | 项目名称、背景、申请材料 |
| 奖学金 | `apply for a scholarship` | 申请目标、学术表现、需要的材料 |
| 向机构求助 | `ask for assistance with ...` / `seek help in ...` | 需要机构做什么、自己的资助计划 |

### 84.2 2006 年英语（一）Q51：请机构帮助寻找受资助儿童

## 八十五、辞职信：2005 年英语（一）真题（原书第 92—93 页）

### 85.1 辞职信必备的三项信息

1. **明确告知离职决定**：`I have decided to resign from my position as ...`。
2. **解释原因而不过度指责**：可说明职业方向不匹配、工作内容与预期不同。
3. **表达歉意并提出交接安排**：对可能造成的不便表示理解，提供合理的工作移交协助。

<Callout type="warn" title="辞职信不是抱怨信">

将 `the work and team environment are both far from my expectation` 直接作为主要理由，语气容易显得针对单位和同事。若题目只要求解释辞职原因，用 `the position is different from what I had expected` 就能更稳健地表达核心事实。

</Callout>

### 85.2 2005 年英语（一）Q51：从杂志社编辑职位辞职

## 八十六、通知：2020 年歌唱比赛真题（原书第 94—95 页）

### 86.1 通知与书信的格式要分开记

**Notice** 的目标是让读者知道一件事并决定是否行动。原书列出了标题、日期、正文和署名四个组成部分：这一框架有帮助，但**不是每道题都强制要求同样的日期位置、右对齐或段首缩进**；优先执行题目明确要求。

| 项目 | 通知中的主要作用 | 应检查的问题 |
| --- | --- | --- |
| 标题 | 明确文体 `Notice` | 题目是否要求标题？ |
| 发布日期（视需要） | 标明通知发布时点 | 未提供日期时，是否有必要自行设定？ |
| 主体 | 说明活动与参与方式 | 时间、地点、对象、活动内容是否足够明确？ |
| 署名 | 标明发布组织 | 是否遵守“不使用自己的名字”？ |

通知一般**不需要书信式称呼** `Dear ...`，也不需要 `Yours sincerely`。组织署名（如 `The Student Union`）往往比个人署名更贴合通知情境。

### 86.2 2020 年英语（一）Q51：向国际学生发布歌唱比赛通知

<Callout type="info" title="原题与示例补充信息的边界">

题干确认了发布方（学生会）、通知对象（国际学生）和活动性质（歌唱比赛），**没有指定比赛的确切日期、场地、评委组成或报名邮箱**。原书范文给出了 `June 16, 2020`、`April 26, 2020`、五位音乐教授和 `123@ab.com` 等情境细节，仅用于示范如何展开内容。下文提供一份**可替换情境信息的练习稿**，不要将补充安排当作学校真实公告。

</Callout>

## 八十七、建议信句式：掌握功能，不背十句同义套话（原书第 95—96 页）

原书第 95 页开始进入“句式积累”。同一功能下往往列十余句，仅换用 `offer / put forward / propose` 等动词。复习应按**沟通功能和礼貌程度**分类，保留最自然且可迁移的句式。

### 87.1 开头句：说明背景，再引出建议

| 使用情境 | 推荐句型 | 中文意思 |
| --- | --- | --- |
| 直接提供建议 | `I'd like to offer a few suggestions on ...` | 我想就……提几点建议。 |
| 回应求助邮件 | `Thank you for asking for my advice on ...` | 感谢你来信征求关于……的建议。 |
| 结合具体问题 | `With regard to ..., I would suggest ...` | 关于……，我建议…… |
| 引出下文 | `Here are some practical ways to ...` | 以下是……的几种可行办法。 |
| 对机构提出建议 | `I am writing to suggest several ways to improve ...` | 我写信是想提出一些改进……的建议。 |

**段落衔接**：`First, ...` → `In addition, ...` → `Finally, ...` 足够清晰。中间最重要的是**建议与问题之间的因果关联**，而不是连接词数量。

### 87.2 结尾句：态度诚恳，不给对方施压

| 推荐表达 | 适用情境 |
| --- | --- |
| `I hope you find these suggestions helpful.` | 同学、朋友间的普通建议 |
| `I hope you will consider these suggestions.` | 给机构、老师的建议 |
| `Please let me know if you would like to discuss them further.` | 需要进一步沟通 |
| `Thank you for considering my suggestions.` | 尊重对方决定的正式结尾 |

<Accordions>
<Accordion title="为什么不建议直接背 Please take good consideration of my advice？" id="ky-method-p96-advice-consideration">

  `take good consideration of ...` 搭配不自然。应写 `give my suggestions careful consideration`、`consider my suggestions carefully` 或更简单的 `I hope you'll consider my suggestions.`。其中 `consider` 是及物动词，**不用** `consider about sth.`。

</Accordion>
<Accordion title="Your prompt attention to my suggestions would be highly appreciated 是否适合所有建议信？" id="ky-method-p96-advice-prompt">

  不适合。`prompt attention` 常用于需要尽快处理的正式事务；朋友间提出学习建议时显得生硬，甚至像催办工作。按读者身份选择语气，通常用 `I hope these ideas are helpful.` 即可。

</Accordion>
<Accordion title="怎么让建议有说服力，而不是只写 should？" id="ky-method-p96-advice-reason">

  每个核心建议写成“**行动 + 理由／效果**”。例如 `You could join a study group, which would give you more chances to discuss difficult questions.`，比重复 `You should study harder` 更具体。

</Accordion>
</Accordions>

## 八十八、邀请信句式：邀请谁做什么，以及如何回复（原书第 96—97 页）

### 88.1 开头应包含明确邀请

| 典型情境 | 推荐句式 | 写作重点 |
| --- | --- | --- |
| 普通活动 | `I'd like to invite you to join ...` | `invite sb. to do sth.` |
| 正式会议 | `On behalf of ..., I am writing to invite you to attend ...` | 表明组织代表身份 |
| 有地点和日期 | `We would be delighted if you could attend ... on ... at ...` | 不遗漏关键安排 |
| 邀请担任特定角色 | `Would you be willing to serve as ...?` | 把角色写明，而非只说出席 |

### 88.2 结尾：说明希望得到怎样的答复

- `Please let me know if you will be able to attend.`：询问能否参加。
- `We would be delighted to have you with us.`：表达欢迎。
- `I would appreciate it if you could reply by Friday.`：需要截止日时使用。
- `Please feel free to contact me if you need further details.`：提供继续询问的方式。

<Callout type="warn" title="别把客气当作完成任务">

邀请信如果要求说明**活动时间、地点、内容、收信人负责的任务**，这些信息必须写在正文中。`It is my great honor ...` 可以作为礼貌补充，但不应替代真实安排。原书的 `Look forward to hearing from you soon.` 在正式书面语中可改为完整主语句 `I look forward to hearing from you.`；`look forward to` 后接名词或动名词。

</Callout>

### 88.3 句式微练习

把空泛的 `I hope you can come to our activity.` 改成有信息量的邀请：

> `We would be delighted if you could join our student discussion on Friday afternoon and share your experience with the participants.`

该句同时体现**活动内容、时间、希望对方承担的角色**。若题干未给时间，则写作时可以合理设定，但必须与其他段落一致。

## 八十九、推荐信句式：推荐对象、依据和适配性（原书第 97 页）

### 89.1 推荐景点／书籍与推荐人选，重点不同

| 推荐对象 | 应写的理由 | 高质量句式 |
| --- | --- | --- |
| 旅游景点 | 历史文化、特色体验、交通便利 | `I recommend visiting ..., where you can learn about ...` |
| 书籍／电影 | 主题、内容、与读者兴趣的关系 | `Given your interest in ..., I think you'll enjoy ...` |
| 人选／职位 | 能力、经历、已观察到的表现 | `I believe ... would be a strong candidate because ...` |
| 活动／课程 | 学习收获、时间安排、与需求的匹配 | `This program would suit you because ...` |

### 89.2 开头与结尾的精简句式库

- 开头：`Knowing that you are interested in Chinese history, I'd like to recommend ...`（推荐与对方兴趣相关）。
- 开头：`I am pleased to recommend ... for the position of ...`（正式推荐岗位人选）。
- 说明依据：`What makes this place special is ...` / `She has demonstrated ... through ...`。
- 结尾：`I hope you find my recommendation useful.`。
- 结尾：`If you need more details, I'd be happy to provide them.`。

**原书表达优化**：

| 原书短语 | 问题 | 推荐替换 |
| --- | --- | --- |
| `I can't wait to recommend ...` | 语气偏兴奋、口语化，不适合所有正式信件 | `I'd like to recommend ...` |
| `I would like to take the liberty of recommending ...` | 过度客套，日常推荐不必使用 | `I would like to recommend ...` |
| `Hope my recommendation is a very valuable guideline to you.` | `recommendation` 与 `guideline` 的搭配较生硬 | `I hope my recommendation is helpful.` |
| `Based on these inferences, ...` | 推荐理由通常是事实依据，不是逻辑“推论” | `Based on her experience, ...` |
| `the right one for the post` | 指人时表达笼统 | `a suitable candidate for the position` |

<Callout type="idea" title="推荐信的最佳扩写方法">

用 **一个事实 → 一个判断 → 一个对读者的好处**。例如：`The museum has an extensive collection of ancient artifacts, so it would be an excellent choice if you're interested in local history.` 内容具体，比 `It is very great and famous` 更有说服力。

</Callout>

## 九十、答复信句式：把读者的问题逐项解决（原书第 98 页）

答复信（*reply / response letter*）的优先级是**准确回答问题，而不是热情表达对来信的感激**。原书列有多种开头、结尾，大多数可以压缩到以下功能型表达。

| 交际功能 | 自然句式 | 提醒 |
| --- | --- | --- |
| 礼貌开场 | `Thank you for your email about ...` | 说明来信主题 |
| 准备回复 | `I'm happy to answer your questions about ...` | 给出明确回应 |
| 开始列信息 | `Here are the details you asked for.` | 之后立即分项回答 |
| 说明待确认事项 | `The exact date has not been confirmed yet.` | 不把未知写成确定事实 |
| 给出下一步 | `You can register by ...` | 要可执行、与情境吻合 |
| 邀请进一步咨询 | `Please let me know if you have any further questions.` | 比 `contact me for more questions` 自然 |
| 礼貌收尾 | `I hope this information helps.` | 不必重复多个同义结束句 |

<Accordions>
<Accordion title="答复信正文如何排列信息？" id="ky-method-p98-reply-order">

  **问题驱动**：先把来信要问的事情列出，再按原顺序作答。例如学生询问志愿项目的报名条件、工作时间、活动内容，可以按这三点逐项答复，而不是反复介绍“项目十分有意义”。

</Accordion>
<Accordion title="原书的双重结尾为什么需要精简？" id="ky-method-p98-reply-ending">

  `I hope my reply is of benefit to you`、`Please get in touch with me`、`If any further information is needed` 功能高度重合。约 100 词的应用文中，用 `I hope this helps. Please let me know if you need anything else.` 就够了，余下字数应留给实质问题。

</Accordion>
</Accordions>

## 九十一、道歉信开头与结尾：句式选择和搭配纠错（原书第 99 页）

### 91.1 什么时候应该用哪一种道歉句？

| 事件 | 推荐开头 | 特别提醒 |
| --- | --- | --- |
| 过去已经发生的失误 | `I'm writing to apologize for ...` | `for` 后用名词或动名词 |
| 未能完成一件事 | `I'm sorry I couldn't ...` | 直接说清未能做的事情 |
| 将来不得不取消安排 | `I'm sorry that I won't be able to ...` | 说明不能履行承诺的原因 |
| 书面正式致歉 | `Please accept my sincere apologies for ...` | `apologies` 为复数形式 |
| 说明影响 | `I apologize for any inconvenience this has caused.` | 过去已发生影响用 `has caused` |

### 91.2 收尾要从“情绪”过渡到“行动”

- `I'll make sure this doesn't happen again.`：承诺防止再次发生。
- `Please let me know how I can make things right.`：询问可以怎样弥补。
- `Thank you for your patience and understanding.`：感谢理解。
- `Once again, I apologize for the inconvenience.`：再致歉一次即可。

<Callout type="warn" title="三组容易误用的搭配">

1. `apologize to sb. for (doing) sth.`：**不能**把道歉原因放在 `to` 后。
2. `sorry for doing sth.` 与 `sorry that ...`：前者接名词／动名词，后者接完整从句。
3. `regret to inform you that ...`：强调**遗憾地告知坏消息**，并不天然表示自己犯错；道歉责任仍应明确说清。

</Callout>

## 九十二、申请信句式：背景、资格、材料与期待回复（原书第 99—100 页）

### 92.1 精选开头句

| 申请目的 | 表达 |
| --- | --- |
| 应聘 | `I am writing to apply for the position of ...` |
| 回应招聘广告 | `I am writing in response to your advertisement for ...` |
| 申请硕士课程 | `I would like to apply for admission to your master's program in ...` |
| 表达兴趣 | `I am particularly interested in this opportunity because ...` |
| 自我背景 | `I am currently a third-year student majoring in ... at ... University.` |

**注意**：`I am a ... major from ... University` 可以表达专业身份，但比 `I major in ...` 或 `I am a student majoring in ...` 略生硬；`I'm awfully interested` 带有口语色彩，正式申请可用 `particularly interested`。

### 92.2 正文：不要只有身份，要有可验证的匹配理由

高质量申请信通常能回答三个问题：**我申请什么？我为什么合适？你可以如何联系或进一步了解我？**

| 空泛句 | 改写示例 | 提升点 |
| --- | --- | --- |
| `I am very good.` | `I have organized several student events and learned to work effectively in a team.` | 使用具体经历，而非空泛自夸。 |
| `I love this job very much.` | `The position interests me because it combines writing with communication.` | 说明动机与岗位特点的联系。 |
| `I hope you choose me.` | `I would appreciate the opportunity to discuss my qualifications in an interview.` | 提出符合申请过程的下一步。 |

### 92.3 精选结尾句及条件限制

| 结尾句 | 适用前提 |
| --- | --- |
| `Thank you for considering my application.` | 几乎所有申请信 |
| `I look forward to hearing from you.` | 需要对方回复 |
| `I would welcome the opportunity to attend an interview.` | 求职或需要面试的项目 |
| `Please let me know if you need any further information.` | 申请材料可能需要补充 |
| `I have attached my résumé for your consideration.` | **确实有附件**时使用 |

<Accordions>
<Accordion title="原书 Please find enclosed a copy of my résumé 一定能写吗？" id="ky-method-p100-resume">

  不一定。纸质信函附寄材料时 `enclosed` 合适；电子邮件更常用 `attached`。考研写作不能默认题目允许或已安排附件。如果没有附件，可删去这一句，把字数留给申请资格与请求。

</Accordion>
<Accordion title="Would you please write me back at your earliest convenience 是否必须背？" id="ky-method-p100-early-reply">

  不必。它不是错误，但有时显得过于催促。通常 `I look forward to your reply` 更简洁；确有报名截止期时，才应具体说明期望回复日期。

</Accordion>
</Accordions>

## 九十三、辞职信精选开头：区分正式通知与普通口语（原书第 100 页）

原书第 100 页末尾开始列举辞职信开头句。六句基本表达相同意思，按正式程度选两种即可：

| 建议程度 | 例句 | 说明 |
| --- | --- | --- |
| **首选：正式且直接** | `I am writing to inform you of my decision to resign from my position as ...` | 结构清晰，可用于正式书信。 |
| **首选：强调正式告知** | `I am writing to formally notify you that I am resigning as ...` | 明确传达决定。 |
| 可用：简洁说法 | `I have decided to resign from my current position.` | 不啰嗦，适合随后解释原因。 |
| 不建议正式场景首选 | `I am writing this letter to tell you my decision to quit my job.` | `quit my job` 口语化，`resign` 更符合商务书信。 |

## 九十五、应用文写作收尾：辞职信与通知的高频表达（原书第 101—102 页）

原书这两页延续了上一页的应用文句式库，分别列出**辞职信的开头、结尾**以及**通知的开头、结尾**。它们是供选择的语言材料，**并不意味着写一封短笺要把所有句式叠加**。在约 100 词的 A 节写作中，每个段落只需选用最适合任务的 1—2 种表达。

### 95.1 辞职信：决定明确，原因得体，交接负责

<Steps>
<Step>

### 第一段：明确辞职决定

核心句：`I am writing to resign from my position as ...`（我写信申请辞去……职位。）

如果题干要求说明辞职生效日，可写 `My last working day will be ...`；如果题干没有给具体日期，**不要自作主张编出确定日期**。

</Step>
<Step>

### 第二段：简述原因并表达感谢

原因必须与题干一致。原书 2005 年真题所提供的“工作不符合预期”，可以表述为 `The position has turned out to be different from what I had expected.`（这份工作与我原来的预期有所不同。）

接着写 `I appreciate the opportunities and support I have received.`，不用夸张表达，也不必指责雇主。

</Step>
<Step>

### 第三段：提出交接并礼貌结尾

例如 `I will do my best to ensure a smooth handover.`（我会尽力确保工作平稳交接。）和 `Thank you for your understanding.`（感谢您的理解。）

</Step>
</Steps>

| 写作功能 | 推荐表达 | 使用说明 |
| --- | --- | --- |
| 告知离职 | `I am writing to resign from my position as ...` | 简洁、正式，优于冗长的 `This letter is written to inform you ...` |
| 提出正式通知 | `Please accept this letter as formal notice of my resignation.` | 符合正式工作沟通语境；通知期以题干为准 |
| 感谢支持 | `Thank you for the guidance and support you have given me.` | 具体自然，不使用生硬的 `appreciate plenty of help` |
| 对不便致歉 | `I apologize for any inconvenience my departure may cause.` | 道歉一次即可；不要在各段机械重复 |
| 提供交接 | `Please let me know how I can help during the transition.` | *transition* 表示人员、工作安排的过渡期 |
| 祝愿 | `I wish you and the company continued success.` | 礼貌结束，无须再重复辞职决定 |

<Callout type="warn" title="原书辞职句式的四处校正">

- `terminate my employment with your company as ...` 过于行政化，而且作为套用句容易补不完整。考场优先写 `resign from my position as ...`。
- `I sincerely wish you could approve my resignation` 不是通用的英语辞职信句型。辞职是否需要批准取决于具体情境；原题要求辞职时，明确通知或提出请求即可。
- `I appreciate plenty of help and encouragement from you constantly` 不自然。宜写 `I sincerely appreciate your help and encouragement.`。
- `I will appreciate it if ...` 用于礼貌请求时通常改成 `I would appreciate it if ...`。不要把“批准离职”硬塞进所有辞职信。

</Callout>

<Accordions>
<Accordion title="可直接复习：辞职信功能段落范例" id="ky-method-p101-resignation">

**开头（决定）**：

Dear Mr. Smith,

I am writing to resign from my position as an assistant at your company. Although I have learned a great deal from the experience, the job has turned out to be different from what I had expected.

**结尾（感谢与交接）**：

Thank you for your guidance and support. I apologize for any inconvenience my departure may cause and will do my best to ensure a smooth handover.

Yours sincerely,

Li Ming

**使用提醒**：该段落是根据辞职信写作任务整理的示例，其中称呼、岗位属于演示信息，并非额外的真题事实。实际考试应依据题干调整。

</Accordion>
</Accordions>

### 95.2 通知：把五个关键要素写清楚

与书信不同，通知（*notice*）主要用于**公开传达活动安排或规章事项**。与其背诵 `It is hereby announced publicly that ...` 这样复杂的句子，不如把信息写得明确。

| 要素 | 应回答的问题 | 推荐表达 |
| --- | --- | --- |
| 发布方 | 谁组织或发布？ | `The Student Union will organize ...` |
| 活动 | 举办什么，目的是什么？ | `A singing contest will be held to ...` |
| 时间地点 | 何时、何地开展？ | `It will take place at ... on ...` |
| 参与方式 | 谁有资格、如何报名？ | `Students who wish to participate can register ...` |
| 咨询与署名 | 有疑问联系谁？ | `For further information, please contact ...` |

**原书句式纠偏**：

| 原句或倾向 | 问题 | 更稳妥的表达 |
| --- | --- | --- |
| `This is to notify that ... is going to organize ...` | 缺少明确的被通知对象，不宜作为万能模板 | `We are pleased to announce that ...` / `The Student Union will hold ...` |
| `It is hereby announced publicly that ...` | 书面、冗余，与校园活动不相称 | `Notice is hereby given that ...`（正式场合）或直接写活动事项 |
| `Under the auspices of ...` | 偏正式，只在确有主办、支持机构时使用 | `Organized by ...` |
| `all students are requested to participate ...` | 如果是自愿报名，不能强行改成必须参加 | `All interested students are welcome to join.` |
| `please send your résumé to ...` | 仅适用于招聘／遴选，普通比赛报名未必需要简历 | `Please register by ...` |
| `For any clarification or enquiry ...` | 语法虽可理解，但冗长 | `For more details, please contact ...` |

<Tab value="通知结构示意">

**Notice**

The Student Union will hold **[event]** to **[purpose]**. The event will take place **[time]** at **[place]**.

Students who are interested can register **[how and by when]**. For more details, please contact **[contact information, if supplied]**.

**The Student Union**

> 方括号中的内容是待填信息，而非某套真题的既定安排；考试作答时根据题目给定条件决定是否需要填写。

</Tab>
<Tab value="常见易错点">

- **自愿 / 强制**：`welcome to join` 不等于 `required to attend`。
- **报名 / 投简历**：普通竞赛多写 `register` 或 `sign up`；招募岗位才可能要求 `submit a résumé`。
- **时间介词**：`at 3 p.m.`，`on Friday`，`in Room 301`；完整时间地点必须与题干一致。
- **通知落款**：如果发布主体是学生会，写 `The Student Union`，不要无根据地换成个人署名。
- **联系方式**：题干未提供时可以用合乎题意的报名渠道表达，但不应伪称某个具体手机号、邮箱是题目给的。

</Tab>
</Tabs>
