<Callout type="idea" title="总复习原则：语言基础 + 题型方法 + 真题复盘">

单词和语法是理解原文的基础，但考试还要求在时间限制内迅速找到证据。学习一个技巧时，要能回答三个问题：**凭什么定位？凭什么选它？凭什么排除其余选项？**

</Callout>
