这页用于验证新的通用图表层。普通文档只需要提供结构化数据，不需要直接接触 Recharts；Claude Benchmark 这类高定制专题仍然保留自己的 Feature 组件。

## 柱状图

<StudyBarChart
  title="章节练习量"
  description="示例：比较不同数学章节的练习题数量。"
  data={[
    { chapter: "极限", count: 18 },
    { chapter: "导数", count: 14 },
    { chapter: "积分", count: 27 },
    { chapter: "级数", count: 13 },
    { chapter: "微分方程", count: 11 }
  ]}
  xKey="chapter"
  series={[{ key: "count", label: "题目数量" }]}
/>

## 推荐使用方式

普通文章优先使用 `StudyBarChart`、`StudyLineChart`、`StudyAreaChart`、`StudyPieChart`、`StudyScatterChart` 和 `StudyHistogram`。需要断轴、特殊纹理、自定义标签位置、多视图联动等复杂交互时，再像 Claude Benchmark 一样创建专题 Feature，而不是不断给通用组件增加开关。
