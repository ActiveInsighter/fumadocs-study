# 不同的二叉搜索树

> LeetCode 96：Unique Binary Search Trees

给定整数 $n$，使用值为 $1,2,\dots,n$ 的 $n$ 个节点，能够构造出多少棵**结构不同**的二叉搜索树（BST）？

原题示意图：

![不同的二叉搜索树示例](https://file1.kamacoder.com/i/algo/20210113161941835.png)

<Callout type="info" title="本题真正考查什么">
这道题不是让我们把所有二叉搜索树真的构造出来，而是只统计“结构数量”。最关键的转化是：**固定根节点以后，左、右子树的节点集合就被唯一确定，而左右两边的结构可以独立选择。**
</Callout>

## 1. 为什么这道题可以用动态规划

二叉搜索树满足：

- 左子树所有节点值都小于根节点；
- 右子树所有节点值都大于根节点；
- 左右子树本身仍然是二叉搜索树。

因此，如果我们从 $1\sim n$ 中选择 $j$ 作为根节点：

- 左子树只能使用 $1\sim j-1$，共有 $j-1$ 个节点；
- 右子树只能使用 $j+1\sim n$，共有 $n-j$ 个节点。

问题立即被拆成两个规模更小、形式完全相同的子问题。

这正是动态规划需要的结构。

## 2. 先从小规模找规律

当 $n=1$ 时，显然只有一棵树。

当 $n=2$ 时，一共有两种：

![n=1 与 n=2 的二叉搜索树](https://file1.kamacoder.com/i/algo/20210107093106367.png)

当 $n=3$ 时，可以分别选择 $1$、$2$、$3$ 作为根节点：

![n=3 时按根节点分类](https://file1.kamacoder.com/i/algo/20210107093129889.png)

仔细观察会发现：

- 根为 $1$：左边有 $0$ 个节点，右边有 $2$ 个节点；
- 根为 $2$：左边有 $1$ 个节点，右边有 $1$ 个节点；
- 根为 $3$：左边有 $2$ 个节点，右边有 $0$ 个节点。

于是：

$$
G(3)=G(0)G(2)+G(1)G(1)+G(2)G(0)
$$

这里 $G(k)$ 表示“由 $k$ 个不同节点能组成多少棵不同的 BST”。

这已经暴露出了完整递推关系。

## 3. 状态定义

定义：

$$
\boxed{dp[i]=\text{由 }i\text{ 个不同节点组成的不同二叉搜索树数量}}
$$

注意这里状态只依赖**节点个数**，而不依赖节点具体取值。

例如，使用：

$$
\{1,2,3\}
$$

和使用：

$$
\{7,8,9\}
$$

能够形成的 BST 结构数量完全一样，因为二叉搜索树只关心元素之间的相对大小关系。

<Callout type="tip" title="一个很重要的状态抽象">
如果题目只统计结构数量，那么连续的 $k$ 个有序元素到底是 $1\sim k$，还是 $100\sim 99+k$，通常没有区别。把“具体数值”抽象成“节点数量”，状态就会大幅简化。
</Callout>

## 4. 固定根节点后为什么要相乘

假设总共有 $i$ 个节点，选择第 $j$ 个节点作为根。

那么：

$$
L=j-1
$$

$$
R=i-j
$$

左子树共有：

$$
dp[L]
$$

种结构，右子树共有：

$$
dp[R]
$$

种结构。

左子树的每一种结构都可以与右子树的每一种结构组合，因此固定根节点 $j$ 时，总方案数为：

$$
\boxed{dp[j-1]\cdot dp[i-j]}
$$

这实际上使用了组合计数中的**乘法原理**。

![固定根节点后左右子树组合](https://file1.kamacoder.com/i/algo/20210107093226241.png)

## 5. 为什么还要对所有根节点求和

根节点可以是：

$$
1,2,\dots,i
$$

不同根节点对应的二叉搜索树集合互不重叠，因此要使用加法原理把所有情况相加：

$$
\boxed{
 dp[i]=\sum_{j=1}^{i}dp[j-1]\cdot dp[i-j]
}
$$

也就是：

```cpp
for (int j = 1; j <= i; ++j) {
    dp[i] += dp[j - 1] * dp[i - j];
}
```

这一递推式是本题的核心。

## 6. `dp[0] = 1` 为什么不是 0

这是本题最值得理解的初始化。

如果没有节点，直觉上可能觉得“树的数量是 0”。但在组合递推中，**空树必须视为一种合法结构**：

$$
\boxed{dp[0]=1}
$$

原因可以从两个角度理解。

### 角度一：组合意义

假设 $j=1$ 是根节点，那么左子树没有节点。

如果空左子树有 $0$ 种方案，那么：

$$
dp[0]\cdot dp[i-1]=0
$$

就会错误地认为“根为最小值”的所有树都不存在。

实际上，左边为空本身就是一种确定状态，所以应记作 1 种。

### 角度二：乘法单位元

在组合问题中：

- “没有选择”有时是一种合法选择；
- 它在乘法计数中应该充当单位元。

因此：

$$
1\times dp[i-1]=dp[i-1]
$$

正好符合语义。

<Callout type="warning" title="不要机械地把空状态设为 0">
动态规划初始化不是“数组默认填 0”这么简单。初始化必须服务于状态定义和递推公式。只要递推中存在乘法，尤其要警惕空状态是否应该是 $1$。
</Callout>

## 7. 遍历顺序

因为：

$$
dp[i]
$$

只依赖：

$$
dp[0],dp[1],\dots,dp[i-1]
$$

所以外层节点数量必须从小到大计算：

```cpp
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= i; ++j) {
        dp[i] += dp[j - 1] * dp[i - j];
    }
}
```

这里：

- `i`：当前总节点数；
- `j`：当前选择的根节点位置。

## 8. 手推一次 `dp` 数组

从：

$$
dp[0]=1
$$

开始。

### $i=1$

只有根节点 1：

$$
dp[1]=dp[0]dp[0]=1
$$

### $i=2$

$$
dp[2]=dp[0]dp[1]+dp[1]dp[0]
$$

$$
=1+1=2
$$

### $i=3$

$$
dp[3]=dp[0]dp[2]+dp[1]dp[1]+dp[2]dp[0]
$$

$$
=2+1+2=5
$$

### $i=4$

$$
dp[4]
=dp[0]dp[3]+dp[1]dp[2]+dp[2]dp[1]+dp[3]dp[0]
$$

$$
=5+2+2+5=14
$$

因此前几项为：

| $i$ | $dp[i]$ |
| ---: | ---: |
| 0 | 1 |
| 1 | 1 |
| 2 | 2 |
| 3 | 5 |
| 4 | 14 |
| 5 | 42 |

## 9. C++ 标准动态规划写法

```cpp
class Solution {
public:
    int numTrees(int n) {
        vector<int> dp(n + 1, 0);
        dp[0] = 1;

        for (int i = 1; i <= n; ++i) {
            for (int root = 1; root <= i; ++root) {
                int leftSize = root - 1;
                int rightSize = i - root;
                dp[i] += dp[leftSize] * dp[rightSize];
            }
        }

        return dp[n];
    }
};
```

复杂度：

$$
\boxed{T(n)=O(n^2)}
$$

$$
\boxed{S(n)=O(n)}
$$

## 10. 为什么这其实是卡特兰数

本题的递推式：

$$
dp[n]=\sum_{k=0}^{n-1}dp[k]dp[n-1-k]
$$

正是经典的**卡特兰数（Catalan Number）**递推：

$$
C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}
$$

且：

$$
C_0=1
$$

因此：

$$
\boxed{dp[n]=C_n}
$$

卡特兰数还有闭式：

$$
\boxed{
C_n=\frac{1}{n+1}\binom{2n}{n}
}
$$

也可以写成：

$$
C_n=\frac{(2n)!}{n!(n+1)!}
$$

不过在算法学习阶段，动态规划更重要，因为它直接展示了“枚举根节点 → 左右子问题 → 乘法组合 → 对根求和”的结构。

## 11. 卡特兰型问题的识别模板

以后看到下面这些特征，可以主动联想到卡特兰型 DP：

1. 对一个有序对象选择某个位置作为“中心 / 根 / 分割点”；
2. 分割后得到左右两个独立子问题；
3. 左右方案数要相乘；
4. 对所有分割位置再求和。

典型结构就是：

$$
\boxed{
 dp[n]=\sum dp[\text{left}]\cdot dp[\text{right}]
}
$$

这种结构不仅出现在二叉搜索树中，还会出现在括号序列、凸多边形划分等组合计数问题中。

## 12. 高频错误

### 错误一：把 `dp[0]` 设为 0

结果所有包含空子树的组合都会被乘成 0。

### 错误二：左右子树方案数相加

错误：

```cpp
dp[i] += dp[left] + dp[right];
```

左右子树是**同时选择**，应使用乘法原理：

```cpp
dp[i] += dp[left] * dp[right];
```

### 错误三：只考虑某一个根节点

题目统计的是所有不同 BST，因此必须遍历所有可能根节点。

### 错误四：把节点值本身塞进状态

本题结构数量只依赖节点个数，不依赖具体值。

## 14. 一句话抓住本题

> **枚举根节点；左边有多少种、右边有多少种就相乘；再把每个根节点对应的方案数相加。**

这是比死记公式更重要的思维模型。
