# 爬楼梯（进阶版）：从斐波那契到完全背包

[卡码网 57：爬楼梯](https://kamacoder.com/problempage.php?pid=1067)

给定两个正整数 `n` 和 `m`：

- 楼梯一共有 `n` 阶；
- 每一步可以走 `1, 2, ..., m` 阶；
- 同一种步长可以使用任意多次；
- **不同的步长顺序视为不同方案**。

求到达第 `n` 阶一共有多少种走法。

例如：

```text
n = 3, m = 2
```

三种方案分别为：

```text
1 + 1 + 1
1 + 2
2 + 1
```

所以答案为 `3`。

<Callout type="info" title="这不是一道新的模板题">
它本质上就是前面的“组合总和 IV”换了一个故事背景：目标和变成楼梯高度，数字变成每一步允许走的台阶数。
</Callout>

## 1. 从普通爬楼梯开始

经典爬楼梯中，每次只能走 `1` 或 `2` 阶。

如果定义：

$$
dp[i]=\text{到达第 }i\text{ 阶的方案数}
$$

那么最后一步只有两种可能：

- 从第 $i-1$ 阶走 $1$ 阶；
- 从第 $i-2$ 阶走 $2$ 阶。

因此：

$$
dp[i]=dp[i-1]+dp[i-2]
$$

这就是斐波那契型递推。

现在把允许的步长扩展为：

$$
1,2,3,\ldots,m
$$

那么最后一步可能来自：

$$
i-1,i-2,\ldots,i-m
$$

于是自然得到：

$$
\boxed{dp[i]=\sum_{j=1}^{m}dp[i-j]}
$$

其中只累加满足 $i-j\ge 0$ 的项。

这已经给出了最直接的动态规划解法。

## 2. 为什么它又是完全背包

换一个视角：

- 背包容量：`n`；
- 物品：步长 `1 ~ m`；
- 每种物品可以使用无限次；
- 恰好装满容量 `n`；
- 不同使用顺序算不同方案。

因此它是：

$$
\boxed{\text{完全背包 + 排列计数}}
$$

这个分类非常重要，因为它直接决定了遍历顺序。

| 问题元素 | 背包解释 |
| --- | --- |
| 楼梯高度 `n` | 背包容量 |
| 一次走 `j` 阶 | 选择重量为 `j` 的物品 |
| 步长可重复使用 | 完全背包 |
| `1+2` 与 `2+1` 不同 | 排列计数 |
| 恰好走到第 `n` 阶 | 恰好装满 |

## 3. 状态定义

定义：

$$
\boxed{dp[i]=\text{恰好到达第 }i\text{ 阶的方案数}}
$$

最终答案就是：

$$
\boxed{dp[n]}
$$

## 4. 状态转移：枚举最后一步

对于第 `i` 阶，如果最后一步走了 `j` 阶，那么此前必须已经到达：

$$
i-j
$$

因此所有“到达 $i-j$ 的方案”，都可以在末尾追加一步 `j`，得到一个新的“到达 $i$ 的方案”。

于是：

$$
dp[i] += dp[i-j]
$$

对所有：

$$
1\le j\le m,\qquad j\le i
$$

累加即可。

完整递推为：

$$
\boxed{dp[i]=\sum_{j=1}^{\min(i,m)}dp[i-j]}
$$

<Callout type="tip" title="把 j 理解为“最后一步”最清楚">
只要能明确“最后一步走了多少阶”，前面的部分就被唯一归入 `dp[i-j]`。因此不同结尾不会重复计数，也不会遗漏。
</Callout>

## 5. 为什么 `dp[0] = 1`

初始化：

$$
\boxed{dp[0]=1}
$$

这里的 `1` 表示：

> 从起点到起点存在一种“什么都不走”的空方案。

它不是说真的存在一种爬楼梯动作，而是为了让后续状态能够正确产生。

例如计算 `dp[1]`：

$$
dp[1] += dp[0]
$$

这样才能得到“一步走 1 阶”这一种方案。

如果令：

$$
dp[0]=0
$$

则所有状态都会失去最初的来源。

这与“组合总和 IV”“零钱兑换 II”等计数型背包中的 `dp[0] = 1` 是同一个思想。

## 6. 最关键的遍历顺序

标准代码：

```cpp
for (int i = 1; i <= n; ++i) {
    for (int step = 1; step <= m; ++step) {
        if (i >= step) {
            dp[i] += dp[i - step];
        }
    }
}
```

也就是：

1. 外层遍历楼梯高度 / 背包容量；
2. 内层遍历步长 / 物品。

为什么？

因为本题要求的是**排列数**。

例如 `n = 3, m = 2`：

```text
1 + 2
2 + 1
```

必须分别计数。

当我们计算 `dp[i]` 时，内层枚举“最后一步是什么”，就会自然区分不同顺序。

### 如果物品放在外层会发生什么？

如果写成：

```cpp
for (int step = 1; step <= m; ++step) {
    for (int i = step; i <= n; ++i) {
        dp[i] += dp[i - step];
    }
}
```

这种写法更接近“先决定用了哪些步长种类”，会把不同顺序压成同一组合。

因此：

$$
\boxed{\text{排列计数：容量在外，物品在内}}
$$

这条规律与“组合总和 IV”完全一致。

## 7. 手推 `n = 4, m = 3`

允许步长：

$$
1,2,3
$$

初始化：

```text
dp = [1, 0, 0, 0, 0]
```

### `i = 1`

只有最后一步走 `1`：

$$
dp[1]=dp[0]=1
$$

```text
dp = [1, 1, 0, 0, 0]
```

### `i = 2`

最后一步可以走 `1` 或 `2`：

$$
dp[2]=dp[1]+dp[0]=1+1=2
$$

对应：

```text
1 + 1
2
```

### `i = 3`

$$
dp[3]=dp[2]+dp[1]+dp[0]
$$

$$
=2+1+1=4
$$

对应：

```text
1 + 1 + 1
1 + 2
2 + 1
3
```

### `i = 4`

$$
dp[4]=dp[3]+dp[2]+dp[1]
$$

$$
=4+2+1=7
$$

因此答案为：

$$
\boxed{7}
$$

## 8. 与三道经典题的统一关系

这道题最好不要孤立记忆。

| 题目 | 可选元素 | 是否可重复 | 是否区分顺序 | 本质 |
| --- | --- | --- | --- | --- |
| 爬楼梯 | `1, 2` | 是 | 是 | 线性 DP / 完全背包排列计数 |
| 爬楼梯进阶版 | `1 ~ m` | 是 | 是 | 完全背包排列计数 |
| 组合总和 IV | `nums` | 是 | 是 | 完全背包排列计数 |

从统一视角看，它们都满足：

$$
\boxed{dp[i]=\sum_{x\in S,\ x\le i}dp[i-x]}
$$

其中 $S$ 是允许使用的步长 / 数字集合。

不同题目只是 $S$ 的定义不同。

<Callout type="info" title="真正应该记住的是模型">
当题目问“使用若干可重复元素，按顺序组成目标值，一共有多少种方法”时，应优先联想到完全背包的排列计数，而不是某一道具体题的代码。
</Callout>

## 9. C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<long long> dp(n + 1, 0);
    dp[0] = 1;

    // 排列计数：先遍历容量，再遍历物品
    for (int i = 1; i <= n; ++i) {
        for (int step = 1; step <= m; ++step) {
            if (i >= step) {
                dp[i] += dp[i - step];
            }
        }
    }

    cout << dp[n] << '\n';
    return 0;
}
```

### 复杂度

设楼梯高度为 `n`，最大步长为 `m`：

$$
\boxed{T(n)=O(nm)}
$$

空间复杂度：

$$
\boxed{S(n)=O(n)}
$$

## 10. 高频误区

### 误区一：看到“爬楼梯”就只想到斐波那契

当步长从 `{1, 2}` 扩展为 `{1, 2, ..., m}` 后，二项递推自然变成多项递推。

本质不是“背一个斐波那契公式”，而是：

> 枚举最后一步，从所有合法前驱状态转移过来。

### 误区二：把组合和排列混淆

本题：

```text
1 + 2
2 + 1
```

是两种方案，因此必须按排列数处理。

### 误区三：认为完全背包一定是“物品外层、容量内层”

“完全背包”只决定：

> 同一物品可以重复使用，所以容量更新允许正序。

至于谁放在外层，还取决于：

- 求组合数；
- 求排列数；
- 求最值。

### 误区四：忘记 `dp[0] = 1`

计数型问题中，`dp[0] = 1` 往往表示空方案，是所有后续方案生成的起点。

## 11. 一眼识别模板

当题目同时满足：

- 有一个目标值 `target`；
- 有若干正整数可重复选；
- 要恰好组成目标；
- 不同顺序算不同方案；

可以优先尝试：

```cpp
vector<long long> dp(target + 1, 0);
dp[0] = 1;

for (int sum = 1; sum <= target; ++sum) {
    for (int x : nums) {
        if (sum >= x) {
            dp[sum] += dp[sum - x];
        }
    }
}
```

其核心含义永远是：

> 枚举当前总和，再枚举最后放入哪个元素。

## 13. 本题总结

这道题真正值得掌握的不是代码，而是模型迁移过程：

```text
普通爬楼梯
    ↓ 扩展允许步长
广义线性 DP
    ↓ 把步长看成可重复物品
完全背包
    ↓ 不同顺序视为不同方案
排列计数
```

最终得到：

$$
\boxed{dp[i]=\sum_{j=1}^{\min(i,m)}dp[i-j]}
$$

以及最重要的遍历顺序：

$$
\boxed{\text{容量在外，物品在内}}
$$

掌握这一层关系后，“爬楼梯进阶版”和“组合总和 IV”就不再是两道不同的题，而是同一个动态规划模型的不同外壳。
