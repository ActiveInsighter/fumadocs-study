## 专题六｜全面深化改革开放

<Callout type="info" title="专题总线索">

**为什么改**：改革开放是决定当代中国命运的关键一招 → **往哪里改**：完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化 → **怎样改**：方向正确、人民至上、系统协同、统筹改革发展稳定 → **改革新阶段**：进一步全面深化改革，以推进中国式现代化为主题 → **开放维度**：坚定不移扩大高水平对外开放。

</Callout>

### 一、改革开放为什么是“关键一招”？

#### 1. 改革开放的历史与时代定位

| 教材表述 | 对应层次 | 关键词 |
| --- | --- | --- |
| **党和人民大踏步赶上时代的重要法宝** | 历史进步与现代化发展 | 赶上时代 |
| **坚持和发展中国特色社会主义的必由之路** | 社会主义建设道路 | 必由之路 |
| **决定当代中国命运的关键一招** | 国家发展命运 | 关键一招 |
| **决定实现“两个一百年”奋斗目标和民族复兴的关键一招** | 发展目标与民族复兴 | 目标实现 |
| **当代中国最显著的特征、最壮丽的气象** | 时代特征 | 最显著 |
| **党的一次伟大觉醒、中国人民和中华民族发展史上的一次伟大革命** | 理论和实践创新 | 伟大觉醒、伟大革命 |

> **教材判断：只有社会主义才能救中国，只有改革开放才能发展中国、发展社会主义、发展马克思主义。**

“改革开放只有进行时，没有完成时”侧重改革的**长期性、持续性**，不是说一切制度和政策都应毫无方向地不断变化。

#### 2. 三次具有标志意义的三中全会

<Steps>
<Step>

**党的十一届三中全会（1978 年）**：开启**改革开放和社会主义现代化建设新时期**。

</Step>
<Step>

**党的十八届三中全会（2013 年）**：作出**全面深化改革**的重大部署，推动改革由局部探索、破冰突围向**系统集成、全面深化**转变。

</Step>
<Step>

**党的二十届三中全会（2024 年）**：部署**进一步全面深化改革、推进中国式现代化**，是十八届三中全会以来全面深化改革的**实践续篇**和新征程上的**时代新篇**。

</Step>
</Steps>

| 问法 | 精准对应 |
| --- | --- |
| **改革开放历史新时期的开启** | 十一届三中全会 |
| **全面深化改革的系统部署** | 十八届三中全会 |
| **进一步全面深化改革、推进中国式现代化** | 二十届三中全会 |

<Callout type="warn" title="会议“届次”不能混淆">

**十一届—十八届—二十届**三中全会分别连接“改革开放—全面深化改革—进一步全面深化改革”。“三中全会”三个字相同，不表示会议任务完全一样。

</Callout>

### 二、全面深化改革必须坚持正确方向

#### 1. 改什么、怎么改的根本标准

必须有利于**坚持和改善党的全面领导、坚持和完善中国特色社会主义制度**，这是判断改革方向的重要根本标准。改革不是放弃根本制度，而是通过改革使制度更加成熟、更加定型。

#### 2. 出发点和落脚点：人民利益

**促进社会公平正义、增进人民福祉**，体现社会主义改革开放的出发点和落脚点。相关措施最终要有利于**更好实现、维护人民利益**。

#### 3. “三个进一步解放”：既是目的，也是条件

| 三项内容 | 理论意义 | 容易误写的地方 |
| --- | --- | --- |
| **进一步解放思想** | 开启改革开放事业与推进全面深化改革的重要思想前提 | 不是思想随意化 |
| **进一步解放和发展社会生产力** | 改革开放的鲜明特征和首要任务 | 不等于仅追求速度 |
| **进一步解放和增强社会活力** | 社会主义改革的内在要求和基本目的 | 不等于取消必要治理 |

<Callout type="tip" title="把“方向、目的、条件”三层分开">

**改革方向**：坚持党的全面领导和中国特色社会主义制度。**人民层面的出发点和落脚点**：公平正义、人民福祉。**推动改革的条件和目标**：解放思想、发展生产力、增强社会活力。

</Callout>

### 三、全面深化改革的总目标与治理现代化

#### 1. 总目标必须完整背诵

> **完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。**

- **前半句**规定改革的**根本方向**。
- **后半句**明确改革的**鲜明指向和时代要求**。

不能只背“治理现代化”而忘记“完善和发展中国特色社会主义制度”，也不能把两部分理解为相互排斥。

#### 2. 治理体系与治理能力怎样区分？

<Tabs items={['国家治理体系', '国家治理能力', '二者关系']}>
<Tab value="国家治理体系">

是在党的领导下管理国家的**制度体系**，侧重国家治理的**制度安排、组织结构、运行规则**。

</Tab>
<Tab value="国家治理能力">

运用国家制度管理社会各方面事务的**实际能力**，侧重制度的执行、协调和治理效能。

</Tab>
<Tab value="二者关系">

二者是**有机整体、相辅相成**：好的制度体系为提高治理能力提供基础；治理能力提升才能充分发挥制度体系的实际效能。

</Tab>
</Tabs>

**三个要求**：坚定中国特色社会主义**制度自信**；更好发挥**制度优势**；把制度优势**转化为国家治理效能**。

<Callout type="warn" title="治理体系 ≠ 治理能力">

“治理体系现代化”强调**制度与组织运行的体系化**；“治理能力现代化”强调**能够有效运用这些制度解决问题**。只有制度设计而没有执行能力，不能自动产生治理成效。

</Callout>

### 四、改革方法论：系统、试点、稳定与法治

| 方法 | 内涵 | 典型材料 |
| --- | --- | --- |
| **系统性、整体性、协同性** | 加强改革间的统筹协调，不碎片化推进 | 多部门联动、总体方案 |
| **顶层设计与摸着石头过河相结合** | 既重全局规划，也重基层探索和实践检验 | 总体制度设计与试点探索并用 |
| **统筹改革发展稳定** | 兼顾改革力度、发展速度、社会可承受程度 | 在稳定中推进改革，在改革发展中促进稳定 |
| **胆子要大、步子要稳** | 既敢于破解难题，也遵循规律、审慎推进 | 攻坚克难与稳妥实施 |
| **重大改革于法有据** | 重大改革与法治建设衔接 | 授权立法、依法推进改革 |

#### 改革、发展、稳定的三种定位

| 概念 | 精准位置 |
| --- | --- |
| **改革** | 经济社会发展的**强大动力** |
| **发展** | 解决一切经济社会问题的**关键** |
| **稳定** | 改革发展的**前提** |

**重要结合点**：把**改善人民生活**作为正确处理改革发展稳定关系的结合点。不能以“改革越快越好”取代“改革力度、发展速度与社会可承受程度相统一”。

### 五、进一步全面深化改革：主题、主线、目标、原则

#### 1. 为什么“改革开放永无止境”？

1. 由**社会基本矛盾运动规律**决定：生产力不断发展，生产关系和上层建筑需要相应调整。
2. 是总结世界社会主义实践历史经验的认识。
3. 是在新征程推进党和人民事业发展的现实要求。

这与马原“生产力和生产关系、经济基础和上层建筑的矛盾”直接对应。

#### 2. “进一步全面深化改革”的五个定位

| 提问 | 准确回答 |
| --- | --- |
| **主题** | **推进中国式现代化** |
| **主线** | **制度建设** |
| **牵引** | **经济体制改革** |
| **出发点和落脚点** | **促进社会公平正义、增进人民福祉** |
| **工作要求** | **更加注重系统集成、更加注重突出重点、更加注重改革实效** |

**总目标**：**继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化**。与全面深化改革总目标具有连续性，其中“继续”体现新阶段的接续推进。

#### 3. “六个坚持”：改革的重要原则

1. **坚持党的全面领导**。
2. **坚持以人民为中心**。
3. **坚持守正创新**。
4. **坚持以制度建设为主线**。
5. **坚持全面依法治国**。
6. **坚持系统观念**。

**党的领导**是进一步全面深化改革、推进中国式现代化的**根本保证**。

#### 4. 中国式现代化相关十个定位词

| 定位词 | 对应内容 |
| --- | --- |
| **重要保障**（经济体制） | 高水平**社会主义市场经济体制** |
| **首要任务** | **高质量发展** |
| **基础性、战略性支撑** | **教育、科技、人才** |
| **发挥市场经济体制优势的内在要求** | **科学的宏观调控、有效的政府治理** |
| **必然要求**（城乡关系） | **城乡融合发展** |
| **鲜明标识** | **开放** |
| **本质要求**（民主领域） | 发展**全过程人民民主** |
| **重要保障**（法治领域） | **法治** |
| **重大任务**（社会领域） | 在发展中**保障和改善民生** |
| **行稳致远的重要基础** | **国家安全** |

<Callout type="tip" title="定位词取决于限定语">

“重要保障”可能指**高水平社会主义市场经济体制**，也可能指**法治**；必须看题目问的是经济制度还是法治领域。**不能孤立背关键词，而忽略提问对象。**

</Callout>

### 六、坚定不移扩大高水平对外开放

#### 1. 为什么要扩大开放？

- **开放也是改革**，以开放促改革、促发展是重要历史经验。
- 中国发展与世界发展相互联系，**开放带来进步，封闭必然落后**。
- 高水平开放是**推动高质量发展的强大动力**、满足人民美好生活需要的**内在要求**、推动经济全球化的**主动作为**、构建人类命运共同体的**重要举措**。

#### 2. 高水平开放：三个角度

<Tabs items={['制度型开放', '自主与单边开放', '以民生为目的']}>
<Tab value="制度型开放">

**制度型开放是高水平对外开放的重要标志**，突出规则、规制、管理、标准等方面对接国际高标准。

</Tab>
<Tab value="自主与单边开放">

强调更加积极的**自主开放**，以及面向**最不发达国家的单边开放**等形式，体现主动扩大市场开放。

</Tab>
<Tab value="以民生为目的">

**增进民生福祉是对外开放的根本目的**，不宜把开放本身或外贸规模增长当作脱离人民生活的终极目标。

</Tab>
</Tabs>

**开放与独立自主不是二选一**：强调高水平对外开放的同时，仍需保持发展主动权、维护经济安全。

### 七、常考易错项

<Accordions>
<Accordion title="错误：党的十八届三中全会开启了改革开放和社会主义现代化建设新时期">

开启新时期的是**十一届三中全会**；十八届三中全会部署**全面深化改革**。

</Accordion>
<Accordion title="错误：改革的总目标就是建立完全不需要国家治理能力的制度">

总目标是**完善和发展中国特色社会主义制度、推进治理体系和治理能力现代化**，两方面不可拆开。

</Accordion>
<Accordion title="错误：改革发展稳定中，改革是前提，稳定是动力">

**改革是动力，发展是关键，稳定是前提**；改善人民生活是正确处理三者关系的结合点。

</Accordion>
<Accordion title="错误：进一步全面深化改革的主题是单纯追求经济增长速度">

主题是**推进中国式现代化**，其主线是**制度建设**，牵引是**经济体制改革**。

</Accordion>
<Accordion title="错误：对外开放的根本目的就是扩大进出口额">

高水平开放强调规则、体制和开放合作，而**增进民生福祉是根本目的**。

</Accordion>
</Accordions>

**考前速背：**&#x2060;十一—十八—二十届三中全会；改革**方向：制度**，**总目标：制度完善＋治理现代化**；方法论**系统协同、顶层与试点、改革发展稳定、于法有据**；进一步改革**主题中国式现代化、主线制度、牵引经济、六个坚持**；开放**制度型、主动开放、民生福祉**。
