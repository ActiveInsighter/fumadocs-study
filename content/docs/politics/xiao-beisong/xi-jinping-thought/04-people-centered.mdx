## 专题五｜坚持以人民为中心

<Callout type="info" title="专题主线：人民地位 → 党的立场 → 工作方法 → 发展成果">

**人民是历史的创造者**，决定了坚持以人民为中心的理论根据；**人民立场是中国共产党的根本政治立场**，回答“为了谁”；**群众路线是党的生命线和根本工作路线**，回答“依靠谁、怎样做”；**促进全体人民共同富裕**，体现发展的价值取向与目标要求。

</Callout>

### 一、如何理解“江山就是人民，人民就是江山”？

这句话可以从四个角度把握，不能只从情感层面理解。

| 理解角度 | 核心原理 | 答题关键词 |
| --- | --- | --- |
| **理论依据** | 人民是历史的创造者、社会进步的主体力量 | 历史唯物主义、人民主体 |
| **历史经验** | 紧紧依靠人民、为人民利益奋斗，是党从胜利走向胜利的重要经验 | 民心、群众支持、历史经验 |
| **现实依据** | 国家政权性质决定人民在国家中的地位，人民的主人翁地位要求把人民放在最高位置 | 人民当家作主、国家性质 |
| **党的性质宗旨** | 坚持人民立场与党的性质、宗旨内在统一 | 性质宗旨、为人民服务 |

#### 1. 人民是历史创造者：理论根源

历史唯物主义认为，人民群众通过创造物质财富、精神财富和推动社会变革创造历史。**人民不是社会发展的被动接受者，而是历史活动的主体力量。**

这同第一模块“人民群众在历史发展中的作用”直接相连：唯物史观强调人民群众的决定性作用，而非把历史进步仅归功于某位杰出人物。

#### 2. 民心是最大的政治：历史经验

教材强调，始终同人民在一起、为人民利益而奋斗、依靠人民创造历史伟业，是中国共产党取得历史性成就的重要原因。**民心向背关系事业兴衰成败**。

#### 3. 人民主人翁地位：现实要求

人民在一个国家的地位由国家的政权性质决定。**人民当家作主**要求党和国家的各项工作重视人民诉求、维护人民利益、回应人民关切。

#### 4. 党的性质宗旨：根本依据

坚持以人民为中心不是临时采取的措施，而是与党的性质宗旨相联系的根本立场。注意区分**理论依据**（唯物史观）与**组织政治属性的依据**（党的性质宗旨），两者共同支撑“人民至上”。

### 二、人民立场：党的根本政治立场

> **人民立场是中国共产党的根本政治立场，是党区别于其他政党的显著标志。**

#### 1. 为什么要尊重人民历史地位？

- 尊重人民主体地位、发挥人民主体作用，是总结党的百年奋斗历史经验得到的重要认识。
- **保持党同人民群众的血肉联系**，关系党的生死存亡、兴旺发达。
- 把人民利益作为党和国家事业发展的重要出发点和落脚点，是以人民为中心的执政理念的具体体现。

<Callout type="warn" title="两个“最大”必须分开记忆">

- 我们党**最大的政治优势**：**密切联系群众**。
- 党**执政后的最大危险**：**脱离群众**。

“优势”与“危险”的内容、方向相反，但都围绕党群关系，不能把二者调换。

</Callout>

#### 2. 坚持人民至上：价值取向

**人民至上**既是党的百年奋斗重要历史经验，也是新时代治国理政的根本价值取向。可分为“目标—评价—政绩观”三层：

<Tabs items={['奋斗目标', '评价主体', '正确政绩观']}>
<Tab value="奋斗目标">

**人民对美好生活的向往就是党的奋斗目标。** 这回答政策和发展的价值归宿。

</Tab>
<Tab value="评价主体">

**人民是党的工作的最高裁决者和最终评判者。** 不能以单纯形式指标替代人民的实际感受和满意程度。

</Tab>
<Tab value="正确政绩观">

**为民造福是最大政绩**；树立和践行正确政绩观，**起决定性作用的是党性**。二者分别回答“什么是政绩”与“正确政绩观的决定因素”。

</Tab>
</Tabs>

| 常见考题表达 | 对应结论 |
| --- | --- |
| 党的奋斗目标 | 人民对美好生活的向往 |
| 党的工作最高裁决者、最终评判者 | **人民** |
| 做好一切工作的价值取向和根本标准 | **让群众满意** |
| 最大政绩 | **为民造福** |
| 正确政绩观起决定性作用的因素 | **党性** |

### 三、群众路线：从“知”到“行”

#### 1. 地位及基本含义

**群众路线是党的生命线和根本工作路线**，也是党始终坚持的根本工作方法，是保持活力和战斗力的重要传家宝。

联系毛泽东思想活的灵魂，可记住完整表述：**一切为了群众，一切依靠群众，从群众中来，到群众中去。**

#### 2. 贯彻群众路线的三个抓手

<Steps>
<Step>

**“知”是基础和前提。** 深入了解群众真实处境、实际需要和具体困难，而不是依据想象代替调查。

</Step>
<Step>

**“行”是重点和关键。** 将了解的情况转化为实际政策和行动，在实践中解决问题。

</Step>
<Step>

**调查研究是有效途径。** 通过调查研究获取真知灼见，使决策与现实问题相联系。

</Step>
</Steps>

<Callout type="tip" title="选择题判断法">

材料强调**深入基层、听取诉求、开展调研**，常对应群众路线与调查研究；强调**办成实事、解决问题、检验效果**，则体现由“知”向“行”的落实。**只听取意见但不落实**，不能称为完整贯彻群众路线。

</Callout>

### 四、共同富裕：内涵、时间目标与实现原则

#### 1. 为什么共同富裕重要？

| 定位 | 准确说法 |
| --- | --- |
| **本质要求** | **共同富裕是中国特色社会主义的本质要求** |
| **现代化特征** | 是**中国式现代化的重要特征**，也是教材讨论中区别于西方现代化的重要标志 |
| **重大政治意义** | 不仅是经济问题，也是关系**党的执政基础**的重大政治问题 |
| **人的发展** | 促进共同富裕与促进**人的全面发展**高度统一 |

#### 2. 如何准确理解“共同”？

共同富裕包含**全体人民共同富裕**和**物质生活、精神生活都富裕**两个层次。

<Callout type="warn" title="四个“不是”是选择题高频陷阱">

共同富裕**不是少数人的富裕，不是整齐划一的平均主义，不是所有人同时富裕，也不是所有地区同时达到同一个富裕水平**。

正确理解：**全体人民、物质与精神并重、允许合理差异、循序渐进推进**。

</Callout>

#### 3. 两个阶段性目标

| 时间节点 | 目标定位 |
| --- | --- |
| **2035 年** | 全体人民共同富裕**取得更为明显的实质性进展** |
| **本世纪中叶** | 全体人民共同富裕**基本实现** |

“取得进展”与“基本实现”**不能颠倒**，也不要把“2035 年基本实现社会主义现代化”与“共同富裕基本实现”的时间节点混淆。

#### 4. 扎实推进共同富裕的四项原则

1. **鼓励勤劳创新致富**：鼓励通过诚实劳动与创新创造财富。
2. **坚持基本经济制度**：从我国所有制、分配制度和市场经济体制的制度条件出发。
3. **尽力而为、量力而行**：既积极推进，又考虑客观条件和实际承受能力。
4. **坚持循序渐进**：承认长期性、阶段性，避免急于求成、整齐划一。

#### 5. 方法论：统一“做大蛋糕”与“分好蛋糕”

共同富裕要求在**高质量发展中**持续改善分配关系和公共服务，不能把“富裕”理解为不发展生产力、只在既有成果中平均分配；也不能只强调扩大总量而忽视公平共享。

此处是帮助理解的概括，具体分配制度在专题九中展开。

### 五、高频辨析与错题复盘

<Accordions>
<Accordion title="错误：坚持以人民为中心的主要依据只是党的情感承诺">

不准确。它与**人民群众创造历史的唯物史观原理、历史经验、人民的国家主人翁地位、党的性质宗旨**密切相关。

</Accordion>
<Accordion title="错误：党最大的政治优势是脱离群众也能独立完成任务">

恰恰相反：**最大的政治优势是密切联系群众，执政后的最大危险是脱离群众**。

</Accordion>
<Accordion title="错误：衡量政绩，最根本的是统计数据越大越好">

不能脱离人民利益。教材强调**为民造福是最大政绩**、群众满意是根本标准；树立正确政绩观起决定性作用的是**党性**。

</Accordion>
<Accordion title="错误：共同富裕就是所有地区、所有人同时达到相同收入">

这属于**平均主义和同步富裕**的错误理解。共同富裕强调全体人民分享发展成果，同时承认地区、个人发展条件差异和长期渐进过程。

</Accordion>
<Accordion title="错误：2035 年共同富裕已基本实现">

按照本专题原资料的时间目标，**2035 年是取得更为明显的实质性进展；本世纪中叶是基本实现**。

</Accordion>
</Accordions>

**速背闭环：**人民是历史创造者 → **民心是最大政治** → **人民立场是根本政治立场** → **密切联系群众（最大优势）/脱离群众（最大危险）** → **为民造福是最大政绩** → **共同富裕：全体、物质精神、非平均非同步、四原则、两节点**。
