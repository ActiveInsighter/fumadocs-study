## 专题十四｜以保障和改善民生为重点加强社会建设

<Callout type="info" title="本专题核心：一个目标、一个关系、四项民生工作">

**让人民生活幸福是“国之大者”。增进民生福祉是发展的根本目的，也是社会主义生产的根本目的。**

- **重要关系**：发展是解决民生问题的&#x2060;**“总钥匙”**，民生是发展的&#x2060;**“指南针”**。
- **工作思路**：**坚守底线、突出重点、完善制度、引导预期**。
- **四项重点**：完善**分配制度**、实施**就业优先战略**、健全**社会保障体系**、推进**健康中国建设**。

</Callout>

### 一、为什么保障和改善民生是社会建设的重点？

#### 1. 增进民生福祉的五个定位

| 角度 | 必背表述 | 理解重点 |
| --- | --- | --- |
| **人民幸福** | **民生是人民幸福之基**，是人民最关心的问题 | 直接关乎群众切身利益 |
| **中国式现代化** | **在发展中保障和改善民生**是中国式现代化的**重大任务** | 发展成果要体现在生活改善上 |
| **执政宗旨** | 增进民生福祉是**立党为公、执政为民的本质要求** | 体现以人民为中心 |
| **生产目的** | 增进民生福祉是**社会主义生产的根本目的**，也是发展的**根本目的** | 不能单以增长数字代替生活质量 |
| **现代化出发点** | 人民对美好生活的向往是现代化建设的**出发点和落脚点** | 让人民生活幸福是**国之大者** |

<Callout type="tip" title="区分‘根本目的’与‘物质基础’">

发展经济、增加生产力是改善民生的重要**物质基础**；但经济发展本身不是脱离人民需要的终点。教材将**增进民生福祉**概括为发展的**根本目的**，强调发展成果由人民共享。

</Callout>

#### 2. 发展与民生的辩证关系

<Tabs items={['发展支撑民生', '民生促进发展']}>
<Tab value="发展支撑民生">

**发展是解决民生问题的“总钥匙”**，是改善民生的**物质基础**。发展创造就业、财政收入、公共服务资源和更丰富的产品供给。离开经济社会发展的实际条件，保障与改善民生便缺乏可持续基础。

</Tab>
<Tab value="民生促进发展">

**民生是发展的“指南针”**。改善收入、就业、教育、医疗、养老等条件，可以增强居民消费预期、减少后顾之忧、提高劳动积极性，进而**扩大内需、催生增长点**，反过来促进发展。

</Tab>
</Tabs>

**答题主线**：坚持**在发展中保障和改善民生**，又通过持续改善民生**推动经济社会高质量发展**，形成相互促进的良性循环。

### 二、保障和改善民生的总体原则

| 原书考点 | 对应内容 | 怎样识别 |
| --- | --- | --- |
| **工作思路** | **坚守底线、突出重点、完善制度、引导预期** | 关注民生工作的组织方式 |
| **重中之重** | 解决人民群众**最关心、最直接、最现实的利益问题** | 关注民生问题优先次序 |
| **重要方针** | **尽力而为、量力而行** | 关注目标与资源条件的匹配 |
| **重要原则** | **人人尽责、人人享有** | 关注共同建设、共享成果 |

#### 怎样理解“尽力而为、量力而行”？

**尽力而为**：在条件允许的情况下积极回应人民的现实需要，持续改善民生；**量力而行**：立足发展阶段、财政能力和公共资源供给水平，形成**可持续的政策安排**。

两者不是“只做一点”与“花钱不受约束”的二选一，而是**积极作为与尊重客观条件的统一**。

<Callout type="warn" title="“人人尽责、人人享有”不是“人人只享有，不承担责任”">

民生保障强调广泛参与与成果共享，体现**权利与责任的联系**；同时要关注不同群体条件和现实困难，不能机械理解成所有人必须承担相同数量的责任。

</Callout>

### 三、完善收入分配制度

#### 1. 收入分配的定位

**收入分配是民生之源**，是改善民生、实现发展成果由人民共享**最重要、最直接的方式**。

**分配制度是促进共同富裕的基础性制度**。要构建**初次分配、再分配、第三次分配协调配套**的制度体系。

#### 2. 三次分配：谁发挥什么作用？

| 分配环节 | 主体机制 | 关键政策和措施 | 易错点 |
| --- | --- | --- | --- |
| **初次分配** | 市场主体与生产要素分配机制 | 提高**劳动报酬在初次分配中的比重**；完善工资合理增长机制；探索通过土地、资本等要素的使用权、收益权增加中低收入群体要素收入 | 不能只按资本收益而忽视劳动者权益 |
| **再分配** | 国家公共政策和财政社会保障机制 | 加强**税收、社会保障、转移支付**调节，提高调节精准性 | **税收、社保、转移支付**是最典型识别词 |
| **第三次分配** | 社会力量依法自愿参与 | 支持企业、社会组织和个人参与**公益慈善事业** | **慈善捐赠不是政府强制征税** |

<Steps>
<Step>

**初次分配重基础。** 劳动者通过劳动获得报酬，生产要素依法参与分配；政策强调完善工资增长机制，维护劳动者权益，逐步壮大**中等收入群体**。

</Step>
<Step>

**再分配重调节。** 通过税收、社会保障和转移支付等制度调节收入分配，促进基本公共服务和社会公平。

</Step>
<Step>

**第三次分配重补充。** 通过自愿公益慈善等社会参与方式发挥补充作用，不取代前两次分配，也不等同于行政强制分配。

</Step>
</Steps>

#### 3. 三种情境快速判题

<Tabs items={['提高工资收入', '税收与社保', '公益慈善']}>
<Tab value="提高工资收入">

材料强调企业完善工资增长机制、保障劳动报酬、劳动者通过生产经营获取收入时，优先判断为**初次分配**。

</Tab>
<Tab value="税收与社保">

材料强调个税调节、社会保险和社会救助、财政向困难群体转移支付时，优先判断为**再分配**。

</Tab>
<Tab value="公益慈善">

材料强调公益基金会、个人自愿捐赠、企业社会责任慈善项目时，优先判断为**第三次分配**。

</Tab>
</Tabs>

<Callout type="tip" title="特别容易混淆的一句话">

**分配制度是促进共同富裕的“基础性制度”**，而**就业是“最基本的民生”**，**社会保障是“基本制度保障”**。三个“基本”修饰的对象不同。

</Callout>

### 四、实施就业优先战略

#### 1. 就业为什么放在优先位置？

1. **就业是最基本的民生**。
2. 就业是最大的**民生工程、民心工程、根基工程**。
3. 是劳动者赖以生存发展的**基础**，是共享经济发展成果的**基本条件**。
4. 就业状况是民生改善的&#x2060;**“温度计”**，也是国家长治久安的重要支撑。

#### 2. 实施就业优先战略的政策含义

把就业放在经济社会发展的**优先位置**，统筹经济政策与就业目标，扩大就业容量，促进劳动者增收和生活改善。

**新时代新征程就业工作的新定位、新使命：促进高质量充分就业。**

| 关键词 | 含义侧重点 |
| --- | --- |
| **充分就业** | 尽可能创造更多适合劳动者的就业机会，缓解结构性与总量性压力 |
| **高质量就业** | 重视劳动者权益、收入、稳定性和发展机会等就业质量因素 |
| **高质量充分就业** | 同时关注**数量与质量**，不能只用登记就业人数替代全部政策目标 |

**易错**：就业优先不意味着一切经济活动都以短期岗位数量为唯一目标，而是使经济社会发展与就业质量、就业机会形成良性联系。

### 五、健全社会保障体系

#### 1. 社会保障的地位和作用

**社会保障**是保障改善民生、维护社会公平、增进人民福祉的**基本制度保障**，也是促进经济社会发展、共享改革发展成果的重要制度安排。

| 社会保障的三种作用 | 怎样理解 |
| --- | --- |
| **民生保障安全网** | 在年老、疾病、失业等风险情境下提供基本保障 |
| **收入分配调节器** | 通过社会保障安排促进公平，缩小部分群体的风险差异 |
| **经济运行减震器** | 在经济波动时发挥稳定预期和保障基本生活的作用 |

#### 2. 社会保障体系的重点和方向

- **根本出发点和落脚点**：**增进民生福祉、促进社会公平**。
- **新时代加强社会建设的重要着力点**：健全完善社会保障体系。
- **健全完善的三个重点**：**增强公平性、适应流动性、保证可持续性**。
- **社会保障体系的主体**：**社会保险**。
- **总体建设目标**：完善**覆盖全民、统筹城乡、公平统一、安全规范、可持续的多层次社会保障体系**。

<Callout type="warn" title="社会保险 ≠ 社会保障全部内容">

**社会保险是社会保障体系的主体**，但整个体系还包括其他不同层次的保障安排。题目问“主体”与“全部组成”时应特别注意。

</Callout>

#### 3. 三个“重点”的理解

| 关键词 | 政策含义 |
| --- | --- |
| **公平性** | 减少不合理的保障差异，提升制度公平与可及性 |
| **流动性** | 适应跨地区、跨职业等就业和人口流动的现实需要 |
| **可持续性** | 兼顾当期保障水平、基金长期收支和未来人口结构变化 |

这三个目标可能需要**统筹协调**，不能只强调某一方面而忽视另两方面。

### 六、推进健康中国建设

原资料在本专题对健康中国的论述较集中，核心是四个定位：

1. **人民健康是社会文明进步的基础**。
2. **人民健康是民族昌盛和国家富强的重要标志**。
3. 保障和促进人民健康，是促进**人的全面发展**的必然要求。
4. **人民健康是社会主义现代化的重要标志**。

**理解提示**：健康中国建设不仅涉及医疗服务，也体现人口健康、公共卫生和生活质量与现代化建设之间的密切联系。在答题中应把握**健康对人的全面发展与现代化的基础作用**，而不是只理解成医院数量增长。

### 七、各项民生政策如何形成整体？

| 民生任务 | 直接解决的问题 | 同其他工作的联系 |
| --- | --- | --- |
| **分配制度** | 发展成果怎样更加合理地分配 | 提升劳动收入、促进共同富裕 |
| **就业优先** | 劳动者如何取得收入和发展机会 | 就业为收入分配与社会保障提供基础 |
| **社会保障** | 如何应对生活风险、兜住民生底线 | 减少后顾之忧、稳定消费和预期 |
| **健康中国** | 如何保障人的健康和全面发展 | 人口健康提升生活质量和劳动能力 |

**整体逻辑**：以**高质量发展**为物质基础，坚持**尽力而为、量力而行**，通过收入分配、就业、社会保障和健康建设推进民生改善，使发展成果更好惠及人民。

## 专题十五｜在共建共治共享中推进社会治理现代化

<Callout type="info" title="专题总纲：方法—体系—主体—基层">

**加强和创新社会治理**，要在党的领导下，发挥政府主导作用，推动社会多元主体参与，维护人民群众根本利益。

- **四种治理方法**：系统治理、依法治理、综合治理、源头治理。
- **七个体系要素**：党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑。
- **三大理念**：**共建是基础、共治是关键、共享是目标**。
- **基层落点**：城乡社区是社会治理的最基本单元，基层治理是国家治理的基石。

</Callout>

### 一、为什么必须加强和创新社会治理？

社会治理直接关系**国家长治久安、社会安定有序、人民安居乐业**。它不是单靠政府某个部门解决个别问题，而是通过完善规则、协商协调和多元参与，妥善处理社会关系、公共事务与各种风险。

| 考查角度 | 准确表述 | 理解抓手 |
| --- | --- | --- |
| **根本目的** | 维护人民群众**根本利益** | 最终服务人民生活和社会安定 |
| **领导与主导** | **党的领导**，政府**主导** | 领导、负责、参与不是同一层次 |
| **参与基础** | 社会**多元主体参与** | 不是政府单方面包办 |
| **目标导向** | 构建**共建共治共享**社会治理格局 | 把参与过程与治理成果联系起来 |

#### 四种治理方法有什么不同？

<Tabs items={['系统治理','依法治理','综合治理','源头治理']}>
<Tab value="系统治理">

把社会治理问题放到**相互联系的整体系统**中，统筹政府部门、社会组织、基层自治主体和群众力量，避免各自为政、头痛医头。

**识别材料**：跨部门联动、上下协同、区域协作、统筹资源。

</Tab>
<Tab value="依法治理">

使治理活动有明确的**法律规则、程序与权利保障**，依法规范公共权力和社会行为。

**识别材料**：依照法定权限、依法行政、依法调解纠纷、规范执法。

</Tab>
<Tab value="综合治理">

综合运用**行政、法律、经济、教育、协商等多种方式**，因事制宜解决复杂问题。

**识别材料**：多种措施共同发力、综合施策、协同整治。

</Tab>
<Tab value="源头治理">

把治理重心前移到**问题产生的原因和风险形成的初期**，重视预防、排查和及时化解矛盾。

**识别材料**：预防在先、风险排查、化解在萌芽状态、抓早抓小。

</Tab>
</Tabs>

<Callout type="warn" title="辨析：四种方法是相互配合的治理要求">

“源头治理”并非不处理已经出现的问题；“依法治理”也不是只依靠处罚。现实治理可以同时体现**系统统筹、依法处理、综合施策和源头预防**。选择题应根据题干最突出的做法判断。

</Callout>

### 二、完善社会治理体系：七个要素与一个理念

#### 1. 七个要素完整记忆

> **党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑。**

| 要素 | 主要作用 | 常见混淆 |
| --- | --- | --- |
| **党委领导** | 把握政治方向、统筹协调 | 不等于政府负责的行政管理职能 |
| **政府负责** | 依法履行公共服务和治理职责 | 不等于政府包揽一切社会事务 |
| **民主协商** | 通过沟通、讨论形成共识 | 不等于放弃法律规则 |
| **社会协同** | 发挥社会组织等力量作用 | 不等于以社会组织代替政府 |
| **公众参与** | 保障群众在社会治理中的主体参与 | 不等于仅在事后被动接受结果 |
| **法治保障** | 以法治规范权责、程序和救济 | 不是脱离法定程序的任意决定 |
| **科技支撑** | 利用数字技术提升治理效能 | 技术手段不能代替制度与人的判断 |

**快速背诵分组**：**领导负责（2）—协商协同参与（3）—法治科技支撑（2）**。

#### 2. 共建、共治、共享的层次

<Steps>
<Step>

#### 共建是基础

在社会治理中共同参与**制度、平台、组织、资源和能力建设**，为治理提供基础条件。

</Step>
<Step>

#### 共治是关键

各方在治理过程中形成**合理分工、互动协商、协同参与**的机制，推动问题解决。

</Step>
<Step>

#### 共享是目标

治理成果最终体现为社会秩序、公平正义、公共服务和人民群众**获得感、幸福感、安全感**的提升。

</Step>
</Steps>

**三者不是并列口号**：共建提供条件、共治形成过程、共享体现目标。不能把“共治是基础”“共建是最终目标”随意互换。

#### 3. 社会治理共同体

建设**人人有责、人人尽责、人人享有**的社会治理共同体：

- **人人有责**：社会成员共同承担与自身角色和能力相适应的社会责任。
- **人人尽责**：将参与治理落实为具体行动与履责机制。
- **人人享有**：推动治理成果惠及全体人民。

<Callout type="tip" title="与专题十四民生原则的联系">

民生建设强调**人人尽责、人人享有**；社会治理共同体进一步强调**人人有责、人人尽责、人人享有**。两者都体现人民参与和成果共享，但不要漏写社会治理共同体中的&#x2060;**“有责”**。

</Callout>

### 三、城乡社区治理：为什么要向基层下沉？

#### 1. 基层治理的三个定位

| 关键词 | 对应定位 |
| --- | --- |
| **基层治理** | **国家治理的基石** |
| **城乡社区** | **社会治理最基本的单元** |
| **联系服务居民群众** | 党和政府联系、服务群众的&#x2060;**“最后一公里”** |

社会治理的重心必须**向基层下移、落实到城乡社区**，努力建设**和谐有序、绿色文明、创新包容、共建共享**的幸福家园。

#### 2. 基层治理中不同主体如何定位？

- **基层党组织**：发挥**领导核心作用**。
- **基层政府**：发挥**主导作用**。
- **基层群众性自治组织**：发挥**基础作用**。
- **社会与居民群众**：依法参与公共事务，形成政府治理、社会调节与居民自治的**良性互动**。

<Callout type="warn" title="三种‘作用’必须准确配对">

问基层组织作用时，按**党组织领导核心—政府主导—群众性自治组织基础**记忆；这与上一节的七要素并不矛盾，只是更聚焦城乡社区治理的组织结构。

</Callout>

#### 3. 新时代“枫桥经验”与“浦江经验”

<Tabs items={['新时代“枫桥经验”','“浦江经验”']}>
<Tab value="新时代“枫桥经验”">

突出**坚持党的领导、依靠群众、预防在前、调解优先、就地解决矛盾**等基层治理取向，把矛盾纠纷尽可能化解在基层、化解在萌芽状态。

**材料识别**：网格走访、人民调解、邻里纠纷前端化解、群防群治。

</Tab>
<Tab value="“浦江经验”">

突出**领导干部下访接访、深入基层解决群众反映的问题**，使诉求办理更加贴近基层实际。

**材料识别**：领导干部下基层接访、带着问题到一线、推动群众诉求就地解决。

</Tab>
</Tabs>

两者都服务于完善**新形势下正确处理人民内部矛盾的机制**，但具体切入点不同：前者更强调**基层预防化解**，后者更强调**领导干部下访解决问题**。

#### 4. 市域社会治理现代化

**市域**是把风险隐患**解决在基层、化解在萌芽状态**的重要治理层级，处于推进基层治理现代化的前线位置。

- **“市域”并非“城乡社区”的同义词**：一个是更高层次的区域协调平台，一个是贴近居民的基本治理单元。
- 要提升市域统筹、风险预防和跨部门协调能力，支持基层治理并妥善应对跨区域问题。

### 四、典型题干怎么判断？

| 材料出现 | 优先联系的原理 | 原因 |
| --- | --- | --- |
| 多部门联合制定方案、共同处置风险 | **系统治理、综合治理** | 注重整体协调和多种手段 |
| 纠纷处理有法可依、程序透明 | **依法治理** | 治理要依据法律规则 |
| 矛盾在社区网格被提前发现并调解 | **源头治理、枫桥经验** | 重点是预防和基层化解 |
| 领导干部深入基层集中接访 | **浦江经验** | 下访接访是关键动作 |
| 居民议事协商后共同改造公共空间 | **民主协商、公众参与、共建共治** | 体现主体参与与协商解决 |
| 解决风险的同时改善所有居民的公共服务 | **共享** | 着眼治理成果惠及人民 |

### 五、易错辨析与闭卷自测

<Accordions>
<Accordion title="判断：社会治理现代化就是政府单方面提高管理效率。">

**错误。** 教材强调党的领导、政府主导，以及**社会协同、公众参与、民主协商、法治保障、科技支撑**等多方面共同作用。

</Accordion>
<Accordion title="判断：共建是治理的关键，共治是治理的目标。">

**错误。** **共建是基础、共治是关键、共享是目标**，三者次序和含义不可随意替换。

</Accordion>
<Accordion title="判断：城乡社区是社会治理最基本的单元，基层治理是国家治理的基石。">

**正确。** 也是理解“社会治理重心下移”和“联系服务群众最后一公里”的基础。

</Accordion>
<Accordion title="问答：基层党组织、基层政府、基层群众性自治组织分别发挥什么作用？">

依次是**领导核心作用、主导作用、基础作用**。

</Accordion>
<Accordion title="问答：四种治理方法和七个体系要素分别是什么？">

**四方法**：系统治理、依法治理、综合治理、源头治理。

**七要素**：党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑。

</Accordion>
</Accordions>

<Callout type="tip" title="考前一分钟速背">

**四治**：系统、依法、综合、源头；**七要素**：党委、政府、民主、社会、公众、法治、科技；**三理念**：共建基础、共治关键、共享目标；**治理共同体**：人人有责、人人尽责、人人享有；**基层三定位**：国家治理基石、最基本单元、最后一公里；**两经验**：枫桥经验、浦江经验。

</Callout>
