## 专题十九｜坚持“一国两制”和推进祖国完全统一

<Callout type="info" title="本专题考纲式总览">

本专题按照原书知识框架分为两部分：

1. **全面准确理解和贯彻“一国两制”方针**：牢记**“一国”是前提与基础**，维护**国家主权、安全、发展利益**是最高原则；区分中央全面管治权与特别行政区高度自治权。
2. **推进祖国完全统一**：把握教材中关于两岸关系的**九二共识、和平统一、一国两制**等表述，以及新时代党解决台湾问题总体方略的**“十个坚持”**。

以下“重要定位词”均按照本书的考研政治理论表述整理，避免将**教材主张、历史事实和法律概念**混作同一个层次。

</Callout>

### 一、“一国两制”的科学内涵

#### 1. 根本宗旨与最高原则

| 设问 | 教材表述 | 核心含义 |
| --- | --- | --- |
| **根本宗旨** | **维护国家主权、安全、发展利益，保持香港、澳门长期繁荣稳定** | 包含国家整体利益与特别行政区发展稳定两个方面 |
| **最高原则** | **维护国家主权、安全、发展利益** | 其他制度安排以此为前提 |
| **“一国”与“两制”关系** | **“一国”是实行“两制”的前提和基础** | “一国”是根本，“两制”从属并派生于“一国” |
| **国家主体制度** | **国家主体实行社会主义制度** | 特别行政区依法保留其原有资本主义制度 |

**“一国两制”是一个完整体系**，并非将“一国”和“两制”割裂为两个可以相互替代的主张。“一国”与“两制”的关系，不能被理解成两个互不相干或彼此等量的政治实体。

#### 2. 为什么说“一国”是根、本、前提？

<Steps>
<Step>

**首先，统一的国家主体是制度前提。** 特别行政区不是独立主权国家，其自治权在国家宪制秩序内运行。

</Step>
<Step>

**其次，国家主体的制度保持明确定位。** 教材强调**国家主体实行社会主义制度**，港澳依法保持原有资本主义制度长期不变。

</Step>
<Step>

**最后，两种制度安排统一于“一国”之内。** 港澳的制度与高度自治权必须以国家主权和宪制安排为根据。

</Step>
</Steps>

<Callout type="warn" title="经典混淆：“两制”不是两个平行主权国家">

原书明确强调**“两制”从属、派生于“一国”**，“一国”之内两种制度不构成**等量齐观、比肩并列**的主权关系。

因此考题说“‘两制’是‘一国’的前提”“两个制度分属两个独立国家”，均不符合本专题的教材论述。

</Callout>

### 二、中央全面管治权与高度自治权

#### 1. 它们是什么关系？

**坚持中央全面管治权和保障特别行政区高度自治权相统一**，是正确把握“一国两制”制度安排的重要内容。

| 概念 | 理论定位 | 必须牢记 |
| --- | --- | --- |
| **中央全面管治权** | 中央对特别行政区的全面管治权是其高度自治的**前提和基础** | **源、本** |
| **特别行政区高度自治权** | 根据宪法、基本法等宪制安排获得授权，并体现中央行使全面管治权 | **流、末** |

- **高度自治不是完全自治**：特别行政区依法享有广泛自治权，但不是独立主权意义上的完全自治。
- **高度自治不是联邦式分权**：原书强调，特别行政区自治权属于**中央授权的地方事务管理权**。
- **不存在所谓“剩余权力”**：不能把没有逐项写明的权力推定为特别行政区固有的主权权力。

<Callout type="tip" title="判断设问是问“来源”，还是问“范围”">

- 问**权力来源、根本前提**：中央的**全面管治权与中央授权**。
- 问**特别行政区依法享有什么**：宪法、基本法规定的**高度自治权**。
- 问**二者关系**：**前提与体现、源与流、本与末**，不是彼此割裂。

</Callout>

#### 2. 依法治港治澳的宪制基础

**宪法和基本法共同构成特别行政区的宪制基础**。原书强调，宪法和基本法的共同实施，是“一国两制”制度在特别行政区运行的重要特征。

| 概念 | 在题目中的用途 |
| --- | --- |
| **宪法** | 国家根本法，构成特别行政区宪制秩序的根本基础 |
| **特别行政区基本法** | 在宪法框架下规定特别行政区制度与相关权力安排 |
| **依法治港治澳** | 坚持并维护由**宪法和基本法共同构成**的宪制基础与秩序 |

**相关要求**：

- 坚定落实**“爱国者治港”“爱国者治澳”**原则。
- 坚持**依法治港治澳**，在宪法和基本法规定的框架内实施治理。
- 正确处理中央全面管治权与特别行政区高度自治权之间的关系。

#### 3. 原书列示的有关底线

本教材把下列行为列为不能触碰的底线，要求按原有政治法律语境理解：

1. 危害**国家主权和安全**。
2. 挑战**中央权力**和香港特别行政区**基本法权威**。
3. 利用香港对内地进行**渗透破坏**。

**辨析**：原书列示这“三条底线”旨在强调“一国两制”的国家主权与宪制边界，不能把它们与上文关于生态环境保护的“三条红线”或国土空间规划“三条控制线”混淆。

### 三、“一国两制”的提出与实践顺序

**原书表述**：“一国两制”的提出，**首先是为了实现和维护国家统一**；这一构想**最早针对台湾问题提出**，但**首先运用于解决香港和澳门问题**。

| 维度 | 需要记忆的内容 |
| --- | --- |
| **提出的初衷** | 实现和维护国家统一 |
| **最早面向的问题** | **台湾问题** |
| **首先运用的领域** | **香港和澳门问题** |

<Callout type="warn" title="“最早针对”和“首先运用”不是同一问法">

**针对台湾问题提出**与**先用于香港、澳门问题**都可以同时成立，因为前者指构想的最初问题指向，后者指实际制度运用的历史次序。

</Callout>

### 四、推进祖国完全统一：几个关键定位

#### 1. 与民族复兴及国家利益的关系

教材将**实现祖国完全统一**视为**中华民族伟大复兴的必然要求**，并把以下表述作为本专题的重要考点：

- 实现完全统一是由中华民族伟大复兴的**时和势**决定的。
- 中华文明具有突出的**统一性**，国家统一是中国核心利益的核心。
- 维护国家**主权和领土完整**是国家核心利益和不可逾越的红线。
- 大陆和台湾同属一个中国，中国是中华民族的共同家园。

#### 2. 两岸关系中的主要定位词

| 原书设问 | 对应提法 |
| --- | --- |
| 实现两岸统一的**最佳方式** | **“和平统一、一国两制”** |
| 推动两岸关系和平发展的**关键** | 坚持体现一个中国原则的**“九二共识”** |
| 两岸关系有关共识的**核心** | 对**两岸同属一个中国**的共同认知 |
| 发展两岸关系的**出发点和落脚点** | **为两岸同胞谋福祉** |
| 决定两岸关系走向和实现完全统一的**关键因素** | **祖国大陆的发展进步** |
| 两岸关系和平发展的**最大现实威胁**（教材表述） | **“台独”势力及其分裂活动** |

<Callout type="info" title="辨析：“原则—共识—方式—基础”不等同">

**一个中国原则**：本专题对台政策的基础性政治原则；**“九二共识”**：教材强调体现一个中国原则，是推动两岸关系和平发展的**关键**；**“和平统一、一国两制”**：教材强调为实现两岸统一的**最佳方式**；**祖国大陆的发展进步**：被概括为决定两岸关系走向的**关键因素**。

</Callout>

#### 3. 为什么“祖国大陆的发展进步”被称为关键因素？

按照本书论述，国家综合实力、制度能力、经济社会发展等长期因素影响两岸关系演进及实现统一的条件。因此，要把两岸问题放到**民族复兴与国家发展**的总体进程中理解。

**考试提示**：题目若问“发展两岸关系的出发点”，选**为两岸同胞谋福祉**；若问“决定走向的关键因素”，选**祖国大陆的发展进步**。两个都是“关键”类高频词，但设问对象不同。

### 五、新时代党解决台湾问题的总体方略：“十个坚持”

以下按原资料的**十个坚持**完整整理，保留其不同政策定位，不用笼统概括代替原条目。

| 序号 | 内容要点 | 定位 |
| --- | --- | --- |
| **1** | 坚持**党中央对对台工作的集中统一领导** | **根本保证** |
| **2** | 坚持在**中华民族伟大复兴进程**中推进祖国统一 | **历史方位** |
| **3** | 坚持在**祖国大陆发展进步基础**上解决台湾问题 | **战略思路** |
| **4** | 坚持**“和平统一、一国两制”**基本方针 | **大政方针** |
| **5** | 坚持**一个中国原则和“九二共识”** | **政治基础** |
| **6** | 坚持推动两岸关系**和平发展、融合发展** | **实践途径** |
| **7** | 坚持**团结台湾同胞、争取台湾民心** | **根本动力** |
| **8** | 坚持**粉碎“台独”分裂图谋** | **必然要求** |
| **9** | 坚持**反对外部势力干涉** | **外部条件** |
| **10** | 坚持**决不承诺放弃使用武力** | **战略支撑** |

#### 1. 怎样记下完整顺序？

<Steps>
<Step>

**1—3：方向与战略**

党中央集中统一领导（**根本保证**）→ 民族复兴进程（**历史方位**）→ 大陆发展进步（**战略思路**）。

</Step>
<Step>

**4—6：方针、基础、路径**

和平统一、一国两制（**大政方针**）→ 一个中国原则与九二共识（**政治基础**）→ 和平发展、融合发展（**实践途径**）。

</Step>
<Step>

**7—10：动力、要求、外部条件、支撑**

争取台湾民心（**根本动力**）→ 反对分裂（**必然要求**）→ 反对外部干涉（**外部条件**）→ 不承诺放弃使用武力（**战略支撑**）。

</Step>
</Steps>

#### 2. “十个坚持”中的重点区分

<Tabs items={['政治基础与根本保证','实践途径与根本动力','战略支撑与大政方针']}>
<Tab value="政治基础与根本保证">

**根本保证**：坚持党中央对对台工作的集中统一领导。

**政治基础**：坚持一个中国原则和“九二共识”。

**区分**：一个是**组织领导与政策统筹**，一个是**两岸关系的政治原则与共识**。

</Tab>
<Tab value="实践途径与根本动力">

**实践途径**：推动两岸关系**和平发展、融合发展**。

**根本动力**：**团结台湾同胞、争取台湾民心**。

**区分**：前者强调怎么推进，后者强调依靠什么社会力量与民心条件。

</Tab>
<Tab value="战略支撑与大政方针">

**大政方针**：坚持“**和平统一、一国两制**”。

**战略支撑**：坚持**决不承诺放弃使用武力**。

这两条在教材中是**不同层次的政策表述**，不应误作同一个定位词。

</Tab>
</Tabs>

<Callout type="warn" title="辨析：教材政策表述与行动事实之间的界限">

“坚持决不承诺放弃使用武力”在此是原书列出的**战略政策立场**，并不等于已发生、正在发生或必定发生某种具体军事行动。复习时应按题目要求记忆**政策定位**，不要将表述扩展为未经证实的现实事件判断。

</Callout>

### 七、易错辨析与闭卷自测

<Accordions>
<Accordion title="错误：“两制”是“一国”的前提，两者相互独立。">

**错误。** **“一国”是前提和基础，“两制”从属和派生于“一国”**，统一于一个国家之内。

</Accordion>
<Accordion title="错误：特别行政区的高度自治权相当于主权意义上的完全自治。">

**错误。** 本教材强调高度自治权来自**中央授权**，与中央全面管治权有**源与流、本与末**的关系。

</Accordion>
<Accordion title="问答：“一国两制”最早为解决哪一问题提出，首先运用于哪里？">

**最早针对台湾问题提出；首先运用于香港和澳门问题。**

</Accordion>
<Accordion title="错误：推动两岸关系和平发展的关键因素与出发点都是祖国大陆的发展进步。">

**错误。** 两岸关系和平发展的**关键**是坚持体现一个中国原则的“九二共识”；为两岸同胞谋福祉是发展两岸关系的**出发点和落脚点**；祖国大陆发展进步是决定两岸关系走向的**关键因素**。

</Accordion>
<Accordion title="自测：新时代对台工作总体方略“十个坚持”对应哪十种定位？">

依次是：**根本保证、历史方位、战略思路、大政方针、政治基础、实践途径、根本动力、必然要求、外部条件、战略支撑。**

</Accordion>
<Accordion title="错误：宪法与基本法构成两套彼此独立的宪制基础。">

**错误。** 本教材强调**宪法和基本法共同构成特别行政区宪制基础**，应在整体宪制秩序中理解其联系。

</Accordion>
</Accordions>

<Callout type="tip" title="考前一分钟速背">

**“一国”前提、国家主权安全发展利益最高原则；中央全面管治权是源、本，高度自治是流、末；宪法与基本法共同构成宪制基础；最早为台湾提出、先用于港澳；两岸共识关键、民生福祉落点、大陆发展关键因素；十个坚持的“保证、方位、思路、方针、基础、途径、动力、要求、条件、支撑”。**

</Callout>
