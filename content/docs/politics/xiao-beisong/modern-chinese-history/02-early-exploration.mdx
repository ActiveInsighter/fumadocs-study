## 专题三｜不同社会力量对国家出路的早期探索

<Callout type="info" title="三次早期探索——看领导力量、目标、失败原因">

| 探索 | 领导力量 | 核心主张 | 教材归纳的根本历史局限 |
| --- | --- | --- | --- |
| **太平天国农民战争** | **农民阶级** | 反封建、平均土地；后期出现发展资本主义的设想 | 农民阶级自身局限，缺乏先进阶级领导和科学理论 |
| **洋务运动** | **地主阶级洋务派** | “**中体西用**”，**自强、求富**，引进近代技术 | 维护封建制度基础上进行技术改革，具有封建性 |
| **戊戌维新运动** | **资产阶级维新派** | **君主立宪、变法图强**，自上而下改良 | 不敢根本否定封建制度、依赖皇权、惧怕群众 |

</Callout>

### 一、太平天国农民战争

#### 1. 爆发的背景

- **鸦片战争后**清政府加重征税，农民负担更加沉重。
- 资本主义入侵冲击传统农业与家庭手工业结合的自然经济，加深部分地区社会矛盾。

#### 2. 《天朝田亩制度》：以土地问题为中心的社会理想

**定位**：最能体现**太平天国社会理想和此次农民起义特色**的纲领性文件，是以**解决土地问题为中心**的比较完整的社会改革方案。

| 维度 | 主要内容与评价 |
| --- | --- |
| **核心诉求** | 反对封建土地所有制，提出平均分配土地的主张 |
| **积极意义** | 体现农民要求摆脱封建土地压迫、平均分配土地的强烈愿望 |
| **历史局限** | 描绘的小生产平均主义理想具有**不切实际的空想性** |
| **实行状况** | 土地平分方案在太平军控制地区**并未付诸实施** |

<Callout type="warn" title="对《天朝田亩制度》的评价要双向作答">

**有反封建土地所有制的积极意义**，但**具有空想性、未付诸实施**。不能把“提出方案”误写为“已经实现全国土地平均分配”，也不能把它说成发展资本主义的纲领。

</Callout>

#### 3. 《资政新篇》：带有资本主义色彩的后期方案

**定位**：太平天国后期提出的社会发展方案，是**中国近代史上第一个比较系统的发展资本主义的方案**。

- **突出设想**：提倡雇佣劳动、学习西方经济与制度经验，把“向西方学习”从生产力层面延伸至**生产关系层面**。
- **重要意义**：体现晚期部分太平天国领导人主动探索近代经济社会转型的努力。
- **局限**：受历史和战争条件制约，**未付诸实施**。

#### 两个纲领的重点对照

<Tabs items={['《天朝田亩制度》','《资政新篇》']}>
<Tab value="《天朝田亩制度》">

- **土地中心**：平均分配土地、否定封建土地所有制。
- **经济倾向**：以小生产平均主义的理想为特征，并非发展资本主义制度的系统方案。
- **评价关键词**：**农民社会理想、空想性、未付诸实施**。

</Tab>
<Tab value="《资政新篇》">

- **社会发展方案**：提倡雇佣劳动及学习西方近代制度。
- **经济倾向**：**资本主义色彩**。
- **评价关键词**：**第一个比较系统的发展资本主义的方案、未付诸实施**。

</Tab>
</Tabs>

<Callout type="tip" title="易考“第一”与“最能体现”">

**最能体现太平天国农民起义特色**的是**《天朝田亩制度》**；**第一个比较系统的发展资本主义的方案**是**《资政新篇》**。两者都没有真正实现，不要只记“未实施”而忽视二者理论性质的差别。

</Callout>

#### 4. 历史意义：五个方面

1. **沉重打击**清王朝封建统治阶级，动摇其统治根基。
2. 被概括为**中国旧式农民战争的最高峰**，并具有新的历史特点。
3. 冲击孔子和儒家经典的正统权威，在一定程度上削弱封建统治思想基础。
4. 打击外国侵略势力。
5. 在 19 世纪中叶亚洲民族解放运动中具有重要影响。

**“新特点”主要是什么？** 《资政新篇》反映部分太平天国领导人尝试**向外国学习、探索新的发展道路**，超出以往传统农民战争常见的社会理想。

#### 5. 失败原因

| 层次 | 具体原因 |
| --- | --- |
| **根本原因** | **农民阶级不是新的生产力和生产关系的代表**，无法克服小生产者的阶级局限，缺乏先进阶级领导与科学理论指导 |
| **领导集团方面** | 难以抑制腐败，不能保持长期团结 |
| **军事方面** | 重大战略失误 |
| **思想文化方面** | 未能正确对待儒学 |
| **对外认识方面** | 对西方资本主义侵略者缺乏理性认识 |

**主要教训**：在半殖民地半封建社会，**单纯的农民战争难以完成民族独立、人民解放的历史任务**。

### 二、洋务运动：地主阶级洋务派的技术自强尝试

#### 1. 目的与指导思想

**目的**：首先为购买、制造洋枪洋炮以镇压农民起义；还包含加强海防边防、发展相关政治经济军事实力的意图。**根本政治目的**是**维护封建统治**，而非建立独立资本主义国家。

**指导思想：中学为体，西学为用（中体西用）。** 即保持封建伦理纲常所维系的政治社会秩序，将西方近代工业和技术作为辅助工具。

**目标口号：自强、求富。**

#### 2. 三个主要内容

<Steps>
<Step>

**兴办近代企业**。最先兴办**军事工业**，后设立部分**民用企业**；多数民用企业采取**官督商办**的形式，基本是资本主义性质的近代企业。

</Step>
<Step>

**建立新式海陆军**。训练新式军队、建设近代海军，**北洋水师**是清政府海军主力。

</Step>
<Step>

**兴办新式教育**。创办翻译学堂、工艺学堂、军事学堂，并派遣留学生。

</Step>
</Steps>

#### 3. 历史作用与失败标志

| 方面 | 教材评价 |
| --- | --- |
| **近代工业** | 客观上推动早期工业与民族资本主义的发展；是**中国近代化的开端** |
| **近代教育** | 是中国**近代教育的开始**，引进近代自然科学知识，拓宽视野 |
| **社会风气** | 工商业者社会地位上升，推动社会风气与价值观念变化 |
| **失败标志** | **甲午战争中北洋海军全军覆没**，标志洋务运动的失败 |

#### 4. 失败的三个原因

1. **封建性**：在保持封建政治经济制度的前提下推进技术改革，受旧制度制约。
2. **对列强的依赖性**：依靠西方列强获取技术、军备和其他资源，受到外部制约。
3. **企业管理的腐朽性**：管理体制与经营方式存在问题，限制企业效率和发展。

<Callout type="warn" title="“近代化的开端”不是“民族民主革命的开端”">

**洋务运动**常被概括为中国**近代化的开端**；**五四运动**是**新民主主义革命的开端**。判断题出现“开端”，必须看对象。

</Callout>

### 三、戊戌维新运动：资产阶级维新派的改良尝试

#### 1. 维新运动兴起的背景

- **民族资本主义经济初步发展**，提供一定的阶级与经济基础。
- **甲午战争失败**加剧民族危机，促成救亡图存意识扩展。
- 维新派中的知识分子推动向西方学习由器物技术进到**政治制度与思想文化**层面。
- **上书、著书、办学会、设学堂、办报刊**等活动传播维新思想。

#### 2. 维新派与守旧派的论战：三大问题

1. **要不要变法**。
2. **要不要兴民权、设议院、实行君主立宪**。
3. **要不要废八股、改科举、兴西学**。

**性质**：是**资产阶级思想与封建主义思想在中国的第一次正面交锋**。其思想解放作用推动了维新思潮和戊戌变法的发展。

<Callout type="tip" title="两次论战不要混淆">

本专题**维新派与守旧派**论战的焦点，围绕**变法、君主立宪、科举教育**；下一专题**革命派与改良派**论战则围绕**是否革命推翻清朝、是否实行共和、是否进行社会革命**。

</Callout>

#### 3. 性质与意义

**性质**：一场**资产阶级性质的政治改良运动**。维新派试图通过自上而下改革改变国家状况，但改革**未从根本上否定封建制度**，整体方案较为温和、不彻底。

**历史意义**：

1. **爱国救亡运动**：推动中华民族的觉醒。
2. **资产阶级政治改良运动**：在政治、经济等方面冲击封建制度。
3. **思想启蒙运动**：传播西方资产阶级政治学说与自然科学知识，有利于思想解放和民主思想传播。

#### 4. 失败原因：客观阻力与自身局限

| 方面 | 具体表现 |
| --- | --- |
| **客观原因** | 以慈禧太后为首的强大守旧势力反对 |
| **主观局限之一** | **不敢根本否定封建主义**：依赖君主制度，未触动封建土地所有制，思想上托古改制 |
| **主观局限之二** | **对帝国主义抱有幻想** |
| **主观局限之三** | **惧怕人民群众**，缺乏广泛群众基础 |

**历史教训**：在当时的中国，**依靠封建统治者自上而下改良**难以完成民族独立、人民解放的历史任务。

### 四、三次探索的综合比较

| 比较 | 太平天国 | 洋务运动 | 戊戌维新 |
| --- | --- | --- | --- |
| **主要阶级力量** | **农民阶级** | **地主阶级洋务派** | **资产阶级维新派** |
| **核心方式** | 农民起义与战争 | 引进近代技术、办企业、练军队 | 依托朝廷**自上而下变法** |
| **经典文件／口号** | 《天朝田亩制度》《资政新篇》 | **中体西用、自强求富** | **君主立宪、变法图强** |
| **历史贡献** | 反封建、反侵略；后期出现新的社会设想 | 推动早期工业、近代教育和社会风气变化 | 爱国救亡、政治改良、思想启蒙 |
| **主要历史局限** | 农民阶级局限 | 维护封建基础、对外依赖 | 对旧制度妥协、惧怕群众 |
| **教材总结的道路教训** | 单纯农民战争不能完成任务 | 在维持封建制度下仅靠技术求强难以成功 | 依靠统治者自上而下改良难以成功 |

<Callout type="info" title="“失败”与“没有历史作用”是两回事">

三次探索**都未实现近代中国两大历史任务**，但各自留下了不同的实践影响和思想遗产。评价应坚持**历史意义与局限性同时分析**，不能以最终失败抹杀某一运动的全部作用。

</Callout>

### 五、选择题陷阱与闭卷自测

<Accordions>
<Accordion title="错误：两个太平天国纲领均是平均主义土地制度方案">

**错误。** 《天朝田亩制度》以**平均土地**为核心；《资政新篇》是带有**资本主义色彩的发展方案**。

</Accordion>
<Accordion title="错误：《资政新篇》在太平军统治地区得到广泛实施">

**错误。** 由于历史条件限制，**未付诸实施**。

</Accordion>
<Accordion title="错误：洋务运动根本目的是建立资产阶级共和国">

**错误。** 洋务运动根本在于**维护封建统治**，引进西方近代技术为其服务。

</Accordion>
<Accordion title="错误：戊戌维新运动是中国资产阶级推翻帝制的武装革命">

**错误。** 戊戌维新是**资产阶级改良运动**；武装革命推翻清王朝的道路属于下一专题辛亥革命的历史进程。

</Accordion>
<Accordion title="错误：维新派与守旧派的论战属于资产阶级内部革命路线的斗争">

**错误。** 这是**资产阶级思想与封建主义思想第一次正面交锋**；革命派与改良派的论战才是在资产阶级阵营内部围绕革命与改良展开。

</Accordion>
</Accordions>

### 六、考前一分钟背诵

**太平天国—农民阶级：天朝田亩均田地、资政新篇讲资本主义；最高峰、阶级局限。洋务—地主洋务派：中体西用、自强求富；军工到民用、北洋水师、近代化开端；甲午失败。戊戌维新—资产阶级改良派：变法、民权议院、改科举；爱国救亡、政治改良、思想启蒙；自身局限加守旧势力。**
