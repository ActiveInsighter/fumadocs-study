## 专题一｜马克思主义中国化时代化的历史进程和理论成果

<Callout type="info" title="本专题知识框架｜一项提出、两个原因、两个结合、五项成果">

- **明确提出**：**1938 年**，毛泽东在党的**六届六中全会**的政治报告**《论新阶段》**中，明确提出“马克思主义的中国化”命题。
- **推进的两个原因**：马克思主义理论本身发展的**内在要求**；解决中国实际问题的**客观需要**。
- **根本途径**：把马克思主义基本原理**同中国具体实际相结合、同中华优秀传统文化相结合**，即**“两个结合”**。
- **五项主要理论成果**：毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想。
- **理论成果的关系**：**一脉相承又与时俱进**，同时要区分其形成的时代背景和实践基础。

</Callout>

### 一、“马克思主义中国化”命题是怎样提出的？

#### 1. 历史节点：1938 年党的六届六中全会

| 考点 | 准确表述 |
| --- | --- |
| **时间** | **1938 年** |
| **人物** | **毛泽东** |
| **会议** | **党的六届六中全会** |
| **报告** | **《论新阶段》** |
| **历史定位** | 党**首次明确提出**“马克思主义中国化”的重大命题 |

<Callout type="warn" title="三类信息必须整体记忆">

不要将**六届六中全会**记成**六届七中全会**；也不要把《论新阶段》误写为《新民主主义论》。考试经常通过**年份、会议、著作的错位组合**制造干扰项。

</Callout>

#### 2. 为什么必须推进马克思主义中国化时代化？

<Tabs items={['理论自身发展的内在要求', '解决中国问题的客观需要']}>
<Tab value="理论自身发展的内在要求">

马克思主义不是僵化的教条，其理论生命力在于**随着时代变化和现实实践不断丰富发展**。

因此，推进中国化时代化，是马克思主义理论**自身发展**的要求。

**定位词：内在要求。**

</Tab>
<Tab value="解决中国问题的客观需要">

中国革命、建设、改革以及新时代实践，都具有自己的具体历史条件；解决中国问题，必须把马克思主义基本原理运用于**中国实际**。

因此，推进中国化时代化，是**解决中国实际问题**的需要。

**定位词：客观需要。**

</Tab>
</Tabs>

**两项原因的关系：**既要求马克思主义理论**发展创新**，也要求理论回应中国现实问题。它们不是彼此矛盾的两种选择，而是推进理论创新的两个相互联系的依据。

### 二、马克思主义中国化时代化的根本途径：“两个结合”

<Steps>
<Step>

**第一个结合：**把**马克思主义基本原理同中国具体实际相结合**。

理解重点：把基本原理运用于中国现实，研究中国社会发展的历史条件、现实需要及实践经验，防止脱离国情、机械照搬。

</Step>
<Step>

**第二个结合：**把**马克思主义基本原理同中华优秀传统文化相结合**。

理解重点：重视中华优秀传统文化中的思想资源，使理论创新扎根中国历史文化土壤，不等于不加辨别地承袭一切传统观念。

</Step>
</Steps>

教材特别强调：

> **坚守好马克思主义这个“魂脉”和中华优秀传统文化这个“根脉”，是理论创新的基础和前提。**

| 概念 | 对应对象 | 典型干扰点 |
| --- | --- | --- |
| **魂脉** | **马克思主义** | 错写为“中华优秀传统文化” |
| **根脉** | **中华优秀传统文化** | 错写为“马克思主义” |
| **两个结合** | 中国具体实际 + 中华优秀传统文化 | 只保留其中一个“结合” |

<Callout type="tip" title="分清两个不同层次的提法">

**“根本途径”**对应**“两个结合”**；**“理论创新的基础和前提”**强调**坚守马克思主义魂脉与中华优秀传统文化根脉**。两项表述有内在联系，但题目问哪个定位词，就要回答哪个对应内容。

</Callout>

### 三、马克思主义中国化时代化有哪些主要理论成果？

按原资料列举，共有五项：

1. **毛泽东思想**。
2. **邓小平理论**。
3. **“三个代表”重要思想**。
4. **科学发展观**。
5. **习近平新时代中国特色社会主义思想**。

#### 如何理解这些理论成果的历史联系？

- **毛泽东思想**是在中国革命和建设的实践中形成、发展的马克思主义中国化理论成果。
- **邓小平理论、“三个代表”重要思想、科学发展观**，是改革开放和社会主义现代化建设时期形成发展的重要理论成果。
- **习近平新时代中国特色社会主义思想**，是在中国特色社会主义进入新时代的历史方位下形成发展的重大理论成果。

<Callout type="info" title="理论成果的归类口径">

按课程的一般表述，**中国特色社会主义理论体系**包含邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想等理论成果；**毛泽东思想**和**中国特色社会主义理论体系**有历史承继关系，但不能把二者简单当成同一概念。不同教材章节对理论成果可能按历史阶段分别展开，复习以题干指定的分类口径为准。

</Callout>

### 四、毛泽东思想与中国特色社会主义理论体系是什么关系？

#### 1. 一脉相承：共同的马克思主义立场、观点、方法

教材强调三层关系：

1. 毛泽东思想蕴含的马克思主义**立场、观点、方法**，为中国特色社会主义理论体系提供了**基本遵循**。
2. 中国特色社会主义理论体系在**新的历史条件下**，进一步**丰富和发展**了毛泽东思想。
3. 它们都是**马克思列宁主义在中国的运用和发展**，以独创性成果丰富马克思主义理论宝库，是党和国家必须长期坚持的指导思想，是全国各族人民团结奋斗的共同思想基础。

#### 2. 与时俱进：形成背景和实践基础不完全相同

| 对比 | **毛泽东思想** | **中国特色社会主义理论体系** |
| --- | --- | --- |
| **时代背景** | **战争与革命**的时代 | **和平与发展**成为时代主题的历史条件 |
| **实践基础** | **中国革命和建设** | **改革开放和社会主义现代化建设**，并在新时代实践中持续发展 |
| **理论联系** | 提供重要立场、观点、方法与基本遵循 | 在新的历史条件下继承、丰富、发展相关理论 |

<Callout type="warn" title="时间与实践基础不要混写">

- 不能说毛泽东思想**形成于改革开放时期**。
- 也不能把中国特色社会主义理论体系的形成基础说成是**领导新民主主义革命的直接实践**。
- 教材中的“战争与革命”“和平与发展”用于**概括相应理论形成的主要时代背景**，不是说各时期的社会实践只包含两个词所指的事情。

</Callout>

#### 3. 怎样理解“一脉相承又与时俱进”？

<Tabs items={['一脉相承', '与时俱进', '答题合并句']}>
<Tab value="一脉相承">

强调理论发展的**连续性**：坚持马克思主义基本立场、观点、方法，保持理论渊源和指导思想的内在联系。

</Tab>
<Tab value="与时俱进">

强调理论发展的**创新性**：时代环境、实践课题和具体任务发生变化，理论必须不断作出新的回答。

</Tab>
<Tab value="答题合并句">

**马克思主义中国化时代化的理论成果既一脉相承又与时俱进，既坚持马克思主义的基本立场、观点、方法，又在不同历史条件和实践基础上实现理论创新与发展。**

</Tab>
</Tabs>
