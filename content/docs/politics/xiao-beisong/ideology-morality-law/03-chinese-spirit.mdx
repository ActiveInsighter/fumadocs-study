## 专题四｜中国精神

<Callout type="info" title="中国精神的核心框架">

**中国精神**是实现中华民族伟大复兴不可或缺的**精神支撑**，是**兴国强国之魂**。其重要组成部分是**以爱国主义为核心的民族精神**和**以改革创新为核心的时代精神**。弘扬中国精神，要把民族精神的传承与时代精神的创造结合起来。

</Callout>

### 一、崇尚精神：中华民族的优秀传统

教材用三个方面说明中华民族重视精神价值的传统：**重视物质生活与精神生活的关系、不懈追求理想、注重品格养成**。

#### 1. 正确处理物质生活与精神生活的关系

| 引文或典型说法 | 体现的精神价值 | 解释 |
| --- | --- | --- |
| **“不义而富且贵，于我如浮云”** | 重道义，不以不义之财为追求 | 强调财富获取的正当性 |
| **“道德当身，故不以物惑”** | 坚持道德操守 | 不被物欲轻易迷惑 |
| **“一箪食，一瓢饮，在陋巷……回也不改其乐”** | 安贫乐道、精神坚守 | 精神追求不完全由物质富足决定 |
| **见利思义、以义制利、先义后利** | 义利关系中的价值取向 | 不否认合理利益，而是以道义规范逐利方式 |

<Callout type="tip" title="‘重精神’不等于轻视物质条件">

引文所强调的是**道义与财富之间的价值次序**，而不是要求人们完全脱离物质生活。物质生活和精神生活相互联系，考题关注的是**不能把物欲作为唯一价值尺度**。

</Callout>

#### 2. 对理想的不懈追求

| 名句 | 关联考点 |
| --- | --- |
| **“志士仁人，无求生以害仁，有杀身以成仁”** | 对崇高理想与道义原则的坚守 |
| **“兼相爱，交相利”** | 对理想社会关系的思考和追求 |
| **“为天地立心，为生民立命，为往圣继绝学，为万世开太平”** | 对社会理想与天下责任的追求 |

**识别线索**：题干突出志向、理想、社会责任与理想社会的追求时，优先联系**对理想的不懈追求**。

#### 3. 对品格养成的重视

- **“三不朽”**：立德、立功、立言；**“立德”居首**。
- **“自天子以至于庶人，壹是皆以修身为本”**：重视修身立德与道德人格的养成。

**识别线索**：强调**修身、品格、立德、人格**的材料，对应第三类传统；不要与“追求理想”一概混同。

### 二、中国精神的丰富内涵

#### 1. “四个伟大”

| 表述 | 理解线索 |
| --- | --- |
| **伟大创造精神** | 创造发明、开拓新局 |
| **伟大奋斗精神** | 艰苦奋斗、自强不息 |
| **伟大团结精神** | 团结协作、守望相助 |
| **伟大梦想精神** | 胸怀理想、追求复兴 |

这些是**中国人民和中华民族精神面貌的生动展现**。四者相互关联，不能机械将复杂材料只对应单一维度。

#### 2. 伟大建党精神与中国共产党人的精神谱系

**伟大建党精神是中国共产党的精神之源。** 中国共产党人在长期实践中形成的精神谱系，进一步**丰富了中国精神的内涵**。

<Callout type="warn" title="两个‘源’‘魂’定位不同">

- **伟大建党精神**：中国共产党的**精神之源**。
- **中国精神**：实现中华民族伟大复兴的精神支撑，**兴国强国之魂**。
- **民族精神的核心**：爱国主义；**时代精神的核心**：改革创新。

不要把“伟大建党精神是精神之源”误答为“时代精神的核心”。

</Callout>

### 三、中国精神为什么是复兴伟业的精神支撑？

<Tabs items={['精神纽带', '精神动力', '精神支柱']}>
<Tab value="精神纽带">

**中国精神是凝聚中国力量的精神纽带。** 它凝结共同的历史记忆、价值追求和国家认同，有助于形成团结奋进的社会力量。

</Tab>
<Tab value="精神动力">

**中国精神是激发创新创造的精神动力。** 它鼓励主动探索、改革创新，以实际行动回应时代发展问题。

</Tab>
<Tab value="精神支柱">

**中国精神是推进复兴伟业的精神支柱。** 在长期任务与困难挑战面前，为持续奋斗提供精神支撑。

</Tab>
</Tabs>

| 命题问法 | 对应表达 |
| --- | --- |
| 凝聚中国力量 | **精神纽带** |
| 激发创新创造 | **精神动力** |
| 推进复兴伟业 | **精神支柱** |

### 四、民族精神与时代精神：两大组成部分

#### 1. 民族精神：以爱国主义为核心

**民族精神**是在长期共同生活和社会实践中形成的，为民族多数成员认同的**价值取向、思维方式、道德规范、精神气质的总和**，是民族生存和发展的精神支柱。

- 历史形成：在中华民族长期发展过程中形成、延续并丰富。
- **核心：爱国主义**。
- 爱国主义是中华民族的重要精神财富，集中表达对祖国及民族共同体的深厚情感与责任。

#### 2. 时代精神：以改革创新为核心

**时代精神**是在新的历史条件下形成和发展的，体现民族特质、顺应时代潮流的**思想观念、价值取向、精神风貌和社会风尚的总和**。

**改革开放以来，形成了以改革创新为核心的时代精神。** 其典型表现分为三个方面：

1. **思想观念**：突破陈规、大胆探索、敢于创造。
2. **责任感和使命感**：不甘落后、奋勇争先、追求进步。
3. **精神状态**：坚忍不拔、自强不息、锐意进取。

#### 3. 二者是什么关系？

| 比较 | 以爱国主义为核心的**民族精神** | 以改革创新为核心的**时代精神** |
| --- | --- | --- |
| **形成维度** | 民族长期共同生活和历史实践 | 特定时代的新情况、新任务与实践探索 |
| **核心** | **爱国主义** | **改革创新** |
| **突出作用** | 凝聚民族认同与精神力量 | 激发与时俱进、开拓创造 |
| **共同点** | 都是**中国精神的重要组成部分**，紧密关联，共同支撑民族生存与发展 | 同左 |

**理解**：民族精神不是一成不变的静态遗产；时代精神也不是彻底割断历史的产物。二者在历史继承与创新发展中相互联系。

## 专题五｜爱国主义

<Callout type="info" title="先记住五个定位词">

**爱国主义是中华民族的民族心、民族魂。** 当代中国爱国主义的**本质**，是坚持**爱国和爱党、爱社会主义高度统一**。新时代爱国主义的**鲜明主题**是实现中华民族伟大复兴的**中国梦**；新时代爱国主义**教育**的鲜明主题是**全面建成社会主义现代化强国、实现中华民族伟大复兴**。弘扬新时代爱国主义的重要**着力点**是**维护祖国统一和民族团结**。

</Callout>

### 一、爱国主义的基本内涵

**爱国主义**体现人们对自己祖国的**深厚感情**，揭示**个人对祖国的依存关系**，是对家园、民族和文化的**归属感、认同感、尊严感、荣誉感**的统一。

从社会规范角度看，爱国主义还是调节**个人与祖国之间关系**的**道德要求、政治原则和法律规范**。

| 关键词 | 正确理解 | 易错点 |
| --- | --- | --- |
| **深厚感情** | 对祖国、民族和共同文化的认同 | 不能只理解为一时的情绪表达 |
| **依存关系** | 个人成长发展与国家、民族的生存发展相联系 | 不能把个人与国家完全割裂 |
| **四种感受的统一** | 归属感、认同感、尊严感、荣誉感 | 四个词不是互不相关的独立定义 |
| **三种规范维度** | 道德要求、政治原则、法律规范 | 不能误称为“只有道德要求” |

### 二、爱国主义表现在哪四个方面？

<Tabs items={['爱大好河山', '爱骨肉同胞', '爱灿烂文化', '爱自己的国家']}>
<Tab value="爱大好河山">

珍爱祖国的自然环境、山河国土及共同生活的家园。土地、资源、生态环境既是文化情感的寄托，也是人民生产生活的重要条件。

**材料线索**：山川国土、自然资源、生态家园、守护祖国土地。

</Tab>
<Tab value="爱骨肉同胞">

体现对民族利益共同体的**自觉认同**，是**检验一个人对祖国忠诚程度的试金石**。

**材料线索**：关心同胞、维护群众利益、团结互助、休戚与共。

</Tab>
<Tab value="爱灿烂文化">

文化是国家和民族的**灵魂**、延续发展的**精神基因**，也是涵养民族心理、个性和精神的重要基础，是民族凝聚力的文化源泉。

**材料线索**：传承中华优秀传统文化、保护文化遗产、弘扬民族精神。

</Tab>
<Tab value="爱自己的国家">

国家是个体成长发展的**基本屏障和坚实依托**，个人与国家相互依存、密不可分，这也是教材强调的**最深刻的爱国理由**。

**材料线索**：维护国家安全、主权统一、国家根本利益、共同发展条件。

</Tab>
</Tabs>

#### 四个方面的定位词对照

| 表现 | 考试易出现的定位词 |
| --- | --- |
| **爱祖国的大好河山** | 自然家园、河山国土 |
| **爱自己的骨肉同胞** | **检验对祖国忠诚程度的试金石** |
| **爱祖国的灿烂文化** | **民族精神基因、民族凝聚力的重要基础** |
| **爱自己的国家** | **个体成长发展的基本屏障和坚实依托、最深刻的爱国理由** |

<Callout type="warn" title="“试金石”与“最深刻的爱国理由”不是同一定位">

- **忠诚程度的试金石**：**爱自己的骨肉同胞**。
- **最深刻的爱国理由**：**国家是个体成长发展的基本屏障和坚实依托**。

选择题中即使前后语句都正确，只要将两个定位词错配，就可能成为错误选项。

</Callout>

### 三、爱国主义的历史性、现实性

**爱国主义是具体的、现实的。** 不同历史条件下，爱国主义具有不同的内容和时代特点。

- **历史性**：祖国的处境、社会制度、时代任务和实践形式会发生变化，爱国主义的具体表达与之相联系。
- **现实性**：爱国主义不仅是历史记忆，也要求回应当代国家发展与社会生活中的现实问题。
- **共同点**：虽然表达形式和任务变化，个人对祖国的情感与责任依然是重要内核。

**辨析**：历史性不代表爱国主义只是过去的传统；现实性也不代表今天的爱国主义与历史文化完全割裂。

### 四、新时代爱国主义的主题与本质

#### 1. 两个“鲜明主题”要区分

| 题干问法 | 应答内容 |
| --- | --- |
| **新时代爱国主义的鲜明主题** | **实现中华民族伟大复兴的中国梦** |
| **新时代爱国主义教育的鲜明主题**（按《中华人民共和国爱国主义教育法》及原资料） | **全面建成社会主义现代化强国、实现中华民族伟大复兴** |

<Callout type="tip" title="为何同时记住两个版本？">

前者概括**新时代爱国主义实践的主题**，后者对应**爱国主义教育法规定的教育主题**。二者高度相关，但**提问对象不同、措辞不同**，不能在考研定位词判断中随意替换。

</Callout>

#### 2. 当代中国爱国主义的本质

**坚持爱国和爱党、爱社会主义高度统一**，是**当代中国爱国主义的本质**，也是教材强调的**当代中国爱国主义精神最重要的体现**。

具体要求包括：

1. 拥护国家的基本制度，**遵守宪法法律**。
2. **维护国家安全和统一**，捍卫国家利益。
3. 为国家繁荣发展贡献自己的力量。
4. 在当代中国的实践中，将个人追求与**建设中国特色社会主义、实现民族复兴和推进祖国统一**相结合。

**注意区分**：本质和最重要体现均强调**爱国、爱党、爱社会主义相统一**；新时代爱国主义的**主题**则强调**实现中华民族伟大复兴**。

### 五、怎样做新时代的忠诚爱国者？

<Steps>
<Step>

#### 坚持爱国、爱党、爱社会主义相统一

这是新时代爱国主义的重要政治要求。需要把国家发展、人民利益和实际行动结合起来，而不是停留于口头表达。

</Step>
<Step>

#### 维护祖国统一和民族团结

将**维护祖国统一和民族团结**作为弘扬新时代爱国主义的**着力点**，积极维护国家主权、安全和民族团结。

</Step>
<Step>

#### 尊重和传承中华民族历史文化

**中华优秀传统文化**是中华民族的**精神命脉**、民族延续的**文化基因**，也是在世界文化交流中保持文化主体性的重要根基。

</Step>
<Step>

#### 坚持立足中国又面向世界

包含三个重要方向：

- **维护国家发展主体性**。
- **自觉维护国家安全**。
- **推动构建人类命运共同体**。

爱国主义与理性、开放的国际视野并不必然冲突：立足本国实际，也要重视国际联系与合作。

</Step>
</Steps>

#### 四项要求速查

| 要求 | 定位关键词 | 应排除的误解 |
| --- | --- | --- |
| **爱国爱党爱社会主义相统一** | **本质、最重要体现** | 爱国主义仅是一种抽象情感 |
| **维护统一和团结** | **着力点** | 把爱国仅理解为个人情绪表态 |
| **尊重和传承历史文化** | **精神命脉、文化基因** | 把文化传承看成无关紧要 |
| **立足中国、面向世界** | **主体性、安全、人类命运共同体** | 把爱国与对外交流合作绝对对立 |
