## 4.1 商品、价值、劳动、货币

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 商品经济 | 为交换而生产产品的经济形式 | 产品有用不等于一定是商品 |
| 商品 | 通过劳动生产、用于交换的产品 | 既有使用价值又有价值 |
| 自然经济 | 主要为生产者自身消费而生产 | 不以交换为主要目的 |
| 社会分工 | 社会生产活动被分配为不同专门工作 | 商品经济产生的条件之一 |
| 生产资料及产品属于不同所有者 | 商品交换需要独立利益主体 | 商品经济产生另一重要条件 |
| 使用价值 | 物能满足某种需要、有用性 | 是商品的自然属性，未必由劳动单独产生 |
| 价值 | 凝结在商品中的无差别的一般人类劳动 | 是商品的社会属性，不等于售价或有用性 |
| 交换价值 | 商品与其他商品相交换的量的比例关系 | 是价值的一种表现形式 |
| 商品二因素 | 同一商品同时具有使用价值和价值 | 不是价值与价格二因素 |
| 具体劳动 | 制衣、种菜等具有特定形式、生产使用价值的劳动 | 形成使用价值，同时劳动也有自然条件作用 |
| 抽象劳动 | 抛开具体形式的人类劳动耗费 | 形成商品的价值 |
| 劳动二重性 | 同一个商品生产劳动，既是具体劳动也是抽象劳动 | 不是两次劳动、两种劳动者 |
| 劳动是财富的源泉之一 | 劳动与自然界共同构成物质财富的源泉 | **劳动是价值的唯一源泉**，但不是使用价值/财富的唯一源泉 |
| 社会必要劳动时间 | 现有正常生产条件、平均熟练度和劳动强度下生产商品需要的时间 | 不等于生产者本人耗时 |
| 个别劳动时间 | 某个生产者实际耗费的时间 | 更慢不代表创造更多社会价值 |
| 劳动生产率 | 单位时间能生产多少产品 | 社会劳动生产率提高，单位商品价值量通常下降 |
| 价值量 | 商品中凝结的社会必要劳动量 | 与社会必要劳动时间成正比；与社会劳动生产率成反比 |
| 简单劳动与复杂劳动 | 一般劳动与经训练形成的更复杂劳动 | 复杂劳动在价值形成中可折合倍加的简单劳动 |
| 价值形式 | 商品价值通过交换关系表现的方式 | 经简单、扩大、一般形式到货币形式 |
| 一般等价物 | 能与许多其他商品交换、表现其价值的特殊商品 | 货币是固定充当一般等价物的商品 |
| 价值尺度 | 货币用来衡量、表现商品价值 | 标价可为观念上的货币，不一定现场付款 |
| 流通手段 | 一手交钱一手交货，钱在买卖中流通 | 与赊购还债不同 |
| 贮藏手段 | 货币退出流通、被保存起来 | 要注意教材所说货币形式和具体前提 |
| 支付手段 | 赊购、清偿债务、交税、发工资等独立付款 | 不是当场商品交换的流通手段 |
| 世界货币 | 在国际经济关系中发挥货币职能 | 不是任一国内交易都算 |
| 价值规律 | 商品价值量由社会必要劳动时间决定，交换以价值为基础 | 价格围绕价值波动，不是永久等于价值 |
| 价值规律作用 | 调节资源配置、推动技术改进、形成优胜劣汰等 | 自发作用也会产生消极后果 |
| 私人劳动 / 社会劳动 | 私人生产者各自组织劳动 / 劳动成果须符合社会需要并获社会承认 | 商品经济的基本矛盾 |
| 私人劳动转化为社会劳动 | 产品通过交换获得社会承认 | 并非生产者自称有用就完成转化 |
| 商品拜物教 | 人与人的社会经济关系表现为物和物之间的关系 | 不是字面上的“崇拜商品” |

## 4.2 剩余价值、资本、积累与危机

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 劳动力 | 人拥有的劳动能力 | **劳动力**成为商品，不是“劳动”本身先成为商品 |
| 劳动力商品的价值 | 维持劳动者及其家庭再生产、训练等所需生活资料价值 | 不能直接等同工人创造的新价值总量 |
| 劳动力商品的使用价值 | 在生产中通过劳动能够创造新价值，且可能超过劳动力本身价值 | 剩余价值生产的关键 |
| 资本 | 能在特定生产关系中实现价值增殖的价值 | 机器、货币本身不是脱离关系就天然成为资本 |
| 资本原始积累 | 通过暴力、剥夺等历史过程造成生产资料与生产者分离 | 不是工人节约攒钱、资本家勤俭起家 |
| 雇佣劳动 | 生产者出卖劳动力，受资本雇佣 | 体现特定社会生产关系 |
| 资本主义劳动过程 | 劳动者在资本控制下生产使用价值 | 同时存在剩余价值生产的价值增殖过程 |
| 价值形成过程 | 新劳动创造的价值加上旧价值转移 | 还未突出新增价值超过劳动力价值的环节 |
| 价值增殖过程 | 劳动生产的新价值超过劳动力自身价值 | 资本主义剩余价值生产的关键过程 |
| 不变资本 $c$ | 投向机器、原料等生产资料的资本；原有价值转移，不在这一过程中创造新价值 | “不变”指在剩余价值生产中的价值增殖作用 |
| 可变资本 $v$ | 购买劳动力的资本；通过劳动力使用产生超过其价值的新价值 | “可变”不是因为工人工资天天变 |
| 剩余价值 $m$ | 劳动者创造、超过劳动力价值而由资本占有的价值 | 按马克思主义政治经济学原理来源于剩余劳动 |
| 必要劳动时间 | 劳动日中再生产劳动力价值所需时间 | 不是“无意义或没必要劳动” |
| 剩余劳动时间 | 劳动日中超过必要劳动的部分 | 剩余价值的来源 |
| 剩余价值率 | 剩余价值与可变资本之比 | $m'=m/v$，体现资本对雇佣劳动的剥削程度 |
| 绝对剩余价值 | 必要劳动时间大体不变，通过延长劳动日等增加剩余劳动时间 | 关注总劳动日延长 |
| 相对剩余价值 | 劳动日既定，通过提高社会生产率等缩短必要劳动时间 | 关注必要劳动时间减少 |
| 超额剩余价值 | 个别企业效率领先，个别价值低于社会价值而取得的额外剩余价值 | 随技术推广可能消失，是相对剩余价值的重要动因 |
| 资本积累 | 把剩余价值转化为新的资本继续扩大生产 | 不是“资本循环”同义词 |
| 简单再生产 | 按原规模重复生产 | 不意味着资本主义剥削关系停止再生产 |
| 扩大再生产 | 投入扩大、规模增长地再生产 | 不等于所有增长都源于新建企业 |
| 资本积聚 | 单个资本通过自身剩余价值资本化而变大 | 要经积累，相对慢 |
| 资本集中 | 原有多个资本通过合并、吞并、股份制等汇聚为更大资本 | 不直接增加社会资本总额 |
| 资本技术构成 | 生产资料实物量与使用它的劳动量的比例 | 关注机器、原料与劳动的技术比例 |
| 资本价值构成 | 不变资本价值与可变资本价值的比例 | 关注 $c:v$ |
| 资本有机构成 | 由技术构成决定并反映其变化的价值构成 | 不能把全部价值价格波动都说成有机构成变化 |
| 资本有机构成提高 | 生产中资本投入对劳动投入的比例趋于增大 | 与技术进步、相对过剩人口联系 |
| 相对过剩人口 | 相对于资本增殖对劳动力的需求出现过剩 | 不是社会不需要这些人、更不是绝对人口太多 |
| 资本积累一般规律 | 资本积累伴随资本结构、劳动需求与贫富关系的矛盾变化 | 不是收入差距每年都单向扩大之类机械断言 |
| 资本循环 | 产业资本经历购买、生产、售卖，周而复始变换职能形式 | 关注不同阶段的连续运动 |
| 货币资本 / 生产资本 / 商品资本 | 买入生产要素的钱 / 生产过程中的资本 / 待售成品形态的资本 | 产业资本三种职能形式 |
| 资本周转 | 资本循环的重复，着重考察周转时间、次数与速度 | 与资本循环的关注点不同 |
| 固定资本 / 流动资本 | 生产资本按价值周转方式区分 | 不等于 $c/v$：原料是流动资本也属不变资本 |
| 社会总资本再生产 | 各个资本生产与交换相互衔接，使整个社会生产连续进行 | 不是只研究一家企业利润 |
| 两大部类 | I 部类生产生产资料，II 部类生产消费资料 | 不是国营部门和民营部门 |
| 价值补偿 / 实物补偿 | 卖产品收回价值 / 实际获得继续生产所需物品 | 社会再生产要两者都实现 |
| 工资是劳动力的价值或价格 | 工资支付的是劳动力的购买价格 | 表面上看像“劳动全部获得报酬”的假象 |
| 利润 | 剩余价值以全部预付资本收益形式表现 | 利润是剩余价值的转化形式 |
| 利润率 | 利润与全部预付资本之比 | $p'=m/(c+v)$，通常低于剩余价值率 |
| 平均利润 | 资本在部门间竞争形成的平均化利润 | 不是每个资本家从每个工人身上直接取得同额剩余价值 |
| 生产价格 | 成本价格加平均利润的价格基础 | 不等于与价值规律脱离；涉及剩余价值再分配 |
| 资本主义基本矛盾 | 社会化大生产与生产资料资本主义私人占有之间的矛盾 | 是经济危机的根本原因 |
| 生产社会化 | 生产劳动越来越依赖广泛协作、分工、社会联系 | 不等于社会已经实行公有制 |
| 相对生产过剩 | 生产相对劳动群众的有支付能力需求过剩 | 不意味着社会实际需要都满足了 |
| 经济危机周期性 | 积累和供需比例等矛盾通过危机周期性表现 | 不等于资本主义有固定周期日历 |
| 资本主义意识形态 | 在资本主义经济关系上形成、服务其社会秩序的思想体系 | 有历史性、阶级性，也不能否认其包含人类文化成果 |

## 4.3 政治经济学最容易串的公式与逻辑

**商品价值形成**：

$$
W=c+v+m
$$

其中 $c$ 为生产资料转移的旧价值，$v+m$ 是活劳动创造的新价值。以下以同一时期、同一资本口径作教材中的简化计算：

$$
m'=\frac{m}{v}\times100\%,\qquad p'=\frac{m}{c+v}\times100\%
$$

- **价值 VS 财富**：价值的唯一源泉是抽象人类劳动；物质财富（使用价值）有劳动和自然条件等源泉。不要把前一句变成“劳动是财富的唯一源泉”。
- **劳动 VS 劳动力**：资本家买的是劳动力；劳动力在使用中通过劳动创造新价值。
- **技术进步 VS 价值创造**：机器、AI 等生产资料可转移自身价值并提高劳动生产率；不能因此在马克思主义劳动价值论中直接将机器认定为创造剩余价值的独立源泉。
- **个别时间 VS 社会必要时间**：某工厂笨、做得慢，不意味着商品社会价值自动提高。
- **资本分类两套坐标**：$c/v$ 依据剩余价值生产中的作用；固定/流动资本依据资本价值周转方式。机器多属固定、不变；原料多属流动、不变；劳动力对应可变且相关资本价值周转快。
- **积累 VS 积聚 VS 集中**：再投资是“积累”；一个企业自己长大是“积聚”；几个资本合成大资本是“集中”。
- **绝对 VS 相对 VS 超额剩余价值**：加班延长劳动日/压缩必要劳动时间/某企业率先提高效率形成个别领先。
