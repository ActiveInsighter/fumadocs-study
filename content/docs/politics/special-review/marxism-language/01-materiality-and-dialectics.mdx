## 1.1 唯物论：物质、意识、时空、规律

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 哲学基本问题 | 思维和存在、意识和物质是什么关系 | 两个方面：谁第一性；能不能认识 |
| 唯物主义 | 物质是根本的，意识依赖物质 | 唯物不自动等于辩证 |
| 唯心主义 | 把精神、观念等看作世界的本原 | 分主观和客观唯心主义 |
| 主观唯心主义 | 个人意识、感觉被视为决定存在的根本 | “我的感觉创造世界”式 |
| 客观唯心主义 | 人以外的精神实体、理念被视为世界的本原 | “绝对精神创造世界”式 |
| 古代朴素唯物主义 | 用水、火等具体物质解释万物本原 | 把物质范畴等同具体形态 |
| 近代形而上学唯物主义 | 承认物质先在但带机械、孤立或不彻底局限 | 不等于辩证唯物主义 |
| 辩证唯物主义 | 物质先在，又从运动、联系、矛盾看世界 | 马原的理论立场 |
| 可知论 | 认为人能够认识世界 | 不等于“已经认识完了” |
| 不可知论 | 否认或怀疑人能认识世界的本质 | “物自体永远不可知”倾向 |
| 物自体 | 脱离人的认识、被设定为永远不能真正认识的“物自身” | 真题可借此考反不可知论 |
| 客观实在性 | 不依赖人的意识而存在 | 物质范畴的**唯一特性**（教材固定定位） |
| 哲学物质范畴 | 对一切客观物质形态共同属性的抽象概括 | 不等于原子、电子或某种粒子 |
| 物质与意识的绝对对立 | 只在“谁是世界本原/第一性”的范围有绝对意义 | 不是两者不能相互作用 |
| 运动是物质的根本属性 | 物质不是永恒静止的存在 | 不能说“运动脱离物质” |
| 运动是物质的存在方式 | 物质必然以某种运动形式存在 | “静止是存在方式”是偷换 |
| 绝对运动 / 相对静止 | 始终变化 / 某些关系和性质阶段性稳定 | 动中有静，静中有动 |
| 静止是运动的衡量尺度 | 有相对稳定的参照，才能说清变化有多大 | 不等于静止是运动的根源 |
| 时间一维性 | 时间从过去到现在到未来，不可逆流 | 不能等同空间三维性 |
| 时空的客观性 | 时间空间不是人幻想出来的 | “时空观念变化”不代表时空因认识才存在 |
| 运动物质的存在形式 | 物质运动一定在时间和空间中展开 | 时空不能脱离物质运动而独立解释 |
| 自在自然 / 人化自然 | 尚未经社会实践直接改造的自然 / 人的实践作用过的自然 | 被改造并不意味着不再客观 |
| 主观世界与客观世界二重化 | 人的意识活动与客观存在可以区分，实践联系并改造二者 | 不是分成两个互不相干的世界 |
| 意识的客观内容、主观形式 | 内容来自客观现实，表达、加工形式属于主体 | 鬼神、龙等想象也有现实素材 |
| 主观映象 | 客观现实在人脑中的反映和加工 | 不能等同照镜子式“直观复制” |
| 能动反映 | 人会选择、概括、加工与创造性想象 | 不等于任意创造客观事实 |
| 意识的物质外壳 | 语言等是思想表达和交流的物质形式 | 语言变化不决定社会生活本身 |
| 意识的目的性、计划性 | 先设定目的、再安排实际行动 | 光想不做不能直接改变客观世界 |
| 规律的客观性 | 规律不是人随意制定或取消的 | 人可以认识、利用，改变起作用的条件 |
| 尊重规律与发挥能动性统一 | 按真实约束寻找合适行动方式 | 反对宿命论与唯意志论 |
| 物质世界统一性 | 世界在根本上统一于物质 | 不是具体事物形态都一样 |
| 人工智能模拟意识活动 | 机器可执行复杂信息加工和智能任务 | 不应直接推出“AI具有与人完全相同的人类社会意识”；也别否定AI实际作用 |
| 机械决定论 | 认为未来所有细节由既定条件机械锁死、排除偶然性 | 不是辩证唯物主义决定论 |
| 唯意志论 | 把个人意志看作不受客观条件限制的决定力量 | “想怎样就怎样” |

## 1.2 辩证法：联系、矛盾、发展、否定

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 普遍联系 | 事物处于多种联系中，不能孤立理解 | 不是“任意两件事都有直接必然联系” |
| 联系的客观性 | 客观联系不是想象出来的 | 人能创造联系的实现条件而非凭空制造规律 |
| 联系的多样性、条件性 | 联系有直接/间接、内在/外在等形式，还依赖条件 | 不是只要相关就存在因果 |
| 新事物 | 符合客观发展方向、有生命力的事物 | 不等于刚出现、技术新、名字新 |
| 旧事物 | 丧失发展合理性、逐渐被取代的事物 | 不等于年代久远的东西必定无价值 |
| 对立统一规律 | 事物内部矛盾是发展动力的核心说明 | 唯物辩证法**实质与核心** |
| 矛盾同一性 | 对立双方相互依赖、贯通，条件具备时转化 | 不是双方没有差别 |
| 矛盾斗争性 | 对立双方相互区别、排斥、限制的倾向 | 不一定表现为流血冲突 |
| 同一性相对 / 斗争性绝对 | 某些一致状态要条件；对立运动普遍存在 | 不等于斗争时时都激烈 |
| 内因 / 外因 | 内部矛盾 / 外部环境及作用 | 内因是根据，外因是条件，外因通过内因起作用 |
| 矛盾普遍性 | 事事有矛盾，时时有矛盾 | 不是所有矛盾内容相同 |
| 矛盾特殊性 | 不同事物、不同阶段、不同方面有具体差异 | 具体问题具体分析 |
| 矛盾共性与个性 | 共同性质与具体独特之处相联系 | 共性寓于个性之中 |
| 主要矛盾 | 复杂过程中最需要抓的那对矛盾 | 解决“先抓什么问题” |
| 次要矛盾 | 其他仍然存在并影响过程的矛盾 | 不等于可以完全不管 |
| 矛盾主要方面 | 一对矛盾中对事物性质居支配地位的方面 | 解决“这个事物总体是什么性质” |
| 矛盾次要方面 | 同一矛盾中处于从属地位的一方 | 可在条件变化下转为主要方面 |
| 两点论 | 同时看到矛盾的两个方面、主次矛盾 | 不等于平均用力 |
| 重点论 | 在兼顾全面的基础上抓主导因素 | 不等于只看一点 |
| 质 | 使事物区别于其他事物的基本属性 | 不能拿数量多少替代 |
| 量 | 数量、规模、程度、速度等可以计量的方面 | 某些量变不立刻改质 |
| 度 | 使事物保持原有性质的量的范围、限度 | 适度不是越少越好 |
| 量变 | 数量增减或结构次序等渐进变化 | 不等于“没有变化” |
| 质变 | 事物根本性质发生变化 | 量变积累到突破度的界限等可导致质变 |
| 渐进性与飞跃性统一 | 逐步积累与关键转折相联系 | 不是只有渐进或只有突变 |
| 辩证否定 | 事物自身矛盾发展导致克服旧的状态 | 不等于外力简单摧毁 |
| 自我否定 | 旧事物内部生长出改变自身的因素 | 不等于人主观说“不” |
| 扬弃 | 既克服又保留并改造合理内容 | 不是全盘照收或全盘扔掉 |
| 否定之否定 | 发展历经反复、曲折，在更高阶段前进 | 不是简单“回到老样子” |
| 螺旋式上升、波浪式前进 | 总方向发展但道路有回环、反复 | 与循环论、直线论区分 |
| 本质 / 现象 | 内在深层联系 / 外在可呈现的样子 | 现象可能表现或掩盖本质 |
| 真象 / 假象 | 正面表现本质 / 歪曲表现本质 | 假象是客观存在的现象，不等于主观错觉 |
| 内容 / 形式 | 构成事物的要素和过程 / 表达及组织方式 | 内容决定形式，形式有反作用 |
| 原因 / 结果 | 引起变化的现象或过程 / 被引起的变化 | 在不同联系中可以相互转化 |
| 必然 / 偶然 | 内在基本趋势 / 非决定性条件下的多种表现 | 偶然不是无原因，必然借偶然表现 |
| 现实 / 可能 | 现在实际存在 / 有条件实现但尚未实现 | 可能性不是必然性 |
| 现实可能 / 抽象可能 | 在现有条件下有实现根据 / 逻辑可想但现实条件不具备 | 不要把一切想象都算现实可能 |
| 主观辩证法 / 客观辩证法 | 思维反映和把握矛盾运动 / 客观世界本身的矛盾运动 | 主观辩证法不是创造客观规律 |
| 归纳 / 演绎 | 从个别概括一般 / 用一般原则分析个别 | 都有适用条件和局限 |
| 分析 / 综合 | 拆解构成部分 / 联系整体把握 | 反对只拆不合、只合不分 |
| 逻辑与历史统一 | 理论把握应合理反映事物发展历史规律 | 逻辑不是事件流水账 |
| 系统思维 | 从整体结构、要素关系、功能及环境分析 | 不是把各部分简单加总 |
| 战略思维 | 从长远、全局、趋势把握重要关系 | 不等于抛弃现实细节 |
| 底线思维 | 识别最坏风险、守住基本边界并提前准备 | 不等于只看消极面 |
| 创新思维 | 在尊重实际与规律前提下探索新方法 | 不是随意否定一切旧方法 |
