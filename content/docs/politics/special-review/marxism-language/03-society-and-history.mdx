## 术语与白话对照

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 社会存在 | 社会生活中的客观物质条件、活动 | 主要涉及地理、人口、生产方式 |
| 社会意识 | 社会成员的思想、观念、文化与心理 | 受社会存在决定又有反作用 |
| 历史观基本问题 | 社会存在与社会意识关系 | 与一般哲学基本问题相关但不能混用 |
| 物质资料生产方式 | 社会如何组织生产物质生活资料 | 社会物质性的集中体现、社会发展决定力量 |
| 地理环境的作用 | 为生产生活提供自然前提、制约条件 | 不是社会制度性质的根本决定因素 |
| 人口因素 | 人口数量、结构、分布、素质等条件 | 重要条件，但非社会发展根本决定力量 |
| 社会意识的相对独立性 | 思想并非完全同步反映经济变化 | 依赖社会存在却不机械一致 |
| 不平衡性、不完全同步 | 经济变化快慢与文化、制度发展速度不一致 | 可超前也可滞后 |
| 历史继承性 | 后来的文化思想继承、改造既有传统 | 不等于只由上一代思想决定 |
| 最突出的反作用 | 思想能通过人的实践推动或阻碍社会现实 | 是社会意识相对独立性的突出表现 |
| 生产力 | 人们在生产中改造自然、获得物质资料的实际能力 | 劳动者、劳动资料、劳动对象等相关要素 |
| 劳动者是最活跃因素 | 人掌握技能并能运用、改进生产资料 | 不能改成“机器最活跃” |
| 劳动资料 / 劳动对象 | 用什么生产 / 对什么进行生产加工 | 两者共同属于生产资料 |
| 生产关系 | 人在生产中的经济关系，包括所有制、地位及分配关系 | **生产资料所有制**是核心 |
| 生产力决定生产关系 | 生产水平和方式从根本上要求相应组织关系 | 生产关系可促进或阻碍生产力 |
| 经济基础 | 社会一定发展阶段占统治地位的生产关系总和 | 不是“全部经济活动、GDP、科技” |
| 上层建筑 | 建立在经济基础上的观念、制度、组织设施 | 可分观念和政治上层建筑 |
| 观念上层建筑 | 政治法律思想、道德、哲学、宗教、艺术等 | 不等于制度组织本身 |
| 政治上层建筑 | 政治法律制度与政权组织、设施等 | 国家政权是其中的核心 |
| 经济基础决定上层建筑 | 制度与思想的根本性质受经济关系制约 | 上层建筑具有反作用 |
| 社会基本矛盾 | 生产力/生产关系、经济基础/上层建筑的矛盾 | 社会发展的**根本动力** |
| 社会主要矛盾 | 在特定历史阶段居主导地位的社会矛盾 | 不是“社会基本矛盾”的同义词 |
| 阶级斗争的直接动力作用 | 阶级社会中阶级间现实斗争推动某些社会变革 | 不是所有社会、所有领域的唯一动力 |
| 社会革命 | 社会基本制度发生根本改变的变革 | 不等于一般政策微调 |
| 社会改革 | 在一定社会制度框架内调整、变革相关关系和机制 | 不等于必然改变社会制度根本性质 |
| 世界历史的形成 | 随生产发展、普遍交往扩大，人类历史相互联系 | 不等于全球各地区发展道路一致 |
| 社会形态 | 经济基础与上层建筑统一的社会历史类型 | 更替有一般趋势也有具体差异 |
| 社会形态更替的统一性、多样性 | 有发展一般规律；道路、顺序和具体模式可能不同 | 不等于各国必须复制某国时间表 |
| 历史必然性与历史选择性 | 客观条件决定可行边界，人和群体在其中作出选择 | 既非全由个人意志决定，也非机械宿命 |
| 科学技术是历史发展的杠杆 | 科技能显著增强改造世界能力 | 不自动决定制度性质或消除矛盾 |
| 科技的社会作用具有两重性 | 可增进福利，也可因使用方式造成负面后果 | 不能推出“科技本身只有负作用” |
| 人民群众是历史创造者 | 多数人的物质生产、精神创造、社会实践推动历史 | 不是个人领袖独自创造历史 |
| 历史人物作用 | 重要个人可影响事件形式、速度和局部进程 | 不凭个人意志改变历史基本规律 |
| 英雄史观 | 把少数杰出人物的意志当作历史根本动力 | 与承认英雄有重要作用不同 |
| 人的本质是社会关系的总和 | 人的现实生活方式、身份和发展离不开社会关系 | 不是说个人没有自然属性 |
| 人的本质在其现实性上 | 讨论真实历史社会中的人，而非抽象孤立的“人性” | 不是每个人性格完全相同 |
| 人与自然的物质变换 | 人通过生产生活与自然交换物质能量 | 要合理调节，不是无限征服自然 |
| 生产方式的决定性 | 不同社会的物质生产组织从根本上影响社会结构 | 不等于文化、政治作用为零 |
