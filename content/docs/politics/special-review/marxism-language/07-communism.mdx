## 术语与白话对照

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 科学预见未来 | 根据现实发展矛盾和一般规律判断趋势 | 不预测每个细节、速度和年份 |
| 现实社会内部的新社会因素 | 旧制度发展中出现可指向新社会的生产和社会条件 | 不是幻想凭空降临 |
| 在批判旧世界中发现新世界 | 研究旧制度矛盾及其变化，发现发展方向 | 不是先画完整未来蓝图 |
| 共产主义崇高理想 | 马克思主义设想的人的自由全面发展的社会理想 | 与现实建设的阶段目标区分 |
| 共产主义基本特征 | 物质财富极大丰富；社会关系高度和谐、精神境界提高；人自由全面发展 | 不能把其中一项当作全部 |
| 生产资料普遍公有 | 生产资料不再以私人资本占有作为社会基础 | 不等于个人日用品全部被取消 |
| 各尽所能、按需分配 | 个人充分发挥能力，生活消费依据需要满足 | 建立在生产力高度发展等条件上 |
| 劳动成为生活的第一需要 | 劳动从谋生负担进一步成为自我发展和实现的重要需要 | **第一需要**不能改成**唯一需要** |
| 旧式社会分工的消失 | 人不再被固定、僵化的社会分工片面束缚 | 不等于任何分工与专业合作立即完全消失 |
| 人的自由而全面发展 | 人在能力、社会关系、生活方式等多方面获得发展 | 不等于人人具有完全相同的能力与生活 |
| 个体与社会发展的统一 | 人的充分发展与共同社会条件相互促进 | 不是个人利益与公共利益永不出现矛盾 |
| 必然王国向自由王国飞跃 | 从主要受不自觉的外在关系支配，走向自觉组织生活、运用规律 | 自由不是超出一切客观规律 |
| 人的依赖性关系 | 人主要受直接人身依附关系约束的历史阶段 | 不等于依赖具体工具 |
| 以物的依赖性为基础的人的独立性 | 人取得形式个人独立，却受商品货币及资本关系制约 | 是对一定历史阶段社会关系的概括 |
| 自由个性 | 在共同社会条件支持下充分发展的个人 | 不等于绝对自我中心主义 |
| 国家的自行消亡 | 阶级对立等社会条件发生变化后国家的阶级统治职能失去基础 | 不能靠宣告、命令提前取消 |
| 历史必然性 | 从社会矛盾运动判断未来变革趋势 | 不是说具体时间路线全可预知 |
| 过程长期性 | 旧社会到新社会、社会主义进一步发展需较长历史过程 | 与历史必然性不矛盾 |
| 远大理想与共同理想 | 长期的共产主义目标与现阶段中国特色社会主义理想追求 | 不能混成同一历史阶段与政策内容 |
