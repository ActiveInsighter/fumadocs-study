## 术语与白话对照

| 术语/词根 | 翻译成人话 | 判断边界 |
|---|---|---|
| 范畴 | 一个高度概括的理论概念 | 不等于某个具体东西 |
| 规定性 | 使事物成为这种事物的性质、限定 | “质的规定性”不是人为规定的制度 |
| 本原 | 世界最根本上是什么、从什么出发解释世界 | 不等于“更重要、更有用” |
| 第一性、第二性 | 谁先在逻辑上具有根本地位、谁依赖谁 | 不是时间上先出生、谁价值大 |
| 同一性 | 依据语境：可认识性；或对立双方相联与转化 | “思维和存在同一性”≠二者完全一样 |
| 对立统一 | 相互区别、矛盾，又相互联系并共同构成整体 | 不是互相抵消或完全和谐 |
| 辩证 | 从联系、发展、矛盾及条件变化看问题 | 不等于折中、各打五十大板 |
| 形而上学（马原语境） | 孤立、静止、片面地看问题 | 不等于日常说的“高深哲学” |
| 客观性 | 不依赖人的主观意志为转移 | 不等于“能用肉眼直接看见” |
| 主观性 | 与人的意识、立场、需要或认识形式有关 | 不天然等于错误或随意 |
| 能动性 | 人有目的地认识、选择、改造，不是被动挨打 | 不等于可以凭空创造现实或规律 |
| 受动性 | 人的活动受到客观条件限制、影响 | 不等于只能消极等待 |
| 中介 | 连接两个环节的媒介、工具、桥梁 | 不是决定二者关系的唯一来源 |
| 对象、客体 | 人认识或改造所指向的东西 | 不意味着对象只能被动、不能变化 |
| 主体 | 进行认识、实践、评价的人或社会群体 | 不等于“自我意识决定一切” |
| 对象化 | 人的能力、劳动通过活动体现在成果中 | 不等于“把人变成物品” |
| 外化 | 原先存在于主体中的能力、目的通过活动表现到外部 | 不等于无条件创造物质 |
| 内化 | 外部知识、规范、经验转化成主体自身能力或观念 | 不等于直接生产客观事物 |
| 自在 | 尚未成为人的有意识实践对象，或尚未自觉把握自身地位 | 依不同章节语境理解 |
| 自为 | 自觉认识自身处境与目标并开展行动 | 与“自在”不是好坏二分 |
| 异化 | 人创造的社会关系或成果反过来支配人、与人相对立 | 不是“任何技术都必然反人类” |
| 异己力量 | 本由人产生却作为外在、难控制的力量与人对立 | 可用于劳动、资本、技术等材料 |
| 扬弃 | 克服旧的消极部分，同时保留、改造合理部分 | 不是全盘否定，也不是原封不动继承 |
| 中介环节 | A 影响 B 必须经过的过程、机制或条件 | 防止“一有想法，现实立刻变”的错误 |
| 源泉 | 某种东西产生的根本来源或内在原因 | 与动力、条件、表现、结果区分 |
| 动力 | 促使事物变化发展的力量 | 不等于所有动力都具有最终决定地位 |
| 实质、核心 | 最能抓住该理论内在内容的一层 | 不能随便替换成“形式、表现” |
| 根本、决定性 | 处在解释链条的基础层，地位最深 | 不排除其他因素的影响、反作用 |
| 直接、间接 | 是否通过另外的中介过程发挥作用 | “直接动力”≠“根本动力” |
| 一般与特殊 | 一类事物的共同点与某个事物的独特性 | 一般存在于特殊之中，不悬空存在 |
| 抽象与具体 | 抽取一面性质；把多种规定和联系综合地把握 | 理论上的“具体”不只是眼前可见 |
| 历史性 | 受一定历史条件和发展阶段制约 | 不等于“已经过时” |
| 合规律性 | 符合对象的客观规律 | 不保证这个目的本身值得追求 |
| 合目的性 | 实现人提出的目的，满足需要 | 不保证手段符合规律、伦理或社会利益 |
| 前提、基础、条件 | 事情成立或发生所需要的支持 | 前提不一定是根本原因或唯一原因 |
| 反作用 | 被决定的一方反过来影响决定方 | 不是把根本决定关系颠倒 |
| 现实性 | 已实际存在、并具有现实根据的状态 | 与“可能性”“纯粹想象”区别 |
| 必然性 | 内部联系支配下的确定趋势 | 不是每个细节和时间都注定 |
| 偶然性 | 非决定性联系、条件交错下可能这样或那样的表现 | 不是无原因、无规律 |
| 一元论/二元论 | 世界本原归一/归二的哲学立场 | 二元论不等于承认事物两面性 |
| 历史主动 | 认识现实趋势并积极创造实现目标的条件 | 不等于随意制定历史规律 |
