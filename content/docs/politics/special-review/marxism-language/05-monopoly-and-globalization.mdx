## 术语与白话对照

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 自由竞争资本主义 | 企业主要通过市场竞争参与资本主义生产 | 不是毫无国家制度存在 |
| 生产集中 | 生产越来越汇集到少数大企业 | 不等于垄断已然形成 |
| 资本集中 | 原有资本合并、重组、并购 | 是垄断形成的重要过程 |
| 垄断 | 少数大企业形成对某些部门生产销售的控制 | **垄断不能消灭竞争** |
| 垄断组织 | 卡特尔、辛迪加、托拉斯、康采恩等形式 | 组织形式不等于没有竞争 |
| 垄断与竞争并存 | 垄断组织之间、内部、对外仍有争夺 | 竞争形式可能更复杂、激烈 |
| 银行垄断资本 | 银行业高度集中形成的垄断资本 | 与工业垄断资本融合形成金融资本 |
| 金融资本 | 银行垄断资本和工业垄断资本融合、相互渗透的资本 | 不是泛指任何银行的钱 |
| 金融寡头 | 控制金融资本并由此掌握重大经济政治影响力的少数大资本集团 | 是群体，不等于“金融资本”本身 |
| 参与制 | 通过层层控股、持股支配多个企业 | 金融寡头在经济领域实现统治的重要方式 |
| 个人联合 | 通过企业领导、管理人员等交叉任职和联系发挥影响 | 常与政治领域统治方式相联系 |
| 垄断利润 | 凭垄断地位取得的高额利润 | 不能说凭空创造了新的社会总价值 |
| 垄断价格 | 垄断组织为获高额利润控制形成的价格 | 不否定价值规律整体作用 |
| 垄断高价 / 垄断低价 | 卖方抬高售价 / 买方压低采购价 | 不保证垄断可无限任意定价 |
| 私人垄断资本主义 | 垄断主体主要是私人资本集团 | 不等于国家从不干预经济 |
| 国家垄断资本主义 | 国家政权和私人垄断资本在经济上结合 | 在马原框架下仍属于资本主义性质 |
| 国有资本与私人资本结合 | 国家与私人垄断资本以投资、采购、扶持等方式发生联系 | 不代表剥削关系自动消失 |
| 资本输出 | 资本以投资、贷款等形式向国外扩张 | 与单纯商品出口不同 |
| 商品输出 | 把商品卖到国外 | 不是直接将资本作为生产经营资金投到国外 |
| 跨国公司 | 在多个国家组织生产经营的公司 | 经济全球化的重要组织形式 |
| 国际垄断同盟 | 各国垄断资本在国际范围形成合作和控制关系 | 不等于国家之间不再竞争 |
| 经济全球化 | 生产、贸易、资本和金融联系跨国深化 | 各地收益并不自动均等 |
| 生产全球化 | 一件产品的生产分布在不同国家和地区 | 不等于一国独立完成全部环节 |
| 贸易全球化 | 跨境商品和服务交易扩展 | 与金融全球化的交易对象不同 |
| 金融全球化 | 资金、资产、金融业务跨境流动联系增强 | 不等于金融风险被消除 |
| 全球化是双刃剑 | 能促进流动和发展，也可能扩大不平等与风险 | 不能绝对说所有国家始终同等受益 |
| 法人资本所有制 | 由公司、机构等法人组织控制资本的所有制形式 | 不等于全体劳动者直接占有生产资料 |
| 雇员持股、参与管理 | 劳资关系在形式和利益安排上出现调整 | 不等于雇佣劳动关系从根本上消失 |
| 职业经理人阶层 | 企业所有权和日常管理职能有所分离 | 不等于管理者都持有全部企业资本 |
| 金融化 | 金融活动、金融利润及金融关系在经济中的作用增强 | 与马克思主义特定的“金融资本”形成概念有别 |
| 经济发展失调 | 资本主义运行中增长、结构、分配等矛盾表现 | 不是资本主义历史上完全没有进步 |
| 政治体制失灵 | 政治调节出现代表性、效率、矛盾治理等问题 | 不等于所有政治活动瞬时停止 |
| 社会融合机制失效 | 社会关系、利益调节难以妥善弥合分化 | 与经济危机不能直接画等号 |
| 资本主义历史进步性 | 曾促进生产力发展、社会联系扩大 | 承认进步性不等于否认基本矛盾 |
| 资本主义历史过渡性 | 作为历史发展阶段，具有不能永久克服的内在矛盾 | 历史趋势不等于明天自动结束 |
| 资本主义生产方式的自我否定 | 自身发展孕育超越原有生产关系的条件与力量 | 不等于市场竞争一多就自动出现社会主义 |
