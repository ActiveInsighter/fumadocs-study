## 术语与白话对照

| 专业术语或晦涩表达 | 人话解释 | 易混或陷阱 |
|---|---|---|
| 科学的世界观和方法论 | 对世界有系统的认识，并提供分析问题的基本方法 | 真题问“马克思主义为什么行”的**根本原因**，不能只答其他正确特点 |
| 自然、社会、人类思维发展的一般规律 | 研究跨领域的共同发展关系，不是背自然科学某一公式 | 不等于对所有事件有具体预言 |
| 马克思主义哲学 | 物质世界、社会历史、认识实践的基础理论 | 三大组成之一 |
| 马克思主义政治经济学 | 揭示资本主义经济关系与价值、剩余价值机制 | 与日常宏观经济学术语不完全等同 |
| 科学社会主义 | 研究社会主义形成的客观依据和实现的现实力量、道路 | 不是空想蓝图 |
| 社会根源 | 工业资本主义发展与矛盾提供的历史土壤 | 不是思想来源 |
| 阶级基础 | 工人阶级的发展与独立政治斗争 | 不等于自然科学前提 |
| 思想渊源 | 德国古典哲学、英国古典政治经济学、英法空想社会主义 | 直接理论来源的三项要匹配 |
| 自然科学前提 | 细胞学说、能量守恒和转化、进化论等成就 | 不等于马克思主义三组成部分 |
| 两个伟大发现 | 唯物史观、剩余价值学说 | 奠定科学社会主义的理论基石 |
| 唯物史观 | 从物质生产、社会关系和人民实践解释历史 | 不是“地理环境决定论” |
| 剩余价值学说 | 解释雇佣劳动条件下剩余价值的产生 | 不是“机器独立创造新价值” |
| 公开问世 | 理论作为明确纲领公开进入历史舞台 | 《共产党宣言》 |
| 首次系统阐述历史唯物主义 | 较完整地说明社会历史发展的唯物主义观点 | 《德意志意识形态》 |
| 全面阐述马克思主义理论体系 | 对哲学、政治经济学、科学社会主义作系统论述 | 《反杜林论》 |
| 第一个无产阶级政党 | 具有明确政治纲领的无产阶级政党组织 | 共产主义者同盟，不等于第一国际 |
| 科学性 | 以科学世界观和方法论认识规律、接受实践检验 | 不等于“永不需要发展” |
| 人民性 | 以人民解放和利益为价值立场 | **本质属性** |
| 实践性 | 从实践中来、在实践中发展并作用于实践 | **实践观点**是首要和基本观点 |
| 发展性 | 与历史条件及新实践相结合而发展 | 不能把理论视为现成方案 |
| 科学性与革命性统一 | 既认识客观规律，又指向现实社会的变革 | 不是“只揭示事实，不考虑立场” |
| 魂脉 / 根脉 | 马克思主义 / 中华优秀传统文化 | 顺序不能颠倒 |
| 认识工具 / 行动指南 / 科学真理 | 帮助看世界 / 指导中国发展 / 说明人类社会发展的真理性 | 三种价值表述各有侧重 |
