## 术语与白话对照

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 实践 | 人有目的地改造客观世界的物质性社会活动 | 单纯幻想、思考不等于实践 |
| 实践的客观实在性 | 活动要通过现实的人、工具和物质过程完成 | 不等于没有主观目标 |
| 自觉能动性 | 实践者能确定目标、选择方式 | 不等于意念直接改变世界 |
| 社会历史性 | 实践在人类社会中进行并受时代条件限制 | 不是孤立个人的活动 |
| 物质生产实践 | 满足物质生活需要的生产劳动活动 | 最基本的实践类型 |
| 社会政治实践 | 改造社会关系、政治制度的现实活动 | 与经济生产实践不同 |
| 科学文化实践 | 在实际活动中探索、验证、创造知识文化 | 科学实验是重要形式但非最基本形式 |
| 实践主体 / 客体 / 中介 | 谁在干 / 对谁或什么干 / 借助什么工具和手段 | 中介扩展认识能力，不凭空造规律 |
| 直接经验 / 间接经验 | 自己亲历所得 / 通过书籍他人获得 | 两者最终来源都可追溯到实践 |
| 实践是认识来源 | 认识材料最终来自人与客观世界的实践接触 | 不等于每人必须事事亲历 |
| 实践是认识动力 | 现实问题、工具发展、实践变化推动认识深化 | 不等于认识没有相对独立性 |
| 实践是认识目的 | 认识最终为指导实践、改造世界服务 | 不等于认识的每一步都立刻实用 |
| 检验真理的唯一标准 | 判断认识是否符合现实最终靠实践检验 | 逻辑证明可辅助，但不与实践并列 |
| 反映论 | 认识是主体对客观世界的反映 | 马原强调**能动**反映，不是消极复制 |
| 能动反映论 | 认识既反映对象，又经主体选择、加工、创造 | 不等于思想任意决定对象 |
| 先验论 | 知识被认为可脱离实践经验、先天地产生 | 与从实践认识世界区别 |
| 直观反映论 | 把认识当成镜子式被动复制 | 忽略主体主动加工 |
| 感性认识 | 对外部现象、直观特征的认识 | 感觉、知觉、表象 |
| 理性认识 | 对本质、规律及内部联系的认识 | 概念、判断、推理 |
| 表象 | 先前感知对象在头脑中留下的形象 | 不是“本质”，也不是纯观念创造 |
| 概念 / 判断 / 推理 | 提炼共性 / 作出断定 / 按逻辑得出结论 | 理性认识的三种形式 |
| 第一次飞跃 | 从感性认识上升到理性认识 | 需感性材料和科学思维加工 |
| 第二次飞跃 | 从理性认识回到实践，指导行动接受检验 | 比停在理论层更具现实意义 |
| 经验论 / 唯理论 | 片面夸大感性经验 / 片面夸大理性认识 | 不能割裂感性理性统一 |
| 非理性因素 | 情感、意志、灵感等影响认识的因素 | 能推动或妨碍，但不能替代客观检验 |
| 认识的反复性 | 受对象复杂性、条件和能力制约，要多次尝试 | 不等于永远无法认识 |
| 认识的无限性 | 实践发展与世界复杂性使认识不断深化 | 不等于个人能在有限时间全知 |
| 认识的上升性 | 经纠错、深化向更高认识发展 | 不是简单原地打转 |
| 主客观具体的历史的统一 | 想法须符合具体时空、条件和发展阶段的现实 | 不等于任何时代照搬同一方案 |
| 真理的客观性 | 判断对错的内容和标准不由个人愿望决定 | 不等于真理在认识形式上不经人脑 |
| 真理的绝对性 | 真理正确反映客观对象，并包含可不断深化的客观内容 | 不等于全知、终极封闭体系 |
| 真理的相对性 | 一项正确认识在广度、深度和条件上有边界 | 不等于“部分正确、部分错误” |
| 真理与谬误 | 符合客观实际的认识 / 不符合的认识 | 在具体条件变化时可能转化 |
| 实践标准的确定性 | 只有实践能最终检验认识真理性 | 不等于任何一次实验已给终极答案 |
| 实践标准的不确定性 | 具体实践受当时条件制约、检验需要深化 | 不等于还有第二个最终标准 |
| 逻辑证明 | 通过逻辑关系和已有知识验证论证 | 重要辅助，但不能替代实践 |
| 价值 | 客观事物的属性对特定主体需要的意义 | 既要看客体，也要看主体需要及关系 |
| 价值主体性 | 对谁有用、有什么意义随主体而异 | 不等于价值全凭想象 |
| 价值客观性 | 客体真实属性与实际需要关系客观存在 | 不等于不同主体评价必然相同 |
| 价值多维性 | 同一对象可以在经济、文化、生态等方面有价值 | 不是“每个维度都同样重要” |
| 价值社会历史性 | 不同时代的社会需要改变价值实现方式 | 不等于人类随意创造客体属性 |
| 潜在价值 / 现实价值 | 有满足需要的可能 / 经过实践真正发挥作用 | 潜在价值往往需实践转化 |
| 价值评价 | 根据主体需要评估事物意义、利弊和优劣 | 可以有合理与错误之分 |
| 认知性评价 | 判断事实是什么、是否真实 | 与“值不值得、好不好”区别 |
| 价值性评价 | 判断事物对主体需求的意义、利弊 | 不是纯粹主观爱好 |
| 真理尺度 / 价值尺度 | 是否符合客观规律 / 是否满足合理需要 | 成功实践应统筹二者 |
| 必然王国 / 自由王国 | 被不自觉的客观关系支配 / 能自觉认识并合理驾驭规律 | 自由不是脱离规律 |
| 守正创新 | 坚持基本正确原则并回应新实践 | 守正非固守旧做法，创新非彻底抛弃原则 |
