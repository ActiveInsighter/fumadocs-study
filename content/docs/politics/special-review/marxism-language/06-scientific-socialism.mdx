## 术语与白话对照

| 专业术语或表达 | 翻译成人话 | 反向辨析 |
|---|---|---|
| 空想社会主义 | 看出旧制度问题并向往新社会，但缺乏科学解释和现实实现道路 | 并非完全没有批判价值 |
| 批判的空想社会主义 | 对资本主义有较深刻批判的一类早期社会主义思想 | 圣西门、傅立叶、欧文是代表 |
| 科学社会主义 | 根据社会发展规律、阶级力量分析社会主义的实现 | 两大发现奠定理论基石 |
| 两大发现 | 唯物史观与剩余价值学说 | 解释历史规律与资本主义剥削机制 |
| 空想走向科学 | 不仅描述好社会，而且说明经济根源、现实力量与路径 | 不等于画出更精细未来城市规划图 |
| 第一国际 | 1864 年成立的国际工人组织 | 不等于世界第一个无产阶级政党 |
| 巴黎公社 | 无产阶级夺取政权的第一次伟大尝试 | 不是第一个长期巩固的社会主义国家 |
| 十月革命 | 1917 年俄国革命，建立社会主义国家的重要历史节点 | 社会主义从理论走向现实 |
| 资本主义经济政治发展不平衡 | 各国发展水平、矛盾及条件并不一致 | 是一国或数国社会主义革命首先胜利论的理论根据 |
| 一国或数国首先胜利论 | 社会主义革命不必所有资本主义国家同时胜利 | 不等于任何国家任何时候都必然首先胜利 |
| 战时共产主义 | 俄国内战时期的非常经济措施，余粮收集、限制商品货币关系等 | 不能等同成熟、永久的社会主义经济模式 |
| 新经济政策 | 通过粮食税、商品交换、市场和多种经济成分恢复发展经济 | 不等于抛弃社会主义建设目标 |
| 由战时共产主义转向新经济政策 | 因现实生产和社会条件调整具体建设办法 | 说明必须从实际出发 |
| 苏联模式 | 一定历史条件下形成的高度集中的建设体制 | 不是社会主义唯一可行模式 |
| 两个必然 | 资本主义必然灭亡、社会主义必然胜利 | 是历史趋势判断，不是到期自动发生 |
| 无产阶级历史使命 | 在特定阶级和社会条件中承担改造旧社会的历史任务 | 不是抽象的个人英雄使命 |
| 无产阶级政党先锋队 | 以工人阶级为阶级基础、由先进分子组成并以科学理论指导的政治组织 | 先进性不能反向决定工人阶级的历史属性 |
| 科学社会主义基本原则 | 对社会主义事业发展的基本规律和方向的概括 | 不等于所有国家同一套政策清单 |
| 基本原则与具体道路统一 | 原理有共同性，制度政策和步骤须结合各国现实 | 反对照搬、教条化与丢弃原则 |
| 社会主义建设长期性 | 生产力、历史条件、国内外矛盾等决定建设需长期探索 | 不能期望政治变革后一切条件立刻成熟 |
| 发展道路多样性 | 不同国家因阶段、历史、文化等条件差异走不同具体道路 | 共同原则不意味着完全相同 |
| 生产力水平与社会发展阶段的决定作用 | 决定不同建设道路的重要根本条件 | 地理、民族因素是影响因素，不能升格为唯一决定因素 |
| 历史文化传统的重要条件 | 既有文化与历史塑造具体政策和路径的特点 | 不是根本决定力量 |
| 时代和实践发展的现实原因 | 新问题使不同国家需要更新路径和方法 | 不是“实践变化就可以随意抛弃基本原则” |
