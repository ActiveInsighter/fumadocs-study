## 易混点速查

| 题干关键词/易混项 | 正确选择或辨析 |
|---|---|
| 近代史开端 | **1840鸦片战争**；因社会性质改变 |
| 民主主义革命由旧到新 | **1919五四运动**；非1921建党 |
| 全民族抗战开始 | **1937七七事变**；中国抗战起点是**1931九一八** |
| 民族意识开始普遍觉醒 | **1894—1895甲午战争战败及瓜分危机** |
| 第一个不平等条约 | **1842《南京条约》** |
| 近代较早诞生的新阶级 | **工人阶级**（早于民族资产阶级） |
| 近代最主要矛盾 | **帝国主义与中华民族的矛盾**；同时另一主要矛盾是封建主义与人民大众 |
| 近代历史任务的前提 | **民族独立、人民解放**；后为国家富强人民幸福 |
| 反侵略战争屡败的内部根本原因 | **社会制度腐败**，经济技术落后是重要原因 |
| 瓜分中国失败的根本原因 | **人民顽强的反侵略斗争**；列强矛盾是其他重要原因 |
| 太平天国土地纲领 | 《天朝田亩制度》；非《资政新篇》 |
| 中国近代较早系统发展资本主义方案 | 《资政新篇》；未实施 |
| 洋务企业“官督商办”性质 | 很多民用企业**基本属资本主义性质**；政治目的仍是维护封建统治 |
| 维新与洋务分歧实质 | **是否学习西方政治制度和思想文化** |
| 维新派的政体方案 | **君主立宪**；革命派才主张民主共和 |
| 革命派与改良派论战焦点 | **是否以革命手段推翻清王朝** |
| 结束君主专制制度 | **辛亥革命**；并未结束整个封建社会 |
| 革命党首次全国性统一资产阶级政党 | **1905中国同盟会**；兴中会是1894革命团体 |
| 新文化运动起点 | **1915陈独秀《青年杂志》**；非1919五四 |
| 最早系统介绍马克思主义 | **李大钊**；与陈独秀创办《青年杂志》不等同 |
| 五四导火线 | **巴黎和会中国外交失败**；俄国十月革命是国际思想条件 |
| 中共首次明确民主革命纲领 | **1922中共二大**；非1921一大 |
| 第一次国共合作正式形成 | **1924国民党一大**；1923中共三大是合作决定 |
| 独立武装反抗国民党反动派第一枪 | **1927南昌起义**；八七会议为政治方针 |
| 思想建党、政治建军 | **1929古田会议**；非1935遵义 |
| 统一战线策略 vs 全面抗战路线 | **1935瓦窑堡** vs **1937洛川** |
| 马克思主义中国化命题 vs 毛泽东思想入党章 | **1938六届六中全会** vs **1945中共七大** |
| 延安整风主要任务 | **反对主观主义，整顿学风** |
| 1947战略进攻 vs 1948战略决战 | 大别山等三路进攻 vs 辽沈淮海平津 |
| 三大战役 vs 南京解放 | 摧毁国民党主要军事力量 vs 南京国民党政权覆灭 |
| 1949建国 vs 1956改造 | 新民主主义革命基本胜利 vs 社会主义基本制度建立 |
| 1949新政协 vs 1954人大 | 临时宪法/新型政党制度 vs 人大制度/社会主义类型宪法 |
| 1978 vs 1981 | 伟大转折、改革开放 vs 指导思想拨乱反正完成 |
| 1982 vs 1992 | 建设有中国特色的社会主义 vs 社会主义市场经济改革目标 |
| 1992南方谈话 vs 十四大 | 重大理论阐释 vs 正式确定市场经济体制目标 |
| 2002、2012、2021小康 | **建设目标**、**建成目标**、**建成目标实现** |
| 1961与1979八字方针 | “调整巩固充实提高” vs “调整改革整顿提高” |
