## 1.1 1840—1919：侵略、觉醒与旧道路探索

| 年份 | 历史事件/文献 | 精准考点/常设陷阱 |
|---|---|---|
| **1839** | 林则徐虎门销烟 | 鸦片战争前的禁烟运动；勿当作近代史分期起点 |
| **1840—1842** | 鸦片战争 | 中国近代史开端；社会性质开始发生变化，不是中国从此才落后 |
| **1841** | 三元里人民抗英 | 近代中国第一次大规模的群众性反侵略武装斗争 |
| **1842** | 中英《南京条约》 | 近代第一个不平等条约；割香港岛、通商口岸、协定关税 |
| **1843** | 中英《虎门条约》；魏源《海国图志》 | 领事裁判权、片面最惠国待遇等；魏源“师夷长技以制夷” |
| **1844** | 中美《望厦条约》、中法《黄埔条约》 | 区分中英《虎门条约》 |
| **1851** | 金田起义 | 太平天国农民战争开始 |
| **1853** | 太平天国定都天京；《天朝田亩制度》 | 以解决农民土地问题为中心，平均主义带空想性 |
| **1856—1860** | 第二次鸦片战争 | 中国主权进一步遭破坏，清政府危机加深 |
| **1858、1860** | 《天津条约》《北京条约》 | 分属第二次鸦片战争，不是1842年的《南京条约》 |
| **1859** | 洪仁玕《资政新篇》 | 近代中国早期比较系统的发展资本主义方案；并未得到实施 |
| **1861前后—1890年代** | 洋务运动 | 封建统治阶级洋务派；“自强、求富”“中体西用” |
| **1864** | 太平天国失败 | 农民阶级局限性与中外反动势力镇压 |
| **19世纪70—80年代** | 边疆危机 | 与甲午战后的列强瓜分狂潮区分 |
| **1894** | 兴中会成立；中日甲午战争开始 | 孙中山提出“振兴中华”；兴中会是革命团体，非全国统一政党 |
| **1895** | 《马关条约》；公车上书 | 台湾、澎湖列岛割让；允许日本在华设厂；帝国主义瓜分狂潮、民族意识普遍觉醒 |
| **1898** | 戊戌维新/百日维新 | 103天；维新派主张君主立宪、制度改革，非民主共和 |
| **1900** | 义和团与八国联军侵华 | 中国反瓜分斗争；须区分反侵略意义和落后局限 |
| **1901** | 《辛丑条约》 | 清政府进一步成为列强统治中国的工具；巨额赔款与驻兵特权 |
| **1905** | 中国同盟会成立；《民报》发刊词 | 中国近代第一个全国性统一的资产阶级革命政党；三民主义 |
| **1905—1907** | 革命派与改良派论战 | 焦点是**要不要以革命手段推翻清王朝**；不是维新派与守旧派思想交锋 |
| **1911-10-10** | 武昌起义 | 辛亥革命高潮；清王朝覆灭进程加速 |
| **1912-01-01** | 中华民国南京临时政府成立 | 资产阶级共和国性质；不等于反帝反封建任务完成 |
| **1912-03** | 《中华民国临时约法》 | 中国历史上第一部具有资产阶级共和国宪法性质的法典 |
| **1913、1915、1917** | 二次革命、护国运动、护法运动等 | 孙中山继续民主共和斗争；不能误写其发动1926北伐 |
| **1915** | 陈独秀创办《青年杂志》（后为《新青年》） | 新文化运动兴起；民主与科学，五四前主要属资产阶级民主主义性质 |
| **1917** | 俄国十月革命 | 给中国先进知识分子以马克思主义和革命实践启示 |
| **1918—1919** | 李大钊介绍十月革命与马克思主义 | 《庶民的胜利》等；1919《我的马克思主义观》较系统传播马克思主义 |
| **1919-05-04** | 五四运动 | 直接导火线是巴黎和会外交失败；新民主主义革命开端，非社会主义革命开始 |

## 1.2 1919—1927：建党、国共合作、大革命

| 年份 | 事件 | 考研专用对应语 |
|---|---|---|
| 1919年6月起 | 五四运动工人运动兴起、中心转至上海 | 北京学生是先锋，工人阶级成为主力；“彻底性”指不妥协立场，不是完成任务 |
| 1920 | 上海、北京等共产党早期组织成立；陈望道译《共产党宣言》 | 上海早期组织由陈独秀等发起；翻译地点不能归到北大 |
| **1921-07** | 中共一大 | **中国共产党正式成立**；集中力量组织工人；一大不是首次提出最低纲领 |
| **1922** | 中共二大 | **第一次明确提出反帝反封建民主革命纲领**、提出民主联合战线策略 |
| 1922 | 安源路矿工人大罢工 | 党首次独立领导取得完全胜利的工人斗争（题库表述） |
| 1923 | 中共三大 | 决定与国民党合作，党员以**个人身份**加入国民党；独立性仍须保持 |
| **1924-01** | 国民党一大 | **第一次国共合作正式形成**；新三民主义为政治基础；党内合作 |
| 1925 | 五卅运动、省港大罢工 | 全国大革命高潮；孙中山于1925年逝世 |
| 1926 | 北伐开始 | 反帝反军阀，工农群众广泛参与；孙中山不可能亲自发动 |
| 1927年4月、7月 | 四一二、七一五反革命政变 | 第一次国共合作破裂、大革命失败；教训是领导权、武装、群众与土地问题 |

## 1.3 1927—1937：土地革命、新道路、长征

| 年份 | 事件 | 考点 |
|---|---|---|
| **1927-08-01** | 南昌起义 | 武装反抗国民党反动派第一枪；独立领导革命战争、创建人民军队的开端 |
| **1927-08-07** | 八七会议 | 确定土地革命和武装起义方针；“枪杆子里面出政权”；纠正右倾错误 |
| 1927-09 | 秋收起义、三湾改编 | 创建工农革命军；“支部建在连上”；井冈山道路探索 |
| 1927-10 | 井冈山革命根据地创建 | 农村革命根据地道路的重要起点 |
| 1927-12 | 广州起义 | 三大起义之一；不等于农村包围城市道路已全面成熟 |
| 1928 | 井冈山会师；《中国的红色政权为什么能够存在？》《井冈山的斗争》 | 工农武装割据、红色政权存在条件 |
| 1928、1929 | 《井冈山土地法》《兴国土地法》 | 由“没收一切土地”向“没收公共土地及地主阶级土地”等调整 |
| **1929-12** | 古田会议 | 思想建党、政治建军，党对军队的绝对领导 |
| **1930** | 《星星之火，可以燎原》《反对本本主义》 | 农村革命道路、调查研究、反对教条主义 |
| **1931** | 瑞金中华苏维埃共和国临时中央政府成立 | 局部革命政权，不是全国执政 |
| 1931—1935 | 王明“左”倾教条主义错误 | 第五次反“围剿”失败与被迫长征的重要背景 |
| **1934-10** | 中央红军开始长征 | 战略转移，不是1935年开始 |
| **1935-01** | 遵义会议 | 主要解决当时迫切的军事与组织问题；党史生死攸关转折点 |
| 1935-10 | 中央红军与陕北红军会师 | 中央红军长征胜利的重要节点，不同于三大主力会师 |
| **1936-10** | 红军三大主力会师 | 长征胜利结束；勿与1935混淆 |

## 1.4 1931—1945：抗战主线（与长征阶段交叠）

| 年份 | 事件 | 考点 |
|---|---|---|
| **1931-09-18** | 九一八事变 | 中国人民抗日战争起点；揭开世界反法西斯战争序幕 |
| 1935 | 华北事变 | 民族危机加剧、民族矛盾上升 |
| **1935-12-09** | 一二·九运动 | 抗日救亡运动新高潮 |
| **1935-12** | 瓦窑堡会议 | 建立抗日民族统一战线的策略方针 |
| **1936-12-12** | 西安事变 | 和平解决促使十年内战局面基本结束、国内和平初步实现 |
| **1937-07-07** | 七七事变（卢沟桥事变） | 中国全民族抗战开始；不应作为抗日战争最早起点 |
| **1937-08** | 洛川会议 | 全面抗战路线、抗日救国十大纲领 |
| **1937-09** | 国共合作宣言发表与蒋介石谈话 | 抗日民族统一战线/第二次国共合作正式形成 |
| 1937-09 | 平型关大捷 | 全民族抗战以来中国军队主动寻歼敌人的第一次重大胜利 |
| 1938 | 台儿庄大捷 | 国民党正面战场重大胜利；区分平型关 |
| **1938-05至06** | 毛泽东《论持久战》 | 驳亡国论和速胜论；战略防御—相持—反攻；兵民是胜利之本 |
| **1938-09至11** | 六届六中全会 | 明确提出“马克思主义的中国化”命题；纠正王明右倾错误 |
| 1938年10月后 | 抗战进入战略相持 | 敌后战场与游击战战略地位显著提高 |
| 1940 | 百团大战；《新民主主义论》 | 敌后抗战重大行动；新民主主义理论系统阐述 |
| 1941—1945 | 延安整风（重点在1942） | 反主观主义整顿学风是最主要任务；反宗派主义、反党八股 |
| 1945-04至06 | 中共七大 | **毛泽东思想确立为党的指导思想并写入党章** |
| **1945-08至09** | 日本宣布投降、签署投降书 | 中国抗战胜利；近代反抗外敌入侵第一次取得完全胜利 |
| 1945-10-25 | 台湾受降仪式 | 战后恢复对台湾行使主权（历史文件链：开罗宣言、波茨坦公告、日本投降书） |

## 1.5 1945—1949：解放战争与建国

| 年份 | 事件 | 标志与陷阱 |
|---|---|---|
| 1945-08至10 | 重庆谈判、《双十协定》 | 中共争取和平民主，不能误作联合抗日 |
| **1946-01** | 旧政治协商会议 | 五项协议，限制一党独裁；不是新民主主义性质的国家制度安排 |
| **1946-05-04** | 五四指示 | 从减租减息转向耕者有其田政策 |
| **1946-06** | 国民党进攻中原解放区 | 全国规模内战爆发，解放军战略防御 |
| **1947-06** | 刘邓大军千里跃进大别山等三路挺进中原 | 解放战争**战略进攻序幕**，非战略决战 |
| 1947 | 《中国土地法大纲》 | 废除封建性及半封建性剥削土地制度、耕者有其田 |
| **1948-04-30** | 中共中央“五一口号” | 召开新政协、筹备联合政府的政治号召 |
| 1948 | 中央请示报告制度 | 加强党中央集中统一领导；非抗日根据地精兵简政 |
| **1948-09至1949-01** | 辽沈、淮海、平津三大战役 | 战略决战，国民党主要军事力量基本被摧毁 |
| **1949-01** | 民主人士《对时局的意见》 | 拥护中国共产党领导，参与筹建新中国 |
| **1949-03** | 七届二中全会 | 工作重心农村转城市；两个务必；由新民主主义向社会主义转变的方向 |
| 1949-03-23至25 | 进京赶考、进驻北平香山 | 执政考验、工作重心转移；不是新中国成立的日期 |
| **1949-04-23** | 南京解放 | 南京国民党政权覆灭，区别三大战役胜利 |
| 1949-06-30 | 《论人民民主专政》 | 新国家政权的理论准备 |
| **1949-09** | 中国人民政治协商会议第一届全体会议 | 代行全国人大职权，建立新型政党制度；《共同纲领》具临时宪法作用 |
| **1949-10-01** | 中华人民共和国成立 | 新民主主义革命基本胜利、半殖民地半封建社会结束；不是社会主义基本制度已建立 |

## 1.6 1949—1978：社会主义制度确立、建设探索

| 年份 | 事件 | 考点 |
|---|---|---|
| 1949以后 | “另起炉灶”“打扫干净屋子再请客”“一边倒” | 新中国初期三项外交方针；不等于闭关锁国 |
| 1950 | 《中华人民共和国土地改革法》；抗美援朝开始 | 完成民主革命遗留任务与巩固新生政权 |
| 1951—1952 | “三反”“五反” | 三反：反贪污、反浪费、反官僚主义；五反针对资本主义工商业违法行为 |
| **1952年底** | 国民经济恢复任务基本完成 | 进入新的有计划建设条件，三大改造尚未完成 |
| **1953** | 过渡时期总路线、“一五”计划实施 | “一化三改”：社会主义工业化，改造农业、手工业、资本主义工商业 |
| **1954-09** | 一届全国人大、第一部社会主义类型宪法 | 人民代表大会制度在全国范围内建立 |
| **1956** | 三大社会主义改造基本完成 | 社会主义基本制度建立；进入社会主义初级阶段 |
| **1956-04** | 《论十大关系》；“第二次结合”探索 | 开始独立探索适合中国的社会主义建设道路，非已找到完整答案 |
| **1956-09** | 中共八大 | 主要矛盾、集中力量发展社会生产力；既反保守又反冒进 |
| 1956 | “百花齐放、百家争鸣”“长期共存、互相监督” | 科学文化与党派关系两类方针，别混成1949“一边倒” |
| **1957** | 《关于正确处理人民内部矛盾的问题》 | 两类不同性质的社会矛盾、人民内部矛盾以民主方法处理 |
| 1958 | 大跃进、人民公社化 | 急于求成和“左”的错误，不能以局部成就否定其严重失误 |
| **1961** | 八字方针“调整、巩固、充实、提高” | 与1979“调整、改革、整顿、提高”区分 |
| 1962 | 七千人大会 | 总结经验教训、纠正部分经济建设错误 |
| 1964—1965 | 三届全国人大提出四个现代化 | 农业、工业、国防、科学技术现代化 |
| **1966—1976** | “文化大革命” | 给党、国家和人民带来严重灾难；1981年历史决议作出系统评价 |
| 1970 | “东方红一号” | 重大科技成就，另有1964首颗原子弹爆炸成功 |
| 1971 | 恢复中华人民共和国在联合国合法席位 | 对外关系重要突破 |
| 1972 | 中美关系开始正常化 | 区分1979中美正式建交 |
| **1976** | 粉碎“四人帮” | “文化大革命”结束，不等于改革开放开始 |

## 1.7 1978—2012：改革开放与中国特色社会主义

| 年份 | 事件 | 历史定位 |
|---|---|---|
| **1978** | 真理标准问题大讨论 | 思想解放先导，批判“两个凡是” |
| **1978-12** | 十一届三中全会 | 思想、政治、组织路线拨乱反正，工作重心转向现代化建设，改革开放伟大转折 |
| 1979 | 《告台湾同胞书》；中外合资经营企业法 | 争取和平统一、对外开放初步展开 |
| **1980** | 深圳、珠海、汕头、厦门四个经济特区 | 不含1988年的海南；同年恢复世行和IMF代表权 |
| **1981** | 十一届六中全会，第二个历史决议 | 《关于建国以来党的若干历史问题的决议》；指导思想拨乱反正完成 |
| **1982** | 中共十二大 | “走自己的道路，建设有中国特色的社会主义” |
| **1984** | 十二届三中全会 | 公有制基础上的有计划商品经济，城市经济体制改革全面展开 |
| **1987** | 中共十三大 | 社会主义初级阶段、基本路线“一个中心两个基本点”、三步走 |
| **1992** | 南方谈话；中共十四大 | 前者阐释改革、社会主义本质、计划市场都是经济手段；后者确立社会主义市场经济体制改革目标 |
| **1997** | 中共十五大 | 邓小平理论确立为指导思想并写入党章；社会主义初级阶段基本纲领 |
| **1997、1999** | 香港、澳门回归祖国 | “一国两制”实践的重要节点 |
| **2001** | 中国加入世界贸易组织 | 必须排除“截至1997年十五大召开前”之类的时间限定 |
| **2002** | 中共十六大 | “三个代表”重要思想确立指导地位；全面建设小康社会 |
| **2007** | 中共十七大 | 科学发展观、中国特色社会主义理论体系等 |

## 1.8 2012年以来：新时代，兼顾更新

| 年份 | 事件 | 要点 |
|---|---|---|
| **2012** | 中共十八大 | 确保到2020年全面建成小康社会；新时代历史起点 |
| **2017** | 中共十九大 | 明确新时代方位；新社会主要矛盾；习近平新时代中国特色社会主义思想写入党章 |
| **2019** | 十九届四中全会 | 坚持完善中国特色社会主义制度、推进国家治理体系和治理能力现代化 |
| **2021-02** | 脱贫攻坚取得全面胜利 | 区分2021年7月宣布全面建成小康社会 |
