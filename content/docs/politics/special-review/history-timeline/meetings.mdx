## 2.1 1921—1949：革命时期会议纵向总表

| 会议 | 时间、地点 | 核心考点 | 最容易混成什么 |
|---|---|---|---|
| **中共一大** | 1921年7月，上海、嘉兴南湖 | 建党，马克思列宁主义指导，集中力量组织工人 | 不是反帝反封建民主革命**最低纲领**的首次明确提出 |
| **中共二大** | 1922年7月，上海 | 首次明确提出反帝反封建民主革命纲领；最高纲领与最低纲领 | 不是正式国共合作 |
| **中共三大** | 1923年6月，广州 | 决定建立国共合作，党员个人加入国民党 | 1924国民党一大才是第一次合作**正式形成** |
| **国民党一大** | 1924年1月，广州 | 新三民主义、联俄联共扶助农工；第一次国共合作正式形成 | 与中共三大不能调换；“政治基础”是新三民主义 |
| **八七会议** | 1927年8月7日，汉口 | 批判陈独秀右倾错误，确定土地革命和武装起义方针，“枪杆子里面出政权” | 南昌起义已在8月1日，不能说八七会议第一次打响起义枪声 |
| **古田会议** | 1929年12月，福建上杭 | 红四军党的九大，思想建党、政治建军，红军是执行革命政治任务的武装集团 | 不是遵义会议、也不是七大首次写入毛泽东思想 |
| **遵义会议** | 1935年1月，贵州遵义 | 重点解决军事、组织问题；生死攸关的转折点；独立自主处理革命问题 | 不是确定抗日民族统一战线策略的瓦窑堡会议 |
| **瓦窑堡会议** | 1935年12月，陕北 | 建立广泛抗日民族统一战线的策略方针，反关门主义 | 不是1937全面抗战路线的洛川会议 |
| **洛川会议** | 1937年8月，陕北 | 全面抗战路线、《抗日救国十大纲领》，发动全民族抗战 | 不是1935瓦窑堡的统一战线策略、不是1938《论持久战》 |
| **六届六中全会** | 1938年9—11月，延安 | 毛泽东明确提出“马克思主义的中国化”命题，巩固独立自主原则和统一战线正确方针，克服王明右倾错误 | 不是1945把毛泽东思想写入党章的中共七大 |
| **六届七中全会** | 1944—1945，延安 | 通过《关于若干历史问题的决议》，统一思想认识，为七大召开创造条件 | 与1981、2021历史决议区分 |
| **中共七大** | 1945年4—6月，延安 | 毛泽东思想确立为党的指导思想并写入党章；政治路线；三大优良作风 | 不要误选古田会议“思想建党政治建军” |
| **旧政治协商会议** | 1946年1月，重庆 | 国共各方协商五项协议，一定程度限制一党独裁，性质**不是新民主主义** | 1949年新政协有建国纲领，不是这次旧政协 |
| **七届二中全会** | 1949年3月，西柏坡 | 工作重心由乡村转向城市；从农业国向工业国、从新民主主义向社会主义转变；**两个务必** | 不能说1949已完成社会主义改造 |
| **中国人民政治协商会议第一届全体会议** | 1949年9月，北平 | 代行全国人大职权，通过《共同纲领》；新型政党制度确立；选举中央人民政府有关机构领导人 | 不同于1954年第一届全国人大与正式宪法 |

## 2.2 1949以后：制度、改革、理论定位会议

| 会议 | 时间 | 最该背的一句话 |
|---|---|---|
| **一届全国人大一次会议** | **1954** | 第一部社会主义类型宪法；人民代表大会制度在全国范围内建立 |
| **中共八大** | **1956** | 社会主义制度确立后的主要矛盾，集中力量发展社会生产力；在综合平衡中稳步前进 |
| **七千人大会** | **1962** | 总结经济建设中出现的经验教训 |
| **三届全国人大一次会议** | **1964—1965** | 农业、工业、国防、科学技术四个现代化目标 |
| **十一届三中全会** | **1978** | 改革开放伟大转折、工作重点转经济建设、重新确立正确路线 |
| **十一届六中全会** | **1981** | 第二个历史决议；指导思想拨乱反正完成 |
| **中共十二大** | **1982** | “走自己的道路，建设有中国特色的社会主义” |
| **十二届三中全会** | **1984** | 有计划的商品经济，城市经济体制改革全面展开 |
| **中共十三大** | **1987** | 初级阶段理论、一个中心两个基本点、三步走 |
| **中共十四大** | **1992** | 建立社会主义市场经济体制改革目标 |
| **中共十五大** | **1997** | 邓小平理论写入党章，确立为指导思想 |
| **中共十六大** | **2002** | “三个代表”重要思想写入党章；全面**建设**小康社会 |
| **中共十七大** | **2007** | 科学发展观阐述、中国特色社会主义理论体系概括 |
| **中共十八大** | **2012** | 确保全面**建成**小康社会，新的历史方位的起点 |
| **中共十九大** | **2017** | 新时代政治判断、主要矛盾变化、习近平新时代中国特色社会主义思想指导地位 |
| **十九届四中全会** | **2019** | 国家制度和治理体系、治理能力现代化 |
| **十九届六中全会** | **2021** | 第三个历史决议，百年奋斗成就和经验 |
| **中共二十大** | **2022** | 中国式现代化与全面建设社会主义现代化国家中心任务 |
| **二十届三中全会** | **2024** | 进一步全面深化改革、推进中国式现代化 |
| **二十届四中全会** | **2025** | “十五五”规划建议；与2024年的全面深化改革《决定》不要混 |

## 2.3 同名“X大”对照：一分钟扫盲

- **一大：成立党**；**二大：提出民主革命纲领**；**三大：中共决定国共合作**；**1924国民党一大：正式合作**。
- **古田会议：怎样建党、建军**；**遵义会议：怎样在危局中独立自主纠正错误**；**瓦窑堡：与哪些力量联合抗日**；**洛川：怎样动员全国抗战**。
- **六届六中：马克思主义中国化命题**；**延安整风：全党思想路线和学风建设**；**七大：毛泽东思想写入党章**。
- **七届二中：准备全国执政，工作重心转移**；**1949政协：协商建国**；**1954人大：正式确立根本政治制度**。
- **1956八大：社会主义建设任务**；**1978十一届三中：改革开放转折**；**1981十一届六中：总结党史与拨乱反正**。
- **1982十二大：建设有中国特色的社会主义**；**1987十三大：初级阶段基本路线**；**1992十四大：市场经济目标**；**1997十五大：邓小平理论**；**2002十六大：“三个代表”**；**2007十七大：科学发展观与理论体系**。
- **2017十九大：新时代主要矛盾与思想地位**；**2021十九届六中：百年决议**；**2022二十大：中国式现代化中心任务**；**2024二十届三中：进一步全面深化改革**；**2025二十届四中：“十五五”**。
