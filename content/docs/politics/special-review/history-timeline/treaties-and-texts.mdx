## 3.1 不平等条约与战争结果

| 战争、时期 | 条约或文件 | 考法和性质 |
|---|---|---|
| 鸦片战争 | 1842《南京条约》、1843《虎门条约》 | 第一个不平等条约、司法/关税等主权受损 |
| 鸦片战争后 | 1844中美《望厦条约》、中法《黄埔条约》 | 2012-26题库考过美国、法国对应条约 |
| 第二次鸦片战争 | 1858《天津条约》、1860《北京条约》 | 侵略特权扩大、主权损害进一步加深 |
| 甲午战争 | 1895《马关条约》 | 台湾及澎湖列岛割让、列强投资设厂特权、瓜分狂潮与民族普遍觉醒 |
| 八国联军侵华 | 1901《辛丑条约》 | 清政府沦为帝国主义统治中国的工具这一教材经典判断 |
| 抗战胜利 | 1943《开罗宣言》、1945《波茨坦公告》《日本投降书》 | 战后日本窃取中国领土归还的文件链；与《德黑兰宣言》区分 |

## 3.2 中国近代各社会力量探索方案

| 力量/运动 | 文献与主张 | 目的、进步性 | 根本限制 |
|---|---|---|---|
| 农民阶级太平天国 | 《天朝田亩制度》平均土地 | 农民反封建愿望，土地诉求强烈 | 小生产者绝对平均主义，空想性 |
| 太平天国后期 | 《资政新篇》发展工商业、资本主义 | 近代比较系统发展资本主义设想 | 缺乏社会经济基础，没有实行 |
| 洋务派 | 中体西用、自强求富 | 引入近代企业、军备、教育 | 封建性、依赖性、管理腐朽；目的仍是维护封建统治 |
| 资产阶级维新派 | 君主立宪、兴民权、设议院 | 爱国救亡、政治改良、思想启蒙 | 寄希望于皇帝与列强，不敢发动群众 |
| 资产阶级革命派 | 旧三民主义、民主共和 | 推翻君主专制、建立共和国 | 反帝反封建纲领不彻底、群众与政党力量不足 |

## 3.3 三民主义：旧、新、三大政策

| 主题 | 旧三民主义（1905） | 新三民主义（1924） |
|---|---|---|
| 民族主义 | 驱除鞑虏、恢复中华；**未鲜明提出彻底反帝纲领** | 突出反帝，主张中国境内各民族平等 |
| 民权主义 | 创立民国，资产阶级共和国 | 强调民权为一般平民所共有 |
| 民生主义 | 平均地权（不等同于把地主土地平均分给农民） | 平均地权、节制资本；后来还发展出耕者有其田主张 |
| 合作基础 | 尚不具备1924年合作基础 | 与中国共产党民主革命阶段纲领基本一致，是第一次国共合作政治基础 |
| 三大政策 | 旧三民主义不含1924完整政策 | 联俄、联共、扶助农工；三大政策**不是**三民主义本身的三个“主义” |

**注意**：1924年新三民主义不是直接等于中国共产党最高纲领；二者只是在**民主革命阶段**有基本一致的政治要求。

## 3.4 关键人物、著作与“最早/开始/成熟”

| 人物/文献 | 历史定位 | 误选辨析 |
|---|---|---|
| **林则徐《四洲志》** | 近代中国开眼看世界第一人 | 不等同以制度改革为重点 |
| **魏源《海国图志》** | 师夷长技以制夷：主要学习外国**军事和科学技术** | “长技”不是民主共和国制度 |
| **严复《天演论》** | 物竞天择、适者生存，救亡图存思潮 | 与孙中山“振兴中华”口号出处区分 |
| **孙中山《兴中会章程》** | 1894提出“振兴中华” | 1905同盟会纲领才提出“创立民国” |
| **《民报》发刊词** | 1905孙中山将纲领概括为民族、民权、民生 | 与《新民丛报》改良派阵地不同 |
| **《中华民国临时约法》** | 1912资产阶级共和国宪法性质法典，主权在民、国民平等 | 不是废除全部不平等条约，更非废除封建土地制度 |
| **李大钊《我的马克思主义观》** | 1919系统传播马克思主义 | 与1915陈独秀创办《青年杂志》区分 |
| **《中国的红色政权为什么能够存在？》《井冈山的斗争》** | 1928红色政权存在条件、工农武装割据 | 与1935遵义会议不同 |
| **《星星之火，可以燎原》** | 1930革命道路与农村根据地思想 | 不是单纯强调先占大城市 |
| **《反对本本主义》** | 1930调查研究，“没有调查，没有发言权”，反教条主义 | 与1938“马克思主义中国化”命题区分 |
| **《论反对日本帝国主义的策略》** | 1935阐明抗日民族统一战线策略 | 不是1938解释持久战三阶段 |
| **《中国革命战争的战略问题》** | 1936中国革命战争战略总结 | 与《论持久战》抗日战争背景不同 |
| **《实践论》《矛盾论》** | 1937思想方法与哲学总结 | 不直接等于古田会议建军决议 |
| **《论持久战》** | 1938揭示中日战争客观特点与战略三阶段 | 不是速胜论，也不是亡国论 |
| **《〈共产党人〉发刊词》** | 1939统一战线、武装斗争、党的建设三个法宝 | 将党的建设称“伟大工程” |
| **《新民主主义论》** | 1940较系统阐述新民主主义政治、经济、文化 | 与1945确立毛泽东思想指导地位区分 |
| **1945《关于若干历史问题的决议》** | 六届七中全会，总结党内历史问题 | 第一个历史决议 |
| **《论人民民主专政》** | 1949新中国国体与国家政权理论准备 | 不等于1954社会主义类型宪法 |
| **1949《共同纲领》** | 新民主主义性质，起**临时宪法作用** | 不是社会主义基本制度建立 |
| **《论十大关系》** | 1956调动国内外一切积极因素、探索社会主义建设道路 | “开始探索”≠已经完成“第二次结合” |
| **《关于正确处理人民内部矛盾的问题》** | 1957区分敌我矛盾与人民内部矛盾，民主方法 | 与社会基本矛盾、主要矛盾不同 |
| **1981《关于建国以来党的若干历史问题的决议》** | 第二个历史决议，评价重大历史问题、指导思想拨乱反正 | 不是1945，也不是2021 |
| **2021《关于党的百年奋斗重大成就和历史经验的决议》** | 第三个历史决议，四阶段、五大历史意义、十条经验 | 不应提前到2017十九大 |

## 3.5 三个历史决议必背

1. **1945年六届七中全会**：《关于若干历史问题的决议》，总结建党以来特别是重大路线斗争的经验，统一党内思想，为七大作准备。
2. **1981年十一届六中全会**：《关于建国以来党的若干历史问题的决议》，科学评价建国以来重大历史问题、毛泽东历史地位和毛泽东思想，标志指导思想拨乱反正完成。
3. **2021年十九届六中全会**：《中共中央关于党的百年奋斗重大成就和历史经验的决议》，总结党百年奋斗成就、历史意义和经验。
