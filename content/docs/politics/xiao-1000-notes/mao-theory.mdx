## 导论与毛泽东思想


### 马克思主义中国化时代化与毛泽东思想

- 马克思主义中国化时代化，就是把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合。
- 马克思主义中国化时代化的理论成果之间既一脉相承又与时俱进。
- 毛泽东思想形成发展的时代条件是：**战争与革命**；实践基础是：**中国革命和建设的实践**。
- 毛泽东思想活的灵魂是：**实事求是、群众路线、独立自主**。


### 活的灵魂与历史地位

- 毛泽东思想的精髓是：**实事求是**。
- 群众路线的基本内容：**一切为了群众，一切依靠群众**；从群众中来，到群众中去。
- 独立自主是中国革命和建设的基本立足点。
- 毛泽东思想是马克思主义中国化时代化的第一次历史性飞跃，是中国革命和建设的科学指南。


## 新民主主义革命理论


### 社会性质、革命任务与革命对象

- 近代中国社会性质是：**半殖民地半封建社会**；近代中国最主要矛盾是：**帝国主义和中华民族的矛盾**。
- 近代中国革命的根本任务是：**推翻帝国主义、封建主义和官僚资本主义的统治**。
- 新民主主义革命总路线：**无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命**。
- 新民主主义革命的对象是：**帝国主义、封建主义、官僚资本主义**；首要对象是帝国主义。


### 革命动力、领导力量与性质

- 新民主主义革命的动力包括：**工人阶级、农民阶级、城市小资产阶级、民族资产阶级**。
- 新民主主义革命的领导力量是：**无产阶级及其政党**；这是区别新旧民主主义革命的根本标志。
- 中国革命的主力军是：**农民**；无产阶级最可靠的同盟军是：**贫雇农**。
- 新民主主义革命的性质是：**资产阶级民主主义革命，前途是社会主义**。


### 革命道路与三大法宝

- 新民主主义革命道路是：**农村包围城市、武装夺取政权**。
- 中国革命道路形成的根本原因是：**中国半殖民地半封建社会的国情**。
- 新民主主义革命三大法宝是：**统一战线、武装斗争、党的建设**。
- 统一战线中的两个联盟：**工农联盟是基础**；同非劳动人民的联盟是必要补充。
- 武装斗争是中国革命的主要斗争形式；人民军队唯一宗旨是：**全心全意为人民服务**。

## 社会主义改造与初步探索


### 过渡时期总路线与三大改造

- 过渡时期总路线的主体是：**实现社会主义工业化**；两翼是：**对农业、手工业和资本主义工商业的社会主义改造**。
- 农业社会主义改造遵循原则：**自愿互利、典型示范、国家帮助**；道路是互助合作。
- 手工业社会主义改造道路是：**合作化**。
- 资本主义工商业社会主义改造方式是：**和平赎买**；高级形式是公私合营。
- 社会主义改造完成的标志是：**社会主义基本制度在我国确立**。


### 基本制度确立与社会主义建设探索

- 社会主义基本制度确立后，我国社会主要矛盾转化为：**人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾**。
- 《论十大关系》标志着党探索中国社会主义建设道路的良好开端。
- 社会主义社会基本矛盾仍是：**生产关系和生产力、上层建筑和经济基础之间的矛盾，但具有非对抗性**。
- 正确处理人民内部矛盾的总方针是：**民主的方法**；处理敌我矛盾用专政的方法。


| 高频考法 | 对应内容 |
| --- | --- |
| 过渡时期总路线的**主体** | 实现社会主义工业化 |
| 过渡时期总路线的**两翼** | 对农业、手工业和资本主义工商业的社会主义改造 |
| 农业改造 | 互助合作；自愿互利、典型示范、国家帮助 |
| 手工业改造 | 合作化 |
| 资本主义工商业改造 | 和平赎买；高级形式为公私合营 |

<Callout type="info" title="时间与概念边界">

**社会主义改造完成**标志社会主义基本制度在我国确立，不等于社会主义现代化已经完成。

</Callout>


## 中国特色社会主义理论体系


### 邓小平理论与改革开放

- 邓小平理论首要的基本理论问题是：**什么是社会主义、怎样建设社会主义**。
- 社会主义本质：**解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕**。
- 社会主义初级阶段基本路线的核心内容是：**一个中心、两个基本点**；中心是经济建设。
- 改革开放是决定当代中国命运的关键一招，也是决定实现“两个一百年”奋斗目标和民族复兴的关键一招。


### 社会主义市场经济、“三个代表”与科学发展观

- 社会主义市场经济理论突破了把计划经济和市场经济看作社会制度属性的传统观念。
- “三个代表”重要思想回答的核心问题是：**建设什么样的党、怎样建设党**。
- 中国共产党始终代表：**中国先进生产力的发展要求**；中国先进文化的前进方向；中国最广大人民的根本利益。
- 科学发展观第一要义是：**发展**；核心立场是：**以人为本**；基本要求是：**全面协调可持续**；根本方法是：**统筹兼顾**。


| 理论或概念 | 对应关键词 |
| --- | --- |
| 邓小平理论的首要基本理论问题 | 什么是社会主义、怎样建设社会主义 |
| “三个代表”重要思想回答的核心问题 | 建设什么样的党、怎样建设党 |
| 科学发展观 | 发展、以人为本、全面协调可持续、统筹兼顾 |
