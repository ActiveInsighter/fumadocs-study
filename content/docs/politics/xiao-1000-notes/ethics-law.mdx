## 人生观与理想信念


### 人生目的、人生价值与实现路径

- 人生观的核心是：**人生目的**；人生目的是人生实践活动的总目标，决定人生态度和人生价值选择。
- 人生价值包括**自我价值和社会价值**，评价人生价值的根本尺度是看一个人的实践活动是否符合社会发展客观规律、是否促进历史进步。
- 评价人生价值的根本标准是：**劳动以及通过劳动对社会和他人作出的贡献**。
- 人生价值实现的根本途径是：**社会实践**。


### 理想信念与个人理想

- 理想具有**超越性、实践性、时代性**；信念具有**执着性、支撑性、多样性**。
- 理想信念是人的精神世界的核心，是人精神上的“钙”。
- 中国特色社会主义共同理想是现阶段我国各族人民的共同理想。
- 个人理想只有同国家前途、民族命运相结合，才有价值和生命力。

| 容易混淆的考点 | 标准定位 |
| --- | --- |
| 人生观的**核心** | **人生目的** |
| 评价人生价值的**根本尺度** | 是否符合社会发展客观规律、是否促进历史进步。 |
| 评价人生价值的**根本标准** | **劳动以及通过劳动对社会和他人作出的贡献** |
| 实现人生价值的**根本途径** | **社会实践** |

<Callout type="warn" title="尺度、标准、途径不可混用">

**根本尺度**回答“是否符合历史进步方向”，**根本标准**回答“通过什么贡献评价”，**根本途径**回答“怎样实现人生价值”。

</Callout>


## 中国精神与社会主义核心价值观


### 民族精神、时代精神与爱国主义

- 中国精神是兴国强国之魂，包括以**爱国主义**为核心的民族精神和以**改革创新**为核心的时代精神。
- 爱国主义的基本内涵：**爱祖国的大好河山、爱自己的骨肉同胞、爱祖国的灿烂文化、爱自己的国家**。
- 新时代爱国主义的本质是：**坚持**爱国和爱党、爱社会主义高度统一**。
- 民族精神的核心是：**爱国主义**；时代精神的核心是：**改革创新**。


### 核心价值观的三个层面

- 社会主义核心价值观国家层面：**富强、民主、文明、和谐**；社会层面：**自由、平等、公正、法治**；个人层面：**爱国、敬业、诚信、友善**。
- 社会主义核心价值观是当代中国精神的集中体现，凝结着全体人民共同的价值追求。
- 坚定价值观自信，必须自觉以社会主义核心价值观引领多样化社会思潮。

## 道德建设


### 道德的起源、功能与社会主义道德原则

- 道德起源于人类的历史发展和**社会实践**，本质上是由经济基础决定的特殊社会意识形态。
- 道德的主要功能包括：**认识功能、规范功能、调节功能**。
- 社会主义道德建设的核心是：**为人民服务**；原则是：**集体主义**。
- 集体主义强调国家利益、社会整体利益和个人利益的辩证统一。


### 社会公德、职业道德、家庭美德与个人品德

- 社会公德主要规范：**文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法**。
- 职业道德主要规范：**爱岗敬业、诚实守信、办事公道、热情服务、奉献社会**。
- 家庭美德主要规范：**尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里互助**。
- 个人品德是通过社会道德教育和个人自觉道德修养形成的稳定心理状态和行为习惯。

| 道德规范类别 | 具体要求 |
| --- | --- |
| **社会公德** | 文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法。 |
| **职业道德** | 爱岗敬业、诚实守信、办事公道、热情服务、奉献社会。 |
| **家庭美德** | 尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里互助。 |
| **个人品德** | 通过社会道德教育和个人自觉道德修养形成的稳定心理状态和行为习惯。 |

<Callout type="warn" title="社会主义道德建设的核心与原则">

**核心是为人民服务，原则是集体主义。** 题目若问“核心”不可误选“集体主义”；问“原则”不可误选“为人民服务”。

</Callout>


## 法治观与法律基础


### 社会主义法律、法治总目标与法治体系

- 法律是由国家制定或认可并由国家强制力保证实施的行为规范体系。
- 我国社会主义法律的本质特征：**体现党的主张和人民意志的统一，具有科学性和先进性**。
- 全面依法治国总目标是：**建设中国特色社会主义法治体系，建设社会主义法治国家**。
- 中国特色社会主义法治体系包括：**完备的法律规范体系、高效的法治实施体系、严密的法治监督体系、有力的法治保障体系、完善的党内法规体系**。
- 坚持走中国特色社会主义法治道路，必须坚持**党的领导、人民当家作主、依法治国有机统一**。


### 宪法原则、法治思维与法律权利义务

- 宪法是国家的**根本法**，具有最高法律地位、法律权威、法律效力。
- 我国宪法的基本原则包括：**党的领导原则、人民当家作主原则、尊重和保障人权原则、社会主义法治原则、民主集中制原则**。
- 法治思维主要内容：**法律至上、权力制约、公平正义、权利保障、正当程序**。
- 法律权利与法律义务相互依存、相互贯通，二者在总量上是等值的、功能上互补。
- 大学生应尊法学法守法用法，自觉维护宪法法律权威。
