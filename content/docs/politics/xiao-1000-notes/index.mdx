## 如何使用这份笔记

<Steps>
<Step>

### 抓住答案关键词

先背**本质、核心、根本、标志、基础、源泉、特征、目的**等高频定位词，再复述完整判断句。

</Step>
<Step>

### 连带记忆并列考点

遇到**包括、表现、要求、原则、途径**等提问，把并列点逐项记牢，避免多选题漏选。

</Step>
<Step>

### 用对照表排除易混选项

尤其要区别**原因与条件、主体与两翼、领导力量与革命性质、绝对与相对剩余价值**等概念。

</Step>
</Steps>

<Tabs items={['单选题', '多选题', '易混辨析', '材料分析']} defaultIndex={0}>
<Tab value="单选题">

优先定位一句话里的 **“唯一”“根本”“首要”“核心”“实质”**，记清每个限定词对应的概念。

</Tab>
<Tab value="多选题">

把分号分开的各点当作**同一组考点**记忆，并注意它们是否具有不同层次。

</Tab>
<Tab value="易混辨析">

先确定题干问的是**划分标准、根本原因、现实条件还是结果表现**，再排除偷换概念的表述。

</Tab>
<Tab value="材料分析">

围绕**理论观点 → 结合材料 → 现实意义**组织表达；不能只堆关键词而不回应材料。

</Tab>
</Tabs>
