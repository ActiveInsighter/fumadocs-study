## 考点100 “一国两制”是中国特色社会主义的伟大创举

### 1. 从基本概念理解“一国两制”

**“一国两制”**&#x2060;是指在**一个统一的中华人民共和国之内**，**国家主体实行社会主义制度**，香港、澳门等个别地区依法保留原有的资本主义制度和生活方式。实践与法律安排必须放在「**一个国家**」的大前提下理解。

- **提出与应用的先后**：最早**针对台湾问题**提出，**首先运用于解决香港、澳门问题**。考选择题时尤其注意把「提出」和「实践」对换的错误选项。
- **制度性质**：是中国特色社会主义制度创新的重要成果、中国共产党领导人民实现祖国和平统一的伟大构想，是国家的基本国策。
- **思想方法**：体现原则性与灵活性、现实性与长远性、一致性与差异性的统一，包含中华文化的**和合理念**，体现尊重差异、求同存异。
- **对外启示**：为国际社会处理类似问题提供新思路、新方案，但不能推成各国都照搬完全一样的制度。

### 2. 什么是高度自治

香港、澳门是**直辖于中央人民政府的地方行政区域**，依法享有行政管理权、立法权、独立的司法权和终审权等高度自治权。**高度自治≠完全自治≠国家主权**，权力来源是**中央授权**。

肖1000多选1、2尤其侧重它作为**制度创新、和平统一构想、和合理念、差异协调**的综合意义。考题常把这几项全部列为正确；如果选项称港澳为独立主权国家，则与基本国情和法理前提冲突。

## 考点101 准确把握“一国两制”的科学内涵，坚持和完善制度体系

### 1. 「最高原则」与「根本宗旨」是两道不同题

| 题干限定词 | 对应标准表述 |
| --- | --- |
| **最高原则** | **维护国家主权、安全、发展利益** |
| **根本宗旨** | **维护国家主权、安全、发展利益，保持香港、澳门长期繁荣稳定** |
| “一国”的地位 | **“一国”是实行“两制”的前提和基础** |
| “两制”的地位 | **“两制”从属和派生于“一国”，统一于“一国”之内** |
| 两种制度关系 | 在“一国”前提下和谐相处、相互促进，**不能等量齐观、比肩并列** |

<Callout type="warn" title="别把“宗旨”机械缩成“最高原则”">
两者前半句相同，但“根本宗旨”**还包括保持港澳长期繁荣稳定**；题干是**多选**或给出两组表述时尤其要看是否遗漏后半部分。
</Callout>

### 2. 中央全面管治权与特区高度自治权

**全面管治权是授权特别行政区高度自治的前提和基础，高度自治权是中央行使全面管治权的体现。**&#x2060;两者是**源与流、本与末**的关系，不是彼此对立的主权分配。

- **全面管治权**：中央对特别行政区依法拥有的全面管治权限。
- **高度自治权**：依宪法、基本法和中央授权行使的地方事务管理权，不是特区固有权力。
- **不存在所谓“剩余权力”**：并非「中央未明说的全部权力都由特区享有」。
- **依法治港治澳**：宪法和基本法**共同构成**特别行政区的宪制基础；国家主权、安全、发展利益是制度运行不能突破的根本界限。
- **爱国者治港／爱国者治澳**：这是事关国家主权、安全、发展利益及港澳长期繁荣稳定的**根本原则**，也是保证长治久安的必然要求。

### 3. 【2015-8】高度自治权的权力来源

**题干摘要**：香港回归、基本法实施后，香港特别行政区的高度自治权是什么？

**答案：D．中央授予的地方事务管理权。**

- **A 完全自治权**：错误，高度自治不等于国家完全自治。
- **B 中央授权之外的剩余权力**：错误，特别行政区不存在所谓剩余权力。
- **C 特别行政区固有的权力**：错误，其权力来源于**中央授权**。
- **D 中央授予的地方事务管理权**：正确，直接揭示权力性质和来源。

**题型归纳：权力性质题**。答题顺序是「**单一制国家—中央全面管治权—法定授权—高度自治**」，不靠「自治程度高」推定主权属性。

### 4. 【2019-25】“一国”和“两制”如何有机结合

**原题要求**：在坚持“一国”基础上，使“两制”之间和谐相处、相互促进，以下哪些必须做到？

**答案：ABD。**

| 选项 | 判断 | 关键理由 |
| --- | --- | --- |
| **A** 维护中央权力和保障特区高度自治权结合 | **正确** | 中央全面管治权是特区自治的来源与前提 |
| **B** 坚持“一国”原则和尊重“两制”差异结合 | **正确** | 坚持原则和尊重差异统一 |
| **C** 利用国际有利条件和发挥港澳优势结合 | **不选** | 说法可用于发展工作，但**不直接回答“一国”与“两制”关系** |
| **D** 发挥祖国内地坚强后盾作用与提高港澳自身竞争力结合 | **正确** | 两种制度在一个国家中可以互促 |

**方法**：多选题不能只判定某个说法「是否正面」，必须继续判定它是否属于**题干所限定的关系范畴**。C常被误选，原因是它本身表述不必然错误，却不解决这道题的逻辑问题。

### 5. 肖1000的三类重要变式

1. **关系正误（多选4）**：“一国”是根、本、前提；“两制”派生从属；**“两制等量齐观”错误**。
2. **权源判断（多选5）**：全面管治权和高度自治权统一；属**源与流、本与末**；**没有“剩余权力”**。
3. **原则保障（多选6）**：“爱国者治港／治澳”关系主权安全、发展利益及港澳繁荣稳定；不要机械套用「党的领导是人民当家作主和依法治国的根本保证」来替换本题定义。

## 考点102 保持香港、澳门长期繁荣稳定，支持融入国家发展大局

### 1. 港澳治理的工作抓手

- 依法维护国家安全、完善维护国家安全的法律制度和执行机制。
- 健全特别行政区选举和治理制度，坚持和完善「爱国者治港」「爱国者治澳」。
- 支持行政长官及特别行政区政府依法施政，完善依法治理、巩固宪法和基本法共同确立的宪制秩序。
- 充分发挥**背靠祖国、联通世界**的优势，积极参与**粤港澳大湾区建设**、共建“一带一路”等国家发展战略。

**三组地位易混**：「一国两制」是港澳发展**最大优势**；国家改革开放是**最大舞台**；共建“一带一路”、粤港澳大湾区等战略带来**新的重大机遇**。

### 2. “一国两制”不能触碰的三条底线

| 原则底线 | 原题定位 |
| --- | --- |
| 危害**国家主权安全** | 【2020-26】A |
| 挑战**中央权力和香港特别行政区基本法权威** | 【2020-26】C |
| 利用香港对内地进行**渗透破坏** | 【2020-26】D |

### 3. 【2020-26】贯彻落实“一国两制”的底线

**答案：ACD。**

- **A** 危害国家主权安全：触碰原则底线，正确。
- **B** 干扰内地与香港的民间交流：本题所列的**三条原则底线**中没有这一项，不能因其消极就选。
- **C** 挑战中央权力和香港特别行政区基本法权威：触碰底线，正确。
- **D** 利用香港对内地进行渗透破坏：触碰底线，正确。

**命题机关**：把「影响社会生活的行为」混入「触碰根本政治法律底线的行为」。做题时重点锁定国家主权、中央权力、基本法权威、渗透破坏。

## 考点103 实现祖国完全统一是中华民族伟大复兴的必然要求

### 1. 核心判断

**解决台湾问题、实现祖国完全统一**，是中国共产党矢志不渝的历史任务、全体中华儿女的共同愿望、中华民族伟大复兴的必然要求。

- **民族复兴、国家统一**是大势所趋、大义所在、民心所向。
- **台湾问题因民族弱乱而产生，必将随着民族复兴而解决**，是教材对历史进程的概括。
- **追求统一、反对分裂**是中华民族长期形成的价值取向；中华文明具有突出的统一性。
- 两岸关系和平发展有利于和平、共同发展和两岸同胞福祉；「和平发展」不能等同于接受「一中一台」或永久分离。

### 2. 三个层次：原因—方向—障碍

| 出题角度 | 选项中应识别的主要内容 |
| --- | --- |
| **为什么要统一** | 民族复兴的必然要求、共同愿望与历史任务 |
| **怎样争取统一** | 坚持一个中国原则、推动和平发展与融合发展、争取民心 |
| **主要障碍及风险** | “台独”分裂活动、外部势力干涉等 |

## 考点104 坚持贯彻新时代党解决台湾问题的总体方略：十个坚持

### 1. 十个坚持 × 十个定位词（必背表）

| 次序 | 纲要内容 | 精确的“帽子” |
| --- | --- | --- |
| 1 | 坚持**党中央对台工作集中统一领导** | **根本保证** |
| 2 | 在**中华民族伟大复兴进程**中推进统一 | **历史方位** |
| 3 | 在**祖国大陆发展进步基础上**解决台湾问题 | **战略思路** |
| 4 | 坚持**和平统一、一国两制**基本方针 | **大政方针** |
| 5 | 坚持**一个中国原则和“九二共识”** | **政治基础** |
| 6 | 推动两岸关系**和平发展、融合发展** | **实践途径** |
| 7 | **团结台湾同胞、争取台湾民心** | **根本动力** |
| 8 | **粉碎“台独”分裂图谋** | **必然要求** |
| 9 | **反对外部势力干涉** | **外部条件** |
| 10 | **决不承诺放弃使用武力** | **战略支撑** |

**高危互换：**「政治基础」不是融合发展；「历史方位」不是大陆发展基础；「根本动力」不是不承诺放弃使用武力；「战略支撑」也不是党的集中统一领导。肖1000单选2、3分别直接考**历史方位**和**战略支撑**。

### 2. 【2018-8】两岸关系和平发展的政治基础

**答案：A．坚持“九二共识”，反对“台独”。**&#x2060;其核心在于**认同大陆和台湾同属一个中国**，体现**一个中国原则**。

- **A** 是两岸关系和平发展的政治基础，正确。
- **B** 相互尊重、求同存异：是交流相处的重要方法，**不是题问“政治基础”**。
- **C** 增强两岸同胞民族、文化、国家认同：有助于民意与情感联结，但不替代政治基础。
- **D** 深化利益融合、增进两岸同胞福祉：属于推进和平发展及其宗旨层面的措施，不是政治基础本身。

**做题技巧**：不能见到「维护和平」「增强认同」「增进福祉」就选；政治基础题先找**一个中国原则、“九二共识”、反对“台独”**。

### 3. 【2025-32】依法惩治“台独”顽固分子犯罪的《意见》

**来源说明**：这道题**出现在用户材料《精讲精练》本章**，但**未在其分类真题本章单独列出**；核对公开的2025年考研政治真题答案为**ABCD**。背景是2024年6月21日五部门联合印发相关《意见》。

**答案：ABCD。**

- **A** 明确有关分裂行径的犯罪性质、刑事责任和惩处程序：法律规范层面的作用，正确。
- **B** 回应两岸最大多数民众的诉求与期盼：该题给出的政策意义，正确。
- **C** 彰显捍卫国家主权、统一和领土完整的坚定立场：政治立场层面的作用，正确。
- **D** 充实反“台独”、反干涉法律工具箱：依法反分裂的制度作用，正确。

此题特点在于**法律内容—民众诉求—政治立场—法律工具**四个方面并列，而不是只选最像“法律专业表述”的A、D。与【2020-26】题不同，这里四项都属于该法律文件的作用。

## 考点105 牢牢把握两岸关系主导权和主动权

### 1. 基本方针与行动方向

- **“和平统一、一国两制”**&#x2060;是实现两岸统一的最佳方式，既考虑台湾现实情况，也有利于统一后长治久安。
- 以最大诚意、尽最大努力争取**和平统一前景**，但**决不承诺放弃使用武力**。这两个表述在教材中是同时成立的，不能把后者改成首选军事方案。
- 坚持**一个中国原则和“九二共识”**，反对“台独”分裂图谋和外部势力干涉。
- 深化两岸经济、文化、社会交流合作和融合发展，维护两岸同胞利益福祉。

### 2. 容易混淆的定位总表

| 概念 | 地位及考题问法 |
| --- | --- |
| “一国两制”的**最高原则** | 维护国家主权、安全、发展利益 |
| “一国两制”的**根本宗旨** | 上述最高原则 + 港澳长期繁荣稳定 |
| 港澳**高度自治权**的权源 | 中央授权，不是固有权力 |
| 两岸关系和平发展**政治基础** | 一个中国原则和“九二共识”，反对“台独” |
| 对台工作的**根本保证** | 党中央集中统一领导 |
| 对台工作的**历史方位** | 在民族复兴进程中推进统一 |
| 统一的**战略支撑** | 决不承诺放弃使用武力 |

## 肖1000精简版错项集中排查

1. **“一国”之内两种制度并列、平等分割主权** → 错：「两制」从属于「一国」。
2. **高度自治意味着特区拥有未明示的剩余权力** → 错：高度自治来自中央授权。
3. **“爱国者治港”可以由一般的依法治国口号代替** → 错：涉及特定根本原则和治理要求。
4. **民族复兴和国家统一彼此无关** → 错：精讲精练强调二者的内在历史关联。
5. **统一的历史方位是“和平统一、一国两制”** → 错：这是**大政方针**；历史方位是「民族复兴进程」。
6. **不承诺放弃使用武力意味着否定争取和平统一** → 错：教材强调坚持争取和平统一前景，同时保留战略支撑。
7. **题目问“一国两制关系”就把国际市场便利性选上** → 错：要检验是否真正回答“一国”与“两制”的**内部关系**，对应【2019-25】C。

4. 【2019-25】为何不选C？——**未回答“一国”与“两制”的关系**。
5. 「十个坚持」中根本保证、政治基础、战略支撑分别是什么？——**党集中统一领导；一个中国原则和“九二共识”；决不承诺放弃使用武力**。
6. 【2025-32】为何四项全选？——**四项分别概括《意见》的法律规范、民意、政治立场及法律工具意义**。
