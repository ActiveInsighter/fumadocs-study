## 二、考点100｜“一国两制”：先明确性质，再理解两种制度 ★★★★☆

**“一国两制”**&#x2060;是中国共产党领导人民实现祖国和平统一的伟大构想，是国家的一项基本国策，也是中国特色社会主义制度创新的重要成果。

含义：在统一国家内，**国家主体实行社会主义制度**，香港、澳门等特别行政区依法保持原有资本主义制度和生活方式；港澳特别行政区直辖于中央人民政府，依据宪法和基本法享有高度自治权。**在一个国家内实行不同制度，不等于存在两个互不隶属的主权国家。**

易错时间与对象：

- 伟大构想**最早针对台湾问题提出**，在解决香港、澳门问题中**首先付诸实践**。
- **1997年7月1日**，中国政府对香港恢复行使主权；**1999年12月20日**，中国政府对澳门恢复行使主权。
- “一国两制”既不是两种制度平起平坐，也不是把特别行政区理解为享有完整主权的地方。

**命题模型**：题目问“为什么说是伟大创举”，可从**适合中国国情、实现国家统一的制度创新、尊重差异与求同存异、提供解决类似问题的新思路**四层展开。

## 三、考点101｜“一国”与“两制”：高频中的高频 ★★★★★

### 1. 三组必须分开的定位

| 题目关键词 | 回答 |
| --- | --- |
| **最高原则** | **维护国家主权、安全、发展利益** |
| **根本宗旨** | **维护国家主权、安全、发展利益，保持香港、澳门长期繁荣稳定** |
| **“一国”与“两制”的关系** | **“一国”是前提和基础，是根、是本；“两制”从属和派生于“一国”** |

“最高原则”与“根本宗旨”表述相近，**根本宗旨还包括保持港澳长期繁荣稳定**。做选择题时必须看题干是否要求完整表述。

### 2. 中央全面管治权与特别行政区高度自治权

**核心结构**：中央对特别行政区拥有**全面管治权**，特别行政区**高度自治权源自中央授权**。中央全面管治权是授权高度自治的前提和基础，高度自治权是中央行使全面管治权的体现，属于**源与流**的关系。

特别行政区依法享有行政管理权、立法权、独立司法权和终审权，但**高度自治不等于完全自治，自治权不是特别行政区固有的，也没有中央未授予部分的“剩余权力”**。

**真题精析｜2015年单选8（原题67，考点101）**

> 题干：香港回归后实行“一国两制”“港人治港”、高度自治，问香港特别行政区的**高度自治权是什么性质的权力**？
>
> A 完全自治权；B 中央授权以外的剩余权力；C 特别行政区固有的权力；D **中央授予的地方事务管理权**。

**资料答案：D。**&#x2060;A错在“完全”，B错在主张存在剩余权力，C错在“固有”。D同时体现中央授权与高度自治的性质。遇到“独立司法权”“终审权”时也不能据此推定港澳享有独立主权。

### 3. “一国”基础上的三个“有机结合”

**真题精析｜2019年多选25（原题66，考点101）**

> 题干问如何正确处理“一国”与“两制”的关系，选项分别为：
>
> A **中央权力与特别行政区高度自治权相结合**；B **坚持“一国”原则与尊重“两制”差异相结合**；C 利用国际有利条件与发挥港澳优势相结合；D **祖国内地坚强后盾与港澳自身竞争力相结合**。

**资料答案：ABD。**&#x2060;A对应中央与地方授权关系；B回答制度关系；D回答在“一国”基础上发挥“两制”优势的协同关系。C所述内容可在开放发展背景下讨论，但**不是题目要求的“一国”与“两制”三个有机结合的对应表述**。本题训练的是**正确陈述不一定符合特定题干范围**。

### 4. 治港治澳的制度链条

- **宪法和基本法共同构成特别行政区的宪制基础**。不能只说“仅依据基本法”，更不能脱离国家宪法。
- **“爱国者治港”“爱国者治澳”**&#x2060;是落实“一国两制”、维护主权安全、保持繁荣稳定的重要制度原则。
- **依法治港治澳**是全面依法治国的应有之义，依法治理与中央全面管治权、特别行政区高度自治权并不冲突。

## 四、考点102｜港澳长治久安：三条底线与融入发展 ★★★★★

港澳的发展既要**维护国家主权、安全、发展利益**，又要充分发挥港澳**背靠祖国、联通世界**的优势。教材对香港发展阶段的表述包括从**由乱到治**迈向**由治及兴**；实践上涉及维护国家安全法律制度与执行机制、依法施政以及积极融入国家发展大局。

### 不可触碰的三条底线

| 底线内容 | 辨析 |
| --- | --- |
| 危害国家主权和安全 | 涉及“一国”的前提 |
| 挑战中央权力及特别行政区基本法权威 | 涉及国家宪制秩序 |
| 利用香港对内地进行渗透破坏 | 涉及国家安全与统一 |

**真题精析｜2020年多选26（原题68，考点102）**

> 题干以2019年香港社会事件为背景，问贯彻“一国两制”方针**不允许触碰的原则底线**：A危害国家主权安全；B干扰内地与香港民间交流；C挑战中央权力和香港特别行政区基本法权威；D利用香港对内地进行渗透破坏。

**资料答案：ACD。**&#x2060;这三项直接对应底线的三种情形。B并非这道题所考的原则底线清单，不能把任何负面行为都归到该固定表述中。做多选题应区分“政策希望改善的方面”与“原则底线”。

### 国家发展大局：有优势，也有制度前提

- **“一国两制”是港澳最大的制度优势**；国家改革开放提供发展舞台。
- 粤港澳大湾区建设、共建“一带一路”等可以成为融入国家发展大局的重要机遇。
- “发挥港澳优势”是积极发展的一部分，但**不能取代国家主权、安全和发展利益的原则前提**。

## 五、考点103—105｜祖国完全统一、对台工作方略与主导权 ★★★★★

### 1. 为什么统一问题不能只理解为“地区经济合作”？

教材将解决台湾问题、实现祖国完全统一界定为**中华民族伟大复兴的必然要求**，与国家主权和领土完整密切相关。经济文化交流、民心沟通和融合发展是重要途径，但不能代替**一个中国原则与“九二共识”作为政治基础**。

### 2. 统一总体方略“十个坚持”的功能词

| 方略内容（简写） | 作用／定位 |
| --- | --- |
| 党中央对台工作集中统一领导 | **根本保证** |
| 在民族复兴进程中推进统一 | **历史方位** |
| 依托大陆发展进步解决台湾问题 | **战略思路** |
| 和平统一、一国两制 | **大政方针** |
| 一个中国原则和“九二共识” | **政治基础** |
| 两岸关系和平发展、融合发展 | **实践途径** |
| 团结台湾同胞、争取台湾民心 | **根本动力** |
| 反对“台独”分裂图谋 | **必然要求** |
| 反对外部势力干涉 | **外部条件** |
| 决不承诺放弃使用武力 | **战略支撑** |

复习时将**定位词和政策内容成对记忆**，尤其“根本保证”与“政治基础”、“战略思路”与“战略支撑”容易串位。

### 3. 政治基础的真题

**真题精析｜2018年单选8（原题69，考点104）**

> 题干问两岸关系和平发展的**政治基础**是什么？
>
> A **坚持“九二共识”，反对“台独”**；B相互尊重、求同存异；C增进两岸同胞民族、文化、国家认同；D深化利益融合、促进两岸福祉。

**资料答案：A。**&#x2060;B、C、D可属于关系改善、交流融合等内容，但回答“政治基础”必须回到**体现一个中国原则的“九二共识”**&#x2060;及反对分裂的要求。题目问的不是“哪些行动有利于两岸关系”，不能将所有正面政策都选入。

### 4. 两岸关系主导权和主动权

教材强调坚持一个中国原则，推进两岸经济、文化交流与融合发展，争取和平统一前景，同时反对“台独”与外部干涉。注意分清四层：**政治前提—政策方针—实践途径—战略保障**。考试常把其中一层改写为另一层的“唯一根本基础”。

### 5. 精讲精练补充材料（未计入本分类题库4道）

《精讲精练》考点104收录一则标为**2025年多选32**的案例，以2024年6月21日五部门发布的依法惩治相关分裂国家犯罪的意见为背景，重点考察：**明确行为与法律责任、维护国家主权统一和领土完整、完善反分裂法治工具**。本章将其用于理解**法治手段与国家统一的联系**，不将其与本章4道分类真题混计。
