## 二、唯物论：世界的本原、存在方式和意识（考点6—14）

### 考点6｜哲学基本问题：不要把两组划分混淆

哲学的基本问题是**思维和存在（意识和物质）的关系问题**，它有两个彼此不同的方面：

| 提问 | 形成的分野 | 精确判断 |
| --- | --- | --- |
| **谁是世界的本原，何者第一性？** | **唯物主义 vs 唯心主义** | 物质第一性，意识第二性＝唯物主义；反过来＝唯心主义 |
| **思维能否正确认识存在？** | **可知论 vs 不可知论** | 可知论承认思维和存在的同一性；不可知论否认或怀疑世界可以被认识 |
| **世界以何种状态存在和发展？** | **辩证法 vs 形而上学** | 联系、发展、全面、内部矛盾 vs 孤立、静止、片面 |

三种唯物主义形态：古代朴素唯物主义把本原归为水火等具体形态；近代形而上学唯物主义往往以原子等物质结构解释世界；**辩证唯物主义**把握客观实在以及物质、运动、实践的统一。**唯物主义未必是辩证法，唯心主义也不必然反对辩证法。**&#x2060;例如机械唯物主义存在形而上学局限，黑格尔的辩证法具有唯心主义基础。

**【2009-1，真题完整核心】**“物质和意识的对立只有在非常有限的范围内才有绝对意义。”这个范围是：

- A. 物质和意识何者为第一性
- B. 物质和意识是否具有同一性
- C. 物质和意识何者更重要
- D. 物质和意识何者与社会生活关系更密切

**答案：A。**&#x2060;这里的“绝对对立”特指哲学本体论上的第一性归属，而不意味着物质与意识互不关联；**第一性不等于“价值更重要”**，C、D偷换“本原”与“价值”。【2008-1】还曾问马克思主义哲学与旧哲学的根本区别，正确抓手是**从客观的物质实践活动理解现实世界**，而不能只停留在笼统的“坚持物质第一性”。

**肖1000题设陷**：“心诚则灵”若理解为意念直接决定客观成败，是夸大意识能动作用；“宇宙诞生时未来一切已完全确定”属于**机械决定论**，不能误认作辩证唯物主义决定论。

### 考点7｜物质范畴：客观实在性与具体物质形态区分

物质是**标志客观实在的哲学范畴**；它**不依赖人的意识而存在，又能够为人的意识所反映**。哲学物质范畴概括各种具体物质形态的共同本质，与物理学中的某种粒子、能量形式等具体科学概念是**共性与个性**的关系。

**三层推理**：

1. 不能直接看见，不等于不存在。暗物质、磁场等可通过客观效应间接认识。
2. 人的认识进步会改变人对物质形态的理解，但**不会赋予物质以客观性**。
3. 自然科学发现新结构，不会推翻“物质世界具有客观实在性”的哲学概括。

**【2026-17，多选原题】**&#x2060;天文学通过引力效应探测无法直接发光、也不参与电磁相互作用的“暗物质”，据此测绘宇宙结构。人们对暗物质的认识表明：

- A. 物质存在的客观性只有通过人们具体的感知才得以确证
- B. 物质不依赖于人类的意识而存在，并能为人类的意识所反映
- C. 物质世界是外在于人类的直观的、机械的、自在的对象
- D. 物质世界不是超越于人类理性所能理解的现象之外的“物自体”

**答案：BD。**&#x2060;B强调**客观性 + 可知性**，D反对把世界视作根本不可认识之物；A把“客观存在”错误依附于“直接感知”，C倒退到消极直观的旧唯物主义。

**肖1000题收束**：列宁的定义要抓“**客观实在**”四字。哲学范畴不是对某种单一自然科学对象的命名。

### 考点8｜物质与运动、运动与静止

**核心三句**：

- **运动是物质的根本属性和存在方式**；离开物质的运动是唯心主义，离开运动的物质是形而上学。
- **运动绝对、无条件、永恒；静止相对、有条件、暂时。**&#x2060;静止有两种意义：相对位置暂时不变、根本性质暂时不变。
- 二者**动中有静、静中有动**；静止提供认识事物、衡量运动的尺度。否认相对静止，容易走向相对主义、诡辩论。

**【2013-1】**“舟行洲不行”“鸽飞阁不飞”，问静止的哲学作用，选择“**运动的衡量尺度**”，不要误选“运动的存在方式”。**【2007-1】**“风定花犹落，鸟鸣山更幽”说明**静中有动、动中有静**。

**【2015-18】平衡题考多原理综合**：体操、悬停、地球运行等“保持平衡”提示绝对运动和相对静止的统一、对**度**的精确把握、内部因素协调（A、C、D）；材料不能直接证明“辩证否定的方式和方向”（B）。这一题说明**多选题可跨相邻考点同时成立**，必须辨识材料所蕴含的多重客观关系。

### 考点9｜时间、空间：客观存在与主观时间观

- **时间**：物质运动的持续性和顺序性，突出**一维性、不可逆性**。
- **空间**：物质运动的广延性和伸张性，突出**三维性**，其性质与物质分布和运动状态密切相关。
- **时空是运动着的物质的基本存在形式**；物质、运动和时空不可分割。时空的客观实在性不因人的认识变化而变化，但时空观念会随认识发展深化。

| 材料线索 | 应抓的原理 | 应排除的表述 |
| --- | --- | --- |
| 用天体运动确定年月日、用光传播定义光年 | 时空通过物质运动表现出来 | “时空仅是人为制定的观念” |
| 黑洞照片、引力波及广义相对论观测 | 空间性质与物质运动有关；人的时空观念不断拓展 | “黑洞的存在取决于拍到照片” |
| 时不我待、青春易逝、一去不复返 | **时间一维性** | 只说一般因果关系 |
| 长江沉积物示踪、追溯形成时代 | 由物质运动认识具体时空过程 | “整个宇宙时空是有限的” |

**【2020-17，多选原题核心】**&#x2060;首次拍摄黑洞照片表明：

- A. 空间的性质依赖于物质的分布及其运动状态
- B. 世界是物质的统一体
- C. 物质世界的客观存在与人的实践和认识水平有关
- D. 空间的观念随着人的认识发展而拓展

**答案：ABD。**&#x2060;C把“认识客体”与“客体存在”偷换。**【2022-19】**&#x2060;奋斗中“定义”时间是赋予时间以人生意义，不是人创造客观时间；A测量运动的客观尺度、B存在形式、D不可分割成立，C主观联想不成立。**【2016-18】**&#x2060;诗词对时间流逝的感慨考一维性，必须辨析诗句是否呈现不可逆、不能重来的特征。

### 考点10｜物质世界的二重化（和意识、实践合并识记）

人类的**劳动和实践活动**使自然界与人类社会、客观世界与主观世界分化，同时又成为二者统一的纽带。

- **自然界**包含天然自然及人化自然；**人类社会**是在人的实践活动中形成的高级物质存在形态。
- **客观世界**：不依赖于意识的自然存在与社会存在；**主观世界**：认识、情感、意志、信念等意识活动。
- **易错句**：主观世界具有相对独立性，**并不是**不依赖物质独立存在的第二个本原。

肖1000题直接考“自然界和人类社会相分化的关键是什么”，答案是**人的实践活动**，并非单独的思维活动、语言、脑的出现。

### 考点11｜物质与意识：意识为什么不是照相机

意识的起源：自然界长期发展形成反应能力、刺激感应、动物心理等基础；**社会实践尤其是劳动**对人的意识形成具有决定性作用。**意识是人脑的机能和属性，是客观世界的主观映象**；其内容来自客观世界，形式具有主观性。

**意识的四类能动作用**：

1. **目的性、计划性**：活动可以预先设定目标。
2. **创造性**：分析、综合、想象、构造现实中尚不存在的观念形式。
3. **指导实践改造客观世界**：观念经由物质实践才可能转化为现实成果；不是想一想便能改变客观事实。
4. **调节人的行为和生理活动**：例如心理状态影响行为，但不能超越生理条件与客观规律。

**【2017-2，典型误区】**“意识是对客观世界的反映，所以脑中有鬼神观念证明现实鬼神存在”错误在于把意识当作对存在的**直观、机械的反映**。幻想也以现实素材为原型，可以经加工、重组形成，**客观来源不等于所想对象真实存在**。

**【2007-17，龙的形象】**“角似鹿、头似驼、鳞似鱼、爪似鹰”等材料揭示观念的素材可追溯到客观世界，且经过人脑加工：A、D成立；并非一切观念都是直接模仿，更不能认为虚幻观念必然是对本质的反映。

**【2010-17，字典释义变更】**《新华字典》多个版本随社会生活调整“科举”等词条：意识是对客观世界的能动反映，受社会生活变化影响，并借语言这一物质外壳表达（A、C、D）；不能把意识变化归因为**词义改变**本身（B）。

**肖1000题辨析**：毕加索用线条表现公牛，说明**意识的主动创造性**；不同人看同一肖像，仍是**同一客观对象的不同主观映象**。

### 考点12｜尊重客观规律与发挥主观能动性（近年重中之重）

**规律**是事物发展中固有的、内在的、本质的、必然的联系；**客观、不以意志为转移**。人**不能创造、消灭或任意改变规律**，却能认识、利用规律，在规律允许的条件下创造新的实践结果。

| 两者关系 | 准确表述 | 误区 |
| --- | --- | --- |
| 客观规律 → 主观能动性 | **尊重客观规律是正确发挥主观能动性的前提** | 认为意志、政策、热情能取代客观条件 |
| 主观能动性 → 客观规律 | **积极发挥能动性，才能认识和利用规律** | 消极等待，把规律理解为宿命 |
| 统一的根基 | **实践是客观规律性与主观能动性统一的基础** | 错把“认识活动”或“纯精神活动”当统一基础 |
| 能动性发挥条件 | 一切从实际出发；实践是根本途径；依托物质条件和手段 | 只靠主观愿望“想出来、做出来” |

**【2026-2，单选原题核心】**&#x2060;叶片飘落受重力、形状、空气阻力、涡流、风、旋转动能等因素共同作用。问“事物运动的规律”：

- A. 取决于外在因素作用的大小
- B. 是纯粹偶然因素作用的结果
- C. 取决于物质形态变化的概率
- D. 是各种因素相互作用的结果

**答案：D。**&#x2060;规律不能约化为某个外因、纯粹偶然或孤立概率；材料强调**多种内外条件的客观综合作用**。

**【2026-18，多选原题核心】**&#x2060;科学家发现马铃薯杂交来源及块茎形成机理，据此设计“地下结土豆、地上长番茄”的育种路径。问科学家能够利用基因技术培育新型作物，是因为：

- A. 对客观事物规律的把握是人们正确活动的基础
- B. 事物之间的联系通常都是人们主观意志赋予的
- C. 改造客观世界的前提是必须先改造主观世界
- D. 人类改造世界的能力随着科学实践的发展而发展

**答案：AD。**&#x2060;发现规律→理解机理→技术实践→创造成果，是尊重客观规律与发挥主观能动性的完整链条。B否定联系客观性，C把精神改造设为客观改造的绝对先决条件。

**【2025-17，人与病毒共演化】**&#x2060;正确理解为：人与自然和谐共生以客观规律为基础；人的活动选择性与自然先在性动态统一（C、D）。人类实践**并非纯粹的自然演化**，社会活动规律也不能简单还原为生物进化规律。

**【2017-1，“人努力”“天帮忙”】**&#x2060;排放治理与天气变化共同影响雾霾：自然因素不可忽略，但**尊重客观规律是正确发挥主观能动性的前提**。把人“有意识的思想活动”当认识规律的根本前提，或把认识当二者统一基础，均不准确。

**肖1000题配套变式**：“巧用微生物净化水环境”说明**发现并利用客观规律**；人为搭建产业链可以利用客观联系，但联系并非由主观愿望任意产生。

### 考点13｜意识与人工智能：不能由功能强大直接推出有人的意识

在本教材的理论框架中，人工智能是人类智能活动的**模拟、延伸、物化**，属于人类本质力量的对象化和现实化。

| 能够成立 | 不能推出 |
| --- | --- |
| 对可形式化的某些认知活动进行模拟、扩展 | 机器因此成为具有完整人类意识的主体 |
| 通过脑机接口把人的脑活动转为设备运动 | 机器已经具备人的情感、信念、意志和社会交往本质 |
| 利用数据与算法推进材料研发 | AI可以任意改变物质客观属性、取代一切人类认识 |
| 技术进步深化人对物质结构与规律的认识 | 新结构、新性质的发现改变世界的物质性 |

**【2025-18，多选原题】**&#x2060;脑机接口使截瘫患者通过脑电活动驱动气动手套喝水。该技术表明人类意识：

- A. 能够通过智能机器实现对象化现实化
- B. 能够被具有情感、意念、意志的智能机器所代替
- C. 能够还原为数据信息并取代人类社会交往的真情实感
- D. 能够物化为机器的物理运动从而延伸意识器官的功能

**答案：AD。**“设备执行动作”是人的意识通过技术**对象化**，不是证明设备具有完整人的主观精神生活。

**【2022-18】人工智能辅助材料研发**：算法筛选、模型验证和实验验证说明认识不断深化，物质结构性质的具体变化不改变世界的物质性（C、D）；不能据此断言“任意改变物质属性”或“AI取代人类认识”。

### 考点14｜世界的物质统一性：多样性不是多本原

**世界统一于物质，世界的真正统一性在于物质性。**&#x2060;自然界是物质的；人类社会在物质资料生产实践基础上形成，具有客观物质条件和规律；意识依赖物质并反映物质。**多样物质形态、多种存在方式，不影响物质世界统一性。**

- **唯物主义一元论**：世界本原是物质；**唯心主义一元论**：世界本原是精神；**二元论**：把二者当互不依赖的两个本原。不可将“一元论”直接等同“唯物主义”。
- **根本方法论**：一切从实际出发、实事求是，依据客观条件开展实践。

**【2021-17，“南极墙”宇宙结构】**&#x2060;正确判断为“未知与已知世界都是客观存在”“世界只有尚未认识之物，没有根本不可认识之物”（C、D）。不能把**暗物质、暗能量**误当成世界的唯一哲学本原，也不能根据可观测结构有限就说整个世界的时空有限。

**【2019-17，虚拟现实】**&#x2060;虚拟环境提示**物质世界存在形式多样**、**实践可以创造自然界原先不存在的现实状态**（B、D）；虚拟对象依赖真实机器、计算过程和实践条件，不说明“信息是第三种独立本原”。

## 三、唯物辩证法总特征：普遍联系与永恒发展（考点15）

**联系和发展的观点是唯物辩证法的总观点**，其总特征即世界的普遍联系和变化发展。这里的“联系”不是主观联想，“发展”也不等同于任何方向的普通变化。

### 1. 联系四大特征与命题句式

| 联系特征 | 原理与答题提示 | 高频错误表述 |
| --- | --- | --- |
| **客观性** | 联系是事物固有的、不以人的意志为转移；人为建立的联系仍须以客观条件为依据 | 只要想象就可任意建立联系 |
| **普遍性** | 事物内部要素相互联系、事物与外部环境相互联系、世界构成联系的整体 | 每两个具体事物无条件地直接相联 |
| **多样性** | 直接/间接、内部/外部、本质/非本质、必然/偶然等联系共同影响事物 | 联系只有单一形式 |
| **条件性** | 条件影响联系的具体形成和作用；条件可以在尊重规律前提下改变 | 条件决定一切，或可以完全无视条件 |

**特别注意“有条件的普遍联系”**：事物的普遍联系不等于“任意两事物毫无条件地存在现实的直接联系”。肖1000题中“借牧”模式体现通过**中介**发生联系，而非主观制造一切联系。

**【2019-2，原题关键】**“橘生淮南则为橘，生于淮北则为枳……水土异也。”问说明什么。**答案：事物的发展变化以时间、地点和条件为转移（A）**。不能只看“橘”和“枳”的差别就误判为“对立统一”；题干明确将差别的解释落在**水土条件**。

**【2018-17，“墨子号”量子纠缠】**&#x2060;正确选项是：物质世界联系的**客观性、普遍性**；事物联系的**复杂性、多样性**；**世界统一于物质**（A、C、D）。物理现象“尚未完全认知”，不代表联系由人的主观意识制造。

**【2015-17，土壤形成的五大因素】**&#x2060;母质、气候、生物、地形与时间共同作用，得出：事物**作为过程存在**、时间是物质运动的存在形式、发展结果受**多种因素相互作用**影响（A、B、D）。**不能因“发展”一词就选“总是线性上升”**：曲折性、多阶段性完全可能存在。

**【2007-18，柿子与喜鹊】**&#x2060;农民保留熟柿供喜鹊越冬，喜鹊捕虫有益收成，说明联系客观存在、人能认识利用规律、保护生态平衡的重要性（A、B、D）；不应把人与自然关系概括为单纯“相互利用”。

### 2. 变化、运动、发展不是同义词

- **运动和变化**：强调事物状态发生变动，既可前进也可后退。
- **发展**：前进、上升的运动，**实质是新事物产生、旧事物灭亡**。
- **新事物判准**：不是“出现得晚、看上去新、数量多”，而是**符合客观发展规律与历史前进方向**，具有新的结构、功能和生命力；在社会历史领域还要看是否符合广大人民群众的根本利益。

**【2012-17，“沉舟侧畔千帆过，病树前头万木春”】**&#x2060;新事物取代旧事物，根本在于新结构和功能能适应变化了的条件、对旧事物的扬弃、社会领域符合群众根本利益（B、C、D），不能选择“只是出现得更晚”（A）。

**【2006-1】**“世界上唯一不变的是变”重在说明**变是绝对的，不变是相对的**；不能把“变”当作世界的本原，也不能否认相对稳定性。

**高效串联**：客观联系提供发展条件；事物内部矛盾提供发展动力；量变质变呈现状态跃迁；否定之否定揭示长期趋势。后面三大规律不是彼此孤立的记忆点。

## 四、三大规律：动因、状态、方向（考点16—18）

### 考点16｜对立统一规律：整个辩证法的核心

**为什么是实质和核心**：它揭示普遍联系的根本内容和发展的内在动力；贯穿其他规律及基本范畴；提供**矛盾分析法**这一根本认识方法。其逻辑重点是：**矛盾本身推动事物发展**，外部条件通过内部矛盾而起作用。

#### 1. 矛盾的两种属性

| 属性 | 内涵 | 条件性 | 识别线索 |
| --- | --- | --- | --- |
| **同一性** | 对立面相互**依存**、相互**贯通**，在一定条件下相互转化 | 相对、有条件 | 共生、相互促进、转化、协调、相互依赖 |
| **斗争性** | 对立面相互排斥、相互分离的性质和趋势；形式可以是对抗性或非对抗性 | 绝对、无条件 | 差别、排斥、冲突、相互制约 |

两者相互联系：没有差别与对立，就没有作为对立统一的同一性；斗争性寓于同一性之中。**同一性不是没有差别的“完全一样”，斗争性不专指武力冲突。**

**同一性对发展的作用**：使矛盾双方互为发展条件，吸取对方有利因素，并为矛盾双方在一定条件下向对立面转化创造可能。**斗争性对发展的作用**：推动力量对比变化、破除旧统一体的局限，使旧事物向新事物转化。两者共同构成动力。

**内因和外因**：内因（内部矛盾）是发展根据；外因是发展条件，并通过内因起作用。自然环境、技术、政策等材料往往同时含有多种内外条件，不能单因素决定论。

#### 2. 普遍性、特殊性与“白马非马”

- **矛盾普遍性**：矛盾存在于一切事物及其发展过程始终，即无处不在、无时不有。
- **矛盾特殊性**：不同事物、同一事物不同阶段、同一矛盾的不同方面，均有具体特点；方法论是**具体问题具体分析**。
- **共性与个性**：普遍性是共性，特殊性是个性；**共性寓于个性之中**，并通过个性表现出来。不要反写为“个性寓于共性之中”。

**【2018-2，真题完整核心】**“马者所以命形也；白者所以命色也……故曰白马非马。”这一命题错误在于：

- A. 割裂了事物共性和个性之间的联系
- B. 模糊了事物本质和现象之间的联系
- C. 混淆了事物内容和形式之间的区别
- D. 颠倒了事物形态和功能之间的关系

**答案：A。**“马”是包含白马在内的**一般、共性**，“白马”是特定的**个别、个性**；不能因白色这一特殊规定性就否认其属于“马”。

#### 3. 主要矛盾与矛盾主要方面：最容易串错的两问

| 材料在问什么 | 选择原理 | 方法 |
| --- | --- | --- |
| 多个问题中**先抓哪个问题**、找到解决局面的突破口 | **主要矛盾**：多个矛盾中处于支配地位、对发展起决定作用 | 抓重点、牵牛鼻子 |
| 判断**某一个事物的性质、主流是什么** | **矛盾的主要方面**：一个矛盾内部处于支配地位、起主导作用的一方 | 分清主流与支流 |

**事物的性质主要由主要矛盾的主要方面决定**。两点论和重点论必须统一：既看全面，又辨主次，反对只讲重点不讲整体或平均用力。

**【2022-17，“有多少汤泡多少馍”】**&#x2060;按水资源承载能力确定城、地、人、产的规模与结构，体现**一切从实际出发、因地因时制宜、尊重规律与把握适度原则**（B、C、D）。材料不是倡导脱离水资源现实“创造条件充分发挥意识能动性”（A）。该题虽归档于考点16，实际**贯通考点12的客观规律与考点17的度**。

**肖1000题模型**：“没有需求，供给无从实现；新的供给创造需求”体现**同一性**；废弃物转化资源体现矛盾双方在特定条件下相互转化。辨析时需同时确认**两个方面之间有真实对立或相互依存关系**。

### 考点17｜量变质变：量的积累与度的控制

**质**是区别于其他事物的内在规定性；**量**是可用规模、程度、速度等衡量的规定性；**度**是保持事物质的稳定性的数量界限，界限端点是**关节点或临界点**。

- **量变**：数量增减或构成要素排列次序变化，事物在度内保持质的相对稳定。
- **质变**：事物根本性质改变，发生由一种质态向另一种质态的飞跃。
- **量变、质变的根本区分标准**：是否**超出度**，而不是变化快慢、幅度大小或是否能用数字表示。
- **辩证关系**：量变是质变的必要准备；质变是量变的必然结果并为新的量变开辟道路；二者相互渗透，构成渐进性与飞跃性的统一。

| 典型材料 | 命题落点 | 与其他原理区分 |
| --- | --- | --- |
| “水滴石穿”“十年磨一剑”“坚持就是胜利” | **量变积累为质变作准备** | 不是只强调“新事物战胜旧事物” |
| 愚人尝到加少量盐味美，误以为越多越好 | **适度原则** | 重点是“过犹不及”，非抽象地说任何量变都导致质变 |
| 粉笔并非越长越好，太长易断、浪费 | 在最佳范围**把握度** | 不选“单纯越大越好” |
| 多环节每个都得90分，最终总得分降低 | 局部量变叠加可触发结果**质变** | 不要误判为肯定与否定关系 |
| 守住风险底线 | 防止越过造成坏质变的**临界点** | 底线不是任意的心理安慰 |

**【2016-1，真题完整核心】**&#x2060;愚人在菜中加一点盐后觉得鲜美，便直接将一把盐放入口中，结果又苦又咸。启示是什么？

- A. 持续的量变会引起事物发生质的变化
- B. 在认识和处理问题时要掌握适度的原则
- C. 不可能通过一些现象认识事物本质
- D. 事物发展过程中要时时注意事物的自我否定

**答案：B。**&#x2060;虽然量变引起质变可作为背景，但题目的核心设问是“过量导致味道变坏”，**“适度”比泛泛“量变质变”更直接**。

**【2012-2，连乘问题】**&#x2060;五个环节各有九成效果，总效果约为 $0.9^5=0.59049$，由单环节小折扣的累积引出整体绩效突降，重在**量变导致质变**（B）。

**【2011-1，粉笔优选】**&#x2060;材料从过长、过短的弊端比较最佳长度，重在**坚持适度原则**（C）。

**【2010-2，“溪水战胜岩石”】**&#x2060;以持久积累促成改变，所给答案为“**量变必然引起质变**”（C），解题时应补全条件：**量变达到一定程度并突破度，才能发生质变**。

**肖1000题变式**：《百喻经》愚人吃饼，第七个半饼使他吃饱，却以为前六个无用；错误是忽略了**量变的积累是质变的必要准备**。这与“加盐过多”题目虽然同属量变质变，**抓手并不相同**。

### 考点18｜否定之否定：辩证否定不是简单推翻

事物内部包含**肯定因素**（维持现状）和**否定因素**（促使旧事物走向新的阶段）。否定是内部矛盾推动的**自我否定**，而非任意的外部摧毁。

**辩证否定的四层含义**：自我否定；发展的环节；新旧事物联系的环节；实质是**扬弃**，即既克服旧事物中消极因素，也保留、发展其积极因素。

事物发展经历“**肯定—否定—否定之否定**”三个阶段、两次否定，在更高基础上呈现某种“回复”，体现**前进性和曲折性的统一、螺旋式上升或波浪式前进**；不能理解为原地画圈或历史完全重复。

**肖1000题题眼**：燃素说虽被后来的化学理论否定，实验资料中合理成果却得以保存与重新解释，这体现**新旧事物通过否定环节联系、辩证否定的扬弃**。鸡蛋“从内部破壳”寓言强调**内部矛盾推动发展**。对传统文化应批判继承、创新转化；“全盘接受”和“全部摒弃”同属片面否定观。

## 五、五对基本范畴：看题干中的“关系词”选原理（考点19—23）

### 1. 一张总表先建立区别

| 范畴 | 关键词 | 原理框架 | 典型误区 |
| --- | --- | --- | --- |
| **内容与形式**（19） | 要素/结构、实质/表现方式 | 内容决定形式；形式反作用于内容 | 形式绝对决定内容；同一内容只能有同一形式 |
| **本质与现象**（20） | 内在规律/外在表现、表象/真象假象 | 本质通过现象表现，现象体现本质 | “假象是主观的”；“现象完全无法认识本质” |
| **原因与结果**（21） | 引起/被引起 | 原因在前、结果在后；可在因果链中转化 | “先后发生即为因果” |
| **必然与偶然**（22） | 确定趋势/不确定因素 | 必然通过偶然表现；偶然不可忽视 | “偶然决定根本趋势”或“偶然可有可无” |
| **现实与可能**（23） | 已经存在/尚未实现的趋势 | 可能在具备条件时转化为现实 | “任何幻想都存在现实根据” |

### 2. 考点19｜内容与形式

内容是组成事物的要素总和；形式是这些要素结合的结构或内容的表现方式。**内容是基础、决定形式**；形式具有相对独立性，合适时促进内容发展，不适合时阻碍内容发展。

**方法论**：反对只讲包装不讲实质的形式主义，也不能忽视组织方式、技术载体对内容的促进作用。肖1000题中若说“同一内容只能通过同一种形式表现”，应排除。

### 3. 考点20｜本质与现象

本质较为稳定、深藏于内在联系；现象具体、多变、可以感知；二者是**表现与被表现**的关系。认识要**透过现象把握本质**，而不是跳过现象。

**高频边界辨析**：

- **真象、假象都属于客观现象**；假象只是对本质的歪曲、颠倒或反面表现。
- **错觉是主观认识**，不能把假象和错觉视为同一个东西；错觉也不必然由假象引起。
- 不能认为表面现象和本质可以直接等同，也不能认为因现象复杂就无法认识本质。

### 4. 考点21｜原因与结果

因果联系不止是时间先后，关键在于**引起和被引起的关系**。原因通常在前、结果在后；但“A在B之前”不自动等于“A导致B”。同一事物在不同因果链条中可以既是结果又是新原因；存在一因多果、一果多因等复杂形式。

**【2013-2，割羊草】**&#x2060;工程专家不认识羊草，于是观察羊吃什么、再割相应草，利用的是“羊吃草”与“割羊草”之间可追踪的**因果联系**（C）。这里不是凭空主观联系，也不是着重讨论“本质与现象”。

### 5. 考点22｜必然与偶然（2024年真题应重点掌握）

必然性是事物发展中确定不移的趋势，规定发展的基本方向；偶然性是不确定的趋势，能影响发展进程和具体形式。**必然通过偶然表现、偶然受必然制约，并在条件变化时相互转化**。

**【2024-2，真题完整核心】**&#x2060;气候主要受纬度、海陆位置、地形、大气环流和洋流等因素影响，其中个别因素异常可能引发厄尔尼诺，进而造成全球气候变化。**偶然因素是**：

- A. 决定事物发展趋势的根本性因素
- B. 事物发展中可有可无的影响因素
- C. 事物发展中不可忽视的影响因素
- D. 事物发展过程中确定不移的因素

**答案：C。**&#x2060;A、D把偶然性说成“决定根本趋势、确定不移”，错把偶然当必然；B忽视偶然性影响发展的程度和过程。**方法论**：以必然规律制定方向，同时对机遇与风险保持敏感。

### 6. 考点23｜现实与可能

现实是当前客观存在；可能是事物中尚未实现、但存在发展根据的趋势。可区分：

- **不可能**：现实中缺乏成立根据和条件。
- **抽象的可能**：存在某种根据，但现实实现条件**尚不充分**。
- **现实的可能**：现实根据与实现条件较为充分，在一定条件下可以转化为现实。

**【2007-2，《孟子》“挟泰山以超北海”与“为长者折枝”】**&#x2060;区分**可能与不可能**，关键是**现实中有无根据和条件**（C）；若区分“现实的可能”与“抽象的可能”，才重点看根据和条件**是否充分**（D）。这两个问题容易被考试用相近选项刻意混淆。

**肖1000题延伸**：具体实践中要从现实条件出发，防止不利可能转为现实，并积极创造条件促成有利可能实现，但“创造条件”不意味着无中生有、改变客观规律。

## 六、辩证法的认识功能与思维方法（考点24—25）

### 考点24｜客观辩证法与主观辩证法

- **客观辩证法**：客观世界事物的联系、相互作用及其运动发展规律，**不以人的意志为转移**。
- **主观辩证法**：人的概念和思维所体现的辩证运动，**反映客观辩证法**，表现为观念、逻辑形式。
- **统一关系**：在本质上统一，在具体表现形式上不同；不能把两者定义成唯心/唯物两个相互对立的哲学派别。

**【2000年理科第3题】**“主观辩证法与客观辩证法的关系”→**反映与被反映的关系**（A）。

唯物辩证法的批判性、革命性体现在它不把任何既有现象视为永恒不变的终点；**矛盾分析方法**居于根本方法地位，要求从具体事物的矛盾特点出发认识和解决问题。

### 考点25｜六类思维能力：辨认题目到底在说哪一种

| 思维方式 | 核心特点 | 材料识别词 |
| --- | --- | --- |
| **辩证思维** | 用联系、发展、全面和矛盾分析方法理解问题 | 两面性、相互制约、转化、具体分析 |
| **历史思维** | 以史为鉴、知古鉴今，联通过去、现在和未来 | 历史文献、历史规律、从历史认识现实 |
| **系统思维** | 把对象视为有结构、层次、功能的**整体系统** | 多要素、多领域、统筹、协同、全链条 |
| **战略思维** | 立足全局、长远趋势和根本方向 | 总体谋划、长期布局、全局性 |
| **底线思维** | 预判风险、守住临界点、防范最坏结果 | 红线、临界点、风险极限、最坏情况 |
| **创新思维** | 打破惯性、超越陈规、开辟新方法 | 创造新路径、突破旧模式、开拓 |

**【2025-1，真题完整核心】**&#x2060;树立“大农业观”“大食物观”，向耕地、草原、森林、海洋及动植物、微生物多途径开发食物资源，构建多元食物供给体系。突出体现：

- A. 极限思维
- B. 历史思维
- C. 系统思维
- D. 逆向思维

**答案：C。**&#x2060;多要素、多个空间、多个领域的协同是**系统思维**的直接标志；不是在研究历史，也不是单纯把传统路径反过来走。

**【2023-1，《复兴文库》】**“修史立典，存史启智”“一切向前走都不能忘记走过的路”说明**历史、现实、未来是相通的**（A）。不能据此认为“一切历史都是当代史”，也不能说历史事件可完全重复。

**辩证思维四种常用方法**：

| 方法 | 方向或任务 | 需要记住的关系 |
| --- | --- | --- |
| **归纳与演绎** | 个别→一般；一般→个别 | 相互依赖、相互补充 |
| **分析与综合** | 分解要素→重新把握整体 | 分析是综合的基础，综合是分析的完成 |
| **抽象与具体** | 感性具体→抽象→思维具体 | 思维具体不是回到简单感官表象，而是多重规定性的统一 |
| **逻辑与历史** | 理论概念结构与客观历史进程互相印证 | 本质上统一，但不要求每个具体环节机械对应 |

**【2025-2，“从后思索法”】**&#x2060;马克思指出，认识社会历史形式往往从已经形成的结果出发，反向探究其前提和演化过程。与之相一致的是“**人体解剖对于猴体解剖是一把钥匙**”（B）：**较发达、较成熟的形态帮助理解较简单、较早期的形态**。这不是“我思故我在”，也不等于逻辑与历史在所有细节上机械相合。

## 七、考场解题法：由案例稳定定位到哲学原理

### 四步判断

1. **找主语和事件**：材料是在说客观世界的存在、人的认识，还是实践改造？
2. **找矛盾关系**：出现多要素条件、对立依存、数量累积、阶段跨越、先后引起、主流与支流等哪一种？
3. **识别设问的限定语**：特别注意“**根本原因、前提、基础、实质、必然、直接、决定、只有、任何**”。高度绝对化的断言要核对是否违反客观性、条件性。
4. **选择最贴切而非最宏大的原理**：加盐题抓“适度”，育种题抓“认识利用规律”，大食物观抓“系统”，暗物质抓“客观实在和可知性”。真理性的泛泛表述也可能不切题。

### 十组极易混淆的判断

| 错误说法或误区 | 正确替换 |
| --- | --- |
| “第一性”就是“更重要” | 第一性是对**世界本原**的判定 |
| 客观事物被发现后才存在 | 客观事物**先于并独立于**人的认识存在 |
| 物质是原子等某种具体实物 | 哲学物质范畴抽象为**客观实在性** |
| 运动否定静止 | 绝对运动中存在**相对静止** |
| 时间是人的主观感觉 | 时间客观，**时间观念**可以变化 |
| 想象的对象必须在现实中原样存在 | 想象可由现实素材经意识加工重组 |
| 意识能动性等于直接创造客观规律 | 人通过**实践认识并利用**规律，不能随意改变规律 |
| AI功能强便与人的意识完全相同 | AI**模拟、延伸与物化**某些人类智能活动 |
| 新出现或外表新颖的就是新事物 | 新事物要符合**发展规律与方向** |
| 主次矛盾和矛盾主次方面可以互换 | 前者解决“**抓哪个问题**”，后者回答“**性质和主流**” |

## 八、分层复习清单（按原考点6—25核对）

- **必须能结合材料解释**：6 第一性与同一性；7 客观实在；8 运动静止；9 时空；11 意识能动反映；12 规律和能动性；13 人工智能；14 统一性；15 联系发展；16 矛盾分析；17 量变质变；22 必然偶然；25 系统及历史思维。
- **用对比表巩固即可**：10 实践与二重化；18 扬弃；19 内容形式；20 本质现象；21 因果；23 现实可能；24 主客观辩证法。
- **至少复盘一次的跨考点材料**：2015平衡（运动静止＋度）；2020黑洞（时空＋物质统一性）；2022水资源（客观实际＋条件＋度）；2026育种（规律＋实践能力）；2025大食物观（联系＋系统思维）。

### 自测：先读材料，再说原理

1. **“水滴石穿”**：量变的长期积累为什么能够引起质变？
2. **“白马非马”**：共性与个性的正确包含关系为何不能颠倒？
3. **“拍到黑洞之前黑洞是否已经客观存在？”**：客体的存在和人的认识水平有什么区别？
4. **“天气造成局部污染短期反弹”**：为何人的治理仍须尊重客观条件，又不能因此放弃主观努力？
5. **“同一教育内容线上线下呈现”**：此类例子更偏向内容与形式，还是必然与偶然？为什么？
6. **“产业发展抓关键瓶颈，而评价某产业则看优势和短板的主流”**：哪一句对应主要矛盾，哪一句对应矛盾主要方面？

**自测答题要点**：①累积突破度；②共性寓于个性、个性包含更丰富规定；③客观存在独立于认识，认识可逐步深化；④规律是前提、实践是统一基础；⑤内容与形式，前者可借不同后者表现；⑥抓瓶颈是主要矛盾、定性质主流是矛盾主要方面。
