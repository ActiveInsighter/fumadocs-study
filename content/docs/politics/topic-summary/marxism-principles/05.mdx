## 一、考情与本章“因果链”

本资料包分类真题收录 **16 道（128—143）**，对应考点78—84。按原题分布：**78：3道；79：4道；80：1道；81：6道；82—83：未单列；84：2道**。这只是本资料的题目覆盖数量，不是官方考频统计。结合肖1000题的密集辨析，建议先掌握 **78、79、81**，再用 **80、84** 串联，**82、83** 以材料识别与排除绝对化表述为主。

> **一句话贯通**：自由竞争促使生产集中和资本集中，集中催生垄断；垄断一面依靠高价与组织优势追逐利润，一面仍然离不开竞争；随着国家干预、金融资本国际化和经济全球化的发展，资本主义的运行形式发生变化，但这些变化不等于资本主义基本矛盾及其生产关系根本性质消失。

| 最常见题干信号 | 立刻定位 | 注意排除 |
| --- | --- | --- |
| “大资本吞并小资本”“企业合并” | **资本集中** | 不是剩余价值转化为资本的“资本积累” |
| “金融寡头在经济上/政治上控制” | **参与制 / 个人联合** | 不是整个国民思想“绝对一元化” |
| “卖不亏损的最低价” | **成本价格** | 不是保证平均利润的生产价格 |
| “微观规制的类型” | **反托拉斯法、公共事业规制、社会经济规制** | 不要杜撰“公众生活规制” |
| “经济全球化的动因” | **科技生产力、跨国公司、制度与国际组织** | “发展中国家必为主要获益者”错误 |
| “大公司实际经营控制者” | **高级职业经理** | 不等于生产资料最终所有者 |

## 二、自由竞争到垄断：抓住“起点—形成—维持—利润”（考点78）

### 1. 为什么会从自由竞争走向垄断

按教材的历史分期，资本主义经历**自由竞争资本主义**与**垄断资本主义**两个阶段；后者又可考察私人垄断与国家垄断两种形式。生产集中是劳动力、生产资料与商品生产日益向少数大企业集中；资本集中则是多个资本通过兼并、联合等归于少数大资本支配。两者相互促进，但**研究对象不同**：前者问生产规模的分布，后者问资本控制权的集中。

| 概念 | 关键动作 | 一眼识别 |
| --- | --- | --- |
| 资本积累 | 剩余价值**转化为资本** | “以利润扩大再生产” |
| 资本积聚 | 单个资本依靠积累增长 | “一家企业把留存利润投入新厂” |
| **资本集中** | 原有资本合并、吞并 | “兼并竞争对手、控股重组” |
| **生产集中** | 生产活动向少数企业集中 | “少数大厂占据行业多数产量” |

逻辑是**自由竞争→优胜劣汰与积累→生产和资本集中→少数企业控制重要市场→形成垄断**。这里的“集中发展到一定程度，导致垄断”是历史形成机制，并非任何大企业、任何市场份额上升都必然已经具有排他性的垄断地位。

**肖1000题变式**：如果说“生产集中是最简单的、初级的垄断组织形式”，错；**短期价格协定**才是教材所述最简单、初级的垄断组织形式。卡特尔、辛迪加、托拉斯、康采恩只是组织形式不同，目的都在于通过联合控制市场、获取高额垄断利润。

### 2. 垄断为什么不能消除竞争

- **条件未消失**：资本主义私有制与商品经济仍然存在，竞争的经济基础依然存在。
- **垄断需要竞争**：垄断地位不是永久无风险状态，还需同其他资本较量以维持或扩大势力。
- **覆盖不了所有经济活动**：垄断集团内部、集团之间、垄断与非垄断企业之间、非垄断中小企业之间均有竞争。

垄断条件下竞争的**目的**更突出获取高额垄断利润与维护支配权；**手段**包括经济和非经济手段；**范围**扩展到国际市场和经济领域之外；**强度**可以更复杂、更激烈且更具有破坏性。

**【2006-22，多选；第134题】**&#x2060;题干问垄断资本主义的基本经济特征：A垄断组织起决定性作用、B资本输出具有特别重要意义、C金融资本基础上形成金融寡头统治、D垄断使竞争缓和。**正确ABC，排除D**。D把“垄断与自由竞争对立”偷换成“垄断消灭竞争”。

**肖1000题设陷**：说垄断时期竞争“依然只是为获得超额利润而扩大积累”不准确；在比较题中应突出垄断利润与垄断地位的维持。

### 3. 金融资本、金融寡头：形成方式和统治方式不可混记

**金融资本**：工业垄断资本与银行垄断资本的融合；典型形成途径是**金融联系、资本参与、人事参与**。**金融寡头**：在金融资本形成基础上，对经济命脉乃至国家政权具有重要控制力的少数大资本家及其集团。

| 问的是什么 | 正确回答 | 典型干扰 |
| --- | --- | --- |
| 金融资本**怎样形成** | 金融联系、资本参与、人事参与 | 把金融自由化当作其原始形成三途径 |
| 金融寡头怎样在**经济领域**统治 | **参与制**，通过层层控股控制企业 | 把“参与制”说成职工参与决策 |
| 金融寡头怎样在**政治领域**控制国家机器 | 同政府的**个人联合** | 把“个人联合”说成企业兼并 |
| 还可如何影响政策与生活 | 政策咨询机构、媒体与文化等渠道 | “可以使全部国民思想绝对一元化” |

**【2011-18，多选；第129题】**&#x2060;材料说明金融资本形成金融寡头，问操纵控制社会的主要方式：参与制（A）、同政府的个人联合（B）、政策咨询机构影响政策（C）、新闻媒体实现**国民思想意识一元化**（D）。**正确ABC**。D包含无法由实际控制推导出的绝对结果“实现一元化”，把影响力夸大为思想完全统一。

### 4. 垄断利润、垄断价格：从利润来源到价格下限

**垄断利润**是凭借垄断地位获取的、**超过平均利润**的高额利润。教材分析其最终来源仍是劳动者创造的剩余价值，可经本国劳动、其他企业的利润转移、国外劳动以及国家收入再分配等渠道实现；**垄断本身不能创造新的价值总量**。

| 价格 | 使用情景 | 关键词 |
| --- | --- | --- |
| **垄断高价** | 作为出售者操控价格 | 商品卖价高于生产价格 |
| **垄断低价** | 作为买入者操控价格 | 采购价低于生产价格 |
| **成本价格** | 垄断企业回收生产成本的下限 | 支出的生产资料及劳动力成本，教材记为 $c+v$ |
| **生产价格** | 一般竞争条件下成本加平均利润 | 成本价格＋平均利润 |

教材的分析关系可写作：

$$
\text{生产价格}=\text{成本价格}+\text{平均利润},\qquad
\text{垄断价格（分析构成）}=\text{成本价格}+\text{平均利润}+\text{垄断利润}.
$$

后一个式子是说明垄断获利的**构成思路**，不是说现实中任何垄断企业、任何时刻一定能按此加价卖出。

**【2023-4，单选；第128题】**&#x2060;垄断组织为了不出现**净亏损**，能接受的最低销售价格选什么？A成本价格、B生产价格、C垄断低价、D垄断高价。**答案A**。等于成本价格时至少可覆盖题设所说生产成本；等于生产价格还意味着得到平均利润，“不亏损”的门槛并不高到这个程度。注意这是教材设定下的典型成本分析，不要机械替代企业现实会计中全部费用的核算。

**【理1998-15，多选；第130题】**“垄断价格没有否定价值规律”的正确理由：A不能完全脱离价值，C从整个社会看价格总额与价值总额的理论关系仍成立，D改变价值规律的表现形式。**答案ACD**。B“仍围绕价值波动”、E“仍围绕生产价格波动”都混淆了自由竞争条件下的价格运动中心与垄断时期的价格形成机制。**价值规律的基础仍在，价格表现形式发生变化**，不是价值规律失效。

> **高频提醒**：某些商品能够长期偏离价值，不代表**全社会劳动创造的价值总量凭垄断价格而增加**。个别收入分配格局改变与新价值被创造是两个问题。

## 三、国家垄断资本主义及其国际化（考点79）

### 1. 国家垄断资本主义是什么、为什么形成

**国家垄断资本主义**是国家政权与私人垄断资本结合的资本主义形式。形成动因：社会化大生产需要更大范围的组织和调节；经济危机、波动加剧；缓和社会矛盾和协调利益的需要。理解为**在资本主义制度范围内调整和部分扩展生产关系的能力**，而不是生产资料所有制已经转化为社会主义公有制。

**五种主要表现形式**：①国家所有并直接经营的企业；②国家与私人资本共有、合营；③国家向私人垄断企业订货、提供津贴补助、借福利支出扩大市场等方式参与再生产；④以财政、货币政策为典型的**宏观调节**；⑤运用法律规范具体市场活动的**微观规制**。

| 常见材料 | 分类 | 为什么 |
| --- | --- | --- |
| 大规模减税、利率调控、调节总需求 | 宏观调节 | 面向经济总量和增长、就业、价格等目标 |
| 对垄断兼并施行反托拉斯法 | 微观规制 | 规范竞争秩序和主体行为 |
| 管理供水、电网、天然气的收费标准 | 微观规制→**公共事业规制** | 自然垄断行业价格或服务管理 |
| 环保、劳动保护、消费者权益、食品安全监管 | 微观规制→**社会经济规制** | 广泛社会经济行为的规范 |
| 政府采购特定企业产品或向私人企业补贴 | 国家参与私人资本再生产 | 不是财政政策一般性调节的同义词 |

**【2015-21，多选；第133题】**&#x2060;问“微观规制的主要类型”。A社会经济规制、B公共事业规制、C公众生活规制、D反托拉斯法。**答案ABD**。与其死记三个名词，不如看共性：都针对**经济行为与市场秩序**；C并非教材列举的独立三分法。

**双重作用**：国家干预能一定程度协调生产社会化需要、促进现代化并改善部分社会福利；但在教材理论框架中仍服务于资本主义生产关系与垄断资本利益，**不能根除资本主义基本矛盾**。肖1000题若称其“本质上等同于社会主义的国家资本形式”，属于根本性质混淆。

### 2. 金融化：不要混淆“金融资本形成”与“金融垄断资本壮大”

20世纪70年代布雷顿森林体系崩溃后，教材强调**金融自由化和金融创新**为金融垄断资本壮大提供重要制度条件。

- **金融自由化**：放松利率、外汇及金融机构业务限制，扩大金融市场开放。
- **金融创新**：衍生品、证券化、融资技术与综合经营等不断发展。
- **结果的两面性**：融资与资本流动机会增加，金融业在经济中的比重提高；也可能推动虚拟经济脱离实体经济，积累杠杆与危机风险。

**【2023-20，多选；第131题】**&#x2060;问金融垄断资本形成和壮大的重要制度条件：A金融创新、B金融市场管制加强、C金融自由化、D金融危机频繁。**选AC**。B方向相反；D是可能出现的后果或危机现象，不能倒写成重要制度基础。题目是“**原因/条件**”，不问“后果”。

### 3. 资本国际扩张：三个“输出”和两类国际组织

垄断资本扩张的动因包括：为过剩资本寻找较高收益、在国外保持技术优势、争夺商品市场、确保原料能源来源。形式须区分**借贷资本输出、生产资本输出、商品资本输出**：如对外贷款/证券投资、到海外设厂、向海外出售商品。肖1000题常以“技术资本输出”作混淆选项；技术许可和转移可以伴随资本输出，但不能替代本教材列举的三种基本形式。

| 概念 | 正确认识 |
| --- | --- |
| **跨国公司** | 组织跨国生产经营的重要企业形式 |
| **国际垄断同盟** | 垄断组织通过协议形成跨国垄断联盟，早期以国际卡特尔为典型 |
| **当代国际垄断同盟的主要形式** | 国家垄断资本主义的国际联盟 |
| **国际经济调节机制** | 国际组织、协议、区域集团等推进协调合作的机制 |

资本输入有双向效果：可获得资金、技术、就业与产业发展机会，同时会面临产业控制权、环境、债务和国际波动风险。不能说“流入资本一律造成伤害”，也不能说“必然全面实现互利”。

**【2020-21，多选；第132题】**&#x2060;国际货币基金组织、世界银行、世界贸易组织等协调机制推动全球化，选项A加强经济联系、B推动商品服务贸易增长、C**有效应对全球性经济危机**、D加快资本技术国际流动。**选ABD**。C错在将**一定程度缓和局部波动**扩大为**能有效解决全球危机**。

**【2006-22，多选；第134题补充】**&#x2060;帝国主义经济特征要记“垄断组织决定性作用、金融寡头、资本输出、国际垄断同盟、领土瓜分”。这是教材归纳的**五点历史特征**，题干出现“竞争缓和”也不取代其中任何一点。

## 四、经济全球化：动力、受益与风险（考点80）

### 1. 三层逻辑比死记并列项更可靠

**第一层——本质**：生产力发展与社会化大生产的客观要求。**第二层——加速条件**：科学技术和生产力发展提供物质基础与根本动力；跨国公司提供合适的组织形式；经济体制变革与国际经济组织提供体制和组织保障。**第三层——表现与效果**：生产、贸易、金融跨国联系加深；分工和生产要素流动效率可能提高，同时利益分配不均、资源环境负担及金融风险显现。

| 容易混淆的关键词 | 正确定位 |
| --- | --- |
| 信息技术革命、物流通信效率提升 | 技术基础、根本动力的具体表现 |
| 跨国公司组织全球产业链 | 企业组织形式 |
| 市场开放、国际经贸规则协调 | 制度组织保障 |
| 商品服务和资本跨境流动 | 表现与结果；不宜倒置为唯一根本原因 |

**【2024-21，多选；第135题】**&#x2060;题问全球化为何迅猛发展：信息技术突破地域限制（A）、国际分工及生产要素优势促进产业链融合（B）、发达国家制定规则使**发展中国家成为主要受益者**（C）、国际经济组织成员放松市场控制并促进贸易投资自由化（D）。**选ABD**。关键排除C：**参与并从中获益**不等于**成为主要受益者**，两类国家在地位、议价权和收益上存在不平衡。

### 2. 三组判断题：积极作用不是无条件肯定

- “经济全球化能推动生产力与分工发展”——可成立；“各国得到相同收益”——不成立。
- “发展中国家也能通过参与全球化获得技术和产业机会”——可成立；“发展中国家一定是主要赢家”——不成立。
- “全球化可能放大跨境经济风险”——可成立；“一切国际金融危机都是全球化的必然产物”——不成立。

**答题模板**：先讲生产社会化的客观趋势，再讲资金、技术、商品、服务的跨境联系及增长可能，最后点出收益不平衡、资源环境和经济风险。遇到“只有好处／只有坏处／必然均等”先警觉。

## 五、二战后资本主义的变化：五条线索、两层判断（考点81）

这是本章分类题最密集的考点（**6道：136—141**）。题目经常不是问“资本主义有没有变化”，而是要将材料精准归入**所有制／劳资分配／阶层结构／调节机制危机／政治制度**，并区分**变化原因与制度本质**。

### 1. 所有制形式的演进：不同历史时段的“主导”

| 阶段 | 教材归纳的主要所有制形式 | 最核心特征 |
| --- | --- | --- |
| 资本主义发展初期 | **私人资本所有制** | 个体资本家直接占有、经营 |
| 19世纪末至20世纪中叶前后 | **私人股份资本所有制** | 股份公司发展、占有者多元 |
| 二战后当代资本主义 | **法人资本所有制居主导**；国家资本所有制发挥重要作用 | 企业法人、机构法人持股并发挥控制力 |

**【2017-4，单选；第139题】**&#x2060;问当代资本主义**居主导地位的资本所有制形式**，四项依次为私人资本、法人资本、私人股份资本、垄断资本私人所有制。**选B法人资本所有制**。国家资本所有制重要，并不等于“主导地位”就是国家资本；股份公司普遍，也不等于“私人股份资本所有制”依然是教材指的当前主导形式。

**思考题**：上市公司大量由机构投资者持股，讨论谁控制企业时，应区分**个人家族股东、法人股东、职业经营者**，不可把“管理者实际控制经营活动”误认成“管理者拥有资本所有权”。

### 2. 劳资关系与阶层结构：“给员工参与”不等于“工人变资本家”

劳资和分配关系的新形式：**职工参与决策、终身雇佣、职工持股**以及社会福利制度的扩大。教材认为这些做法能够在一定程度缓和劳资矛盾、改善部分待遇，但不据此认定资本雇佣劳动的关系彻底改变。

阶层与阶级结构的突出变化：①资本所有权与经营权分离，部分资本所有者不直接经营；②**高级职业经理成为大公司经营活动的实际控制者**；③知识型和服务型劳动者的数量增加。

**【2022-4，单选；第137题】**“当代大公司经营活动的实际控制者”A高级职业经理、B股东大会、C监事会、D董事长。**选A**。题目并非问企业最高权力机构，也非问所有权归属。

**【2018-20，多选；第138题】**&#x2060;问**阶层与阶级结构**的变化：高级职业经理实际控制经营（A）、部分资本所有者转为以证券收益为主的食利者（B）、持股和参与决策使劳动者成为**资本家集团重要力量**（C）、知识服务劳动者增多（D）。**选ABD**。C至少有双重设陷：把“改善劳资关系的方式”错放入“阶层结构变化”，还夸大成“劳动者变为资本家集团”。

**【2013-20，多选；第141题】**&#x2060;问缓和劳资关系的“激励制度”：A参与决策、B终身雇佣、C职工选举管理者、D职工持股。**选ABD**；教材列举的三种制度不包括C。**把本题和138题放在一起比较**：同样涉及员工持股，题目问**类别**时答案会不同。

**【2025-21，多选；第136题】**&#x2060;自动化使工人更多承担监督、调节、操作等现代劳动，问说明什么：A所有制性质根本转变、B生产关系需适应生产力调整、C社会阶级与阶层结构变化、D资产阶级需不断革新生产工具和生产关系。**选BCD**。D中的“革命”指《共产党宣言》所述资本主义生产方式持续变革，不可仅凭“革命”二字排除；A把**调整**说成**根本改性**。

### 3. 调节机制、危机形态和政治制度变化

二战后资本主义国家加强宏观干预；20世纪70年代滞胀后又出现强化市场调节、减弱某些政府管制的政策转向。两者是**不同时段、不同政策侧重**，不可二选一地断定国家完全退出。教材归纳的当代经济风险包括实体经济与虚拟经济脱节、产业空心化、债务问题、周期性与结构性危机交织、社会分化加剧等。政治制度变化包括一些权利扩大、法治完善与改良主义政党影响增长。

对应肖1000题常见陷阱：题目问&#x2060;**“经济发展失调”**&#x2060;时举虚实失衡、福利风险、债务；问&#x2060;**“社会融合机制失效”**&#x2060;时举流动性退化、社会矛盾；问&#x2060;**“政治体制失灵”**&#x2060;时举制度运行困境。即使现实中互有关联，答教材分类题应依其归类判断。

### 4. “变化的根本原因”与“变化的本质”是两道不同的题

四类原因依次辨识：**科技革命与生产力发展——根本推动力量**；工人阶级争取权利的斗争——重要力量；社会主义制度的影响——重要外部影响；改良主义政党改革——促进作用。变化发生于**资本主义制度框架内**，并未从根本上改变资本主义生产关系。

**【2014-4，单选；第140题】**&#x2060;根本推动力量在“改良主义政党改革、工人斗争、科学技术革命和生产力发展、社会主义制度影响”中，**选C**。其他选项并非“完全无关”，而是**逻辑层次不符合题干问法**。

**肖1000题推理训练**：如选项称“取得社会福利，故资本雇佣劳动的生产关系从根本上消失”“新技术改变了生产组织，故剩余价值的追逐不再存在”，都将**阶段性调整**偷换为**根本性质更替**。

## 六、21世纪资本主义新特征与深层矛盾（考点82—83）

这两项**在本套分类真题中未单列**，但精讲精练和肖1000题都有专门材料，应掌握“一眼匹配”的分类框架，而不是用大量时间背诵每一句表述。

| 考点82：四项新特征 | 具体材料判断 |
| --- | --- |
| 科技创新加速生产方式变化 | 产业结构、生产组织和劳动形式、新经济形态 |
| **国际金融资本垄断影响日益显现** | 金融垄断寡头化、国际化；经济虚拟化、产业空心化 |
| 社会阶层层级复杂多样 | 职业和阶层分化、结构调整 |
| 全球范围的权力与资源竞争 | 发达资本主义国家凭优势推行霸权主义与强权政治的教材归纳 |

教材用“**最突出、最鲜明、最主要的特征**”对应的是**国际金融资本的垄断**，不是笼统的“科技创新”。考点83则按**经济发展失调／政治体制失灵／社会融合机制失效**三类组织典型矛盾。两项均回扣考点84：形式变化与基本矛盾没有消失可以同时成立。

## 七、历史进步性、历史局限与过渡的长期性（考点84）

评价资本主义要避免两个极端：既不能否认其推动技术、分工和生产力增长的历史作用，也不能把这种作用推成“资本主义无限制地适应生产力”。

- **历史进步性**：科技在资本逐利动力和竞争压力下加快应用，社会生产力获得显著提高；相对封建生产方式曾有历史进步作用。
- **内在局限性**：资本主义生产社会化与资本主义私人占有的矛盾，在经济危机、分配和社会冲突中反复表现。
- **历史趋势与时间尺度**：生产力增长与资本社会化为更高形态创造物质条件；但历史趋势**不保证近期、不经斗争、不经复杂过程就自动实现**。

**【2021-4，单选；第142题】**&#x2060;马克思谈资本主义在发展劳动生产力时，亦为更高级生产形式创造物质条件。A资本越发展越能永远巩固自身、B可无限解放生产力、C资本扩张一定不利于创造财富、D资本主义是一种**历史的、过渡性的生产方式**。**选D**。这是“具有进步性≠永恒合理性”的经典材料。

**【2019-20，多选；第143题】**&#x2060;问替代资本主义为何是**长期复杂过程**：A制度有一定自我调节能力、B发展不平衡、C任何社会形态**绝对稳定**、D资本主义生产关系当前仍有容纳生产力的发展空间。**选ABD**。C用“绝对”否认社会更替；A、D说明并非“今天存在基本矛盾，明天必然立即消亡”。

## 九、肖1000题举一反三与小测

**典型变式1：主体和路径辨析。**&#x2060;某集团通过控股不同公司的母子公司层级控制许多企业，问是“金融资本的三种形成路径”还是“金融寡头控制企业的方法”？应答后者——**参与制**；与其形成的金融联系、资本参与、人事参与不能混为一组。

**典型变式2：国家调节手段分类。**&#x2060;政府使用利率政策稳定总需求，同时制定反垄断法约束某家平台。前者属**宏观调节**，后者属**微观规制**；它们都是国家垄断资本主义教材五种表现形式中的不同类目。

**典型变式3：说明制度性质时的逻辑。**&#x2060;职工持有少量股票、劳动方式更加技术化，能说明管理与分配形式变化，**不能推出雇佣劳动制度及所有制根本变性**；此题专防从“量与形式变化”跳到“性质彻底变化”。

**典型变式4：排除题中的绝对化关键词。**“垄断消除竞争”“国际机构有效化解所有全球危机”“各国从全球化均等受益”“所有社会形态绝对稳定”“资本主义生产关系已经根本改变”，都应立即回到对应概念验证。

### 考前自测

1. 某企业靠兼并三家对手跃升行业最大：**资本集中**；如果靠利润扩大自有产能：**资本积累／积聚**。
2. 金融寡头“参与制”首先回答什么？**经济领域的层层控制**。
3. 各种垄断价格最终能创造额外的社会总价值吗？**不能**，它调整的是价值与剩余价值的分配。
4. 自由化和创新属于金融垄断资本的什么？**重要制度条件**，不是金融危机的同义词。
5. 当前企业由高级经理掌控经营，是否意味着其成为公司资本的最终所有者？**否**。
6. 当代资本主义在生产关系范围内的自我调整，与资本主义基本矛盾存在能否同时成立？**能**。
