## 一、本章考情与学习路线

上传的《政治分类真题》在本章收录 **27题**；其中考点44“社会存在与社会意识” **8题**、49“社会形态更替” **4题**、59“个人在社会历史中的作用” **4题**，合计16题，占本章所收题目的多数。考点45、50、54、58各 **2题**；46、48、57各 **1题**。考点43、47、51—53、55、56虽未在这份分类文件中单独对应真题，却是理解命题的桥梁，应结合肖1000题适度整合，不宜彻底跳过。

| 梯队 | 关键章节内容 | 核心命题问题 |
| --- | --- | --- |
| **第一梯队** | 社会存在与社会意识（43—44）、社会形态更替（48—50）、历史创造者（56—59） | “社会意识为何变化/为何不同步？”“规律客观性为何不排斥历史选择？”“人民群众与杰出人物如何区分？” |
| **第二梯队** | 社会基本矛盾（45—46、51）、科技（54） | “哪个是决定力量？”“科技是否自动决定制度？”“生产关系与经济基础怎样区分？” |
| **框架补充** | 交往和世界历史（47）、阶级斗争革命改革（52—53）、文化（55） | 熟记准确定位、不要乱用‘根本动力’‘唯一决定’ |

本章的总逻辑可写成一条线：**生产方式构成社会的物质基础→社会存在决定社会意识；生产力与生产关系、经济基础与上层建筑的矛盾推动社会发展；发展通过人民群众的实践实现，具体个人和制度选择受历史条件制约。** 题目常故意混淆这一链条中“最基本”“根本动力”“最突出的表现”“直接动力”等不同层级词语。

## 二、历史观基本问题：社会存在与社会意识（考点43—44）

### 1. 唯物史观与唯心史观的分界（43）

**社会存在与社会意识的关系问题是社会历史观的基本问题。** 唯物史观认为社会存在决定社会意识，社会意识反映社会存在并具有能动反作用；唯心史观则从人们的思想、意志、观念乃至神意解释社会历史的根本动力。认识这一点，才能把社会发展规律与历史人物的目的性统一起来：**历史活动有意识，不等于社会历史由意识创造或任意决定。**

一个常见偷换是从“人会自觉选择”直接推出“任何社会制度都由思想家的观念设计决定”。历史选择需要现实的生产力、生产关系与社会条件作为基础，不能任凭主观愿望跳过客观条件。

### 2. 社会存在三项内容与各自地位（44）

| 要素 | 主要含义 | 考试中的准确地位 |
| --- | --- | --- |
| **自然地理环境** | 人类生存活动需要的自然条件、资源和生态系统 | 生存与发展的**必要条件**，能加速或延缓发展，不是社会性质的决定力量 |
| **人口因素** | 人口数量、结构、质量、分布等 | 重要的物质生活条件，作用受社会生产状况和制度制约 |
| **物质资料生产方式** | 生产力与生产关系的统一 | **社会存在发展的基础与决定力量；最集中体现社会物质性** |

**【2011-2，单选真题】** 问“社会存在的多种物质生活条件中，最集中体现人类社会物质性的是”：A社会形态，B地理环境，C人口因素，D生产方式。**答案 D。** 地理与人口虽必要，却不能替代生产方式在社会性质、发展方向上的决定作用。

**肖1000题“藏粮于地、藏粮于技”**：自然条件与科学技术作用都不可忽略，但要排除“科学技术是生产力中最活跃因素”这一表述（按本章知识体系，**最活跃的因素是劳动者**），还应排除“技术可完全摆脱物质条件”。

### 3. 人与自然：不是单向支配，更不是退回原始生态

人属于自然界，又能通过社会劳动认识、利用、改造自然。人与自然的关系是物质变换过程，既有对自然规律的遵循，也有对自然条件的能动利用；不当开发可能损害自然，最终伤及社会自身发展。

**【2022-2，单选，生态护林员与脱贫“双赢”】** “人不负青山，青山定不负人”四选项中，B“生产力包括自然要素，合理开发自然能促进社会发展”正确。A“自然自发满足人的要求”、C“人只能被动适应自然”、D“自然能动补偿人的劳动”均错。**答案 B。** 自然有客观条件与效应，但不能把自然拟人化成具有目的与意志的主体。

**【2021-18，多选，气候变化与病毒适应性】** A“自然环境是生存发展重要前提”、D“人类受自然制约同时也改变自然环境”正确，**答案 AD**。B把自然环境说成决定社会发展的因素；C说人只能适应不能改造，均违背历史唯物主义。

**【2004-2，单选，‘北大荒’变‘北大仓’又退耕】** 题眼是改造自然有边界，人应当**合理调节人与自然的物质变换**（D）。A恢复到原始生态、B一切改造都遭自然报复、C人永远被自然支配均绝对化。**答案 D。** 可迁移到肖1000题的南水北调、生态城市、气候治理等材料。

### 4. 社会意识的内容与三类相对独立性

社会意识是社会生活的精神方面，包括社会心理、思想观念等，是**社会存在的反映**。社会存在是其产生变化的客观根源；但社会意识并不对社会存在作机械、同步的镜像复制：

1. **不完全同步性、不平衡性**：社会存在变化后，既可能有滞后认识，也可能出现超前的思想预测；不同地区经济与文化发展水平不完全同步。
2. **历史继承性及内部相互作用**：道德、宗教、艺术、哲学等既受现实制约，也继承历史成果并相互影响。
3. **对社会存在的能动反作用**：先进的社会意识能够推动社会发展；落后的意识可能阻碍发展。这是社会意识相对独立性的**最突出表现**。

**【2015-2，单选】** 问“社会意识相对独立性最突出的表现”。A不完全同步、B各种形式相互影响、C历史继承、D对社会存在的能动反作用。**答案 D。** A—C都是相对独立性的表现，唯D直接表明其对物质生活有现实作用，这类题要特别留心“**最突出**”。

**【2021-3，单选，生物识别技术快于法律完善】** 法律规范与新技术发展具有**不平衡性**，**答案 C**。不能说法律“只能落后”“总是阻碍”，也不能说法律法规是技术发展最终动力。法律可滞后，也可能因前瞻治理提前形成规则。

**【2022-20，多选，‘逆袭’‘躺平’‘YYDS’等热词】** A“社会心态是社会生产生活的反映”、B“社会意识随社会存在变化而变化”正确，**答案 AB**。C“社会意识是自发反映”错误地把所有社会意识都归为非自觉的；D颠倒因果，用社会心态决定社会生活多样性。

**【2020-19，多选，‘一方水土孕育一方文化’】** A经济状况影响、决定文化发展的基本形态；B地理空间影响文化外在特征；D文化具有相对独立性。**答案 ABD。** 地域文化的形成既有自然条件，也有经济和历史因素，不能由“水土”推出地理环境决定一切，更不能把文化说成决定社会发展的根本力量（C）。

**肖1000题合并辨析**：《新华字典》词义变化、“吃过猪肉/见过猪跑”仍被理解、文学随时代变化，分别侧重**客观生活来源、历史延续与发展不完全同步、社会意识依赖社会存在**。文章与文艺可以走在时代前列，但先进意识的影响仍要通过现实社会实践实现。

## 三、社会基本矛盾的两级结构（考点45—46、51）

### 1. 看懂三层关系，别把概念混成一锅（45）

**生产力是人们改造自然、创造物质财富的现实能力**。基本要素包括劳动者、劳动资料和劳动对象；生产工具是劳动资料中最重要的部分，是衡量生产力发展水平的重要标志；**劳动者是生产力中最活跃的因素**。科学技术作为先进生产力的重要标志，转化为实际生产力需要与劳动者、生产资料和生产组织等结合。

**生产关系是人们在物质生产过程中形成的不以人的意志为转移的经济关系**，包括生产资料所有制关系、生产中人们的地位及其相互关系、产品分配关系，其中**生产资料所有制关系最基本、具有决定性作用**，是判断不同生产方式与经济结构性质的重要依据。

| 问的是 | 首先选什么 | 为什么 |
| --- | --- | --- |
| 区分历史上的不同经济时代 | 生产工具的状况 | 显示生产力发展程度 |
| 区分不同经济结构或生产关系性质 | 生产资料所有制关系 | 生产关系内部起决定作用的方面 |
| 社会历史发展的最终决定力量 | 生产力的发展 | 生产关系必须与之相适应 |
| 社会历史存在的基础 | 物质资料生产方式 | 是生产力和生产关系的统一 |
| 社会发展的根本动力 | 社会基本矛盾运动 | 包含生产力与生产关系、经济基础与上层建筑两对矛盾 |

**辩证关系**：生产力状况决定生产关系的性质、变革要求；生产关系反作用于生产力。**适合发展要求的生产关系促进生产力，不适合则阻碍。**“生产关系一定要适合生产力状况”不是说二者在所有时期都完全一致、无矛盾，而是说在矛盾运动中必然要求调整。

**【2019-3，单选】** 马克思说变革时代的意识应从物质生活矛盾解释，问最根本的“物质生活矛盾”。A“生产力与生产关系的现存冲突”；B经济基础与上层建筑；C社会与自然；D社会存在与意识。**答案 A。** 两对都是基本矛盾，但**生产力与生产关系的矛盾更基本**。

**【2020-18，多选，区块链促进交易与契约网络】** 人与人形成的关系：B“具有多样性、复杂性”、C“归根到底受生产关系制约”正确，**答案 BC**。A把交易关系缩成“单纯经济商业”、D把基于数字技术的真实社会关系误称只存在于虚拟空间；技术媒介变化不取消现实社会关系和经济基础。

**肖1000题高频材料**：“手推磨”与“蒸汽磨”说明一定生产关系有相应生产力的物质条件；**新质生产力**发展需要调整生产关系、畅通要素配置；“新农具”体现新生产工具和劳动形式变化。不可说“科学技术独自决定全部社会形态更替”。

### 2. 经济基础—上层建筑：两个‘基础’并不相同（46）

**经济基础**是社会一定阶段由生产力所决定的**生产关系的总和**；**上层建筑**是建立在经济基础之上的意识形态和相应政治法律制度、组织、设施。

| 类型 | 内容示例 | 试题陷阱 |
| --- | --- | --- |
| **观念上层建筑（意识形态）** | 政治法律思想、道德、宗教、艺术、哲学 | 不是一切语言文字、自然科学知识都自动属于意识形态 |
| **政治上层建筑** | 政治法律制度，政权、政党、军队、警察、法庭、监狱等 | “政党/法庭”并非只是思想观念 |

**政治上层建筑居主导地位，国家政权是其核心。** 国家是历史范畴，阶级社会中是阶级矛盾不可调和的产物，是阶级统治的工具，不是永恒存在的天然共同体。

基本规律：**经济基础决定上层建筑的产生、性质、变更要求；上层建筑反作用于经济基础。** 上层建筑维护适应社会发展要求的经济基础和生产关系时，可促进生产力发展；若阻碍生产力进步，也可能有保守和阻碍作用。不能把“服务于现有经济基础”自动等同于“历史上永远进步”。

**【2012-18，多选，批判将马克思主义说成‘经济单一因素决定论’】** A把多因素综合作用歪曲为单因素；B把经济基础和上层建筑双向作用歪曲为单向；C把归根到底的决定作用歪曲为唯一决定。**答案 ABC。** D“意识形态对历史始终具有积极反作用”本身错误，落后、反动意识也可能阻碍社会发展。**区分‘归根到底决定’与‘唯一、直接、即时决定’是本题核心。**

### 3. 两对矛盾的关系与社会发展动力（51）

- 第一对：**生产力↔生产关系**；第二对：**经济基础↔上层建筑**。
- 生产关系对于生产力而言，是经济关系中与生产力相适应与否的方面；相对于上层建筑而言，生产关系的总和构成经济基础。
- **社会基本矛盾是社会发展的根本动力**，贯穿不同社会形态；其中生产力是最基本的动力因素和最终决定力量。
- **社会主要矛盾**随特定历史阶段可能发生变化，不等于贯穿全部社会形态的两对基本矛盾。

肖1000题的“科技是否根本动力”多选将科技革命称作经济变革“杠杆”是对的；把科技等同**社会基本矛盾的根本动力**则错。对于“改革是否解决基本矛盾”，回答的是改革**调整生产关系和上层建筑**、促进生产力，并非取消矛盾本身。

## 四、交往、社会进步、社会形态和文明（考点47—50）

### 1. 普遍交往和世界历史（47）

物质交往是精神交往的基础，交往促进生产力、社会关系、文化传播和人的全面发展。民族与国家随着普遍交往日益形成相互联系的世界历史。**生产方式的发展变革是世界历史形成发展的基础；普遍交往是世界历史的基本特征。** 不能把世界历史简单理解为“世界各地历史机械相加”，更不能说全球化消除了矛盾。

### 2. 社会进步：总体向前但道路曲折（48）

社会进步一方面体现为**社会形态由低级向高级的发展**，另一方面也包括**同一社会形态内部的发展和改革**。进步趋势不排斥阶段性曲折、挫折或局部倒退。社会进步的重要标志是人的发展程度；人的体力、智力、个性与交往能力得到发展，**最根本表现为自由程度提高**。

人的发展三阶段：

1. **人的依赖关系占统治地位**——资本主义以前的社会。
2. **以物的依赖关系为基础的人的独立性**——资本主义社会。
3. **自由个性**——共产主义社会，人的自由全面发展。

**【2026-1，单选，现代化‘阶梯式递进、不断发展进步’】** 判断四项：①前进性与曲折性统一；②规律性与能动性统一；③连续性与非连续性统一；④直线性与循环性统一。正确为**①②③（A）**。社会发展是曲折的、有阶段性质变的过程，不是直线反复或简单循环；“阶梯式递进”还体现人的努力在客观规律约束下发挥作用。

### 3. 五种社会形态与更替的客观必然性（49）

五种社会形态：**原始社会→奴隶社会→封建社会→资本主义社会→共产主义社会**（社会主义社会为共产主义的第一阶段）。**分类依据是经济基础、尤其生产关系的性质**，不是当下统治集团名称、人口数量或劳动工具数量。

但**统一性不等于每个国家严格机械地依次经历所有阶段**：具体国家和民族可因历史条件不同而有不同路径乃至跨越某一形态。任何选择都受生产力发展水平、客观条件、人民群众根本利益和整体历史发展规律制约；“跨越”不等于“用法令取消必需的物质条件”。

**【2023-2，单选】** 判断五种形态划分依据。C“经济基础特别是生产关系的性质”正确，**答案 C**；A生产工具状况偏重生产力水平，B政治属性、D分工范围都不能作为五种形态的根本分类依据。

**【2018-18，多选，社会形态更替具有客观性和必然性但不排斥历史选择】** A客观趋势提供可能性空间；B主观能动性与客观规律性统一；C人们历史选择归根到底是人民群众的选择——**答案 ABC**。D“客观历史过程由每个个人的主观意志决定”错误。

**【2006-18，多选，马克思说不能用法令取消发展阶段但能缩短分娩痛苦】** A合规律性与合目的性统一，C自觉选择作用，D人类总体历史进程不能任意超越正确；B“社会发展和自然演变同样都是自觉的”错误，**答案 ACD**。句中&#x2060;**“不能取消”与“能够缩短”必须同时解释**，少解释一边都会误入机械决定论或唯意志论。

**【2021-2，单选，历史是最好的教科书】** 能汲取历史经验是因为**历史发展有不以人意志为转移的客观规律**（A），并非事件机械重演或已经掌握全部规律。

### 4. 文明多样性（50）：客观差异不是优劣序列

文明概括人类社会实践所创造的**物质、精神、制度成果**；每一文明是在特定自然环境、历史背景、民族传统与生产生活交往方式中发展起来的。因此文明的不同样态有其现实历史原因；彼此交流互鉴能够丰富发展，不能假定只有一种合法的文明模式，也不能认定文明必须彼此隔绝才能形成。

**【2026-21，多选，黄河、长江、尼罗河等‘河流与文明’】** B“每种文明生长于特定自然环境和民族传统”、C“自然地理环境可以加速或延缓文明进步”为正确；A“文明交流主要通过河流完成”、D“地理环境决定文明形态”错误。**答案 BC**。河流很重要，**重要条件≠决定力量**。

**【2024-19，多选，人类文明的多样性】** A“独特生产与生活方式决定文明发展不同样态”、C“每一文明都有独特性，是人类文明的组成部分”正确，**答案 AC**。B文明存在天生优越或更强文化基因、D文明独自在隔离状态下发展均错误。题目并非要求否认文明间差异，而是**承认差异、反对优越论和封闭论**。

## 五、阶级斗争、改革、科技、文化各在哪一层发挥作用（考点52—55）

### 1. 阶级斗争、社会革命与改革（52—53）

**阶级斗争是阶级社会发展的直接动力**，不能写成“一切社会的根本动力”——后者是**社会基本矛盾**。社会革命是社会形态更替的重要手段和决定性环节，可显著激发人民群众改造社会的力量。

**改革是推动社会发展的又一重要动力**：它在既定社会制度的自我调整和完善中改变不适应生产力发展的生产关系和上层建筑，是同一社会形态内部的量变或部分质变。对社会主义而言，改革是自我完善和发展，不是简单取消原有全部制度。

**命题口诀**：根本动力**两对基本矛盾**；最终决定力量**生产力**；阶级社会直接动力**阶级斗争**；社会革命是形态更替的重要手段；**改革**推动制度自我调整；**科技革命**是强大杠杆。层次不同，不能争抢“唯一”。

### 2. 科学技术是强大杠杆，不是自动向善的万能决定力量（54）

科技作为先进生产力的重要标志，推动生产方式、生活方式、思维方式发生深刻变化，也受社会需求推动。科技有双重社会效应：促进生产与社会进步，同时可能出现生态、伦理、安全、社会风险。其用途与社会后果还受制度、利益关系、认识水平和使用方式等条件制约。

**【2024-3，单选，北斗‘天上一张网’与‘地上一张网’】** 导航精度由米级向更精密水平推进，应用延伸农林牧渔、出行生活；问推动技术精度持续提高的根本需求。四选项为A科研规范、B实践主体意志、C主体兴趣、D社会实践的需要，**答案 D**。题眼是现实社会活动不断对精度提出要求，而非兴趣或主观愿望自身可以决定技术演进。

**【2010-18，多选，经济危机孕育科技革命】** C“社会实践的需要是科技发展的强大动力”、D“科技创新推动社会经济跨越式发展”正确，**答案 CD**。A“科技革命是摆脱社会危机的根本出路”、B“科技是社会形态更替的根本标志”错误，均夸大科技的独立决定作用。

**肖1000题数字技术材料**：数字创新可能改变产业组织与社会关系，但不能直接断定一切数字技术进步都会**自动**触发根本性制度变革；技术对人的思维方式产生影响，也不等于任何技术后果都积极。

### 3. 文化作用：思想指引、精神动力、凝聚力量（55）

文化对社会发展可以发挥积极或消极作用。先进文化有助于提供**思想指引、精神动力、凝聚力量**，并经由人的行为和社会实践影响物质活动，但不能把精神力量看成**不经实践直接物化为产品**。

**肖1000题“中秋节与海外华人”**：共同节日维系共同身份与情感，是文化**凝聚力量**的典型；“素人写作”体现社会生活为文化创作提供素材、人民群众创造精神财富，作品也可反作用于社会生活；不能推出“文化是社会进步的根本动力”。

## 六、唯物史观怎样回答“谁创造历史”（考点56—59）

### 1. 英雄史观与群众史观（56）

**英雄史观**夸大少数人物意志或精神力量，忽略社会生产与广大群众的历史实践；**群众史观**立足现实的实践活动，认定人民群众是创造历史的决定性力量，同时不否定历史人物的具体作用。两者不是“完全忽视英雄”和“完全歌颂英雄”的修辞差异，而是对**社会历史根本动力与主体**的解释不同。

### 2. 历史创造者的判定方法与人的本质（57）

唯物史观考察人必须从**现实的人**出发，即处于具体社会关系中、基于生活需要和社会需要从事活动的能动的人；人的本质“在其现实性上，是**一切社会关系的总和**”。其根本属性是**社会属性**，人的本质不是孤立个体天生具有的不变抽象物。

**【2009-4，单选，《关于费尔巴哈的提纲》论人的本质】** 选项A自然与社会属性的统一、B人的共同属性概括、C一切社会关系总和、D自由理性外化；**答案 C**。题眼是“**在其现实性上**”，不应将“社会属性是人的本质属性”弱化为生物属性与社会属性并列说明。

进一步的三个判断角度：从**社会历史的整体过程**而非单人经历理解历史；从**历史必然性与实践的推动作用**理解创造者；区分人类总体、群体与个人的不同历史层次。每个人可以对社会有或大或小影响，不等于所有个人都在同等意义上构成“历史的创造者”。

### 3. 人民群众的范围、决定作用与条件制约（58）

- **量的角度**：社会人口的绝大多数；**质的角度**：一切对社会历史发展起推动作用的人们。
- **最稳定的主体**：从事物质资料生产的劳动群众；不同历史时代的构成可以变化。
- **三大作用**：创造**物质财富**，创造**精神财富**，构成**社会变革的决定力量**。
- **受条件制约**：社会经济条件有首要决定性影响，政治条件、精神文化条件同样影响人民群众活动方式和效果。

**【2018-3，单选，‘坚持以人民为中心’理论基础】** B“人民群众是历史的创造者的原理”，**答案 B**；A人的本质是社会关系、C活动受条件制约、D泛指“总体人的主体地位”都不是此题最直接、最准确的理论依据。

**【2013-18，多选，人民群众的界定】** A“从量上看社会人口绝大多数”、B“从质上看推动社会历史发展的人们”、D“最稳定主体从事物质资料生产的劳动群众及其知识分子”正确，**答案 ABD**。C“任何时代都不包括剥削阶级”带有绝对化判断，忽视“人民群众”作为历史范畴，因而不选。

**肖1000题‘投资于人’**：投资教育、技能与人的发展，与人民群众是历史创造者、劳动者是生产力中最活跃因素相吻合；不能说“个体物质欲望是根本动力”或“人口决定全部历史进程”。

### 4. 历史人物：作用巨大，但不能替代规律与群众（59）

历史人物是特定历史事件的主要倡导者、领导者或思想文化代表，其作用可以是进步的，也可能是阻碍的。杰出人物可以提出新的历史任务、**影响历史事件进程甚至决定个别事件的结局**；但**不能从根本上改变社会历史发展的总方向与总进程**。人物的出现具有客观历史条件的必然性，也包含具体个体出现的偶然性。

评价人物遵循三个原则：**置于具体时代条件中考察；全面分析功过及历史作用；坚持人民群众和客观社会规律的基本立场。** 不能用今天的认识水平机械苛求历史人物，也不能将历史成功全归功于领袖、将挫折全归咎于个人。

**【2025-3，单选，历史人物评价的时代条件】** D“从特定的历史条件出发作具体全面考察和评价”正确。A“杰出人物与群众作用同等重要”、B“智慧性格能改变历史基本方向”、C“逆境作用必然比顺境大”错误。**答案 D。** 本题是典型“反个人崇拜式单因论，不否认个人能动性”的思想。

**【2023-17，多选，‘乐队需要指挥’与领袖权威】** A引领社会发展方向、B影响事件进程、C凝聚群众力量正确；D“领袖创造人类社会历史”把历史创造者从人民群众改成个人。**答案 ABC。** A应结合具体历史条件理解为在符合历史规律与群众利益的前提下发挥引领作用，不能把它读成改变全部历史发展的客观方向。

**【2017-18，多选，历史人物一般规律】** A不能决定改变总进程、总方向；B其智慧性格影响历史；C进步人物可能首先提出新任务正确；D“历史人物总起积极作用”错误，**答案 ABC**。

**【2014-18，多选，史铁生‘每个人都能为后人照亮道路’】** A“历史是无数个人相互作用的合力”、D“每个人对社会有大小不同的作用”正确；B“杰出人物决定历史走向”、C“人人都是历史创造者”错误，**答案 AD**。严格区分“**每个人有影响**”与“**人民群众是历史创造者**”。

## 七、四大易混组合：集中速查

| 极像、但不等同的概念 | 正确分辨 |
| --- | --- |
| 社会存在 **vs** 社会意识 | 前者是社会物质生活条件，后者是精神层面；后者以反映前者为基础并有反作用 |
| 地理环境/人口 **vs** 生产方式 | 前两者重要、必要，但生产方式是最集中的社会物质基础与决定力量 |
| 生产力 **vs** 生产关系 | 生产力强调改造自然的能力；生产关系强调生产过程中的人际经济关系 |
| 生产工具 **vs** 生产资料所有制 | 前者显示生产力水平；后者决定生产关系性质 |
| 生产关系 **vs** 经济基础 | 生产关系相对于生产力的矛盾是生产关系；社会一定阶段生产关系的总和构成经济基础 |
| 观念上层建筑 **vs** 政治上层建筑 | 前者是思想意识形态，后者是制度、机构与政治组织 |
| 社会基本矛盾 **vs** 社会主要矛盾 | 基本矛盾贯穿社会发展始终；主要矛盾有阶段性变化 |
| 根本动力 **vs** 直接动力 **vs** 又一动力 | 社会基本矛盾；阶级斗争（阶级社会）；改革 |
| 社会历史必然性 **vs** 历史选择性 | 必然性限定现实可能空间；群众在历史条件中能动选择具体路径 |
| 文明多样性 **vs** 文明优越论 | 文明有现实历史差异，不等于某一种文明天然高级于其余文明 |
| 科学技术社会作用 **vs** 决定社会形态的力量 | 科技推动生产力并具有双重效应，不能替代生产方式及基本矛盾 |
| 人民群众决定历史 **vs** 个人影响历史 | 前者决定总体进程，后者可以改变具体事件进程，受客观条件限制 |

## 八、把材料题拆成“决定条件—能动作用—边界”的三步法

**第一步，找决定条件。** 地方文化先找现实经济与自然条件；社会制度变化先找生产力与生产关系；历史人物行动先找所在时代条件；文明形成先找生产生活方式。

**第二步，找能动作用。** 社会意识可以反作用于社会存在；上层建筑可以反作用于经济基础；人民群众和个人通过实践产生影响；科技与文化可促进或阻碍社会进步。

**第三步，找限定边界。** 凡是把“重要条件”写成“决定力量”、把“有反作用”写成“始终积极”、把“可以选择”写成“任意设计”、把“历史人物有影响”写成“个人创造历史”，均属本章常见错误选项。

**专题练习回收建议**：先做2011/2015/2021/2022的社会存在与社会意识题，形成基础判断；再做2019/2012的两对基本矛盾；随后做2023/2018/2006的历史形态选择，最后连做2025/2023/2017/2014的历史人物题。肖1000题优先对应**生产工具/所有制、自然条件的非决定性、社会意识相对独立性、人民群众与个体作用**四组易错选项。
