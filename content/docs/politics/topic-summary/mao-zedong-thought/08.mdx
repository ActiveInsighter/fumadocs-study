## 考点29 科学发展观的科学内涵与主要内容

### 1. “第一要义—核心立场—基本要求—根本方法”四位一体

| 题目设问 | 唯一精确对应 | 典型误配 |
| --- | --- | --- |
| **第一要义** | **推动经济社会发展**（常简记为“发展”） | “以人为本”不是第一要义 |
| **核心立场** | **以人为本** | “统筹兼顾”不是核心立场 |
| **基本要求** | **全面协调可持续** | “发展”不是基本要求 |
| **根本方法** | **统筹兼顾** | “全面协调可持续”不是根本方法 |

理解而非只背词：**发展**回答“要完成什么任务”；**以人为本**回答“发展为了谁、依靠谁”；**全面协调可持续**回答“发展质量与结构应符合哪些要求”；**统筹兼顾**回答“现实中怎样处理复杂关系”。

**【2009-11，单选，答案C】**：考“根本方法”，直接选**统筹兼顾**。A发展、B以人为本、D全面协调可持续均是理论的真实内涵，但**对应的层级不对**，属于典型“内容对而位置错”的干扰项。

**肖1000**：单选1固定考**基本要求＝全面协调可持续**；多选1四句合考，不能因为其中某一条看起来重要就漏选其余部分。

<Callout type="info" title="用两道练习建立反向检索">
看到“**根本方法**”立刻反应“**统筹兼顾**”；看到“**基本要求**”立刻反应“**全面协调可持续**”。再倒过来默写各自的设问。这两组尤其容易相互替换，也是2009年真题与肖1000精简题的重合知识点。
</Callout>

### 2. 主要内容：不是单纯只谈经济发展

| 建设领域 | 教材核心知识 | 可能设置的错项 |
| --- | --- | --- |
| **经济建设** | 以科学发展为主题、以**加快转变经济发展方式**为主线 | 将发展简单等同于片面追求增长速度 |
| **民主政治** | 坚持**党的领导、人民当家作主、依法治国有机统一** | 三者中任意一项可以单独取代其余两项 |
| **文化建设** | 社会主义核心价值体系是**兴国之魂**，决定中国特色社会主义发展方向 | 把“核心价值体系”误写成一般经济政策 |
| **社会建设** | **社会和谐是中国特色社会主义的本质属性** | 把和谐简单理解为没有任何社会矛盾 |
| **生态文明** | 生态文明建设关系人民福祉和民族未来，是长远大计 | 将生态环境只归结为短期经济成本 |
| **党的建设** | 加强**党的执政能力建设、先进性和纯洁性建设** | 将党的建设与科学发展割裂 |

科学发展观不仅关注经济总量，也关注经济、政治、文化、社会、生态等领域间的**协调**，并关注人民群众现实利益与长期发展能力。

### 3. 党的领导、人民当家作主、依法治国：三项地位不能串

| 要素 | 在社会主义民主政治中的定位 |
| --- | --- |
| **党的领导** | 人民当家作主和依法治国的**根本保证** |
| **人民当家作主** | 社会主义民主政治的**本质和核心** |
| **依法治国** | 党领导人民治理国家的**基本方略** |
| **三者统一的根源** | 由**社会主义国家的本质**决定 |

**【2008-12，单选，答案B】**：问“三者的统一性由什么决定”，选**社会主义国家的本质**。A“社会主义初级阶段基本国情”、C“根本任务”、D“发展战略”虽然是相邻章节的重要概念，却不能替换本题**根源层次**。

**肖1000单选2**：问坚定不移走中国特色社会主义政治发展道路“最根本的是”什么，要答**党的领导、人民当家作主、依法治国有机统一**，不能缩减为只强调其中一项。坚持党的领导是根本保证，而“最根本的要求”问的是**三者有机统一**。

### 4. “以人为本”和“共同富裕”不是无条件同义

- **以人为本**是科学发展观的**核心立场**，强调发展为了人民、发展依靠人民、发展成果由人民共享。
- **共同富裕**是社会主义本质和发展的重要目标，在第六章邓小平社会主义本质概括中出现。
- 两者方向相通，但设问如果明确限定“科学发展观的核心立场”就只选**以人为本**，不能直接用“共同富裕”替代原句。

## 考点30 科学发展观的历史地位

### 1. 最鲜明的精神实质要背四个词

**解放思想、实事求是、与时俱进、求真务实**。

| 理论与表述对象 | 固定表述 | 考查方式 |
| --- | --- | --- |
| 邓小平理论的**精髓** | 解放思想、实事求是 | 第六章的两词表达 |
| 贯彻“三个代表”的**关键** | 坚持与时俱进 | 第七章“关键—核心—本质”中的第一项 |
| 科学发展观**最鲜明的精神实质** | **解放思想、实事求是、与时俱进、求真务实** | 本章要求**四词完整** |

**肖1000多选2**四个词均需选中；教材仿真单选把两词、三词、四词分设选项，若问“精神实质”必须选**四词全表述**。

### 2. 创造性回答什么问题

- 邓小平理论：围绕“**什么是社会主义、怎样建设社会主义**”。
- “三个代表”重要思想：在进一步回答社会主义问题的基础上，创造性回答“**建设什么样的党、怎样建设党**”。
- **科学发展观**：在继承前述认识基础上，创造性回答“**新形势下实现什么样的发展、怎样发展**”。

这一组是“理论成果—时代课题”的标准匹配。**科学发展观不是与改革开放和社会主义建设实践割裂的全新理论体系**，而是中国特色社会主义理论体系的重要组成部分、**新世纪新阶段的接续发展**。

### 3. 历史地位

1. 是中国特色社会主义理论体系在**新世纪新阶段的接续发展**，拓展对中国特色社会主义发展规律的认识。
2. 是**全面建设小康社会、加快推进社会主义现代化的根本指针**。
3. 将**经济建设、政治建设、文化建设、社会建设、生态文明建设**的要求联系起来，强调科学发展、协调发展和可持续发展。
