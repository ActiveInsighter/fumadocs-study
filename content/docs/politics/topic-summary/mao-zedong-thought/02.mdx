## 考点5 新民主主义革命理论形成的依据

### 1. 近代中国国情：最基本国情、主要矛盾、历史任务

- **最基本国情**：近代中国逐步沦为**半殖民地半封建社会**。
- **两对主要矛盾**：帝国主义和中华民族的矛盾；封建主义和人民大众的矛盾。通常前者是各种矛盾中**最主要的矛盾**。
- **革命的根本任务**：推翻帝国主义、封建主义、官僚资本主义的反动统治，破除束缚生产力发展的社会关系和政治制度，为民族独立、人民解放、国家富强、人民幸福创造前提。
- **由社会性质决定的革命性质**：**资产阶级民主革命**，尚不是直接消灭全部资本主义私有制的无产阶级社会主义革命。

| 题干关键词 | 准确回答 | 易混错误 |
| --- | --- | --- |
| “最基本国情” | 半殖民地半封建社会 | “殖民地社会”“资本主义社会” |
| “最主要的矛盾” | 帝国主义和中华民族的矛盾 | 把封建主义和人民大众的矛盾无条件设为首要 |
| “革命的首要对象” | 帝国主义 | 把民族资产阶级当作首要敌人 |
| “当时革命的性质” | 资产阶级民主革命 | 因共产党的领导而判断为社会主义革命 |

### 2. “旧民主主义”变为“新民主主义”：时代与起点

- **俄国十月革命（1917）**&#x2060;改变世界革命时代背景：中国民主革命成为世界无产阶级社会主义革命的一部分。
- **五四运动（1919）**&#x2060;标志中国民主革命进入**新民主主义革命**阶段。
- **新与旧的根本分界**不是反帝反封建任务是否出现，而是**领导权掌握在无产阶级及其政党手中，还是资产阶级手中**。指导思想和革命前途也随之发生改变。

**肖1000多选1**把新民主主义革命新的内容概括为：处于新的时代、无产阶级及中国共产党领导、马克思列宁主义指导、前途是社会主义。全选四个变化仍要抓住**根本标志是领导阶级改变**。

### 3. 理论从实践中来：两次胜利、两次失败与规律认识

理论不是一开始就完整掌握的：中国共产党领导民主革命，通过正反经验比较，逐步认识中国革命的规律。

| 革命实践 | 在总结中形成的理论 |
| --- | --- |
| 两次国共合作及其经验教训 | 统一战线理论 |
| 创建、巩固农村革命根据地 | 农村包围城市、武装夺取政权的道路理论 |
| 长期革命战争 | 人民军队建设、革命战争和战略战术理论 |
| 党的组织由弱到强、与非无产阶级思想作斗争 | 党的建设理论 |

**2024年多选第22题：BCD。**&#x2060;题干“两次胜利、两次失败”“才认识必然王国”，考的是**革命实践推动对客观规律的认识**：马克思主义同中国具体实际相结合，认识经历探索过程，新民主主义理论凝结正反经验。A“党已完全掌握……规律”表述绝对化，应排除。

<Callout type="info" title="题型迁移：认识论与革命史结合">
如果题干讲“实践—失败—总结—再实践—形成路线”，既可从马原“实践是认识的基础、认识在实践中深化”理解，也可从毛中特“马克思主义与中国实际相结合”理解。不要把“认识必然王国”误读为**一劳永逸地掌握了全部规律**。
</Callout>

## 考点6 新民主主义革命的总路线

### 1. 总路线两次重要表述

**1939年**，《中国革命和中国共产党》提出新民主主义革命总路线的基本思想；**1948年**，《在晋绥干部会议上的讲话》作出**完整概括**：

> **无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命。**

“1948年完整”尤其因为革命对象中明确加上**官僚资本主义**。与“1939年提出”“1940年系统阐明”不是相互排斥，而是不同层次的理论发展。

**理科2000年单选第10题：C**，直接考“完整提出总路线”的著作；肖1000单选3也考**新增官僚资本主义**这一精细变化。

### 2. 革命对象：三座大山与同盟者的界限

| 革命对象 | 为什么是对象 | 选择题陷阱 |
| --- | --- | --- |
| **帝国主义** | 民族压迫的重要根源，近代中国革命的首要对象 | 中国革命不只是反国内封建压迫 |
| **封建主义** | 封建土地所有制和军阀专制阻碍社会生产力及民主进步 | 反封建主要涉及地主阶级及封建制度，不是反一切传统文化 |
| **官僚资本主义** | 与帝国主义、封建势力和反动国家政权结合的买办性、封建性国家垄断资本主义，严重阻碍社会发展 | **不等于反对一切资本主义**；民族资本主义工商业反而应予保护 |

革命对象随形势变化而有阶段性突出对象：大革命时期反对帝国主义支持下的北洋军阀；土地革命时期反对国民党新军阀；全民族抗战时期主要反日本帝国主义；解放战争时期主要反对美帝国主义支持下的国民党反动派。阶段性对象变化**不等于总路线被推翻**。

### 3. 革命动力、主力军、领导力量、核心问题

| 名词 | 对应群体与意义 | 易混辨析 |
| --- | --- | --- |
| **最基本的动力、领导阶级** | **工人阶级** | 工人阶级不是中国当时人口最多的群体 |
| **主力军** | **农民阶级** | 农民是主力军，不等于农民是革命的领导阶级 |
| **重要革命动力** | 城市小资产阶级、民族资产阶级 | 民族资产阶级有两面性，需依据实践实行既联合又斗争 |
| **中国革命的中心问题、新民主主义革命理论核心问题** | **无产阶级领导权** | 不可替换为“农民问题” |
| **中国革命的基本问题** | **农民问题** | 农民问题是基本问题，不等于领导权的核心命题 |
| **新民主主义革命的实质** | **中国共产党领导下的农民革命** | 并不否定工人阶级领导地位 |

**实现无产阶级领导权的具体条件与支柱：**

1. 领导同盟者向共同敌人斗争并取得胜利；给予同盟者实际物质利益，至少不损害其利益，并进行政治教育——**基本条件**。
2. 建立以工农联盟为基础的广泛统一战线——实现领导权的**关键**。
3. 在统一战线中保持思想、政治、组织独立性，坚持对资产阶级又联合又斗争——**基本策略**。
4. 依靠一支无产阶级领导、以农民为主体的强大革命武装——**坚强支柱**。
5. 加强无产阶级政党自身建设——**根本保证**。

**肖1000单选4、5、9，多选2、8**反复从“根本标志”“中心问题”“领导权基本条件”“农民主力军”设置陷阱。记忆时先把**人群角色与革命论断**分别列出，再理解它们怎样相互支持。

### 4. 新、旧民主主义革命与社会主义革命：三类比较

| 比较角度 | 旧民主主义革命 | 新民主主义革命 | 社会主义革命 |
| --- | --- | --- | --- |
| **革命性质** | 资产阶级民主革命 | **资产阶级民主革命**（新式、特殊的） | 无产阶级社会主义革命 |
| **领导力量** | 资产阶级 | **无产阶级及其政党** | 无产阶级及其政党 |
| **指导思想** | 资产阶级民主主义等思想 | **马克思列宁主义** | 马克思列宁主义 |
| **主要任务** | 反帝反封建等民主革命任务 | **反帝、反封建、反官僚资本主义** | 改变生产资料私有制等社会主义革命任务 |
| **发展前途** | 资本主义 | **社会主义** | 建立社会主义制度 |

**两步走的辩证关系**：

- **第一步**是民主主义革命，**第二步**是社会主义革命。
- 民主主义革命是社会主义革命的**必要准备**，社会主义革命是民主主义革命的**必然趋势**。
- 两个阶段**性质不同**，不能“毕其功于一役”；但又**紧密联系**，不能人为插入一个必须经过的独立资本主义统治阶段。
- 两个阶段能够**有机连接**，原因是中国民主革命受**无产阶级领导**，其中含有决定性的**社会主义因素**。

**2012年单选第10题：C。**&#x2060;问两个革命阶段**为什么能有机连接**，是因为**民主主义革命中包含社会主义因素**；“国情决定要分两步”回答的是为什么有阶段性，**没有回答为什么紧密衔接**。

**2004年多选第20题：DE。**&#x2060;D“必要准备”和E“必然趋势”并列成立。A“一次完成”、B“任务相同”、C“中间必须有独立资本主义过渡阶段”均错误。

#### “左”和右：一道题两种极端

| 错误倾向 | 代表表达 | 错在何处 |
| --- | --- | --- |
| **“左”倾一次革命论、“毕其功于一役”** | 不分阶段，反帝反封建同时立即反对民族资产阶级 | **混淆了新民主主义与社会主义革命的区别** |
| **右倾“二次革命论”** | 民主革命由资产阶级领导，社会革命留待将来，两个阶段割裂 | **割裂了两个革命阶段的联系，放弃无产阶级领导权** |

<Callout type="warn" title="常考四个“不是”">
**不是**因为领导者是无产阶级，新民主主义革命的性质就成为社会主义革命；**不是**所有民族资产阶级都属于必须打倒的三大对象；**不是**“两步走”意味着中间必须长期实行独立的资产阶级专政；**不是**“两个阶段衔接”允许取消民主革命的历史任务。
</Callout>

## 考点7 新民主主义的基本纲领

这一考点在本资料的分类真题中**没有单独列题**，但在肖1000题精简版单选11—14、多选4—7中有较密集覆盖，应作为**多选题拿分点**学习。

### 1. 政治纲领：革命胜利后建什么国家

推翻帝国主义、封建主义的统治，建立**无产阶级领导、以工农联盟为基础、各革命阶级联合专政**的新民主主义共和国。

- **国体**：各革命阶级联合专政。
- **政体**：民主集中制的人民代表大会制度。
- **价值原则**：人民当家作主。
- **历史定位**：新民主主义共和国是特定历史时期的、**过渡性质**的国家形式。

切忌把它写成由资产阶级单独专政、工农两阶级单独专政，或者认为已与社会主义国家政权的一切具体特征完全相同。

### 2. 经济纲领：三个“没收/保护”要区别对象和性质

| 基本条款 | 对象与政策 | 理由 / 性质 |
| --- | --- | --- |
| **没收封建地主阶级的土地归农民所有** | 废除封建剥削土地关系 | **新民主主义革命的主要内容**；土地改革直接满足贫雇农要求 |
| **没收官僚资产阶级的垄断资本归新民主主义国家所有** | 官僚资本主义 | 具有**新民主主义革命与社会主义革命双重性质** |
| **保护民族工商业** | 合法民族资本主义工商业 | **经济纲领极具特色的一项**；有利于社会生产力发展 |

三个容易设陷阱的表述：

1. “没收**一切**资本主义经济”——**错**；新民主主义革命保护民族工商业，反对的是官僚资本主义。
2. “官僚资本之所以被没收，仅因为它属于资本主义”——**错**；重点是它的买办性、封建性、垄断性及与反动政权结合的性质。
3. “保护民族工商业意味着民族资本主义占国民经济主导地位”——**错**；保护政策基于其当时的积极生产力作用，不等于承认其占主导地位。

**肖1000单选11—13；多选5—7**主要围绕经济纲领“完整三项”“官僚资本性质”“为什么保护民族资本”设问，记忆应抓**保护、没收的分界线**。

### 3. 文化纲领：民族的、科学的、大众的

新民主主义文化是**无产阶级领导的、人民大众的反帝反封建文化**，即民族的科学的大众的文化。

| 关键词 | 含义 | 易错选项 |
| --- | --- | --- |
| **民族的** | 内容上反对帝国主义压迫，主张民族独立尊严；形式上具有中国特色、中国作风与民族形式 | “民族的”不等于排斥吸收外国先进文化 |
| **科学的** | 反对封建迷信，主张实事求是、客观真理、理论与实践相统一 | 不是只涉及自然科学知识的“专业文化” |
| **大众的** | 为广大人民群众服务，体现文化的民主性与普及性 | 不是少数精英特权或脱离大众的文化 |

**肖1000单选14**是很典型的定位题：“民族的”若问**内容**，落在反帝压迫、民族独立尊严；若问**形式**，落在民族风格、中国气派。注意区分题干限定词。

## 考点8 新民主主义革命道路：农村包围城市、武装夺取政权

### 1. 必须走这条路：由什么决定？

**国情决定主要斗争形式与主要力量**：

- 近代中国**内无民主制度、外无民族独立**，敌人掌握强大国家暴力机器，决定革命的**主要斗争形式是武装斗争**，主要组织形式是军队。
- 中国是人口以农民为多数的农业大国；**农民是主力军**，革命必须深入农村，发动农民，通过土地革命获取广泛社会支持。
- 大城市往往被反动力量长期控制，照搬俄国十月革命“首先中心城市胜利”的具体路径，不符合当时中国情况。

**2010年多选第27题：ABCD。**&#x2060;正确选项从中国的政治条件、农民主力军、敌我力量空间分布、革命发展现实等不同角度说明道路依据；属于**多项条件共同成立**的题，而不是某一单因论。

### 2. 能够走这条路：红色政权长期存在的条件

| 层次 | 具体因素 | 应背的限定 |
| --- | --- | --- |
| **根本原因** | 半殖民地半封建的中国政治、经济、文化发展**极端不平衡**，多个帝国主义间接统治、军阀割据形成薄弱地区 | “根本原因”专指这一国情结构 |
| **群众基础** | 大革命洗礼后，部分农村革命基础较好 | 基础有利，但不是根本原因 |
| **客观发展条件** | 全国革命形势继续发展 | 有利于根据地坚持与扩大 |
| **力量保证** | **相当力量正式红军**的存在 | 不等于只靠自发农民起义 |
| **主观条件** | **党的有力量的领导和正确政策** | 关键主观条件，不能替换为根本的国情因素 |

**2011年单选第5题：A。**&#x2060;直接问农村革命根据地长期存在和发展的**根本原因**，只能选**中国政治、经济、文化发展极不平衡的半殖民地半封建大国**。B群众基础、C红军力量、D党的正确领导虽是有利或必要条件，不能顶替“根本原因”。

### 3. “工农武装割据”三者关系

| 要素 | 地位 | 为什么不能缺少 |
| --- | --- | --- |
| **土地革命** | **基本内容** | 解决农民土地问题，动员革命主力军 |
| **武装斗争** | **主要形式、强有力的保证** | 保卫土地革命成果与根据地 |
| **农村革命根据地建设** | **战略阵地、依托** | 为开展土地革命与长期武装斗争提供稳定空间 |

三者相互依赖：**没有土地革命，革命缺乏广泛的群众基础；没有武装斗争，难以保卫革命成果；没有根据地，长期斗争缺乏战略依托。**

### 4. 道路探索的重大意义

中国共产党没有照抄俄国经验，而是探索出从农村到城市夺取全国胜利的道路，这既符合中国革命实际，也独创性地发展了马克思列宁主义，体现了马克思主义中国化时代化的方法论意义。

**2018年单选第11题：A。**&#x2060;题目考武装斗争的**实质**：**工人阶级领导的农民战争**。“工人阶级领导”回答领导权，“农民战争”回答参战主体、社会基础和革命的现实形态。D虽也含“无产阶级领导”，但“反帝国主义战争”不能完整概括题目所问的实质。

<Callout type="warn" title="三连问必须分开">
**为什么必须走？**——内无民主外无独立、农民占绝大多数。**为什么能够走？**——政治经济发展不平衡等五项条件。**怎样走？**——正确处理土地革命、武装斗争、根据地建设三者关系。这三种问法不可以用一套固定答案硬套。
</Callout>

## 考点9 新民主主义革命的基本经验

> **三大法宝**：**统一战线、武装斗争、党的建设**。不是与“活的灵魂”同一套概念。

### 1. 统一战线：必要性、可能性、两个联盟、四个策略

**为什么必要**：近代社会阶级结构复杂，呈“两头小中间大”；革命具有长期性、残酷性和不平衡性，需要联合可能联合的力量。

**为什么可能**：半殖民地半封建社会多重矛盾交织，社会阶级之间既有矛盾也有反对共同敌人的合作空间。

**两个联盟：**

| 联盟 | 构成 | 地位 |
| --- | --- | --- |
| **劳动人民联盟** | 工人阶级与农民阶级、广大知识分子及其他劳动者，**以工农联盟为主体** | **基本的、主要的联盟，是统一战线的基础** |
| **工人与非劳动人民的联盟** | 主要是与**民族资产阶级**的联盟，也包括一定条件下与其他可以合作的非劳动群体 | **非基本、辅助性但不可缺少的重要联盟** |

**2006年单选第9题：B。**&#x2060;问**基本的、主要的联盟**：必须选**以工农联盟为主体的劳动人民联盟**，不能把民族资产阶级混进这个基本联盟；民族资产阶级主要在第二个联盟中。

**四个策略**：以工农联盟为基础；对资产阶级实行又联合又斗争；发展进步势力、争取中间势力、孤立顽固势力；在统一战线中坚持独立自主、保持思想政治组织的独立性。

**“两头小中间大”**：

- **两头**：无产阶级与地主大资产阶级。
- **中间**：农民阶级、城市小资产阶级、民族资产阶级等。
- **2005年多选第21题：AC。**&#x2060;考的正是“两头”对应**无产阶级和地主大资产阶级**，不是把农民算入“两头”。

### 2. 统一战线的四个历史阶段

| 时期 | 统一战线形式 | 重点认识 |
| --- | --- | --- |
| **1924—1927** | 国民革命联合战线（第一次国共合作） | 反帝反军阀的国民革命 |
| **1927—1937** | 工农民主统一战线 | 土地革命战争时期 |
| **1937—1945** | 抗日民族统一战线（第二次国共合作） | 抗日民族矛盾突出 |
| **解放战争时期** | 人民民主统一战线 | 反对国民党反动派，争取革命胜利 |

**肖1000多选13**：“以国共合作为基础”成立的是**国民革命联合战线、抗日民族统一战线**，并非工农民主统一战线或人民民主统一战线。选项并列时，优先抓“**国共合作**”的特殊条件。

### 3. 武装斗争：军队建设四项原则

1. **党对军队绝对领导**——人民军队建设的根本原则，也是毛泽东建军思想核心。
2. **全心全意为人民服务**——人民军队唯一宗旨；军队应与人民血肉相连。
3. **革命的政治工作**——官兵一致、军民一致、瓦解敌军和优待俘虏。
4. **正确的战略战术原则**——适应具体革命条件运用军事策略。

**肖1000多选14、15**：前三项政治工作基本原则是“官兵一致、军民一致、瓦解敌军和优待俘虏”；“支部建在连上”重要，但并非题目限定的**三项政治工作基本原则**。

### 4. 党的建设：思想建设优先与三大优良作风

在新民主主义革命时期，党内存在不少农民和小资产阶级出身的党员，因而必须用无产阶级思想克服各种非无产阶级思想，把**党的思想建设**始终放在首位。

- **组织建设**：贯彻民主集中制，建设有力量的党组织。
- **作风建设**：形成**理论联系实际、密切联系群众、批评与自我批评**相结合的三大优良作风。
- **政治路线**：围绕正确的政治路线加强党的建设。

**2014年单选第12题：D。**“房子经常打扫、脸经常洗，思想工作也会沾染灰尘”考的是**批评与自我批评**；不要仅因“党的思想工作”字样误选思想建设以外的作风，也不要把它混为“密切联系群众”。

**注意两个历史场景的用语差别**：本章讨论革命时期**思想建设放在首位**；新时代全面从严治党强调**党的政治建设摆在首位**。不能跨教材章节机械套用。

### 5. 三大法宝之间的内在关系

- **统一战线与武装斗争**是战胜敌人的基本武器；统一战线必须以武装斗争为支柱，武装斗争须在统一战线中形成广泛支持。
- **党的组织和领导**是掌握统一战线和武装斗争的关键；党的建设保证党正确领导和正确运用前两者。
- **理论联系实际、密切联系群众、批评和自我批评**是党在长期革命斗争中形成的优良作风，不能用来替代“三大法宝”的正式内容。

## 考点10 新民主主义革命理论的意义

本资料分类真题没有为考点10单列题目，按**基础性知识**掌握，不宜与考点6、8、9投入相同的反复练习量。

**理论意义**：科学回答在以农民为主体、经济文化落后的半殖民地半封建东方大国如何进行革命的问题，正确解决革命的性质、道路、阶段、领导力量和前途等理论难题，丰富发展了马克思主义，推进马克思主义中国化时代化。

**实践意义**：指引中国共产党领导人民取得新民主主义革命胜利，建立中华人民共和国，改变中国人民和中华民族历史命运，并对世界政治格局产生深刻影响。

### 必考“第一”与代表性文献对照

| 事件 / 论断 | 正确对应 |
| --- | --- |
| 第一次系统提出三大法宝并阐述党建伟大工程 | 1939年《〈共产党人〉发刊词》 |
| 提出新民主主义革命概念、相关总路线基本思想 | 1939年《中国革命和中国共产党》 |
| 系统阐明新民主主义理论 | 1940年《新民主主义论》 |
| 对新民主主义革命总路线作**完整概括** | 1948年《在晋绥干部会议上的讲话》 |
| 明确“党工作重心由乡村转移到城市”，强调执政后建设 | 1949年党的七届二中全会 |
| 科学归纳毛泽东思想活的灵魂 | 1981年《关于建国以来党的若干历史问题的决议》 |

> 必须看清“**提出**”“**系统阐明**”“**完整概括**”三个动词，否则极容易把1939、1940、1948三种正确对应关系误判为互相矛盾。

### 六道无需选项的自测题

1. **为什么中国新民主主义革命仍属于资产阶级民主革命？**——主要是反帝反封建等民主革命任务；新旧之别取决于无产阶级领导权、指导思想及革命前途，不能将其性质改写为社会主义革命。
2. **中国革命中心问题、基本问题、主要内容、实质分别是什么？**——无产阶级领导权；农民问题；没收地主土地归农民；党领导下的农民革命。
3. **没收地主土地、没收官僚资本、保护民族工商业分别针对谁？**——封建地主；官僚资产阶级；民族资本主义工商业。
4. **为什么农村根据地能够长期存在，哪个条件是根本原因？**——多因素共同作用；根本原因是近代中国政治经济文化发展极端不平衡。
5. **三大法宝、三大活的灵魂、三大作风分别是什么？**——统一战线/武装斗争/党的建设；实事求是/群众路线/独立自主；理论联系实际/密切联系群众/批评和自我批评。
6. **革命两步走为什么既要区别又要衔接？**——性质任务不同，不能“毕其功于一役”；民主革命受无产阶级领导、包含社会主义因素，故两阶段有机联系。
