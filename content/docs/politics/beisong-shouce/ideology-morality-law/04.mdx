# 第四章 明确价值要求 践行价值准则

## 专题六｜社会主义核心价值观

<Callout type="info" title="专题主线与速记">

**普通价值观**体现主体对客体价值的立场、态度；**核心价值观**在社会思想观念体系中处于主导地位。社会主义核心价值观的**24字**分为国家、社会、公民三个层面；显著特征是**先进性、人民性、真实性**，其中**人民性是根本特性**。

</Callout>

### 一、价值观与核心价值观：两个概念

#### 1. 价值观是什么？

**价值观**是主体对客体**有无价值、价值大小**所持的立场和态度，是对价值及其相关内容的基本观点和看法。

**基本作用**：对人的具体行为起着**规范和导向作用**。

- 价值观回答“**什么重要、什么值得追求**”。
- 价值评价侧重某个具体对象是否有价值；价值观通常是较为稳定、具有方向性的基本看法。
- 价值观会影响人们选择目标、判断利益和作出行动。

#### 2. 核心价值观是什么？

**核心价值观**是一定**社会形态和社会性质的集中体现**，在一个社会的思想观念体系中**处于主导地位**，体现着社会制度的**阶级属性、社会运行的基本原则、社会发展的基本方向**。

| 维度 | 普通意义上的价值观 | 核心价值观 |
| --- | --- | --- |
| **基本含义** | 主体关于价值的立场、态度和基本看法 | 社会思想观念体系中居于**主导地位**的价值取向 |
| **侧重点** | 对个人或群体行为的规范、导向 | 对社会制度、社会秩序和共同追求的深层规定 |
| **考研关键词** | 有无价值、价值大小、行为导向 | **社会性质、主导地位、价值标准、重要稳定器** |

#### 3. 核心价值观为什么重要？

核心价值观承载一个**民族、国家的精神追求**，体现一个社会评判**是非曲直的价值标准**，是国家的**重要稳定器**。能否形成具有强大感召力的核心价值观，关系社会和谐稳定、国家长治久安。

> 对一个民族、一个国家来说，**最持久、最深层的力量**是**全社会共同认可的核心价值观**。

<Callout type="warn" title="高频定位词">

“最持久、最深层的力量”对应**全社会共同认可的核心价值观**，不是某个群体的短期偏好，也不是外部物质刺激。

</Callout>

### 二、社会主义核心价值观的基本内容：三个层面、24个字

<Tabs items={['国家层面', '社会层面', '公民层面']}>
  <Tab value="国家层面">

**富强、民主、文明、和谐**。

**回答：我们要建设什么样的国家？**

**作用：**&#x2060;揭示当代中国经济社会发展的**价值目标**。

| 核心词 | 教材强调的定位 |
| --- | --- |
| **富强** | 促进社会进步、人的自由全面发展的**物质基础** |
| **民主** | **社会主义民主**，核心是**人民当家作主** |
| **文明** | 社会进步的**重要标志**，也是社会主义现代化国家的重要特征 |
| **和谐** | 中华文明的**核心价值理念** |

</Tab>
  <Tab value="社会层面">

**自由、平等、公正、法治**。

**回答：我们要建设什么样的社会？**

**作用：**&#x2060;揭示社会主义社会发展的**价值取向**。

| 核心词 | 教材强调的定位 |
| --- | --- |
| **自由** | **社会活力之源**，社会主义的价值理想 |
| **平等** | **人类追求的美好状态** |
| **公正** | **人类社会进步的标尺**，社会主义制度的本质要求 |
| **法治** | **人类政治文明的重要成果**，现代社会的主要特征 |

</Tab>
  <Tab value="公民层面">

**爱国、敬业、诚信、友善**。

**回答：我们要培育什么样的公民？**

**作用：**&#x2060;每个公民应当遵循的**价值规范**。

| 核心词 | 教材强调的定位 |
| --- | --- |
| **爱国** | 最深沉、最持久的情感；公民应遵循的**最基本价值准则**；中华民族优良传统 |
| **敬业** | 对待生产劳动和人类生存的**根本价值态度** |
| **诚信** | **个人立身处世的基本价值规范**；**社会存续发展的重要价值基石** |
| **友善** | 维系良好**人际关系和社会关系**的基本价值准则 |

</Tab>
</Tabs>

#### 三个层面怎样构成统一整体？

| 层面 | 24字中的四项要求 | 提问方式 | 主要定位 |
| --- | --- | --- | --- |
| **国家** | **富强、民主、文明、和谐** | 建设什么样的**国家** | **价值目标** |
| **社会** | **自由、平等、公正、法治** | 建设什么样的**社会** | **价值取向** |
| **公民** | **爱国、敬业、诚信、友善** | 培育什么样的**公民** | **价值规范** |

这些要求不是割裂的三套口号，而是把涉及**国家、社会、公民**的价值要求融为一体：

1. **体现社会主义本质要求**。
2. **继承中华优秀传统文化**。
3. **吸收世界文明有益成果**。
4. **体现时代精神**。

<Callout type="tip" title="判断材料的快速方法">

“现代化国家的发展目标、人民当家作主”侧重**国家层面**；“公共制度与社会秩序中的权利平等、规则公正”侧重**社会层面**；“诚信经营、敬业履职、友善待人”侧重**公民层面**。同一材料也可能体现多个层面，需抓住题干所问的**主要对象**。

</Callout>

### 三、社会主义核心价值观的重要性

**总体定位：**&#x2060;社会主义核心价值观是**当代中国精神的集中体现**，是中国特色社会主义**道路、理论、制度、文化的价值表达**，凝结着全体人民共同的价值追求，是**当代中国发展进步的精神指引**。

#### 1. 当代中国发展进步的精神指引：三个方面

| 方面 | 核心表述 |
| --- | --- |
| **坚持和发展中国特色社会主义的价值遵循** | 为中国特色社会主义事业提供价值方向 |
| **提高国家文化软实力的迫切要求** | 构成文化认同与价值感召的重要内容 |
| **推进社会团结奋进的“最大公约数”** | 在多样利益与观念中凝聚共同价值追求 |

#### 2. 为什么要培育和践行？

- **整合社会意识与形成共识**：有助于凝聚社会价值共识、防范和化解社会矛盾，汇聚共同奋斗力量。
- **提供价值支撑**：有助于保证经济社会发展沿着正确方向前进，为实现中华民族伟大复兴提供价值支持。

**区别记忆：**“重要性”主要回答**为什么重要、具有何种地位**；“培育践行的重要性”主要回答**落实以后怎样作用于社会实践**。

### 四、社会主义核心价值观的三大显著特征

教材将**先进性、人民性、真实性**概括为社会主义核心价值观的显著特征，也是坚定核心价值观自信的重要依据。

#### 1. 先进性：反映人类社会发展进步的价值理念

- **体现社会主义的本质属性**。其先进性**集中体现**在它是社会主义所坚持和追求的价值理念。
- **扎根中华优秀传统文化土壤**。中华优秀传统文化是涵养社会主义核心价值观的**重要源泉**，体现其历史底蕴。
- **吸纳世界文明有益成果**。强调交流互鉴，而非封闭地看待自身文化。

#### 2. 人民性：彰显人民至上的价值立场

- **人民至上**是鲜明的价值立场。
- **人民性**是社会主义核心价值观的**根本特性**。

#### 3. 真实性：因真实可信而具有道义力量

- 教材强调，**真实性**是社会主义核心价值观与以往价值观的一个**重要区别**。
- 中国特色社会主义实践及其发展成效，被用来说明这一价值观的**正确性、可信性**，并推动价值追求化为具体的社会生活实践。

| 特征 | 考查定位词 | 关键判断依据 |
| --- | --- | --- |
| **先进性** | 社会主义价值理念；中华优秀传统文化；人类文明成果 | **集中体现**在社会主义所坚持和追求的价值理念 |
| **人民性** | 人民至上 | **根本特性** |
| **真实性** | 真实可信、现实实践 | 区别于以往价值观的**重要特点** |

<Callout type="info" title="教材术语辨析：‘普世价值’与‘全人类共同价值’">

原资料在这一专题专门区分两个**特定政治理论语境中的术语**：它将“普世价值”作为一种带有特定政治倾向的**资本主义价值观话语**加以批判，同时强调不能将这种话语与我国倡导的**全人类共同价值**直接画等号。

**应试边界**：这里是教材对相关**政治话语及其意识形态含义**的阐述。解题时应结合其特定语境，不宜把“不同国家都可能赞同某些基本价值”与教材批评的特定政治话语混为一谈。

</Callout>

### 六、命题辨析与自测

<Accordions>
  <Accordion title="误区一｜‘民主、公正、诚信、爱国’都属于同一个层面">

错误。**民主**是国家层面，**公正**是社会层面，**诚信、爱国**是公民层面。必须按原有的**4×3结构**分别记忆。

</Accordion>
  <Accordion title="误区二｜社会主义核心价值观的根本特性是先进性">

错误。其显著特征包括先进性、人民性、真实性，其中**人民性是根本特性**。先进性集中体现于社会主义坚持和追求的价值理念。

</Accordion>
  <Accordion title="误区三｜社会层面的法治与公民层面的诚信可以互相替代">

不可以。**法治**是社会层面的价值取向，**诚信**是公民层面的价值规范；虽然二者在社会治理中相关，但**定位不同**。

</Accordion>
  <Accordion title="自测｜社会主义核心价值观的三个层面分别回答什么问题？">

国家层面：“我们要建设什么样的**国家**？”——**价值目标**。

社会层面：“我们要建设什么样的**社会**？”——**价值取向**。

公民层面：“我们要培育什么样的**公民**？”——**价值规范**。

</Accordion>
</Accordions>

**考前一句话复述：**&#x2060;核心价值观是国家重要稳定器；国家富民文和、社会自平公法、公民爱敬诚友；社会主义核心价值观体现当代中国精神，具有**先进性、人民性、真实性**，**人民性最根本**。
