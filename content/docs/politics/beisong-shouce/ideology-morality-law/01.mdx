# 第一章 领悟人生真谛 把握人生方向

## 专题二｜人生观

<Callout type="info" title="一条主线串起人生观">

**个人与社会的关系问题**，是认识和处理人生问题的重要着眼点和出发点；其中最根本的是**个人利益与社会利益的关系**。人生观包括**人生目的、人生态度、人生价值**三个方面，**人生目的是人生观的核心**。人生价值既有**自我价值**，又有**社会价值**；实现人生价值的必由之路是**社会实践**。

</Callout>

### 一、个人与社会的辩证关系

#### 1. 对立统一：相互依存、制约、促进

- **个人离不开社会**：社会为个人生存与发展提供物质条件、制度条件及交往环境。
- **社会发展依赖个人的实践活动**：社会不是同现实个人无关的抽象实体，个人的劳动与创造构成社会运行发展的现实内容。
- **关系具有辩证性**：个人与社会存在利益一致的一面，也可能出现局部、暂时的利益差异，需要正确处理。

#### 2. 根本层次：个人利益与社会利益

| 概念 | 准确理解 | 防止误读 |
| --- | --- | --- |
| **个人利益** | 现实个人在生活发展中合理的利益和需要 | 不是天然与社会利益相对立 |
| **社会利益** | 全体社会成员利益的**有机统一**，体现其根本利益和长远利益 | **不是**个人利益的简单加总 |
| **二者关系** | 社会利益为个人利益实现提供**前提和基础**，同时保障个人利益；个人通过参与社会实践实现自身发展 | 不是取消个人的合理利益 |

<Callout type="tip" title="为什么‘社会利益不是个人利益简单相加’？">

社会利益不仅涉及个别人的即时需要，还包含公共设施、社会秩序、生态环境等由众多成员共同维系的条件。因此需要从**整体、长远、相互联系**的角度认识，而非做简单的数量相加。

</Callout>

#### 3. 社会性与个人发展

**人的社会性**决定了个人的发展与社会的发展紧密关联。按照本专题的价值立场，个人应当在**推动社会进步的实践**中实现自我发展。

### 二、人生观的三个基本方面

人生观是人们关于**人生目的、人生态度、人生价值**等问题的总看法和根本观点。

<Tabs items={['人生目的', '人生态度', '人生价值']}>
  <Tab value="人生目的">

**回答：人为什么活着？**

人生目的是人生观的**核心**，起着方向性作用，决定**人生道路、人生态度和人生价值选择**。

**关键词：**&#x2060;目标、方向、追求什么、为何而活。

</Tab>
  <Tab value="人生态度">

**回答：人应当怎样活着？**

人生态度是人在实际生活中对待人生问题的**心理倾向和行为取向**，体现以怎样的态度实现人生目标。

**关键词：**&#x2060;面对困难的态度、认真务实、积极乐观。

</Tab>
  <Tab value="人生价值">

**回答：什么样的人生才有价值？**

人生价值是人的生命及其实践活动对**社会和个人**所具有的作用与意义，包含**自我价值和社会价值**。

**关键词：**&#x2060;贡献、意义、满足需要、自我发展。

</Tab>
</Tabs>

#### 三者如何相互作用？

| 关系方向 | 具体表述 |
| --- | --- |
| **人生目的 → 人生态度、人生价值** | 人生目的决定人对现实生活的态度及人生价值选择和评价方向 |
| **人生态度 → 人生目的、人生价值** | 人生态度影响能否坚持目标、能否实现价值 |
| **人生价值 → 人生目的、人生态度** | 价值判断又会影响目的的选择和生活态度 |

<Callout type="warn" title="注意‘核心’的准确指向">

题目问**人生观的核心**，应答**人生目的**；不能因为人生价值重要，就将它改写成人生观的核心。三者互相影响不意味着地位完全相同。

</Callout>

### 三、人生的自我价值与社会价值

#### 1. 两种价值的定义

| 维度 | **自我价值** | **社会价值** |
| --- | --- | --- |
| **价值指向** | 个体实践活动对**自身生存发展**的意义 | 个体实践活动对**社会、他人**的意义 |
| **主要表现** | 自身物质和精神需要的满足程度 | 对社会和他人的实际贡献 |
| **重要性** | 个体生存和发展的**必要条件** | 社会存在和发展的**重要条件** |
| **在相互关系中的作用** | 实现自我价值是个人为社会创造更大价值的**前提** | 实现社会价值是个人自我完善、全面发展的**保障** |

#### 2. 为什么要统一两种价值？

- 只谈自身满足而拒绝承担社会责任，难以把握人生的**社会意义**。
- 只谈外在贡献而否认个体合理的物质精神需要，也不能正确把握人的生存发展条件。
- **自我价值和社会价值相互联系、相互依存**，应在现实实践中促进二者统一。

**教材特别强调**：没有社会价值，人生的自我价值就无法存在。这一判断应联系人的**社会性**及个人发展必须依托社会的道理理解，而不是断言某个人一时没有作出突出贡献，就不具有任何作为人的尊严或应有权利。

#### 3. 判断材料的方法

- “学习、锻炼、健康成长，满足个人发展需要”强调**自我价值**。
- “用所学知识帮助他人、解决社会问题”强调**社会价值**。
- “在服务社会的过程中成长进步”体现**两者辩证统一**。

### 四、人生观与世界观、价值观

| 概念关系 | 正确结论 |
| --- | --- |
| **世界观 → 人生观** | **世界观决定人生观**，为人生问题提供根本认识前提 |
| **人生观 → 世界观** | 人生观对世界观的**巩固、发展和变化**起重要作用 |
| **价值观 → 人生观** | 价值观对人生观的形成与发展具有重要的**引导作用** |

**不要把“决定”随意换位**：世界观与人生观相联系，但教材的基本提法是**世界观决定人生观**。

### 五、正确的人生观及其要求

#### 1. 高尚的人生追求

**服务人民、奉献社会**。这一提法强调个人的人生追求与社会发展及他人需要相联系。

#### 2. 积极进取的人生态度

| 要求 | 具体理解 |
| --- | --- |
| **认真** | 认真对待生活、学习和承担的责任 |
| **务实** | 立足客观条件，求真务实，不空谈 |
| **乐观** | 以积极态度面对困难和挫折 |
| **进取** | 主动学习、奋斗，持续提高能力 |

#### 3. 人生价值评价：两个尺度要区分

<Tabs items={['根本尺度', '今天衡量人生价值的标准']}>
  <Tab value="根本尺度">

**看一个人的实践活动是否符合社会发展的客观规律、是否促进了历史进步。**

记忆词：**客观规律、历史进步**。

</Tab>
  <Tab value="今天衡量人生价值的标准">

最重要的是看一个人是否用自己的**劳动和聪明才智**为国家和社会真诚奉献，为人民群众尽心尽力服务。

记忆词：**劳动贡献、服务社会和人民**。

</Tab>
</Tabs>

#### 4. 人生价值评价的三种方法

1. **既看贡献大小，也看尽力程度**：评价应考虑实际条件、主观努力和成果。
2. **既尊重物质贡献，也尊重精神贡献**：不以金钱数量替代对各种社会贡献的判断。
3. **既注重社会贡献，也注重自身完善**：不把人的成长与服务社会割裂。

#### 5. 实现人生价值的条件与途径

<Steps>
  <Step>

**从社会客观条件出发。** 尊重实际的社会环境、发展阶段和可获得的实践资源。

</Step>
  <Step>

**从个体自身条件出发。** 认识兴趣、特长、基础、责任与局限，选择适合的方向。

</Step>
  <Step>

**增强能力和本领。** 通过知识积累、训练和反思提升创造价值的实际能力。

</Step>
  <Step>

**投身社会实践。** 社会实践是实现人生价值的**必由之路**。

</Step>
</Steps>

<Callout type="warn" title="错误人生观的辨析">

教材反对以一己私利作为出发点和落脚点的**拜金主义、享乐主义、极端个人主义**。注意：反对**拜金主义**不等于反对合理的物质生活需要；反对**极端个人主义**也不等于否定个人合法正当的利益。

</Callout>

### 六、常见干扰项与定位词

<Accordions>
  <Accordion title="错误：个人与社会关系的最根本问题是个人能力与社会资源的关系">

重要出发点是**个人与社会的关系**；这一关系最根本地表现为**个人利益与社会利益的关系**。

</Accordion>
  <Accordion title="错误：人生观的核心是人生态度或人生价值">

人生观的**核心是人生目的**，它决定人生道路、人生态度及人生价值选择。

</Accordion>
  <Accordion title="错误：自我价值和社会价值互不相关，必须二选一">

人生价值内在地包含**自我价值与社会价值**；二者相互联系，应当在实践中促进统一。

</Accordion>
  <Accordion title="错误：衡量人生价值只能看经济收入或物质贡献">

应把握**历史进步的根本尺度**，并全面运用**贡献与尽力、物质与精神、社会贡献与自身完善**三组评价方法。

</Accordion>
  <Accordion title="错误：只要有崇高目标，就无需考虑社会客观条件">

实现人生价值必须**从社会客观条件和自身条件出发**，提高能力，并投身现实实践。

</Accordion>
</Accordions>

### 七、考前速背

**着眼点**：个人与社会；**最根本**：个人利益与社会利益；**人生观三方面**：目的、态度、价值；**核心**：人生目的；**自我价值**是个体生存发展必要条件，**社会价值**是社会存在发展重要条件；**根本尺度**：符合规律、促进历史进步；**必由之路**：社会实践。
