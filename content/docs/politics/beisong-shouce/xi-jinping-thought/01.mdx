# 第一章 新时代坚持和发展中国特色社会主义

## 专题二｜中国特色社会主义

<Callout type="info" title="四层学习逻辑">

**从哪里来**：历史和人民的选择；**是什么**：坚持科学社会主义基本原则并具有鲜明中国特色；**怎样坚持**：坚定道路、理论、制度、文化**四个自信**；**进入新时代之后怎样推进**：把握新的历史方位、主要矛盾，一以贯之贯彻基本理论、基本路线、基本方略，统筹“五位一体”和“四个全面”。

</Callout>

### 一、中国特色社会主义：历史和人民的选择

#### 1. “怎么来的”：根本成就与历史基础

教材概括，**中国特色社会主义是党和人民历尽千辛万苦、付出巨大代价取得的根本成就**，具有深厚的历史渊源和广泛的现实基础。

在关于中国发展道路的理论表述中，坚持中国特色社会主义被视为**实现中华民族伟大复兴的必由之路**，也是“**五个必由之路**”的重要内容。

**理解三个层次**：

1. **历史选择**：中国近现代社会的探索、革命与建设过程提供历史条件。
2. **人民选择**：历史主体的实践为制度发展提供现实基础。
3. **现实道路**：在长期建设、改革与发展中形成并不断完善。

#### 2. “是什么”：社会主义而不是其他什么主义

中国特色社会主义**坚持科学社会主义基本原则**，又根据时代条件赋予其鲜明的中国特色，是**科学社会主义理论逻辑与中国社会发展历史逻辑的辩证统一**。

<Callout type="warn" title="四种机械照搬，都不符合教材阐述">

中国特色社会主义的历史实践，**不是**我国历史文化的简单复制，**不是**把马克思主义经典作家的设想机械变成现成模板，**不是**其他国家社会主义实践的再版，**也不是**国外现代化道路的翻版。

材料强调的不是否定学习和借鉴，而是**坚持科学社会主义原则、结合中国实际自主探索**。

</Callout>

### 二、“四个自信”：从改革开放以来的根本成就理解

#### 1. 根本原因：道路、理论、制度、文化四个维度

改革开放以来取得成绩和进步的重要根本原因，可以从四个“**开辟、形成、确立、发展**”概括：

| 历史成就 | 四位一体中的定位 | 为什么重要 |
| --- | --- | --- |
| **开辟中国特色社会主义道路** | **实现途径** | 回答走什么路 |
| **形成中国特色社会主义理论体系** | **行动指南** | 回答以什么理论指导实践 |
| **确立中国特色社会主义制度** | **根本保障** | 提供制度性保证 |
| **发展中国特色社会主义文化** | **精神力量** | 提供价值认同和精神支撑 |

**共同基础**：四者**统一于中国特色社会主义伟大实践**。既不能用某一项完全替代其他三项，也不能把四者看成相互孤立的要素。

<Tabs items={['道路自信', '理论自信', '制度自信', '文化自信']}>
  <Tab value="道路自信">

坚信中国特色社会主义道路是实现社会主义现代化、创造人民美好生活的重要**实现途径**。

</Tab>
  <Tab value="理论自信">

坚持中国特色社会主义理论体系的**行动指南**作用，在实践发展中推进理论创新。

</Tab>
  <Tab value="制度自信">

坚持中国特色社会主义制度提供的**根本保障**，并通过改革和治理实践加以完善。

</Tab>
  <Tab value="文化自信">

发挥中国特色社会主义文化的**精神力量**，重视中华优秀传统文化、革命文化和社会主义先进文化的相互联系。

</Tab>
</Tabs>

#### 2. “四个自信”从何而来？

**来源于实践、来源于人民、来源于真理。**

其理论支撑和根本依据，教材强调**社会主义必然代替资本主义的客观规律**。对这种自信的理解，应从历史实践、现实基础和客观规律三方面展开。

#### 3. 坚定“四个自信”的三方面基础和优势

<Steps>
  <Step>

**党的领导优势**：中国共产党的领导是中国特色社会主义**最本质的特征**、中国特色社会主义制度的**最大优势**。

</Step>
  <Step>

**发展积累的优势**：新中国成立以来特别是改革开放、党的十八大以来，逐步形成更完善的制度保证、更坚实的物质基础、更主动的精神力量。

</Step>
  <Step>

**文明文化优势**：绵延五千多年的中华文明为中国特色社会主义提供深厚的**文化根脉**与精神资源。

</Step>
</Steps>

#### 4. 为什么“说到底是坚定文化自信”？

**文化自信是更基础、更广泛、更深厚的自信**，是国家、民族发展中**最基本、最深沉、最持久**的力量。

中国特色社会主义文化的来源应分清三层：

- **源自**中华优秀传统文化。
- **熔铸于**党领导人民在革命、建设、改革中创造的**革命文化与社会主义先进文化**。
- **植根于**中国特色社会主义伟大实践。

<Callout type="tip" title="“四个自信”的易错对应">

**道路—实现途径，理论—行动指南，制度—根本保障，文化—精神力量。** 提问“最基本、最深沉、最持久的力量”，要抓**文化自信**；“制度最大优势”，要抓**党的领导**。

</Callout>

### 三、中国特色社会主义进入新时代

#### 1. 新时代是我国发展新的历史方位

**中国特色社会主义新时代**是我国发展的**新的历史方位**，意味着中国特色社会主义事业进入了新的发展阶段。

<Callout type="warn" title="“新发展阶段”不等于改变社会主义所处的基本历史阶段">

进入新时代，**没有改变**我国仍处于并将长期处于**社会主义初级阶段**的基本国情，也**没有改变**我国作为世界最大发展中国家的国际地位。

这里的“新的发展阶段”应放在中国特色社会主义事业发展中理解，**不是社会主义初级阶段已经结束**。

</Callout>

#### 2. 进入新时代的三个依据

1. **我国社会主要矛盾发生新变化**：这是作出新时代重大判断的**基本依据**。
2. **党的主要任务发生新变化**：强国建设和民族复兴事业提出新的历史任务。
3. **中国和世界关系发生新变化**：中国与国际社会的相互联系和影响进一步发展。

**时间辨析**：中国特色社会主义进入新时代，历史方位从**2012 年党的十八大**开始；**2017 年党的十九大**对进入新时代以及社会主要矛盾变化作出重要明确概括。不能把提出论断的大会年份机械等同于新时代开始之年。

### 四、新时代我国社会主要矛盾的变化

#### 1. 新时代的主要矛盾

> **人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。**

| 矛盾的一方 | 指向 | 判断依据 |
| --- | --- | --- |
| **人民日益增长的美好生活需要** | 人民需要的范围、内容、层次持续扩展 | 不再只局限于物质文化的数量增长 |
| **不平衡不充分的发展** | 发展中结构、区域、领域、质量等方面的问题 | 满足人民需要的**主要制约因素** |

**着力点**：在继续推动发展的基础上，**着力解决发展不平衡不充分的问题**。主要矛盾的变化是关系全局的历史性变化，但并没有取消社会主义初级阶段这一基本国情。

#### 2. 不同时期社会主要矛盾速查

| 历史时期 | 主要矛盾的教材概括 | 易混点 |
| --- | --- | --- |
| **1840—1949 年 9 月** | 帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾；前者是最主要矛盾 | 近代中国两大主要矛盾 |
| **1949 年 10 月—1952 年底** | 人民大众同帝国主义、封建主义和国民党反动派残余势力之间的矛盾 | 新中国成立初期 |
| **1953—1956 年** | 国内**工人阶级同资产阶级**的矛盾 | 社会主义改造时期 |
| **1956 年底以后、改革开放时期的长期表述** | 人民日益增长的**物质文化需要**同**落后的社会生产**之间的矛盾 | 在党的八大历史表述与后来的规范表述之间，要注意会议原话差异 |
| **新时代** | 人民日益增长的**美好生活需要**和**不平衡不充分的发展**之间的矛盾 | 党的十九大明确概括 |

**历史精确性提示**：上述表格沿用原资料的分期概括。党的八大关于主要矛盾的原始表述为人民对**经济文化迅速发展的需要**与当前**经济文化不能满足需要**的状况之间的矛盾，不能误认两种历史文本完全逐字相同。

### 五、新时代坚持和发展中国特色社会主义要一以贯之

#### 1. 贯彻党的基本理论、基本路线、基本方略

| 概念 | 定位 |
| --- | --- |
| **基本理论** | 坚持和发展中国特色社会主义的**行动指南** |
| **基本路线** | **国家的生命线、人民的幸福线** |
| **基本方略** | 党的十九大概括的**“十四个坚持”**，反映了相关规律性认识 |

#### 2. “五位一体”与“四个全面”

- **“五位一体”总体布局**：经济建设、政治建设、文化建设、社会建设、生态文明建设。
- **“四个全面”战略布局**：全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党。

| “四个全面”组成 | 角色 |
| --- | --- |
| **全面建设社会主义现代化国家** | **战略目标**，在战略布局中居于引领地位 |
| **全面深化改革** | 战略举措之一 |
| **全面依法治国** | 战略举措之一 |
| **全面从严治党** | 战略举措之一 |

**“一个战略目标 + 三大战略举措”**是本专题中“四个全面”最容易考的关系。不要把已完成的“全面建成小康社会”继续列为新时期这一战略布局的第一项。

### 六、命题分析与辨误

<Accordions>
  <Accordion title="错误：道路、理论、制度、文化四者的定位完全相同">

四者统一于实践，但定位不同：**实现途径、行动指南、根本保障、精神力量**。

</Accordion>
  <Accordion title="错误：进入新时代意味着我国不再处于社会主义初级阶段">

新时代是新的**发展历史方位**，没有改变我国社会主义初级阶段基本国情。

</Accordion>
  <Accordion title="错误：社会主要矛盾已经不再包含发展问题">

新时代的主要制约因素是**发展不平衡不充分**，仍需在推动发展的基础上着力解决这些问题。

</Accordion>
  <Accordion title="错误：‘四个全面’的四项都是战略举措">

**全面建设社会主义现代化国家**是战略目标；其余三项是战略举措。

</Accordion>
  <Accordion title="为什么坚定‘四个自信’说到底要坚定文化自信？">

文化自信被概括为**更基础、更广泛、更深厚的自信**，文化所提供的精神力量具有长期性；其根基来自优秀传统文化、革命文化和社会主义先进文化，并植根于伟大实践。

</Accordion>
</Accordions>

<Callout type="tip" title="一分钟速背">

**历史人民选择—科学社会主义中国化—四个自信（路理制文＝途径指南保障力量）—文化自信更基础—新时代从十八大开始，十九大明确概括—社会主要矛盾变化但初级阶段未变—基本理论路线方略—五位一体＋四个全面（一个目标、三项举措）。**

</Callout>
