# 第十七章 全面从严治党

## 专题二十｜全面从严治党

<Callout type="info" title="本专题主线：战略方针 → 建设布局 → 反腐败 → 自我革命">

按教材理论体系，**全面从严治党是新时代党的建设的鲜明主题和战略方针**。

- **四个定位**：**核心是加强党的领导，基础在全面，关键在严，要害在治**。
- **建设重点**：**党的政治建设是根本性建设**，政治建设摆在首位、统领其他建设；思想建设是基础性建设。
- **反腐败基本方针**：一体推进**不敢腐、不能腐、不想腐**。
- **跳出历史周期率的第二个答案**：**党的自我革命**。

</Callout>

### 一、全面从严治党为什么重要？

#### 1. 战略定位

原书归纳以下几个层次：

1. **全面建设社会主义现代化国家、全面推进中华民族伟大复兴，关键在党，关键在全面从严治党。**
2. **党要管党、从严治党**是党的建设的一贯要求和根本方针。
3. **全面从严治党**是党永葆生机活力、走好新的赶考之路的**必由之路**，也是新时代党的建设的**鲜明主题**。
4. 加强党的自身建设是推进伟大事业、进行伟大斗争、实现伟大梦想的要求，也是把党建设成为坚强有力的马克思主义执政党的重要条件。

#### 2. 把战略方针拆成四个关键词

| 关键词 | 教材定位 | 怎样理解 |
| --- | --- | --- |
| **核心** | **加强党的领导** | 把党的领导作为全面从严治党的根本政治指向 |
| **基础** | **全面** | 内容、对象、责任、制度等多个维度覆盖 |
| **关键** | **严** | 坚持严格要求、严格管理、严格监督 |
| **要害** | **治** | 落实管党治党责任、提高制度化规范化水平 |

<Callout type="warn" title="常考错配">

“**全面是核心**”“**严是要害**”“**党的领导是基础**”均把四组定位词错配。依次是：**核心—领导，基础—全面，关键—严，要害—治**。

</Callout>

#### 3. 全面从严治党体系的“四个全”

<Tabs items={['内容全涵盖','对象全覆盖','责任全链条','制度全贯通']}>
  <Tab value="内容全涵盖">

**内容上全涵盖**：党的各方面建设、各领域工作都贯彻全面从严要求，不局限于整治腐败。

</Tab>
  <Tab value="对象全覆盖">

**对象上全覆盖**：管党治党针对党组织和党员干部，不允许出现不受约束的例外。

</Tab>
  <Tab value="责任全链条">

**责任上全链条**：压实各层级、各环节的管党治党责任，不能只由某一部门或环节单独承担。

</Tab>
  <Tab value="制度全贯通">

**制度上全贯通**：以衔接配套的制度机制和党内法规提供持续性约束与保障。

</Tab>
</Tabs>

**对应关系**：**内容—涵盖，对象—覆盖，责任—链条，制度—贯通**，属于最适合做客观题的四组搭配。

### 二、以党的政治建设为统领推进党的各项建设

#### 1. 政治建设：根本性建设，摆在首位

**坚持以党的政治建设为统领**，是新时代党的建设的**根本要求**。政治建设摆在首位，被教材视为新时代党的建设理论的重大创新。

**为什么摆在首位？**

- **党的政治建设是党的根本性建设**。
- **旗帜鲜明讲政治**是马克思主义政党的根本要求。
- **政治建设决定党的建设方向和效果**。

**首要任务**：**保证全党服从中央，维护党中央权威和集中统一领导**。

<Callout type="tip" title="辨析三个“第一位”">

- **政治方向**是党生存发展的**第一位问题**。
- 在领导干部诸项能力中，**政治能力**居**第一位**。
- 新时代党的建设把**政治建设**摆在**首位**。

这些表述相互关联，但答题对象分别是**方向、能力、建设布局**。

</Callout>

#### 2. 思想建设：基础性建设

- **性质**：党的**基础性建设**。
- **重要经验**：坚持**思想建党、理论强党**。
- **根本任务**：**用党的创新理论凝心铸魂**。
- **党内政治生活的首要任务**：加强思想教育和理论武装。

思想建设侧重思想理论武装、理想信念和政治认同；政治建设强调政治方向、政治立场和维护集中统一领导。**“思想建设是基础性建设”不能替换为“思想建设是根本性建设”。**

#### 3. 组织建设：组织体系与干部队伍

| 层次 | 关键定位 |
| --- | --- |
| 贯彻新时代党的组织路线的**重点** | **严密党的组织体系** |
| 贯彻新时代党的组织路线的**关键** | **建设高素质专业化干部队伍** |

理解：组织体系提供运行结构，干部队伍承担落实任务；二者不能在“重点”和“关键”上互换。

#### 4. 作风建设与纪律建设

| 建设方面 | 对应定位 | 典型考题线索 |
| --- | --- | --- |
| **作风建设** | **作风问题核心是党同人民群众的关系问题** | 联系群众、形式主义、作风常态化长效化 |
| **纪律建设** | 加强纪律建设是全面从严治党的**治本之策** | 纪律规矩、严格约束、正风肃纪 |

坚持推进作风建设**常态化长效化**，是保持党同人民群众血肉联系的有效途径。

#### 5. 制度建设贯穿各项建设

- **制度治党、依规治党**是全面从严治党的**长远和根本之策**。
- **党内法规**是全面从严治党的重要**制度支撑**。
- **党内监督**是永葆党的肌体健康的**生命之源**；在教材表述中，它在党和国家各种监督形式中具有**根本性、第一位**的地位。

**注意区分**：

| 术语 | 不同定位 |
| --- | --- |
| **加强纪律建设** | 全面从严治党的**治本之策** |
| **坚持制度治党、依规治党** | 全面从严治党的**长远和根本之策** |
| **党内法规** | 重要**制度支撑** |
| **党内监督** | 永葆党的肌体健康的**生命之源** |

**两种“治本之策”并不冲突**：前者突出**纪律建设**，后者强调**制度治党、依规治党**的长期制度方法，不能把题干限定词省略后机械套用。

#### 6. 新时代党的建设总要求：抓住主线与统领

新时代党的建设总要求中，需要记住的层次为：

- **主线**：加强党的**长期执政能力建设、先进性和纯洁性建设**。
- **统领**：党的**政治建设**。
- **根基**：坚定**理想信念宗旨**。
- **着力点**：调动全党**积极性、主动性、创造性**。

### 三、坚定不移推进反腐败斗争

#### 1. 反腐败工作的基本定位

教材从党自身建设的角度强调：

1. **腐败**是危害党的生命力和战斗力的**最大毒瘤**，是长期执政面临的**最大威胁**。
2. **反腐败**是**最彻底的自我革命**，也是全面从严治党的&#x2060;**“必答题”**。
3. 新时代反腐败斗争的鲜明特征之一是**标本兼治**。
4. **制度制约和监督权力**是反腐倡廉的核心内容。

#### 2. 一体推进“三不腐”

<Steps>
  <Step>

**不敢腐：前提。** 强化惩治震慑，使腐败行为面临明确后果。

</Step>
  <Step>

**不能腐：关键。** 完善制度和权力监督制约，减少腐败滋生空间。

</Step>
  <Step>

**不想腐：根本。** 强化理想信念、思想教育和廉洁文化建设。

</Step>
</Steps>

**一体推进不敢腐、不能腐、不想腐**，既是全面从严治党的**重要方略**，也是反腐败斗争的**基本方针**。

<Callout type="warn" title="前提、关键、根本不要写反">

**不敢腐—前提，不能腐—关键，不想腐—根本。** “不能腐”强调制度约束，不是“不敢腐”的简单同义说法；“不想腐”侧重思想上的内在自觉。

</Callout>

### 四、党的自我革命：跳出历史周期率的第二个答案

#### 1. 从历史周期率问题切入

在教材理论框架中，**党的自我革命**被称为跳出历史周期率的**第二个答案**；**全面从严治党**是新时代党的自我革命的伟大实践。

**勇于自我革命**是中国共产党区别于其他政党的**显著标志**，被概括为其**最大的优势、最鲜明的品格**。

为什么强调自我革命？按原书，主要包括三个依据：

1. 党的宗旨和利益立场：**除了国家、民族、人民的利益，没有自身特殊利益**。
2. 坚持真理、修正错误：敢于**直面问题**，不讳疾忌医。
3. 长期目标与使命：为实现长期奋斗目标，需要通过持续的自我检视和自我完善保持组织活力。

#### 2. 自我革命的“四个自我”

<Tabs items={['自我净化','自我完善','自我革新','自我提高']}>
  <Tab value="自我净化">

发现并清除损害党的先进性和纯洁性的消极因素，保持组织健康。

</Tab>
  <Tab value="自我完善">

通过检视问题、健全机制和改进工作补齐短板。

</Tab>
  <Tab value="自我革新">

主动适应新情况，破除不适应实际的观念和机制。

</Tab>
  <Tab value="自我提高">

提升领导能力、工作水平和实践本领。

</Tab>
</Tabs>

<Callout type="info" title="自我革命重在治权">

**党的自我革命重在治权**；把权力关进制度笼子，是新时代全面从严治党的一项重要任务。此处的“治权”与前文“制度制约和监督权力”相互联系。

</Callout>

#### 3. “九个以”：推进自我革命的实践要求

| 顺序 | “以……” | 对应定位 |
| --- | --- | --- |
| 1 | **以坚持党中央集中统一领导** | **根本保证** |
| 2 | **以引领伟大社会革命** | **根本目的** |
| 3 | **以习近平新时代中国特色社会主义思想** | **根本遵循** |
| 4 | **以跳出历史周期率** | **战略目标** |
| 5 | **以解决大党独有难题** | **主攻方向** |
| 6 | **以健全全面从严治党体系** | **有效途径** |
| 7 | **以锻造坚强组织、建设过硬队伍** | **重要着力点** |
| 8 | **以正风肃纪反腐** | **重要抓手** |
| 9 | **以自我监督和人民监督相结合** | **强大动力** |

**背诵分组**：保证—目的—遵循；目标—方向—途径；着力点—抓手—动力。

<Callout type="tip" title="九个以：最易混的四组">

- **根本保证**：党中央集中统一领导。
- **根本目的**：引领伟大社会革命。
- **主攻方向**：解决大党独有难题。
- **战略目标**：跳出历史周期率。

“根本保证”和“根本目的”是两种不同的逻辑地位，不能互换。

</Callout>

### 六、考前闭卷复述

**四定位**：核心加强领导、基础全面、关键严、要害治。

**四全**：内容全涵盖、对象全覆盖、责任全链条、制度全贯通。

**建设布局**：政治建设根本且首位，思想建设基础，组织建设重体系和队伍，作风建设连群众，纪律建设治本，制度建设贯穿各项建设。

**反腐败**：不敢腐**前提**、不能腐**关键**、不想腐**根本**。

**自我革命**：第二个答案；**四个自我**；牢记**九个以**九组定位词。
