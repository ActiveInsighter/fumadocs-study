# 第八章 发展全过程人民民主

## 专题十一｜发展全过程人民民主

<Callout type="info" title="本专题六条主线">

**人民民主是社会主义的生命。全过程人民民主是社会主义民主政治的本质属性。**

掌握六个板块：**政治制度体系**；**党的领导、人民当家作主、依法治国有机统一**；**全过程人民民主**；**协商民主和基层民主**；**新时代爱国统一战线**；**铸牢中华民族共同体意识**。

</Callout>

### 一、人民民主为什么是社会主义的生命？

原书从以下角度阐明人民民主的重要性：

1. **民主是全人类共同价值**，也是人类政治文明发展的成果。
2. **民主是中国共产党和中国人民长期坚持的重要理念**。
3. 人民民主建立在社会主义经济基础之上，体现国家性质与社会主义制度要求，是**新型的社会主义民主**。
4. 发展社会主义民主政治是全面建设社会主义现代化国家的**内在要求与重要目标**。
5. **人民民主是社会主义的生命**；从教材的政治理论语境看，民主建设与社会主义现代化、民族复兴密切相关。

**理解抓手**：民主首先而且主要是**一种国家制度**；不仅要看是否有表达意愿的环节，还要看人民如何通过制度安排参与政治生活、实现利益诉求。

### 二、坚定中国特色社会主义政治制度自信

#### 1. 制度自信与制度优势

**制度优势是一个政党、一个国家的最大优势**。坚定中国特色社会主义制度自信，首先要坚定对**中国特色社会主义政治制度**的自信。

原书概括我国社会主义民主政治制度能够：

- 保障人民广泛享有权利、参与国家治理和社会治理；
- 调节国家政治关系、增强民族凝聚力与社会稳定；
- **集中力量办大事**；
- 维护国家独立自主与主权、安全、发展利益。

#### 2. 人民当家作主的制度体系

| 制度 | 层级与定位 | 重点内容 |
| --- | --- | --- |
| **人民代表大会制度** | **根本政治制度** | 人民行使国家权力的重要制度安排，是实现全过程人民民主的**重要制度载体** |
| **中国共产党领导的多党合作和政治协商制度** | **基本政治制度** | 新型政党制度，人民政协发挥政治协商、民主监督、参政议政作用 |
| **民族区域自治制度** | **基本政治制度** | 统一与自治结合，民族因素与区域因素结合 |
| **基层群众自治制度** | **基本政治制度** | 保障群众依法直接行使民主权利和开展自我管理、自我服务、自我教育、自我监督 |

##### 人民代表大会制度的基本认识

其制度安排被概括为符合国情、体现社会主义国家性质、保证人民当家作主、保障民族复兴，并实现三个**有效保证**：

1. **有效保证国家沿着社会主义道路前进**。
2. **有效保证国家治理跳出治乱兴衰的历史周期率**。
3. **有效保证国家政治生活既充满活力又安定有序**。

<Callout type="warn" title="人民代表大会制度 ≠ 全民直接管理全部国家事务">

人民通过人民代表大会制度依法行使国家权力，主要是通过**选举代表等制度化形式**实现；基层群众自治制度则着重保障人民在基层**依法直接行使民主权利**。不能把“人民当家作主”理解为每个人都直接参与每项国家事务的具体管理。

</Callout>

##### 人民政协的五个定位与三项职能

**五个定位**：人民政协是中国人民爱国统一战线的组织；实行中国共产党领导的多党合作和政治协商制度的重要机构；发扬社会主义民主、实践全过程人民民主的重要形式；社会主义协商民主的重要渠道和专门协商机构；国家治理体系的重要组成部分。

| 范畴 | 正确表述 |
| --- | --- |
| **三项主要职能** | **政治协商、民主监督、参政议政** |
| **两大主题** | **团结和民主** |
| **工作中心环节** | **加强思想政治引领，广泛凝聚共识** |
| **政党制度特点** | **共产党领导、多党派合作；共产党执政、多党派参政** |

<Callout type="tip" title="政协与人大不能混淆">

**人民政协不是国家权力机关，也不是国家机构**。1954年第一届全国人民代表大会召开后，人民政协不再代行全国人民代表大会的职权。我国**不是西方式多党制**；民族区域自治体现**单一制**国家结构，而不是联邦制。

</Callout>

### 三、坚定不移走中国特色社会主义政治发展道路

坚持**党的领导、人民当家作主、依法治国有机统一**：

<Tabs items={['党的领导', '人民当家作主', '依法治国']}>
  <Tab value="党的领导">

是人民当家作主和依法治国的**根本保证**。走中国特色社会主义政治发展道路，**最根本的是坚持党的领导**。

</Tab>
  <Tab value="人民当家作主">

是社会主义民主政治的**本质特征**，决定民主政治建设的价值方向。

</Tab>
  <Tab value="依法治国">

是党领导人民治理国家的**基本方式**。通过法治使国家治理有制度化、规范化的运行机制。

</Tab>
</Tabs>

三者并非互相取代，而是统一于社会主义民主政治实践。

### 四、全过程人民民主的本质、内涵和特点

#### 1. 根本定位

**全过程人民民主是社会主义民主政治的本质属性**，是我国社会主义民主长期实践的成果，也是新时代民主政治理论与实践的重要创新。

#### 2. 四组统一

| 四组统一 | 理解角度 | 常见误区 |
| --- | --- | --- |
| **过程民主与成果民主** | 重视参与过程，也关注实际结果 | 只看参与形式、不问效果 |
| **程序民主与实质民主** | 有民主程序，也要有真实的人民主体地位 | 程序与实际利益脱节 |
| **直接民主与间接民主** | 基层直接参与与制度化间接参与相互衔接 | 认为只有直接参与才算民主 |
| **人民民主与国家意志** | 人民意愿依法通过制度程序转化为国家决定 | 把人民参与与国家制度割裂 |

#### 3. 三个覆盖特征与三项优势

- **全链条、全方位、全覆盖**：强调民主实践在过程、领域和参与环节上的系统性。
- 既有**完整制度程序**，又有**完整参与实践**：体现时间连续性、内容整体性、运行协同性、人民参与的广泛性与持续性。
- **最广泛、最真实、最管用**：强调人民参与范围、制度实现程度和治理效果。

**出发点和落脚点**：始终着眼于实现**最广大人民的根本利益**。

### 五、协商民主和基层民主

#### 1. 协商民主：全过程人民民主的重要形式

> **有事好商量，众人的事情由众人商量，找到全社会意愿和要求的最大公约数，是人民民主的真谛。**

- **协商民主是党的群众路线在政治领域的重要体现**。
- **选举民主与协商民主相互补充、相得益彰**。
- 在教材中，协商民主被概括为中国社会主义民主政治**独特、独有、独到的形式**。
- 作用包括**促进科学民主决策、扩大有序参与、凝聚社会共识**。

#### 2. 基层民主：全过程人民民主的重要体现

| 基层民主形式 | 对应领域 | 主要功能 |
| --- | --- | --- |
| **村民委员会** | 农村 | 村民依法开展自治 |
| **居民委员会** | 城市社区 | 社区居民依法开展自治 |
| **职工代表大会** | 企事业单位 | 职工依法参与民主管理 |

发展基层民主是**实现人民有效政治参与的重要渠道**，也是人民当家作主的**有效途径**、社会主义民主**最广泛的实践**。

<Callout type="warn" title="协商民主不等于仅开会表态；基层民主也不等于人民政协">

协商民主强调**讨论、协商和凝聚共识**；基层民主强调社区、村庄和单位中的**依法自治与直接参与**。它们同属全过程人民民主的实践领域，但**组织、职能和适用范围不同**。

</Callout>

### 六、巩固和发展新时代爱国统一战线

#### 1. 地位和作用

**统一战线是凝聚人心、汇聚力量的强大法宝**，贯穿党的革命、建设和改革实践，也是推动民族复兴的重要法宝。

新时代尤其强调其在**维护主权、安全与发展利益**，**围绕中心、服务大局**，以及**巩固党的阶级基础、扩大群众基础**等方面的作用。

#### 2. 统战工作的七个定位

| 提问关键词 | 精确答案 |
| --- | --- |
| **本质要求** | **大团结大联合**，解决**人心和力量**问题 |
| **工作对象** | **党外人士**，重点是其中的**代表人士** |
| **工作方法关键** | **求同存异**，尊重多样性、寻求一致性 |
| **最鲜明特征** | **党领导的统一战线** |
| **最核心最根本的问题** | **坚持党的领导** |
| **宗教工作的本质** | **群众工作**；坚持我国宗教**中国化方向** |
| **新时代历史责任** | **促进中华儿女大团结** |

“求同存异”应与**团结—批评—团结**的优良传统联系记忆，着眼于寻找最大公约数、画出最大同心圆。

### 七、铸牢中华民族共同体意识

#### 1. 基本定位

**民族团结是我国各族人民的生命线；中华民族共同体意识是民族团结之本。** 中华民族共同体的形成具有深厚历史基础，对共同体的认同在中华民族形成中具有重要决定意义。

#### 2. 五个“相”与其具体指向

| 五个方面 | 历史或现实意义 |
| --- | --- |
| **血脉相融** | 共同体形成和发展的**历史根基** |
| **信念相同** | 缔造统一多民族国家的**内生动力** |
| **文化相通** | 形成多元一体文明格局的**文化基因** |
| **经济相依** | 构建统一经济体的**强大力量** |
| **情感相亲** | 中华民族一家亲的**坚强纽带** |

#### 3. 为什么要铸牢？

- 是新时代党的民族工作的**主线**，也是民族地区各项工作的主线。
- 有助于巩固维护**国家统一和民族团结**的思想基础。
- 有助于增进各民族**自觉认同**、防范和应对民族领域风险挑战。
- 为国家兴旺发达和长治久安提供重要思想保证。

**四个“与共”**：**休戚与共、荣辱与共、生死与共、命运与共**。

原资料还提及制定**民族团结进步促进法**的重要意义：贯彻新时代民族工作思想；推进中华民族共同体建设；促进共同繁荣与中国式现代化；在法治轨道上推进民族事务治理现代化。这里讲的是**立法意义**，不能仅由该段表述推断相关立法在任意考试时点的最新进展。

### 八、考点辨析与闭卷自测

<Accordions>
  <Accordion title="人民政协与人民代表大会的主要区别？">

**人民代表大会是国家权力机关，人民代表大会制度是根本政治制度。人民政协不是国家机关**，是爱国统一战线组织、协商民主重要渠道和专门协商机构。政协职能是**政治协商、民主监督、参政议政**。

</Accordion>
  <Accordion title="党的领导、人民当家作主、依法治国分别是什么定位？">

**党的领导是根本保证；人民当家作主是本质特征；依法治国是基本方式**，三者有机统一。

</Accordion>
  <Accordion title="全过程人民民主的四组统一与三个覆盖特征是什么？">

**过程与成果、程序与实质、直接与间接、人民民主与国家意志**四组统一；**全链条、全方位、全覆盖**。

</Accordion>
  <Accordion title="协商民主、基层民主、统一战线有哪些不同定位？">

协商民主是**实践全过程人民民主的重要形式**；基层民主是**全过程人民民主的重要体现**；统一战线是**凝聚人心、汇聚力量的强大法宝**。

</Accordion>
  <Accordion title="中华民族共同体意识与民族团结之间的关系是什么？">

**民族团结是生命线，共同体意识是民族团结之本**。民族工作要以铸牢共同体意识为主线，树立四个“与共”的共同体理念。

</Accordion>
</Accordions>
