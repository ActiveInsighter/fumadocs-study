# 第十章 建设社会主义文化强国

## 专题十三｜建设社会主义文化强国

<Callout type="info" title="本专题主线：文化自信—正确方向—传承创新—繁荣发展—扩大影响">

建设文化强国要把握六个方向：**坚定文化自信**、坚持中国特色社会主义文化发展道路、建设具有**凝聚力和引领力的社会主义意识形态**、以**社会主义核心价值观**引领文化建设、推动优秀传统文化**创造性转化和创新性发展**、发展文化事业产业并提升**文化软实力与国际传播能力**。

</Callout>

### 一、文化繁荣兴盛的地位与文化自信

#### 1. 文化为什么重要？

| 重要性 | 对应角度 |
| --- | --- |
| **中华民族伟大复兴的精神支撑** | 民族复兴 |
| **社会主义现代化强国建设的应有之义** | 现代化建设 |
| **满足人民美好生活需要的内在要求** | 人民文化生活 |
| **在世界文化激荡中站稳脚跟的前提基础** | 文化主体性与国际竞争 |

**文化自信**是**更基础、更广泛、更深厚的自信**，是国家、民族发展中**最基本、最深沉、最持久的力量**。

#### 2. 文化自信的三重根基

| 根基 | 原书定位 | 主要内容 |
| --- | --- | --- |
| **中华优秀传统文化** | **深厚基础** | 民族的根脉，体现中华文化的历史积淀 |
| **革命文化与社会主义先进文化** | **坚强基石** | 党领导人民在斗争和建设中孕育的文化成果 |
| **中国特色社会主义伟大实践** | **现实基础** | 将当代实践经验提炼为理论与文化创造的动力 |

**坚定文化自信的首要任务**：立足中华民族伟大历史实践和当代实践，**用中国道理总结中国经验，把中国经验提升为中国理论，实现精神上的独立自主**。

<Callout type="warn" title="三种文化的定位不能对调">

**中华优秀传统文化——深厚基础；革命文化和社会主义先进文化——坚强基石；中国特色社会主义实践——现实基础。**

</Callout>

#### 3. 文化发展道路与文艺方针

- **发展方向**：发展**面向现代化、面向世界、面向未来**，**民族的科学的大众的**社会主义文化。
- **根本方向**：坚持**为人民服务、为社会主义服务**，这是决定社会主义文化事业前途命运的关键。
- **重要方针**：**百花齐放、百家争鸣**。
- **文化的生命所在与本质特征**：**创新创造**。

### 二、建设具有强大凝聚力和引领力的社会主义意识形态

#### 1. 意识形态工作的战略地位

**意识形态关乎旗帜、关乎道路、关乎国家政治安全**，决定文化前进方向和发展道路。

坚持**马克思主义在意识形态领域指导地位的根本制度**，其意义可概括为：

1. 是历史形成的结论。
2. 是坚持加强党对宣传思想文化工作全面领导的**本质要求**。
3. 是发展社会主义先进文化的**有力保障**。
4. 是巩固社会主义制度、保证文化建设正确方向的**必然要求**。

#### 2. 宣传思想文化与新闻舆论的定位

| 工作领域 | 高频提法 |
| --- | --- |
| **意识形态工作** | **为国家立心、为民族立魂** |
| **哲学社会科学** | 坚持**马克思主义指导**是当代中国哲学社会科学区别于其他哲学社会科学的**根本标志** |
| **新闻舆论工作** | 坚持**正确政治方向**是**第一位要求** |
| **新闻舆论工作的根本原则** | **党性原则**；最根本的是坚持党对新闻舆论工作的领导 |
| **新闻媒体** | 社会舆论的**发射器和放大器**；做大做强主流舆论阵地 |
| **互联网** | 意识形态工作的**主阵地、主战场、最前沿**；管好用好互联网具有关键意义 |

<Callout type="tip" title="不要将‘第一位要求’与‘根本原则’交换">

**新闻舆论工作第一位要求：正确政治方向。根本原则：党性原则。** 两项都强调政治方向，但问法不同，定位必须准确。

</Callout>

### 三、以社会主义核心价值观引领文化建设

原书本专题这里采用**跨模块参照**，指向《思想道德与法治》“社会主义核心价值观”专题。为保持本篇独立完整，保留应掌握的基本框架：

| 层面 | 四个词 | 主要回答的问题 |
| --- | --- | --- |
| **国家层面** | **富强、民主、文明、和谐** | 建设什么样的国家 |
| **社会层面** | **自由、平等、公正、法治** | 建设什么样的社会 |
| **公民层面** | **爱国、敬业、诚信、友善** | 培育什么样的公民 |

**社会主义核心价值观**是**当代中国精神的集中体现**，凝结全体人民共同价值追求；对于文化建设的意义在于提供**价值导向、精神凝聚和行为规范**。

**三项显著特征**：**先进性、人民性、真实性**。其内容融国家、社会、公民的价值要求于一体，体现社会主义本质要求，继承中华优秀传统文化，吸收世界文明有益成果，体现时代精神。

<Callout type="warn" title="最容易出现的两组错配">

**富强民主文明和谐是国家层面**，**自由平等公正法治是社会层面**，**爱国敬业诚信友善是公民层面**。“法治”处于社会层面，不要与公民层面的“诚信”混换。

</Callout>

### 四、传承发展中华优秀传统文化

#### 1. 中华文明与中华优秀传统文化的评价

**中华文明**是中华民族**独特的精神标识**，是当代中国文化的**根基**，是维系海内外中华儿女的重要精神纽带，也是文化创新的重要资源。

**中华优秀传统文化**是中华文明的**智慧结晶与精华**，是中华民族的**根和魂**，是文化软实力的重要基础，是中国特色社会主义扎根的文化沃土，是党的创新理论的重要文化根基。

#### 2. 中华文明五个突出特性

| 突出特性 | 教材对应的深远影响 | 记忆提示 |
| --- | --- | --- |
| **连续性** | 从根本上决定中华民族**必然走自己的路** | **1**个决定 |
| **创新性** | 决定**守正不守旧、尊古不复古**的进取精神；决定**敢于迎接新挑战、接受新事物**的品格 | **2**个决定 |
| **统一性** | 决定各民族文化融为一体、遭遇挫折仍能凝聚；决定**国土不可分、国家不可乱、民族不可散、文明不可断**的共同信念；决定**国家统一是核心利益的核心**；决定坚强统一国家关乎各族人民命运 | **4**个决定 |
| **包容性** | 决定各民族**交往交流交融**的历史取向；决定多宗教信仰并存的格局；决定中华文化**兼收并蓄**的开放胸怀 | **3**个决定 |
| **和平性** | 决定中国坚持做世界和平建设者、全球发展贡献者、国际秩序维护者；主张交流互鉴而非文化霸权；不强加自身价值观和制度；坚持合作而非阵营对抗 | **4**个决定 |

**原书记忆法：1—2—4—3—4。** 这是五项特性在原书表格中对应分项数目的**记忆提示**，不是独立的历史统计结论。

<Accordions>
  <Accordion title="连续性与统一性怎样区别？">

**连续性**重在文明传承不断、由此坚持**走自己的路**；**统一性**重在中华民族**凝聚为多元一体**、维护国家统一和共同命运。

</Accordion>
  <Accordion title="创新性和包容性怎样区别？">

**创新性**重在守正创新、敢于面对新挑战；**包容性**重在交往交流交融、对不同文明**兼收并蓄**。

</Accordion>
  <Accordion title="和平性是不是意味着否认国家利益和安全？">

不是。**和平性**强调和平发展、合作与交流互鉴，并不取消国家主权、安全和发展利益的正当维护。

</Accordion>
</Accordions>

#### 3. 创造性转化与创新性发展

**创造性转化、创新性发展**，强调让优秀传统文化的思想理念、文化精神与**当代中国和现代社会**相适应、相协调，使有当代价值的文化内容得到新的表达与发展。

<Tabs items={['创造性转化', '创新性发展']}>
  <Tab value="创造性转化">

侧重对有价值的传统文化内容进行**适应当代生活的转化和表达**，使其在新的社会条件下更易理解、传播和实践。

</Tab>
  <Tab value="创新性发展">

侧重在保有优秀文化精神的基础上**丰富内涵、拓展表达、发展新的文化形态**。

</Tab>
</Tabs>

**二者联系**：不是“照搬古代文化”，更不是“全盘否定传统”；核心是**立足当代实践，激活优秀文化价值**。

### 五、繁荣发展文化事业和文化产业

#### 1. 为什么要发展文化事业与文化产业？

**繁荣发展文化事业和文化产业**是满足人民精神文化需求、保障人民文化权益的**基本途径**。

| 定位 | 对应内容 |
| --- | --- |
| **当代中国文艺的崇高使命** | **举精神旗帜、立精神支柱、建精神家园** |
| **文艺和文艺工作的出发点与落脚点** | **满足人民精神文化需求** |
| **保障文化权益的重要途径** | **发展文化事业、提升公共文化服务水平** |
| **文化产业发展质量的重要尺度** | 能否提供**满足文化需要并增强人民精神力量**的文化产品 |

#### 2. 社会效益与经济效益的关系

**坚持把社会效益放在首位、社会效益和经济效益相统一**。文化产业的评价不能唯市场收入、盈利规模，更要考虑作品的思想内涵、公共文化意义与社会影响。

<Callout type="tip" title="文化事业与文化产业不可混同">

**文化事业**常涉及公共文化服务和基本文化权益；**文化产业**具有市场经营和产品供给属性。两者都服务于满足人民精神文化需求，但组织方式和评价侧重点不同。

</Callout>

### 六、提升国家文化软实力与中华文化影响力

1. **文化传播力、文明影响力**的提高，是国家发展兴盛的重要方面，软实力与硬实力应相得益彰。
2. **文化软实力**集中体现以文化为基础形成的**凝聚力、生命力、吸引力和影响力**。
3. 一个国家文化软实力的根本支撑，是其**核心价值观的生命力、凝聚力和感召力**。
4. 对外推介中华文化，要**开放自信、谦逊谦和**，塑造**可信、可爱、可敬**的中国形象。
5. 加强**国际传播能力建设**，提高传播效能，增强与综合国力相匹配的国际话语权。
6. **讲好中国故事、传播好中国声音**，重在传播理念，注意**以我为主、以理服人、以情动人**。

### 七、错项与考前自测

<Accordions>
  <Accordion title="错项：文化自信仅来自中华优秀传统文化">

错。还包括**革命文化和社会主义先进文化的坚强基石**，以及**中国特色社会主义伟大实践的现实基础**。

</Accordion>
  <Accordion title="错项：新闻舆论工作的第一位要求是经济效益">

错。**正确政治方向**是第一位要求，**党性原则**是根本原则；文化产品评价也强调**社会效益优先**。

</Accordion>
  <Accordion title="错项：中华文明包容性说明中华民族必然走自己的路">

混淆。**走自己的路**对应**连续性**，包容性对应**交往交流交融、兼收并蓄**。

</Accordion>
  <Accordion title="错项：判断文化产业发展水平最重要的是经济效益">

错。应看其是否能提供更多**满足人民文化需求、增强人民精神力量**的文化产品，坚持**社会效益首位**。

</Accordion>
  <Accordion title="背出五个突出特性和原书顺序">

**连续性、创新性、统一性、包容性、和平性**；对应表格原书提示**1—2—4—3—4**。

</Accordion>
</Accordions>
