# 第九章 全面依法治国

## 专题十二｜全面依法治国

<Callout type="info" title="结构说明：合并原书的交叉参照内容">

**原书第三部分“专题十二”只列出全面依法治国需要处理的四组重大关系**，把其他知识点引向**第五部分《思想道德与法治》专题十三、十四、十五**。为了让本篇成为**独立、完整的复习文档**，下文将两处内容按知识框架合并整理；四组重大关系仍单列，避免遗漏原专题正文。

**总定位：**习近平法治思想是**根本遵循**；中国特色社会主义法治道路是**唯一正确道路**；中国特色社会主义法治体系是**总抓手**；依宪治国、依宪执政是**首要任务**。

</Callout>

### 一、全面依法治国为什么重要？

1. **法律是治国之重器，法治是治国理政的基本方式**。
2. 全面依法治国事关**党执政兴国、人民幸福安康、党和国家长治久安**。
3. 是坚持完善中国特色社会主义制度、推进**国家治理体系和治理能力现代化**的重要方面。
4. 是解决发展中的重大问题、促进**社会公平正义**、维护社会和谐稳定的**根本要求**。
5. 在现代化建设中具有**全局性、战略性、基础性、保障性**地位，要发挥法治**固根本、稳预期、利长远**的作用。

**注意**：这里的“根本要求”是法治对于治理现代化等任务的要求，不等于把“法治”替换成一切政治建设中的“根本保证”。

#### 2. 习近平法治思想的理论地位

- 回答新时代**为什么实行全面依法治国、怎样实行全面依法治国**等重大问题。
- 是马克思主义法治理论中国化时代化的重要理论成果。
- 是对党领导法治建设实践经验的总结。
- 是**在法治轨道上全面建设社会主义现代化国家的根本遵循**，也是推进法治中国建设的重要思想指引。

### 三、中国特色社会主义法治道路

#### 1. 内涵、核心要义和必然性

**中国特色社会主义法治道路**是中国特色社会主义道路在法治领域的具体体现。

**核心要义**：

1. **坚持党的领导**；
2. **坚持中国特色社会主义制度**；
3. **贯彻中国特色社会主义法治理论**。

**选择这一道路的依据**：历史发展经验、我国社会主义国家性质、我国基本国情。

#### 2. 五个必须遵循的原则

<Tabs items={['党的领导', '人民主体', '法律平等', '法德结合', '中国实际']}>
  <Tab value="党的领导">

党的领导是社会主义法治的**最根本保证**，强调**党领导立法、保证执法、支持司法、带头守法**。

</Tab>
  <Tab value="人民主体">

全面依法治国最广泛、最深厚的基础是**人民**；法治建设要保障人民依法享有权利、履行义务。

</Tab>
  <Tab value="法律平等">

**法律面前人人平等**是社会主义法治的基本要求。既要反对特权和歧视，也要坚持违法行为依法追究。这里的平等不是忽视现实案件依法适用的不同条件。

</Tab>
  <Tab value="法德结合">

坚持**依法治国与以德治国相结合**，发挥法律规范作用和道德教化作用，重视法治对道德理念的承载。

</Tab>
  <Tab value="中国实际">

坚持**从中国实际出发**，使法治建设与国情、制度和治理实践相结合。

</Tab>
</Tabs>

### 四、总抓手：中国特色社会主义法治体系

| 五个体系 | 在原书中的关键定位 |
| --- | --- |
| **完备的法律规范体系** | 法治体系的**前提**，法治国家、法治政府、法治社会的**制度基础** |
| **高效的法治实施体系** | 建设中国特色社会主义法治体系的**重点** |
| **严密的法治监督体系** | 保证宪法法律实施、制约监督权力的重要保障 |
| **有力的法治保障体系** | 全面依法治国的**重要依托** |
| **完善的党内法规体系** | 法治体系的**本质要求和重要内容** |

**区分“总抓手”和“具体体系”**：总抓手是**建设中国特色社会主义法治体系**，并非仅指其中的**法律规范体系**。这五个体系从规范、实施、监督、保障和党内法规等方面相互联系。

#### 首要任务：依宪治国、依宪执政

**坚持依法治国首先要坚持依宪治国，坚持依法执政首先要坚持依宪执政。** 宪法权威是法治权威的重要基础。不能把“依宪治国、依宪执政”仅缩成“加强一般行政执法”。

### 五、全面依法治国的工作布局和重要环节

#### 1. 两组共同推进与一体建设

| 工作布局 | 关键关系 |
| --- | --- |
| **依法治国、依法执政、依法行政共同推进** | 关键在于**党坚持依法执政、各级政府坚持依法行政** |
| **法治国家、法治政府、法治社会一体建设** | **法治国家是目标；法治政府是建设法治国家的重点；法治社会是基础** |

**法治政府建设**是推进全面依法治国的**重点任务和主体工程**；**法治社会建设**是推进全面依法治国的**基础工程**。

#### 2. 科学立法、严格执法、公正司法、全民守法

<Steps>
  <Step>

**科学立法——前提。** 立法是法治的**龙头环节**，强调提高立法质量，使法律规范切合客观实际。

</Step>
  <Step>

**严格执法——关键。** 行政执法坚持**法定职责必须为、法无授权不可为**，完善执法程序和责任机制。

</Step>
  <Step>

**公正司法——重点。** **公正是法治的生命线**，公正司法是维护社会公平正义的**最后一道防线**。

</Step>
  <Step>

**全民守法——基础。** 使法治成为社会共识和行为准则；法律权威离不开人民的**内心拥护与真诚信仰**。

</Step>
</Steps>

### 六、原书专题十二的重点：四组重大关系

以下四组是**第三部分本专题实际展开的核心正文**，应重点逐条区分。

#### 1. 政治与法治

**党和法的关系是政治与法治关系的集中反映**，是全面依法治国的一个**根本问题**；党和法治关系也是法治建设的**核心问题**。

**党的领导与社会主义法治是一致的**：社会主义法治必须坚持党的领导，党的领导必须依靠社会主义法治。

错误理解包括“党的领导可以不受法治原则约束”和“法治要求排斥党的领导”。二者都割裂了教材所强调的有机统一。

#### 2. 改革与法治

**改革和法治相辅相成、相伴而生，如鸟之两翼、车之双轮**。

- 改革需要法律制度的引领、规范与保障。
- 法治建设也要适应改革实践要求而不断完善。
- 不能把“改革要发展”误读为“改革可以任意突破法治”，也不能用僵化守旧的理解妨碍依法推进改革。

#### 3. 依法治国与以德治国

**法治和德治都是治国理政不可或缺的重要手段**：

- 法治发挥**规范、约束与保障**作用。
- 德治发挥**价值引导与教化**作用。
- 应把法律的规范作用与道德的教化作用结合，而不是简单认为只需其中一种。

#### 4. 依法治国与依规治党

**坚持依法治国和依规治党有机统一，是全面依法治国的内在要求。**

**依法治国**面向国家与社会治理的法律秩序；**依规治党**强调党内法规和党的自身治理。二者既有侧重点，也应相互促进、相互协调。

> **定位句**：依规治党深入党心，依法治国才能深入民心。关键不是二选一，而是形成有机统一。

### 七、易错题与章节交叉记忆

<Accordions>
  <Accordion title="错项：全面依法治国的首要任务是建设中国特色社会主义法治体系">

错误。**建设中国特色社会主义法治体系是总抓手**；**依宪治国、依宪执政是首要任务**。

</Accordion>
  <Accordion title="错项：法治政府是法治建设的总体目标，法治社会是主体工程">

不准确。**法治国家是目标**；**法治政府建设是重点任务和主体工程**；**法治社会建设是基础工程**。

</Accordion>
  <Accordion title="错项：法律规范体系是五个法治体系中的实施重点">

不准确。**法律规范体系是前提**，**法治实施体系是重点**。

</Accordion>
  <Accordion title="错项：坚持法治要求放弃改革，改革则可不考虑法律约束">

错误。二者**相辅相成**，应在法治轨道上推进改革，并及时完善法律制度以适应改革需要。

</Accordion>
  <Accordion title="错项：党内法规体系与全面依法治国无关">

错误。**完善党内法规体系**是中国特色社会主义法治体系的重要内容，**依法治国和依规治党有机统一**是内在要求。

</Accordion>
