# 第十四章 建设巩固国防和强大人民军队

## 专题十八｜建设巩固国防和强大人民军队

<Callout type="info" title="主线：强国必须强军，军强才能国安">

国防和军队现代化是**中国式现代化的重要组成部分**。新时代强军目标：建设一支**听党指挥、能打胜仗、作风优良**的人民军队，把人民军队建设成为**世界一流军队**。

**听党指挥是灵魂、能打胜仗是核心、作风优良是保证。**

</Callout>

### 一、建设巩固国防和强大人民军队的时代定位

#### 1. 为什么说“强国必须强军”？

建设与我国国际地位相称、与国家安全和发展利益相适应的**巩固国防和强大人民军队**，是新时代国家发展需要的重要组成部分。

| 原书判断 | 含义 |
| --- | --- |
| **强国必须强军，军强才能国安** | 国防和军队建设关乎主权、安全、发展利益 |
| **国防和军队现代化是中国式现代化重要组成部分** | 国家现代化与国防现代化相互联系 |
| **军事手段始终是保底手段** | 军事实力是维护总体安全的重要支撑 |

**辨析**：军事力量不是社会发展全部因素的替代物，也不能把“军事手段是保底手段”理解成所有问题都必须使用军事方式解决。材料强调的是维护国家安全所需的**战略保障能力**。

#### 2. 新时代人民军队使命任务：“四个战略支撑”

<Steps>
  <Step>

**政治与制度保障**：为巩固**中国共产党领导和我国社会主义制度**提供战略支撑。

</Step>
  <Step>

**主权与领土完整**：为捍卫国家**主权、统一和领土完整**提供战略支撑。

</Step>
  <Step>

**海外利益**：为维护我国**海外利益**提供战略支撑。

</Step>
  <Step>

**国际和平发展**：为促进**世界和平与发展**提供战略支撑。

</Step>
</Steps>

<Callout type="tip" title="“四个战略支撑”的速记方法">

按由内向外、由近及远记忆：**党和制度 → 主权统一领土 → 海外利益 → 世界和平发展**。四个领域层次不同，选择题容易用遗漏或交换对象来设置干扰。

</Callout>

### 二、新时代强军目标的内涵：灵魂、核心、保证

#### 1. 三个目标部分不能随意互换

<Tabs items={['听党指挥：灵魂','能打胜仗：核心','作风优良：保证']}>
  <Tab value="听党指挥：灵魂">

**听党指挥是灵魂**，决定军队建设的**政治方向**。坚持党对人民军队的**绝对领导**是人民军队永远不变的军魂，听党指挥是人民军队建设的首要要求。

**定位词**：灵魂、军魂、政治方向、首要要求、命脉。

</Tab>
  <Tab value="能打胜仗：核心">

**能打胜仗是核心**，反映军队的**根本职能**和军队建设的**根本指向**。

**能打仗、打胜仗**体现人民军队履行使命任务所需的现实能力。

**定位词**：核心、根本职能、根本指向、根本价值。

</Tab>
  <Tab value="作风优良：保证">

**作风优良是保证**，关系军队的**性质、宗旨和本色**。光荣传统与优良作风是人民军队的重要特色和政治优势。

**定位词**：保证、性质、宗旨、本色、优良传统。

</Tab>
</Tabs>

| 项目 | 正确定位 | 常见错误选项 |
| --- | --- | --- |
| **听党指挥** | **灵魂**、决定政治方向 | 把“灵魂”错配给能打胜仗 |
| **能打胜仗** | **核心**、根本职能和根本指向 | 把“核心”错配给作风优良 |
| **作风优良** | **保证**、关系性质宗旨本色 | 把“保证”错配给听党指挥 |

#### 2. 为什么强调党对人民军队的绝对领导？

在原书的理论体系中，党对人民军队的绝对领导是**建军之本、强军之魂**，关系军队的政治属性和战略方向。建设强大人民军队，需要把政治建军的要求贯穿国防和军队现代化建设。

<Callout type="warn" title="党对军队绝对领导与军委主席负责制的关系">

- **党对人民军队的绝对领导**：根本性的政治原则和军魂。
- **军委主席负责制**：坚持党对人民军队绝对领导的**根本制度和根本实现形式**，在相关制度体系中处于**最高层次、统领地位**。

二者一为**政治原则**、一为**制度实现形式**，答题时注意设问对象。

</Callout>

### 三、国防和军队现代化新“三步走”战略安排

| 时间节点 | 目标 | 不可错配 |
| --- | --- | --- |
| **2027 年** | 实现**建军一百年奋斗目标** | 不是“全面建成世界一流军队” |
| **2035 年** | **基本实现国防和军队现代化** | “基本实现”不能漏掉 |
| **本世纪中叶** | 把人民军队**全面建成世界一流军队** | 不是仅“基本实现现代化” |

<Steps>
  <Step>

#### 到 2027 年：实现建军一百年奋斗目标

重点在于按照战略安排推进建军百年目标，属于新“三步走”中的第一个时间节点。

</Step>
  <Step>

#### 到 2035 年：基本实现国防和军队现代化

“**基本实现**”是高频考点，不能表述为这时已经完成一切建设任务。

</Step>
  <Step>

#### 到本世纪中叶：全面建成世界一流军队

这是新“三步走”的远景目标，体现军队现代化建设的长期战略安排。

</Step>
</Steps>

<Callout type="tip" title="记忆口诀">

**“2027 建军百年，2035 基本现代化，世纪中叶世界一流。”** 年份、完成程度、目标对象三项需要一起记。

</Callout>

### 四、高质量推进国防和军队现代化

#### 1. 关键定位词

| 原书表述 | 准确对应 |
| --- | --- |
| 高质量推进国防和军队现代化 | 推进中国式现代化的**应有之义** |
| 根本指向与检验标准 | 始终是**战斗力** |
| **巩固提高一体化国家战略体系和能力** | 高质量推进国防和军队现代化的**必由之路** |
| **政治建军** | 人民军队的**立军之本** |
| **军委主席负责制** | 党对军队绝对领导的**根本制度和根本实现形式** |

#### 2. 战斗力为什么是检验标准？

军队建设是否有效，最终需要体现为履行使命任务的**现实能力**。装备、训练、组织、技术和管理都是提升能力的条件与途径，但**不能将某个单独指标代替战斗力的综合检验**。

**审题线索**：“实战化训练”“能够履行使命”“战备水平”“建设成效怎么检验”通常指向**战斗力标准**。

#### 3. 一体化国家战略体系和能力

原书将**巩固提高一体化国家战略体系和能力**定位为高质量推进国防和军队现代化的**必由之路**。

理解重点：国防和军队建设涉及军事、科技、工业、经济和社会等多种资源，需要重视**国家战略力量的整体统筹与能力协同**，而非彼此分散建设。

**与总体国家安全观的联系**：专题十七要求统筹各领域安全；本专题进一步从国防和军队现代化角度强调**战略资源协同**与**军事能力建设**。

### 六、题目训练与陷阱

<Accordions>
  <Accordion title="错误：新时代强军目标中，作风优良是军队建设的核心。">

**错误。** **能打胜仗是核心**；作风优良是**保证**；听党指挥是**灵魂**。

</Accordion>
  <Accordion title="错误：到2035年把人民军队全面建成世界一流军队。">

**错误。** **2035 年基本实现国防和军队现代化**；到**本世纪中叶**全面建成世界一流军队。

</Accordion>
  <Accordion title="问答：新时代人民军队使命任务的四个战略支撑是什么？">

为巩固**党的领导和社会主义制度**、捍卫**国家主权统一与领土完整**、维护**海外利益**、促进**世界和平与发展**提供战略支撑。

</Accordion>
  <Accordion title="错误：检验军队现代化成效的根本标准是某一类装备数量。">

装备能力很重要，但原书强调的**根本指向和检验标准是战斗力**，不能以某个单项指标完全取代。

</Accordion>
  <Accordion title="问答：军委主席负责制的制度定位是什么？">

是坚持党对人民军队**绝对领导的根本制度和根本实现形式**，在党领导军队的制度体系中处于最高层次、统领地位。

</Accordion>
</Accordions>
