### 一、实现中华民族伟大复兴的中国梦

#### 1. 中国梦的本质与党的中心任务

中华民族伟大复兴，是近代以来中国人民的共同梦想，也是中国共产党矢志不渝的奋斗目标。党的百年奋斗可以围绕**实现中华民族伟大复兴**这一主题来理解。

> **中国梦的本质：国家富强、民族振兴、人民幸福。**

| 内涵 | 核心指向 | 判断关键词 |
| --- | --- | --- |
| **国家富强** | 国家综合实力和现代化发展 | 富强、强国 |
| **民族振兴** | 民族复兴和民族整体发展 | 复兴、振兴 |
| **人民幸福** | 人民生活福祉和美好生活 | 人民幸福、民生 |

**新时代新征程中国共产党的中心任务**：团结带领全国各族人民**全面建成社会主义现代化强国、实现第二个百年奋斗目标，以中国式现代化全面推进中华民族伟大复兴**。

<Callout type="warn" title="“中国梦的本质”与“实现道路”不可互换">

- **本质**：国家富强、民族振兴、人民幸福。
- **道路和方式**：以**中国式现代化**全面推进中华民族伟大复兴。
- **中心任务**：全面建成社会主义现代化强国、实现第二个百年奋斗目标，并以中国式现代化推进复兴。

</Callout>

### 二、中国式现代化怎样在长期探索中形成？

中国式现代化是中国共产党领导人民**长期探索和实践的重大成果**。将其历史条件分为四个阶段，有利于理解每一时期为现代化提供了什么。

| 历史阶段 | 主要探索与实践 | 为中国式现代化提供什么 |
| --- | --- | --- |
| **新民主主义革命时期** | 取得新民主主义革命的胜利 | 创造**根本社会条件** |
| **社会主义革命和建设时期** | 完成社会主义革命，推进社会主义建设 | 奠定**根本政治前提和制度基础**，积累经验、理论准备和物质基础 |
| **改革开放和社会主义现代化建设新时期** | 工作中心转向经济建设，实行改革开放 | 提供**充满新的活力的体制保证和快速发展的物质条件** |
| **中国特色社会主义新时代** | 解决现代化建设中的突出矛盾问题，推进理论和实践创新 | 提供**更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量** |

<Callout type="tip" title="四个阶段的定位串记">

**革命：社会条件 → 社会主义革命建设：政治前提与制度基础 → 改革开放：体制活力与物质条件 → 新时代：制度、物质、精神的进一步增强。**

</Callout>

### 三、中国式现代化的五个中国特色

**五个特征是“是什么样的现代化”**，其中很多题直接考察关键词的精确匹配。

<Tabs items={['人口规模巨大', '共同富裕', '两个文明协调', '人与自然和谐', '和平发展道路']}>
  <Tab value="人口规模巨大">

**中国式现代化是人口规模巨大的现代化。** 这是中国式现代化的**显著特征**。

大规模人口条件下推进现代化，对资源配置、公共服务、区域协调和长期规划提出更高要求。

</Tab>
  <Tab value="共同富裕">

**中国式现代化是全体人民共同富裕的现代化。** 这是其**本质特征**，也是**区别于西方现代化的显著标志**。

共同富裕强调**全体人民**，不能理解为少数人先行富裕后永远固化差距，也不等于平均主义。

</Tab>
  <Tab value="两个文明协调">

**中国式现代化是物质文明和精神文明相协调的现代化。**

**物质富足、精神富有**是社会主义现代化的**根本要求**；兼顾物质富足和精神富有是**崇高追求**。物质发展不意味着精神建设自然完成。

</Tab>
  <Tab value="人与自然和谐">

**中国式现代化是人与自然和谐共生的现代化。**

**尊重自然、顺应自然、保护自然**，促进人与自然和谐共生，是其**鲜明特点**。这里既强调发展的生态边界，也强调发展方式转型。

</Tab>
  <Tab value="和平发展道路">

**中国式现代化是走和平发展道路的现代化。**

坚持在维护世界和平与发展中谋求自身发展，并以自身发展更好维护世界和平与发展、推动构建人类命运共同体，是其**突出特征**。

</Tab>
</Tabs>

#### 五个特征的定位词汇总

| 五个中国特色 | 原书特别强调的定位 |
| --- | --- |
| **人口规模巨大** | **显著特征** |
| **全体人民共同富裕** | **本质特征**、区别于西方现代化的显著标志 |
| **物质文明与精神文明协调** | 物质富足、精神富有是**根本要求**；两者兼顾是崇高追求 |
| **人与自然和谐共生** | **鲜明特点** |
| **走和平发展道路** | **突出特征** |

<Callout type="warn" title="一字之差也要区分">

**共同富裕的“本质特征”**与**中国式现代化的“本质要求”**不是同一组概念。五个中国特色是特征概括；九条本质要求是推进中国式现代化的根本性要求。

</Callout>

### 四、中国式现代化的本质要求

#### 1. 九条本质要求

教材提到的中国式现代化的**九项本质要求**，完整概括如下：

1. **坚持中国共产党领导**。
2. **坚持中国特色社会主义**。
3. **实现高质量发展**。
4. **发展全过程人民民主**。
5. **丰富人民精神世界**。
6. **实现全体人民共同富裕**。
7. **促进人与自然和谐共生**。
8. **推动构建人类命运共同体**。
9. **创造人类文明新形态**。

**答题策略**：问“本质要求”时首先识别**党的领导、中国特色社会主义**等方向性表述，再将经济、政治、文化、社会、生态及世界维度联系起来。九项不是随意排列的九个政策举措。

#### 2. 为什么党的领导居于根本地位？

**中国式现代化是中国共产党领导的社会主义现代化**。这决定了中国式现代化的**根本性质**，是**管总、管根本**的要求。

| 党的领导的重要作用 | 教材指向 |
| --- | --- |
| **决定根本性质** | 确保中国式现代化坚持社会主义方向 |
| **锚定奋斗目标** | 推进现代化目标的长期性、连续性与稳定性 |
| **激发强劲动力** | 通过推进**改革开放**激发发展活力 |
| **凝聚磅礴力量** | 汇聚人民群众的智慧和力量 |

<Callout type="info" title="领导的决定性作用：四个动词">

**决定性质、锚定目标、激发动力、凝聚力量**。这与五个中国特色的具体定位词不同，属于解释“**为什么必须坚持党的领导**”的答题框架。

</Callout>

### 五、中国式现代化的世界意义

教材从**独立自主的现代化道路、现代化理论与实践创新、发展中国家的选择**三个方面展开。

1. **提供全新的现代化模式**：强调现代化并不天然等同于西方化，拓展现代化实现形式。
2. **丰富世界现代化理论与实践**：在发展观、文明观、民主观和生态观等方面提供不同路径的经验与理论探索。
3. **为发展中国家提供新的选择**：强调在本国历史文化和现实条件下探索符合自身国情的发展道路。

教材将中国式现代化概括为**深深植根于中华优秀传统文化，体现科学社会主义的先进本质，吸收人类优秀文明成果，创造人类文明新形态**。这并非否认不同国家现代化道路之间可以交流互鉴。

### 六、考研易错与自测

<Accordions>
  <Accordion title="错误：2035 年的目标是全面建成社会主义现代化强国">

**2035 年：基本实现社会主义现代化；本世纪中叶：建成社会主义现代化强国。** 不要颠倒。

</Accordion>
  <Accordion title="错误：人口规模巨大是中国式现代化的“本质特征”">

**人口规模巨大是显著特征**；**全体人民共同富裕是本质特征**。

</Accordion>
  <Accordion title="错误：新时代的现代化探索首次创造了国家现代化的一切前提">

现代化道路是在**革命、社会主义革命和建设、改革开放、新时代**长期探索中形成的。各阶段提供不同条件。

</Accordion>
  <Accordion title="中国式现代化的九条本质要求包括哪些？">

**党的领导、中国特色社会主义、高质量发展、全过程人民民主、丰富人民精神世界、全体人民共同富裕、人与自然和谐共生、人类命运共同体、人类文明新形态。**

</Accordion>
  <Accordion title="中国式现代化在党的领导方面有哪四项作用？">

**决定根本性质、确保目标行稳致远、激发发展动力、凝聚人民力量。**

</Accordion>
  <Accordion title="为什么说中国梦的本质不是只有国家富强？">

因为中国梦的本质是**国家富强、民族振兴、人民幸福**三个方面的统一，人民幸福不可被省略。

</Accordion>
</Accordions>
