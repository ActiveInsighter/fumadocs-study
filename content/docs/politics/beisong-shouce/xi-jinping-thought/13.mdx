# 第十三章 维护和塑造国家安全

## 专题十七｜维护和塑造国家安全

<Callout type="info" title="一条主线：总体国家安全观 → 统筹发展和安全 → 新安全格局">

**国家安全是民族复兴的根基，社会稳定是国家强盛的前提。** 国家安全是中国式现代化行稳致远的重要基础。

总体国家安全观的五大要素必须对应记牢：**以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托。**

</Callout>

### 一、国家安全为什么是“头等大事”？

#### 1. 三个定位

| 定位 | 教材表述 | 含义 |
| --- | --- | --- |
| **现代化发展** | 国家安全是**中国式现代化行稳致远的重要基础** | 现代化进程需要持续稳定的环境 |
| **民族复兴与国家强盛** | **国家安全是民族复兴的根基，社会稳定是国家强盛的前提** | 安全和稳定具有基础保障意义 |
| **战略地位** | 国家安全是关乎国家发展稳定和社会长治久安的**重大战略问题、头等大事** | 必须从全局谋划安全工作 |

#### 2. 为什么要更加重视系统性风险？

原书概括进入新时代后，国家安全面临**更严峻复杂的形势**，不同威胁与挑战之间的**联动效应**凸显。国家由发展中大国迈向现代化强国的关键阶段，安全任务涉及政治、经济、军事、科技、网络、社会及外部环境等多个领域。

**理解重点**：一个领域的问题可能通过产业链、信息网络、公共卫生或社会运行环节影响其他领域。这正是为什么需要从“局部安全”提升到**总体国家安全**视角。

<Callout type="warn" title="国家安全不是狭义的国防安全">

**军事安全只是国家安全的重要保障领域之一**。总体国家安全观将政治、人民、经济、文化、社会、科技、生态、网络、数据等多方面安全纳入系统考量。把国家安全简单等同于军事安全，是范围缩小的常见干扰项。

</Callout>

### 二、总体国家安全观：五大要素与核心方法

#### 1. 五大要素逐一对应

| 具体要素 | 准确定位 | 不可替换为 |
| --- | --- | --- |
| **人民安全** | **宗旨** | “根本”或“基础” |
| **政治安全** | **根本**；须放在**首要位置** | “宗旨”或“依托” |
| **经济安全** | **基础** | “政治安全的根本位置” |
| **军事、科技、文化、社会安全** | **保障** | “宗旨” |
| **促进国际安全** | **依托** | “国内安全唯一来源” |

**口诀**：**人宗旨、政根本、经基础、军科文社作保障、国际安全为依托。**

<Callout type="tip" title="“根”和“魂”另有所指">

原书指出：总体国家安全观的核心要义可集中体现为&#x2060;**“十个坚持”**，其中**坚持党对国家安全工作的绝对领导**是“根”和“魂”。

因此要区分：

- **政治安全**是总体国家安全观五大要素中的**根本**。
- **党的绝对领导**是总体国家安全工作中的&#x2060;**“根”和“魂”**。

两个定位来自不同设问，不能混成同一句话。

</Callout>

#### 2. 总体国家安全观为什么强调“总体”？

“**总体**”是这一安全观的关键，体现系统观念、整体思维和多层面协同。

<Tabs items={['大安全理念','统筹多对关系','全过程贯通','打好总体战']}>
  <Tab value="大安全理念">

国家安全是**全面的、系统的、共同的、整体的安全**，需要避免只重视单一部门、单一时期或单一风险类别。

</Tab>
  <Tab value="统筹多对关系">

统筹：**外部安全和内部安全、国土安全和国民安全、传统安全和非传统安全、自身安全和共同安全**。

**答题关键**：不是只选一端，而是根据具体条件协调处理这些安全关系。

</Tab>
  <Tab value="全过程贯通">

维护国家安全要**贯穿党和国家工作各方面、全过程**，而不是等到风险集中爆发才采取行动。

</Tab>
  <Tab value="打好总体战">

综合运用**全社会、全政府、全体系、全手段**应对重大国家安全风险挑战，强调统筹力量、形成合力。

</Tab>
</Tabs>

#### 3. 三重关系：政治安全、人民安全、国家利益至上

- **政治安全**：维护人民安全和国家利益的**根本保证**。
- **人民安全**：在这一关系中**居于中心地位**。
- **国家利益至上**：实现政治安全和人民安全的**要求和原则**。

<Callout type="warn" title="“政治安全首位”不意味着可以忽略人民安全">

原书强调三者**有机统一**。政治安全关乎主权、政权、制度和意识形态的稳固，但维护政治安全最终应同人民安全、国家整体利益相联系；不能把它们视为彼此排斥的选项。

</Callout>

### 三、统筹发展和安全：为什么缺一不可？

#### 1. 发展与安全的不同作用

| 比较 | **发展** | **安全** |
| --- | --- | --- |
| 回答的问题 | **动力问题** | **保障问题** |
| 定位 | 具有**基础性、根本性**，是解决安全问题的**总钥匙** | 是发展的**条件和保障** |
| 对另一方的作用 | 经济社会发展为安全能力提供资源支撑 | 稳定环境有利于维护长期发展成果 |

**总要求**：**统筹发展和安全，以发展促安全、以安全保发展**，推动**高质量发展与高水平安全良性互动**。

<Steps>
  <Step>

#### 发展提供物质条件与动力

经济和技术进步能提升基础设施、应急能力、公共服务和风险应对能力。没有发展，安全保障的现实支撑可能不足。

</Step>
  <Step>

#### 安全为持续发展保驾护航

安全风险若不能妥善处理，已经形成的发展成果和生产生活秩序可能受到严重冲击。

</Step>
  <Step>

#### 二者协调推进

发展不应以无限放大风险为代价，安全也不应脱离发展实际；要在实践中实现**发展和安全相互支撑**。

</Step>
</Steps>

**原书比喻**：发展和安全是**一体之两翼、驱动之双轮**。记住“**发展是基础，安全是条件**”，即可避免因“基础性”与“保障性”词汇相近而颠倒。

### 四、以新安全格局保障新发展格局

#### 1. 首要位置：政治安全

构建统筹各领域安全的新安全格局，必须把**维护政治安全作为首要任务**。政治安全是国家安全的**根本**、新时代国家安全的**生命线**。

**政治安全的主要内容**：

1. **政权安全**：维护国家政权的稳定。
2. **制度安全**：维护国家根本制度和基本制度的稳定。
3. **意识形态安全**：维护意识形态领域的安全。

政治安全影响经济安全、军事安全和社会安全等其他领域，是维护国家主权、安全、发展利益的重要方面。

#### 2. 重点领域国家安全：主阵地、主战场

| 领域 | 原书定位或关注重点 |
| --- | --- |
| **国土安全** | **立国之基**；与国家领土、领海和其他国土安全问题相关 |
| **经济安全** | **国家安全的基础**；涉及经济运行与重要经济利益 |
| **社会安全** | 人民群众**安全感的晴雨表**、社会安定的**风向标** |
| **网络、人工智能、数据安全** | 面向数字化、智能化背景下的各类风险 |
| **生物安全与公共卫生安全** | 涉及生物风险防范和公共卫生体系 |
| **外部安全** | 涉及外部环境及国际安全相关风险 |

**平安的民生意义**：原书指出，平安是人民群众解决温饱后最迫切的需要之一，也是重要民生和基本发展环境。此类材料通常同时考查**社会安全与人民安全**。

#### 3. 体系与制度建设为何是长效措施？

**健全国家安全体系、加强国家安全制度建设**，是保障国家安全的**治本之策**，是维护和塑造国家安全的重要支撑。

| 做法 | 主要侧重点 |
| --- | --- |
| 处置一次具体安全风险 | **应急性、事件性**处置 |
| 健全体系、完善制度和工作机制 | **长期性、系统性、制度性**保障 |

不能因为应急处置重要，就忽视制度建设的治本作用。

### 六、典型误区与自测

<Accordions>
  <Accordion title="错误：总体国家安全观以政治安全为宗旨。">

五要素中**人民安全是宗旨、政治安全是根本**。二者都重要，但具体定位不同。

</Accordion>
  <Accordion title="错误：发展与安全必须先完成一项，再开始另一项。">

教材强调两者相互依存，要**同步推进**，实现**高质量发展与高水平安全良性互动**。

</Accordion>
  <Accordion title="问答：总体国家安全观的‘总体’主要体现在哪里？">

体现**大安全理念**；统筹**内外、国土与国民、传统与非传统、自身与共同安全**；贯穿党和国家工作全过程；综合运用全社会、全政府、全体系、全手段应对风险。

</Accordion>
  <Accordion title="问答：政治安全包含哪三项？它与人民安全的关系是什么？">

主要包括**政权安全、制度安全、意识形态安全**。政治安全是维护人民安全和国家利益的**根本保证**，人民安全**居于中心地位**，国家利益至上是两者统一的要求和原则。

</Accordion>
  <Accordion title="错误：国家安全治本之策就是加强单次风险应急处置。">

单次处置很重要，但本专题的**治本之策**是**健全国家安全体系、加强国家安全制度建设**。

</Accordion>
</Accordions>

<Callout type="tip" title="考前一分钟速背">

**国安是复兴根基、稳定是强盛前提；总体安全“人民宗旨、政治根本、经济基础、军科文社保障、国际依托”；党的绝对领导是“根”“魂”；统筹发展和安全，“发展动力、安全保障”；政治安全居首位、政权制度意识形态三方面；制度体系建设是治本之策。**

</Callout>
