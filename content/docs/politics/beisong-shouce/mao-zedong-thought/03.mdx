# 第三章 社会主义改造理论

## 专题四｜社会主义改造理论

<Callout type="info" title="专题主线：新民主主义社会 → 过渡时期总路线 → 三大改造 → 社会主义基本制度">

- **时间**：1949 年新中国成立至 **1956 年底**社会主义改造基本完成。
- **社会性质**：**新民主主义社会**，属于从新民主主义向社会主义**过渡的社会**，不是独立、固定的社会形态。
- **总路线**：**“一化三改”**——社会主义工业化是**主体**，三大改造是**两翼**。
- **改造对象**：**农业、手工业、资本主义工商业**；前两者以合作化为主要形式，后者通过国家资本主义形式和和平赎买实现改造。
- **历史节点**：**1956 年底**，社会主义改造基本完成，社会主义基本制度确立。

</Callout>

### 一、从新民主主义向社会主义的转变

#### 1. 过渡时期与新民主主义社会的性质

**1949—1956 年**，我国从新民主主义向社会主义过渡。过渡时期的社会性质是**新民主主义社会**；它不是一种独立的社会形态，而是通向社会主义社会的**过渡性社会形态**，属于社会主义体系。

<Callout type="warn" title="同一时期的三个不同说法">

- **过渡时期**：1949 年新中国成立后到社会主义改造基本完成。
- **新民主主义社会**：过渡时期中国社会的性质。
- **进入社会主义社会**：以 **1956 年底社会主义改造基本完成、社会主义基本制度确立**为重要标志。

不能认为新中国一成立，社会主义公有制就已占主体地位；也不能把新民主主义社会视为独立稳定的终极制度。

</Callout>

#### 2. 五种经济成分及其性质

| 经济成分 | 经济性质 | 作用与变化方向 |
| --- | --- | --- |
| **社会主义性质的国营经济** | 社会主义 | 掌握经济命脉，居于**领导地位** |
| **半社会主义性质的合作社经济** | 半社会主义 | 从个体经济向**社会主义集体经济**过渡 |
| **农民和手工业者的个体经济** | 个体经济 | 当时占**绝对优势**，处于向不同方向发展的“十字路口” |
| **私人资本主义经济** | 资本主义 | 需根据过渡时期政策逐步改造 |
| **国家资本主义经济** | 具有过渡性质 | 从私人资本主义经济向**社会主义国营经济**过渡 |

**三种主要经济成分**：社会主义经济、个体经济、资本主义经济；**两种过渡性质成分**：半社会主义的合作社经济、国家资本主义经济。

<Callout type="tip" title="“领导地位”不等于“占绝对优势”">

在新民主主义社会，**社会主义国营经济居领导地位**，但从当时经济成分的比重看，**个体经济占绝对优势**。这是选择题反复考查的区分。判断领导地位看经济命脉和引领作用，判断占比看经济成分构成。

</Callout>

#### 3. 社会阶级构成和主要矛盾

**三个基本阶级（教材归类口径）**：工人阶级；农民阶级和其他小资产阶级；民族资产阶级。

**1952 年底土地改革基本完成后**，工人阶级和资产阶级的矛盾逐渐成为国内主要矛盾。解决这一矛盾，推动社会向社会主义转变。

<Tabs items={['新民主主义社会', '社会主义初级阶段']}>
  <Tab value="新民主主义社会">

存在多种经济成分；**国营经济居领导地位**，但**社会主义公有制尚未占主体地位**，个体经济占优势；社会具有鲜明的过渡性质。

</Tab>
  <Tab value="社会主义初级阶段">

社会主义基本制度已经确立，社会主义公有制成为经济基础。仍然存在多种所有制经济，但社会的**根本制度性质**与新民主主义社会不同。

</Tab>
</Tabs>

### 二、党在过渡时期的总路线：“一化三改”

#### 1. 基本内容与内在关系

| 结构 | 内容 | 定位 |
| --- | --- | --- |
| **一化** | 逐步实现国家的**社会主义工业化** | **主体** |
| **三改之一** | 对**个体农业**进行社会主义改造 | **两翼**之一 |
| **三改之二** | 对**个体手工业**进行社会主义改造 | **两翼**之一 |
| **三改之三** | 对**资本主义工商业**进行社会主义改造 | **两翼**之一 |

这里的“两翼”是对**三大改造总体**的概括，不是指三大改造中只取其中两项。

**显著特点**：社会主义**建设与改造同时并举**，把实现工业化与变革所有制关系结合起来，体现**发展生产力与变革生产关系**的有机统一。

#### 2. 为什么提出过渡时期总路线？

<Steps>
  <Step>

**国营经济的物质基础**：社会主义国营经济已在国家经济生活中占有相对强大的地位。

</Step>
  <Step>

**农民的合作化意愿**：土地改革完成后，广大农民在发展生产中产生互助合作的现实要求。

</Step>
  <Step>

**利用和限制资本主义工商业的经验**：新中国成立初期的经济管理实践，为逐步改造资本主义工商业提供经验。

</Step>
  <Step>

**有利的国际形势**：当时的国际环境为向社会主义过渡提供了一定条件。

</Step>
</Steps>

**实行社会主义改造的历史必要性**：建设独立富强的国家需要工业化；当时资本主义经济规模和力量有限，难以单独承担工业起飞的基础任务；农业合作化有助于保障工业化；国际条件也促使中国作出社会主义过渡的选择。

### 三、农业与个体手工业的社会主义改造

#### 1. 农业改造：引导农民走互助合作道路

| 考点 | 准确内容 |
| --- | --- |
| **改造形式** | 通过**合作化**，将个体经济逐步改造为集体经济 |
| **道路** | 积极引导农民组织起来，走**互助合作**道路 |
| **原则** | **自愿互利、典型示范、国家帮助** |
| **方针** | **积极领导、稳步前进** |
| **农村阶级政策** | **依靠贫下中农**，发展互助合作，由逐步限制到最后消灭富农剥削 |
| **方法** | 循序渐进、逐步过渡 |

**三个阶段：**

<Steps>
  <Step>

**互助组**：在个体所有制基础上组织劳动和生产互助，具有**社会主义萌芽性质**。

</Step>
  <Step>

**初级农业生产合作社**：土地等重要生产资料仍保留一定个人所有形式，同时实行统一经营与合作，具有**半社会主义性质**。

</Step>
  <Step>

**高级农业生产合作社**：实现集体所有、集体经营，具有**完全的社会主义性质**。

</Step>
</Steps>

<Callout type="info" title="土改后农民的“两种积极性”">

土地改革完成后，农民既有发展**个体经济**的积极性，也有发展**互助合作**的积极性。因此，教材强调要通过政策引导，遵循自愿互利和渐进原则，而非将合作化简单理解成无条件强制合并。

</Callout>

#### 2. 手工业改造：合作化与三阶段组织形式

**方针**：积极领导、稳步前进。**方法**：说服教育、典型示范、国家帮助。

| 阶段 | 《毛泽东思想和中国特色社会主义理论体系概论》常用名称 | 性质 |
| --- | --- | --- |
| **第一阶段** | **手工业供销小组** | 社会主义萌芽性质 |
| **第二阶段** | **手工业供销合作社** | 半社会主义性质 |
| **第三阶段** | **手工业生产合作社** | 完全的社会主义性质 |

<Callout type="warn" title="跨课程术语差别：供销小组 / 生产合作小组">

原资料提醒：个体手工业合作化的第一阶段，**《毛泽东思想和中国特色社会主义理论体系概论》**&#x2060;常写作“**手工业供销小组**”，而&#x2060;**《中国近现代史纲要》**&#x2060;的相关叙述可能写作“**手工业生产合作小组**”。复习中应辨别**教材语境和组织形式阶段**，不能把第一阶段误判为已经具有完全社会主义性质的生产合作社。

</Callout>

#### 3. 农业与手工业合作化速查表

| 改造对象 | 社会主义萌芽 | 半社会主义 | 完全社会主义 |
| --- | --- | --- | --- |
| **农业** | **互助组** | **初级农业生产合作社** | **高级农业生产合作社** |
| **手工业** | **手工业供销小组** | **手工业供销合作社** | **手工业生产合作社** |

**记忆顺序**：农业是“互助组 → 初级社 → 高级社”；手工业是“供销小组 → 供销合作社 → 生产合作社”。两者方向一致，但**具体组织名称不能互换**。

### 四、资本主义工商业的社会主义改造

#### 1. 总体方式：国家资本主义与和平赎买

对资本主义工商业的改造，通过国家资本主义的形式，逐步把资本主义私有制转变为社会主义公有制。其重要方法是**和平赎买**。

**“赎买”的准确理解**：并非国家一次性向资本家支付巨额收购款，而是通过规定形式，使资本家在一定期限内从企业利润中取得一定收入，逐步改变企业的所有制性质。

#### 2. 实行和平赎买为何具有可能性？

1. **民族资产阶级在社会主义革命阶段具有两面性**：既有从剥削雇佣劳动中获利的一面，也有拥护国家制度、愿意接受社会主义改造的一面。
2. **长期统一战线关系**：中国共产党与民族资产阶级存在长期合作的政治条件。
3. **政权和经济条件**：人民民主专政的国家政权和掌握经济命脉的社会主义国营经济提供保障。
4. **经济调节与监督条件**：粮食统购统销、企业中的工人监督等政策机制提供现实可能。

<Callout type="warn" title="民族资产阶级的“两面性”会随革命阶段变化">

- **民主革命时期**：**革命性和动摇性**。
- **社会主义革命、改造时期**：既存在**剥削工人获取利润**的一面，也存在**拥护国家政策、愿意接受改造**的一面。

回答“两面性”必须先识别题目给出的**历史时期**。

</Callout>

#### 3. 从低级到高级的国家资本主义形式

| 阶段 | 主要形式 | 利润分配 | 企业性质和典型特征 |
| --- | --- | --- | --- |
| **初级形式** | **委托加工、计划订货、统购包销、经销代销**等 | 按具体形式处理企业收益；教材以&#x2060;**“四马分肥”**&#x2060;说明过渡期间部分企业利润分配 | 主要是企业**外部**的合作，企业具有**社会主义因素** |
| **高级形式前期** | **个别企业的公私合营** | **四马分肥** | 企业内部有社会主义成分和资本主义成分的合作，属于**半社会主义性质** |
| **高级形式后期** | **全行业公私合营** | **定股定息** | 企业生产资料转归国家所有，基本具有**社会主义国营性质** |

**“四马分肥”**&#x2060;通常指把相关企业的利润在**国家所得税、企业公积金、工人福利费、资方红利**四方面进行分配。

**“定股定息”**：在全行业公私合营后，按资本家原有股份，依规定年限和比例支付固定利息，是和平赎买的一种具体政策安排。

<Callout type="tip" title="国家资本主义的性质由什么决定？">

本专题讨论的**国家资本主义**是一种与社会主义直接相联系、在国家控制和管理下的特殊资本主义经济，其具体性质要结合**国家政权性质和经济制度背景**理解，而不是看到“国家”二字就直接认定其已完全是社会主义所有制。

</Callout>

#### 4. 不仅改造企业，也改造人

教材明确强调**企业制度改造与资本主义工商业者的思想、劳动和社会身份转变相结合**，使原有工商业者逐步成为自食其力的社会主义劳动者。

因此，社会主义改造既涉及**生产资料所有制的变化**，也涉及对原有工商业者的教育和引导；不能仅理解成企业所有权的行政变更。

### 五、社会主义改造的基本历史经验

<Steps>
  <Step>

**社会主义工业化建设与社会主义改造同时并举**，处理建设和改造的关系。

</Step>
  <Step>

**积极引导、逐步过渡**，根据各经济成分特点采取不同组织形式与步骤。

</Step>
  <Step>

**运用和平方法进行改造**，结合实际社会经济条件处理所有制和社会关系变化。

</Step>
</Steps>

**逻辑关联**：工业化提出发展生产力的要求，改造调整生产关系；通过渐进、适当的方法，力图推动二者协调发展。

### 六、社会主义基本制度的确立及其意义

#### 1. 1956 年底：基本确立

**1956 年底**，对农业、手工业和资本主义工商业的社会主义改造**基本完成**，**社会主义公有制**成为社会的经济基础，中国从新民主主义社会进入**社会主义社会**，并进入**社会主义初级阶段**与全面建设社会主义的历史时期。

| 易考问题 | 精确对应 |
| --- | --- |
| **社会主义改造基本完成的时间** | **1956 年底** |
| **社会主义基本制度确立的标志** | **社会主义改造基本完成** |
| **进入社会主义社会的重要经济标志** | **社会主义经济制度建立，公有制成为经济基础** |
| **社会性质发生什么变化** | 由**新民主主义社会**转变为**社会主义社会** |

<Callout type="warn" title="“基本完成”不等于“一切经济社会问题已经解决”">

社会主义基本制度的建立是历史阶段与社会制度性质的变化，并不意味着**生产力已经高度发达**，也不意味着社会主义建设任务随之结束。中国进入社会主义社会时仍处于**初级阶段**。

</Callout>

#### 2. 历史意义：六个层次

1. **制度变革**：在教材叙述中，被概括为中国历史上深刻而伟大的社会变革，为当代中国发展进步奠定重要制度基础。
2. **民族发展**：推动中华民族由近代以来的衰落走向历史性转变。
3. **阶级关系**：改变旧社会的阶级剥削关系，确立劳动人民的政治主体地位。
4. **生产与创造活力**：调动工人阶级和劳动人民的积极性、创造性，促进社会生产力发展。
5. **国际意义**：被视为世界社会主义运动史上的重要历史成果。
6. **理论意义**：为科学社会主义理论与实践提供新的历史经验。

### 七、选择题常见陷阱

| 说法 | 判断 | 原因 |
| --- | :---: | --- |
| 1949 年新中国成立意味着社会主义改造已经基本完成 | ✗ | 基本完成在**1956 年底** |
| 新民主主义社会是向社会主义过渡的社会 | ✓ | 不是独立稳定的社会形态 |
| 过渡时期社会主义国营经济占有领导地位，个体经济则占数量优势 | ✓ | **领导**与**数量占比**不同 |
| “一化三改”中的“三改”只指农业和手工业改造 | ✗ | 还包括**资本主义工商业** |
| “一化三改”体现社会主义工业化与社会主义改造同时并举 | ✓ | **建设与改造并举** |
| 初级农业生产合作社具有完全社会主义性质 | ✗ | 是**半社会主义性质** |
| 农业和手工业改造的组织形式从第一步起就完全相同 | ✗ | 同为合作化，但名称和组织内容不同 |
| 国家对资本主义工商业的改造只有强制没收一种办法 | ✗ | 采取**国家资本主义形式与和平赎买** |
| 全行业公私合营实行定股定息 | ✓ | 注意与**四马分肥**区别 |
| 社会主义基本制度确立意味着中国已越过社会主义初级阶段 | ✗ | 当时**进入**社会主义初级阶段 |

### 八、考研自测

<Accordions>
  <Accordion title="自测一｜新民主主义社会有哪五种经济成分？哪两种是过渡性质？">

社会主义性质的国营经济、半社会主义性质的合作社经济、农民和手工业者的个体经济、私人资本主义经济、国家资本主义经济。其中**合作社经济和国家资本主义经济**具有过渡性质。

</Accordion>
  <Accordion title="自测二｜完整解释“一化三改”，以及建设与改造的关系。">

一化是**社会主义工业化**，三改是对**农业、手工业、资本主义工商业**进行社会主义改造。工业化是主体，三大改造为两翼，体现**社会主义工业化和社会主义改造同时并举**。

</Accordion>
  <Accordion title="自测三｜农业和手工业各有哪些合作化阶段？">

农业：**互助组 → 初级农业生产合作社 → 高级农业生产合作社**。手工业：**手工业供销小组 → 手工业供销合作社 → 手工业生产合作社**。对应社会主义萌芽、半社会主义、完全社会主义三种性质。

</Accordion>
  <Accordion title="自测四｜资本主义工商业改造的形式、方法、步骤是什么？">

通过**国家资本主义**形式，以**和平赎买**进行改造；从**委托加工、计划订货、统购包销、经销代销**等初级形式，发展到**个别企业公私合营**，再到**全行业公私合营**；区别“四马分肥”与“定股定息”。

</Accordion>
  <Accordion title="自测五｜为什么说1956年底是关键节点？">

社会主义改造基本完成，公有制成为经济基础，社会主义基本制度确立，中国社会由新民主主义转为社会主义，进入社会主义初级阶段和全面建设社会主义的新时期。
