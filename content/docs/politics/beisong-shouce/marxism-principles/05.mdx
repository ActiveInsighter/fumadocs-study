# 第五章 资本主义的发展及其趋势

## 专题二十三｜资本主义的基本矛盾与经济危机

<Callout type="info" title="一道题看清四个层次">

- **基本矛盾**：生产社会化与生产资料资本主义私人占有之间的矛盾。
- **危机本质特征**：生产**相对**过剩。
- **危机的一般形式可能性**：货币的流通手段、支付手段职能使买与卖等环节可能分离。
- **危机爆发的根本原因**：资本主义**基本矛盾**。

上述四层分别回答“制度矛盾是什么、危机表现为什么、危机何以可能、根本原因是什么”，不可相互替换。

</Callout>

### 一、资本主义基本矛盾是什么？

**资本主义基本矛盾**是：

> **生产社会化与生产资料资本主义私人占有之间的矛盾。**

理解这个表述应分清两侧：

| 一侧 | 核心特点 | 直观含义 |
| --- | --- | --- |
| **生产社会化** | 生产依赖广泛社会分工、协作和相互联系 | 产品由社会化生产网络共同形成 |
| **资本主义私人占有** | 生产资料及生产成果处在资本主义私人占有关系之中 | 企业主要依照自身资本增殖利益组织生产与经营 |

生产越来越依赖社会范围的协调，但资本主义私人占有和逐利机制使社会总体生产与实现之间可能发生冲突。这一基本矛盾贯穿资本主义生产方式的发展，在经济危机中集中表现出来。

<Callout type="tip" title="与前一专题区分">

在以私有制为基础的商品经济中，**私人劳动和社会劳动的矛盾**是其基本矛盾；这一矛盾在资本主义条件下进一步发展，表现为**生产社会化和生产资料资本主义私人占有的矛盾**。两个提法适用的理论层次不同。

</Callout>

### 二、经济危机的本质：生产相对过剩

资本主义经济危机的本质特征是**生产相对过剩**，而不是物品超过了社会所有人的实际需要。

<Tabs items={['相对过剩', '绝对过剩（错误理解）']}>
  <Tab value="相对过剩">

相对于劳动人民的**有支付能力的需求**而言，市场上部分商品难以按有利于资本再生产的条件售出，导致商品积压、生产收缩等现象。

**重点：不是没人需要，而是有效需求不足以实现商品价值。**

</Tab>
  <Tab value="绝对过剩（错误理解）">

认为社会所有人的实际需要都已经被充分满足，商品在任何意义上都不再需要。

这**不是**教材所说的资本主义经济危机的本质特征。

</Tab>
</Tabs>

**示例：**&#x2060;某社会居民依旧需要住房、衣物和生活资料，但购买能力不足，企业的部分商品难以销售，生产与消费之间出现矛盾。它体现“相对于有支付能力的需求的过剩”，不能据此说社会需要已经完全满足。

### 三、经济危机为什么会产生？

#### 1. 一般形式可能性：货币职能

在以货币为媒介的商品流通中，商品销售与下一次购买在时间和空间上可能分离，债权债务及延期支付关系也可能产生连锁风险。因此，货币的**流通手段**和**支付手段**职能为经济危机提供**抽象的一般的、形式上的可能性**。

<Callout type="warn" title="形式上的可能性不是根本原因">

不能把“使用货币”或“货币具有支付手段职能”，直接写成**资本主义经济危机爆发的根本原因**。它只说明危机在商品货币关系中**何以可能**。

</Callout>

#### 2. 根本原因：资本主义基本矛盾

**根本原因**是**生产社会化与生产资料资本主义私人占有之间的矛盾**，具体呈现为两对矛盾：

| 具体表现 | 要害 | 易错表述 |
| --- | --- | --- |
| **生产无限扩大的趋势**与劳动人民**有支付能力的需求相对缩小**之间的矛盾 | 资本追逐扩张，但商品价值实现受有效需求制约 | 错把“有支付能力的需求”写成“任何实际需要” |
| **个别企业内部生产的有组织性**与**整个社会生产的无政府状态**之间的矛盾 | 企业内部可以有计划组织生产，但社会总体比例关系在资本逐利竞争中可能失衡 | 错把“局部有组织”当成“社会生产整体已经协调” |

**辨析：**&#x2060;教材中的“无限扩大”指资本追求扩张的内在趋势，不是说现实产量在任意时点都无限增长；“有支付能力的需求相对缩小”也不等于所有居民的名义收入必然持续下降。

### 四、经济危机为什么具有周期性？

在马克思主义政治经济学的理论叙述中，经济危机的**周期性**由资本主义基本矛盾运动的**阶段性**决定。

经典再生产周期可概括为：

| 阶段 | 典型表现 | 在周期中的定位 |
| --- | --- | --- |
| **危机** | 商品滞销、生产收缩、资本价值损失等 | **基本阶段** |
| **萧条** | 经济活动低迷、恢复缓慢 | 低谷或停滞阶段 |
| **复苏** | 生产、投资和交易逐渐恢复 | 向扩张过渡 |
| **高涨** | 生产和经营活动趋于活跃 | 扩张阶段 |

<Callout type="tip" title="四阶段不是任何时候都机械齐全">

教材强调**危机阶段是资本主义再生产周期的基本阶段**，但实际经济运行**不一定每次都严格依次、完整经历四个阶段**。答题时抓住“周期性—基本矛盾运动的阶段性—危机是基本阶段”这条链。

</Callout>

### 五、与资本积累、资本循环的联系

- **资本积累**促进资本规模扩大和社会化生产发展，也会使资本主义基本矛盾进一步展开。
- **商品资本售卖阶段**承担剩余价值的实现任务；滞销意味着生产出来的价值与剩余价值难以顺利实现。
- **社会总产品的实现问题**包括价值补偿与实物补偿；宏观比例关系失调会干扰再生产的继续进行。
- **经济危机**在教材中被看作资本主义再生产矛盾的集中爆发和强制性调整，而非资本主义基本矛盾被永久消除。

### 六、选择题速判

| 命题 | 判断 | 理由 |
| --- | :---: | --- |
| 资本主义经济危机的本质特征是生产相对过剩 | ✓ | 相对于有支付能力的需求 |
| 资本主义经济危机的本质是社会需要全部得到满足 | ✗ | 将相对过剩误作绝对过剩 |
| 经济危机的一般形式可能性同货币的流通、支付职能有关 | ✓ | 商品销售、购买及清偿行为可以分离 |
| 经济危机的根本原因是货币作为支付手段 | ✗ | 根本原因是资本主义基本矛盾 |
| 个别企业内部生产有组织性意味着全社会生产有计划性 | ✗ | 局部与社会总体不能混淆 |
| 资本主义经济危机的周期性与基本矛盾运动的阶段性有关 | ✓ | 周期性不是外部偶然事件的简单重复 |

<Accordions>
  <Accordion title="练习：只要某个市场中出现商品积压，就能断定发生了资本主义经济危机吗？">

不能。个别企业或市场的商品积压可能有许多具体原因；**整个资本主义经济危机**是涉及社会再生产运行的系统性现象。做考研概念题时，应抓经济危机的**本质特征、根本原因与周期性**，不要把微观销售不畅等同于全面危机。

</Accordion>
  <Accordion title="练习：危机爆发后，资本主义基本矛盾就被消除了吗？">

不能。按教材分析，危机能够以强制方式暂时调整社会再生产中的某些比例关系，**不能从根本上消除**资本主义基本矛盾，因此危机具有反复出现的可能。

</Accordion>
</Accordions>

## 专题二十四｜垄断资本主义

<Callout type="info" title="本专题知识主线">

**自由竞争 → 生产集中与资本集中 → 垄断形成 → 金融资本与金融寡头 → 垄断利润、垄断价格 → 国家垄断资本主义 → 金融垄断发展和资本国际化。**

高频区别：**资本积累 / 资本积聚 / 资本集中；垄断 / 竞争；垄断利润 / 垄断价格；金融资本 / 金融寡头；国家垄断资本主义 / 国有经济的一般概念。**

</Callout>

### 一、垄断如何在自由竞争中形成？

#### 1. 生产集中与资本集中

<Tabs items={['生产集中', '资本集中', '资本积累与积聚']}>
  <Tab value="生产集中">

生产资料、劳动力和商品生产**日益集中于少数大型企业**的过程。

**直接结果：**&#x2060;大企业在全社会生产中的比重不断提高，少数企业对生产规模及行业活动的影响力增强。

</Tab>
  <Tab value="资本集中">

通过**大资本吞并小资本**，或者**多个资本合并**形成更大的资本。

**关键词：兼并、收购、合并、资本控制权集中。**&#x2060;不应同“把剩余价值留存为资本”的积累混淆。

</Tab>
  <Tab value="资本积累与积聚">

- **资本积累**：剩余价值转化为资本（剩余价值资本化）。
- **资本积聚**：**单个资本**通过积累而逐步扩大其规模。
- **资本集中**：通过已有资本间的**合并、吞并**形成更大的资本。

积累强调资本增殖及再投资，积聚强调同一资本规模成长，集中强调资本在不同所有者之间的重新聚合。

</Tab>
</Tabs>

从理论逻辑看，生产集中、资本集中是资本家追逐剩余价值和竞争发展的结果；当少数大型企业控制重要市场份额时，**自由竞争的发展可引起垄断**。

#### 2. 垄断形成的三个主要原因

1. **生产集中达到较高程度**：少数大型企业容易联合，谋求高额利润。
2. **企业规模巨大**：规模本身对市场准入和竞争形成限制。
3. **避免两败俱伤的竞争**：企业之间可能达成妥协，联合实施垄断。

教材提到的**初级、最简单的垄断组织形式**是**短期价格协定**。

**垄断组织的本质**：利用联合、独占或瓜分商品生产与销售市场，操纵垄断价格，获取高额垄断利润。

<Callout type="warn" title="垄断不等于竞争消失">

**垄断形成后，竞争依然存在，而且竞争具有新的范围和手段。**“垄断彻底消除竞争”是典型错误判断。

</Callout>

### 二、为什么垄断不能消灭竞争？

#### 1. 垄断条件下仍存在竞争的三条原因

- 垄断**没有消除产生竞争的经济条件**。
- 垄断组织为了维持自身地位，仍须在国内外市场上**通过竞争**不断巩固优势。
- 任何垄断组织都不能**包揽整个社会生产**，仍存在组织之间、组织内部或垄断与非垄断企业之间的竞争。

#### 2. 垄断竞争的新特点

| 对比维度 | 自由竞争时期（典型） | 垄断条件下 |
| --- | --- | --- |
| **目的** | 获取更多利润、超额利润 | 获取**高额垄断利润**，维护和扩大垄断地位 |
| **手段** | 主要运用价格、成本等经济手段 | 经济手段之外，还可能运用**非经济手段** |
| **范围** | 主要集中在国内经济领域 | 涉及更多领域，竞争规模扩大并向**国际范围**扩展 |

这里强调资本主义发展阶段的**总体特征**，不能据此理解为自由竞争阶段从未存在国际贸易，或垄断阶段只使用非经济手段。

### 三、金融资本和金融寡头

#### 1. 两者定义与形成

| 概念 | 定义 | 关键词 |
| --- | --- | --- |
| **金融资本** | **工业垄断资本与银行垄断资本相融合**形成的垄断资本 | 两类垄断资本的融合 |
| **金融寡头** | 在金融资本基础上产生、掌握强大经济和政治控制力的少数垄断资本集团 | 控制与支配 |

形成金融资本的主要途径：**金融联系、资本参与、人事参与**。

#### 2. 金融寡头如何实施控制？

<Steps>
  <Step>

**经济控制**：主要通过**参与制**，利用层层持股、控股关系，以一定量自有资本控制更大规模的社会资本。

</Step>
  <Step>

**国家机器控制**：主要通过与政府的**个人联合**，例如重要人员的密切联系与流动。

</Step>
  <Step>

**政策、舆论与社会领域影响**：通过政策咨询机构等影响公共政策，还可能借助新闻、教育、文化等领域的影响力介入公共生活。

</Step>
</Steps>

<Callout type="tip" title="两组标准答案">

- 经济领域的主要手段：**参与制**。
- 对国家机器的主要手段：**个人联合**。

题目若改问“金融资本形成的主要途径”，则应答**金融联系、资本参与、人事参与**；不要把两组答案混合。

</Callout>

### 四、垄断利润与垄断价格

#### 1. 认识垄断利润

- **垄断资本追逐的目标**：获取**垄断利润**。
- **垄断利润**：垄断资本家凭借垄断地位获取的高于平均利润的高额利润。
- **归根到底的来源**：无产阶级和其他劳动人民创造的剩余价值及其再分配。
- **主要实现方式**：垄断组织制定或影响**垄断价格**。

垄断利润的取得主要可以从四类途径理解：

1. 加强对本国无产阶级和其他劳动人民的剥削。
2. 借助垄断高价、低价，转移或取得其他企业尤其是非垄断企业的一部分利润。
3. 通过国际资本扩张，从其他国家劳动人民创造的价值中取得收益。
4. 利用有利于垄断资本的国家收入再分配机制，将一部分社会收入转化为垄断资本收入。

#### 2. 垄断高价与垄断低价

<Tabs items={['垄断高价', '垄断低价']}>
  <Tab value="垄断高价">

垄断组织在**出售商品**时规定的**高于生产价格**的价格。

记忆：**卖得贵**。

</Tab>
  <Tab value="垄断低价">

垄断组织在**购买非垄断企业提供的原材料等生产资料**时规定的**低于生产价格**的价格。

记忆：**买得便宜**。

</Tab>
</Tabs>

#### 3. 垄断价格为什么没有否定价值规律？

<Callout type="info" title="核心：改变价值分配，并非凭空创造价值">

在劳动价值论的框架下，商品价值量的基础仍是**社会必要劳动时间**。垄断能够影响价格形成和价值分配，却不能仅靠抬高价格就增加**全社会新创造的价值总量**。

因此，**垄断价格是价值规律在垄断资本主义阶段的具体表现**，而不是价值规律失效的证据。

</Callout>

在教材的抽象总量分析中，垄断所取得的超额利润主要体现社会价值和剩余价值的重新分配；它不同于生产过程中新创造的价值。教材据此强调，从全社会总体看，价格与价值的相应总量关系仍受价值规律约束。

| 价值规律的不同表现形式 | 价格围绕什么波动？ |
| --- | --- |
| 平均利润形成前 | **价值** |
| 平均利润形成后 | **生产价格** |
| 垄断形成后 | **垄断价格** |

<Callout type="warn" title="高频易混">

“垄断价格**可能长期偏离**价值或生产价格”可以成立；“垄断价格**取消价值决定关系**”则不符合教材逻辑。

</Callout>

### 五、国家垄断资本主义

#### 1. 定义、产生与实质

**国家垄断资本主义**是**国家政权与私人垄断资本相融合**的垄断资本主义形式。

其产生是科技进步和生产社会化发展、资本主义基本矛盾进一步展开的结果，通常涉及：

- 社会生产力发展要求更大范围的资本组织和资源协调。
- 经济波动与危机加深，推动国家干预经济活动。
- 协调利益关系、缓和社会矛盾的需要。

**实质**：在资本主义社会制度框架内，私人垄断资本借助国家机器服务资本增殖和垄断统治。

#### 2. 五种主要形式

| 形式 | 识别线索 |
| --- | --- |
| **国家所有并直接经营的企业** | 国家直接经营企业 |
| **国家与私人共有、合营的企业** | 国家与私人资本共同持有企业 |
| **国家以多种形式参与私人垄断资本的再生产** | 财政、信用、合同等对私人资本再生产的参与 |
| **宏观调节** | 面向总需求、增长、就业等总体经济运行的调节 |
| **微观规制** | 面向特定企业、行业和市场行为的规范与限制 |

<Callout type="tip" title="不能简单把国家垄断资本主义等同于一切国有企业">

这一范畴具有**特定的资本主义社会关系前提**。单凭“国家持股”“国家经营企业”这两个字面特点，不能脱离社会制度、资本关系直接认定所有国家的国有经济都是国家垄断资本主义。

</Callout>

#### 3. 它解决了资本主义基本矛盾吗？

**没有从根本上解决。**&#x2060;国家干预能够在一定阶段促进协调和调整，国家垄断资本主义也可能缓和部分冲突，但**不会改变资本主义制度的基本性质**，不能消除生产社会化与资本主义私人占有的矛盾。

### 六、金融垄断资本的新发展

#### 1. 形成条件与表现

教材将**金融自由化与金融创新**概括为金融垄断资本形成、壮大的重要制度条件。金融化发展体现在：

1. 金融寡头及金融组织结构变化：传统大型银行之外，**非银行金融机构**的影响扩大。
2. 衍生金融工具、金融市场和资产交易扩展，金融资本的运作方式更加复杂。
3. 金融部门在资本主义经济的利润分配及资源控制中作用上升。
4. 部分资本从实体生产领域流向金融市场，可能形成**虚拟经济与实体经济脱节**的风险。
5. 金融垄断力量对经济决策、财富分配及政治领域的影响增强。

<Callout type="info" title="如何理解‘金融化’这一教材概括？">

它说明金融活动与金融资本在资本主义经济中的作用更突出。考研题目按**金融自由化、金融创新、金融垄断资本壮大及其风险**的知识链掌握即可；不宜把教材的阶段性描述机械理解为所有国家、所有时期都以完全相同的速度和比例变化。

</Callout>

#### 2. 金融垄断资本发展的潜在后果

- 金融业利润和资产规模扩张，金融资本影响力增强。
- 实体部门与金融部门之间的资源分配可能失衡，**过度金融化**加大经济脆弱性。
- 经济权力集中还可能借助政治渠道扩大其影响。

此处的“金融资本”和“金融垄断资本”属于**资本主义发展阶段**的理论概念；不要把一切现代金融活动等同于金融垄断。

### 七、垄断资本向世界范围扩展

#### 1. 国际扩张的经济动因

| 动因 | 具体目的 |
| --- | --- |
| **资本输出** | 将国内过剩资本投向国外，追逐更高利润 |
| **技术转移** | 将部分非核心技术转至国外，在海外维持或获得竞争优势 |
| **开拓市场** | 争夺国际商品销售市场 |
| **资源保障** | 争取原料、能源的稳定来源 |

#### 2. 国际扩张的三种基本形式

| 形式 | 理解关键词 | 例子（示意） |
| --- | --- | --- |
| **借贷资本输出** | 国际借贷、资金有偿使用 | 向海外主体提供商业贷款 |
| **生产资本输出** | 对外直接生产投资 | 在海外建设工厂 |
| **商品资本输出** | 对外销售商品、实现商品价值 | 向海外市场出口成品 |

**辨析：**&#x2060;不能把“资本输出”简单等同于“商品出口”。两者在资本国际扩张的划分中分别涉及不同的职能资本形式。

#### 3. 国际垄断组织与国际经济调节机制

教材列举的相关形式包括：

- **国际垄断同盟**：早期代表有**国际卡特尔**（例如国际钢铁卡特尔）；当代还有国家垄断资本主义的国际联盟等更复杂形式。
- **国家间组织和区域联合**：教材以**七国集团（G7）、欧洲联盟（EU）**&#x2060;等说明当代国际经济协调与垄断资本关系的不同层面。
- **国际经济调节机制**：国际经济组织、国际经济协议和地区性经济组织，如**国际货币基金组织、世界银行、世界贸易组织**等。

<Callout type="warn" title="组织类别须辨清分析层次">

**国际卡特尔**是企业之间的垄断联合；**G7、欧盟、IMF、世界银行、WTO**则涉及政府间协调或国际经济治理，**不是同一种法律和组织形态**。本书在讨论国际垄断与经济调节时并列举例，不表示它们在性质、职权或成员结构上等同。

</Callout>

### 八、整合速记与经典干扰项

| 说法 | 判断 | 解析 |
| --- | :---: | --- |
| 资本集中是多个资本合并或大资本吞并小资本 | ✓ | 重在已有资本的重新集中 |
| 垄断会彻底消除竞争 | ✗ | 经济条件未消失，竞争手段与范围变化 |
| 金融资本由工业垄断资本与银行垄断资本融合形成 | ✓ | 这是教材定义 |
| 金融寡头控制经济主要通过参与制 | ✓ | 经济控制手段 |
| 金融寡头控制国家机器主要通过参与制 | ✗ | 主要通过**个人联合** |
| 垄断利润主要通过垄断价格来实现 | ✓ | 垄断价格是主要实现方式 |
| 垄断价格意味着价值规律已经失效 | ✗ | 价值规律的表现形式变化 |
| 国家垄断资本主义从根本上消除了资本主义基本矛盾 | ✗ | 资本主义性质未改变 |
| 金融创新、金融自由化与金融垄断资本发展有关 | ✓ | 教材列出的重要制度条件 |
| 垄断资本国际扩张只表现为商品出口 | ✗ | 还有借贷资本、生产资本输出 |

<Accordions>
  <Accordion title="练习：一家大公司收购数家竞争对手，主要体现资本积累还是资本集中？">

从**资本相互合并、吞并**的角度，首先体现**资本集中**。若题目强调将剩余价值重新投入经营扩大资本，则侧重**资本积累**；二者现实中可能同时发生，但概念判据不同。

</Accordion>
  <Accordion title="练习：出现少数大型企业后，价格是否必然由市场以外的力量任意决定？">

不是。垄断组织可以影响价格形成，部分垄断价格会偏离生产价格，但其盈利及价值分配仍受生产、竞争、需求及价值规律等条件制约。**垄断不能使价值规律消失**。

</Accordion>
  <Accordion title="练习：国家加强经济干预，是不是说明垄断资本主义性质根本改变了？">

不是。按教材，国家垄断资本主义是资本主义制度内的一种调整发展形式，**基本经济关系和基本矛盾没有从根本上改变**。

</Accordion>
</Accordions>

<Callout type="info" title="下一专题：经济全球化">

垄断资本的国际扩张是理解现代世界经济联系的一条线索，但**经济全球化不是垄断资本输出的简单同义词**。下一专题重点掌握生产、贸易、金融全球化及其动因。

</Callout>

## 专题二十五｜经济全球化

<Callout type="info" title="本专题必背框架">

**三种表现：生产全球化、贸易全球化、金融全球化。**

**三类动因：科学技术进步与生产力发展（物质基础、根本推动力）→ 跨国公司发展（企业组织形式）→ 经济体制变革与国际经济组织发展（体制、组织保障）。**

</Callout>

### 一、经济全球化是什么？

在考研政治的理论语境中，经济全球化可以理解为：随着生产力发展与国际分工深化，商品、服务、生产活动、资本等在世界范围的联系、交换与配置不断加强，各国经济的相互依存程度上升。

它是**生产力发展和社会化大生产的客观要求**。学习时应把握“经济活动跨国联系加强”的共同特征，而不应将它限定成“只有商品进出口增加”。

<Callout type="tip" title="本专题原文范围">

原资料在本专题主要集中讲解**三种表现、三项动因**，并提醒不要把当今各种国际问题都归因于经济全球化。本整理版在忠实保留这些知识点的基础上添加理解示例和概念对比；拓展说明不视为原书新增考点。

</Callout>

### 二、经济全球化的三种表现

<Tabs items={['生产全球化', '贸易全球化', '金融全球化']}>
  <Tab value="生产全球化">

生产过程的不同环节和生产要素在**多个国家之间分布和协作**，形成跨国生产网络和国际产业分工。

**示例：**&#x2060;某产品由多个国家分别完成研发、零部件制造、装配和物流，体现生产过程的全球性组织。

**识别词：**&#x2060;国际分工、跨国生产链、全球价值链、海外生产基地。

</Tab>
  <Tab value="贸易全球化">

商品和服务的跨境交易不断扩展，不同国家之间的市场联系深化。

**示例：**&#x2060;产品通过国际贸易在多国市场销售，进口原材料、出口制成品等跨国交易更加紧密。

**识别词：**&#x2060;跨境贸易、国际市场、国际商品和服务交换。

</Tab>
  <Tab value="金融全球化">

资金、金融交易和金融机构的跨境联系增强，资本在国际金融市场上流动。

**示例：**&#x2060;跨境融资、国际证券投资、银行跨国经营与国际支付网络的发展。

**识别词：**&#x2060;国际资本流动、跨境融资、国际金融市场、全球金融联系。

</Tab>
</Tabs>

| 典型案例 | 最直接体现 |
| --- | --- |
| 不同国家共同承担一个产品的设计、零部件制造和组装 | **生产全球化** |
| 一国企业把产品卖到世界多个市场 | **贸易全球化** |
| 企业或金融机构跨境融资、国际证券投资 | **金融全球化** |

<Callout type="warn" title="三者相互联系，但考点仍须按活动性质区分">

跨国公司在海外建厂，主要体现**生产活动跨国布局**；如果题目描述其商品跨境销售，则体现**贸易全球化**；如果强调跨境信贷与融资，则体现**金融全球化**。同一企业可能同时参与三者，但判断题材应抓住**直接描述的行为**。

</Callout>

### 三、经济全球化的三类动因

#### 1. 科学技术进步与生产力发展：物质基础和根本推动力

科学技术进步降低跨国沟通、组织与运输的障碍，提高跨区域合作与分工的可能性；尤其是信息技术革命，使全球生产和交易联系更紧密。

教材定位：**科学技术的进步和生产力的发展，为经济全球化提供坚实的物质基础和根本推动力。**

#### 2. 跨国公司发展：企业组织形式

跨国公司能够在不同国家之间配置资本、技术、劳动力和其他资源，组织跨境生产、采购及营销，推动国际分工和生产要素流动。

教材定位：**跨国公司的发展，为经济全球化提供适宜的企业组织形式。**

#### 3. 经济体制变革与国际经济组织发展：制度与组织保障

各国经济体制的调整以及国际经济组织、合作安排的发展，能够为跨国贸易、投资及经济联系提供制度、规则和组织性协调。

教材定位：**各国经济体制的变革和国际经济组织的发展，是经济全球化的体制与组织保障。**

| 动因 | 对应作用 | 题目抓词 |
| --- | --- | --- |
| **科技进步与生产力发展** | **物质基础、根本推动力** | 技术、生产力、信息革命 |
| **跨国公司发展** | **适宜的企业组织形式** | 跨国企业、全球生产布局 |
| **经济体制变革与国际组织发展** | **体制与组织保障** | 体制、组织、制度与规则 |

<Callout type="warn" title="选项陷阱：不要互换‘根本推动力’和‘组织形式’">

问“经济全球化的根本推动力”，首选**科学技术进步和生产力发展**；问“适宜的企业组织形式”，选**跨国公司**。跨国公司的重要性不意味着它是世界经济一切发展的唯一原因。

</Callout>

### 四、如何正确认识经济全球化与国际经济问题？

本专题原资料特别强调：**当今困扰世界的许多问题，并不能简单归咎于经济全球化本身。**

例如，教材将国际金融危机的成因特别联系到**金融资本过度逐利和金融监管严重缺失**，反对把金融危机机械描述为“经济全球化发展的必然产物”。

为了把这一点学透，可以区分三个层次：

1. **全球化本身是什么？**——各国生产、贸易和金融的跨国联系深化。
2. **全球化过程中可能出现什么问题？**——风险跨境传导、产业链相互依赖、不同主体利益分配不均衡等可能性。
3. **某次危机为什么发生？**——需要研究具体的资本运动、监管条件、金融结构与经济背景，不能用“因为全球化”四个字代替原因分析。

<Callout type="info" title="辨析：联系增强 ≠ 所有问题的直接原因">

全球化可能改变风险传播的范围与速度，但**传播渠道**、**制度诱因**和**根本原因**不是同一概念。答题时看到“全部由经济全球化导致”“只要全球化就必然引起国际金融危机”等绝对化表述，要重点审查。

</Callout>

### 五、与前后专题的联系（拓展理解）

| 对接知识 | 联系 |
| --- | --- |
| **商品经济和价值规律** | 跨境贸易扩大了商品交换的空间，不能因此认为商品经济的一般规律自动消失 |
| **剩余价值理论与资本积累** | 资本逐利和积累是分析资本跨国扩张的重要线索，但不等同于经济全球化的全部动因 |
| **垄断资本主义** | 资本国际化、跨国垄断组织影响全球经济联系，却不能把所有全球化主体都归入垄断资本 |
| **当代资本主义的新变化** | 技术进步、金融化和生产组织形式演变，使全球经济联系呈现新特征 |

以上为帮助理解而增补的知识衔接，不替代本专题原有的**表现与动因**两组核心考点。

### 六、选择题速判与自测

| 说法 | 判断 | 理由 |
| --- | :---: | --- |
| 经济全球化是生产力发展和社会化大生产的要求 | ✓ | 理论总定位 |
| 经济全球化仅仅意味着国际商品贸易增加 | ✗ | 还表现为生产、金融全球化 |
| 科技进步和生产力发展为经济全球化提供根本推动力 | ✓ | 物质基础与根本动力 |
| 跨国公司提供经济全球化适宜的企业组织形式 | ✓ | 促进生产要素跨国流动 |
| 国际经济组织的发展提供一定组织保障 | ✓ | 不是根本推动力的同义词 |
| 国际金融危机必然由经济全球化本身造成 | ✗ | 不能把具体危机的原因一概归咎于全球化 |

<Accordions>
  <Accordion title="练习 1：一家企业在全球多个国家设厂组装产品，主要体现哪种全球化？">

**生产全球化。**&#x2060;材料强调在不同国家组织生产活动；如果改为强调出口销售，则侧重**贸易全球化**。

</Accordion>
  <Accordion title="练习 2：什么因素为经济全球化提供根本推动力？">

**科学技术的进步和生产力的发展**。跨国公司对应**企业组织形式**；各国经济体制变革和国际经济组织发展对应**体制与组织保障**。

</Accordion>
  <Accordion title="练习 3：国际金融危机是否可以只归因于经济全球化？">

**不能。**&#x2060;按教材的论述，金融资本过度逐利、金融监管严重缺失等具体因素更能解释相关危机的形成；经济全球化与危机的传导环境有关，不等于所有危机的必然成因。

</Accordion>
</Accordions>

<Callout type="info" title="一页速记">

**表现三项：**&#x2060;生产 / 贸易 / 金融。

**动因三项：**&#x2060;科技生产力（根本推动力） / 跨国公司（组织形式） / 经济体制与国际组织（保障）。

**判断原则：**&#x2060;不要把经济全球化等同于一切国际经济问题的根本原因。

</Callout>

## 专题二十六｜正确认识当代资本主义的新变化

<Callout type="info" title="考点总览｜五方面变化、四项原因、两个层次">

- **二战后变化的五方面**：生产资料所有制；劳资关系和分配关系；社会阶层和阶级结构；经济调节机制与经济危机形态；政治制度。
- **变化的四项原因**：科学技术革命和生产力发展（**根本推动力量**）；工人阶级的斗争；社会主义制度初步显示的优越性；改良主义政党的改革。
- **判断变化的实质**：变化是资本主义生产方式的自我调节，**没有改变其制度本质、基本矛盾和马克思主义关于资本主义基本论断的科学性**。
- **当代新特征**：数字化与智能化、国际金融垄断、阶级结构复杂化，以及发达资本主义国家对外推行霸权主义和强权政治的有关表现（均按教材理论框架把握）。

</Callout>

### 一、第二次世界大战后资本主义发生了哪些变化？

#### 1. 生产资料所有制的变化

<Tabs items={['国家资本所有制', '法人资本所有制', '二者辨析']}>
  <Tab value="国家资本所有制">

**国家资本所有制形成并发挥重要作用。**&#x2060;国家以资本所有者、经营者或管理者等身份参与经济活动，反映现代资本主义所有制形式的调整。

考试抓词：**国家资本、政府持有资本、国家参与经济活动**。

</Tab>
  <Tab value="法人资本所有制">

**法人资本所有制崛起并成为居主导地位的资本所有制形式。**&#x2060;法人组织通过持有股份等方式集中和支配资本，企业所有权及经营管理出现一定程度的分离。

考试抓词：**机构持股、法人持股、股份化、职业经理人**。

</Tab>
  <Tab value="二者辨析">

- **国家资本所有制**突出资本由资本主义国家持有或参与控制。
- **法人资本所有制**突出法人组织作为资本持有者、支配者。
- **二者不能直接等同于社会主义公有制**；判别所有制性质还要联系其所处的社会制度与生产关系。

</Tab>
</Tabs>

<Callout type="warn" title="易错：所有权形式变化 ≠ 所有制社会性质根本改变">

股份分散、机构持股、国家持股等可以改变资本的组织与控制方式，但**仅凭“持股主体改变”不能推断资本主义生产关系已经根本改变**。

</Callout>

#### 2. 劳资关系和分配关系的变化

原资料列出四项典型做法：

| 表现 | 怎样理解 | 关键词 |
| --- | --- | --- |
| **职工参与决策** | 劳动者在一定范围内参与企业决策与管理 | 参与管理 |
| **终身雇佣** | 某些企业、时期采用较长期稳定的雇佣安排 | 雇佣稳定 |
| **职工持股** | 劳动者以持股形式分享部分资本收益 | 股权激励 |
| **社会福利制度普及化、全民化** | 社会保障、福利政策覆盖面和保障方式出现变化 | 社会福利 |

以上是教材概括的**战后发展中的典型变化**，不意味着所有资本主义国家在任何时期都实施了完全相同的制度，也不意味着劳动与资本的利益矛盾因此消失。

#### 3. 社会阶层和阶级结构的变化

1. **传统资本家的地位与作用变化**：大公司中拥有所有权的资本家，通常不再直接负责日常经营管理。
2. **高级职业经理人的作用增强**：成为大公司经营管理的实际控制者或主要执行者。
3. **知识型、服务型劳动者数量增加**：劳动方式随技术进步和产业结构变化而调整。

**区分两个不同问题：**“谁拥有资本”和“谁日常经营企业”。职业经理人掌握管理职能，不等于企业所有权关系或资本主义生产关系已被取消。

#### 4. 经济调节机制和经济危机形态的变化

##### 经济调节机制

- 二战后，国家干预经济的程度和方式发生调整。
- **20 世纪 70 年代起**，伴随资本主义经济滞胀及新自由主义思潮扩展，西方一些国家转向更强调**市场调节、弱化部分政府干预**的政策取向。

<Callout type="tip" title="时间线辨析">

**战后资本主义有国家干预增强的阶段，也有市场化政策加强的阶段。**&#x2060;不要把其中某一阶段的政策取向说成全部时期、所有国家不变的模式。

</Callout>

##### 经济危机形态的新表现

| 教材所列现象 | 关键含义 |
| --- | --- |
| 去工业化、产业空心化 | 部分制造业收缩、产业竞争力受到影响 |
| 经济高度金融化 | 金融及虚拟经济与实体经济的脱节风险 |
| 财政严重债务化 | 债务负担及债务危机问题 |
| 两极分化与社会对立加剧 | 收入、财富与利益分化问题 |
| 增长乏力 | 周期性危机与结构性危机交织 |
| 金融危机频发 | 金融市场震荡及跨境传导风险 |

这里列出的是原书对当代资本主义危机形态的归纳，具体国家、时期的严重程度需要结合事实材料判断；这些变化**不等于经济危机的根本原因发生变化**。

#### 5. 政治制度的变化

教材列举：

- 政治制度出现**多元化趋势**，公民权利有所扩大。
- **法治建设加强**，以协调社会各阶级、阶层之间的利益。
- **改良主义政党**在政治舞台上的影响有所扩大。

考试常要求将“**制度运行与权利安排有所调整**”和“**资本主义政治制度的阶级性质根本改变**”区分开。

### 二、这些变化为什么发生？

| 原因 | 具体作用 | 考查定位 |
| --- | --- | --- |
| **科学技术革命和生产力发展** | 推动产业结构、生产组织、劳动方式、所有制组织形式调整 | **根本推动力量** |
| **工人阶级争取权利和利益的斗争** | 促使劳资关系、劳动保障及利益分配作出一定调整 | 社会斗争力量 |
| **社会主义制度初步显示的优越性** | 对资本主义国家的经济社会政策调整形成一定影响 | 外部制度影响 |
| **改良主义政党的改革** | 借助政策与制度改革协调利益冲突 | 政治改革因素 |

<Callout type="warn" title="定位题：不能把四项原因任意互换">

题目问**根本推动力量**，对应**科学技术革命和生产力的发展**；问社会保障和劳资关系调整，工人阶级争取利益的斗争也是重要因素。多项原因可以共同作用，但不同概念的**地位**并不相同。

</Callout>

### 三、变化的实质：为什么仍然属于资本主义？

<Steps>
  <Step>

**从原因看：**&#x2060;资本主义生产方式为适应生产力发展要求，在社会发展规律和资本主义经济规律作用下不断进行自我调节。

</Step>
  <Step>

**从范围看：**&#x2060;这些变化总体仍发生在资本主义制度的基本框架内。

</Step>
  <Step>

**从性质看：**&#x2060;生产关系的局部调整、管理方式变化和政策改革，不意味着资本主义生产关系根本性质改变。

</Step>
</Steps>

**三个“没有”要完整记忆：**

1. **没有改变资本主义制度的本质。**
2. **没有克服资本主义的基本矛盾。**
3. **没有改变马克思主义关于资本主义基本论断的科学性。**

这三个结论在教材的马克思主义理论分析框架内成立，考试应按其准确措辞把握。切忌把“发生新变化”直接推成“基本矛盾已经消失”。

### 四、当代资本主义变化呈现哪些新特征？

#### 1. 科技创新加速生产方式变化

可归纳为三层：

- **产业结构调整**：数字技术、智能化发展影响产业构成。
- **生产组织和劳动形式变化**：生产、协作和管理方式调整。
- **新经济形态出现**：新技术与资本组织结合，催生新的经营和交易形态。

概念定位：科技创新**推动生产方式变化**，但“技术变化”不直接等于“社会制度性质变化”。

#### 2. 国际金融垄断资本主义的影响日益显现

教材强调：**国际金融资本的垄断**是当代资本主义**最突出、最鲜明、最主要的特征**，重点记住三个表现：

| 表现 | 关键词 | 理解 |
| --- | --- | --- |
| **金融垄断寡头化** | 寡头、金融控制 | 金融资源与控制力向少数主体集中 |
| **金融垄断国际化** | 跨境、国际金融 | 金融资本在世界范围内组织与运作 |
| **经济虚拟化、产业空心化** | 金融化、脱实向虚 | 金融活动与实体生产之间可能出现失衡 |

> 注意："国际金融垄断资本主义"是这一理论专题对当代资本主义发展特点的归纳；分析具体经济问题，仍需要研究可核实的产业、金融与制度事实。

#### 3. 社会阶级、阶层结构复杂化、多样化

新型劳动方式、专业分工和职业类型使社会结构更加复杂，但不能由“职业分类更加丰富”推出“阶级和利益矛盾自然消失”。

#### 4. 发达资本主义国家推行霸权主义和强权政治的有关表现

原书从以下方面概括：

- **金融优势**：利用金融资本和相关市场支配力影响国际投资、生产、流通、交换与贸易。
- **文化传播优势**：利用文化产业和传播媒介输出价值观念。
- **知识产权和信息技术优势**：通过技术壁垒、信息资源不均衡形成所谓“信息鸿沟”“数字鸿沟”“技术鸿沟”。
- **国际政治影响力**：借助集团政治和国际组织等渠道干预国际事务。

<Callout type="info" title="答题边界">

这里是教材对**某类国际权力关系及其批判**的概括，不是对任何单一国家、所有企业或所有跨国合作活动的无差别判断。若题目给出具体事例，应分别判断其是否涉及金融、文化、技术或政治影响力。

</Callout>

## 专题二十七｜资本主义的历史地位和发展趋势

<Callout type="info" title="核心论证：基本矛盾 → 历史局限 → 历史趋势">

**生产社会化与生产资料资本主义私人占有之间的矛盾**，是理解资本主义历史局限性及其发展趋势的主线。

本专题要区分：**资本主义在历史上发挥过推动生产力发展的作用**（历史进步性）与**资本主义生产关系存在历史局限**（历史过渡性）；更要区分**历史趋势判断**与**具体时间表预测**。

</Callout>

### 一、如何理解资本主义的历史地位？

资本主义不是脱离历史条件的、始终不变的制度。依据历史唯物主义，社会生产方式应当放到**生产力与生产关系的矛盾运动**中考察。

- **历史进步性（知识衔接）**：与封建社会的生产方式相比，资本主义推动了社会生产力发展、社会化大生产扩大和世界市场形成。
- **历史局限性（本专题重心）**：随着生产社会化深入，资本主义私人占有关系与生产力发展的矛盾更为突出，暴露其历史过渡性。

<Callout type="tip" title="注意原资料的重心">

原资料在这个专题中**重点讲政治制度局限、资本主义局限和社会主义代替资本主义的历史必然性**；“历史进步性”部分只是根据相邻知识作出的必要衔接，并非额外虚构原书条目。

</Callout>

### 二、资本主义政治制度的四项局限性

教材在阶级分析框架下列出四项：

| 序号 | 教材所概括的局限性 | 考题抓词 |
| --- | --- | --- |
| 1 | 资本主义民主受金钱及资产阶级精英利益影响 | 金钱操纵、精英统治 |
| 2 | 法律形式上的平等可能掩盖实际的不平等 | 形式平等、事实不平等 |
| 3 | 资本主义政党制服务于资产阶级统治的维系 | 政党制、阶级性质 |
| 4 | 政党恶斗与相互掣肘影响决策效率，可能激化社会矛盾 | 政党纷争、决策效率 |

<Tabs items={['形式平等与实际平等', '政党竞争与制度性质']}>
  <Tab value="形式平等与实际平等">

**形式平等**强调法律赋予主体相同的权利资格；**实际平等**还涉及资源、条件与社会经济地位等方面。

本课程的考点并非否认法律平等的重要性，而是提醒：**仅凭法条中的平等承诺，不能直接推断现实条件已经完全平等**。

</Tab>
  <Tab value="政党竞争与制度性质">

政党轮替、选举竞争、政策调整可能改变**政治运行方式**，却不必然改变**制度的经济基础和阶级属性**。这是教材所强调的制度层次与政策层次的区分。

</Tab>
</Tabs>

### 三、资本主义生产方式的三项历史局限性

#### 1. 基本矛盾对生产力发展的制约

随着生产社会化程度不断提高，生产活动越来越依赖社会分工与协作，但生产资料仍采取资本主义私人占有形式。教材认为，这一**基本矛盾**会制约生产力进一步发展，并表现为不同层面的经济冲突。

#### 2. 财富占有两极分化与经济危机

资本的积累和资本主义分配关系，会引起财富和收入占有的分化；生产与有支付能力的需求之间的矛盾，也与**生产相对过剩的经济危机**相联系。

> **复习链接：**&#x2060;上一批专题二十三已经明确，资本主义经济危机的**本质特征**是生产相对过剩，**根本原因**是资本主义基本矛盾。不要混淆“表现”“直接诱因”和“根本原因”。

#### 3. 资产阶级对经济、政治运行的支配与社会冲突

教材从生产关系与国家政治关系出发，指出资本所有者对经济及政治运行的影响，会与不同社会群体的利益诉求发生矛盾，从而加剧社会冲突。

**综合结论：**&#x2060;这三方面的局限性，体现了资本主义生产方式的**历史过渡性**。

### 四、为什么说资本主义为社会主义所代替具有历史必然性？

<Steps>
  <Step>

**基本矛盾是根本依据。**

生产社会化与生产资料资本主义私人占有的矛盾内含资本主义社会多方面冲突。按照教材论证，社会主义生产方式的建立，旨在从生产关系层面解决这一矛盾。

</Step>
  <Step>

**资本积累使基本矛盾继续发展。**

资本积累推动生产集中、资本集中和生产社会化进一步发展，也可能使原有的生产关系矛盾更为突出。这构成资本主义历史过渡性的经济逻辑。

</Step>
  <Step>

**国家垄断资本主义提供资本社会化的更高形式。**

教材认为国家垄断资本主义使资本的组织和社会化程度上升，因而可被看作向更高社会生产方式发展的某种历史条件，即所谓&#x2060;**“社会主义的前奏”**。

</Step>
  <Step>

**阶级矛盾与斗争构成重要社会力量。**

资产阶级和无产阶级之间的利益矛盾与斗争，是马克思主义分析资本主义发展趋势的重要社会政治线索。

</Step>
</Steps>

<Callout type="warn" title="警惕把“历史必然性”误读为“短期自动发生”">

**历史发展趋势 ≠ 每个国家同一时间完成制度转变 ≠ 不需要现实条件和社会实践。**

这里讲的是历史唯物主义的趋势性论断，并不是为资本主义何时结束提供日历、倒计时或线性路线图。下一专题将进一步解释社会发展道路的**长期性、多样性**。

</Callout>

### 五、四个容易混淆的判断维度

| 维度 | 该问什么？ | 不要误写成 |
| --- | --- | --- |
| **生产力** | 社会化大生产是否发展、劳动生产率如何变化 | 生产力发展本身等于制度更替 |
| **生产关系** | 生产资料归谁占有、资本与劳动如何联系 | 股份制、经理制变化必然消灭基本矛盾 |
| **政治制度** | 政治运行方式、利益协调机制如何调整 | 有政治改革即已改变制度阶级性质 |
| **历史趋势** | 基本矛盾将怎样推动长期变化 | 制度转换可以机械预测具体日期 |

### 六、选择题辨析与巩固

| 命题判断 | 结论 | 解析 |
| --- | :---: | --- |
| 资本主义在历史上推动过生产力发展 | ✓ | 肯定历史进步性，不代表否认历史局限性 |
| 资本主义生产关系的历史局限与其基本矛盾有关 | ✓ | 本专题的主线 |
| 法律形式上的平等足以保证现实生活中一切方面完全平等 | ✗ | 形式与实际不能简单等同 |
| 资本主义经济危机的本质是生产绝对过剩 | ✗ | 应为**生产相对过剩** |
| 资本积累能够推动生产社会化并激化资本主义基本矛盾 | ✓ | 本专题的第二条论证 |
| 国家垄断资本主义的出现意味着资本主义基本矛盾被彻底消除 | ✗ | 自我调节不等于消除基本矛盾 |
| 历史发展趋势一经揭示，就能准确推算制度更替的具体年份 | ✗ | 必然性不等于具体时间确定性 |

<Accordions>
  <Accordion title="自测一｜为什么资本主义既有历史进步性，又有历史局限性？">

因为一种生产方式可以在一定历史条件下推动生产力发展；当生产力继续进步，原有生产关系又可能与新的发展要求发生矛盾。**不能用静止、孤立的观点看待一种社会制度。**

</Accordion>
  <Accordion title="自测二｜资本主义为社会主义所代替的四条论据是什么？">

**基本矛盾、资本积累、国家垄断资本主义的社会化发展、资产阶级与无产阶级的矛盾和斗争。**

</Accordion>
  <Accordion title="自测三｜“国家垄断资本主义是社会主义的前奏”是否意味着其已是社会主义？">

**不意味着。**&#x2060;教材使用“前奏”来说明其资本社会化程度与未来发展条件的关系，不能因此把**国家垄断资本主义**直接等同于**社会主义公有制或社会主义制度**。

</Accordion>
</Accordions>

<Callout type="info" title="一页速背">

**政治制度四项局限**：金钱与精英影响、形式与事实不平等、政党制的阶级属性、政党纷争。

**资本主义三项局限**：基本矛盾制约生产力、两极分化与经济危机、资产阶级支配与社会冲突。

**替代趋势四条论证**：基本矛盾 → 资本积累 → 国家垄断资本主义的社会化 → 阶级矛盾和斗争。

</Callout>
