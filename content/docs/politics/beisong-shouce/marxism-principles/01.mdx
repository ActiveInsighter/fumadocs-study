# 第一章 世界的物质性及发展规律

## 专题二｜世界的物质性

<Callout type="info" title="知识主线">

**哲学基本问题 → 物质及其客观实在性 → 物质的运动和时空 → 人类实践与世界的物质统一性。** 重点区分“客观存在”与“人的主观认识”。

</Callout>

### 一、哲学的基本问题

哲学的基本问题是**存在和思维的关系问题**，又称物质和意识的关系问题，包含两个方面：

1. **何者为第一性**：物质还是意识是世界的本原？这是区分唯物主义与唯心主义的基本依据。
2. **有无同一性**：思维能否正确反映存在，人能否认识世界？这是区分可知论与不可知论的重要依据。

#### 哲学立场的四组区分

| 问题 | 一种回答 | 另一种回答 |
| --- | --- | --- |
| 世界的本原是什么 | **唯物主义**：物质第一性，意识第二性 | **唯心主义**：意识第一性，物质第二性 |
| 世界能否被认识 | **可知论**：认为世界可以认识 | **不可知论**：否认世界能被认识或被完全认识 |
| 世界怎样存在和发展 | **辩证法**：联系、发展、全面地看问题，强调内部矛盾 | **形而上学**：孤立、静止、片面地看问题，否认内部矛盾的作用 |
| 社会历史由什么决定 | **历史唯物主义**：社会存在决定社会意识 | **历史唯心主义**：社会意识决定社会存在 |

<Callout type="warn" title="不要把不同划分标准混为一谈">

唯物主义与唯心主义对应**世界本原**；辩证法与形而上学对应**世界的存在和发展方式**；历史唯物主义与历史唯心主义对应**社会历史观**。这些不是同一划分维度。

</Callout>

#### 唯心主义的两种表现

<Tabs items={['主观唯心主义', '客观唯心主义']}>
  <Tab value="主观唯心主义">

把**人的感觉、心灵、观念**当作世界本原。识别关键词：心、感觉、个人观念等。

</Tab>
  <Tab value="客观唯心主义">

把独立于具体个人的某种**精神实体或理念**当作世界本原。识别关键词：理、绝对观念等。

</Tab>
</Tabs>

物质和意识的对立，在**何者是第一性、何者是第二性**的问题上具有绝对意义；超出这一范围，二者又存在联系，其对立具有相对性。

### 二、物质及其存在方式

#### 1. 马克思主义的物质范畴

**物质**是不依赖于人的意识而存在，并能为人的意识所反映的**客观实在**。

- **物质的唯一特性**：客观实在性。
- **不等于看得见、摸得着**：磁场等客观存在并不都能被感官直接觉察，可借助仪器认识。
- **认识具有开放性**：已知世界和未知世界都客观存在；随着实践发展，人们能不断扩大对未知世界的认识。按照辩证唯物主义的可知论立场，世界上只有尚未认识之物，没有不可认识之物。
- **哲学物质范畴 ≠ 自然科学物质结构概念**：前者是一般、共性、普遍、抽象；后者是个别、个性、特殊、具体。二者是共性与个性的关系。

马克思主义以前的旧唯物主义，在自然观上通常坚持唯物主义，但没有将唯物主义贯彻到社会历史领域，因而被称为不彻底的“半截子”唯物主义。

#### 2. 物质与运动

**运动是物质的根本属性和存在方式**，物质与运动不可分割。

| 错误设想 | 导向 |
| --- | --- |
| 设想**不运动的物质** | 形而上学观点 |
| 设想**没有物质的运动** | 唯心主义观点 |

#### 3. 运动与静止

| 运动 | 相对静止 |
| --- | --- |
| **绝对的、无条件的** | **相对的、有条件的** |
| 体现变动性 | 体现一定条件下的稳定性 |

相对静止的典型情形：**空间相对位置暂时不变**，或**事物根本性质暂时不变**。二者相互依赖、相互渗透、相互包含，即“动中有静、静中有动”。

相对静止的意义包括：它是事物存在和发展的必要条件，是人们认识、利用事物的前提，是过去运动的结果与未来运动的出发点，也是理解和衡量运动的尺度。

<Callout type="warn" title="两种极端错误">

- 把相对静止绝对化、否认运动：走向**形而上学不变论**。
- 只承认绝对运动、否认相对静止：走向**相对主义诡辩论**，如“人连一次也不能踏进同一条河流”。

</Callout>

#### 4. 物质运动的时间和空间

**时间与空间是运动着的物质的基本存在形式**，具有客观性。没有脱离物质运动的“纯粹”时间和空间，也没有脱离时间、空间的物质运动。

| 维度 | 结论 |
| --- | --- |
| 时间的突出特点 | **一维性**：时间流逝不可逆转 |
| 时空的客观实在性 | **绝对的** |
| 时空的具体特性 | **相对的**，随物质运动状态变化 |
| 具体物质形态的时空 | **有限的** |
| 整个物质世界的时空 | **无限的** |

**时空本身**具有客观性；**时空观念**是人们对时空的认识，会随着认识的发展而变化。不要把两者混淆。常见配对：**绝对—无条件，相对—有条件**。

### 三、实践与世界的物质统一性

#### 1. 物质世界的二重化

人类社会从自然界中分化出来，主观世界从客观世界中分化出来，体现物质世界的二重化。**实践**既是这两组关系发生分化的关键，也是它们实现统一的关键。

自然界中的过程主要自发发生；人类社会则包含人的有目的的实践活动。二者不是截然分开的：人通过实践形成的“人化自然”仍具有客观实在性。

#### 2. 世界物质统一性原理

- **基本原理**：包括自然界和人类社会在内的整个世界，其真正的统一性在于**物质性**。
- **统一与多样性并存**：世界统一于物质，而物质世界具有多样的物质形态和结构层次。
- **理论意义**：世界物质统一性原理是辩证唯物主义最基本、最核心的观点，是马克思主义的基石。

<Callout type="tip" title="考点延伸">

无论是天然自然还是人化自然，都具有客观实在性。人类社会虽然包含思想、文化等精神现象，但作为社会整体仍具有物质性，不能仅因社会中有意识活动便否认社会的物质基础。

</Callout>

### 四、命题分析与经典干扰项

原书统计：**2010 年以来选择题考查 10 次**（原书统计口径）。常考“物质的客观性”和“时空自身与时空观念的区别”。

<Accordions>
  <Accordion title="错误：物质的客观存在要靠人的感知才能获得或确立">

客观实在性**不依赖人的认识和实践水平**。人能否感知、何时发现某个对象，属于认识问题，不决定其是否客观存在。类似“物质世界的客观存在与人的认识水平有关”“特殊情况下物质不再具有客观实在性”均属于错误观点。

</Accordion>
  <Accordion title="错误：时间只是事物运动的主观联想或观念形式">

时间和空间是**客观存在形式**；有关时间与空间的概念、理论和观念才属于认识。不能因人的时空观念变化，就认定时空本身由观念创造。

</Accordion>
  <Accordion title="错误：整个物质世界的时间和空间是有限的">

应区分**具体物质形态的有限性**与**整个物质世界时空的无限性**，不能直接由局部推出整体。

</Accordion>
</Accordions>

## 专题三｜物质与意识的辩证关系

<Callout type="info" title="抓住决定与反作用">

**物质决定意识，意识对物质具有能动反作用。** 发挥主观能动性必须以尊重客观规律为前提，并经由实践作用于客观世界；意识不是脱离物质条件的独立力量。

</Callout>

### 一、物质决定意识

#### 1. 意识的起源

意识既是**自然界长期发展**的产物，也是**社会历史发展**的产物。社会实践，特别是**劳动**，在意识的产生与发展过程中起决定性作用；**语言**是思维的物质外壳和意识的现实形式。

#### 2. 意识的本质

意识是人脑这一特殊物质的机能和属性，是**客观世界的主观映象**。

| 角度 | 核心判断 | 易混点 |
| --- | --- | --- |
| **内容** | 客观的 | 意识的材料最终来源于客观世界 |
| **形式** | 主观的 | 不同主体可以用不同方式反映同一对象 |
| **整体** | 客观内容与主观形式的统一 | 主观形式并不意味着意识能脱离物质而独立存在 |

认识正确或错误、先进或落后，都不意味着意识是头脑凭空生成的：意识仍以客观现实为其反映对象和来源。

<Callout type="tip" title="三个常考判断">

1. **人脑是意识的器官，而不是意识的源泉**；意识的源泉是客观世界。
2. 意识有主观性，但其产生和存在**依赖物质**。
3. 在本书的马克思主义哲学命题框架中，意识与社会实践紧密相联，强调人的主体性；高级动物的感觉和心理、机器的智能表现，不与人的社会意识概念直接等同。

</Callout>

### 二、意识对物质的能动反作用

意识的能动作用集中表现在四个方面：

| 表现 | 如何理解 |
| --- | --- |
| **目的性、计划性** | 人能预先提出活动目标并形成实施计划 |
| **创造性** | 能在已有经验基础上进行加工、综合、想象与理论创新 |
| **指导实践改造客观世界** | 意识通过人的实践活动发挥现实作用 |
| **调控人的行为与生理活动** | 意识可以影响人的行为选择和某些生理过程 |

<Callout type="warn" title="选择题防陷阱">

“意识能够指导实践”不等于“意识可以直接、不经实践改变客观世界”，更不等于“意识决定物质”。

</Callout>

### 三、主观能动性与客观规律性的辩证统一

#### 1. 什么是规律

规律是事物变化发展过程中**本身所固有的、内在的、本质的、必然的联系**。规律与必然性、本质属于同一层次的范畴。

#### 2. 尊重规律与发挥能动性的关系

- **尊重客观规律**，是正确发挥主观能动性的前提。
- **充分发挥主观能动性**，才能在实践中正确认识和利用客观规律。

二者不是非此即彼：否认规律的客观性会滑向主观随意性；忽视人的能动性又不能充分认识和利用规律。

#### 3. 正确发挥主观能动性的前提和条件

1. **从实际出发**是正确发挥主观能动性的前提。
2. **实践**是正确发挥主观能动性的根本途径。
3. 还必须依赖一定的**物质条件和物质手段**。

#### 4. 自然规律与社会规律

| 方面 | 自然规律 | 社会规律 |
| --- | --- | --- |
| **发挥作用的方式** | 作为无意识的力量自发地发挥作用 | 通过具有一定目的和意图的人的活动发挥作用 |
| **表现形式** | 在相同客观物质条件下，可以以相同形式反复表现 | 具有历史性，在不同社会、国家、民族和历史阶段可能表现不同 |
| **共同点** | 不以人的意志为转移，都是内在的、本质的、必然的联系 | 不以人的意志为转移，都是内在的、本质的、必然的联系 |

**规律不由人创造、消灭或任意改变，但可以被认识和利用。** 利用规律时可以通过实践改变其发生作用的具体条件，不等于改变规律本身。

### 四、意识与人工智能

本书从马克思主义哲学视角，将人工智能视为**人的意识能动性的一种特殊表现**，是人的本质力量的对象化和现实化。

<Tabs items={['能够实现的功能', '教材强调的区别']}>
  <Tab value="能够实现的功能">

- 将人的**部分智能活动机器化**。
- 将意识活动的某些环节从人脑活动中抽离出来，物化为机器的物理运动。
- **模拟和扩展**人脑的某些活动。
- 在一定程度上承担某种社会功能。

</Tab>
  <Tab value="教材强调的区别">

原书强调：人工智能不能简单等同于**人的社会性意识与实践主体**，并从以下角度展开：

- 人工智能与人的完整意识不能直接画等号；原书认为不能由机器模拟推出其必然取代或超越人类智能。
- 人类意识包含情感、信念、意志等复杂形式，技术层面的模拟不等于人在社会交往中的真实情感关系。
- 人的社会属性、社会活动中的自主与自觉，不应仅以机器的任务执行能力衡量。
- 自然语言的意义理解和潜意识等问题，具有机器模拟难以完全还原的复杂性。

</Tab>
</Tabs>

<Callout type="info" title="理解教材与技术判断的边界">

以上“能够做什么、不能做什么”是**原书的哲学论述和考试表述口径**。尤其“永不可能超越人类智能”等对未来技术的绝对性预测，并非已由科学证明的定论；复习时宜把重点放在**人的意识具有社会实践属性**，而不是将所有技术判断当作永恒结论。

</Callout>

### 五、命题分析与易错辨析

原书统计：**2010 年以来选择题考查 7 次**（原书统计口径）。关键是识别“决定”“依赖”“取决于”“任意”“随意”等词。

<Accordions>
  <Accordion title="错误：人的意识取决于语词含义的改变">

语言是思维的物质外壳，但不能把语言符号的变化当作决定意识内容的根源。意识来源于客观世界，并在实践中形成发展。

</Accordion>
  <Accordion title="错误：认识的反复性和无限性决定客观事物的复杂性">

因果顺序颠倒。客观事物的复杂性及实践、认识条件等因素，制约着认识过程；不能让认识特征反过来决定客观事物本身。

</Accordion>
  <Accordion title="错误：自然规律依靠人的活动才能存在和发挥作用">

自然规律不以人的活动为存在前提；不能把通过人的目的性活动实现的社会规律与自然规律的作用方式混同。

</Accordion>
  <Accordion title="错误：人能随意创造、消灭、修改既有自然规律">

规律是客观联系，不能人为任意创造、消灭或修改。人可以认识规律、利用规律，并通过实践改变规律发生作用的条件。

</Accordion>
  <Accordion title="错误：社会规律没有重复性，或者与自然规律一样完全盲目地起作用">

社会规律同样具有客观性，在一定条件下也具有规律性的重复表现，但其实现方式体现人的有意识活动，而且具体表现具有历史性。

</Accordion>
  <Accordion title="错误：规律由多数人的意志决定；科学研究可以任意改变物质的性质和结构">

多数人的意志不能决定规律是否存在；科研能够依照客观条件改变物质的具体状态、结构或性质，却不能以任意方式摆脱客观规律制约。

</Accordion>
</Accordions>

## 专题四｜事物的普遍联系和变化发展

<Callout type="info" title="核心结论">

**联系和发展的观点是唯物辩证法的总观点**，集中体现唯物辩证法的总特征。常考两类判断：联系是否客观、普遍但又有条件；一个事物是否真正属于新事物。

</Callout>

### 一、联系的四个特征

| 特征 | 基本含义 | 命题关键词 |
| --- | --- | --- |
| **客观性** | 联系是事物本身所固有的，不以人的意志为转移 | 不能认为联系都是人的意志赋予 |
| **普遍性** | 事物内部要素相互联系；每个事物与其他事物处在一定联系中；整个世界是普遍联系的整体 | 普遍联系不等于任意两个事物都有直接联系 |
| **多样性** | 联系有直接与间接、内部与外部、本质与非本质、必然与偶然等形式 | 注意多种具体联系并存 |
| **条件性** | 条件会支持或制约事物发展与人的活动；条件能够改变，但改变须尊重客观规律 | 可以创造条件，不等于任意建立联系 |

#### 自在事物的联系与人为事物的联系

- **自在事物的联系**：在人产生之前已经存在，或处在人的活动之外，具有客观性。
- **人为事物的联系**：通过人的实践活动建立，带有人化特点；但其形成的客观根据和建立后的实际联系仍具有客观性。

<Callout type="warn" title="判断题陷阱">

“人为事物的联系”**不意味着**“所有联系都是人为的”，也不意味着“人为建立的联系没有客观性”。创造联系的现实条件必须客观存在，并受规律制约。

</Callout>

### 二、发展是什么

#### 1. 发展的实质

发展是事物变化过程中**前进的、上升的运动**，其实质是**新事物的产生和旧事物的灭亡**。

**运动、变化与发展不能完全画等号**：发展特别强调方向上的前进与上升，并非凡是发生变化就一定构成发展。

#### 2. 新事物为什么具有生命力

1. **适应变化了的条件**：新事物具有新的要素、结构和功能，能够适应新的环境。
2. **通过扬弃超越旧事物**：不是把旧事物一笔勾销，而是在克服局限性的基础上保留有积极作用的因素，增添旧事物无法容纳的新内容。
3. **在社会历史领域具有群众基础**：新事物体现先进力量的创造性活动，从根本上符合人民群众的利益和要求，能够获得拥护，从而具有历史发展的生命力。

#### 3. 区分新事物与旧事物

| 判断方式 | 是否可靠 | 原因 |
| --- | --- | --- |
| 看**出现时间**是否更晚 | 不可靠 | 新出现的事物不一定是新事物 |
| 看**外在形式**是否新奇 | 不可靠 | 形式新颖不等于符合发展方向 |
| 看是否**合乎历史前进方向、具有远大前途** | 可靠 | 这是哲学意义上的新事物的核心判断标准 |
| 看是否**丧失历史必然性、日趋灭亡** | 用于判断旧事物 | 不以其存在时间长短作为唯一依据 |

<Callout type="tip" title="一句话区分">

**“新出现”强调时间，“新事物”强调发展方向。** 二者不能直接等同。

</Callout>

### 三、过程观点：一切事物都处于发展过程

任何事物都有其产生、发展和灭亡的历史，都是一定的**过程**。因此，世界可理解为各种过程的集合体。

唯物辩证法从**现实的暂时性**与**发展的永恒性**的统一出发理解事物，具有批判性和革命性。所谓“凡是在历史上产生的都要在历史上灭亡”，强调具体历史事物不是永恒不变的。

### 四、命题分析与经典干扰项

原书统计：**2010 年以来选择题考查 7 次**（原书统计口径）。

<Accordions>
  <Accordion title="错误：事物之间的联系通常都是人的主观意志赋予的">

忽视联系的**客观性**。人的活动可以建立具体联系，但联系有其客观基础，不能随心所欲。

</Accordion>
  <Accordion title="错误：一切联系都在人类实践活动中形成">

忽视自在事物的联系。自然界中的许多联系早于人类活动就已存在。

</Accordion>
  <Accordion title="错误：任意两个事物都可以直接联系起来">

混淆**普遍联系**和**直接联系**。普遍联系并不意味着忽略条件性，更不意味着任意两个对象都必须有直接联系。

</Accordion>
</Accordions>

#### 考点串联

**联系提供理解发展的条件和结构，发展揭示事物变化的方向，而矛盾则进一步解释发展的内在动力。** 下一专题的对立统一规律是这一逻辑的核心。

## 专题五｜对立统一规律

<Callout type="info" title="本专题的核心价值">

**对立统一规律是唯物辩证法的实质和核心**，回答事物“为什么发展”。考研尤其关注**矛盾同一性与斗争性、普遍性与特殊性、主要矛盾与矛盾主要方面**三组区分。

</Callout>

### 一、对立统一规律为什么是实质和核心

1. 揭示事物普遍联系的根本内容、变化发展的内在动力，从根本上回答**事物为什么发展**。
2. 贯穿量变质变规律、否定之否定规律以及唯物辩证法基本范畴，是理解其他辩证法规律与范畴的**中心线索和“钥匙”**。
3. 提供认识世界、改造世界的根本方法——**矛盾分析方法**。

### 二、矛盾的两种基本属性

矛盾是反映**事物内部或事物之间的对立统一关系**的哲学范畴。

| 基本属性 | 含义 | 特点 |
| --- | --- | --- |
| **同一性** | 矛盾双方相互联系、相互依存，并在一定条件下相互贯通 | **相对的、有条件的** |
| **斗争性** | 矛盾双方相互排斥、相互分离的倾向和趋势 | **绝对的、无条件的** |

- **同一性以差别和对立为前提**，不是取消差别的完全相同。
- **斗争性寓于同一性之中**，同一性通过斗争性体现；斗争有多样形式，基本可分为**对抗性**和**非对抗性**。
- **两者相互结合，共同推动发展**；不能把同一性或斗争性当作孤立起作用的力量。
- **和谐是矛盾的一种特殊表现形式**，体现特定条件下的平衡、协调与合作；和谐仍是相对的、有条件的，并不等于矛盾消失。

<Callout type="warn" title="易错的绝对与相对">

**绝对：斗争性。相对：同一性、和谐。** 不能认为矛盾同一性在任何情况下都起主要作用，更不能把同一性理解为矛盾双方完全没有差别。

</Callout>

### 三、矛盾的普遍性与特殊性

#### 1. 各自含义

- **普遍性（共性）**：矛盾无处不在、无时不有。
- **特殊性（个性）**：不同事物的矛盾、同一矛盾的不同方面及其在不同发展阶段上各有特点。

#### 2. 辩证统一关系

1. **共性是无条件的、绝对的**；**个性是有条件的、相对的**。
2. 任何现实事物的矛盾都是共性与个性的有机统一。
3. **共性寓于个性之中**：没有离开个性的共性，也没有离开共性的个性。
4. 人的认识一般经历**从个别到一般，再从一般到个别**的辩证发展过程。

<Callout type="tip" title="原文识别修正">

原文这一处重复出现“没有离开个性的个性”，属于明显的文字识别或誊录异常。此处按共性与个性的辩证关系校正为“**没有离开共性的个性**”。

</Callout>

#### 3. 共性与整体不是一回事

| 例子 | 属于哪种关系 | 理由 |
| --- | --- | --- |
| 水果与苹果 | **一般与个别** | 苹果具有水果的一般属性，同时有自身特殊属性 |
| 汽车与汽车零部件 | **整体与部分** | 零部件组成汽车，而不是汽车这一类别下的某个具体种类 |

不能把“共性寓于个性之中”颠倒为“个性寓于共性之中”：**个性比共性更为丰富**，共性不能穷尽个性的全部具体规定。

### 四、矛盾力量的不平衡性

<Tabs items={['主要矛盾', '矛盾的主要方面']}>
  <Tab value="主要矛盾">

在**诸多矛盾之间**，处于支配地位并对事物发展起决定作用的矛盾，是**主要矛盾**。

**判题提示：** 如果材料突出“很多问题中首先抓哪个关键问题”，通常优先考虑主要矛盾。

</Tab>
  <Tab value="矛盾的主要方面">

在**同一对矛盾的两个方面之间**，处于支配地位、起主导作用的一方，是**矛盾的主要方面**。**事物的性质主要由主要矛盾的主要方面决定**。

**判题提示：** 如果材料突出“某一事物的性质究竟由哪一方面主导”，通常优先考虑矛盾的主要方面。

</Tab>
</Tabs>

### 五、关于绝对与相对的集中比较

| 绝对的、无条件的 | 相对的、有条件的 |
| --- | --- |
| **运动** | 静止 |
| **时空的客观实在性** | 时空的具体特性 |
| **矛盾的斗争性** | 矛盾的同一性 |
| **矛盾的普遍性（共性）** | 矛盾的特殊性（个性） |
| — | 和谐（矛盾的一种特殊表现形式） |

#### 矛盾如何得到解决

矛盾双方的对立不能简单依靠主观意愿予以调和，但**矛盾的解决形式多种多样**，主要包括：

1. 一方克服另一方。
2. 双方同归于尽。
3. 双方形成协同运动的新形式。
4. 双方融合成为一个新事物。

因此“解决矛盾一定是其中一方消灭另一方”属于片面观点。

### 六、分析题：识别与组织答案

<Steps>
  <Step>

#### 确定问题是在问哪一层次

问“发展为什么发生”，联系**矛盾是发展内在动力**；问“如何处理相反因素”，联系**同一性和斗争性相结合**；问“普遍经验如何适用于具体情境”，联系**共性与个性相统一**。

</Step>
  <Step>

#### 判断是多个矛盾还是一个矛盾的两方面

“统筹多项任务、抓住关键问题”通常从**主要矛盾**切入；“判断事物性质、区分主流与支流”通常从**矛盾主要方面**切入。

</Step>
  <Step>

#### 用材料落实理论，而不是只堆术语

说明材料中的具体双方及其相互关系、在何种条件下发生转化，以及应如何坚持**具体问题具体分析**。注意区分一般规律与具体条件。

</Step>
</Steps>

### 七、命题分析与经典干扰项

原书统计：**2010 年以来本专题选择题考查 2 次**（原书统计口径）；此外它是**马原分析题的高频理论工具**，尤其是主要矛盾、对立统一关系、共性与个性以及相应的认识过程。

<Accordions>
  <Accordion title="错误：同一性在事物发展过程中始终处于主要方面">

同一性与斗争性都不能孤立发挥作用；不能无条件地判定同一性始终居于主要方面。

</Accordion>
  <Accordion title="错误：矛盾一方只有克服另一方才能实现统一">

矛盾解决有多种形式，包括双方形成新协同运动、融合成新事物等，并不只有“一方克服另一方”。

</Accordion>
  <Accordion title="错误：矛盾的普遍性就是整体，特殊性就是部分">

普遍性与特殊性是**一般与个别**关系；整体与部分是另一组范畴，不能混用。

</Accordion>
</Accordions>

## 专题六｜量变质变规律

<Callout type="info" title="一条主线">

**量变是质变的必要准备，质变是量变的必然结果；新的质变又为新的量变开辟道路。** 区分量变与质变，关键看变化**是否超出度，是否引起事物性质的根本改变**。

</Callout>

### 一、质、量、度：认识事物的三个规定性

| 概念 | 准确定义 | 判断角度 |
| --- | --- | --- |
| **质** | 一事物区别于其他事物的**内在规定性** | 它是什么，属于什么性质的事物 |
| **量** | 事物的规模、程度、速度等可以用数量关系表示的规定性 | 有多少，达到何种程度 |
| **度** | 保持事物**质的稳定性**的数量界限 | 在什么范围内仍是原来的事物 |
| **关节点（临界点）** | 度的两端界限 | 超出度的界限，原有的质就会发生改变 |

**认识质**是认识和实践的起点与基础，**认识量**使认识进一步深化、精确化。

<Callout type="tip" title="质、量与存在的关系">

- **质与事物的存在直接同一**：特定的质，是某物之所以为某物的根据。
- **量不与事物的存在直接同一**：在一定范围内，量的增减不改变原有的质。
- **度使二者联系起来**：说明量变在什么界限内仍不引发质变。

</Callout>

### 二、量变与质变：比较与识别

<Tabs items={['量变', '质变']}>
  <Tab value="量变">

量变是保持事物**质的相对稳定性**的不显著变化，体现发展渐进过程的**连续性**。

- 典型表现：数量增减、程度变化等。
- 判断抓手：虽然有变化，**事物的根本性质尚未改变**。
- 辅助例子：在一定条件下，液态水不断升温而尚未发生相变。

</Tab>
  <Tab value="质变">

质变是事物**性质的根本变化**，体现渐进过程与连续性的**中断**。

- 典型表现：突破原有度的界限，旧质被新质取代。
- 判断抓手：不是量的变化“看起来很大”，而是**质已经改变**。
- 辅助例子：在给定压强下，液态水达到相变条件而汽化。

</Tab>
</Tabs>

<Callout type="warn" title="最易混淆的判断标准">

**是否超出度**是区分量变与质变的根本标志；不能单凭变化的**速度、幅度、是否肉眼可见**判断。

</Callout>

### 三、量变质变的三层辩证关系

<Steps>
  <Step>

#### 量变是质变的必要准备

数量和程度的积累为质的飞跃创造条件。没有一定的量变过程，便不会出现与之相应的质变。

</Step>
  <Step>

#### 质变是量变的必然结果

量变达到一定程度，突破保持旧质的度，便会引起质变。因此，**单纯的量变不可能永远持续下去**。

</Step>
  <Step>

#### 质变为新的量变开辟道路

旧质转变为新质之后，事物在新的质的基础上继续经历量的变化，推动发展不断向前。

</Step>
</Steps>

#### 量变与质变相互渗透

1. 在**总的量变过程**中，可以出现**阶段性、局部性的部分质变**。
2. 在**质变过程**中，包含旧质的量逐渐收缩和新质的量逐渐扩张。

这意味着二者有区别，但并不是互不交错的机械阶段。

### 四、方法论：适度、积累与时机

| 材料关键词 | 所体现的原理 | 方法论意义 |
| --- | --- | --- |
| 恰到好处、过犹不及、掌握分寸 | **度与适度原则** | 需要保持原有质时注意界限 |
| 循序渐进、日积月累 | **量变是质变的必要准备** | 注重量的积累，防止急于求成 |
| 突破瓶颈、实现跃升 | **质变是量变的必然结果** | 条件成熟时抓住时机推动飞跃 |
| 新阶段、新起点 | **质变为新的量变开辟道路** | 在新的基础上继续发展 |

**适度原则不是“永不突破界限”**：维持某种性质时需要适度，推动发展时则可能需要创造条件，促成积极的质变。

### 五、命题分析与辨误

原书统计：**2010 年以来选择题考查 4 次**（沿用原书口径）。命题多要求根据具体材料识别量变、质变和适度原则。

<Accordions>
  <Accordion title="误区：数量变化幅度大，就必然是质变">

错误。质变的标志是**超出度、引起根本性质改变**；变化幅度大小不是独立判准。

</Accordion>
  <Accordion title="误区：量变过程不可能出现任何质变">

错误。总的量变过程中，可以发生**局部性、阶段性的部分质变**。

</Accordion>
  <Accordion title="误区：质变完成后，量变质变规律就停止作用">

错误。新的质变会开启**新基础上的量变**，发展仍然继续。

</Accordion>
  <Accordion title="误区：适度就是保守，不能突破旧状态">

错误。适度原则强调认识和把握度；实践中仍应根据发展需要，**把握实现积极质变的时机**。

</Accordion>
</Accordions>

**复习闭环**：质、量、度 → 量变与质变 → 必要准备、必然结果、新的量变 → 适度原则与把握时机。

## 专题七｜否定之否定规律

<Callout type="info" title="核心原理">

**辩证否定的实质是“扬弃”**：对旧事物既**批判又继承**，既克服消极因素又保留积极因素。**否定之否定规律揭示事物发展的前进性与曲折性的统一**。

</Callout>

### 一、辩证否定观：四个要点

| 要点 | 准确含义 | 考研识别语 |
| --- | --- | --- |
| **自我否定** | 否定是事物的**自我否定、自我发展**，是其内部矛盾运动的结果 | 自身发展、内在矛盾 |
| **发展的环节** | 通过否定，旧事物向新事物转变 | 新旧更替 |
| **联系的环节** | 新事物孕育于旧事物，二者通过否定相联系 | 继承基础、保留合理因素 |
| **扬弃** | 对旧事物**既克服又保留，既批判又继承** | 不是全盘否定，也不是原样照搬 |

#### 辩证否定与形而上学否定

<Tabs items={['辩证否定观', '形而上学否定观']}>
  <Tab value="辩证否定观">

- 根源：事物的**内部矛盾**推动自我否定。
- 性质：否定同时是**发展的环节、联系的环节**。
- 结果：**扬弃**，在继承合理因素的基础上形成新事物。

</Tab>
  <Tab value="形而上学否定观">

- 将否定看成**外在的、主观任意的否定**。
- 将否定理解为**不包含肯定的绝对否定**，只破坏不继承。
- 割裂事物发展的前后联系。

</Tab>
</Tabs>

<Callout type="warn" title="内部否定≠外部破坏">

教材用“人踩死虫子”说明**一物对另一物的外部否定**。它并非虫子内部矛盾推动的自我发展，不能拿来直接替代辩证否定的概念。对外部作用也不能一概抹去其影响，重点是区分**否定的根源**。

</Callout>

### 二、否定之否定：两次否定、三个阶段

<Steps>
  <Step>

#### 肯定阶段

事物在一定条件下保持已有的质，同时包含推动其变化发展的内在矛盾。

</Step>
  <Step>

#### 否定阶段

内部矛盾的发展推动原有状态被扬弃，形成相应的新阶段。

</Step>
  <Step>

#### 否定之否定阶段

再次经过辩证否定，事物在**更高的发展阶段**出现某些与出发点相似的特点，仿佛“回复”，实则**不是简单回到原点**。

</Step>
</Steps>

| 从哪个角度看 | 结论 |
| --- | --- |
| **总体方向** | **前进性**：新的阶段包含发展和提升 |
| **具体道路** | **曲折性**：不是直线式上升，中途会有反复和曲折 |
| **形象表述** | **波浪式前进、螺旋式上升** |

**教材例子**：古代朴素辩证法 → 形而上学 → 唯物辩证法。古代朴素辩证法与唯物辩证法都强调联系和发展，但后者建立在更丰富的科学实践基础上，不是思想史的简单循环。

<Callout type="tip" title="怎样把握“周期性”">

“肯定—否定—否定之否定”概括的是事物**辩证发展的逻辑**，不能机械要求每一种具体变化都严格呈现形式相同、时间相等的三个阶段。关键是**扬弃后的提高**，不是简单重复。

</Callout>

### 三、同量变质变规律、新旧事物关系的联系

- **量变质变规律**回答事物发展过程中**渐进性与飞跃性**的关系，突出变化的状态与形式。
- **否定之否定规律**揭示发展道路的**前进性与曲折性**，强调扬弃与螺旋式上升。
- **新事物与旧事物**不是割裂的：新事物通过扬弃超越旧事物，从旧事物获得必要的条件与合理因素。

### 四、命题分析与典型干扰项

原书统计：**2010 年以来选择题考查 6 次**（原书口径）。原书还提到“肯定、否定”的若干选项在其统计期内多作为干扰项，这属于**特定年份试题回顾**，不能当作未来考试的固定命题规则。

<Accordions>
  <Accordion title="错误：事物发展总是线性上升">

混淆了**总趋势的前进性**与**道路的曲折性**。正确表述是波浪式前进、螺旋式上升。

</Accordion>
  <Accordion title="错误：事物发展是周而复始的原样循环">

否认了发展中的**新质与更高阶段**。否定之否定的“回复”不是回到完全相同的原点。

</Accordion>
  <Accordion title="错误：发展是直线性与循环性的统一">

教材强调的是**前进性与曲折性的统一**，不能把发展归结成直线式上升或原样循环。

</Accordion>
  <Accordion title="错误：新事物对旧事物必须完全抛弃，没有任何继承">

违反辩证否定观。否定的实质是**扬弃**，既克服消极因素，又保留积极因素。

</Accordion>
</Accordions>

**记忆结构**：自我否定 → 发展环节、联系环节 → **扬弃** → 肯定—否定—否定之否定 → **前进性与曲折性统一**。

## 专题八｜联系和发展的基本环节（五对范畴）

<Callout type="info" title="五对范畴的共同方法">

五对范畴均体现**对立统一**。答题通常从“**区别是什么 → 怎样相互依存、相互作用 → 在什么条件下转化 → 对实践有什么启示**”四个角度展开。注意：每一对范畴的具体联系**不完全相同**，不能把所有关系机械套成“双方互相决定”。

</Callout>

### 一、五对范畴总览

| 范畴 | 前一项着重强调 | 后一项着重强调 | 核心关系 |
| --- | --- | --- | --- |
| **内容—形式** | 事物内部要素及其联系 | 内容得以表现的结构和方式 | **内容决定形式，形式反作用于内容** |
| **本质—现象** | 内在、一般、相对稳定的联系 | 外显、个别、多变的表现 | **本质决定现象，现象表现本质** |
| **原因—结果** | 引起一定现象的现象 | 被引起的现象 | **因果相连、相互依存；在不同联系中可互换角色** |
| **必然—偶然** | 事物发展中确定、合规律的趋势 | 不确定、非必定出现的表现 | **必然通过偶然表现，偶然受必然制约** |
| **现实—可能** | 当前实际存在的状况 | 尚未成为现实的发展趋势 | **条件具备时可能转化为现实** |

### 二、内容与形式

#### 1. 内容决定形式

**内容是事物存在的基础**，对形式起决定作用。有什么样的内容，就需要有与之相适应的形式；内容变化后，形式也需要作相应调整。

#### 2. 形式对内容具有反作用

- **适合内容的形式**，能够推动内容的发展。
- **不适合内容的形式**，可能阻碍内容的发展。
- **同一内容可以有不同形式**；**同一种形式也可以体现不同内容**。不能理解为一个内容只能对应一个固定形式。

<Callout type="tip" title="例子仅用于辅助理解">

同一教学内容可以用讲解、表格、图解等不同形式呈现。形式是否有效，要看是否**适合内容及其发展需要**，不能断言形式越复杂越好。

</Callout>

### 三、本质与现象

#### 1. 相互区别

| 比较 | 本质 | 现象 |
| --- | --- | --- |
| **范围** | 一般的、普遍的 | 个别的、具体的 |
| **稳定性** | 相对稳定 | 多变、易逝 |
| **位置与把握方式** | 深藏于事物内部，要通过**理性思维**把握 | 表面、外显，可为感官所感知 |

#### 2. 相互依存：本质决定现象，现象表现本质

**本质总通过现象表现自己的存在**，任何现象也都以某种方式表现着本质。因此，不存在完全不表现为现象的本质，也不存在完全不表现本质的现象。

#### 3. 真象、假象与错觉：三者不能混同

<Tabs items={['真象', '假象', '错觉']}>
  <Tab value="真象">

**客观的现象**：从直接、正面的方面表现事物本质。注意这里的“真象”不等同于日常用语中的“真相”。

</Tab>
  <Tab value="假象">

**客观的现象**：以歪曲、颠倒或相反的形式表现事物本质，**仍是本质的表现**。假象不能简单理解为“不存在的东西”。

</Tab>
  <Tab value="错觉">

**主观认识上的错误**：人在感知、判断中产生偏差。假象可能使人产生错觉，但**错觉不一定都由假象引起**。

</Tab>
</Tabs>

<Callout type="warn" title="易错判断">

- **真象和假象都是客观现象**；**错觉是主观的**。
- 不能说“假象不反映本质”，也不能说“仅凭直接感官就能把握本质”。

</Callout>

### 四、原因与结果

**原因**是引起一定现象的现象，**结果**是被引起的现象。

1. **相互区别**：在**同一个具体因果联系**中，原因与结果不能任意倒置，原因在前、结果在后。
2. **相互依存**：没有“无果之因”，也没有“无因之果”；实际因果链条总处在普遍联系中。
3. **相互转化**：某一现象在一个联系中是**结果**，在另一联系中可以成为**原因**，反之亦然。

<Callout type="tip" title="注意因果关系与时间先后不同">

有因果关系通常涉及先后，但**时间在前不必然就是原因**。判题还须看二者之间是否具有引起与被引起的客观联系。

</Callout>

### 五、必然与偶然

#### 1. 相互依存

**必然**体现事物发展中内在的、合乎规律的联系；**偶然**表现为并非一定如此发生的情况。二者相联系：**必然总是通过偶然表现出来，并借助偶然为自己开辟道路**。

#### 2. 相互转化

在不同过程、不同条件和联系中，某种现象的**必然或偶然地位可能发生变化**。不能抽离具体条件给某个事件贴上永恒的标签。

#### 3. 命题抓手

- 偶然因素**不是事物发展的根本决定因素**，但仍是发展中**不可忽视的因素**。
- **必然性与本质**处于同等程度的范畴，揭示事物内在联系；**认识必然性、认识本质**都是科学认识的重要任务。
- 教材的表达方向是**“必然通过偶然表现出来”**，不应颠倒成“偶然通过必然表现出来”。

### 六、现实与可能

| 概念 | 含义 | 命题关键词 |
| --- | --- | --- |
| **现实** | 当前实际存在的客观状况 | 已经存在、当下状态 |
| **可能** | 事物尚未实现、但有根据的发展趋势 | 潜在、趋势、发展方向 |
| **不可能** | 在相应条件下**没有实现根据和条件**的情况 | 缺乏客观根据 |

**现实会产生新的可能；可能只有在必要的主客观条件成熟时，才能转化为现实。** 发展过程体现现实与可能的辩证转化。

#### 对“可能”的进一步区分

<Tabs items={['现实的可能', '抽象（非现实）的可能']}>
  <Tab value="现实的可能">

具有**较充分的现实根据和条件**，实现所需条件更为成熟。

</Tab>
  <Tab value="抽象（非现实）的可能">

有一定客观根据，但**现实条件尚不充分**；不能把它当成已经能够立即实现的现实可能。

</Tab>
</Tabs>

人的实践可以**创造、改变条件**，促使好的可能转化为现实；但**主观愿望并不能把客观上不可能的事情任意变成可能**。

### 七、材料题：如何快速匹配五对范畴

<Steps>
  <Step>

#### 先找题目在比较什么

“方式、载体、结构”与“实际内涵” → **内容与形式**；“表象”与“内在规律” → **本质与现象**。

</Step>
  <Step>

#### 再找因果、规律或条件

“引发、导致” → **原因与结果**；“偶然事件与发展趋势” → **必然与偶然**；“条件成熟、前景实现” → **现实与可能**。

</Step>
  <Step>

#### 最后套用该范畴专属关系

明确“**什么决定什么**”“**什么表现什么**”“**在什么条件下转化**”，不要把五对关系混成一套无差别公式。

</Step>
</Steps>

### 八、经典干扰项汇总

原书统计：**2010 年以来选择题考查 8 次**（原书统计口径）。

<Accordions>
  <Accordion title="错误：事物发展的规律是纯粹偶然因素作用的结果；偶然因素可有可无">

前者抹去了规律的**内在必然性**；后者忽视了**偶然因素不可忽视**。历史过程总包含必然性与偶然性。

</Accordion>
  <Accordion title="错误：历史过程不包含任何偶然因素">

错误。**必然性通过偶然性表现**；历史的发展既有内在规律，也体现为丰富多样的具体事件。

</Accordion>
  <Accordion title="错误：事物的本质会随着人的认识改变；不能通过现象认识本质">

本质是**客观的内在联系**，不随人的主观认识任意改变；认识可以通过研究现象逐步把握本质。

</Accordion>
  <Accordion title="错误：只要充分发挥主观能动性，不可能就会转化为可能">

错误。主观能动性必须以**客观规律和现实条件**为根据，不可能被主观意志任意改变为可能。

</Accordion>
</Accordions>

**背诵总句**：**内容决定形式，形式反作用于内容；本质决定现象，现象表现本质；原因与结果相互依存、在不同联系中相互转化；必然通过偶然表现；可能在条件具备时转化为现实。**

## 专题九｜唯物辩证法是认识世界和改造世界的根本方法

<Callout type="info" title="本专题重点">

**唯物辩证法是客观辩证法与主观辩证法的统一。** 两者在**本质上统一、表现形式不同**，是**被反映与反映**的关系。运用辩证法，要求提升**辩证、历史、系统、战略、底线、创新**六种思维能力。

</Callout>

### 一、客观辩证法与主观辩证法

| 对照 | 客观辩证法 | 主观辩证法 |
| --- | --- | --- |
| **指向** | 客观事物自身的联系、运动与发展 | 客观辩证法在**人的思维中**的反映 |
| **表现形式** | **外部必然性的形式** | **观念的、逻辑的形式** |
| **基本关系** | 被反映的一方 | 反映的一方 |

- **统一性**：主观辩证法反映客观辩证法，二者在本质上统一。
- **差别性**：现实中的客观运动与思维中的观念、逻辑运动不是相同的存在形式。
- **方法论**：既不能把主观想法当作客观规律，也不能认为人的思维无法反映客观辩证联系。

<Callout type="warn" title="判断题防误">

“主观辩证法创造、决定客观辩证法”是错误的；“主观辩证法和客观辩证法毫无联系”也不对。**正确关系是反映与被反映的统一。**

</Callout>

### 二、六大思维能力

下表“典型材料”用于帮助识别题干，不是原书中的新增固定定义。

| 思维能力 | 把握的侧重点 | 题目中的典型线索 |
| --- | --- | --- |
| **辩证思维** | 联系、发展、全面地把握事物及其矛盾 | 一分为二、矛盾分析、统筹兼顾 |
| **历史思维** | 从历史过程、发展阶段与趋势理解问题 | 历史条件、历史方位、长期演进 |
| **系统思维** | 把握整体结构、要素关系及其协同 | 全局与局部、系统治理、协同配合 |
| **战略思维** | 着眼全局、长远、根本性问题 | 长远布局、整体谋划、抓住方向 |
| **底线思维** | 预判风险，准备应对不利局面 | 风险防范、守住底线、防患于未然 |
| **创新思维** | 面对新问题开拓新思路、新办法 | 破除惯性、创新办法、突破旧路径 |

#### 重点掌握系统思维

**系统**是由相互联系、相互作用的若干要素组成，具有**稳定结构和特定功能**的有机整体。

**坚持系统观念**，就是将事物放在**普遍联系的系统**中来认识和处理；系统的存在和特征体现了物质世界普遍联系的具体性。

<Tabs items={['理解系统', '识别命题']}>
  <Tab value="理解系统">

系统并非要素的简单堆积：要素之间的相互作用、结构安排以及整体功能，都是理解系统不可忽视的方面。既要分析**整体**，也要分析**组成部分之间的联系**。

</Tab>
  <Tab value="识别命题">

材料强调“部门各自为政导致效果不佳，需要跨部门协同、统筹全局”，通常可联系**系统思维**；材料强调风险预案、避免突破不可承受边界，则更偏向**底线思维**。

</Tab>
</Tabs>

### 三、用六种思维读材料

1. **看对象**：题干是否涉及多要素、多主体、多阶段？优先考虑联系、系统与历史视角。
2. **看任务**：是要求解释矛盾、观察长期趋势，还是制定策略、控制风险、提出新方法？
3. **看落点**：最后仍须回到**尊重客观规律**，在实践中运用科学的认识方法。

<Callout type="tip" title="分析题答题组织">

先说明材料体现的**思维能力和哲学依据**，再结合材料指出其**具体表现与方法论要求**。不要只堆砌“辩证、系统、创新”六个名词，而未解释为什么适用于题干。

</Callout>

### 四、命题分析与易错辨析

原书统计：**2010 年以来选择题考查 3 次**（原书口径）。选择题多要求判断材料运用了何种思维方法；原书还指出**辩证思维与创新思维**曾是分析题考点。

<Accordions>
  <Accordion title="误区：强调全局就可以忽略局部和具体要素">

错误。系统观念要求把握**整体、要素和相互联系**；不是用整体代替对部分的分析。

</Accordion>
  <Accordion title="误区：创新思维意味着不受现实条件和客观规律限制">

错误。创新仍须**立足实际、尊重客观规律**；不能将创新等同于主观任意设想。

</Accordion>
  <Accordion title="误区：六大思维互相排斥，每道材料只能体现一种思维">

错误。现实问题往往需要**多种思维共同运用**。选择题要抓题干最突出、最契合选项的方面。

</Accordion>
</Accordions>

**背诵框架**：**客观与主观辩证法**（反映关系）→ **六大思维能力**（辩证、历史、系统、战略、底线、创新）→ **系统的要素、结构、功能**（坚持系统观念）。
