## 道德起源、功能与集体主义层次

**1.** 道德起源的第一个历史前提是

**答案：** **劳动**

**2.** 这说明，道德的产生、发展和变化，归根结底源于

**答案：** **社会经济关系**

**3.** 道德具有多方面的功能和效力。通过评价等方式，指导和纠正人们的行为和实践活动、协调社会关系和人际关系的功效与能力，是道德的

**答案：** **调节功能**

**4.** 道德调节的主要形式是

**答案：** **道德评价**

**5.** 道德发挥作用的性质是由

**答案：** **道德所反映的经济基础、代表的阶级利益决定的**

**6.** 集体主义最高层次的道德要求是

**答案：** **无私奉献、一心为公**

**7.** 中华传统美德的根本要求是

**答案：** **公义胜私欲**

**8.** 中国革命道德的灵魂是

**答案：** **坚持社会主义和共产主义理想信念**

**9.** 社会主义职业道德的最高层次的要求是

**答案：** **奉献社会**

**答案：** **办事公道的要求**

## 家庭美德、个人品德与马克思主义道德观

**11.** 符合家庭美德的经典名言

**答案：** **“远亲不如近邻”**

**12.** 在社会道德建设中具有基础性作用的是

**答案：** **个人品德**

**13.** “吾日三省吾身”（曾子）属于中国传统道德修养方法中的

**答案：** **省察克治**

**14.** 个人加强道德修养，在无人监督时依然严格自我约束所体现的方法是

**答案：** **慎独自律**

**15.** 志愿服务是社会文明进步的重要标志，是新时代党引导动员人民群众贡献智慧力量、创造美好生活、实现奋斗目标的生动实践。志愿服务精神的精髓是

**答案：** **奉献**

**16.** 符合马克思主义道德观的表述

**答案要点：**

- **劳动是道德起源的首要前提**
- **道德是适应社会关系尤其是利益关系调节的需要而产生的**

**17.** 马克思主义道德观关于道德起源、本质和特征的正确认识包括

**答案要点：**

- 马克思主义在人类思想史上第一次科学而全面地论述了道德的起源问题，为正确认识和理解道德的本质奠定了基础
- **道德是一种特殊的社会意识形态**
- **道德在阶级社会里不可避免地具有阶级性**
- **道德是社会利益关系的特殊调节方式**

**18.** 作为社会意识的道德一经产生，便有相对独立性。这种相对独立性表现为

**答案要点：**

- **道德的历史继承性**
- **道德对社会发展具有能动的反作用**

**19.** 道德属于上层建筑的范畴，是一种特殊的社会意识形态。道德以善恶为评价方式，发挥作用主要是依靠

**答案要点：**

- **社会舆论**
- **传统习俗**
- **内心信念**

**20.** 道德的功能，一般是指道德作为社会意识的特殊形式对于社会发展所具有的功效与作用。在道德的功能系统中，最基本的功能是

**答案要点：**

- **认识功能**
- **规范功能**
- **调节功能**

## 社会主义道德先进性、传统美德与公民道德建设

**21.** 道德的作用主要表现在

**答案要点：**

- **巩固特定社会的经济基础和上层建筑**
- **提高人的精神境界**
- **促进人的自我完善**
- **推动人的全面发展**

**22.** 道德功能的发挥和实现所产生的社会影响及实际效果，就是道德的作用。道德

**答案要点：**

- **是维系社会稳定、促进国家发展的重要因素**
- **是激励人们改造客观世界和主观世界的一种精神力量**
- **在本质上是知行合一的**

**23.** 与以往社会的道德形态相比，社会主义道德具有显著的先进性特征。这种先进性主要体现在，社会主义道德

**答案要点：**

- **是社会主义经济基础的反映**
- **是对人类优秀道德资源的批判继承和创新发展**
- **克服了以往阶级社会道德的片面性和局限性**

**24.** 全心全意为人民服务是

**答案要点：**

- **贯穿中国革命道德始终的一根红线**
- **社会主义道德观的集中体现**
- **先进性要求和广泛性要求的统一**

**25.** 集体主义

**答案要点：**

- **强调国家利益、社会整体利益和个人利益的辩证统一**
- **强调国家利益、社会整体利益高于个人利益**
- **重视和保障个人的正当利益**

**26.** 根据我国现阶段经济社会生活和人们思想道德的实际，对公民最基本的集体主义的道德要求是

**答案要点：**

- **顾全大局、遵纪守法**
- **热爱祖国、诚实劳动**

**27.** 加强社会主义道德建设必须吸收借鉴优秀道德成果，传承中华传统美德。中华传统美德

**答案要点：**

- **是中华文化的精髓**
- **蕴含着丰富的思想道德资源**
- **是社会主义道德建设的源头活水**
- **是人类文明发展的重要精神财富**

**28.** 体现了中华传统美德强调道德修养，注重道德践履的有

**答案要点：**

- **“修己”“克己”和“慎独”**
- **“善养吾浩然之气”**
- **“察色修身”**

**29.** “六尺巷”体现以和为贵、谦和礼让的传统美德。与仁爱、和谐的思想相呼应的经典表达有

**答案要点：**

- **“己欲立而立人，己欲达而达人”**
- **“亲亲而仁，仁民而爱物”**
- **“兼相爱，交相利”**

**30.** 中国革命道德的当代价值在于，发扬革命道德、传承红色基因，有利于

**答案要点：**

- **加强和巩固社会主义和共产主义的理想信念**
- **培育和践行社会主义核心价值观**
- **引导人们树立正确的道德观**
- **培育良好的社会道德风尚**

**31.** 新时代加强公民道德建设，作为着力点的是

**答案要点：**

- **社会公德建设**
- **职业道德建设**
- **家庭美德建设**
- **个人品德建设**

**32.** 新时代公民道德建设的重点任务是

**答案要点：**

- **筑牢理想信念之基**
- **培育和践行社会主义核心价值观**
- **传承中华传统美德**
- **弘扬民族精神和时代精神**

<Callout type="idea" title="集体主义的三层理解">

坚持**国家利益、社会整体利益和个人利益的辩证统一**，强调前两者高于个人利益，同时**重视和保障个人正当利益**。不能将集体主义等同于否定一切个人利益。

</Callout>

## 公共生活、网络道德、职业诚信与家风建设

**33.** 当代公共生活的特征主要表现在

**答案要点：**

- **活动范围的广泛性**
- **活动内容的开放性**
- **交往对象的复杂性**
- **活动方式的多样性**

**34.** 公共生活需要公共秩序，有序的公共生活是

**答案要点：**

- **社会生产活动的重要基础**
- **提高社会成员生活质量的基本保障**
- **社会文明的重要标志**

**35.** 公共生活中的道德规范即社会公德

**答案要点：**

- **社会公德是指人们在社会交往和公共生活中应该遵守的行为准则**
- **遵纪守法是全体公民都必须遵循的基本行为准则**
- **社会公德是维护公共利益、公共秩序、社会和谐稳定的起码的道德要求**

**36.** 网络生活中的道德要求有

**答案要点：**

- **正确使用网络工具**
- **加强网络文明自律**
- **进行健康网络交往**
- **营造良好网络道德环境**

**37.** 诚实守信是

**答案要点：**

- **中华民族的传统美德**
- **我国公民道德建设的重点**
- **社会主义核心价值观的一条重要准则**

**38.** 职业道德中的诚实守信，要求从业者在职业活动中

**答案要点：**

- **诚实劳动**
- **合法经营**
- **信守承诺**
- **讲求信誉**

**39.** 之所以要注重家教、家风，是因为

**答案要点：**

- **家庭是人生的第一个课堂，父母是孩子的第一任老师**
- **良好的家风，对家庭成员的个人修养产生着重要的作用**
- **良好的家风，对整个社会道德风尚的形成产生着重要的影响**

**40.** 社会主义家庭文明新风尚的内容是

**答案要点：**

- **爱国爱家**
- **相亲相爱**
- **向上向善**
- **共建共享**

**41.** 志愿服务

**答案要点：**

- **是培育和弘扬社会主义核心价值观的重要载体**
- **归根结底是一种先进文化现象**
- **已成为大学生参与社会实践成长成才的重要舞台**
