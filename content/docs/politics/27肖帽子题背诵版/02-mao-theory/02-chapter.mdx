近代中国基本国情是 **半殖民地半封建社会**；新民主主义革命理论的核心问题是 **无产阶级领导权**。农村包围城市、武装夺取政权道路以土地革命、武装斗争和农村革命根据地建设相互配合为基础。

## 国情、革命性质与无产阶级领导权

**1.** 近代中国最基本的国情是

**答案：** **中国是一个半殖民地半封建的社会**

**2.** 1939年毛泽东在《中国革命和中国共产党》中指出，中国是在许多帝国主义国家的统治或半统治之下，实际上处于长期的不统一状态，再加上土地广大，其结果是

**答案：** **经济、政治和文化的发展表现出极端的不平衡**

**3.** 解放战争时期，毛泽东在《在晋绥干部会议上的讲话》中对新民主主义革命的总路线作了完整的概括。这里所说的“完整”是指在革命对象中增加了

**答案：** **官僚资本主义**

**4.** 中国民主主义革命经历了旧民主主义革命和新民主主义革命两个阶段，“旧”阶段转变到“新”阶段的根本标志是

**答案：** **中国革命领导阶级的变化**

**5.** 中国革命的中心问题是

**答案：** **领导权问题**

**6.** 因为中国资产阶级根本上与剥削农民的豪绅地主相联结相混合，中国革命要推翻豪绅地主阶级，便不能不同时推翻资产阶级。这一观点属于

**答案：** **“毕其功于一役”的观点**

**7.** “统帅革命的资产阶级，联合革命的无产阶级，实行资产阶级民主革命。”这一观点的错误实质在于

**答案：** **放弃无产阶级的领导权**

**8.** 在民主革命和社会主义革命的关系问题上，中国共产党党内曾经出现过不同的观点和主张，其中属于右倾错误的是

**答案：** **“二次革命论”**

**9.** 新民主主义革命理论的核心问题是

**答案：** **无产阶级领导权**

**10.** 新民主主义革命时期，党内犯“左”倾错误的人提出“毕其功于一役”的主张，搞所谓的“无间断”革命，这种错误倾向实质上是

**答案：** **混淆了新民主主义革命和社会主义革命的界限**

<Tabs items={["革命分阶段", "两种错误倾向"]} defaultIndex={0}>
<Tab value="革命分阶段">

- **新民主主义革命**是社会主义革命的必要准备。
- **社会主义革命**是新民主主义革命的必然趋势。
- 两个阶段 **既联系，又不能混为一谈**。

</Tab>

| **“毕其功于一役”** | 混淆民主革命与社会主义革命的阶段界限 |

## 土地革命、文化纲领、革命道路与三大法宝

**11.** 新民主主义革命的主要内容是

**答案：** **没收封建地主阶级的土地归农民所有**

**12.** 土地改革的主要和直接任务，就是

**答案：** **满足贫雇农群众的要求**

**13.** 新民主主义经济纲领中极具特色的一项内容是

**答案：** **保护民族工商业**

**14.** 新民主主义文化就是无产阶级领导的人民大众的反帝反封建的文化，即民族的科学的大众的文化。其中“民族的”，就其内容说，是指

**答案：** **反对帝国主义压迫，主张中华民族的尊严和独立**

**15.** 中国革命走农村包围城市、武装夺取政权的道路，根本在于处理好

**答案：** **土地革命、武装斗争、农村革命根据地建设三者之间的关系**

**16.** 这种社会性质决定了中国革命的主要形式是

**答案：** **武装斗争**

**17.** 毛泽东提出的“三大法宝”是指

**答案：** **统一战线、武装斗争、党的建设**

**18.** 中国革命建立最广泛的统一战线不仅是必要的，而且是可能的，这种可能是由

**答案：** **半殖民地半封建的中国社会的交织在一起的诸多矛盾所决定的**

**19.** 新民主主义革命时期，党领导的革命统一战线包含着两个联盟。其中作为统一战线的基础的联盟是

**答案：** **工人阶级同农民阶级、广大知识分子及其他劳动者的联盟**

**20.** 毛泽东思想关于党的建设理论中，始终放在党的建设的首位的是

**答案：** **加强党的思想建设**

## 革命纲领、统一战线与红色政权的存在条件

**21.** 新民主主义革命与旧民主主义革命相比有新的内容和特点，集中表现在新民主主义革命

**答案要点：**

- **处于世界无产阶级社会主义革命的时代，是世界无产阶级社会主义革命的一部分**
- **革命的领导力量是中国无产阶级及其先锋队中国共产党**
- **革命的指导思想是马克思列宁主义**
- **革命的前途是社会主义而不是资本主义**

**22.** 毛泽东指出，无产阶级及其政党要实现对同盟者的领导，必须具备的条件有

**答案要点：**

- **率领同盟者向共同敌人作坚决斗争并取得胜利**
- **给予同盟者物质利益，至少不损害其利益，同时进行政治教育**

**23.** 毛泽东把新民主主义革命和社会主义革命比喻为文章的上篇和下篇。“两篇文章，上篇与下篇，只有上篇做好，下篇才能做好”。毛泽东这段话的含义是

**答案要点：**

- **民主主义革命是社会主义革命的必要准备**
- **社会主义革命是民主主义革命的必然趋势**

**24.** 关于新民主主义政治纲领规定的新民主主义国家，正确的表述有

**答案要点：**

- **国体是各革命阶级联合专政**
- **政体是实行民主集中制的人民代表大会制度**
- **新民主主义共和国是一定历史时期的国家形式，是过渡的形式**
- **人民当家作主是新民主主义国家制度的核心内容和基本准则**

**25.** 新民主主义经济纲领的内容是

**答案要点：**

- **没收封建地主阶级的土地归农民所有**
- **没收官僚资产阶级的垄断资本归新民主主义的国家所有**
- **保护民族工商业**

**26.** 把官僚资本主义作为民主革命的对象，是因为官僚资本主义

**答案要点：**

- **背靠帝国主义，充当其买办，是买办的、封建的国家垄断资本主义**
- **同大地主、大资产阶级的反革命国家政权密切结合，成为国民党统治的经济基础**
- **严重束缚中国社会生产力的发展，阻碍社会进步**

**27.** 在新民主主义条件下保护民族工商业、发展资本主义，是因为

**答案要点：**

- **与官僚资产阶级相比，民族资产阶级同帝国主义和封建主义联系较少**
- **民族资本主义经济是与新生产力相联系的先进生产方式和经济成分**
- **允许私人资本主义经济在不操纵国计民生的范围内发展，有利于社会进步**

**28.** 按当时体例从右向左书写的四个大字，今天从左向右读来就是“本党为农”。党之所以如此重视农民，是因为

**答案要点：**

- **农民是中国革命的主力军**
- **新民主主义革命实质上就是党领导下的农民革命**
- **中国革命实质上就是党领导下的农民战争**

**29.** 中国走农村包围城市、武装夺取政权道路的依据是

**答案要点：**

- **农民占全国人口绝大多数，是无产阶级可靠的同盟军和革命主力军**
- **当时中国对内没有民主制度，受封建主义压迫，对外没有民族独立，受帝国主义压迫**

**30.** 土地革命战争时期，红色政权为何能够在白色政权包围中长期存在？其独特条件包括

**答案要点：**

- **近代中国是多个帝国主义间接统治的半殖民地国家，社会政治经济发展极端不平衡**
- **经历过大革命洗礼，革命群众基础较好**
- **全国革命形势继续向前发展**
- **相当力量的正式红军存在**
- **党的组织坚强有力且政策正确**

## 革命道路、人民军队与党的优良作风

**31.** 中国革命走农村包围城市、武装夺取政权的道路，必须处理好土地革命、武装斗争、农村革命根据地建设三者之间的关系。以下内容正确的有

**答案要点：**

- **土地革命是中国革命的基本内容**
- **武装斗争是中国革命的主要形式**
- **农村革命根据地是中国革命的战略阵地**

**32.** 近代中国社会的阶级结构是“两头小中间大”，“中间”是指

**答案要点：**

- **农民阶级**
- **民族资产阶级**
- **城市小资产阶级**

**33.** 新民主主义革命时期，以国共合作为基础所建立的统一战线有

**答案要点：**

- **国民革命联合战线**
- **抗日民族统一战线**

**34.** 总结党在新民主主义革命时期开展武装斗争的革命经验，建设人民军队要坚持

**答案要点：**

- **党对军队的绝对领导**
- **建设全心全意为人民服务的人民军队**
- **开展革命的政治工作**
- **坚持正确的战略战术原则**

**35.** 开展革命的政治工作是党在新民主主义革命时期建设人民军队的经验之一。人民军队政治工作的基本原则包括

**答案要点：**

- **官兵一致的原则**
- **军民一致的原则**
- **瓦解敌军和优待俘虏的原则**

**36.** 毛泽东在中共七大上总结的中国共产党区别于其他任何政党的显著标志有

**答案要点：**

- **理论和实践相结合的作风**
- **自我批评的作风**
- **和人民群众紧密地联系在一起的作风**

## 党的建设经验 · 思想、组织与作风

**37.** 中国共产党要领导革命取得胜利，必须不断加强党的思想建设、组织建设和作风建设。新民主主义革命时期党的建设的主要经验有

**答案要点：**

- **必须把思想建设始终放在党的建设的首位**，以无产阶级思想克服和改造各种非无产阶级思想
- **必须重视党的组织建设和作风建设**
- **必须联系党的政治路线加强党的建设**

<Callout type="idea" title="关联回顾 · 新民主主义革命三大法宝">

**统一战线、武装斗争、党的建设**是新民主主义革命的三大法宝。党的建设既要重视**思想建设**，也要结合组织建设、作风建设以及党的政治路线。
