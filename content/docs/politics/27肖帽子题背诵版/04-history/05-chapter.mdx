## 从九一八事变到全面抗战与抗日民族统一战线

**1.** 中国人民在九一八事变后开始的局部抗日战争

**答案：** **揭开了世界反法西斯战争的序幕**

**2.** 华北事变发生后，中国共产党组织领导的一二·九运动标志着

**答案：** **中国人民抗日救亡运动新高潮的到来**

**3.** 《义勇军进行曲》之所以发出“中华民族到了最危险的时候”的呐喊，最重要的原因是

**答案：** **日本大举侵华，妄图把中国变为其独占的殖民地**

**4.** 1935年12月，中共中央在陕北瓦窑堡召开政治局扩大会议，提出党的基本策略任务是

**答案：** **党的全面抗战路线的正式形成**

**7.** 1937年8月，中国共产党在陕北洛川召开政治局扩大会议，制定了抗日救国十大纲领，强调要打倒日本帝国主义，关键在于

**答案：** **使已经发动的抗战成为全面的全民族抗战**

**8.** 中国抗日战争进入全民族抗战阶段是在

**答案：** **卢沟桥事变后**

**9.** 毛泽东科学预见了抗日战争的发展进程，指出抗日战争的最关键阶段是

**答案：** **战略相持阶段**

**答案：** **减租减息**

**11.** 以下属于“三三制”原则中所说的中间派的是

**答案：** **开明绅士**

**12.** 抗日战争时期，为克服根据地面临的严重困难局面，毛泽东提出的经济工作和财政工作总方针是

**答案：** **“发展经济，保障供给”**

**13.** 整风运动最主要的任务是

**答案：** **反对主观主义以整顿学风**

**14.** 党的七大在党的历史上具有重要里程碑意义，标志着我们党在政治上、思想上、组织上走向了成熟。“在政治上”的成熟是指

**答案：** **全党团结在毛泽东的旗帜下，实现了党的空前统一和团结**

**15.** 成为抗日战争取得完全胜利的重要标志的是

**答案：** **台湾以及澎湖列岛重归中国主权管辖**

**16.** 这些具有国际法律效力的文件有

**答案要点：**

- **《开罗宣言》**
- **《波茨坦公告》**

**答案：** **以爱国主义为核心的民族精神**

**18.** 中华民族从近代以来陷入深重危机走向伟大复兴的历史转折点是

**答案：** **抗日战争的胜利**

## 持久战、抗日民族统一战线与延安整风

**答案要点：**

- **揭开了世界反法西斯战争的序幕**
- **成为中国人民抗日战争的起点**

**20.** 瓦窑堡会议是从第五次反“围剿”失败到全民族抗战兴起过程中召开的一次重要会议，它表明

**答案要点：**

- **党在新的历史时期将要到来时掌握了政治上的主动权**
- **党开始努力解决政治路线问题**
- **党正在从中国的实际情况出发，创造性地开展工作**

**21.** 洛川会议制定的党的全面抗战路线

**答案要点：**

- **把实行全民族抗战与争取人民民主、改善人民生活结合起来**
- **把反对外敌入侵与推进社会进步统一起来**
- **正确处理了民族矛盾与阶级矛盾的关系**

**22.** 以国共两党合作为基础的抗日民族统一战线正式形成的标志是

**答案要点：**

- **国民党中央通讯社发表《中共中央为公布国共合作宣言》**
- **蒋介石发表实际上承认中国共产党合法地位的谈话**

**23.** 《论持久战》一文

**答案要点：**

- **分析了中日双方存在着的互相矛盾的四个基本特点**
- **批驳了“亡国论”“速胜论”**，明确指出抗日战争是持久的，最后胜利属于中国
- **科学预见了抗日战争由防御到相持、最后到反攻的三个阶段**
- **强调“兵民是胜利之本”，战胜日本的侵略，必须进行人民战争**

**24.** 在中国人民抗日战争中，游击战被提到战略地位，具有全局性意义

**答案要点：**

- **游击战争主要是在外线单独作战，而不是在内线配合正规军的战役作战**
- **在民族战争条件下，游击战争能够大规模地进行**
- **在长期的不断削弱敌人**、壮大自己的斗争中，游击军和游击战必将向正规军和运动战发展

**25.** 独立自主的游击战争

**答案要点：**

- **实质上是抗日战争中时间最长、战斗战役持续不断的一场特殊战略大会战**
- **是人民军队发挥政治优势和军事优势最好的作战形式**
- **是坚持持久抗战、最终彻底战胜日本侵略者的唯一正确的政治军事方针**

**26.** 抗日民族统一战线是以国共合作为基础的。中国共产党在统一战线中要坚持独立自主原则，既统一，又独立。为此，共产党必须

**答案要点：**

- **保持在思想上、政治上和组织上的独立性，放手发动群众**
- **坚持对人民军队的绝对领导，努力发展人民武装和抗日根据地**
- **对国民党采取又团结又斗争、以斗争求团结的方针**

**27.** 针对这种情况，为了坚决揭露打击汪精卫集团的叛国投降活动，继续争取同蒋介石集团合作抗日，1939年7月，中国共产党明确提出的口号有
