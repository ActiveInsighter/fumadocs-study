大革命失败后，中国共产党逐步认识到**开展土地革命、建立人民军队和农村革命根据地**的重要性。逐步开辟**农村包围城市、武装夺取政权**的革命道路。

</Callout>

## 八七会议、工农武装割据与遵义会议

**1.** 国民党政府的统治同北洋军阀的统治没有本质的区别，这是因为

**答案：** **国民党所实行的是代表地主阶级、买办性大资产阶级利益的一党专政和军事独裁统治**

**2.** 在大革命失败的危急关头，中共八七会议确定的方针是

**答案：** **土地革命和武装起义**

**3.** 秋收起义不同于南昌起义的特点有

**答案要点：**

- **公开打出了“工农革命军”的旗帜**
- **不仅是军队的行动，而且有数量众多的工农武装参加**

**4.** 由大革命失败到土地革命战争兴起的历史性转变是

**答案：** **八七会议**

**5.** 在新民主主义革命时期，对中国革命具有决定意义的新起点是

**答案：** **从进攻大城市转为向农村进军**

**6.** 9月29日，毛泽东领导起义军在江西永新县三湾村进行了著名的三湾改编，确立了

**答案：** **支部建在连上的原则**

**7.** 古田会议创造性地解决了在农村环境中、在党组织和军队以农民为主要成分的条件下

**答案要点：**

- **如何保持党的无产阶级先锋队性质的重大问题**
- **如何建设党领导的新型人民军队的重大问题**

**8.** 在大革命失败、白色恐怖极其严重的条件下，中国革命之所以能够得到坚持和发展，根本原因就在于中国共产党

**答案：** **紧紧地依靠农民，领导农民进行了土地制度的革命**

**9.** 在土地革命战争时期建立的苏维埃政权的性质是

**答案：** **工农民主专政**

**10.** 在20世纪30年代前期、中期，中国共产党内屡次出现严重的“左”倾错误，其原因是多方面的。主要的原因在于

**答案：** **党不善于把马克思列宁主义与中国实际全面地、正确地结合起来**

**11.** 中央红军进行长征的直接原因是

**答案要点：**

- **红军在第五次反“围剿”作战中遭到失败**
- **红军已无在原地扭转战局的可能**

**12.** 开启了中国共产党独立自主解决中国革命实际问题的新阶段的会议是

**答案：** **遵义会议**

**13.** 中国共产党在长征途中召开的遵义会议，集中解决了在当时具有决定意义的

**答案：** **军事问题和组织问题**

**14.** 毛泽东系统地说明党的政治策略上的诸问题的著作是

**答案：** **《论反对日本帝国主义的策略》**

## 农村革命根据地、长征与历史经验

**15.** 中国共产党从失败的危局中开出了新局，表现在

**答案要点：**

- **举行了武装抵抗，创建了人民军队**
- **建立了农村革命根据地，实行了土地制度的改革**
- **开辟了农村包围城市、武装夺取政权的道路**

**16.** 在革命的危急关头，1927年7月中旬，中共中央政治局临时常委会决定

**答案要点：**

- **将党所掌握和影响的部队向南昌集中，准备起义**
- **组织湘、鄂、赣、粤四省的农民发动秋收起义**
- **召集中央紧急会议，讨论和决定大革命失败后的新方针**

**17.** 井冈山革命根据地的建立

**答案要点：**

- **集中体现中国革命的正确方向**
- **点燃了工农武装割据的星星之火**
- **为中国革命开辟出了农村包围城市**、武装夺取政权这样一条前人没有走过的道路

**18.** 1930年5月毛泽东在《反对本本主义》一文中提出和阐述的重要思想有

**答案要点：**

- **没有调查，没有发言权**
- **中国革命斗争的胜利要靠中国同志了解中国情况**

**19.** 农村包围城市、武装夺取政权的理论

**答案要点：**

- 是对1927年大革命失败后中国共产党领导的红军和根据地斗争经验的科学概括
- 是在同当时党内盛行的把马克思主义教条化的错误倾向作坚决斗争的基础上逐步形成的
- **标志着中国化的马克思主义即毛泽东思想的初步形成**

**20.** 中华苏维埃共和国

**答案要点：**

- **是中国共产党在局部地区执政的重要尝试**
- **扩大了党和红色政权的影响**，一定程度上加强了对处于被分割状态的各根据地的中枢指挥作用
- **推动了各根据地的政权**、经济、文化教育和党的自身建设，开创了土地革命战争新局面

**21.** 遵义会议

**答案要点：**

- **标志着中国共产党在政治上开始走向成熟**
- **确立党中央的正确领导，创造性地制定和实施符合中国革命特点的战略策略**
- **开启了党独立自主解决中国革命实际问题的新阶段**

**22.** 长征的胜利

**答案要点：**

- **极大地促进了党在政治上和思想上的成熟**
- **是中国革命转危为安的关键**
