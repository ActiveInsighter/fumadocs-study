## 商品、使用价值与价值及劳动二重性

**1.** 商品具有使用价值和价值两个因素或两种属性，是使用价值和价值的矛盾统一体。决定商品交换的比例的，不是商品的使用价值，而是价值，这是因为

**答案：** **价值在质上是相同的**

**2.** 资本主义制度下的社会财富表现为一种庞大的商品堆积，单个商品表现为其元素形式。下列说法正确的是

**答案：** **不论财富的社会形式如何，使用价值总是构成财富的物质内容**

**3.** 马克思说“一个物可以是使用价值而不是价值。在这个物并不是由于劳动而对人有用的情况下就是这样。”这说明

**答案：** **商品一定是劳动产品**

**4.** 马克思指出：“使用价值虽然是社会需要的对象，因而处在社会联系之中，但是并不反映任何社会生产关系。”这段话表明

**答案：** **使用价值是商品的自然属性**

**5.** 这里所说的“没有质的区别的人类劳动”是指

**答案：** **抽象劳动**

**6.** 马克思指出“在同一时间内，劳动就一种属性来说必然创造价值，就另一种属性来说，必然保存或转移价值。”这一段话说的是

**答案：** **具体劳动和抽象劳动及其作用**

**7.** 马克思指出“如果物没有用，那么其中包含的劳动也就没有用，不能算作劳动，因此不形成价值。”这段话说明

**答案：** **价值的存在以物的有用性为前提**

**8.** 马克思说“一切商品对它们的所有者是非使用价值，对它们的非所有者是使用价值。”也就是说，商品的使用价值和价值不可兼得。“不可兼得”的意思是说

**答案：** **要获得商品的价值，就必须放弃商品的使用价值，反之亦然**

**9.** 任何一种生产商品的劳动，一方面是特殊的具体劳动，另一方面又是一般的抽象劳动，这就是劳动的二重性。在资本主义生产过程中，工人的劳动作为具体劳动，它

**答案：** **转移生产资料的价值**

**10.** 具体劳动能否还原为抽象劳动，在根本上取决于

**答案：** **私人劳动和社会劳动能否实现统一**

**11.** 商品是劳动产品，生产商品的劳动具有二重性，即具体劳动和抽象劳动。具体劳动和抽象劳动是对立统一的关系，二者的区别体现在

**答案：** **具体劳动反映人与自然的关系，抽象劳动反映商品生产者的社会关系**

**12.** 在商品经济条件下，解决私人劳动和社会劳动之间矛盾的唯一途径是

**答案：** **商品交换**

## 社会必要劳动时间、货币与商品经济基本矛盾

**13.** “既然商品的价值由生产商品所耗费的劳动量来决定，那么一个人越懒、越不熟练，他制造商品所花费的时间越多，其商品就越有价值。”这一说法的错误在于混淆了

**答案：** **个别劳动时间和社会必要劳动时间**

**14.** 生产商品所需要的社会必要劳动时间随着劳动生产率的变化而变化。劳动生产率是指

**答案：** **劳动者生产使用价值的效率**

**15.** 在其他条件不变的情况下，随着社会劳动生产率提高而提高的是

**答案：** **单位时间生产的商品数量**

**16.** 这表明，提高劳动生产率会使单位时间内生产的商品数量和个别商品的价值量发生变化，即

**答案：** **商品数量增加，个别商品的价值量减少**

**17.** 俗话说“一分钱一分货”，但是在实际的商品交换过程中，既有“一分钱二分货”的现象，也有“一分钱半分货”的现象。这说明

**答案：** **价格围绕商品的价值自发波动**

**18.** 马克思主义认为，货币是

**答案：** **固定充当一般等价物的商品**

**19.** 充当贮藏手段的货币

**答案：** **必须是足值的金属货币**

**20.** 消费者的经济行为中，属于货币执行价值尺度职能的是

**答案：** **购买商品房，合同约定房价30万元**

**21.** 商品的使用价值和价值的矛盾、生产商品的具体劳动和抽象劳动的矛盾，根源于

**答案：** **私人劳动和社会劳动的矛盾**

**22.** 商品生产者的劳动的社会性质是由

**答案：** **社会分工决定的**

**23.** 这种价值论试图用价值分配来解释价值创造，混淆了

**答案：** **价值形成的源泉和价值形成的条件之间的关系**

**24.** 在资本主义条件下，劳动是否是生产性的，取决于

**答案：** **劳动能否为资本家带来剩余价值**

**25.** 以私有制为基础的商品经济的基本矛盾是

**答案：** **私人劳动和社会劳动的矛盾**

<Callout type="warn" title="价值量易错点">

决定商品价值量的是 **社会必要劳动时间**，不是个别生产者耗费的劳动时间；提高**社会**劳动生产率，在其他条件不变时使**单位商品价值量下降**，单位时间商品数量增加。

</Callout>

<Tabs items={["剩余价值生产", "资本基本计算"]} defaultIndex={0}>
<Tab value="剩余价值生产">

| 对比概念 | 区分关键词 |
| --- | --- |
| **绝对剩余价值** | 延长工作日、提高劳动强度，以延长剩余劳动时间 |
| **相对剩余价值** | 缩短必要劳动时间、在工作日长度不变时相对延长剩余劳动时间 |
| **超额剩余价值** | 个别价值低于社会价值，个别企业先行提高劳动生产率 |

</Tab>
<Tab value="资本基本计算">

- **剩余价值率** = 剩余价值 ÷ 可变资本 × 100%。
- **例：**&#x2060;预付资本 100 万元，不变资本与可变资本之比为 3∶1，则可变资本为 25 万元；剩余价值率为 200% 时，剩余价值为 **50 万元**。
- **逆向例：**&#x2060;预付资本 100 万元，剩余价值率 150%，剩余价值 30 万元，则可变资本为 20 万元，不变资本与可变资本之比为 **4∶1**。
- **注意：**&#x2060;劳动时间计算题若省略了原题具体条件，不能仅凭两个百分比反推完整解题过程。

</Tab>
</Tabs>
